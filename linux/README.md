# MarkupCraft for Linux

MarkupCraft comes inside [CadCraft Studio](https://github.com/getcadcraft/studio) (all eight apps in one install) from 0.5 on; there are no separate MarkupCraft installers any more. Get Studio 0.7 from the [download page](https://getcadcraft.com/download#studio) or its [GitHub release](https://github.com/getcadcraft/studio/releases/tag/studio-v0.7.0). Studio ships as a `.deb` and an AppImage.

## File types

- Listed under "Open with": `.pdf` (PDF document)
