BCF（BIM 协作格式）是一种开放的文件格式，用于在 BIM 工具之间传递问题。许多模型协调和建模程序都可以将 `.bcfzip` 文件作为问题列表导入。MarkupCraft 写入的是 **BCF 2.1**。

## 生成文件

1. 打开“{{ui:Markups}}”选项卡。
2. 筛选列表，只保留你要发送的内容，例如“{{ui:Status}}”为“待处理”。只有列出的批注会被导出。
3. 选择{{ui:BCF}}。
4. 等待程序为每条批注生成快照（“正在为 BCF 生成快照（第 5 个，共 20 个）…”）。

结果：“<name> markups.bcfzip”开始下载，状态栏会显示其中包含的主题数量和文件大小。

## 包含的内容

每条批注都会成为一个**主题**：

| 主题字段 | 填写内容 |
|---|---|
| 标题 | 整改编号、主题和图纸，例如“#4 A-101 上的云线 — 平面图” |
| 类型 | 批注类型（云线、标注框、长度……） |
| 状态 | 待处理、已接受、已拒绝或已完成 |
| 标签 | 批注类型和图纸 |
| 作者和日期 | 批注的作者、创建日期和修改日期 |
| 指派对象、截止日期 | 来自其整改项（如有） |
| 描述 | 其文字或图章文字、测量值、注释，以及图纸和文件 |
| 评论 | 每条回复一条，附带作者和日期 |
| 快照 | 批注在其所在图纸部分上的图片 |
| 视点 | 批注在图纸上位置的俯视图 |

再次导出同一批注会得到相同的主题 ID，因此支持导入 BCF 的工具可以将其识别为同一个问题。

## 需要注意的局限

- **图纸不是模型。** 视点指向批注在纸面上的位置，以纸面上的米为单位计量。它无法让 BIM 工具定位到模型中的某处。请使用快照和图纸名称来查找位置。
- **状态和类型是 MarkupCraft 自有的**（待处理、已接受、已拒绝、已完成；云线、标注框……）。文件按 BCF 允许的方式声明了它们，但拥有固定列表的工具可能会映射或忽略这些值。
- **导入带回的是注释，而不是模型视图。** {{ui:Import BCF}}会为你导出的批注添加回复和状态，并为其他问题生成备注；它无法显示模型相机。参见[批注列表与导出](topic:markups-list-and-export#import-bcf)。
- 对于图纸审阅，通常将批注以 PDF 形式发回更简单。BCF 用于将图纸上的意见带入模型协调流程。
