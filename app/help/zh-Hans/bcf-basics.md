BCF（BIM协作格式）是一种开放的文件格式，用于在 BIM 工具之间传递问题。许多模型协调和创作程序可以将 `.bcfzip` 文件作为问题列表导入。MarkupCraft 写入 **BCF 2.1**。

## 制作文件

1. 打开{{ui:批注}}选项卡。
2. 筛选列表，只保留要发送的内容，例如{{ui:状态}}为“打开”。只有列出的批注会被导出。
3. 选择{{ui:BCF}}。
4. 等待程序为每个批注生成快照（“正在为BCF生成快照（第5项，共20项）…”）。

结果：“<name> markups.bcfzip”开始下载，状态栏显示其中的主题数量和文件大小。

## 文件内容

每个批注对应一个**主题**：

| 主题字段 | 填充内容 |
|---|---|
| 标题 | 整改编号、主题和图纸，例如“#4 A-101上的修订云线 — 平面图” |
| 类型 | 批注类型（修订云线、标注框、长度…） |
| 状态 | 打开、已接受、已拒绝或已完成 |
| 标签 | 批注类型和图纸 |
| 作者和日期 | 批注的作者、创建日期和修改日期 |
| 负责人、截止日期 | 来自其整改项（如有） |
| 描述 | 批注的文字或图章内容、测量值、注释，以及图纸和文件 |
| 评论 | 每条回复一条，附作者和日期 |
| 快照 | 批注在图纸相应部分的图片 |
| 视点 | 批注在图纸上位置的俯视图 |

再次导出同一批注会得到相同的主题 ID，因此导入 BCF 的工具可以将其识别为同一问题。

## 导入时返回的内容

{{ui:导入BCF}} 可读取 BCF 2.0、2.1 和 3.0 文件（已用 19 个 buildingSMART 官方 3.0 测试文件检查：所有主题均可读取，其中三个含文字的主题，其评论也已读取）。对于属于你的主题（主题 ID 相同），它会将新评论添加为回复，并采用新状态。其他主题会成为其标签或文件名所指图纸上的注释；若没有指定，则成为当前打开图纸上的注释。注释的文字为主题的标题、描述、负责人和截止日期，其评论作为回复。

| BCF 主题中的内容 | MarkupCraft 中的对应 |
|---|---|
| 标题、描述、负责人、截止日期 | 注释文字 |
| 含文字的评论 | 回复 |
| 状态 打开、已接受、已拒绝、已完成（Closed、Resolved、Done 计为已完成） | 批注状态 |
| 作者和创建日期 | 注释的作者和日期 |
| 相机位置 | 图纸上的位置，仅适用于通过标签或文件名与图纸关联的主题 |
| 模型选择、隐藏部分、剖切平面、快照 | 不保留：图纸上没有可显示它们的模型 |

## 使用限制

- **图纸不是模型。** 视点指向批注在纸面上的位置，以纸面上的米为单位计量。它无法让 BIM 工具跳转到模型中的某个位置。请使用快照和图纸名称找到该位置。
- **状态和类型是 MarkupCraft 自己的**（打开、已接受、已拒绝、已完成；修订云线、标注框…）。文件会按 BCF 允许的方式声明它们，但具有固定列表的工具可能会映射或忽略它们。
- **导入带回的是评论，而不是模型视图。** {{ui:导入BCF}} 会为你导出的批注添加回复和状态，并为其他问题生成注释；它无法显示模型相机。参见[批注列表与导出](topic:markups-list-and-export#import-bcf)。
- 对于图纸评审，通常将批注以 PDF 形式发回更简单。BCF 用于将图纸上的评论带入模型协调流程。
