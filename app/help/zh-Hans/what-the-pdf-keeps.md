标注副本是在原始 PDF 上添加批注（PDF 注释）后得到的文件。页面本身及其图形、文字、书签和链接都会原样复制。

## 每个批注

| MarkupCraft | 保存为 | 其他 PDF 查看器显示为 |
|---|---|---|
| 矩形、框云 | 方形注释（云线：云状边框） | 矩形或云线注释 |
| 椭圆 | 圆形注释 | 椭圆注释 |
| 多边形、自由云线 | 多边形注释（云线：云状边框） | 多边形或云线注释 |
| 多段线 | PolyLine 注释 | 多段线注释 |
| 直线、箭头 | 直线注释（箭头：闭合箭头） | 直线或箭头注释 |
| 长度 | 标记为尺寸并带有测量值的直线注释 | 长度测量（若查看器支持） |
| 面积 | 标记为面积并带有测量值的多边形注释 | 面积测量（若支持）；否则为多边形 |
| 计数组 | 一个墨迹注释，每个项目一个圆环；其文字为 "group: n" | 墨迹注释 |
| 画笔、荧光笔 | 墨迹注释（荧光笔会被标记为荧光笔） | 墨迹注释 |
| 文字 | FreeText 注释 | 文本框注释 |
| 标注框 | 带标注引线的 FreeText 注释 | 标注框注释 |
| 注释 | 文本注释 | 便签，打开后显示其文字 |
| 图章 | 图章注释 | 图章注释 |

每个批注都会连同以下内容一并保存：

- **其自身外观**，完全按 MarkupCraft 在屏幕上的绘制方式保存，因此在任何查看器中外观一致，打印效果也相同，包括整改编号标记；
- **作者**、**创建和修改日期**、**主题**、**批注文字**（对于文本框和标注框，为文字和批注内容）、**颜色**和**不透明度**；
- **其 MarkupCraft 详细信息**，保存在其他程序会忽略的私有条目中：状态、整改项、样式和类型，以便精确地重新打开。

## 回复串和状态

- 每条回复都会保存为链接到其批注的回复注释，并包含其作者、日期和文字。回复在图纸上没有自己的图标。
- 每次状态变更都会保存为携带审阅状态的回复。其他审阅工具会将其显示为已接受、已拒绝或已完成；“待处理”状态保存为无状态。
- 状态不是“待处理”但没有记录状态变更的批注，会获得一条审阅状态回复，以便其他程序也能看到其状态。
- 对原始文件中只读批注的回复，以相同方式保存，并链接到该批注。

## 每张图纸

- **比例**：已校准的图纸会获得一个覆盖整页的测量视口（保存页面比例的标准方式），以及 MarkupCraft 自身的校准副本。
- **图纸编号**：使用{{ui:重命名图纸}}输入的编号会成为页面标签。若某个文件的任一页有标签，该文件的每一页都会获得标签：依次使用输入的编号、原有标签，最后是页码。
- **图纸标题**：输入的标题仅供 MarkupCraft 保存；其他查看器不显示。

## 文字与字符

文字以 Helvetica 字体书写，所有 PDF 查看器都具备该字体。西欧字符集（Windows-1252）以外的字母在副本中会显示为“?”；保存消息会统计这些字符的数量。

## 计算表和说明

计算表和说明保存在 PDF 中名为 `/MarkupCraftShell` 的私有条目中。其他 PDF 程序会忽略该条目。旧版 MarkupCraft 同样会忽略它，并会在下次保存该文件时将其删除。

## 已有批注的处理

打开已包含批注的 PDF 时：

- MarkupCraft 自身的批注会被完全读回。若其他程序移动或调整了其大小，则以新位置为准。
- 其他程序的矩形、椭圆、直线、多段线、多边形、墨迹、文本框和便签会成为可编辑的批注。**保存时，MarkupCraft 会删除原始注释，并以自己的方式重新写入**，包括其弹出框和回复。外观可能略有变化。
- 其他程序的审阅状态会设置批注状态；以最新的为准。
- 其他内容（文字高亮、其他程序的图章及特殊类型）会在副本中**原样保留**，且为只读。
- 链接和表单字段会原样保留，不会在列表中列出。

再次保存同一文件不会产生重复：MarkupCraft 读取的批注会被替换，而不是再次添加。

## 不会更改的内容

磁盘上的原始文件永远不会被更改。副本未针对大小进行优化，因此可能比原文件略大。受保护（加密）的 PDF 无法保存。
