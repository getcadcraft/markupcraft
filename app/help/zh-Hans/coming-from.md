如果你在 Bluebeam Revu（或其他桌面 PDF 程序）中审阅图纸，MarkupCraft 的大部分功能会让你感到熟悉：云线、标注框、工具集、批注列表、带回复的状态、校准后的测量、图纸叠加。文件处理方式是最大的不同，因此即使你跳过其余部分，也请阅读下一节。

## 五个关键差异

1. **保存会生成新文件。** MarkupCraft 在浏览器中运行，无法覆盖你磁盘上的 PDF。{{ui:Save}}会下载“<name> (marked up).pdf”，原文件保持不变。下次请打开“(marked up)”副本，旧副本请自行清理。
2. **保存时才会保存 PDF。** 在此之前，此浏览器中的恢复副本会在崩溃或关闭标签页时保留你的批注，并在下次提供恢复。它只是安全网：保存 PDF 才能保留审阅结果。
3. **你的配置保存在浏览器中。** 你的作者姓名、工具设置和工具集保存在此电脑的此浏览器中。使用其他浏览器或电脑时会重新开始，清除网站数据也会将其删除。请将工具集导出为备份。参见[保存在此浏览器中的内容](topic:browser-storage)。
4. **尚不支持共享会话。** 目前没有实时共享的审阅会话，也没有云端项目。审阅通过 PDF 传递：保存，发送副本，下一位审阅人回复并保存。
5. **比例以图纸为单位，且仅以图纸为单位。** 图纸内没有视口，也没有“将此比例应用于所有页面”的功能。请校准你要测量的每张图纸。

## 逐项对照

| 你习惯的功能 | 在 MarkupCraft 中 |
|---|---|
| 缩略图面板、页码标签 | 左侧的{{ui:Sheets}}。名称来自页码标签，或从标题栏读取；可使用{{ui:Rename sheet}}修改。 |
| 将多个 PDF 作为一组打开 | 一次性全部打开，它们会成为一个列表。不会保存图纸集文件：下次请重新打开相同的 PDF。 |
| 带工具组的工具集 | “{{ui:Tools}}”选项卡：每个浏览器一个工具集，已保存的工具包含样式和主题。通过 JSON 文件的{{ui:Export}}和{{ui:Import}}进行分享。其他程序的工具集文件无法导入。 |
| 属性面板 | “{{ui:Properties}}”选项卡：状态、主题、注释、样式、回复和整改项集中在一处。 |
| 带列的批注列表 | “{{ui:Markups}}”选项卡，可按图纸、作者、状态和类型筛选。可导出 CSV 或 BCF。暂不支持自定义列，也暂不支持 PDF 或工作簿摘要。 |
| 状态和审阅状态 | {{ui:Status}}：待处理、已接受、已拒绝、已完成。不支持自定义状态集。以标准审阅状态保存。 |
| 批注上的回复 | {{ui:Properties}}中的“回复”串，状态更改会记录在其中。已发送的回复无法编辑。 |
| 校准，然后测长度、面积、计数 | {{ui:Calibrate}}、{{ui:Length}}（{{key:M}}）、{{ui:Area}}（{{key:Q}}，同时给出面积和周长）、{{ui:Count}}（{{key:U}}）。暂不支持角度、半径、体积、多段线长度或洞口。 |
| 叠加页面 | “{{ui:Compare}}”选项卡：红色表示旧图，蓝色表示新图，通过两点对齐。不支持自动“比较文档”圈注。 |
| 图章 | {{ui:Stamp}}，内置六种图章，可自定义文字，并附带你的姓名和日期。暂不支持图片或签名图章。 |
| 整改或问题跟踪 | “{{ui:Punch list}}”选项卡：带编号的项目，包含负责人、截止日期和状态；可导出 CSV。 |
| 实时协作会话 | 尚不可用。请传递已保存的 PDF。 |
| 合并 | 尚未实现。批注仍作为其他查看器可显示和打印的注释保留。 |
| 批注图层 | 尚未实现。请使用主题、作者和列表筛选来整理注释。 |
| 图纸之间的超链接 | 尚未实现。 |
| 空格键平移，滚轮缩放 | 相同：按住{{key:Space}}键并拖动；滚轮在指针处缩放。滚轮不会滚动页面。 |

## 不同的按键

许多单字母快捷键与你的预期相同，但在你下意识按下之前，请先检查以下几项：

- {{key:K}}是{{ui:Callout}}，{{key:Q}}是{{ui:Area}}。如果你习惯用 Q 绘制标注框，在这里它会开始绘制面积。
- {{key:C}}是方框{{ui:Cloud}}；{{key:Shift+C}}是{{ui:Free cloud}}。
- {{key:M}}是{{ui:Length}}，{{key:U}}是{{ui:Count}}，{{key:Y}}是{{ui:Polyline}}，{{key:G}}是{{ui:Polygon}}，{{key:I}}是{{ui:Highlight}}。
- {{key:Mod+D}}会创建所选内容的副本（而不是浏览器的书签功能）。
- {{key:Mod+Plus}}和{{key:Mod+Minus}}缩放图纸，而不是浏览器页面。
- 任何按键都可以更改：见下文。

:::tip
如果你的操作习惯来自 Bluebeam Revu，请在{{ui:Settings}} › {{ui:MarkupCraft}} › {{ui:Menus, keys and mouse}}中选择{{ui:PDF review}}菜单样式：顶部为菜单栏（文件、编辑、视图、文档、批注、测量、窗口），下方为一排审阅工具，{{key:Q}}用于标注框，{{key:H}}用于高亮，{{key:N}}用于多边形，测量功能则使用{{key:Alt+Shift}}加字母。在那里也可以更改任何按键。参见[菜单、按键和鼠标](topic:menus-keys-and-mouse)。
:::

完整列表见[键盘和鼠标](topic:keyboard)。

## 与众不同的行为

- **工具保持选中状态。** 绘制一个云线后，你仍然在绘制云线。按一次{{key:Esc}}键会清除选择，按两次则返回{{ui:Select}}。
- **文字和标注框需要有内容。** 未输入任何内容就结束，将不会添加批注。备注将保持为空。
- **测量需要先设置比例。** 在未校准的图纸上，{{ui:Length}}和{{ui:Area}}会切换到{{ui:Calibrate}}，完成后返回。
- **其他程序的批注。** 在其他程序中创建的矩形、椭圆、直线、多段线、多边形、墨迹、文本框和便签会成为可编辑的 MarkupCraft 批注，并在保存时按 MarkupCraft 的方式重写（外观可能略有变化）。文本高亮、其他程序的图章以及其他特殊类型保持只读：你可以回复它们，但不能更改。
- **西欧字母以外的字符**在保存的 PDF 中会显示为“?”。参见[保存批注后的 PDF](topic:save-the-marked-up-pdf)。
- **图章日期使用 UTC。** 因此在美洲晚间制作的图章可能显示为次日的日期。
- **测量会以标准测量批注的形式保留。** 每张已校准的图纸都会保留其比例，因此能读取 PDF 测量信息的程序通常可以显示它们。具体行为取决于该程序。

## 同时使用两者

你可以在两者之间来回切换。在其他程序中创建的批注可在 MarkupCraft 中打开，而“(marked up)”PDF 可在其他 PDF 程序中打开，所有批注、回复和状态均可见。只有 MarkupCraft 能读回的内容（整改项的负责人和截止日期、项目状态）会保存在文件中，供 MarkupCraft 使用。
