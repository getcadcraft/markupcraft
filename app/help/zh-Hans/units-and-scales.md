## 输入长度

通过两点校准时，请输入实际距离。MarkupCraft可识别以下所有格式：

| 输入内容 | 含义 |
|---|---|
| `24'-0"` | 24英尺 |
| `12' 6 1/2"` 或 `12'-6 1/2"` | 12英尺6½英寸 |
| `12' 6` | 12英尺6英寸（省略英寸符号） |
| `6"` 或 `1/2"` | 英寸 |
| `12.5'` 或 `12.5 ft` | 12½英尺 |
| `3 ft 6 in` | 3英尺6英寸（也可用 feet、foot、inch、inches） |
| `3.5 m`、`90 cm`、`900 mm` | 公制（也可用 meter、metre、millimeter、centimetre…） |
| `24` | 不带单位的数字，按{{ui:Show lengths in}}中选择的单位计算 |

也可使用弯引号（’ ”）以及两个单引号（''）表示英寸。零长度和负长度会被拒绝。

:::warning
逗号会被识别为小数点：`1,5 m`表示1.5米。请勿输入千位分隔符：`1,200 mm`会被识别为1.2毫米。请输入`1200 mm`。
:::

## 长度和面积的显示方式

| {{ui:Show lengths in}} | 长度显示为 | 面积显示为 |
|---|---|---|
| {{ui:Feet and inches}} | `12'-6 1/2"`，舍入到1/16英寸 | 平方英尺，保留两位小数 |
| {{ui:Decimal feet}} | `12.54'`，保留两位小数 | 平方英尺，保留两位小数 |
| {{ui:Inches}} | `150.5"`，最多保留两位小数 | 平方英寸，保留一位小数 |
| {{ui:Meters}} | `3.820 m`，保留三位小数 | 平方米，保留三位小数 |
| {{ui:Millimeters}} | `3820 mm`，取整毫米 | 平方毫米，取整 |

面积的周长使用长度格式。

## 预设比例

预设假定PDF为其完整打印尺寸：每英寸72个PDF点，与CAD程序的输出方式一致。

| 组别 | 比例 | 长度显示单位 |
|---|---|---|
| 建筑 | 1/32" = 1'-0"、1/16"、3/32"、1/8"、3/16"、1/4"、3/8"、1/2"、3/4"、1"、1 1/2"、3" = 1'-0" | 英尺和英寸 |
| 工程 | 1" = 10'、20'、30'、40'、50'、60'、100' | 十进制英尺 |
| 公制 | 1:1、1:5、1:10、1:20、1:25、1:50 | 毫米 |
| 公制 | 1:100、1:200、1:250、1:500、1:1000 | 米 |

若要使用预设比例，但以其他单位显示长度，请改为通过两点校准，并在那里选择单位。

## 其他程序保存的比例

当PDF已包含另一程序为某页保存的比例（页面上存储的测量比例）时，若其单位为英尺、英寸、米、厘米或毫米，MarkupCraft会使用该比例。其标签按文件中的原样显示。

## 图纸位置

无论图纸比例如何，状态栏都会以英寸为单位显示指针在图纸上的位置（相对于图纸左上角）。Compare的微调步长以点为单位（每英寸72个点）。

## 精度

测量的精度取决于校准和你的点击。请使用你能找到的最长已知尺寸进行校准，放大视图以点击其端点，然后检查另一个尺寸。制作时已缩放的PDF（“适合页面”输出或半尺寸图纸集），在通过某个尺寸校准后仍然准确，但不能使用预设比例。
