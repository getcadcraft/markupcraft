这是 MarkupCraft 0.7 相比 0.6 的变化。最大的新功能是现场记录：RFI、提交文件和施工日志与批注一起保存在 PDF 中。

## 新增

### RFI、提交文件和施工日志

- **Field 选项卡。** 打开{{ui:现场}}选项卡，选择{{ui:RFI}}、{{ui:提交文件}}或{{ui:施工日志}}。在 RFI 或提交文件所属的图纸上点按或点击，会放置一个定位标记；施工日志则直接放在当前打开的图纸上，不带定位（{{ui:放置定位}}可稍后添加，{{ui:移动定位}}可移动任意定位）。每条记录都有自己的编号（RFI-0001、SUB-0001、LOG-0001）、标题、文字、状态、负责人、到期日期、回复串，以及附件名称列表。参见[跟踪 RFI、提交文件和施工日志](topic:field-records)。
- **查看哪些已逾期。** 可按类型、状态、到期日期（已逾期、7 天内到期、有或没有到期日期）、本张图纸或所有图纸、文字搜索或{{ui:分配给我}}来筛选列表。超过到期日期且仍在等待的记录，会在列表和其定位上以红色标记为**已逾期**。参见[查找重要内容](topic:field-records#find-what-matters)。
- **CSV 和 BCF。** {{ui:CSV}}将列出的记录写成电子表格；{{ui:BCF}}将其写成 BCF 主题，每个主题附带其在图纸上位置的快照。两者都会遵循当前筛选条件。参见[导出](topic:field-records#export)。
- **离线，并将两个副本合并为一。** 记录保存在 PDF 内，无需网络，因此现场的平板电脑可以添加、回复并保存记录。回到办公室后，{{ui:合并}}会按 ID 把另一份同一 PDF 副本中的记录合并进来，且作为一步撤销。参见[保存、离线和合并副本](topic:field-records#save-offline-and-merging-copies)。

### AI 助手

- **助手能做的更多。** 通过 CadCraft Studio 连接的自备助手现在可以设置批注状态（`markup_status`，记录在其回复串中）、在回复串中回复（`markup_reply`），并将{{ui:批注}}列表导出为 CSV 或 BCF（`markups_export`，即列表在筛选后显示的内容）。每项更改都是一步撤销，并以助手的名称签名。参见[助手可以请求的内容](topic:use-with-ai-assistants#what-an-assistant-can-ask-for)。

## 所有应用

- **单位。** {{ui:设置}} › {{ui:常规}} › {{ui:单位}} 下分别为长度、面积、体积、角度和坡度提供一份列表，列出单位定义给出的确切尺寸（美国测量英尺是其独立单位）。关闭从不使用的单位，它们就会从单位列表中移除；给某个单位加星标，新工作就会以该单位开始。文件始终保留其自身的单位。在 MarkupCraft 中，{{ui:设置}} › {{ui:MarkupCraft}} 里的测量和位置单位，以及校准对话框中的单位，都会跟随这些开关；星标会设定测量单位，直到保存 MarkupCraft 自己的设置为止；校准时输入的实际距离可以带有任何单位标记，例如 `3 yd` 或 `1.5 km`。参见[单位、输入的数值和单位列表](common:unit-lists)。
- **更紧凑的布局，面板可收起。** {{ui:设置}} › {{ui:常规}} › {{ui:布局密度}} › {{ui:紧凑}}可在屏幕上容纳更多内容（触摸屏和手机保留较大的按钮）。每个侧边面板都有一个细长的标题栏：拖动它可停靠或浮动面板；将其放到另一个面板的标题栏上，可共用同一框架并作为选项卡显示；将其固定，可使其滑向边缘收起；或将其隐藏，之后再从边缘调出。参见[排列面板](common:arrange-panels#make-the-layout-denser)。
- **对话框可以移动。** 用标题栏把对话框拖离绘图区域；它会回到你离开时的位置。双击标题栏可将其重新居中。参见[移动对话框](common:arrange-panels#move-a-dialog)。
- **AI 助手的操作方案。** 十个供自备助手使用的完整请求（整理图形、打印一套图纸、检查图纸、向模型提问、汇总算量、尝试零件变体……），每个都列出其调用的工具和所需权限，并经过我们的测试重放。应用本身不包含 AI。参见[AI 助手方案](common:assistants-recipes)。
- **语言。** **Português (Portugal)** 是{{ui:设置}} › {{ui:常规}} › {{ui:语言}}中的新选项。它、**Português (Brasil)**、**Español (México)** 和 **Bahasa Indonesia** 现在都提供了应用的全部文字，但仍是尚未经母语者审阅的草稿。帮助主题仍为英文。
- **CadCraft Studio** 在更新检查失败时会说明原因（尚无适用于当前系统的文件、无网络、签名错误），而不只是显示“完成”；并且在有更新版本之前，不会再次显示已关闭的“新增功能”卡片。

## 此版本尚未包含

- **0.7 版未进行代码签名。** 签名以及 Microsoft Store 安装包已推迟到 0.8 版，因为证书验证尚未完成。请在 getcadcraft.com/download 上核对每个文件旁边的 SHA-256。在 Windows 上，如果 SmartScreen 阻止安装程序，请选择{{ui:更多信息}}，然后选择{{ui:仍要运行}}。在 Mac 上，首次运行时，请右键点击 CadCraft Studio 并选择{{ui:打开}}。CadCraft Studio 尚未在应用商店上架，也还没有 iPad 或 iPhone 版本。
- {{ui:单位}}中的角度和坡度列表已保存，但尚无任何程序读取它们。
- 现场记录不会在 CadCraft Studio 实时协作会话中共享（实时会话仅携带批注）；请使用{{ui:合并}}汇总副本。
- 合并时，记录会整体取自最后修改的副本：若两人修改了同一记录的不同字段，则以较晚副本的字段为准。回复串和附件名称会被合并。
- 附件仅为名称，文件保留在原处。记录没有团队、通知或云项目功能，助手目前也没有用于记录的工具。
- 现场记录已在浏览器中以手机和平板尺寸、断网的状态下测试，但尚未在真实平板电脑上手动测试。
- 仍沿用自 0.6 版的内容：将页面对象旋转到任意角度、直接在页面中绘制新图形、更改直线的字体或大小，以及跨多行的文字环绕。包含页面编辑的已保存副本尚未在 Acrobat 中打开过。
- 仍沿用自 0.5 版的内容：撤销页面更改（如添加空白页）、读取扫描图纸中的文字，以及超出你自己网络范围的实时会话。

其余内容见[尚未实现的功能](topic:not-built-yet)。
