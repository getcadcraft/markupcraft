MarkupCraft 仍在开发中。以下是当前版本**不**支持的功能，方便你据此安排工作。这里描述的是当前版本，而不是承诺。

## 与他人协作

| 尚未实现 | 目前这样做 |
|---|---|
| 在不同电脑之间进行云端保存与同步 | 将 PDF 与项目文件放在一起保存。云端保存暂不可用。 |
| 合并两人各自的批注副本 | 在审阅人之间分配图纸，或使用 {{key:Mod+C}} 与 {{key:Mod+V}} 复制少量批注。RFI、送审文件和施工日志可以合并：参见 [跟踪 RFI、送审文件和施工日志](topic:field-records)。 |
| 针对 RFI 和送审文件的团队协作、通知及云端项目 | 将 PDF 转交出去，并使用 {{ui:Merge}} 将各副本合并。 |
| 在实时协作会话中处理 RFI、送审文件和施工日志 | 每人各自处理自己的副本；再用 {{ui:Merge}} 将副本合并。 |
| 合并两人对同一记录不同字段的更改 | 最后更改的副本会整体覆盖该记录（其回复串和附件名称会合并）。事先约定由谁编辑哪条记录。 |
| 用于 RFI、送审文件和施工日志的助手工具 | 在 {{ui:Field}} 选项卡中使用。助手可以处理批注：参见 [将 MarkupCraft 与 AI 助手配合使用](topic:use-with-ai-assistants)。 |
| 编辑或删除已发送的回复 | 立即{{ui:Undo}}，或添加一条更正回复。 |
| 更改批注的作者 | 开始前先设置你的名称。 |

## 批注

| 尚未实现 | 目前这样做 |
|---|---|
| 带可填写字段的图章、认证数字签名 | 使用自定义文字图章（包含你的姓名和日期），或使用签名图片。 |
| 附加照片以外的文件（文档、视频） | 与 PDF 放在一起保存，并在评论中注明。 |
| 指向网站或未打开文件的链接 | 在评论中写明地址或文件名。 |
| 自定义状态集 | 使用四种状态；其他内容请用主题说明。 |
| 编辑随文件以只读方式附带的批注（文本高亮、其他程序的图章） | 回复这些批注，或在它们旁边绘制 MarkupCraft 批注。 |
| 压感笔画 | 设置线宽。 |

## 图纸本身的内容

| 尚未实现 | 目前这样做 |
|---|---|
| 直接在页面中绘制新图形 | 先以批注绘制，再使用 {{ui:Put into the page}}。参见 [修改页面本身的内容](topic:page-content)。 |
| 将页面对象旋转到任意角度 | 移动并调整大小；使用 {{ui:Pages}} 旋转整页。 |
| 更改一行文字的字体或字号，或跨多行的文字 | 逐行修改文字；如需其他字体的新文字，请添加文字批注。 |
| 编辑扫描图片内的内容 | 替换图片，或为其添加批注。 |
| 编辑已加密或已签名的 PDF | 请对方提供未签名副本；批注适用于任何 PDF。 |

## 测量

| 尚未实现 | 目前这样做 |
|---|---|
| 半径测量 | 沿其绘制 {{ui:Arc}}，或测量横跨的 {{ui:Length}} 再取一半。 |
| 编辑洞口的角 | 删除洞口后重新绘制。 |
| 一次为多张图纸应用同一比例 | 逐张校准；选择预设比例每张约需几秒。 |
| 同一张图纸上的多个比例（视口） | 按你测量最多的图纸进行校准。更改图纸比例会重新测量其上的所有内容，因此在为某个细部重新校准前，请先记下细部数值。 |
| 捕捉图纸中的线条 | 点击前放大，或直接输入长度和角度（参见 [按比例草图](topic:calibrate-and-measure#sketch-to-scale)）。 |
| 包含项目、组合和价格的完整算量 | 使用 TakeoffCraft，即 CadCraft 系列的算量应用。 |

## 图纸与文件

| 尚未实现 | 目前这样做 |
|---|---|
| 撤销页面更改（旋转、移动、插入、删除） | 不保存直接关闭，然后重新打开原始 PDF。参见 [打印及更改页面](topic:pages-and-printing)。 |
| 关闭集合中的单个文件 | {{ui:Close}} 会关闭整个集合；需要的文件请重新打开。 |
| 将集合保存为项目并一步重新打开 | 重新打开同样的 PDF。 |
| 按选定比例打印，或一张纸打印多张图纸 | 使用浏览器的打印对话框，或在其他 PDF 阅读器中打印已保存的副本。 |

## 列表与导出

| 尚未实现 | 目前这样做 |
|---|---|
| 将导入的 BCF 问题放置到模型的对应位置 | 未关联到任何图纸的导入问题会堆叠在左上角：请手动移动。 |
| 从其他批注程序导入工具集 | 重新创建所需工具并保存到工具集；为办公室导出该工具集。 |

## 比较

| 尚未实现 | 目前这样做 |
|---|---|
| 比较以字体设置的文字，或生成变更列表 | 使用叠加和滑块，或对绘制线条使用 {{ui:Changed lines}}。 |
| 按线条比较扫描图纸 | 使用图片叠加。 |
| 比较整个集合时自动对齐每一对 | 单独比较有偏移的一对，并使用 {{ui:Align by two points}}。 |

## 面板

| 尚未实现 | 目前这样做 |
|---|---|
| 移动工具栏或状态栏 | 只有两侧面板可以移动。 |

## 平台

- **桌面端：** MarkupCraft 可在 Mac、Windows、Linux 和 iPad 的浏览器中运行，也可在 CadCraft Studio（一次安装包含全部八个应用的桌面应用）中运行。
- MarkupCraft 仍在开发中。标签和行为可能仍会变化，本帮助也会随之更新。
