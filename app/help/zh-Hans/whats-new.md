这是 MarkupCraft 0.8 和 0.8.1 相比 0.7 的变更。最大的新功能是：批注可以成为一项任务，由某人或你连接的助手来完成，并且当图纸真正发生变化时自行关闭。

## 新增

### 会动作的批注

- **将批注设为任务。** 选择一个或多个批注，打开 {{ui:任务}} 选项卡并选择 {{ui:将所选设为任务}}。任务包含标题、负责人（某个人或你连接的助手）、可选的到期日和状态，并保留其在图纸上的位置和回复串。参见 [将批注设为任务](topic:markups-that-act)。
- **自行关闭的任务。** 任务可以监视其批注内的图纸。打开图纸的较新修订版本并选择 {{ui:立即检查}}：如果该区域的线条变化超过一点点，任务会标记为已完成，其批注变为已完成，回复串中的一条备注会说明变化内容。新的日期戳，或移动不到 1.5 点的线条，不计入变化。任务也可以改为监视模型构件：你的助手使用 `tasks_check` 报告该构件，之后报告的内容不同，或构件被删除，都会关闭任务。一步撤销即可重新打开任务。
- **查找工作。** 按状态和负责人筛选 {{ui:任务}} 列表，包括 {{ui:已逾期}}；选择 {{ui:负责人}}，然后选择 {{ui:助手}}，查看等待你的助手处理的内容。超过到期日的任务会在问题面板中显示为警告。{{ui:CSV}} 导出列表。任务与批注一起保存在 PDF 中，并像其他批注属性一样通过实时协作传递。

### 以纯列表显示的变化

- **列出变更。** 打开 {{ui:比较}} 选项卡，然后选择 {{ui:比较整个图纸集}}，选择较早和较晚的文件，再选择 {{ui:列出变更}}。列表先显示数量，然后逐一列出每张变化的图纸，变化最大的排在最前：图纸上的位置、大小（既有实际单位，也有已校准图纸上的纸面英寸）、线条是增加还是删除、该处有多少批注，以及哪些词出现或消失。{{ui:复制列表}} 将其放入剪贴板，{{ui:CSV}} 为每个变化写入一行。参见 [列出修订之间的变化](topic:what-changed-in-words)。

### 语音备注和决定

- **语音备注。** 在 {{ui:备注}} 选项卡中选择 {{ui:录制语音备注}}，然后选择 {{ui:停止录制}}；录音满两分钟会自动停止。备注固定在图纸中心，你可将其拖到合适位置，并在 {{ui:特性}} 中输入说明文字，列表中的 {{ui:播放}} 可播放它。录音保存在 PDF 内。
- **决定。** {{ui:固定一项决定}} 会在图纸上写下一两句话。如果它取代了早先的决定，请在 {{ui:取代}} 中选择那一项：旧决定保留，标记为已被取代，并指向新决定。一步撤销即可撤回。参见 [在图纸上固定语音备注和决定](topic:voice-notes-and-decisions)。

### 红线批注发送至修订

- **发送与答复。** 在 {{ui:任务}} 选项卡中打开 {{ui:红线批注发送至修订}}，输入批注所对照的修订，然后选择 {{ui:导出红线文件}}。你会得到一个 `.redline.json` 文件，每个未关闭的批注对应一项：图纸、位置（以图纸的比例小数表示，因此以其他尺寸重新出图仍能对齐）、文字、作者、回复串及其任务。做修改的人在 `.redline-answers.json` 文件中将其答复为已接受、已拒绝或已完成；{{ui:加载答复文件…}} 会为每个批注设置该状态以及绘图人员的备注，并作为一步撤销。参见 [将批注作为红线批注发送给绘图人员](topic:redline-to-revision)。

### AI 助手

- **更多工具。** 通过 CadCraft Studio 连接的助手现在可以列出任务（`tasks_list`）、创建或更改任务（`task_set`）、移除任务（`task_clear`）、对照较新修订或某个构件检查任务（`tasks_check`），并读取两个已打开图纸集之间变化的纯列表（`revisions_changes`）。它只能使用你在“助手”开关下勾选的工具，并且每次更改都是一步撤销。参见 [在 AI 助手中使用 MarkupCraft](topic:use-with-ai-assistants)。

## 所有应用

- **语言。** CadCraft Studio 现在支持 54 种语言。新增十种：立陶宛语、拉脱维亚语、波斯尼亚语、马拉地语、泰卢固语、阿尔巴尼亚语、南非荷兰语、菲律宾语、斯瓦希里语和乌兹别克语。所有非英语语言都是机器翻译草稿，待母语者审阅后才算完成。
- **输入设备。** {{ui:设置}} › {{ui:全局}} › {{ui:输入设备}} 用于设置触控板、鼠标侧键、手写笔、手指点击、3D 鼠标、游戏手柄或 MIDI 控制器的功能，可对所有应用生效，也可仅对当前应用生效。在你更改任何设置之前，所有设备都保持原有功能。参见 [使用触控板、3D 鼠标或控制器](common:input-devices)。
- **工具栏行数。** {{ui:设置}} › {{ui:常规}} › {{ui:工具栏行数}} 提供 {{ui:换行}}（默认）、{{ui:2行}} 和 {{ui:1行}}，使图纸获得更多空间。参见 [安排面板](common:arrange-panels)。
- **特性网格。** 批注的样式字段使用共享网格，带有可折叠的类别以及标签和值两列。
- **问题面板。** 应用发出的警告，例如已逾期的任务，都会汇集到一个问题面板中。
- **实时协作和插件。** 实时协作会话见 [一起实时协作](common:work-together-live)；随账户的插件列表见 [插件和账户列表](common:addons-basics)。
- **连接你的 AI。** CadCraft Studio 是你自己的助手的中心：连接一次，即可用于全部八个应用。应用本身不包含任何 AI 功能。

## 0.8.1 中的修复

- **Studio 可在运行时切换语言。** 之前，桌面应用和打包版本保持英文。此功能尚未在所有平台上测试：如果语言没有变化，请反馈给我们。
- Studio 0.8 安装版会通过 {{ui:设置}} › {{ui:更新}} 提供 0.8.1 更新。

## 本版本尚未包含

- **未进行代码签名。** Windows 安装程序和 macOS .dmg 尚未签名。在 Windows 上，如果 SmartScreen 阻止安装程序，请选择 {{ui:更多信息}}，然后选择 {{ui:仍然运行}}。在 Mac 上，右键单击 CadCraft Studio 并选择 {{ui:打开}}。应用商店版本暂缓发布。
- **连接你的 AI 尚不完善。** 本版本不承诺提供 Studio 内的一键连接、面向浏览器助手的托管连接器，以及在 Studio 内使用你自己的 API 密钥。任务循环已经测试，但尚未与真实助手一起测试。
- **任务检查需要相同的页面尺寸。** 以其他尺寸重新出图的图纸将无法匹配，因此其任务不会关闭。图纸按图号配对，无图号时按页面位置配对。
- **语音备注仅为录音。** 没有文字转录，助手只能看到备注的长度、作者和说明文字，无法听到声音。录音功能已在无界面浏览器中使用模拟麦克风测试；手机、平板或笔记本上的真实麦克风仍待检查。
- **PDF 中的计算表和原因** 保存在文件的一个私有条目中。旧版 MarkupCraft 会忽略该条目，并在下次保存文件时将其删除，因此请使用 0.8 或更高版本打开并保存此类文件。
- **红线批注中绘图人员一侧的功能。** CadCraft 读取红线批注文件并作出答复的功能尚未实现。
- **其他语言。** 泰米尔语的应用栏超出 528 px。

其余内容见 [尚未实现的功能](topic:not-built-yet)。上一版本见 [0.7 的新增功能](topic:whats-new-0-7)。
