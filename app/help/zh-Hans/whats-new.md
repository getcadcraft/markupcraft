这是 MarkupCraft 0.9 相对于 0.8.1 的变更。核心理念是：你的工作备注不会出现在交给客户的图纸上，并且整套图纸可以一次性完成链接。

## 新增

### 备注、粘贴板和私人注释

- **粘贴板。** 每张图纸周围的区域就是一张工作台：在图纸旁边绘制、输入或粘贴的内容都是备注，永远不会被打印。选择{{ui:显示粘贴板}}可缩小视图以获得更多空间，或选择{{ui:快照到粘贴板}}，拖出一个框，然后选择{{ui:到粘贴板}}，将图纸局部的图片放在图纸旁边。快照是一张图片，图纸改变时它不会随之改变。参见[备注、粘贴板和私人注释](topic:notes-and-pasteboard)。
- **显示和隐藏备注。** 任何批注都可以设为备注：在{{ui:备注}}选项卡中设置{{ui:新建批注为}}，或在{{ui:特性}}中设置{{ui:此批注为}}。{{key:Shift+H}}或图纸下方的{{ui:备注}}开关可同时隐藏或显示所有备注。备注不会出现在打印件、合并副本、列表和导出文件中，其他 PDF 阅读器也不会显示它们。你保存的 PDF 会保留这些备注，供你下次在 MarkupCraft 中打开时使用。
- **私人注释。** 选择{{ui:设置口令}}，然后将某个批注设为{{ui:私人注释}}。它会以至少 10 个字符的口令加密保存在文件中，并且无法恢复：包括我们在内的任何人都无法在没有口令的情况下打开它。{{ui:锁定}}会收起私人注释；{{ui:在此设备上保持解锁}}默认关闭。
- **保存干净副本。** {{ui:保存干净副本}}会删除所有备注、私人注释以及粘贴板上的全部内容。请将它用于发送给客户的文件。

### 整套图纸链接

- **批量链接。** 选择{{ui:页面}} › {{ui:批量链接…}}，或在{{ui:图纸}}面板中的{{ui:查找文字}}下选择{{ui:链接图纸索引…}}。第 1 步列出每张图纸从其标题栏读取的编号和名称；如有错误请予以更正。第 2 步列出找到的索引，例如 `3/A-501` 或 `DETAIL 2 ON A-501`。{{ui:待链接}}显示每个索引对应的图纸和视图，{{ui:未链接}}显示没有对应已打开图纸的编号，{{ui:创建链接}}会一次性全部创建，并且只占一个撤销步骤。补遗或重新编号后可再次运行；手动创建的链接永远不会被更改。带视图的链接会保存为 PDF 链接，因此其他阅读器也能打开该详图。参见[图纸链接](topic:sheet-links)。

### 图纸

- **圆弧，十种方法。** {{ui:圆弧}}工具（{{key:O}}）现在在图纸上方提供一个{{ui:圆弧方法}}框，共十种绘制圆弧的方式，角度、长度、半径和方向均可通过点击或输入指定。参见[用十种方式绘制圆弧](topic:draw-an-arc)。

### 协同工作

- **跟随审阅者。** 在 Live 会话中，选择某人姓名旁的{{ui:跟随}}，你的视图就会随其移动；你自己平移或缩放即可停止跟随。主持人可以选择{{ui:让所有人跟随我}}。人员列表会显示每个人的颜色、姓名、所在图纸以及其最后一次编辑的时间。参见[在 Live 会话中跟随其他审阅者](topic:follow-in-live)。

## 所有应用

- 工具提示使用 Bootstrap 工具提示，启动提示可以关闭，选项卡栏溢出时可以滚动，浏览器标签页标题显示为`<文档> — MarkupCraft | CadCraft`。
- 包含多个部分的面板会打开一个部分并关闭其他部分（箭头旁的锁定按钮可保持一个部分打开）；设置中的开关可关闭此行为。
- 每个应用启动时都会带有一组默认的库项目。
- 设置中的单位选项提供重量和温度单位。

## 已修复

- **已删除的批注不再保留在已保存的 PDF 中可读取。** 以前保存时，已删除或已改写的注释会从其页面上移除，但对象及其文字仍留在文件中。现在保存时会删除这些对象。早期版本保存的文件，在你再次保存之前仍会保留这些内容。

## 已知限制

- 批量链接仅在我们自己的测试图纸集上进行过测试。实际图纸集中的气泡画法多种多样，因此在客户图纸集上可能会漏掉部分视图。扫描图纸需先运行{{ui:识别文字（OCR）…}}。
- 备注、私人注释和粘贴板是在无界面浏览器和我们自己的文件中测试的，尚未在大型真实矢量图纸集上测试，也未在真实的两人 Live 会话中测试。更改口令功能尚未实现。0.9 之前的版本不显示备注。
- 班级视图即人员列表；尚未与真实的教师和学生一起试用。
- 英文以外的语言在母语者审阅之前均为机器草稿。
- Windows 安装程序未进行代码签名（选择更多信息，然后选择仍然运行）；macOS 磁盘映像未经公证（右键单击，然后选择打开）。

## 更早版本：0.8 和 0.8.1

这是 MarkupCraft 0.8 和 0.8.1 相对于 0.7 的变更。最大的新功能是：批注可以成为一项任务，由某人或你自己的助手执行，并且在图纸真正发生变化时自动关闭。

### 新增

**会自动执行的批注**

- **将批注设为任务。** 选择一个或多个批注，打开{{ui:任务}}选项卡，然后选择{{ui:将所选设为任务}}。任务包含标题、执行人（某人或你已连接的助手）、可选的到期日和状态，并会保留其在图纸上的位置及其回复串。参见[将批注设为任务](topic:markups-that-act)。
- **会自动关闭的任务。** 任务可以监视其批注所在区域内的图纸。打开图纸的较新修订版并选择{{ui:立即检查}}：如果该区域的线条变化超过细微程度，任务会被标记为完成，其批注变为已完成，回复串中会有一条备注说明变化内容。新的日期戳，或移动少于 1.5 点的线条，不计入变化。任务也可以改为监视模型构件：你的助手使用 `tasks_check` 报告该构件，之后报告的内容有差异，或构件被删除，都会关闭任务。一个撤销步骤即可重新打开任务。
- **查找工作。** 按状态和负责人筛选{{ui:任务}}列表，包括{{ui:已逾期}}；选择{{ui:负责人}}，然后选择{{ui:助手}}，即可查看等待你的助手处理的工作。超过到期日的任务会在问题面板中显示为警告。{{ui:CSV}}可导出列表。任务与批注一起保存在 PDF 中，并像其他批注属性一样通过 Live 传递。

**变化内容，以纯列表形式呈现**

- **列出变更。** 打开{{ui:比较}}选项卡，然后选择{{ui:比较整套图纸}}，选取较早和较新的文件，并选择{{ui:列出变更}}。列表先显示总数，然后按变化从大到小依次列出每张变化的图纸：位于图纸的什么位置、变化有多大（已校准图纸上同时以实际单位和纸上英寸表示）、线条是增加还是删除、该处有多少个批注，以及哪些文字出现或消失。{{ui:复制列表}}会将其放入剪贴板，{{ui:CSV}}则为每项变化写入一行。参见[列出修订之间的变化内容](topic:what-changed-in-words)。

**语音备注和决定**

- **语音备注。** 在{{ui:备注}}选项卡中选择{{ui:录制语音备注}}，然后选择{{ui:停止录制}}；录音满两分钟会自动停止。备注固定在图纸中心，你可以将其拖到合适的位置，并在{{ui:特性}}中输入说明文字；列表中的{{ui:播放}}即可播放。录音保存在 PDF 内部。
- **决定。** {{ui:固定一项决定}}会在图纸上写下一两句话。如果它取代了之前的某项决定，请在{{ui:取代}}中选择该决定：旧决定保留，标记为已取代，并指向新决定。一个撤销步骤即可撤回。参见[在图纸上固定语音备注和决定](topic:voice-notes-and-decisions)。

**红线批注发送至修订**

- **发送与答复。** 在{{ui:任务}}选项卡中打开{{ui:红线批注发送至修订}}，输入批注所针对的修订版本，然后选择{{ui:导出红线文件}}。你会得到一个 `.redline.json` 文件，其中每个未关闭的批注对应一项：图纸、位置（以图纸的比例表示，因此以其他尺寸重新出图后仍能对齐）、文字、作者、回复串及其任务。负责绘制修改的人员在 `.redline-answers.json` 文件中答复“已接受”“已拒绝”或“已完成”；{{ui:加载答复文件…}}会为每个批注设置该状态及绘图人员的备注，并作为一个撤销步骤。参见[将批注作为红线发送给绘图人员](topic:redline-to-revision)。

**AI 助手**

- **更多工具。** 通过 CadCraft Studio 连接的助手可以列出任务（`tasks_list`）、创建或修改任务（`task_set`）、取消任务（`task_clear`）、将任务与较新修订版或构件进行比对（`tasks_check`），并读取两个已打开图纸集之间变化的纯文字列表（`revisions_changes`）。它只能使用你在{{ui:助手}}开关下勾选的工具，并且每次变更都是一个撤销步骤。参见[在 MarkupCraft 中使用 AI 助手](topic:use-with-ai-assistants)。

### 所有应用

- **语言。** CadCraft Studio 现在支持 54 种语言。其中新增十种：立陶宛语、拉脱维亚语、波斯尼亚语、马拉地语、泰卢固语、阿尔巴尼亚语、南非荷兰语、菲律宾语、斯瓦希里语和乌兹别克语。所有非英语语言在母语者审阅之前均为机器草稿。
- **输入设备。** {{ui:设置}} › {{ui:全局}} › {{ui:输入设备}}用于设定触控板、鼠标侧键、手写笔、手指点按、3D 鼠标、游戏手柄或 MIDI 控制器的功能，可对所有应用生效，也可仅对当前应用生效。在你更改任何设置之前，所有设备的功能与以前相同。参见[使用触控板、3D 鼠标或控制器](common:input-devices)。
- **工具栏行数。** {{ui:设置}} › {{ui:常规}} › {{ui:工具栏行数}}提供{{ui:换行}}（默认）、{{ui:2行}}和{{ui:1行}}选项，使图纸获得更多空间。参见[排列面板](common:arrange-panels)。
- **特性表格。** 批注的样式字段使用共享的表格，其中的类别可折叠，并包含标签列和值列。
- **问题面板。** 应用发出的警告（例如已逾期的任务）会汇集在一个问题面板中。
- **Live 与插件。** Live 会话的说明见[与他人实时协作](common:work-together-live)；随你的账户提供的插件列表见[插件和你的账户列表](common:addons-basics)。
- **连接你的 AI。** CadCraft Studio 是你自有助手的中心：只需连接一次，即可用于全部八个应用。这些应用本身不包含任何 AI。

### 0.8.1 中的修复

- **Studio 可在运行时切换语言。** 以前，桌面应用和打包版本会保持英文。该功能尚未在所有平台上测试：如果语言未能切换，请告诉我们。
- Studio 0.8 的安装可通过{{ui:设置}} › {{ui:更新}}获取 0.8.1。

### 本版本尚未实现

- **未进行代码签名。** Windows 安装程序和 macOS .dmg 尚无签名。在 Windows 上，如果 SmartScreen 阻止安装程序，请选择{{ui:更多信息}}，然后选择{{ui:仍然运行}}。在 Mac 上，右键单击 CadCraft Studio 并选择{{ui:打开}}。商店版本暂缓发布。
- **连接你的 AI 仍有部分未完成。** Studio 内的一键连接、面向浏览器助手的托管连接器，以及在 Studio 内使用你自己的 API 密钥，均不在本版本承诺范围内。任务流程已经测试，但尚未与真实的助手一起测试。
- **任务检查要求页面尺寸相同。** 以其他尺寸重新出图的图纸无法匹配，因此其任务不会关闭。图纸按图纸编号配对，若无编号则按页面位置配对。
- **语音备注仅为录音。** 没有文字转录，助手只能看到备注的时长、作者和说明文字，无法听到声音。录音仅在无界面浏览器中使用模拟麦克风测试过；真实麦克风在手机、平板或笔记本电脑上的表现仍有待检查。
- **PDF 中的计算表和原因** 保存在文件的一个私有条目中。较早的 MarkupCraft 会忽略该条目，并在下次保存文件时将其删除，因此请使用 0.8 或更高版本打开并保存此类文件。
- **绘图人员一方的红线处理。** CadCraft 读取红线文件并进行答复的功能尚未实现。
- **其他语言。** 泰米尔语的应用栏超出 528 px。

其他未实现的内容见[尚未实现的功能](topic:not-built-yet)。上一版本的说明见[0.7 版新增功能](topic:whats-new-0-7)。
