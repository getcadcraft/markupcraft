MarkupCraft占满整个浏览器窗口。自上而下、从左到右依次为：

## 最顶部的栏

位于最上方的细栏属于CadCraft系列，而不属于MarkupCraft本身。它包含：

- 应用名称和你正在运行的版本，
- {{ui:关于MarkupCraft}}，打开该应用在网站上的页面，
- {{ui:帮助}}，在侧面板中打开本帮助（或按{{key:F1}}），
- {{ui:保存以供离线使用}}，将MarkupCraft、它的PDF阅读器和写入器以及本帮助保存在此浏览器中，以便无网络连接时也能打开；之后会显示“离线可用”（参见[离线工作](common:offline)），
- 屏幕模式按钮（{{ui:全屏}}），
- {{ui:设置}}（或{{key:Mod+,}}），其中{{ui:MarkupCraft}}选项卡是此应用自己的设置，{{ui:常规}}是所有CadCraft应用共用的设置（参见[MarkupCraft设置](topic:settings)），以及
- {{ui:图纸}}和{{ui:模型}}，即浅色和深色主题。在{{ui:模型}}下，图纸以深底浅线绘制；你的批注保留各自的颜色。

屏幕模式按钮或{{key:Ctrl+Shift+F}}依次切换三种模式：普通、全屏，以及隐藏各栏的全屏。隐藏各栏后，将指针移到屏幕顶端（或在那里点按），各栏就会滑回。无论是否为Mac，这个快捷键在所有计算机上都使用Control键。

:::note
在全屏模式下，{{key:Esc}}也会使浏览器退出全屏。如果你只是想取消绘制，请再按一次{{key:Ctrl+Shift+F}}返回全屏。
:::

## 工具栏

顶部栏下方的工具按组排列并带有标签：

| 组 | 按钮 |
|---|---|
| 文件 | {{ui:打开}}、{{ui:保存}}、{{ui:关闭}} |
| 选择 | {{ui:选择}}、{{ui:平移}} |
| 绘制 | {{ui:手写笔}}、{{ui:高亮}}、{{ui:直线}}、{{ui:箭头}}、{{ui:矩形}}、{{ui:椭圆}}、{{ui:多段线}}、{{ui:多边形}} |
| 修订 | {{ui:云线}}、{{ui:自由云线}} |
| 注释 | {{ui:标注框}}、{{ui:文字}}、{{ui:注意}}、{{ui:图章}} |
| 测量 | {{ui:校准}}、{{ui:长度}}、{{ui:面积}}、{{ui:计数}} |
| 编辑 | {{ui:撤销}}、{{ui:重做}}、{{ui:复制}}、{{ui:粘贴}}，以及{{ui:更多}}：{{ui:剪切}}、{{ui:复制}}、{{ui:粘贴}}、{{ui:原位粘贴}}、{{ui:创建副本}}、{{ui:删除}}、{{ui:全选}}、{{ui:取消选择}} |

正在使用的工具呈按下状态。将指针停在按钮上可以看到它的快捷键（例如“矩形 (R)”）；{{ui:更多}}菜单在每个命令旁列出其快捷键。当前无法执行的按钮呈灰色：选择批注之前{{ui:复制}}为灰色，复制内容之前{{ui:粘贴}}为灰色。{{ui:保存}}后面的小圆点表示有些批注尚未保存。完整的快捷键列表见[键盘和鼠标](topic:keyboard)。

用过一个工具后它保持启用，因此可以连续绘制多个云线。按{{key:Esc}}（如果新批注仍处于选中状态则按两次）或{{key:V}}可回到{{ui:选择}}。

## 图纸列表（左侧）

{{ui:图纸}}列出每个已打开PDF的每一页。每一行显示图纸的小图、名称、图纸编号或文件与页码，以及其批注数量。标题后面的数字是图纸总数。

- 点击一行即可显示该图纸。
- 在{{ui:搜索图纸}}中输入内容，可按图纸名称、图纸编号或文件名筛选。按{{key:Enter}}打开第一个匹配项。

图纸名称在PDF中有的话就取自PDF。参见[打开图纸集并在图纸间切换](topic:open-a-plan-set)。

## 图纸区域（中间）

你正在处理的图纸。在没有打开任何内容之前，这里显示“打开图纸集”和一个{{ui:打开PDF}}按钮。把PDF拖放到这里的任意位置即可打开。

图纸下方有一条窄栏，包含：

- 上一张和下一张图纸的箭头，以及“第3/12张：A-101 — Floor plan”（将指针停在其上可看到文件和页码），
- 缩小、缩放框（输入百分比并按{{key:Enter}}；在典型屏幕上100%为实际大小）、放大，
- {{ui:适合页面}}和{{ui:适合宽度}}。

图纸集打开期间，每张图纸会记住自己的缩放比例。

比较两张图纸时，这里会出现图例：“仅在旧图纸上”、“仅在新图纸上”和“两者都有”。参见[比较两个修订版](topic:compare-revisions)。

## 面板（右侧）

共有五个选项卡：

| 选项卡 | 显示内容 |
|---|---|
| {{ui:属性}} | 所选批注：作者、日期、测量值、状态、主题、文字、意见、样式、它的回复及其整改项。启用绘图工具且未选择任何内容时，显示新批注将使用的设置。未选择任何内容且{{ui:选择}}处于启用时，显示图纸：编号、标题、名称的读取来源、纸张大小、比例，以及{{ui:重命名图纸}}。 |
| {{ui:批注}} | 已打开图纸集中的所有批注，带筛选，以及{{ui:CSV}}和{{ui:BCF}}导出。参见[批注列表](topic:markups-list-and-export)。 |
| {{ui:整改清单}} | 带责任人、到期日和状态的编号整改项。参见[制作整改清单](topic:punch-list)。 |
| {{ui:工具}} | 工具集：保存的带样式工具。参见[工具集](topic:tool-chest)。 |
| {{ui:比较}} | 叠加两张图纸。参见[比较两个修订版](topic:compare-revisions)。 |

## 状态栏（底部）

- 左侧显示指针在图纸上的位置，以纸张上的英寸为单位（或在[设置](topic:settings)中改为毫米）。
- 中间是消息：工具接下来需要什么、刚保存了什么、为什么某项操作被拒绝。**有操作没有生效时，请看这里。**
- 图纸的比例按钮（“未校准”，或具体比例）。点击可设置比例。参见[校准图纸并测量](topic:calibrate-and-measure)。
- 你的名字（在你提供之前显示“设置你的名字”）。点击可更改。

## 在小屏幕上

宽度低于约1180像素时，面板会变窄，图纸缩略图会缩小。在手机尺寸的屏幕上，各部分会纵向堆叠：工具栏（可横向滚动）、图纸、状态栏、面板，最下方是图纸列表。横向放置的平板保持完整布局。
