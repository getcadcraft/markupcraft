MarkupCraft 支持触摸：可在 iPad（Safari 或 Chrome）、触摸屏笔记本，或安装较新浏览器的 Windows 或 Android 平板上使用。平板横向使用时会显示完整布局。

## 手势

| 手势 | 作用 |
|---|---|
| 单指 | 使用当前工具绘制，或使用 {{ui:Select}} 选择 |
| 双指张开或捏合 | 以两指之间的点为中心缩放 |
| 双指一起移动 | 平移；可在一次操作中同时缩放和平移 |
| 绘制时加入第二根手指 | 取消第一根手指开始的操作，改为缩放 |
| 双击，或按住不放 | 完成多段线、多边形、自由云线或区域 |
| 使用 {{ui:Select}} 时按住文字、标注框或便笺 | 打开其文字进行编辑 |
| 开启 {{ui:Pan}} 时单指 | 平移 |

在触摸屏上，工具栏按钮、菜单、选项卡和对话框按钮都更大，便于用手指点击。

## 抬起时生效的操作

为了使捏合的第一根手指不会留下标记，某些工具在你**抬起**手指时才生效，而不是在触碰时：

- {{ui:Count}}：抬起时添加计数点。
- {{ui:Note}}：抬起时放置便笺。
- {{ui:Polyline}}、{{ui:Polygon}}、{{ui:Free cloud}} 和 {{ui:Area}}：每个点在抬起时添加。
- {{ui:Line}}、{{ui:Arrow}}、{{ui:Length}} 和 {{ui:Calibrate}}：点击起点后再点击终点时，终点在抬起时放置。

若手指在抬起前滑动超过一点，则不算点击，也不会添加任何内容。请干脆地点击；如需更正，请使用 {{ui:Undo}}。

需要拖动的工具（{{ui:Pen}}、{{ui:Highlight}}、{{ui:Cloud}}、{{ui:Rectangle}}、{{ui:Ellipse}}、{{ui:Callout}}、{{ui:Text}}、{{ui:Stamp}}）在触碰时立即开始；第二根手指会将其取消。

## 用手指选择

- 点击批注以选中它；拖动可移动；拖动手柄可调整大小。手指触碰图纸后，批注和手柄的点击范围会增大，手柄也会绘制得更大。
- 在空白图纸上拖动，可绘制选择框（从左到右：完全包含；从右到左：接触即选中）。
- 在 {{ui:Select}} 中，单指**不能**平移。请使用双指，或选择 {{ui:Pan}}。

## 需要键盘的操作

没有键盘时，就没有 {{key:Shift}}、{{key:Esc}} 或 {{key:Enter}}。以下是替代操作：

| 键盘操作 | 没有键盘时 |
|---|---|
| {{key:Esc}} 取消，或返回 {{ui:Select}} | 点击工具栏中的 {{ui:Select}} |
| {{key:Shift}} 绘制 45° 线条、正方形和圆 | 小心绘制；用手柄调整 |
| 按住{{key:Shift}}并点击以添加到选择 | 使用选择框 |
| 按住{{key:Shift}}并点击以移除计数点 | 错误点击后立即{{ui:Undo}} |
| {{key:Mod+Enter}} 结束输入 | 点击文字框外部 |
| {{key:Enter}} 结束多段线，或编辑批注的文字 | 按住不放，或在 {{ui:Properties}} 中使用 {{ui:Edit on the sheet}} |
| {{key:Delete}} | 工具栏或 {{ui:Properties}} 中的 {{ui:Delete}} |
| 用 {{key:Esc}} 开始新的计数组 | 用 {{ui:Select}} 点击空白图纸，然后再次点击 {{ui:Count}} |

带键盘的保护套或蓝牙键盘会恢复所有快捷键；在 iPad 上，⌘ 键可用于 {{key:Mod+Z}} 及其他操作。

在触摸操作中，按钮不显示工具提示。每个工具的快捷键列在 [键盘和鼠标](topic:keyboard) 中。

## 触控笔和 Apple Pencil

触控笔（Apple Pencil、Surface Pen 等）的工作方式与鼠标相同：可以绘制和选择，并在触碰时立即生效。缩放和平移请使用手指。压力不会改变线宽。

## 在 iPad 上打开和保存

- {{ui:Open}} 会显示“文件”选择器：iCloud 云盘、“我的 iPad”，以及你已连接的任何存储应用。
- {{ui:Save}} 会请求下载；副本会保存到“文件”中的“下载”文件夹下（或 Safari 设置中指定的文件夹）。

## 在平板上保护你的工作

:::warning
iPad 上的 Safari 在你离开含有未保存工作的页面时不会提醒你，而且 iPadOS 可能会在后台重新加载标签页以释放内存。MarkupCraft 会在浏览器中保留恢复副本，并在你再次打开时提供恢复（参见 [恢复未保存的内容](common:recover)），但**每张图纸或每次巡查之后都要保存**：无痕标签页不会保留任何副本。
:::

- 你的姓名、工具设置和工具集保存在该 iPad 的该浏览器中，与电脑上一样。参见 [此浏览器中保存的内容](topic:browser-storage)。
- **在无信号的现场访问之前：** 在仍可联网时，于 iPad 上用 Safari（或 Chrome）打开 MarkupCraft，并选择顶部栏中的 {{ui:Save for offline}}。等待显示“已可离线使用”（它会显示“保存中 N / M”；PDF 阅读和写入组件约为 6 MB）。到现场后，打开相同地址或其书签：打开、标注和保存 PDF 无需网络连接。若显示“无法离线使用”，说明你处于无痕标签页中；请使用普通标签页。参见 [离线工作](common:offline)。
- Safari 会删除你数周未使用的离线副本。出行前，请点击“已可离线使用”并选择“重新保存（获取最新版本）”。
- 非常大的图纸集会占用大量内存。在平板上，只打开此次访问需要的图纸。

## 在手机上

可以使用，但屏幕较小：各部分会竖向堆叠（工具栏、图纸、状态栏、面板，然后是图纸列表），工具栏可横向滚动。请用手机查看并快速添加便笺；正式审阅请使用平板或电脑。
