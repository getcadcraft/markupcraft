## 打开图纸集

1. 在工具栏中选择 {{ui:Open}}，或按 {{key:Mod+O}}。
2. 在文件选择器中，选中该图纸集的每个 PDF（{{pick:mac=按住⌘并单击每个文件|windows linux=按住Ctrl并单击每个文件}}，或按住Shift选择一个范围），然后确认。
   也可以将文件从{{pick:mac=访达|windows=文件资源管理器|linux=文件管理器}}拖到图纸区域。拖动时会出现“拖入 PDF 即可打开”。
3. 等待状态栏显示“正在打开 <file>…”。对于大文件，会显示计数：“（10 / 60 张图纸）”。

结果：{{ui:Sheets}} 列表会按打开顺序显示每个文件的每一页，状态栏会显示类似“已打开 3 个文件（集合中共 42 张图纸）。”的内容。如果这些文件已有批注，还会显示读取了多少条批注。

之后要向集合添加更多文件，请以同样方式打开。它们会添加到列表末尾。

## 从空白页开始

若要在没有图纸的情况下草绘或做笔记，请创建空白页，而不是打开 PDF：

1. 在工具栏中选择 {{ui:New}}，或在起始屏幕中选择 {{ui:Start with a blank page}}，或在浏览器允许时按 {{key:Mod+N}}（桌面应用和 Studio 始终支持）。
2. 选择 {{ui:Paper size}}：Letter、Tabloid 或 ANSI B、ARCH D、ARCH E、A4、A3 或 A1，以及 {{ui:Portrait}} 或 {{ui:Landscape}}。
3. 选择 {{ui:Grid}}：{{ui:None}}、{{ui:Dots}} 或 {{ui:Squares}}。英寸纸张上，网格每 1/4 英寸一条，每英寸一条加粗线；公制纸张上，网格每 5 mm 一条，每 10 mm 一条加粗线。网格会打印在页面上。
4. 输入你需要的 {{ui:Pages}} 数量（1 到 20），然后选择 {{ui:Create}}。

结果：会打开一个名为“Untitled-1.pdf”（然后是“Untitled-2.pdf”，依此类推）的新 PDF，它与其他文件一样打开，并在这台电脑上创建。所有工具都可用于它，{{ui:Save}} 会下载“Untitled-1 (marked up).pdf”。MarkupCraft 会记住你的选择，供下次使用。

页面没有比例：状态栏显示“未校准”。网格不代表比例。如需测量，请先校准图纸或选择比例；参见 [校准与测量](topic:calibrate-and-measure)。

要在空白集合中添加页面，请打开其中一张图纸，然后在 {{ui:Sheets}} 列表下选择 {{ui:Add a blank page}}。新页面与其他页面具有相同的纸张和网格，并添加在末尾。与所有页面更改一样，它无法撤销；参见 [打印及更改页面](topic:pages-and-printing)。

## 图纸如何获得名称

MarkupCraft 会将每张图纸命名为“<图纸编号> — <标题>”，例如“A-101 — Floor plan”，名称按以下顺序中找到的第一项确定：

1. 你使用 {{ui:Rename sheet}} 输入的名称（见下文）。
2. PDF 自身的页面标签（若创建 PDF 的人设置过），例如“A-101”。
3. 标题栏：MarkupCraft 读取页面文字，查找形如图纸编号的内容（A-101、A1.01、M-201A、KA1-1），优先查找右下角、右侧条带和底部区域，并将其附近最大的文字作为标题。
4. 否则为文件名加页码：“Plans — page 3”。

要查看使用的是哪一项，请按 {{key:Esc}} 直到未选中任何对象且 {{ui:Select}} 处于启用状态，然后查看 {{ui:Properties}}：“读取自”会显示“页面标签”、“标题栏”、“文件名”或“手动输入”。

:::note
扫描的图纸，以及文字已转为线条导出的 PDF，没有可读取的文本。在重命名之前，它们将按文件和页码命名。MarkupCraft 暂时无法从图像中读取文字。
:::

## 在图纸之间切换

- 在 {{ui:Sheets}} 中点击一张图纸。
- 按 {{key:PageDown}} 切换到下一张图纸，按 {{key:PageUp}} 切换到上一张，或使用图纸下方栏中的箭头。
- 在 {{ui:Search sheets}} 中输入：编号的一部分（“A-2”）、标题中的一个词（“屋顶”）或文件名。列表会随输入缩小（“4 / 42”）。按 {{key:Enter}} 打开第一个匹配项。清空输入框可再次查看所有图纸。

每张图纸都会保留自己的缩放和位置，直到你关闭集合。

## 缩放和平移

:::mouse
- **缩放：** 在图纸上滚动滚轮，它会以指针位置为中心缩放。或按 {{key:Plus}} 和 {{key:Minus}}（也可以配合 {{key:Mod}}），或使用缩放按钮。在缩放框中输入精确的百分比。
- **适合：** {{ui:Fit page}}（{{key:Mod+0}}）显示整张图纸；{{ui:Fit width}}（{{key:Mod+9}}）填满宽度。
- **平移：** 用中键（滚轮）拖动，或用右键拖动，或按住 {{key:Space}} 拖动，或选择 {{ui:Pan}}（{{key:H}}）后拖动。未选中任何对象时，方向键也可以移动图纸。
:::

:::mac mouse
在 Mac 触控板上，双指滚动会缩放（不会滚动图纸）。若要平移，请按住 {{key:Space}} 并用一根手指拖动，或按 {{key:H}} 切换到 {{ui:Pan}}。在 Chrome、Edge 和 Firefox 中，捏合可以缩放。
:::

:::touch
- **缩放和平移：** 用两根手指放在图纸上。张开或捏合可以以两指之间的点为中心缩放，一起移动即可平移。两者可同时进行。
- **单指平移：** 先选择 {{ui:Pan}}。使用其他工具时，单指用于绘制或选择。
- {{ui:Fit page}} 和 {{ui:Fit width}} 位于图纸下方栏中。
:::

你可以将视图缩小到远超整张图纸的范围，也可以放大至 6400%。停止移动后，图纸会稍后重新绘制得清晰。

## 书签

{{ui:Bookmarks}} 位于 {{ui:Sheets}} 面板顶部，显示当前打开图纸所属 PDF 的书签（大纲）。选择一个即可跳转到其页面。铅笔图标用于重命名书签，叉号用于删除书签。{{ui:Build from sheets}} 会为每张图纸创建一个书签，名称与图纸列表中的显示一致（图纸编号和标题）；{{ui:Add for this sheet}} 会为当前图纸添加一个书签。这些更改属于文件中未保存的内容：{{ui:Save}} 会将其写入副本，所有 PDF 阅读器都会显示。

## 旋转视图

图纸下方栏右侧的两个旋转按钮可将视图按四分之一圈向任一方向旋转，用于横向绘制的图纸。只有视图会旋转：PDF 及其批注保持原样，下一张图纸将按其 PDF 的方式打开（在集合打开期间，每张图纸会记住自己的旋转）。在旋转后的视图中添加的文字，会以你所见的方向正向显示。若要在保存的 PDF 中旋转页面本身，请使用 {{ui:Pages}}，然后选择 {{ui:Rotate page clockwise}}；参见 [打印及更改页面](topic:pages-and-printing)。

## 重命名图纸

当图纸的名称错误或缺失时：

1. 显示该图纸。
2. 按 {{key:Esc}} 直到未选中任何对象且 {{ui:Select}} 工具处于启用状态。{{ui:Properties}} 现在会显示该图纸。
3. 选择 {{ui:Rename sheet}}。
4. 输入 {{ui:Sheet number}} 和 {{ui:Title}}，然后选择 {{ui:Save}}。

结果：图纸列表、图纸下方栏和批注列表都会使用新名称，“读取自”显示“手动输入”。可以用 {{key:Mod+Z}} 撤销重命名。

若要恢复为文件中的原始信息，请再次打开 {{ui:Rename sheet}}，清空两个输入框，然后选择 {{ui:Save}}。

保存时，手动输入的图纸编号会成为 PDF 中该页的页面标签，因此其他 PDF 阅读器的页面框中也会显示“A-101”。如果为文件中的任一页设置了编号，该文件的每一页在副本中都会获得标签（依次使用：手动输入的编号、原有标签、页码）。手动输入的标题会保留在 MarkupCraft 中，但其他阅读器不会显示。

## 将 PDF 发送到 TakeoffCraft，或带回此处

当 TakeoffCraft 在同一位置打开（实验室、Try 或在线应用）时，图纸下方栏中会有 {{ui:Open in TakeoffCraft}}。它会在新标签页中打开图纸的 PDF，其打开方式与在此处相同，以便你在其上测量工程量。你的批注保留在此处；请照常保存。

TakeoffCraft 中的 {{ui:MarkupCraft}} 按钮作用相反：它会像你选择了 {{ui:Open}} 一样，在此处打开 PDF。如果浏览器阻止新标签页，请允许本站点弹出窗口，然后再次选择该按钮。
