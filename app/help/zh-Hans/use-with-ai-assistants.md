## 你将学到的内容

如何让AI助手（或你编写的脚本）与MarkupCraft协同工作，以及如何决定它可以操作哪些内容。

MarkupCraft**本身没有AI**，也不会向任何地方发送任何内容。助手需由你自行提供：任何支持模型上下文协议（MCP）的程序均可。MarkupCraft只向其提供工具，由你决定提供哪些工具。

## 启用

1. 打开{{ui:Settings}}（应用栏中的齿轮图标，或按{{key:Mod+,}}），然后进入{{ui:MarkupCraft}}选项卡。
2. 在{{ui:Assistants}}下，勾选**允许AI助手和脚本使用MarkupCraft**。在你勾选之前，该功能处于关闭状态。
3. 选择其可执行的操作：**读取**默认已勾选；仅在需要时勾选**编辑**、**保存**或**导出**。

未勾选权限对应的工具不会提供给助手；如果助手仍然请求这些工具，MarkupCraft会拒绝并将其记录在活动日志中。关闭开关会立即结束所有连接；{{ui:Reset MarkupCraft settings}}也会将其关闭。

## 连接你的助手

助手通过你计算机上的**CadCraft Studio**进行连接：Studio运行一个仅本计算机可访问的小型服务器，并由每次启动时生成的令牌进行保护。在Studio中选择{{ui:Connect an assistant}}，然后将地址和令牌复制到你的助手中（Studio会显示需要粘贴的确切设置）。切勿分享令牌。

:::note
浏览器标签页无法为助手打开连接：在浏览器版应用中，该开关在你使用计算机上的CadCraft Studio之前不会生效。
:::

## 你始终掌控

- **每次更改都是一个撤销步骤**，并以助手的名称标注（例如“助手：添加cloudrect”）。{{key:Mod+Z}}会一次性撤回助手的最后一次更改。
- **你可以知道何时已连接助手。** 应用栏中的一个按钮会在助手连接时显示其名称；点击它即可查看其可执行的操作，或选择**断开连接**。
- **活动。** {{ui:Settings}} › {{ui:MarkupCraft}} › {{ui:Assistants}} › {{ui:Activity}}会列出每次调用：时间、工具、完成或被拒绝。{{ui:Save the log}}可保存一份副本。

## 助手可以请求哪些权限

| 工具 | 权限 | 功能 |
|---|---|---|
| `app_info`、`sheets_list` | 读取 | 已打开的图纸集、其中的图纸，以及每张图纸的批注数量 |
| `markups_list` | 读取 | 批注及其类型、图纸、文字、备注、测量值、状态、作者和回复，可按图纸、状态、类型或作者筛选 |
| `markup_add` | 编辑 | 在图纸上添加矩形、云线、椭圆、文本框、便笺、直线或箭头 |
| `markup_status`、`markup_reply` | 编辑 | 设置批注的状态（记录在其回复串中，并由助手署名）；向回复串添加评论 |
| `markups_export` | 导出 | {{ui:Markups}}列表所显示内容的CSV或BCF（使用你设置的筛选条件）；在Studio中，它可以将文件写入你允许的文件夹 |
| `tasks_list` | 读取 | 作为任务的批注：负责人（人员或助手）、截止日期、状态、链接、关闭方式。`assignee: "assistant"`会列出等待助手处理的工作 |
| `task_set`、`task_clear` | 编辑 | 将批注设为任务或更改任务（标题、负责人、截止日期、状态、链接）；取消任务 |
| `tasks_check` | 编辑 | 关闭其关联的图形区域或模型构件确已变更的任务；传入你从其他应用中读取的构件状态 |
| `revisions_changes` | 读取 | 两个已打开的图纸集之间变更内容的纯文本列表，供你用自己的话进行描述 |
| `pins_list`、`decision_add` | 读取、编辑 | 语音备注（时长、录制者、时间、说明文字；从不包含声音，也没有文字转录）和决定；固定一项决定并取代较早的决定 |
| `redline_export`、`redline_answer` | 导出、编辑 | 为绘图员写入红线文件；应用绘图员的答复 |

由助手添加的批注会将其命名为作者：即助手程序为自己设定的名称，后接“(assistant)”；在你设置了审阅人姓名后，则为“(assistant for <your name>)”。其状态更改和回复的署名方式相同。每项操作均为一个撤销步骤。保存带批注的PDF仍由你负责：照常使用{{ui:Save}}。

无需打开MarkupCraft，CadCraft MCP服务器即可列出你指定文件夹中PDF的批注（`markups_list`），而`cadcraft info Set.pdf`会在命令行中打印这些批注。

## 如果出现问题

- **助手看不到MarkupCraft工具：** 请检查此窗口中的开关是否已打开，以及该窗口是否已在Studio中打开。
- **“需要编辑权限”：** 请在{{ui:Assistants}}下勾选**编辑**，然后再次请求。
- **“401”或“令牌”错误：** 令牌已更改（Studio重新启动，或执行了{{ui:New token}}）。请将新令牌复制到助手的设置中。
