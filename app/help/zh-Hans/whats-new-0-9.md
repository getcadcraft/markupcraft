以下是 MarkupCraft 0.9 相比 0.8.1 的变化。主要理念是：你的工作注释不会出现在交给客户的页面上，并且整套图纸可以一次性完成链接。

## 新增

### 注释、粘贴板和私人注释

- **粘贴板。** 每张图纸周围的区域是一张“桌面”：在图纸旁边绘制、输入或粘贴的任何内容都是注释，且永不打印。选择{{ui:显示粘贴板}}可缩小视图以获得更多空间，或选择{{ui:快照到粘贴板}}，拖出一个框，然后选择{{ui:到粘贴板}}，将图纸部分的图片放在图纸旁边。快照是一张图片，图纸改变时它不会改变。参见[注释、粘贴板和私人注释](topic:notes-and-pasteboard)。
- **显示和隐藏注释。** 任何批注都可以成为注释：在{{ui:备注}}选项卡中设置{{ui:新建批注为}}，或在{{ui:特性}}中设置{{ui:此批注为}}。{{key:Shift+H}}或图纸下方的{{ui:备注}}开关可一次隐藏或显示所有注释。注释不包括在打印、合并后的副本、列表和导出中，其他PDF阅读器也不会显示它们。保存的 PDF 会保留这些注释，供你下次在 MarkupCraft 中打开时使用。
- **私人注释。** 选择{{ui:设置口令}}，然后将批注设为{{ui:私人注释}}。它会使用至少10个字符的口令加密保存在文件中，且无法恢复：任何人（包括我们）都无法在没有口令的情况下打开它。{{ui:锁定}}会收起私人注释；{{ui:在此设备上保持解锁}}默认关闭。
- **保存干净副本。** {{ui:保存干净副本}}会删除所有注释、私人注释以及粘贴板上的所有内容。用于发送给客户的文件。

### 链接整套图纸

- **批量链接。** 选择{{ui:页面}} › {{ui:批量链接…}}，或在{{ui:图纸}}面板中{{ui:查找文字}}下的{{ui:链接图纸索引…}}。第 1 步列出从各图纸标题栏读取的每张图纸的编号和名称；如有错误请修正。第 2 步列出找到的索引，例如`3/A-501`或`DETAIL 2 ON A-501`。{{ui:待链接}}显示每个索引对应的图纸和视图，{{ui:未链接}}显示没有任何已打开图纸对应的编号，{{ui:创建链接}}会一次性全部创建，并可作为一步撤销。在补遗或重新编号后可再次运行；手动创建的链接永远不会被更改。带视图的链接会保存为 PDF 链接，因此其他阅读器也能打开该详图。参见[图纸链接](topic:sheet-links)。

### 绘图

- **圆弧，十种方法。** {{ui:圆弧}}工具（{{key:O}}）现在在页面上有一个{{ui:圆弧方法}}框，提供十种绘制圆弧的方式，并且角度、长度、半径和方向都可以通过点击或输入来确定。参见[用十种方式绘制圆弧](topic:draw-an-arc)。

### 协同工作

- **跟随审阅者。** 在实时协作会话中，选择某人姓名旁的{{ui:跟随}}，你的视图就会随其移动；你自己平移或缩放即会停止跟随。主持人可以选择{{ui:让所有人跟随我}}。人员列表显示每个人的颜色、姓名、其所在的图纸以及最后一次编辑的时间。参见[在实时协作会话中跟随其他审阅者](topic:follow-in-live)。

## 在所有应用中

- 工具提示使用 Bootstrap 工具提示，启动提示可关闭，选项卡栏溢出时可滚动，浏览器标签页标题显示为 `<document> — MarkupCraft | CadCraft`。
- 具有多个部分的面板一次只打开一个部分，并关闭其他部分（箭头旁边的锁定按钮会保持一个打开）；设置中的开关可关闭此行为。
- 每个应用都从默认的库项目集合开始。
- 重量和温度单位可在单位设置中使用。

## 已修复

- **已删除的批注不再保留在已保存的 PDF 中可读。** 以前保存时会把已删除或改写的批注对象从其页面上移除，但对象及其文字仍留在文件中。现在保存时会删除这些对象。早期版本生成的文件会保留这些内容，直到你再次保存它们为止。

## 诚实的限制

- 批量链接已在我们自己的测试图纸集上试过。实际图纸集会以多种方式绘制气泡，因此在客户图纸集上，某些视图可能会被遗漏。扫描图纸需要先使用{{ui:识别文字（OCR）…}}。
- 注释、私人注释和粘贴板已在无头浏览器和我们自己的文件中测试，未使用大型真实矢量图纸集，也未在真实的两人实时协作会话中测试。更改口令的功能尚未实现。0.9版之前的版本不显示注释。
- 班级视图即人员列表，尚未与真实的教师和学生一起测试。
- 除英语外的其他语言在母语人士审阅之前均为机器草稿。
- Windows 安装程序未进行代码签名（选择“更多信息”，然后选择“仍要运行”）；macOS 磁盘映像未经公证（右键单击，然后选择“打开”）。

## 更早版本：0.8 和 0.8.1

以下是 MarkupCraft 0.8 和 0.8.1 相比 0.7 的变化。最重要的新功能是：批注可以成为一项任务，由他人或你自己的助手完成，并会在图纸真正发生变化时自动关闭。

### 新增

**会自动执行的批注**

- **将批注设为任务。** 选择一个或多个批注，打开{{ui:任务}}选项卡，然后选择{{ui:将所选设为任务}}。任务包含标题、执行人（一个人员或你已连接的助手）、可选的截止日以及状态，并会保留其在图纸上的位置和回复串。参见[将批注设为任务](topic:markups-that-act)。
- **自动关闭的任务。** 任务可以监视其批注内的图纸区域。打开图纸的较新修订版并选择{{ui:立即检查}}：如果该区域的线条变化超过细微程度，任务将标记为完成，其批注变为已完成，并且回复串中的一条注释会说明变化。新的日期戳，或移动不超过 1.5 点的线条，都不计入。任务也可以改为监视模型构件：你的助手使用`tasks_check`报告该构件，之后报告的内容不同或构件被删除，都会关闭任务。一步撤销即可重新打开它。
- **查找工作。** 按状态和负责人筛选{{ui:任务}}列表，包括{{ui:已逾期}}；选择{{ui:负责人}}，然后选择{{ui:助手}}以查看等待助手处理的内容。超过截止日的任务会在问题面板中显示为警告。{{ui:CSV}}导出列表。任务与批注一起保存在 PDF 中，并像其他批注属性一样通过实时协作传递。

**变更内容（纯文字列表）**

- **列出变更。** 打开{{ui:比较}}选项卡，然后选择{{ui:比较整套图纸}}，选择较早和较晚的文件，并选择{{ui:列出变更}}。列表以总数开头，随后按变化大小从大到小列出每张变化的图纸：位置、大小（以实际单位显示，在已校准的图纸上也以纸张英寸显示）、线条是增加还是删除、该处有多少批注，以及出现或消失的文字。{{ui:复制列表}}将其放到剪贴板上，{{ui:CSV}}则为每项变更写入一行。参见[列出修订之间的变化](topic:what-changed-in-words)。

**语音备注和决定**

- **语音备注。** 在{{ui:备注}}选项卡中选择{{ui:录制语音备注}}，然后选择{{ui:停止录制}}；录音会在两分钟后自动停止。语音备注固定在图纸中心，你可以将其拖到合适的位置，并在{{ui:特性}}中输入说明文字；列表中的{{ui:播放}}即可播放。录音保存在 PDF 内。
- **决定。** {{ui:固定一项决定}}会在图纸上写一两句话。如果它取代了较早的决定，请在{{ui:取代}}中选择该决定：旧决定保留，标记为“已取代”，并指向新决定。一步撤销即可撤回。参见[在图纸上固定语音备注和决定](topic:voice-notes-and-decisions)。

**红线批注发送至修订**

- **发送与回复。** 在{{ui:任务}}选项卡中打开{{ui:红线批注发送至修订}}，输入批注所对应的修订版本，然后选择{{ui:导出红线文件}}。你会得到一个`.redline.json`文件，每个未完成批注对应一项：包括图纸、位置（以图纸尺寸的分数表示，因此按其他尺寸重新出图时仍能对齐）、文字、作者、回复串及其任务。绘制修改的人在`.redline-answers.json`文件中回复已接受、已拒绝或已完成；{{ui:加载答复文件…}}会为每个批注设置该状态及制图员的备注，整体作为一步撤销。参见[将批注作为红线发送给制图员](topic:redline-to-revision)。

**AI 助手**

- **更多工具。** 通过 CadCraft Studio 连接的助手可以列出任务（`tasks_list`）、创建或修改任务（`task_set`）、清除任务（`task_clear`）、与较新的修订或构件进行对照检查（`tasks_check`），以及读取两套已打开图纸集之间的纯文字变更列表（`revisions_changes`）。它只能使用你在“助手”开关下勾选的工具，且每项更改都可一步撤销。参见[在 MarkupCraft 中使用 AI 助手](topic:use-with-ai-assistants)。

### 在所有应用中

- **语言。** CadCraft Studio 现在支持 54种语言。其中十种为新增：立陶宛语、拉脱维亚语、波斯尼亚语、马拉地语、泰卢固语、阿尔巴尼亚语、南非荷兰语、菲律宾语、斯瓦希里语和乌兹别克语。除英语外的所有语言在母语人士审阅之前均为机器草稿。
- **输入设备。** {{ui:设置}} › {{ui:全局}} › {{ui:输入设备}} 设置触控板、鼠标侧键、手写笔、手指点按、3D 鼠标、游戏控制器或 MIDI 控制器的功能，可对所有应用生效，也可仅对当前应用生效。在你更改任何设置之前，所有设备都保持原有行为。参见[使用触控板、3D 鼠标或控制器](common:input-devices)。
- **工具栏行数。** {{ui:设置}} › {{ui:常规}} › {{ui:工具栏行数}} 包含{{ui:换行}}（默认）、{{ui:2行}}和{{ui:1行}}，以便为绘图留出更多空间。参见[排列面板](common:arrange-panels)。
- **属性网格。** 批注的样式字段使用共享网格，带有可折叠类别以及标签列和值列。
- **问题面板。** 应用产生的警告，如逾期任务，会汇集在一个问题面板中。
- **实时协作与插件。** 实时协作会话在[与他人实时协作](common:work-together-live)中说明；根据你的账户列出的插件列表见[插件和账户列表](common:addons-basics)。
- **连接你的 AI。** CadCraft Studio 是你自己助手的中心：一次连接，即可用于全部八个应用。这些应用本身不包含任何 AI。

### 0.8.1 中的修复

- **Studio 可以在运行时切换语言。** 以前，桌面应用和打包版本保持英文。该功能尚未在所有平台上测试：如果语言没有变化，请告知我们。
- Studio 0.8 的安装版会通过{{ui:设置}} › {{ui:更新}}提供 0.8.1 更新。

### 本版本尚未实现

- **未进行代码签名。** Windows 安装程序和 macOS .dmg 尚未签名。在 Windows 上，如果 SmartScreen 阻止安装程序，请选择{{ui:更多信息}}，然后选择{{ui:仍要运行}}。在 Mac 上，右键单击 CadCraft Studio 并选择{{ui:打开}}。商店版本暂缓发布。
- **连接你的 AI 仍有未完成之处。** Studio 内的一键连接、用于浏览器助手的托管连接器，以及在 Studio 内使用你自己的 API 密钥，均未承诺包含在本版本中。任务循环已经测试，但尚未使用真实助手测试。
- **任务检查需要相同的页面尺寸。** 以另一尺寸重新出图的图纸无法匹配，因此其任务不会关闭。图纸按图纸编号配对；无编号时按页面位置配对。
- **语音备注只是录音。** 没有文字转录，助手只能看到备注的长度、作者和说明文字，而无法听到声音。录音已在无头浏览器中使用虚拟麦克风测试；在手机、平板或笔记本电脑上使用真实麦克风仍有待检查。
- **PDF 中的计算表和理由**保存在文件的私有条目中。较早的 MarkupCraft 会忽略该条目，并在下次保存文件时将其删除，因此请使用 0.8 或更高版本打开并保存此类文件。
- **红线的制图员端。** CadCraft 读取红线文件并进行回复的功能尚未实现。
- **其他语言。** 泰米尔语的应用栏会溢出 528 px。

其余内容见[尚未实现的功能](topic:not-built-yet)。上一版本见[0.7版新增功能](topic:whats-new-0-7)。
