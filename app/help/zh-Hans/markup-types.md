## 工具

| 工具栏 | 快捷键 | 绘制方法 | 默认外观 | 在保存的 PDF 中 |
|---|---|---|---|---|
| {{ui:Pen}} | {{key:P}} | 拖动 | 红色，1.5 pt | 墨迹 |
| {{ui:Highlight}} | {{key:I}} | 拖动 | 黄色，宽 14 pt，半透明，为其下方内容着色 | 墨迹（标记为高亮笔迹） |
| {{ui:Line}} | {{key:L}} | 拖动，或单击起点和终点 | 红色，2 pt | 直线 |
| {{ui:Arrow}} | {{key:A}} | 拖动，或单击起点和终点 | 红色，2 pt，末端为闭合箭头 | 带箭头的直线 |
| {{ui:Arc}} | {{key:O}} | 单击起点、圆弧上的一点，再单击终点 | 红色，2 pt | 沿圆弧的多段线 |
| {{ui:Rectangle}} | {{key:R}} | 拖出一个框 | 红色，2 pt，无填充 | 矩形 |
| {{ui:Ellipse}} | {{key:E}} | 拖出一个框 | 红色，2 pt，无填充 | 圆形 |
| {{ui:Polyline}} | {{key:Y}} | 单击各点，双击结束 | 红色，2 pt | 多段线 |
| {{ui:Polygon}} | {{key:G}} | 单击各点，双击结束 | 红色，2 pt，无填充 | 多边形 |
| {{ui:Cloud}} | {{key:C}} | 拖出一个框 | 红色，1.5 pt 圆弧 | 带云状边框的矩形 |
| {{ui:Free cloud}} | {{key:Shift+C}} | 单击各点，双击结束 | 红色，1.5 pt 圆弧 | 带云状边框的多边形 |
| {{ui:Callout}} | {{key:K}} | 在点上按下，拖到文字处，输入文字 | 红色文字和引线，1 pt，12 pt 文字 | 带标注引线的文字框 |
| {{ui:Text}} | {{key:T}} | 单击或拖出一个框，输入文字 | 红色 12 pt 文字，无边框 | 文字框 |
| {{ui:Note}} | {{key:N}} | 单击，输入文字 | 黄色便笺图标 | 便签 |
| {{ui:Stamp}} | {{key:S}} | 选择图章，单击或拖动 | 带框的大写字母，外加“由 <name>，<date>”；按含义着色 | 图章 |
| {{ui:Length}} | {{key:M}} | 单击起点和终点（需要比例） | 蓝色尺寸线，带刻度和长度值 | 标记为尺寸的直线，附带测量值 |
| {{ui:Angle}} | {{key:X}} | 单击一条边的端点、角点，再单击另一条边的端点 | 蓝色边，角点处有小圆弧，并以度显示角度 | 以角度为文字的多段线 |
| {{ui:Area}} | {{key:Q}} | 单击各角点，双击结束（需要比例） | 蓝色轮廓，浅蓝色填充，显示面积和周长 | 标记为面积的多边形，附带测量值 |
| {{ui:Count}} | {{key:U}} | 单击每个项目 | 橙色编号圆点和“group: n”标签 | 每组一条墨迹批注，每个项目一个圆环 |

触摸时，“双击结束”即为轻触两次，“单击”则是在抬起手指时生效的轻触（用于点、便笺和计数）。

## 每个批注携带的信息

| 字段 | 在哪里看到 |
|---|---|
| 作者 | {{ui:Properties}}、列表、图章的第二行、其他 PDF 查看器 |
| 创建和修改时间 | {{ui:Properties}}（按本地时区）、列表、CSV |
| 状态 | 打开、已接受、已拒绝或已完成 |
| 主题 | 简短标签；默认为类型（“云线”“文字框”“长度测量”） |
| 意见 | 较长的说明。对于便笺，其文字即为意见。 |
| 文字 | 仅限文字框和标注框 |
| 回复 | 讨论串，以及状态变更 |
| 整改项 | 编号、负责人、截止日期、整改项状态，以及加入整改清单的时间 |
| 样式 | 颜色、线宽、填充和填充不透明度（闭合图形、文字和标注框）、不透明度、文字大小（文字、标注框和测量） |

## 只读意见

随文件一同带来、且 MarkupCraft 无法编辑的意见（文字高亮、其他程序的图章以及其他特殊类型）会以类型“其他”列出，状态标签为“只读”。它们保持文件赋予的外观。可以选中它们、查看作者、主题和意见，并对其进行回复。
