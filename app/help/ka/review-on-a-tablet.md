MarkupCraft მუშაობს შეხებით: iPad-ზე (Safari ან Chrome), შეხების ეკრანიან ლეპტოპზე, ან Windows ან Android ტაბლეტზე ახალი ბრაუზერით. ლანდშაფტურ რეჟიმში ტაბლეტი სრულ განლაგებას აჩვენებს.

## ჟესტები

| ჟესტი | რას აკეთებს |
|---|---|
| ერთი თითი | ხატავს მიმდინარე ინსტრუმენტით, ან მონიშნავს {{ui:არჩევა}}-თი |
| ორი თითი, გაშლა ან შეკუმშვა | მასშტაბირებს თითებს შორის წერტილის გარშემო |
| ორი თითი, ერთად გადატანილი | გადაადგილებს; ერთი მოძრაობით შეგიძლიათ მასშტაბირებაც და გადაადგილებაც |
| მეორე თითი ხაზვისას | აუქმებს პირველი თითის მიერ დაწყებულს და მის ნაცვლად იწყებს მასშტაბირებას |
| ორმაგი შეხება, ან შეხება და დაჭერა | ასრულებს პოლიხაზს, მრავალკუთხედს, თავისუფალ ღრუბელს ან არეს |
| ტექსტზე, ზეაწერზე ან შენიშვნაზე შეხება და დაჭერა {{ui:არჩევა}}-თი | ხსნის მის ტექსტს რედაქტირებისთვის |
| ერთი თითი, როცა {{ui:გადაადგილება}} ჩართულია | გადაადგილებს |

შეხების ეკრანზე ზოლის ღილაკები, მენიუები, ჩანართები და დიალოგის ღილაკები უფრო დიდია, რომ თითით ადვილად დაეჯახოთ.

## რა ხდება თითის აშვებისას

იმისთვის, რომ პინჩის პირველი თითი არასდროს დატოვებს ნიშანს, ზოგი ინსტრუმენტი მოქმედებს, როცა თითს **ასწევთ**, და არა მაშინ, როცა ეხებით:

- {{ui:დათვლა}}: წერტილი თითის აშვებისას ემატება.
- {{ui:შენიშვნა}}: შენიშვნა თითის აშვებისას ითავსება.
- {{ui:პოლიხაზი}}, {{ui:მრავალკუთხედი}}, {{ui:თავისუფალი ღრუბელი}} და {{ui:ფართობი}}: ყოველი წერტილი თითის აშვებისას ემატება.
- {{ui:ხაზი}}, {{ui:ისარი}}, {{ui:სიგრძე}} და {{ui:კალიბრაცია}}: როცა ერთხელ შეეხებით დასაწყისს და მეორედ დაბოლოებას, ბოლო წერტილი თითის აშვებისას დაისმება.

თუ თითი აშვებამდე ოდნავ მეტად გასრიალდება, ეს შეხებად არ ითვლება და არაფერი ემატება. შეეხეთ სუფთად; გასასწორებლად გამოიყენეთ {{ui:დაბრუნება}}.

ინსტრუმენტები, რომლებსაც გადათრევთ ({{ui:კალამი}}, {{ui:ხაზგასმა}}, {{ui:ღრუბელი}}, {{ui:მართკუთხედი}}, {{ui:ელიფსი}}, {{ui:ზეაწერი}}, {{ui:ტექსტი}}, {{ui:შტამპი}}), იწყება, როგორც კი შეეხებით; მეორე თითი მათ აუქმებს.

## მონიშვნა თითით

- შეეხეთ მონიშვნას მის მოსანიშნად; გადაათრიეთ მის გადასატანად; გადაათრიეთ სახელური ზომის შესაცვლელად. როცა თითი ფურცელს შეეხება, მონიშვნები და სახელურები უფრო დიდ სამიზნეს იღებს, და სახელურები უფრო დიდად იხატება.
- გადაათრიეთ ცარიელ ფურცელზე მონიშვნის ფანჯრის დასახაზად (მარცხნიდან მარჯვნივ: სრულად შიგნით; მარჯვნიდან მარცხნივ: შეხებით).
- {{ui:არჩევა}}-ში ერთი თითი **არ** ახდენს გადაადგილებას. გამოიყენეთ ორი თითი, ან აირჩიეთ {{ui:გადაადგილება}}.

## რაც კლავიატურას მოითხოვს

კლავიატურის გარეშე {{key:Shift}}, {{key:Esc}} ან {{key:Enter}} არ არის. აი, რა უნდა გააკეთოთ მის ნაცვლად:

| კლავიატურის მოქმედება | კლავიატურის გარეშე |
|---|---|
| {{key:Esc}}, რათა გააუქმოთ ან დაბრუნდეთ {{ui:არჩევა}}-ზე | შეეხეთ {{ui:არჩევა}}-ს ზოლში |
| {{key:Shift}} 45°-იანი ხაზებისთვის, კვადრატებისა და წრეწირებისთვის | ფრთხილად დახაზეთ; მოარგეთ სახელურებით |
| {{key:Shift}}-დაწკაპუნება მონიშვნაში დასამატებლად | გამოიყენეთ მონიშვნის ფანჯარა |
| {{key:Shift}}-დაწკაპუნება დათვლის წერტილის წასაშლელად | {{ui:დაბრუნება}} არასწორი შეხების მომენტალურად |
| {{key:Mod+Enter}}, რათა ჩაწერა დავასრულოთ | შეეხეთ ტექსტის ველის გარეთ |
| {{key:Enter}}, რათა დაასრულოთ პოლიხაზი ან შეცვალოთ მონიშვნის ტექსტი | შეხება და დაჭერა, ან {{ui:ფურცელზე რედაქტირება}} {{ui:თვისებები}}-ში |
| {{key:Delete}} | {{ui:წაშლა}} ზოლში ან {{ui:თვისებები}}-ში |
| დათვლის ახალი ჯგუფის დაწყება {{key:Esc}}-ით | შეეხეთ ცარიელ ფურცელს {{ui:არჩევა}}-თი, შემდეგ კვლავ შეეხეთ {{ui:დათვლა}}-ს |

კლავიატურის ქეისი ან Bluetooth-კლავიატურა აბრუნებს ყველა მალსახმობს; iPad-ზე ⌘ კლავიში მუშაობს {{key:Mod+Z}}-სა და დანარჩენისთვის.

შეხებისას ღილაკები თავის მინიშნებებს არ აჩვენებენ. თითოეული ინსტრუმენტის კლავიში ჩამოთვლილია [კლავიატურა და მაუსი](topic:keyboard)-ში.

## სტილუსი და Apple Pencil

სტილუსი (Apple Pencil, Surface Pen და მსგავსი) მუშაობს როგორც მაუსი: ხატავს და ირჩევს, და მოქმედებს დაუყოვნებლივ შეხებისას. პინჩისა და გადაადგილებისთვის გამოიყენეთ თითები. წნევა ხაზის სისქეს არ ცვლის.

## გახსნა და შენახვა iPad-ზე

- {{ui:გახსნა}} აჩვენებს Files-ის ამრჩევს: iCloud Drive, On My iPad და ნებისმიერ შენახვის აპს, რომელიც დაკავშირებული გაქვთ.
- {{ui:შენახვა}} ითხოვს ჩამოტვირთვას; ასლი ჩნდება Files-ში, Downloads-ის ქვეშ (ან Safari-ის პარამეტრებში დაყენებულ საქაღალდეში).

## სამუშაოს უსაფრთხოდ შენახვა ტაბლეტზე

:::warning
iPad-ის Safari არ გაფრთხილებთ, სანამ შეუნახავი სამუშაოს მქონე გვერდს დატოვებთ, და iPadOS მეხსიერების გასათავისუფლებლად შეიძლება ჩანართი ფონურად ხელახლა ჩატვირთოს. MarkupCraft ბრაუზერში ინახავს აღდგენის ასლს და მას ხელახალი გახსნისას გთავაზობთ (იხილეთ [სამუშაოს აღდგენა](common:recover)), მაგრამ **შეინახეთ ყოველი ფურცლის ან ყოველი სიარულის შემდეგ**: კერძო ჩანართი ასლს არ ინახავს.
:::

- თქვენი სახელი, ინსტრუმენტების პარამეტრები და ინსტრუმენტების ყუთი ინახება იმ ბრაუზერში, იმ iPad-ზე, როგორც კომპიუტერზე. იხილეთ [რა რჩება ამ ბრაუზერში](topic:browser-storage).
- **საველე ვიზიტამდე სიგნალის გარეშე:** სანამ ინტერნეტი გაქვთ, გახსენით MarkupCraft Safari-ში (ან Chrome-ში) iPad-ზე და აირჩიეთ {{ui:ხაზგარეშე შესანახად}} ზედა ზოლში. დაელოდეთ, სანამ არ ეწერება „მზადაა ხაზგარეშე“ (ითვლის „ინახება N-დან M-მდე“-ს; PDF-მკითხველი და ჩამწერი დაახლოებით 6 MB-ია). ობიექტზე გახსენით იგივე მისამართი ან მისი სანიშნე: PDF-ების გახსნა, მონიშვნა და შენახვა კავშირის გარეშე მუშაობს. თუ წერია „ხაზგარეშე არ არის ხელმისაწვდომი“, კერძო ჩანართში ხართ; გამოიყენეთ ჩვეულებრივი. იხილეთ [მუშაობა ხაზგარეშე](common:offline).
- Safari შეიძლება ამოშალოს ხაზგარეშე ასლი, რომელსაც რამდენიმე კვირის განმავლობაში არ იყენებთ. მოგზაურობამდე დააწკაპუნეთ „მზადაა ხაზგარეშე“-ზე და აირჩიეთ „ხელახლა შენახვა (უახლესი ვერსიის მიღება)“.
- ძალიან დიდი ნაკრებები მეხსიერებას ბევრს ხმარობენ. ტაბლეტზე გახსენით მხოლოდ ის ფურცლები, რაც ვიზიტისთვის გჭირდებათ.

## ტელეფონზე

ის მუშაობს, მაგრამ ეკრანი პატარაა: ნაწილები ერთმანეთზე ილაგება (ზოლი, ფურცელი, სტატუსის ზოლი, პანელები, შემდეგ ფურცლების სია), და ზოლი გვერდზე სქროლდება. ტელეფონი გამოიყენეთ სანახავად და სწრაფი შენიშვნის დასამატებლად, ხოლო სერიოზული განხილვისთვის — ტაბლეტი ან კომპიუტერი.
