BCF (BIM Collaboration Format) არის ღია ფაილის ფორმატი, რომელიც საკითხებს BIM ინსტრუმენტებს შორის გადასცემს. ბევრ მოდელის კოორდინაციისა და შემუშავების პროგრამას შეუძლია `.bcfzip` ფაილის იმპორტი როგორც საკითხების სია. MarkupCraft წერს **BCF 2.1**-ს.

## შექმნა

1. გახსენით {{ui:მონიშვნები}} ჩანართი.
2. გაფილტრეთ სია იმის მიხედვით, რისი გაგზავნაც გსურთ, მაგალითად {{ui:სტატუსი}} „ღია“. ექსპორტირდება მხოლოდ სიაში მყოფი მონიშვნები.
3. აირჩიეთ {{ui:BCF}}.
4. დაელოდეთ, სანამ თითოეული მონიშვნის სნეპშოტს გააკეთებს („სნეპშოტების შექმნა BCF-ისთვის (5-დან 20)…“).

შედეგი: ჩამოიტვირთება „<name> markups.bcfzip“, ხოლო სტატუს ზოლში ნათქვამია, რამდენი თემა აქვს ფაილს და რა ზომისაა იგი.

## რა არის ფაილში

ყოველი მონიშვნა ერთ **თემად** გადაიქცევა:

| თემის ველი | რით ივსება |
|---|---|
| სათაური | ხარვეზის ნომერი, საგანი და ფურცელი, მაგალითად „#4 ღრუბელი A-101-ზე — იატაკის გეგმა“ |
| ტიპი | მონიშვნის სახეობა (ღრუბელი, ზეაწერი, სიგრძე…) |
| სტატუსი | ღია, მიღებული, უარყოფილი ან დასრულებული |
| ეტიკეტები | მონიშვნის სახეობა და ფურცელი |
| ავტორი და თარიღები | მონიშვნის ავტორი, შექმნისა და შეცვლის თარიღები |
| მინიჭებულია, ვადა | ხარვეზის ნივთიდან, თუ მას აქვს |
| აღწერა | მისი ტექსტი ან შტამპის სიტყვები, გაზომილი მნიშვნელობა, კომენტარი, ფურცელი და ფაილი |
| კომენტარები | თითო პასუხზე ერთი, ავტორისა და თარიღის მითითებით |
| სნეპშოტი | მონიშვნის სურათი ფურცლის მის ნაწილზე |
| ხედვის წერტილი | მონიშვნის ადგილის ზემოდან ხედი ფურცელზე |

იმავე მონიშვნის ხელახალი ექსპორტი იმავე თემის ID-ს იძლევა, ასე რომ BCF-ის იმპორტის ინსტრუმენტს შეუძლია ის იმავე საკითხად აღიქვას.

## შეზღუდვები, რომლებიც უნდა იცოდეთ

- **ფურცელი არ არის მოდელი.** ხედვის წერტილი მონიშვნის ადგილს მიუთითებს ქაღალდზე, რომელიც ქაღალდის მეტრებში იზომება. ის BIM ინსტრუმენტს მოდელში ადგილამდე არ მიიყვანს. ადგილის საპოვნელად გამოიყენეთ სნეპშოტი და ფურცლის სახელი.
- **სტატუსები და ტიპები MarkupCraft-ისაა** (ღია, მიღებული, უარყოფილი, დასრულებული; ღრუბელი, ზეაწერი…). ფაილი მათ BCF-ის წესით აცხადებს, მაგრამ ინსტრუმენტს საკუთარი ფიქსირებული სიები რომ აქვს, მან შეიძლება ისინი სხვაგვარად დაუკავშიროს ან უგულებელყოს.
- **იმპორტი კომენტარებს შემოიტანს, მოდელის ხედებს — არა.** {{ui:BCF-ის იმპორტი}} ექსპორტირებულ მონიშვნებს პასუხებსა და სტატუსებს უმატებს და სხვა საკითხებს შენიშვნებად ინახავს; მოდელის კამერას ვერ აჩვენებს. იხილეთ [მონიშვნების სია და ექსპორტი](topic:markups-list-and-export#import-bcf).
- ხატვის განხილვისთვის მონიშვნების PDF-ად დაბრუნება ხშირად უფრო მარტივია. BCF საჭიროა იმისთვის, რომ ნახაზის კომენტარები მოდელის კოორდინაციის სამუშაო პროცესში მოხვდეს.
