BCF (BIM Collaboration Format) არის ღია ფაილის ფორმატი, რომელიც საკითხებს BIM ინსტრუმენტებს შორის გადასცემს. მოდელის კოორდინაციისა და შემუშავების ბევრ პროგრამას შეუძლია `.bcfzip` ფაილის იმპორტი საკითხების სიად. MarkupCraft წერს **BCF 2.1**-ს.

## ფაილის შექმნა

1. გახსენით ჩანართი {{ui:Markups}}.
2. გაფილტრეთ სია იმის მიხედვით, რისი გაგზავნაც გსურთ, მაგალითად {{ui:Status}} „ღია“. ექსპორტირდება მხოლოდ სიაში ჩამოთვლილი მონიშვნები.
3. აირჩიეთ {{ui:BCF}}.
4. დაელოდეთ, სანამ თითოეული მონიშვნის სნიმოკს გააკეთებს („BCF-ისთვის სნიმოკების შექმნა (5 მიდან 20)…“).

შედეგად ჩამოიტვირთება ფაილი „<name> markups.bcfzip“, ხოლო სტატუსის ზოლში ნაჩვენებია, რამდენი თემა შეიცავს და რა ზომისაა ფაილი.

## რას შეიცავს

თითოეული მონიშვნა ხდება ერთი **თემა**:

| თემის ველი | რით იავსება |
|---|---|
| სათაური | ნაკლის ნომერი, საგანი და ფურცელი, მაგალითად „#4 ღრუბელი A-101-ზე — იატაკის გეგმა“ |
| ტიპი | მონიშვნის სახე (ღრუბელი, მინიშნება, სიგრძე…) |
| სტატუსი | ღია, მიღებული, უარყოფილი ან დასრულებული |
| ეტიკეტები | მონიშვნის სახე და ფურცელი |
| ავტორი და თარიღები | მონიშვნის ავტორი, შექმნისა და შეცვლის თარიღები |
| მინიჭებულია, ვადა | მისი ნაკლის ელემენტიდან, თუ ის არსებობს |
| აღწერა | მისი ტექსტი ან შტამპის ფორმულირება, გაზომილი მნიშვნელობა, კომენტარი, ფურცელი და ფაილი |
| კომენტარები | თითო პასუხზე ერთი, ავტორისა და თარიღით |
| სნიმოკი | მონიშვნის სურათი ფურცლის მის ნაწილზე |
| ხედი | მონიშვნის ადგილის ზედა ხედი ფურცელზე |

იგივე მონიშვნის თავიდან ექსპორტი იგივე თემის ID-ს იძლევა, ამიტომ BCF-ის იმპორტის მქონე ინსტრუმენტს შეუძლია ის იგივე საკითხად ამოიცნოს.

## იმპორტისას რა შემოდის

{{ui:Import BCF}} კითხულობს BCF 2.0, 2.1 და 3.0 ფაილებს (შემოწმებულია buildingSMART-ის 19 ოფიციალურ 3.0 სატესტო ფაილზე: ყველა თემა წაკითხულია, ხოლო ტექსტიანი კომენტარები სამი ფაილიდან წაკითხულია). თქვენს თემას (იგივე თემის ID) იგი ახალ კომენტარებს პასუხებად უმატებს და იღებს ახალ სტატუსს. ნებისმიერი სხვა თემა ხდება შენიშვნა იმ ფურცელზე, რომელსაც მისი ეტიკეტი ან ფაილის სახელი ასახელებს; წინააღმდეგ შემთხვევაში — ღია ფურცელზე. მისი სათაური, აღწერა, შემსრულებელი და ვადა ხდება შენიშვნის ტექსტი, ხოლო კომენტარები — პასუხები.

| BCF თემაში | MarkupCraft-ში |
|---|---|
| სათაური, აღწერა, შემსრულებელი, ვადა | შენიშვნის ტექსტი |
| ტექსტიანი კომენტარები | პასუხები |
| სტატუსი Open, Accepted, Rejected, Completed (Closed, Resolved, Done დასრულებულად ითვლება) | მონიშვნის სტატუსი |
| ავტორი და შექმნის თარიღი | შენიშვნის ავტორი და თარიღი |
| კამერის პოზიცია | ადგილი ფურცელზე, მხოლოდ იმ თემისთვის, რომელიც ფურცელს ეტიკეტით ან ფაილის სახელით უკავშირდება |
| მოდელის მონიშვნა, დამალული ნაწილები, მჭრელი სიბრტყეები, სნიმოკები | არ ინახება: ფურცელს არ აქვს მოდელი, სადაც მათი ჩვენება შეიძლებოდა |

## შეზღუდვები, რომლებიც უნდა იცოდეთ

- **ფურცელი მოდელი არ არის.** ხედი მიუთითებს მონიშვნის ადგილზე ქაღალდზე, რომელიც ქაღალდის მეტრებში იზომება. ის BIM ინსტრუმენტს მოდელში ადგილამდე არ მიიყვანს. ადგილის საპოვნელად გამოიყენეთ სნიმოკი და ფურცლის სახელი.
- **სტატუსები და ტიპები MarkupCraft-ისია** (ღია, მიღებული, უარყოფილი, დასრულებული; ღრუბელი, მინიშნება…). ფაილი მათ აცხადებს, როგორც BCF ითვალისწინებს, მაგრამ ინსტრუმენტს, რომელსაც საკუთარი ფიქსირებული სიები აქვს, შეუძლია ისინი შეუსაბამოს ან უგულებელყოს.
- **იმპორტი კომენტარებს მოაქვს და არა მოდელის ხედებს.** {{ui:Import BCF}} ექსპორტირებულ მონიშვნებს უმატებს პასუხებსა და სტატუსებს, ხოლო სხვა საკითხებისთვის ქმნის შენიშვნებს; მოდელის კამერას ვერ აჩვენებს. იხილეთ [მონიშვნების სია და ექსპორტი](topic:markups-list-and-export#import-bcf).
- ნახაზების შემოწმებისას მონიშვნების PDF-ად დაბრუნება ხშირად უფრო მარტივია. BCF განკუთვნილია იმისთვის, რომ ნახაზის კომენტარები მოდელის კოორდინაციის სამუშაო პროცესში მოხვდეს.
