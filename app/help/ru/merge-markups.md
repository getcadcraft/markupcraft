Два человека вносят пометки в один PDF в двух копиях. Если они меняли разные пометки, копии можно объединить программой, а не вручную.

## Что делает это возможным

Каждая пометка, которую сохраняет MarkupCraft, несет в PDF собственное имя (идентификатор), и это имя никогда не меняется. Объединение находит пометки по этому имени, а не по их месту в файле, потому что любая программа при сохранении перенумеровывает места. Заметки и запечатанные личные заметки сопоставляются так же.

Листы никогда не меняются: в обеих копиях должно быть одинаковое число страниц. Если оно различается, объединение оставляет вашу копию как есть и сообщает об этом, потому что добавлять или удалять страницы должен человек.

## Настройка

Git нужны две строки один раз на репозиторий:

```
# .gitattributes
*.pdf merge=cadcraft

# one time, on each computer
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Без git запустите `cadcraft merge <base> <ours> <theirs> -o <result>`. Fossil и Mercurial принимают те же три файла в собственной настройке инструмента слияния. Файл задач, который идет вместе с чертежом (`<name>.markups.json`, см. [Пометки с действием](topic:markups-that-act)), объединяется так же, как простой текст.

## Правила

- Пометка, измененная только с одной стороны, принимается. Одинаковое изменение с обеих сторон учитывается один раз.
- Одна и та же пометка, измененная двумя способами, — это **конфликт**: остается ваша сторона, а в отчете перечислены обе. Откройте результат и исправьте эту пометку вручную.
- Пометка, добавленная с любой стороны, сохраняется. Пометка, удаленная с одной стороны и не тронутая с другой, удаляется. Удаленная с одной стороны и измененная с другой: удаляется и попадает в отчет.
- Слои, столбцы, записи и заметки подчиняются тем же правилам.
- Запечатанные личные заметки никогда не открываются: блоки обеих сторон сохраняются как есть.

Объединенный файл — это полная перезапись вашей копии, как собственное «Сохранить» MarkupCraft. Ничего не загружается: всё выполняется на вашем компьютере.
