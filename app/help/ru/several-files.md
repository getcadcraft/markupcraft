Комплект чертежей часто приходит как по одному PDF на дисциплину или по одному PDF на лист. MarkupCraft считает всё, что вы открываете, **одним комплектом**.

## Открытие вместе

Выберите все PDF в окне выбора файлов сразу или перетащите их все на область листов. Чтобы добавить еще позже, откройте их так же; они присоединятся в конец списка {{ui:Листы}} в порядке открытия.

Результат: «Открыто файлов: 6 (листов в комплекте: 84).» Каждая страница — это лист. Листы с номером показывают «Лист A-101» под своим названием; остальные показывают файл и страницу.

Сохраненного файла «комплекта» нет: в следующий раз откройте те же PDF снова (копии «(marked up)», если вы сохраняли).

## По всему комплекту

- **Поиск листа:** {{ui:Поиск листов}} ищет по номерам листов, названиям листов и именам файлов всех файлов. {{key:PageUp}} и {{key:PageDown}} проходят по всем листам всех файлов по порядку.
- **Список пометок:** вкладка {{ui:Пометки}} показывает пометки из всех файлов. Фильтруйте по {{ui:Лист}}, чтобы сузить список. В CSV есть столбец «Файл».
- **Перечень замечаний:** единая нумерация для всего комплекта.
- **Сравнение:** старый и новый лист могут быть из разных файлов.
- **Копирование и вставка:** {{key:Mod+C}} на одном листе и {{key:Mod+V}} на другом — в любом файле. Копия попадает на то же место страницы, слегка смещенная.

## Сохранение

Выберите {{ui:Сохранить}}. Если открыто больше одного файла, MarkupCraft спросит:

- {{ui:Этот файл}}: копия с пометками файла листа, на котором вы находитесь.
- {{ui:Каждый измененный файл}}: копия каждого файла с несохраненными изменениями. Каждая скачивается отдельно как «<имя файла> (marked up).pdf».
- {{ui:Отмена}}

:::chromium
При первом сохранении нескольких файлов сразу Chrome и Edge могут спросить, разрешает ли этот сайт скачивать несколько файлов. Выберите {{ui:Разрешить}}; иначе придет только первая копия.
:::

:::safari
Safari может спрашивать по разу для каждого файла. На iPad каждая копия попадает в приложение «Файлы».
:::

Файл, пометки которого сохранены, перестает считаться измененным; остальные по-прежнему считаются.

Экспорты CSV, BCF и перечня замечаний называются по имени **первого** открытого вами файла.

## Закрытие

{{ui:Закрыть}} закрывает весь комплект; закрыть отдельный файл пока нельзя. Если есть несохраненное, программа спросит:

- {{ui:Отмена}}: ничего не происходит.
- {{ui:Закрыть без сохранения}}: несохраненные пометки теряются.
- {{ui:Сначала сохранить копии}}: сохраняет каждый измененный файл, затем закрывает.

Закрытие также очищает историю отмены.

## Большие комплекты

- Текст каждой страницы читается при открытии, чтобы найти номера листов, поэтому комплект из 100 листов загружается какое-то время. Строка состояния считает листы по мере чтения.
- Изображения листов в списке рисуются, когда вы прокручиваете к ним.
- Каждый открытый PDF хранится в памяти вкладки браузера. Если вкладка начинает тормозить, закройте другие тяжелые вкладки или проверяйте по одной дисциплине за раз.
- Если открыть один и тот же файл дважды, появятся две копии его листов. В таком случае выберите {{ui:Закрыть}} и откройте комплект заново.
