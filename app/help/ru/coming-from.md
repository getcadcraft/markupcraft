Если вы проверяете чертежи в Bluebeam Revu (или комментируете PDF в другой настольной программе для PDF), большая часть MarkupCraft покажется знакомой: облака, выноски, набор инструментов, список пометок, статусы с ответами, измерения по калибровке, наложения листов. Самое большое отличие — в работе с файлами, поэтому прочитайте следующий раздел, даже если пропустите остальное.

## Пять важных различий

1. **Сохранение создает новый файл.** MarkupCraft работает в браузере и не может перезаписать PDF на вашем диске. {{ui:Сохранить}} скачивает «<name> (marked up).pdf», а исходный файл остается как был. В следующий раз откройте копию «(marked up)» и сами удаляйте старые копии.
2. **PDF сохраняется при сохранении.** До этого копия для восстановления в этом браузере сохраняет ваши пометки при сбое или закрытой вкладке, и MarkupCraft предложит ее вернуть при следующем открытии. Это страховка: сохраните PDF, чтобы сохранить проверку.
3. **Ваш профиль хранится в браузере.** Ваше имя автора, настройки инструментов и набор инструментов хранятся в этом браузере на этом компьютере. Другой браузер или компьютер начинает с нуля, а очистка данных сайта их стирает. Экспортируйте набор инструментов как резервную копию. См. [Что хранится в этом браузере](topic:browser-storage).
4. **Общих сеансов пока нет.** Нет live-сессии совместной проверки и облачного проекта. Проверка передается в PDF: сохраните, отправьте копию, следующий человек ответит и сохранит.
5. **Масштаб задается для каждого листа, и только так.** Внутри листа нет видовых экранов и нет «применить этот масштаб ко всем страницам». Откалибруйте каждый лист, на котором измеряете.

## Привычка за привычкой

| Вы привыкли к | В MarkupCraft |
|---|---|
| Панель миниатюр, метки страниц | {{ui:Листы}} слева. Названия берутся из меток страниц или считываются из основной надписи; исправляйте их через {{ui:Переименовать лист}}. |
| Открытие нескольких PDF как набора | Откройте их все сразу; они станут одним списком. Файл набора не сохраняется: откройте те же PDF в следующий раз. |
| Набор инструментов с наборами инструментов | Вкладка {{ui:Инструменты}}: один набор на браузер, сохраненные инструменты со стилем и темой. Делитесь через {{ui:Экспорт}} и {{ui:Импорт}} в виде файла JSON. Файлы наборов инструментов из других программ импортировать нельзя. |
| Панель свойств | Вкладка {{ui:Свойства}}: статус, тема, комментарий, стиль, ответы и пункт перечня замечаний в одном месте. |
| Список пометок со столбцами | Вкладка {{ui:Пометки}} с фильтрами по листу, автору, статусу и виду. Экспорт в CSV или BCF. Нет пользовательских столбцов и пока нет сводки PDF или таблицы. |
| Статус и состояние проверки | {{ui:Статус}}: Открыта, Принята, Отклонена, Выполнена. Нет собственных наборов статусов. Сохраняются как стандартные состояния проверки. |
| Ответы на пометку | Цепочка «Replies» в {{ui:Свойствах}}, где записываются и изменения статуса. Отправленный ответ нельзя изменить. |
| Калибровка, затем длина, площадь, подсчет | {{ui:Калибровать}}, {{ui:Длина}} ({{key:M}}), {{ui:Площадь}} ({{key:Q}}, дает площадь и периметр), {{ui:Счет}} ({{key:U}}). Пока нет угла, радиуса, объема, длины полилинии или вырезов. |
| Наложение страниц | {{ui:Сравнение}}: красный для старого, синий для нового, совмещение по двум точкам. Нет автоматической обводки облаками при сравнении документов. |
| Штампы | {{ui:Штамп}} с шестью встроенными штампами и своим текстом, подписанные вашим именем и датой. Пока нет штампов с изображением или подписью. |
| Отслеживание замечаний или задач | Вкладка {{ui:Перечень замечаний}}: пронумерованные пункты с исполнителем, сроком и статусом; экспорт в CSV. |
| Совместный сеанс live | Пока недоступно. Передавайте сохраненный PDF. |
| Растрирование (flatten) | Еще не создано. Пометки остаются комментариями, которые другие программы могут показать и напечатать. |
| Слои для пометок | Еще не создано. Используйте темы, авторов и фильтры списка, чтобы сортировать комментарии. |
| Гиперссылки между листами | Еще не создано. |
| Пробел для панорамирования, колесо для масштаба | То же: удерживайте {{key:Space}} и перетаскивайте; колесо масштабирует по указателю. Колесо никогда не прокручивает страницу. |

## Клавиши, которые отличаются

Многие клавиши с одной буквой работают так, как вы ожидаете, но проверьте эти, прежде чем пальцы сделают это за вас:

- {{key:K}} — это {{ui:Выноска}}, а {{key:Q}} — {{ui:Площадь}}. Если вы привыкли к Q для выносок, здесь она начнет область.
- {{key:C}} — прямоугольное {{ui:Облако}}; {{key:Shift+C}} — {{ui:Облако от руки}}.
- {{key:M}} — {{ui:Длина}}, {{key:U}} — {{ui:Счет}}, {{key:Y}} — {{ui:Полилиния}}, {{key:G}} — {{ui:Многоугольник}}, {{key:I}} — {{ui:Выделение}}.
- {{key:Mod+D}} дублирует выбранное (вместо закладки браузера).
- {{key:Mod+Plus}} и {{key:Mod+Minus}} масштабируют лист, а не страницу браузера.
- Любую клавишу можно изменить: см. ниже.

:::tip
Если ваши пальцы привыкли к Bluebeam Revu, выберите стиль меню {{ui:Проверка PDF}} в {{ui:Настройки}} › {{ui:MarkupCraft}} › {{ui:Меню, клавиши и мышь}}: строка меню (Файл, Правка, Вид, Документ, Пометка, Измерение, Окно) над рядом инструментов проверки, {{key:Q}} для выноски, {{key:H}} для выделения маркером, {{key:N}} для многоугольника, а измерения на {{key:Alt+Shift}} с буквой. Любую клавишу можно изменить и там. См. [Меню, клавиши и мышь](topic:menus-keys-and-mouse).
:::

Полный список — в [Клавиатура и мышь](topic:keyboard).

## Что работает иначе, чем вы ожидаете

- **Инструменты остаются включенными.** После облака вы по-прежнему рисуете облака. {{key:Esc}} один раз снимает выбор, два раза возвращает {{ui:Выбор}}.
- **Тексту и выноскам нужен текст.** Если завершить без ввода, пометка не добавляется. Заметки остаются пустыми.
- **Измерениям сначала нужен масштаб.** {{ui:Длина}} и {{ui:Площадь}} переключаются на {{ui:Калибровать}} на некалиброванном листе и возвращаются после.
- **Комментарии из других программ.** Прямоугольники, эллипсы, линии, полилинии, многоугольники, рукописные штрихи, текстовые поля и стикеры, созданные в других программах, становятся редактируемыми пометками MarkupCraft и переписываются по правилам MarkupCraft при сохранении (их вид может слегка измениться). Текстовые выделения, штампы других программ и прочие особые виды остаются только для чтения: на них можно ответить, но нельзя их изменить.
- **Символы вне западноевропейских букв** печатаются как «?» в сохраненном PDF. См. [Сохранение PDF с пометками](topic:save-the-marked-up-pdf).
- **Даты штампов** используют UTC, поэтому штамп, сделанный поздно вечером в Америке, может показать завтрашнюю дату.
- **Измерения переносятся** как стандартные комментарии измерений, а каждый откалиброванный лист сохраняет свой масштаб, поэтому программа, которая читает измерения PDF, обычно может их показать. Точное поведение зависит от этой программы.

## Работа в обеих программах

Вы можете переходить туда и обратно. Комментарии, сделанные в других программах, открываются в MarkupCraft, а PDF «(marked up)» открывается в других PDF-программах со всеми пометками, ответами и статусами. То, что читает обратно только MarkupCraft (исполнитель и срок пункта перечня, статус пункта), хранится в файле для MarkupCraft.
