Копия с пометками — это исходный PDF с добавленными комментариями (аннотациями PDF). Сами страницы, их чертежи, текст, закладки и ссылки копируются без изменений.

## Каждая пометка

| MarkupCraft | Сохраняется как | Другие просмотрщики PDF показывают |
|---|---|---|
| Прямоугольник, облако-рамка | Аннотация Square (облако: облачная граница) | Комментарий в виде прямоугольника или облака |
| Эллипс | Аннотация Circle | Комментарий в виде эллипса |
| Многоугольник, свободное облако | Аннотация Polygon (облако: облачная граница) | Комментарий в виде многоугольника или облака |
| Полилиния | Аннотация PolyLine | Комментарий в виде полилинии |
| Линия, стрелка | Аннотация Line (стрелка: закрытый наконечник) | Комментарий в виде линии или стрелки |
| Длина | Аннотация Line, помеченная как размер, с измерением | Измерение длины там, где просмотрщик его поддерживает |
| Площадь | Аннотация Polygon, помеченная как площадь, с измерением | Измерение площади, где поддерживается; иначе многоугольник |
| Группа подсчета | Одна аннотация Ink, кольцо на каждый элемент; её текст: «group: n» | Комментарий Ink |
| Перо, маркер | Аннотация Ink (маркер помечен как таковой) | Комментарий Ink |
| Текст | Аннотация FreeText | Комментарий в виде текстового поля |
| Выноска | Аннотация FreeText с линией выноски | Комментарий в виде выноски |
| Заметка | Аннотация Text | Стикер, который открывается с текстом |
| Штамп | Аннотация Stamp | Комментарий в виде штампа |

Каждая пометка сохраняется с:

- **собственным внешним видом**, нарисованным точно так, как MarkupCraft рисует её на экране, поэтому она выглядит и печатается одинаково в любом просмотрщике, включая значок номера замечания;
- **автором**, **датами создания и изменения**, **темой**, **текстом комментария** (для текстовых полей и выносок — текст и комментарий), **цветом** и **непрозрачностью**;
- **данными MarkupCraft** в личной записи, которую другие программы игнорируют: состояние, пункт замечания, стиль и тип, чтобы пометка открывалась точно такой же.

## Ветки и состояния

- Каждый ответ сохраняется как комментарий-ответ, связанный со своей пометкой, с автором, датой и текстом. У ответов нет собственного значка на листе.
- Каждое изменение статуса сохраняется как ответ с состоянием проверки. Другие инструменты проверки показывают его как Accepted, Rejected или Completed; состояние Open сохраняется без состояния.
- Пометка со статусом, отличным от Open, но без записанного изменения статуса, получает один ответ с состоянием проверки, чтобы другие программы тоже видели статус.
- Ответы на комментарии только для чтения из исходного файла сохраняются так же, со связью с этим комментарием.

## Каждый лист

- **Масштаб:** калиброванный лист получает видовой экран измерения, покрывающий страницу (стандартный способ хранить масштаб страницы), и собственную копию калибровки MarkupCraft.
- **Номер листа:** номер, введенный через {{ui:Переименовать лист}}, становится меткой страницы. Если у какой-либо страницы файла есть метка, каждая страница этого файла получает метку: введенный номер, иначе прежнюю метку, иначе номер страницы.
- **Название листа:** введенное название сохраняется только для MarkupCraft; другие просмотрщики его не показывают.

## Текст и символы

Текст записывается шрифтом Helvetica, который есть в любом просмотрщике PDF. Буквы вне западноевропейского набора (Windows-1252) выводятся как «?» в копии; сообщение при сохранении их подсчитывает.

## Расчетные листы и обоснования

Расчетные листы и обоснования хранятся в личной записи PDF с именем `/MarkupCraftShell`. Другие программы для PDF её игнорируют. Старые версии MarkupCraft тоже её игнорируют и удаляют при следующем сохранении этого файла.

## Что происходит с комментариями, которые уже были

Когда вы открываете PDF, в котором уже есть комментарии:

- комментарии MarkupCraft читаются обратно точно. Если другая программа переместила или изменила размер одного из них, побеждает новое положение.
- Прямоугольники, эллипсы, линии, полилинии, многоугольники, рисунки, текстовые поля и стикеры из других программ становятся редактируемыми пометками. **При сохранении MarkupCraft удаляет исходные объекты и записывает их заново по-своему**, вместе со всплывающими окнами и ответами. Их внешний вид может немного измениться.
- Состояния проверки из других программ задают статус; побеждает самое новое.
- Всё остальное (текстовые выделения, штампы других программ и особые виды) **сохраняется без изменений** в копии, только для чтения.
- Ссылки и поля форм сохраняются без изменений и в список не выводятся.

Повторное сохранение того же файла ничего не удваивает: прочитанные MarkupCraft пометки заменяются, а не добавляются снова.

## Что не меняется

Исходный файл на диске никогда не меняется. Копия не оптимизирована по размеру, поэтому может быть немного больше оригинала. Защищенные (зашифрованные) PDF сохранить нельзя.
