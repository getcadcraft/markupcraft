BCF (BIM Collaboration Format) — открытый формат файлов для передачи замечаний между BIM-инструментами. Многие программы координации и проектирования моделей могут импортировать файл `.bcfzip` как список замечаний. MarkupCraft записывает **BCF 2.1**.

## Создание файла

1. Откройте вкладку {{ui:Пометки}}.
2. Отфильтруйте список так, чтобы остались пометки для отправки, например {{ui:Статус}} «Открыта». Экспортируются только пометки из списка.
3. Выберите {{ui:BCF}}.
4. Дождитесь, пока будет создан снимок каждой пометки («Создание снимков для BCF (5 из 20)…»).

Результат: «<name> markups.bcfzip» скачивается, а в строке состояния показано, сколько замечаний в файле и каков его размер.

## Что в файле

Каждая пометка становится одним **замечанием** (topic):

| Поле замечания | Заполняется |
|---|---|
| Заголовок | Номер пункта, тема и лист, например «#4 Облако на A-101 — План этажа» |
| Тип | Вид пометки (Облако, Выноска, Длина…) |
| Статус | Открыта, Принята, Отклонена или Выполнена |
| Метки | Вид пометки и лист |
| Автор и даты | Автор пометки, даты создания и изменения |
| Исполнитель, срок выполнения | Из пункта перечня замечаний, если он есть |
| Описание | Текст или текст штампа, измеренное значение, комментарий, лист и файл |
| Комментарии | По одному на каждый ответ, с автором и датой |
| Снимок | Изображение пометки на её участке листа |
| Точка обзора | Вид сверху на место пометки на листе |

При повторном экспорте той же пометки получается тот же ID замечания, поэтому инструмент, который импортирует BCF, узнает в ней то же самое замечание.

## Что возвращается при импорте

{{ui:Импорт BCF}} читает файлы BCF 2.0, 2.1 и 3.0 (проверено на 19 официальных тестовых файлах buildingSMART 3.0: прочитаны все замечания, а комментарии трёх из них, где есть текст, тоже прочитаны). Для замечания, которое ваше (тот же ID замечания), новые комментарии добавляются как ответы, и принимается новый статус. Любое другое замечание становится заметкой на листе, указанном в его метке или имени файла, а если такого нет, — на открытом листе. Заголовок, описание, исполнитель и срок выполнения становятся текстом заметки, а комментарии — ответами.

| В замечании BCF | В MarkupCraft |
|---|---|
| Заголовок, описание, исполнитель, срок выполнения | Текст заметки |
| Комментарии с текстом | Ответы |
| Статус Open, Accepted, Rejected, Completed (Closed, Resolved и Done считаются Completed) | Статус пометки |
| Автор и дата создания | Автор и дата заметки |
| Положение камеры | Место на листе, только для замечания, связанного с листом по метке или имени файла |
| Выбор модели, скрытые части, секущие плоскости, снимки | Не сохраняется: у листа нет модели, в которой их можно показать |

## Ограничения, которые нужно знать

- **Лист — это не модель.** Точка обзора указывает на положение пометки на бумаге, измеренное в метрах бумаги. Она не переводит BIM-инструмент к месту в модели. Для поиска места используйте снимок и название листа.
- **Статусы и типы — собственные у MarkupCraft** (Open, Accepted, Rejected, Completed; Cloud, Callout…). Файл их объявляет, как и допускает BCF, но инструмент с собственными фиксированными списками может сопоставить их или пропустить.
- **Импорт приносит комментарии, а не виды модели.** {{ui:Импорт BCF}} добавляет ответы и статусы к пометкам, которые вы экспортировали, и создаёт заметки по остальным замечаниям; показать камеру модели он не может. См. [Список пометок и экспорт](topic:markups-list-and-export#import-bcf).
- Отправка пометок обратно в виде PDF часто проще для проверки чертежей. BCF нужен, чтобы передавать замечания по чертежам в процесс координации модели.
