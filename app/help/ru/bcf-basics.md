BCF (формат совместной работы BIM) — открытый файловый формат для передачи замечаний между BIM-программами. Многие программы координации и проектирования моделей могут импортировать файл `.bcfzip` как список замечаний. MarkupCraft записывает **BCF 2.1**.

## Создание файла

1. Откройте вкладку {{ui:Пометки}}.
2. Отфильтруйте список по тому, что нужно отправить, например {{ui:Статус}} «Открыта». Экспортируются только пометки из списка.
3. Выберите {{ui:BCF}}.
4. Дождитесь, пока будет создан снимок каждой пометки («Создание снимков для BCF (5 из 20)…»).

Результат: файл «<name> markups.bcfzip» скачивается, а в строке состояния показано, сколько тем он содержит и какой у него размер.

## Что в нем содержится

Каждая пометка становится одной **темой**:

| Поле темы | Заполняется |
|---|---|
| Title | Номер замечания, предмет и лист, например «#4 Облако на A-101 — План этажа» |
| Type | Вид пометки (Облако, Выноска, Длина…) |
| Status | Открыта, Принята, Отклонена или Выполнена |
| Labels | Вид пометки и лист |
| Author and dates | Автор пометки, даты создания и изменения |
| Assigned to, due date | Из ее пункта перечня замечаний, если он есть |
| Description | Ее текст или текст штампа, измеренное значение, комментарий, лист и файл |
| Comments | По одному на каждый ответ, с автором и датой |
| Snapshot | Снимок пометки на ее участке листа |
| Viewpoint | Вид сверху на место пометки на листе |

Повторный экспорт той же пометки дает тот же идентификатор темы, поэтому программа, которая импортирует BCF, может распознать ее как то же замечание.

## Ограничения, которые нужно знать

- **Лист — это не модель.** Точка обзора указывает на место пометки на бумажном листе, измеренное в метрах бумаги. Она не переносит BIM-программу в нужное место модели. Для поиска места используйте снимок и название листа.
- **Статусы и виды — собственные для MarkupCraft** (Открыта, Принята, Отклонена, Выполнена; Облако, Выноска…). Файл их объявляет, как и допускает BCF, но программа с собственными фиксированными списками может сопоставить их или пропустить.
- **Импорт приносит комментарии, а не виды модели.** {{ui:Импорт BCF}} добавляет ответы и статусы к экспортированным пометкам и создает заметки по остальным замечаниям; он не может показать камеру модели. См. [Список пометок и экспорт](topic:markups-list-and-export#import-bcf).
- Возвращать пометки в виде PDF для проверки чертежей часто проще. BCF нужен, чтобы передавать замечания по чертежам в процесс координации модели.
