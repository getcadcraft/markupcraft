MarkupCraft este în dezvoltare. Iată ce nu face versiunea actuală, ca să puteți planifica în jurul acestui lucru. Descrie versiunea de astăzi, nu promisiuni.

## Lucrul cu alte persoane

| Încă nerealizat | Ce să faceți astăzi |
|---|---|
| Salvare în cloud și sincronizare între calculatoare | Păstrați PDF-urile împreună cu fișierele proiectului. Salvarea în cloud nu este disponibilă încă. |
| Îmbinarea copiilor adnotărilor a două persoane | Împărțiți foile între revizori sau copiați câteva adnotări cu {{key:Mod+C}} și {{key:Mod+V}}. RFI-urile, documentele de aprobare (submittals) și jurnalele zilnice se îmbină: vedeți [Urmărirea RFI-urilor, a documentelor de aprobare și a jurnalelor zilnice](topic:field-records). |
| Echipe, notificări și proiecte în cloud pentru RFI-uri și documente de aprobare | Transmiteți PDF-ul mai departe și folosiți {{ui:Îmbinare}} pentru a aduce copiile împreună. |
| RFI-uri, documente de aprobare și jurnale zilnice într-o sesiune live | Fiecare persoană lucrează pe propria copie; aduceți copiile împreună cu {{ui:Îmbinare}}. |
| Îmbinarea modificărilor a două persoane la câmpuri diferite ale aceleiași înregistrări | Câștigă ca înregistrare întreagă copia modificată ultima dată (firele de discuție și numele atașamentelor se unesc). Stabiliți cine editează ce înregistrare. |
| Instrumente de asistent pentru RFI-uri, documente de aprobare și jurnale zilnice | Lucrați cu ele în fila {{ui:Teren}}. Asistenții pot lucra cu adnotările: vedeți [Utilizarea MarkupCraft cu un asistent AI](topic:use-with-ai-assistants). |
| Editarea sau ștergerea unui răspuns odată trimis | Anulați imediat sau adăugați un răspuns de corectare. |
| Schimbarea autorului unei adnotări | Setați numele înainte de a începe. |

## Adnotări

| Încă nerealizat | Ce să faceți astăzi |
|---|---|
| Ștampile cu câmpuri de completat, semnături digitale certificate | Folosiți o ștampilă text personalizată, care conține numele și data, sau o imagine a semnăturii. |
| Atașarea altor fișiere decât fotografiile (documente, videoclipuri) | Păstrați-le lângă PDF și faceți referire la ele în comentariu. |
| Linkuri către site-uri web sau către fișiere care nu sunt deschise | Scrieți adresa sau numele fișierului în comentariu. |
| Seturi personalizate de stări | Folosiți cele patru stări, iar subiectul pentru orice altceva. |
| Editarea comentariilor venite cu fișierul ca doar citire (evidențieri de text, ștampile ale altor programe) | Răspundeți la ele sau desenați o adnotare MarkupCraft lângă ele. |
| Trăsături de creion sensibile la presiune | Setați grosimea liniei. |

## Conținutul propriu al paginii

| Încă nerealizat | Ce să faceți astăzi |
|---|---|
| Desenarea de forme noi direct în pagină | Desenați-le ca adnotări, apoi {{ui:Introducere în pagină}}. Vedeți [Modificarea conținutului propriu al paginii](topic:page-content). |
| Rotirea obiectelor paginii la orice unghi | Mutați și redimensionați-le; rotiți întreaga pagină cu {{ui:Pagini}}. |
| Schimbarea fontului sau a mărimii unei linii de text, sau a textului care trece pe mai multe rânduri | Schimbați cuvintele câte o linie; pentru text nou într-un alt font, adăugați o adnotare text. |
| Editarea conținutului unei imagini scanate | Înlocuiți imaginea sau adnotați-o. |
| Editarea PDF-urilor criptate sau semnate | Cereți o copie nesemnată; adnotările funcționează pe orice PDF. |

## Măsurare

| Încă nerealizat | Ce să faceți astăzi |
|---|---|
| Măsurători de rază | Desenați un {{ui:Arc}} de-a lungul ei, sau măsurați {{ui:Lungime}} de la un capăt la altul și împărțiți-o la doi. |
| Editarea colțurilor unei decupări | Eliminați decupările și desenați-le din nou. |
| Aplicarea unei scări la mai multe foi deodată | Calibrați fiecare foaie; alegerea unei presetări ia câteva secunde pentru fiecare foaie. |
| Mai multe scări pe o foaie (ferestre de vizualizare) | Calibrați după desenul pe care măsurați cel mai mult. Schimbarea scării unei foi remăsoară tot ce are, deci notați valorile detaliilor înainte de a recalibra pentru ele. |
| Agățarea de linii din desen | Măriți zoom-ul înainte de a face clic sau introduceți lungimi și unghiuri (vedeți [Schiță la scară](topic:calibrate-and-measure#sketch-to-scale)). |
| O extragere completă de cantități cu articole, ansambluri și prețuri | Folosiți TakeoffCraft, aplicația de extragere de cantități din familia CadCraft. |

## Foi și fișiere

| Încă nerealizat | Ce să faceți astăzi |
|---|---|
| Anularea unei modificări de pagină (rotire, mutare, inserare, ștergere) | Închideți fără salvare și deschideți din nou PDF-ul original. Vedeți [Imprimare și modificarea paginilor](topic:pages-and-printing). |
| Închiderea unui singur fișier dintr-un set | {{ui:Închidere}} închide tot setul; redeschideți fișierele de care aveți nevoie. |
| Salvarea unui set ca proiect pentru redeschidere dintr-un pas | Deschideți din nou aceleași PDF-uri. |
| Imprimarea la o scară aleasă sau mai multe foi pe o hârtie | Folosiți dialogul de imprimantă al browserului sau imprimați copia salvată dintr-un alt vizualizator PDF. |

|---|---|

## Compară

| Încă nerealizat | Ce să faceți astăzi |
|---|---|
| Compararea textului setat într-un font sau a unei liste cu ce s-a schimbat | Folosiți suprapunerea și glisorul, sau {{ui:Linii modificate}} pentru liniile desenate. |

| Alinierea automată a fiecărei perechi la compararea unui întreg set | Comparați o pereche deplasată separat și folosiți {{ui:Aliniere după două puncte}}. |

## Platforme

- **Desktop:** MarkupCraft rulează în browser pe Mac, Windows, Linux și iPad, și în CadCraft Studio, aplicația desktop cu toate cele opt aplicații într-o singură instalare.
- MarkupCraft este în dezvoltare. Etichetele și comportamentul se pot schimba în continuare, iar această documentație se schimbă odată cu ele.
