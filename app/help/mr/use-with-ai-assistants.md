## तुम्ही काय शिकाल

AI सहाय्यकाने (किंवा तुम्ही लिहिलेल्या स्क्रिप्टने) MarkupCraft सोबत कसे काम करावे, आणि तो कशाला स्पर्श करू शकतो हे कसे ठरवायचे.

MarkupCraft स्वतःचे **कोणतेही AI नाही** आणि कुठेही काहीही पाठवत नाही. सहाय्यक तुम्ही आणता: Model Context Protocol (MCP) बोलणारा कोणताही प्रोग्राम. MarkupCraft त्याला फक्त साधने देते, आणि कोणती हे तुम्ही निवडता.

## ते चालू करा

1. {{ui:Settings}} उघडा (अॅप बारमधील गियर, किंवा {{key:Mod+,}}) आणि {{ui:MarkupCraft}} टॅबवर जा.
2. {{ui:Assistants}} खाली, **AI सहाय्यक आणि स्क्रिप्टना MarkupCraft वापरू द्या** टिक करा. तुम्ही तसे करेपर्यंत ते बंद असते.
3. ते काय करू शकते ते निवडा: **Read** सुरुवातीला टिक केलेले असते; **Edit**, **Save** किंवा **Export** फक्त गरज असेल तेव्हाच टिक करा.

तुम्ही टिक केलेल्या परवानग्यांबाहेरची साधने सहाय्यकाला दिली जात नाहीत, आणि त्याने तरीही एखादे मागितले तर MarkupCraft ते नाकारते आणि क्रियाकलाप नोंदीत लिहिते. स्विच बंद केल्यास सर्व जोडण्या एकाच वेळी संपतात; {{ui:Reset MarkupCraft settings}} तोही बंद करते.

## तुमचा सहाय्यक जोडा

सहाय्यक तुमच्या संगणकावरील **CadCraft Studio** द्वारे जोडले जातात: Studio एक छोटा सर्व्हर चालवते जो फक्त हा संगणकच गाठू शकतो, आणि प्रत्येक वेळी सुरू होताना बनवलेल्या टोकनने संरक्षित असतो. Studio मध्ये {{ui:Connect an assistant}} निवडा आणि पत्ता व टोकन तुमच्या सहाय्यकात कॉपी करा (Studio चिकटवायची नेमकी सेटिंग्ज दाखवते). टोकन कधीही शेअर करू नका.

:::note
ब्राउझर टॅब सहाय्यकासाठी जोडणी उघडू शकत नाही: ब्राउझर अॅप्समध्ये तुम्ही तुमच्या संगणकावर CadCraft Studio वापरेपर्यंत स्विचचा काहीही परिणाम होत नाही.
:::

## तुम्ही नियंत्रणात राहता

- **प्रत्येक बदल एक पूर्ववत करण्याची पायरी असतो**, सहाय्यकाच्या नावाने लेबल केलेला (उदा. "Assistant: add cloudrect"). {{key:Mod+Z}} सहाय्यकाचा शेवटचा बदल पूर्णपणे मागे घेते.
- **तुम्हाला कळते, जेव्हा एक जोडलेला असतो.** अॅप बारमधील बटण जोडलेल्या सहाय्यकाचे नाव दाखवते; तो काय करू शकतो ते पाहण्यासाठी किंवा त्याला **Disconnect** करण्यासाठी त्यावर क्लिक करा.
- **क्रियाकलाप.** {{ui:Settings}} › {{ui:MarkupCraft}} › {{ui:Assistants}} › {{ui:Activity}} प्रत्येक कॉल यादी करते: केव्हा, कोणते साधन, आणि पूर्ण झाले की नाकारले. {{ui:Save the log}} एक प्रत ठेवते.

## सहाय्यक काय मागू शकतो

| साधन | परवानगी | ते काय करते |
|---|---|---|
| `app_info`, `sheets_list` | Read | उघडलेले संच, त्यांच्या शीट्स आणि प्रत्येकात किती मार्कअप आहेत |
| `markups_list` | Read | प्रकार, शीट, मजकूर, टिप्पणी, मोजमाप, स्थिती, लेखक आणि उत्तरांसह मार्कअप, शीट, स्थिती, प्रकार किंवा लेखकानुसार फिल्टर केलेले |
| `markup_add` | Edit | शीटवर आयत, क्लाउड, लंबवर्तुळ, मजकूर बॉक्स, नोट, रेषा किंवा बाण जोडते |
| `markup_status`, `markup_reply` | Edit | मार्कअपची स्थिती सेट करते (त्याच्या साखळीत नोंद, सहाय्यकाच्या सहीसह); साखळीत टिप्पणी जोडते |
| `markups_export` | Export | {{ui:Markups}} यादीची स्वतःची CSV किंवा BCF, यादी काय दाखवते ते (तुम्ही सेट केलेल्या फिल्टरसह); Studio मध्ये ते तुम्ही परवानगी दिलेल्या फोल्डरमध्ये फाइल लिहू शकते |
| `tasks_list` | Read | कार्ये असलेले मार्कअप: नेमणूक (व्यक्ती किंवा सहाय्यक), देय दिवस, अवस्था, दुवा, आणि ते कसे बंद झाले. `assignee: "assistant"` सहाय्यकासाठी प्रतीक्षेत असलेले काम यादी करते |
| `task_set`, `task_clear` | Edit | मार्कअपला कार्य बनवते किंवा बदलते (शीर्षक, नेमणूक, देय, अवस्था, दुवा); कार्य काढते |
| `tasks_check` | Edit | ज्या कार्यांशी जोडलेले रेखाचित्र क्षेत्र किंवा मॉडेल घटक खरोखर बदलले आहेत ती बंद करते; दुसऱ्या अॅपमधून वाचलेल्या घटक स्थिती पास करते |
| `revisions_changes` | Read | दोन उघडलेल्या प्लॅन संचांमध्ये काय बदलले त्याची साधी यादी, तुमच्या स्वतःच्या शब्दांत मांडण्यासाठी |
| `pins_list`, `decision_add` | Read, Edit | व्हॉइस नोट्स (लांबी, कोण, केव्हा, कॅप्शन; आवाज कधीही नाही, प्रतिलेखन नाही) आणि निर्णय; निर्णय पिन करते आणि आधीचा बदलते |
| `redline_export`, `redline_answer` | Export, Edit | ड्राफ्टरसाठी रेडलाइन फाइल लिहिते; ड्राफ्टरची उत्तरे लागू करते |

सहाय्याने जोडलेले मार्कअप त्याला लेखक म्हणून दाखवते: सहाय्यक प्रोग्राम स्वतःला देतो ते नाव, त्यानंतर "(assistant)", किंवा तुम्ही तुमचे पुनरावलोकनकर्ता नाव सेट केल्यानंतर "(assistant for <your name>)". त्याचे स्थिती बदल आणि उत्तरे त्याच पद्धतीने सही केलेली असतात. प्रत्येक एक पूर्ववत करण्याची पायरी आहे. सुधारलेली PDF जतन करणे तुमच्याकडेच राहते: नेहमीप्रमाणे {{ui:Save}} वापरा.

MarkupCraft उघडल्याशिवाय, CadCraft MCP सर्व्हर तुम्ही नाव दिलेल्या फोल्डरमधील PDF चे मार्कअप यादी करतो (`markups_list`), आणि `cadcraft info Set.pdf` ते कमांड लाइनवर छापते.

## काही काम न केल्यास

- **सहाय्याला MarkupCraft ची साधने दिसत नाहीत:** या विंडोमध्ये स्विच चालू आहे आणि ती विंडो Studio मध्ये उघडी आहे ते तपासा.
- **"needs the edit permission":** {{ui:Assistants}} खाली **Edit** टिक करा, मग पुन्हा विचारा.
- **"401" किंवा "token" त्रुटी:** टोकन बदलले आहे (Studio रीस्टार्ट झाले, किंवा {{ui:New token}}). नवीन टोकन सहाय्याच्या सेटिंग्जमध्ये कॉपी करा.
