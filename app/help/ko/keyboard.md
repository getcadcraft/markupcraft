{{key:Mod}}로 표시된 단축키는 Mac에서 ⌘ 또는 Control을, Windows와 Linux에서는 Ctrl을 사용할 수 있습니다. 도구 문자 키는 상자에 입력 중이 아닐 때만 작동합니다. 입력하는 동안에는 문자가 그냥 글자로 입력됩니다. 함께 보기: [키, 마우스, 트랙패드](common:keys).

## 그리는 동안

| 키 또는 동작 | 기능 |
|---|---|
| 그리는 동안 {{key:Shift}} | 선, 화살표, 길이, 폴리선 변을 45° 단위로 맞춤. 사각형, 타원, 상자 구름을 정사각형으로 맞춤. 펜과 형광펜은 곧은 한 획 |
| 더블클릭, {{key:Enter}} 또는 오른쪽 클릭 | 폴리선, 폴리곤, 자유 구름 또는 영역 완성 |
| {{key:Backspace}} | 폴리선, 폴리곤, 자유 구름 또는 영역의 마지막 점 제거 |
| {{key:Esc}} | 그리던 것을 취소. 진행 중인 것이 없으면 선택 해제. 선택된 것이 없으면 {{ui:Select}}로 돌아감 |
| {{key:Mod+Enter}} | 문자 상자, 콜아웃 또는 비고의 입력 완료(또는 바깥 클릭) |
| 입력 중 {{key:Esc}} | 입력 중이던 문자를 취소 |
| {{ui:Count}} 사용 시 {{key:Shift}}-클릭 | 선택된 수량 그룹에서 가장 가까운 점 하나 제거 |

## 선택과 편집

| 키 또는 동작 | 기능 |
|---|---|
| 클릭 | 마크업 선택 |
| {{key:Shift}}-클릭 | 마크업을 선택에 추가하거나 선택에서 제거 |
| 빈 시트에서 왼쪽에서 오른쪽으로 드래그 | 창 안에 완전히 들어가는 항목 선택 |
| 빈 시트에서 오른쪽에서 왼쪽으로 드래그 | 창에 닿는 항목 선택 |
| {{key:Mod+A}} | 이 시트의 모든 마크업 선택 |
| 선택한 마크업 드래그 | 이동 ({{key:Shift}}: 45° 단위로 이동) |
| 핸들 드래그 | 크기 조정 또는 모양 변경 ({{key:Shift}}: 비율 유지 또는 45°) |
| 화살표 키 | 선택 항목을 화면 1픽셀씩 이동 ({{key:Shift}}: 10픽셀씩) |
| 더블클릭, 또는 {{key:Enter}} | 문자 상자, 콜아웃 또는 비고의 문자를 편집. 스탬프는 {{ui:Properties}}를 엽니다 |
| {{key:Delete}} 또는 {{key:Backspace}} | 선택 항목 삭제 |
| {{key:Esc}} | 아무것도 선택하지 않음 |
| {{key:Mod+Z}} | 실행 취소 |
| {{key:Mod+Y}} 또는 {{key:Mod+Shift+Z}} | 다시 실행 |

## 잘라내기, 복사, 붙여넣기

같은 명령이 도구 모음의 {{ui:Edit}} 그룹({{ui:Copy}}, {{ui:Paste}})과 {{ui:More}} 메뉴에도 있으며, 각 명령에 해당 단축키가 표시됩니다. 모든 명령은 실행 취소 한 단계입니다. [복사, 붙여넣기 및 복제](topic:select-and-edit#copy-paste-and-duplicate)를 참조합니다.

| 키 | 기능 |
|---|---|
| {{key:Mod+X}} | 잘라내기: 선택 항목을 복사한 뒤 삭제 |
| {{key:Mod+C}} | 선택 항목 복사 |
| {{key:Mod+V}} | 붙여넣기. 포인터가 시트 위에 있으면 복사본이 포인터가 가리키는 곳에 가운데 맞춰 놓이고, 그렇지 않으면 원본 옆에 놓입니다. 설정에서 항상 원본 옆에 붙여넣도록 바꿀 수 있습니다. |
| {{key:Mod+Shift+V}} | 제자리에 붙여넣기: 같은 시트 또는 다른 시트의 같은 위치에 붙여넣기 |
| {{key:Mod+D}} | 선택 항목을 옆에 복제 (클립보드는 그대로 둠) |

## 확대/축소와 초점 이동

| 키 또는 동작 | 기능 |
|---|---|
| 마우스 휠 | 포인터를 중심으로 확대 또는 축소 (휠로는 스크롤되지 않음) |
| {{key:Ctrl}} + 휠 | 더 빠르게 확대/축소 |
| {{key:Plus}} 또는 {{key:Minus}} ({{key:Mod}}와 함께도 가능) | 가운데를 중심으로 확대 또는 축소. {{key:=}}도 플러스로 작동 |
| {{key:Mod+0}} | {{ui:Fit page}} |
| {{key:Mod+9}} | {{ui:Fit width}} |
| 가운데 버튼을 누른 채 드래그 | 초점 이동 |
| 오른쪽 버튼을 누른 채 드래그 | 초점 이동 (폴리선을 그리는 중이 아닐 때) |
| {{key:Space}} 키를 누른 채 드래그 | 초점 이동 |
| 선택 항목이 없을 때 화살표 키 | 초점 이동 |
| {{key:Ctrl+Shift+F}} | 화면 모드: 일반, 전체 화면, 막대를 숨긴 전체 화면 (모든 컴퓨터에서 Control 키) |

:::mac
**트랙패드에서:** 두 손가락 스크롤은 확대/축소합니다. 핀치도 Chrome, Edge, Firefox에서 확대/축소합니다. {{key:Space}} 키를 누른 채 드래그하거나 {{ui:Pan}} 도구로 초점을 이동합니다. 두 손가락 클릭은 오른쪽 클릭이며 폴리선을 완성합니다. 여기서는 Control-클릭이 오른쪽 클릭이 아니라 일반 클릭으로 작동할 수 있으므로 두 손가락 클릭을 사용하십시오.
:::

:::touch
## 터치

| 제스처 | 기능 |
|---|---|
| 한 손가락 | 현재 도구로 그리기 또는 선택 |
| 두 손가락 | 가운데를 기준으로 핀치하여 확대/축소, 움직여서 초점 이동 |
| 획 도중 두 번째 손가락 | 획을 취소하고 대신 확대/축소 |
| 두 번 탭 | 폴리선, 폴리곤, 자유 구름 또는 영역 완성 |

개수 점, 비고, 폴리선 점, 두 점 도구의 두 번째 점은 손가락을 뗄 때 배치됩니다. [iPad 또는 터치 화면에서 검토하기](topic:review-on-a-tablet)를 참조합니다.
:::

## 브라우저가 유지하는 단축키

- {{key:Mod+W}}, {{key:Mod+T}}, {{key:Mod+N}}, {{key:Mod+Q}}는 브라우저의 단축키입니다. 저장되지 않은 마크업이 있을 때 탭이나 창을 닫으면, 컴퓨터에서는 브라우저의 '사이트를 떠나시겠습니까?' 질문 후에 마크업이 사라집니다.
- 대부분의 브라우저는 {{key:Mod+N}}을 새 창에 사용합니다. 그러므로 브라우저 탭에서는 도구 모음의 {{ui:New}}를 사용합니다. 데스크톱 앱과 Studio는 이 키를 MarkupCraft에 전달합니다.
- 앱이 키보드를 가지고 있는 동안 MarkupCraft는 {{key:Mod+O}}, {{key:Mod+S}}, {{key:Mod+D}}, {{key:Mod+A}}, {{key:Mod+V}}, {{key:Mod+Shift+V}}, {{key:Mod+0}}, {{key:Mod+Plus}} 및 {{key:Mod+Minus}}를 브라우저 대신 사용합니다. 마크업이 선택되어 있을 때는 {{key:Mod+C}} 및 {{key:Mod+X}}도 사용합니다. {{key:Mod+,}}는 {{ui:Settings}}를 엽니다. 브라우저 전체 페이지를 확대/축소하려면 브라우저 메뉴를 사용하십시오.
- 일부 브라우저에서는 MarkupCraft가 {{key:Mod+9}}를 받기 전에 마지막 브라우저 탭으로 이동합니다. 그런 경우에는 시트 아래의 {{ui:Fit width}}를 사용하십시오.
- 전체 화면에서 {{key:Esc}} 키를 누르면 전체 화면도 종료됩니다.

## 키가 작동하지 않을 때

- **상자에 입력 중입니다.** 먼저 시트를 클릭하십시오. (그리기 도구로 클릭하면 그려집니다. 그 뒤에 {{key:Esc}} 키를 누르거나 {{key:Mod+Z}} 키로 실행 취소하십시오.)
- **대화상자가 열려 있습니다.** 대화상자가 닫힐 때까지 키 입력은 대화상자로 전달됩니다.
- **도구 모음 버튼을 방금 클릭했습니다.** 이 경우 화살표 키나 {{key:Space}} 키는 그 버튼에 작용합니다. 포인터를 시트 위로 옮겨 휠이나 가운데 버튼을 사용하거나, 버튼을 클릭하는 대신 도구 문자 키를 누르십시오.

## 이동 명령의 위치

이동 명령은 따로 없습니다. 마크업을 선택하고 드래그하십시오 ({{key:Shift}} 키를 누르면 45° 단위가 유지됩니다). 핀은 {{ui:Move pin}} 명령으로, 페이지는 {{ui:Move page earlier}} 또는 {{ui:Move page later}} 명령으로 이동합니다.
