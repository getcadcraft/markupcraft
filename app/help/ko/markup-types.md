## 도구

| 도구 모음 | 키 | 그리는 방법 | 기본 모양 | 저장된 PDF에서 |
|---|---|---|---|---|
| {{ui:Pen}} | {{key:P}} | 드래그 | 빨간색, 1.5pt | 잉크 |
| {{ui:Highlight}} | {{key:I}} | 드래그 | 노란색, 너비 14pt, 투명, 아래 내용에 색을 입힘 | 잉크 (형광펜 획으로 표시) |
| {{ui:Line}} | {{key:L}} | 드래그, 또는 시작점과 끝점 클릭 | 빨간색, 2pt | 선 |
| {{ui:Arrow}} | {{key:A}} | 드래그, 또는 시작점과 끝점 클릭 | 빨간색, 2pt, 끝에 닫힌 화살촉 | 화살촉이 있는 선 |
| {{ui:Arc}} | {{key:O}} | 시작점, 호 위의 점, 끝점 순서로 클릭 | 빨간색, 2pt | 호를 따라가는 폴리선 |
| {{ui:Rectangle}} | {{key:R}} | 상자 드래그 | 빨간색, 2pt, 채우기 없음 | 사각형 |
| {{ui:Ellipse}} | {{key:E}} | 상자 드래그 | 빨간색, 2pt, 채우기 없음 | 원 |
| {{ui:Polyline}} | {{key:Y}} | 점을 클릭하고, 더블클릭으로 완료 | 빨간색, 2pt | 폴리선 |
| {{ui:Polygon}} | {{key:G}} | 점을 클릭하고, 더블클릭으로 완료 | 빨간색, 2pt, 채우기 없음 | 폴리곤 |
| {{ui:Cloud}} | {{key:C}} | 상자 드래그 | 빨간색, 물결 호 1.5pt | 구름 테두리가 있는 사각형 |
| {{ui:Free cloud}} | {{key:Shift+C}} | 점을 클릭하고, 더블클릭으로 완료 | 빨간색, 물결 호 1.5pt | 구름 테두리가 있는 폴리곤 |
| {{ui:Callout}} | {{key:K}} | 지점을 누르고, 문자 위치까지 드래그한 뒤 입력 | 빨간색 문자와 지시선, 1pt, 문자 12pt | 콜아웃 지시선이 있는 문자 상자 |
| {{ui:Text}} | {{key:T}} | 클릭 또는 상자 드래그 후 입력 | 빨간색 12pt 문자, 테두리 없음 | 문자 상자 |
| {{ui:Note}} | {{key:N}} | 클릭 후 입력 | 노란색 비고 아이콘 | 스티커 메모 |
| {{ui:Stamp}} | {{key:S}} | 스탬프를 고르고 클릭 또는 드래그 | 테두리가 있는 대문자와 "<name>, <date> 작성"; 의미에 따라 색 지정 | 스탬프 |
| {{ui:Length}} | {{key:M}} | 시작점과 끝점 클릭 (축척 필요) | 눈금과 길이가 있는 파란색 치수선 | 치수로 표시된 선, 측정값 포함 |
| {{ui:Angle}} | {{key:X}} | 한쪽 끝, 모서리, 다른 쪽 끝 순서로 클릭 | 파란색 변, 모서리의 작은 호, 각도(도) | 각도를 문자로 가진 폴리선 |
| {{ui:Area}} | {{key:Q}} | 모서리를 클릭하고, 더블클릭으로 완료 (축척 필요) | 파란색 윤곽선, 연한 파란색 채우기, 면적과 둘레 | 면적으로 표시된 폴리곤, 측정값 포함 |
| {{ui:Count}} | {{key:U}} | 각 항목 클릭 | 주황색 번호 점과 "그룹: n" 태그 | 그룹마다 잉크 의견 하나, 항목마다 원 하나 |

터치에서는 "더블클릭으로 완료"가 두 번 탭이며, "클릭"은 손을 뗄 때 동작하는 탭입니다(점, 비고, 수량에 해당).

## 모든 마크업이 가지는 정보

| 항목 | 확인 위치 |
|---|---|
| 작성자 | {{ui:Properties}}, 목록, 스탬프의 둘째 줄, 다른 PDF 뷰어 |
| 만든 날짜와 수정한 날짜 | {{ui:Properties}}(사용자의 시간대), 목록, CSV |
| 상태 | 열림, 수락됨, 거부됨 또는 완료됨 |
| 제목 | 짧은 이름이며 기본값은 종류 ("구름", "문자 상자", "길이 측정") |
| 의견 | 더 긴 메모입니다. 비고의 경우 그 문자 내용이 의견입니다. |
| 문자 | 문자 상자와 콜아웃에만 있음 |
| 답글 | 스레드(상태 변경 포함) |
| 펀치 항목 | 번호, 담당자, 기한, 항목 상태, 펀치 리스트에 추가할 때 |
| 스타일 | 색, 선 너비, 채우기 및 채우기 불투명도(닫힌 도형, 문자, 콜아웃), 불투명도, 문자 크기(문자, 콜아웃, 측정) |

## 읽기 전용 의견

파일에 함께 들어 있었고 MarkupCraft가 편집할 수 없는 의견(문자 강조, 다른 프로그램의 스탬프, 기타 특수 종류)은 종류 "기타"와 상태 표시 "읽기 전용"으로 목록에 표시됩니다. 파일이 준 모양을 그대로 유지합니다. 선택하여 작성자, 제목, 의견을 확인할 수 있으며 답글도 달 수 있습니다.

## 아직 만들지 않은 기능

파일 첨부는 아직 만들지 않았습니다. 모든 마크업은 시트에 링크할 수 있습니다. [시트 링크](topic:sheet-links)를 참조합니다. 그림과 서명은 {{ui:Stamp}} 도구로 배치합니다. [스탬프와 비고](topic:stamps-and-notes)를 참조합니다. [아직 만들지 않은 기능](topic:not-built-yet)을 참조합니다.
