MarkupCraft는 개발 중입니다. 아래는 현재 빌드가 **하지 않는** 기능이므로, 계획을 세울 때 참고하십시오. 이 내용은 현재 빌드를 기준으로 하며, 약속이 아닙니다.

## 다른 사람과 함께 작업하기

| 아직 만들지 않은 기능 | 지금 할 수 있는 방법 |
|---|---|
| 컴퓨터 간 클라우드 저장 및 동기화 | PDF를 프로젝트 파일과 함께 보관하십시오. 클라우드 저장은 아직 사용할 수 없습니다. |
| 두 사람이 가진 마크업 사본 병합 | 검토자마다 시트를 나누어 맡거나, {{key:Mod+C}}와 {{key:Mod+V}}로 마크업 몇 개를 복사하십시오. RFI, 제출물, 일일 기록은 병합됩니다: [RFI, 제출물, 일일 기록 추적](topic:field-records)을 참고하십시오. |
| RFI 및 제출물용 팀, 알림, 클라우드 프로젝트 | PDF를 전달하고 {{ui:병합}}을 사용하여 사본을 모으십시오. |
| 실시간 세션의 RFI, 제출물, 일일 기록 | 각자 자신의 사본으로 작업하고, {{ui:병합}}으로 사본을 모으십시오. |
| 한 기록의 서로 다른 항목을 두 사람이 바꾼 내용 병합 | 마지막으로 바뀐 사본이 그 기록 전체를 차지합니다(스레드와 첨부 파일 이름은 합쳐집니다). 누가 어떤 기록을 편집할지 미리 정하십시오. |
| RFI, 제출물, 일일 기록용 어시스턴트 도구 | {{ui:현장}} 탭에서 작업하십시오. 어시스턴트는 마크업을 다룰 수 있습니다: [AI 어시스턴트와 MarkupCraft 사용](topic:use-with-ai-assistants)을 참고하십시오. |
| 보낸 답글 편집 또는 삭제 | 바로 {{ui:실행 취소}}하거나, 정정 답글을 추가하십시오. |
| 마크업의 작성자 변경 | 시작하기 전에 이름을 설정하십시오. |

## 마크업

| 아직 만들지 않은 기능 | 지금 할 수 있는 방법 |
|---|---|
| 입력 칸이 있는 스탬프, 공인 전자 서명 | 이름과 날짜가 포함된 사용자 지정 문자 스탬프나 서명 그림을 사용하십시오. |
| 사진 이외의 파일 첨부(문서, 동영상) | PDF와 함께 보관하고, 댓글에서 참조하십시오. |
| 웹사이트 또는 열려 있지 않은 파일로의 링크 | 댓글에 주소 또는 파일 이름을 적으십시오. |
| 사용자 지정 상태 집합 | 네 가지 상태를 사용하고, 그 밖의 내용은 주제에 적으십시오. |
| 파일에 포함되어 읽기 전용으로 온 댓글 편집(텍스트 강조, 다른 프로그램의 스탬프) | 해당 댓글에 답글을 달거나, 옆에 MarkupCraft 마크업을 그리십시오. |
| 필압에 따라 달라지는 펜 획 | 선 너비를 설정하십시오. |

## 페이지 자체의 내용

| 아직 만들지 않은 기능 | 지금 할 수 있는 방법 |
|---|---|
| 페이지에 새 도형 직접 그리기 | 마크업으로 그린 뒤 {{ui:페이지에 넣기}}를 사용하십시오. [페이지 자체 내용 바꾸기](topic:page-content)를 참고하십시오. |
| 페이지 객체를 임의의 각도로 회전 | 이동하고 크기를 조정하십시오. 페이지 전체는 {{ui:페이지}}에서 회전하십시오. |
| 텍스트 한 줄의 글꼴이나 크기, 또는 여러 줄에 걸친 텍스트 변경 | 한 줄씩 단어를 바꾸고, 다른 글꼴의 새 문구는 문자 마크업을 추가하십시오. |
| 스캔한 그림 안의 내용 편집 | 그림을 바꾸거나 마크업하십시오. |
| 암호화되었거나 서명된 PDF 편집 | 서명되지 않은 사본을 요청하십시오. 마크업은 모든 PDF에서 작동합니다. |

## 측정

| 아직 만들지 않은 기능 | 지금 할 수 있는 방법 |
|---|---|
| 반지름 측정 | 그 위에 {{ui:호}}를 그리거나, 가로지르는 {{ui:길이}}를 측정하여 절반으로 나누십시오. |
| 개구부 모서리 편집 | 개구부를 삭제하고 다시 그리십시오. |
| 여러 시트에 한 번에 같은 축척 적용 | 시트마다 보정하십시오. 사전 설정을 고르는 데 시트당 몇 초가 걸립니다. |
| 한 시트의 여러 축척(뷰포트) | 가장 많이 측정하는 도면에 맞춰 보정하십시오. 시트 축척을 바꾸면 그 시트의 모든 측정값이 다시 계산되므로, 다시 보정하기 전에 세부 치수값을 적어 두십시오. |
| 도면의 선에 스냅 | 클릭하기 전에 확대하거나, 길이와 각도를 입력하십시오([축척에 맞춰 스케치](topic:calibrate-and-measure#sketch-to-scale) 참고). |
| 항목, 복합 단가, 가격을 포함한 전체 물량 산출 | CadCraft 제품군의 물량 산출 앱인 TakeoffCraft를 사용하십시오. |

## 시트와 파일

| 아직 만들지 않은 기능 | 지금 할 수 있는 방법 |
|---|---|
| 페이지 변경 실행 취소(회전, 이동, 삽입, 삭제) | 저장하지 않고 닫은 뒤 원본 PDF를 다시 여십시오. [인쇄 및 페이지 변경](topic:pages-and-printing)을 참고하십시오. |
| 세트의 파일 하나만 닫기 | {{ui:닫기}}는 세트 전체를 닫습니다. 필요한 파일을 다시 여십시오. |
| 세트를 한 번에 다시 열 수 있는 프로젝트로 저장 | 같은 PDF를 다시 여십시오. |
| 선택한 축척으로 인쇄하거나 한 용지에 여러 시트 인쇄 | 브라우저의 인쇄 대화상자를 사용하거나, 저장한 사본을 다른 PDF 뷰어에서 인쇄하십시오. |

## 목록과 내보내기

| 아직 만들지 않은 기능 | 지금 할 수 있는 방법 |
|---|---|
| 가져온 BCF 이슈를 모델 위치에 배치 | 시트에 연결되지 않은 가져온 이슈는 왼쪽 위에 쌓입니다. 직접 옮기십시오. |
| 다른 마크업 프로그램의 도구 세트 가져오기 | 필요한 도구를 다시 만들어 도구 상자에 저장하고, 사무실용으로 내보내십시오. |
