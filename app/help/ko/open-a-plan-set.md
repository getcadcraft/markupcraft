## 세트 열기

1. 도구 모음에서 {{ui:열기}}를 선택하거나 {{key:Mod+O}}를 누르십시오.
2. 파일 선택 창에서 세트의 PDF를 모두 선택하고({{pick:mac=⌘ 키를 누른 채 각 파일을 클릭|windows linux=Ctrl 키를 누른 채 각 파일을 클릭}}, 또는 Shift로 범위를 선택하십시오), 그다음 확인하십시오.
   또는 {{pick:mac=Finder|windows=파일 탐색기|linux=파일 관리자}}에서 파일을 시트 영역으로 끌어다 놓으십시오. 끄는 동안 "PDF를 놓아 열기"가 나타납니다.
3. 상태 표시줄에 "<file> 여는 중…"이 표시되는 동안 기다리십시오. 큰 파일은 진행 수를 셉니다: "(시트 60장 중 10장)".

결과: {{ui:시트}} 목록에 열어 둔 순서대로 모든 파일의 모든 페이지가 표시되고, 상태 표시줄에는 "파일 3개를 열었습니다 (세트에 시트 42장)."와 같은 메시지가 나타납니다. 파일에 댓글이 이미 있었다면 읽은 개수도 함께 표시됩니다.

나중에 세트에 파일을 추가하려면 같은 방법으로 여십시오. 추가된 파일은 목록 끝에 붙습니다.

## 빈 페이지로 시작

도면 없이 스케치하거나 메모하려면 PDF를 여는 대신 빈 페이지를 만드십시오:

1. 도구 모음에서 {{ui:새로 만들기}}를 선택하거나, 시작 화면에서 {{ui:빈 페이지로 시작}}을 선택하거나, 브라우저가 허용하는 경우 {{key:Mod+N}}을 누르십시오(데스크톱 앱과 Studio에서는 항상 가능합니다).
2. {{ui:용지 크기}}를 고르십시오: Letter, Tabloid 또는 ANSI B, ARCH D, ARCH E, A4, A3 또는 A1, 그리고 {{ui:세로}} 또는 {{ui:가로}}.
3. {{ui:그리드}}를 고르십시오: {{ui:없음}}, {{ui:점}} 또는 {{ui:격자}}. 그리드는 인치 용지에서 1/4 in 간격이며 1 in마다 더 굵은 선이 있고, 미터법 용지에서는 5 mm 간격이며 10 mm마다 더 굵은 선이 있습니다. 그리드는 페이지에 인쇄됩니다.
4. 원하는 {{ui:페이지}} 수를 1에서 20 사이로 입력한 다음 {{ui:만들기}}를 선택하십시오.

결과: "Untitled-1.pdf"(다음은 "Untitled-2.pdf" 등)라는 새 PDF가 이 컴퓨터에서 만들어져, 다른 파일과 같은 방식으로 열립니다. 모든 도구를 사용할 수 있고, {{ui:저장}}하면 "Untitled-1 (marked up).pdf"가 다운로드됩니다. MarkupCraft는 다음번을 위해 선택을 기억합니다.

페이지에는 축척이 없으며, 상태 표시줄에 "보정되지 않음"이라고 표시됩니다. 그리드는 축척이 아닙니다. 측정하려면 먼저 시트를 보정하거나 축척을 고르십시오. [보정과 측정](topic:calibrate-and-measure)을 참고하십시오.

빈 세트에 페이지를 추가하려면 세트의 시트 하나를 열고 {{ui:시트}} 목록 아래의 {{ui:빈 페이지 추가}}를 선택하십시오. 새 페이지는 같은 용지와 그리드를 가지며 맨 끝에 들어갑니다. 모든 페이지 변경과 마찬가지로 실행 취소할 수 없습니다. [인쇄 및 페이지 변경](topic:pages-and-printing)을 참고하십시오.

## 시트 이름이 정해지는 방식

MarkupCraft는 각 시트를 "<시트 번호> — <제목>"으로 이름 짓습니다. 예를 들어 "A-101 — 평면도"입니다. 아래 중 처음 찾은 항목을 사용합니다:

1. {{ui:시트 이름 바꾸기}}로 입력한 이름(아래 참고).
2. PDF 자체의 페이지 레이블. PDF를 만든 사람이 설정한 경우입니다(예: "A-101").
3. 표제란: MarkupCraft는 페이지의 텍스트를 읽고 시트 번호처럼 생긴 것(A-101, A1.01, M-201A, KA1-1)을 찾습니다. 오른쪽 아래 모서리, 오른쪽 띠, 아래쪽 띠를 우선하며, 그 근처에서 가장 큰 글자를 제목으로 사용합니다.
4. 그 밖의 경우에는 파일 이름과 페이지: "도면 — 페이지 3".

어떤 항목이 쓰였는지 보려면 {{key:Esc}}를 눌러 아무것도 선택되지 않고 {{ui:선택}} 도구가 켜진 상태로 만든 다음 {{ui:속성}}을 보십시오. "읽은 위치"에는 "페이지 레이블", "표제란", "파일 이름" 또는 "직접 입력"이 표시됩니다.

:::note
스캔한 시트와 글자가 선으로 내보내진 PDF에는 읽을 텍스트가 없습니다. 이름을 바꾸기 전까지는 파일과 페이지로 이름이 붙습니다. MarkupCraft는 아직 이미지의 텍스트를 읽을 수 없습니다.
:::

## 시트 사이 이동

- {{ui:시트}}에서 시트를 클릭하십시오.
- 다음 시트는 {{key:PageDown}}, 이전 시트는 {{key:PageUp}}을 누르거나, 시트 아래 표시줄의 화살표를 사용하십시오.
- {{ui:시트 검색}}에 입력하십시오: 번호의 일부("A-2"), 제목의 단어("지붕") 또는 파일 이름. 입력하는 동안 목록이 좁혀집니다("시트 42장 중 4"). {{key:Enter}}를 누르면 첫 번째 일치 항목이 열립니다. 상자를 비우면 모든 시트가 다시 표시됩니다.

각 시트는 세트를 닫을 때까지 자신의 확대/축소와 위치를 유지합니다.

## 확대/축소와 초점 이동

:::mouse
- **확대/축소:** 시트 위에서 휠을 돌리십시오. 포인터를 중심으로 확대/축소됩니다. 또는 {{key:Plus}}와 {{key:Minus}}를 누르거나({{key:Mod}}와 함께도 가능), 확대/축소 버튼을 사용하십시오. 확대/축소 상자에 정확한 백분율을 입력할 수도 있습니다.
- **맞춤:** {{ui:페이지 맞춤}}({{key:Mod+0}})은 시트 전체를 보여 주고, {{ui:너비 맞춤}}({{key:Mod+9}})은 너비를 채웁니다.
- **초점 이동:** 가운데 버튼(휠)으로 드래그하거나, 오른쪽 버튼으로 드래그하거나, {{key:Space}}를 누른 채 드래그하거나, {{ui:초점 이동}}({{key:H}})을 선택한 다음 드래그하십시오. 아무것도 선택되지 않았을 때는 화살표 키로도 시트를 움직일 수 있습니다.
:::

:::mac mouse
Mac 트랙패드에서는 두 손가락 스크롤이 확대/축소됩니다(시트를 스크롤하지 않습니다). 초점을 이동하려면 {{key:Space}}를 누른 채 한 손가락으로 드래그하거나, {{key:H}}를 눌러 {{ui:초점 이동}}으로 전환하십시오. 핀치는 Chrome, Edge, Firefox에서 확대됩니다.
:::

:::touch
- **확대/축소와 초점 이동:** 시트에 두 손가락을 올리십시오. 벌리거나 모으면 두 손가락 사이를 중심으로 확대/축소되고, 함께 움직이면 초점이 이동합니다. 두 동작은 동시에 일어납니다.
- **한 손가락으로 초점 이동:** 먼저 {{ui:초점 이동}}을 선택하십시오. 다른 도구를 쓸 때는 한 손가락으로 그리거나 선택합니다.
- {{ui:페이지 맞춤}}과 {{ui:너비 맞춤}}은 시트 아래 표시줄에 있습니다.
:::

시트 전체보다 훨씬 멀리 축소할 수 있으며, 6400%까지 확대할 수 있습니다. 움직임을 멈춘 뒤 잠시 후 시트가 선명하게 다시 그려집니다.

## 책갈피

{{ui:시트}} 패널 맨 위의 {{ui:책갈피}}에는 열린 시트가 속한 PDF의 책갈피(개요)가 표시됩니다. 하나를 선택하면 해당 페이지로 이동합니다. 연필 아이콘은 책갈피 이름을 바꾸고, × 아이콘은 책갈피를 삭제합니다. {{ui:시트로 만들기}}는 시트마다 책갈피 하나를 만들며, 시트 목록에 표시된 대로(시트 번호와 제목) 이름이 붙습니다. {{ui:이 시트에 추가}}는 현재 시트용 책갈피 하나를 추가합니다. 변경 사항은 파일의 저장되지 않은 작업에 포함되며, {{ui:저장}}하면 사본에 기록되어 모든 PDF 뷰어에 표시됩니다.

## 보기 회전

시트 아래 표시줄 오른쪽의 두 회전 버튼은 옆으로 그려진 시트를 보기 위해 보기를 양방향으로 90도씩 돌립니다. 보기만 회전하며, PDF와 마크업은 그대로 유지되고, 다음 시트는 해당 PDF의 방식대로 열립니다(세트가 열려 있는 동안 각 시트는 자신의 회전을 기억합니다). 회전된 보기에서 추가한 텍스트는 보이는 대로 바르게 읽힙니다. 저장한 PDF에서 페이지 자체를 회전하려면 {{ui:페이지}}, 그다음 {{ui:페이지를 시계 방향으로 회전}}을 사용하십시오. [인쇄 및 페이지 변경](topic:pages-and-printing)을 참고하십시오.

## 시트 이름 바꾸기

시트 이름이 잘못되었거나 없을 때:

1. 시트를 표시하십시오.
2. {{key:Esc}}를 눌러 아무것도 선택되지 않고 {{ui:선택}} 도구가 켜진 상태로 만드십시오. 이제 {{ui:속성}}에 시트가 표시됩니다.
3. {{ui:시트 이름 바꾸기}}를 선택하십시오.
4. {{ui:시트 번호}}와 {{ui:제목}}을 입력한 다음 {{ui:저장}}을 선택하십시오.

결과: 시트 목록, 시트 아래 표시줄, 마크업 목록이 모두 새 이름을 사용하고, "읽은 위치"에는 "직접 입력"이 표시됩니다. 이름 바꾸기는 {{key:Mod+Z}}로 실행 취소할 수 있습니다.

파일에 적힌 이름으로 되돌리려면 {{ui:시트 이름 바꾸기}}를 다시 열고, 두 상자를 모두 비운 다음 {{ui:저장}}을 선택하십시오.

저장할 때 직접 입력한 시트 번호는 PDF의 페이지 레이블이 되므로, 다른 PDF 뷰어도 페이지 상자에 "A-101"을 표시합니다. 파일의 어느 페이지에든 번호를 붙이면, 그 파일의 모든 페이지가 사본에서 레이블을 받습니다(직접 입력한 번호, 없으면 기존 레이블, 그것도 없으면 페이지 번호). 직접 입력한 제목은 MarkupCraft에 보관되지만 다른 뷰어에는 표시되지 않습니다.

## TakeoffCraft로 PDF 보내기 또는 이곳으로 가져오기

TakeoffCraft가 같은 곳(lab, Try 또는 온라인 앱)에서 열려 있으면 시트 아래 표시줄에 {{ui:TakeoffCraft에서 열기}}가 있습니다. 이곳에서 열었던 방식 그대로 시트의 PDF를 새 탭의 TakeoffCraft에서 열어, 그 위에서 수량을 측정할 수 있습니다. 마크업은 여기에 남으므로, 평소처럼 저장하십시오.

TakeoffCraft의 {{ui:MarkupCraft}} 버튼은 반대 방향으로 같은 일을 합니다. 마치 {{ui:열기}}를 선택한 것처럼 PDF가 이곳에서 열립니다. 브라우저가 새 탭을 차단하면 이 사이트의 팝업을 허용한 다음 버튼을 다시 선택하십시오.
