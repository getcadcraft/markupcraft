이번 문서는 MarkupCraft 0.8.1과 비교한 0.9의 변경 사항입니다. 핵심은 작업 메모가 고객이 받는 페이지에 나타나지 않게 하고, 도면 세트 전체를 한 번에 연결할 수 있게 한 것입니다.

## 새 기능

### 메모, 붙여넣기 보드, 비공개 메모

- **붙여넣기 보드.** 각 시트 주변 영역은 작업대입니다. 시트 옆에 그리거나 입력하거나 붙여넣은 모든 것은 메모이며 인쇄되지 않습니다. 더 넓게 보려면 {{ui:붙여넣기 보드 표시}}를 선택해 축소하고, 도면 일부를 시트 옆에 두려면 {{ui:붙여넣기 보드에 스냅샷}}을 선택해 상자를 드래그한 다음 {{ui:붙여넣기 보드로}}를 선택합니다. 스냅샷은 그림이므로 시트가 바뀌어도 함께 바뀌지 않습니다. 자세한 내용은 [메모, 붙여넣기 보드, 비공개 메모](topic:notes-and-pasteboard)를 참고하십시오.
- **메모 표시와 숨기기.** 모든 마크업은 메모로 만들 수 있습니다. {{ui:메모}} 탭에서 {{ui:새 마크업 유형}}을 설정하거나 {{ui:속성}}에서 {{ui:이 마크업 유형}}을 설정합니다. {{key:Shift+H}} 또는 시트 아래의 {{ui:메모}} 스위치로 모든 메모를 한 번에 숨기거나 표시합니다. 메모는 인쇄, 평면화된 복사본, 목록, 내보내기에서 제외되며 다른 PDF 리더에서는 보이지 않습니다. 저장한 PDF에는 메모가 남아 있어 다음에 MarkupCraft에서 다시 열 때 볼 수 있습니다.
- **비공개 메모.** {{ui:암호 설정}}을 선택한 다음 마크업을 {{ui:비공개 메모}}로 만듭니다. 메모는 10자 이상의 암호로 파일 안에서 암호화되며, 복구 방법은 없습니다. 저희를 포함하여 누구도 암호 없이는 열 수 없습니다. {{ui:잠그기}}를 선택하면 비공개 메모가 숨겨지며, {{ui:이 기기에서 잠금 해제 상태 유지}}는 기본적으로 꺼져 있습니다.
- **주석 없는 복사본 저장.** {{ui:주석 없는 복사본 저장}}은 모든 메모, 비공개 메모, 붙여넣기 보드의 모든 내용을 제거합니다. 고객에게 보내는 파일에 사용하십시오.

### 세트 전체 연결

- **일괄 링크.** {{ui:페이지}} › {{ui:일괄 링크…}}를 선택하거나, {{ui:시트}} 패널의 {{ui:텍스트 찾기}} 아래에서 {{ui:시트 콜아웃 연결…}}을 선택합니다. 1단계에서는 각 시트의 번호와 이름을 제목 블록에서 읽어 나열하며, 잘못된 것은 고칩니다. 2단계에서는 `3/A-501`이나 `DETAIL 2 ON A-501`처럼 찾은 콜아웃을 나열합니다. 연결 예정은 각 콜아웃의 시트와 뷰를 보여 주고, {{ui:연결 안 됨}}은 열려 있는 시트에 없는 번호를 보여 주며, {{ui:링크 만들기}}를 선택하면 모두 한 번의 실행 취소로 만들어집니다. 추가 도면이나 번호 변경 후에는 다시 실행합니다. 직접 만든 링크는 변경되지 않습니다. 뷰가 있는 링크는 PDF 링크로 저장되므로 다른 리더에서도 상세도가 열립니다. 자세한 내용은 [시트 링크](topic:sheet-links)를 참고하십시오.

### 그리기

- **호, 열 가지 방법.** {{ui:호}} 도구({{key:O}})에는 이제 페이지 위에 {{ui:호 방법}} 상자가 있어 열 가지 방법으로 호를 그릴 수 있으며, 각도, 길이, 반지름, 방향을 클릭하거나 입력할 수 있습니다. 자세한 내용은 [열 가지 방법으로 호 그리기](topic:draw-an-arc)를 참고하십시오.

### 함께 작업하기

- **검토자 따라가기.** Live (공동 편집) 세션에서 사람 이름 옆의 {{ui:따라가기}}를 선택하면 내 보기가 상대의 보기와 함께 움직입니다. 직접 이동하거나 확대/축소하면 따라가기가 멈춥니다. 호스트는 {{ui:모두에게 나를 따라오도록 요청}}을 선택할 수 있습니다. 참여자 목록에는 각 사람의 색, 이름, 현재 시트, 마지막 편집 시각이 표시됩니다. 자세한 내용은 [Live (공동 편집) 세션에서 다른 검토자 따라가기](topic:follow-in-live)를 참고하십시오.

## 모든 앱에서

- 툴팁은 Bootstrap 툴팁이며, 시작 팁은 닫을 수 있고, 탭 줄은 넘칠 때 스크롤됩니다. 브라우저 탭 제목은 `<document> — MarkupCraft | CadCraft` 형식으로 표시합니다.
- 여러 섹션이 있는 패널은 하나를 열면 나머지를 닫습니다(캐럿 옆의 잠금으로 하나를 열어 둘 수 있습니다). 설정 스위치로 이를 끌 수 있습니다.
- 각 앱은 기본 라이브러리 객체 모음으로 시작합니다.
- 무게와 온도 단위는 단위 설정에서 사용할 수 있습니다.

## 수정됨

- **삭제된 마크업이 저장된 PDF 안에서 계속 읽히지 않습니다.** 이전에는 저장할 때 삭제되거나 다시 쓰인 주석을 페이지에서 떼어 내더라도, 텍스트가 있는 객체가 파일에 남았습니다. 이제 저장할 때 이러한 객체도 삭제합니다. 이전 빌드로 저장된 파일은 다시 저장할 때까지 이를 계속 포함합니다.

## 알려진 한계

- 일괄 링크는 자체 테스트 세트에서 시험했습니다. 실제 세트는 원 표시를 여러 방식으로 그리므로, 고객 세트에서는 일부 뷰가 누락될 수 있습니다. 스캔한 시트는 먼저 {{ui:문자 읽기(OCR)…}}를 실행해야 합니다.
- 메모, 비공개 메모, 붙여넣기 보드는 헤드리스 브라우저와 자체 파일에서 시험했으며, 대용량 실제 벡터 세트나 실제 2인 Live 세션에서는 시험하지 않았습니다. 암호 변경 기능은 아직 만들지 않았습니다. 0.9 이전 빌드는 메모를 표시하지 않습니다.
- 수업 보기는 참여자 목록입니다. 실제 교사와 학생과는 시험하지 않았습니다.
- 영어 이외의 언어는 원어민이 검토하기 전까지 기계 번역 초안입니다.
- Windows 설치 프로그램에는 코드 서명이 없습니다 ({{ui:추가 정보}}, 그다음 {{ui:그래도 실행}}). macOS 디스크 이미지는 공증을 받지 않았습니다 (마우스 오른쪽 버튼 클릭 후 {{ui:열기}}).

## 이전: 0.8 및 0.8.1

이번 문서는 MarkupCraft 0.7과 비교한 0.8 및 0.8.1의 변경 사항입니다. 가장 큰 새 기능은 마크업을 사람이나 연결된 어시스턴트가 수행하는 작업으로 만들 수 있고, 도면이 실제로 바뀌면 그 작업이 스스로 닫힌다는 점입니다.

### 새 기능

**동작하는 마크업**

- **마크업을 작업으로 만들기.** 마크업을 하나 이상 선택하고 {{ui:작업}} 탭을 연 다음 {{ui:선택 항목을 작업으로 만들기}}를 선택합니다. 작업에는 제목, 작업을 수행할 사람 또는 연결된 어시스턴트, 선택 사항인 기한, 상태가 있으며, 시트 위의 위치와 스레드도 유지합니다. 자세한 내용은 [마크업을 작업으로 만들기](topic:markups-that-act)를 참고하십시오.
- **스스로 닫히는 작업.** 작업은 마크업 안의 도면을 감시할 수 있습니다. 시트의 새 개정판을 열고 {{ui:지금 확인}}을 선택하면, 그 영역의 선이 조금이라도 바뀌었을 때 작업은 완료로 표시되고, 마크업은 완료됨 상태가 되며, 스레드에 무엇이 바뀌었는지 설명하는 메모가 추가됩니다. 새 날짜 도장이나 1.5포인트 미만으로 움직인 선은 변경으로 계산되지 않습니다. 대신 작업이 모델 요소를 감시하도록 할 수도 있습니다. 어시스턴트가 `tasks_check`로 요소를 보고하며, 이후 보고가 다르거나 요소가 삭제되면 작업이 닫힙니다. 실행 취소 한 번이면 다시 열립니다.
- **찾기.** 상태와 담당자로 {{ui:작업}} 목록을 필터링합니다({{ui:기한 초과}} 포함). {{ui:담당자}}를 선택한 다음 {{ui:어시스턴트}}를 선택하면 어시스턴트가 기다리는 작업을 볼 수 있습니다. 기한이 지난 작업은 {{ui:문제}} 패널에 경고로 표시됩니다. {{ui:CSV}}는 목록을 내보냅니다. 작업은 마크업과 함께 PDF에 저장되며, 다른 마크업 속성처럼 Live (공동 편집)를 통해 전달됩니다.

**무엇이 바뀌었는지 목록으로**

- **변경 사항 목록 만들기.** {{ui:비교}} 탭을 열고 {{ui:세트 전체 비교}}를 선택한 다음, 이전 파일과 이후 파일을 고르고 {{ui:변경 사항 목록 만들기}}를 선택합니다. 목록은 개수로 시작해 바뀐 시트를 가장 큰 변경부터 하나씩 다룹니다. 시트에서의 위치, 크기(보정된 시트에서는 실제 단위와 종이 인치 모두), 선이 추가되었는지 삭제되었는지, 그 위치에 있는 마크업 수, 나타나거나 사라진 단어를 보여 줍니다. {{ui:목록 복사}}는 목록을 클립보드에 넣고, {{ui:CSV}}는 변경 한 건마다 한 행을 씁니다. 자세한 내용은 [개정 사이의 변경 내용을 말로 확인하기](topic:what-changed-in-words)를 참고하십시오.

**음성 메모와 결정**

- **음성 메모.** {{ui:메모}} 탭에서 {{ui:음성 메모 녹음}}을 선택한 다음 {{ui:녹음 중지}}를 선택합니다. 녹음은 2분이 지나면 자동으로 멈춥니다. 메모는 시트 가운데에 고정되며, 원하는 위치로 드래그하고 {{ui:속성}}에서 캡션을 입력할 수 있습니다. 목록에서 {{ui:재생}}을 선택하면 재생됩니다. 녹음은 PDF 안에 저장됩니다.
- **결정.** {{ui:결정 고정}}은 시트에 한두 문장을 씁니다. 이전 결정을 대체하는 경우 {{ui:대체 대상}}에서 그 결정을 고릅니다. 기존 결정은 대체됨으로 표시되고 새 결정을 가리킵니다. 실행 취소 한 번으로 되돌릴 수 있습니다. 자세한 내용은 [시트에 음성 메모와 결정 고정하기](topic:voice-notes-and-decisions)를 참고하십시오.

**개정 레드라인**

- **보내고 답변받기.** {{ui:작업}} 탭에서 {{ui:개정판 레드라인}}을 열고, 마크업이 기준으로 삼은 개정판을 입력한 다음 {{ui:레드라인 파일 내보내기}}를 선택합니다. 열린 마크업마다 항목 하나씩 담긴 `.redline.json` 파일을 받습니다. 항목에는 시트, 위치(시트에 대한 분수 비율이므로 다른 크기로 다시 출력해도 맞게 정렬됩니다), 단어, 작성자, 스레드, 작업이 들어 있습니다. 변경을 그리는 사람은 `.redline-answers.json` 파일에 승인됨, 거부됨 또는 완료로 답하고, {{ui:답변 파일 불러오기…}}를 사용하면 각 마크업에 그 상태와 도면 작업자의 메모가 한 번의 실행 취소 단계로 적용됩니다. 자세한 내용은 [레드라인으로 마크업을 도면 작업자에게 보내기](topic:redline-to-revision)를 참고하십시오.

**AI 어시스턴트**

- **더 많은 도구.** CadCraft Studio를 통해 연결한 어시스턴트는 작업 목록을 읽고(`tasks_list`), 작업을 만들거나 바꾸고(`task_set`), 작업을 해제하고(`task_clear`), 작업을 새 개정판이나 요소와 대조하고(`tasks_check`), 열린 두 도면 세트 사이의 변경 목록을 텍스트로 읽을 수(`revisions_changes`) 있습니다. 어시스턴트는 {{ui:어시스턴트}} 스위치에서 선택한 도구만 사용하며, 각 변경은 실행 취소 한 단계입니다. 자세한 내용은 [AI 어시스턴트와 함께 MarkupCraft 사용하기](topic:use-with-ai-assistants)를 참고하십시오.

### 모든 앱에서

- **언어.** CadCraft Studio는 이제 54개 언어를 지원합니다. 새로 추가된 10개는 리투아니아어, 라트비아어, 보스니아어, 마라티어, 텔루구어, 알바니아어, 아프리칸스어, 필리핀어, 스와힐리어, 우즈베크어입니다. 영어가 아닌 모든 언어는 원어민이 검토하기 전까지 기계 번역 초안입니다.
- **입력 장치.** {{ui:설정}} › {{ui:전역}} › {{ui:입력 장치}}에서 트랙패드, 마우스 측면 버튼, 펜, 손가락 탭, 3D 마우스, 게임 컨트롤러, MIDI 컨트롤러의 동작을 모든 앱에 또는 이 앱에만 적용되도록 설정합니다. 설정을 바꾸기 전까지 모든 장치는 이전과 같이 동작합니다. 자세한 내용은 [트랙패드, 3D 마우스, 컨트롤러 사용하기](common:input-devices)를 참고하십시오.
- **도구 모음 행.** {{ui:설정}} › {{ui:일반}} › {{ui:도구 모음 행}}에는 {{ui:줄 바꿈}}(기본값), {{ui:2행}}, {{ui:1행}}이 있어 도면 공간이 더 넓어집니다. 자세한 내용은 [패널 배치하기](common:arrange-panels)를 참고하십시오.
- **속성 그리드.** 마크업의 스타일 필드는 접을 수 있는 범주와 라벨 및 값 열이 있는 공유 그리드를 사용합니다.
- **문제 패널.** 기한이 지난 작업처럼 앱에서 나온 경고는 하나의 문제 패널에 모입니다.
- **Live와 애드온.** Live 세션은 [Live (공동 편집)로 함께 작업하기](common:work-together-live)에서 설명하며, 계정에 따라 제공되는 애드온 목록은 [애드온과 계정 목록](common:addons-basics)에 있습니다.
- **AI 연결.** CadCraft Studio는 자체 어시스턴트를 연결하는 허브입니다. 한 번 연결하면 8개 앱 모두에서 사용할 수 있습니다. 앱 자체에는 AI가 없습니다.

### 0.8.1에서 수정됨

- **Studio는 실행 중에 언어를 바꿀 수 있습니다.** 이전에는 데스크톱 앱과 패키지 버전이 영어로 남아 있었습니다. 아직 모든 플랫폼에서 시험하지 않았으니, 언어가 바뀌지 않으면 알려 주십시오.
- Studio 0.8 설치본은 {{ui:설정}} › {{ui:업데이트}}를 통해 0.8.1을 제공받습니다.

### 이번 버전에 아직 없는 기능

- **코드 서명 없음.** Windows 설치 프로그램과 macOS .dmg에는 아직 서명이 없습니다. Windows에서 SmartScreen이 설치를 막으면 {{ui:추가 정보}}를 선택한 다음 {{ui:그래도 실행}}을 선택합니다. Mac에서는 CadCraft Studio를 마우스 오른쪽 버튼으로 클릭하고 {{ui:열기}}를 선택합니다. 스토어 빌드는 보류 중입니다.
- **AI 연결은 일부 미완성입니다.** Studio 안에서의 원클릭 연결, 브라우저 어시스턴트용 호스팅 커넥터, Studio 안의 자체 API 키는 이번 릴리스에서 보장하지 않습니다. 작업 루프는 시험했지만 실제 어시스턴트로는 아직 시험하지 않았습니다.
- **작업 확인에는 같은 페이지 크기가 필요합니다.** 다른 크기로 다시 출력한 시트는 맞지 않으므로 그 작업은 닫히지 않습니다. 시트는 시트 번호로, 없으면 페이지 위치로 짝을 짓습니다.
- **음성 메모는 녹음만 저장합니다.** 텍스트 기록은 없으며, 어시스턴트는 소리가 아니라 메모의 길이, 작성자, 캡션만 봅니다. 녹음은 헤드리스 브라우저에서 가짜 마이크로 시험했습니다. 휴대폰, 태블릿, 노트북의 실제 마이크는 아직 확인하지 않았습니다.
- **PDF의 계산 시트와 사유**는 파일의 비공개 항목에 저장됩니다. 이전 MarkupCraft는 그 항목을 무시하고 다음 저장 때 버리므로, 그런 파일은 0.8 이상에서 열고 저장하십시오.
- **레드라인의 도면 작업자 쪽 기능.** CadCraft가 레드라인 파일을 읽고 답변하는 기능은 아직 만들지 않았습니다.
- **다른 언어.** 타밀어에서는 앱 바가 528 px 넘칩니다.

그 밖의 내용은 [아직 만들지 않은 기능](topic:not-built-yet)에 있습니다. 이전 릴리스는 [0.7 새로운 기능](topic:whats-new-0-7)을 참고하십시오.
