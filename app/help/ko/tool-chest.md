{{ui:Tools}} 탭에는 **도구 상자**가 들어 있습니다. 모양을 그대로 저장한 마크업이며, 다시 그릴 수 있습니다. 도구는 마크업의 종류, 색상, 선 두께, 채우기, 불투명도, 글자 크기, 주제를 유지하며, 스탬프의 문구, 수량 그룹 이름, 문자 상자나 콜아웃의 시작 텍스트도 함께 저장합니다.

## 처음부터 들어 있는 도구

새 도구 상자에는 여섯 개의 도구가 있습니다: "수정 구름"(빨간색), "질문 구름"(파란색), "노란 형광펜", "RFI 콜아웃"(파란색, "RFI: "로 시작), "현장 확인"("Field verify."라고 쓰는 주황색 콜아웃), 그리고 "조건부 승인"(스탬프).

## 도구로 그리기

1. {{ui:Tools}} 탭을 엽니다.
2. 도구를 클릭합니다. 도구가 눌린 것처럼 보이고, 도구 모음의 해당 도구가 켜집니다.
3. 평소처럼 그립니다. {{ui:Properties}}에 '도구 상자의 "<tool>" 도구로 그리는 중'이라고 표시됩니다.

도구 상자의 도구가 켜져 있는 동안 그리기 전에 {{ui:Properties}}에서 바꾼 설정은 지금 그 도구에만 적용되며, 저장된 도구나 평소 도구 설정은 바뀌지 않습니다. 도구 모음 버튼을 고르거나 도구의 단축키를 누르면 기본 도구로 돌아갑니다.

## 나만의 도구 저장

1. 마크업을 그리고 원하는 대로 스타일을 지정합니다: 색상, 선, 채우기, 주제, 스탬프 문구.
2. 마크업을 선택합니다.
3. {{ui:Tools}} 탭의 {{ui:Save selected as a tool}} 명령 또는 {{ui:Properties}}의 {{ui:Save as a tool}} 명령을 선택합니다.
4. {{ui:Tool name}}을 입력하고 {{ui:Save tool}}을 선택합니다.

결과: 도구가 도구 상자의 끝에 추가되고, {{ui:Tools}} 탭이 열려 그 도구를 보여 줍니다.

## 선택 항목으로 만든 스탬프

여러 마크업을 선택하거나({{ui:Content}} 도구로 페이지 내용을 선택) {{ui:More}} 또는 오른쪽 클릭 메뉴에서 {{ui:Save selection as a stamp…}} 명령을 선택합니다. 도구 상자에는 이들을 모두 담은 스탬프 하나가 추가됩니다("스탬프: 마크업 3개 함께"). 그것을 클릭한 다음 아무 시트나 클릭하면, 마크업들이 클릭한 위치를 중심으로 함께 놓이며, 본인 이름으로 된 새 마크업이 됩니다. 페이지 내용은 그 자리의 페이지에 그려집니다. 이 스탬프는 다른 도구와 마찬가지로 저장되고 도구 상자와 함께 공유됩니다.

## 도구 제거

도구 행 끝의 ×를 선택한 다음 {{ui:Remove}}를 선택합니다. 이미 그려 둔 마크업은 그대로 남습니다.

## 도구 상자 보관 위치

도구 상자는 **이 브라우저, 이 컴퓨터**에 저장됩니다. 다른 브라우저나 컴퓨터에는 별도의 도구 상자가 있으며(기본 여섯 개로 시작), 비공개 창은 닫을 때 도구 상자를 잊고, 브라우저 설정에서 이 사이트의 데이터를 지우면 도구 상자도 삭제됩니다.

브라우저가 저장하지 못하면(저장 공간이 꺼져 있거나 가득 찬 경우) 상태 표시줄에 "이 브라우저에 도구 상자를 보관할 수 없습니다(저장 공간이 꺼져 있거나 가득 찼습니다). 보관하려면 내보내십시오."라고 표시됩니다.

:::safari
Safari는 한동안 사이트를 쓰지 않으면 웹사이트의 저장 데이터를 지울 수 있습니다. 다시 가져올 수 있도록 도구 상자를 가끔 내보내십시오.
:::

**도구 상자를 백업으로 내보내십시오.** 특히 자주 쓰는 도구를 만든 뒤에는 꼭 하십시오.

## 사무실과 도구 상자 공유

1. 도구를 한 번 설정합니다.
2. {{ui:Export}}를 선택합니다. "MarkupCraft tool chest.json" 파일이 만들어집니다.
3. 그 파일을 사무실의 표준 자료를 보관하는 곳에 두거나 여러 사람에게 보냅니다.
4. 다른 사람들은 각자 {{ui:Tools}} 탭에서 {{ui:Import}}를 선택하고 그 파일을 고릅니다.

결과: "MarkupCraft tool chest.json"에서 도구 12개를 가져왔습니다. 같은 도구 상자에서 나온 도구는 이전 복사본을 대체하므로, 갱신된 사무실 도구 상자를 가져오면 중복되지 않고 해당 도구가 새로 고쳐집니다. 새 도구는 추가됩니다. 도구 상자 하나에는 최대 500개의 도구를 담을 수 있습니다.

MarkupCraft는 가져온 파일의 모든 값을 검사하고, 사용할 수 없는 항목은 건너뜁니다("2개 건너뜀(사용 불가)"). 도구 상자 파일이 아니면 가져오기를 거부합니다: "이 파일은 MarkupCraft 도구 상자가 아닙니다." 또는 "이 파일은 도구 상자가 아닙니다(JSON이 아님)."

다른 마크업 프로그램의 도구 상자 파일은 가져올 수 없습니다.
