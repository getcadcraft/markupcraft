BCF(BIM Collaboration Format)는 BIM 도구 사이에서 이슈를 주고받기 위한 개방형 파일 형식입니다. 많은 모델 조정 및 저작 프로그램은 `.bcfzip` 파일을 이슈 목록으로 가져올 수 있습니다. MarkupCraft는 **BCF 2.1**로 작성합니다.

## 만들기

1. {{ui:마크업}} 탭을 엽니다.
2. 보내려는 항목으로 목록을 필터링합니다. 예: {{ui:상태}} "열림". 목록에 표시된 마크업만 내보냅니다.
3. {{ui:BCF}}를 선택합니다.
4. 각 마크업의 스냅샷을 만드는 동안 기다립니다 ("BCF용 스냅샷 만드는 중 (20개 중 5개)…").

결과: "<name> markups.bcfzip" 파일이 다운로드되며, 상태 표시줄에 항목 수와 파일 크기가 표시됩니다.

## 포함된 내용

각 마크업은 하나의 **항목**이 됩니다.

| 항목 필드 | 채워지는 내용 |
|---|---|
| 제목 | 펀치 번호, 주제, 시트. 예: "#4 A-101 수정 구름 — 평면도" |
| 유형 | 마크업 종류 (수정 구름, 콜아웃, 길이…) |
| 상태 | 열림, 승인됨, 거부됨 또는 완료됨 |
| 라벨 | 마크업 종류와 시트 |
| 작성자 및 날짜 | 마크업의 작성자, 생성 날짜와 수정 날짜 |
| 담당자, 기한 | 펀치 항목이 있는 경우 그 항목에서 가져옴 |
| 설명 | 텍스트 또는 스탬프 문구, 측정값, 의견, 시트와 파일 |
| 댓글 | 답글마다 하나씩, 작성자와 날짜 포함 |
| 스냅샷 | 시트의 해당 부분에 있는 마크업 그림 |
| 뷰포인트 | 시트에서 마크업 위치를 위에서 내려다본 뷰 |

같은 마크업을 다시 내보내면 항목 ID가 같으므로, BCF를 가져오는 도구는 이를 같은 이슈로 인식할 수 있습니다.

## 가져올 때 들어오는 내용

{{ui:BCF 가져오기}}는 BCF 2.0, 2.1, 3.0 파일을 읽습니다 (공식 buildingSMART 3.0 테스트 파일 19개로 확인했으며, 모든 항목을 읽었고 텍스트가 있는 세 항목의 댓글도 읽었습니다). 내보낸 마크업과 같은 항목 ID를 가진 항목이면 새 댓글을 답글로 추가하고 새 상태를 반영합니다. 그 밖의 항목은 라벨이나 파일 이름이 지정한 시트에 메모가 되며, 그런 시트가 없으면 열린 시트에 메모가 됩니다. 제목, 설명, 담당자, 기한은 메모의 텍스트가 되고, 댓글은 답글이 됩니다.

| BCF 항목 | MarkupCraft |
|---|---|
| 제목, 설명, 담당자, 기한 | 메모의 텍스트 |
| 텍스트가 있는 댓글 | 답글 |
| 상태 Open, Accepted, Rejected, Completed (Closed, Resolved, Done은 Completed로 봅니다) | 마크업의 상태 |
| 작성자와 생성 날짜 | 메모의 작성자와 날짜 |
| 카메라 위치 | 시트 위의 위치. 라벨이나 파일 이름으로 시트에 연결된 항목에만 해당 |
| 모델 선택, 숨긴 부분, 클리핑 평면, 스냅샷 | 보관하지 않음: 시트에는 이를 보여 줄 모델이 없습니다 |

## 알아둘 한계

- **시트는 모델이 아닙니다.** 뷰포인트는 종이 위에서 마크업의 위치를 가리키며, 종이의 미터 단위로 측정됩니다. BIM 도구를 모델의 특정 위치로 옮기지 않습니다. 위치를 찾을 때는 스냅샷과 시트 이름을 사용합니다.
- **상태와 유형은 MarkupCraft 고유의 것입니다** (Open, Accepted, Rejected, Completed; Cloud, Callout…). BCF가 허용하는 대로 파일에 이를 선언하지만, 자체 고정 목록을 가진 도구는 이를 매핑하거나 무시할 수 있습니다.
- **가져오기는 모델 뷰가 아니라 댓글을 가져옵니다.** {{ui:BCF 가져오기}}는 내보낸 마크업에 답글과 상태를 추가하고, 다른 이슈는 메모로 만들며, 모델 카메라는 표시할 수 없습니다. 자세한 내용은 [마크업 목록 및 내보내기](topic:markups-list-and-export#import-bcf)를 참고하십시오.
- 도면 검토에서는 마크업을 PDF로 돌려 보내는 것이 대개 더 간단합니다. BCF는 도면 의견을 모델 조정 작업 흐름으로 가져갈 때 쓰는 형식입니다.
