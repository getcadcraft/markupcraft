BCF(BIM Collaboration Format)는 BIM 도구 사이에서 이슈를 주고받기 위한 개방형 파일 형식입니다. 많은 모델 조정 및 작성 프로그램이 `.bcfzip` 파일을 이슈 목록으로 가져올 수 있습니다. MarkupCraft는 **BCF 2.1**로 저장합니다.

## 만들기

1. {{ui:마크업}} 탭을 엽니다.
2. 보내려는 항목만 나오도록 목록을 필터링합니다. 예를 들어 {{ui:상태}}를 "열림"으로 설정합니다. 나열된 마크업만 내보내집니다.
3. {{ui:BCF}}을 선택합니다.
4. 각 마크업의 스냅샷을 만드는 동안 기다립니다("BCF용 스냅샷 만드는 중 (20개 중 5개)…").

결과: "<name> markups.bcfzip" 파일이 다운로드되고, 상태 표시줄에 포함된 토픽 수와 파일 크기가 표시됩니다.

## 들어 있는 내용

각 마크업은 **토픽** 하나가 됩니다.

| 토픽 필드 | 채워지는 내용 |
|---|---|
| 제목 | 펀치 번호, 주제와 시트, 예: "#4 A-101의 구름 — 평면도" |
| 유형 | 마크업 종류(구름, 콜아웃, 길이 …) |
| 상태 | 열림, 승인, 거부 또는 완료 |
| 라벨 | 마크업 종류와 시트 |
| 작성자 및 날짜 | 마크업의 작성자, 만든 날짜와 수정한 날짜 |
| 담당자, 기한 | 펀치 항목이 있는 경우 그 항목에서 가져옴 |
| 설명 | 텍스트 또는 스탬프 문구, 측정값, 의견, 시트와 파일 |
| 댓글 | 답글마다 하나씩, 작성자와 날짜 포함 |
| 스냅샷 | 시트의 해당 부분에 있는 마크업 그림 |
| 뷰포인트 | 시트에서 마크업이 있는 위치를 위에서 내려다본 보기 |

같은 마크업을 다시 내보내면 같은 토픽 ID가 나오므로, BCF를 가져오는 도구가 같은 이슈로 인식할 수 있습니다.

## 알아 둘 한계

- **시트는 모델이 아닙니다.** 뷰포인트는 종이 위에서 마크업이 있는 위치를 가리키며, 종이 기준 미터로 측정됩니다. BIM 도구에서 모델의 특정 위치로 이동시키지는 않습니다. 위치를 찾으려면 스냅샷과 시트 이름을 사용합니다.
- **상태와 유형은 MarkupCraft 고유의 값입니다**(열림, 승인, 거부, 완료; 구름, 콜아웃 …). 파일에 선언되지만, BCF가 허용하는 대로 고정된 목록을 가진 도구는 이 값을 다른 값으로 바꾸거나 무시할 수 있습니다.
- **가져오기는 의견을 가져오며, 모델 뷰는 가져오지 않습니다.** {{ui:BCF 가져오기}} 명령은 내보낸 마크업에 답글과 상태를 추가하고, 다른 이슈는 메모로 만듭니다. 모델 카메라를 보여 줄 수는 없습니다. 자세한 내용은 [마크업 목록 및 내보내기](topic:markups-list-and-export#import-bcf)를 참조하십시오.
- 도면 검토에는 마크업을 PDF로 다시 보내는 것이 보통 더 간단합니다. BCF는 도면 의견을 모델 조정 작업 흐름으로 가져가려는 경우에 적합합니다.
