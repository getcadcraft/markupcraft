MarkupCraft는 브라우저 창을 가득 채웁니다. 위에서 아래로, 왼쪽에서 오른쪽으로 설명합니다.

## 맨 위의 막대

모든 것 위에 있는 얇은 막대는 MarkupCraft 자체가 아니라 CadCraft 제품군에 속합니다. 여기에는 다음이 있습니다.

- 앱 이름과 실행 중인 버전,
- {{ui:MarkupCraft 정보}}: 웹사이트의 앱 페이지를 엽니다.
- {{ui:도움말}}: 이 도움말을 측면 패널로 엽니다(또는 {{key:F1}}).
- {{ui:오프라인용 저장}}: MarkupCraft, PDF 리더와 쓰기 도구, 이 도움말을 이 브라우저에 보관해 연결 없이도 열리게 하며, 완료되면 "오프라인 사용 준비됨"이 표시됩니다([오프라인으로 작업하기](common:offline) 참고).
- 화면 모드 버튼({{ui:전체 화면}}),
- {{ui:설정}}(또는 {{key:Mod+,}}): 이 앱 고유의 설정을 담은 {{ui:MarkupCraft}} 탭과 모든 CadCraft 앱이 공유하는 설정을 담은 {{ui:일반}} 탭이 있습니다([MarkupCraft 설정](topic:settings) 참고).
- {{ui:종이}}와 {{ui:모델}}: 밝은 테마와 어두운 테마입니다. {{ui:모델}}에서는 시트가 어두운 배경에 밝게 그려지며, 마크업은 자신의 색을 유지합니다.

화면 모드 버튼 또는 {{key:Ctrl+Shift+F}}를 누르면 일반, 전체 화면, 막대를 숨긴 전체 화면의 세 모드를 차례로 전환합니다. 막대를 숨긴 상태에서는 포인터를 화면 위쪽 가장자리로 옮기거나(또는 그곳을 탭하면) 막대가 다시 나타납니다. 이 단축키는 Mac을 포함한 모든 컴퓨터에서 Control 키를 사용합니다.

:::note
전체 화면에서는 {{key:Esc}}가 브라우저의 전체 화면도 해제합니다. 그리기만 취소하려 했다면 {{key:Ctrl+Shift+F}}를 다시 눌러 전체 화면으로 돌아가십시오.
:::

## 도구 모음

맨 위 막대 아래에서 도구는 이름이 붙은 그룹으로 나뉩니다.

| 그룹 | 버튼 |
|---|---|
| 파일 | {{ui:열기}}, {{ui:저장}}, {{ui:닫기}} |
| 선택 | {{ui:선택}}, {{ui:초점 이동}} |
| 그리기 | {{ui:펜}}, {{ui:강조 표시}}, {{ui:선}}, {{ui:화살표}}, {{ui:사각형}}, {{ui:타원}}, {{ui:폴리선}}, {{ui:폴리곤}} |
| 수정 | {{ui:구름}}, {{ui:자유 구름}} |
| 주석 | {{ui:콜아웃}}, {{ui:문자}}, {{ui:비고}}, {{ui:스탬프}} |
| 측정 | {{ui:보정}}, {{ui:길이}}, {{ui:면적}}, {{ui:수량}} |
| 편집 | {{ui:실행 취소}}, {{ui:다시 실행}}, {{ui:복사}}, {{ui:붙여넣기}}, 그리고 {{ui:더 보기}}: {{ui:잘라내기}}, {{ui:복사}}, {{ui:붙여넣기}}, {{ui:제자리에 붙여넣기}}, {{ui:복제}}, {{ui:삭제}}, {{ui:모두 선택}}, {{ui:선택 해제}} |

사용 중인 도구는 눌린 모양으로 표시됩니다. 버튼 위에 포인터를 올리면 해당 키가 표시되며(예: "사각형 (R)"), {{ui:더 보기}} 메뉴에는 각 명령의 키가 함께 나열됩니다. 지금 사용할 수 없는 버튼은 흐리게 표시됩니다. 마크업을 선택하기 전에는 {{ui:복사}}가, 무언가를 복사하기 전에는 {{ui:붙여넣기}}가 흐리게 보입니다. {{ui:저장}} 뒤의 작은 점은 저장하지 않은 마크업이 있다는 뜻입니다. 전체 키 목록은 [키보드와 마우스](topic:keyboard)에 있습니다.

도구는 그린 뒤에도 켜진 상태로 유지되므로 구름을 연속으로 여러 개 그릴 수 있습니다. {{key:Esc}}(새 마크업이 아직 선택된 상태라면 두 번) 또는 {{key:V}}를 누르면 {{ui:선택}}으로 돌아갑니다.

## 시트 목록 (왼쪽)

{{ui:시트}}에는 열려 있는 모든 PDF의 모든 페이지가 나열됩니다. 각 행에는 시트의 작은 그림, 이름, 시트 번호 또는 파일과 페이지, 마크업 수가 표시됩니다. 제목 뒤의 숫자는 시트 수입니다.

- 행을 클릭하면 해당 시트가 표시됩니다.
- {{ui:시트 검색}}에 입력하면 시트 이름, 시트 번호, 파일 이름으로 걸러집니다. {{key:Enter}}를 누르면 첫 번째 일치 항목이 열립니다.

시트 이름은 PDF에 있으면 거기서 가져옵니다. [도면 세트 열기와 시트 이동](topic:open-a-plan-set)을 참고하십시오.

## 시트 영역 (가운데)

작업 중인 시트입니다. 아무것도 열려 있지 않을 때는 "도면 세트 열기"와 {{ui:PDF 열기}} 버튼이 표시됩니다. 이곳 어디에든 PDF를 끌어다 놓으면 열립니다.

시트 아래의 좁은 막대에는 다음이 있습니다.

- 이전 및 다음 시트 화살표와 "12개 중 3: A-101 — Floor plan"(포인터를 올리면 파일과 페이지가 표시됩니다),
- 축소, 배율 입력란(백분율을 입력하고 {{key:Enter}}를 누릅니다. 100%는 일반적인 화면에서 실제 크기입니다), 확대,
- {{ui:페이지 맞춤}}과 {{ui:너비 맞춤}}.

각 시트는 세트가 열려 있는 동안 자기만의 배율을 기억합니다.

두 시트를 비교하면 여기에 범례가 나타납니다. "이전 시트에만 있음", "새 시트에만 있음", "양쪽 모두 있음"입니다. [두 개정본 비교](topic:compare-revisions)를 참고하십시오.

## 패널 (오른쪽)

탭은 다섯 개입니다.

| 탭 | 표시 내용 |
|---|---|
| {{ui:속성}} | 선택한 마크업의 작성자, 날짜, 측정값, 상태, 주제, 문자, 코멘트, 스타일, 답글, 펀치 항목. 그리기 도구가 켜져 있고 선택한 것이 없으면 새 마크업에 사용할 설정. {{ui:선택}}이 켜져 있고 선택한 것이 없으면 시트의 번호, 제목, 이름을 읽어 온 위치, 용지 크기, 축척, {{ui:시트 이름 바꾸기}}. |
| {{ui:마크업}} | 열려 있는 세트의 모든 마크업을 필터와 함께 표시하고, {{ui:CSV}}와 {{ui:BCF}} 내보내기를 제공합니다. [마크업 목록](topic:markups-list-and-export)을 참고하십시오. |
| {{ui:펀치 리스트}} | 담당자, 기한, 상태가 있는 번호 붙은 펀치 항목. [펀치 리스트 만들기](topic:punch-list)를 참고하십시오. |
| {{ui:도구}} | 도구 상자: 저장해 둔 스타일 적용 도구. [도구 상자](topic:tool-chest)를 참고하십시오. |
| {{ui:비교}} | 두 시트를 겹쳐 봅니다. [두 개정본 비교](topic:compare-revisions)를 참고하십시오. |

## 상태 표시줄 (아래쪽)

- 왼쪽에는 시트 위의 포인터 위치가 용지 기준 인치로 표시됩니다([설정](topic:settings)에서 밀리미터로 바꿀 수 있습니다).
- 가운데에는 메시지가 표시됩니다. 도구가 다음에 기대하는 동작, 방금 저장한 내용, 어떤 동작이 거부된 이유 등입니다. **아무 일도 일어나지 않을 때는 여기를 읽으십시오.**
- 시트의 축척 버튼("보정되지 않음" 또는 축척)입니다. 클릭하면 축척을 설정합니다. [시트 보정과 측정](topic:calibrate-and-measure)을 참고하십시오.
- 사용자 이름(이름을 지정하기 전에는 "이름 설정"). 클릭하면 바꿀 수 있습니다.

## 작은 화면에서

너비가 약 1180픽셀 미만이면 패널이 좁아지고 시트 그림이 작아집니다. 휴대폰 크기의 화면에서는 도구 모음(옆으로 스크롤), 시트, 상태 표시줄, 패널, 맨 아래의 시트 목록 순으로 쌓입니다. 가로 방향의 태블릿은 전체 레이아웃을 유지합니다.
