{{ui:파일}} 그룹의 {{ui:페이지}} 메뉴는 열린 시트가 속한 PDF에서 작동합니다. 이 컴퓨터의 PDF는 절대 바뀌지 않으며, 변경 사항은 저장하는 사본에 포함됩니다.

## 인쇄

1. {{key:Mod+P}}를 누르거나, {{ui:페이지}}, 그다음 {{ui:인쇄…}}를 선택하십시오.
2. 시트가 두 개 이상 열려 있으면 인쇄할 항목을 고르십시오: {{ui:이 시트}}, 이 파일의 모든 페이지, 세트 전체, 또는 입력한 페이지(예: `1-3, 5`).
3. {{ui:인쇄}}를 선택하십시오. 브라우저의 프린터 대화상자가 열립니다. 그곳에서 프린터, 용지, 축척을 고르십시오.

마크업은 시트에서 보이는 그대로 인쇄됩니다. 프린터로 보내는 사본의 페이지에 그려지기 때문입니다. 다른 프로그램이 만든 댓글은 해당 PDF의 설정대로 인쇄됩니다.

:::safari firefox
브라우저가 페이지 안에서 인쇄할 수 없으면, 시트가 새 탭에서 PDF로 열립니다. 그 탭에서 인쇄하십시오.
:::

## 페이지 회전

{{ui:페이지}}, 그다음 {{ui:페이지를 시계 방향으로 회전}} 또는 {{ui:페이지를 반시계 방향으로 회전}}을 선택하십시오. 열린 시트가 90도 회전합니다. 마크업은 도면에서 있던 위치에 그대로 있고, 입력한 텍스트는 페이지와 함께 회전하여 여전히 바르게 읽힙니다.

## 페이지 이동

{{ui:페이지}}, 그다음 {{ui:페이지를 앞으로 이동}} 또는 {{ui:페이지를 뒤로 이동}}을 선택하십시오. 열린 시트는 자신의 PDF에서 이웃 페이지와 자리를 바꿉니다. 마크업, 축척, 시트 번호도 함께 이동합니다.

## 페이지 삽입

- {{ui:PDF에서 페이지 삽입…}}은 열린 시트 뒤에 다른 PDF의 모든 페이지를 넣습니다.
- {{ui:빈 페이지 삽입}}은 열린 시트 뒤에 같은 크기의 빈 페이지를 추가합니다. 스케치와 메모용입니다. {{ui:새로 만들기}}로 만든 세트에서는 세트의 그리드도 함께 적용됩니다.
- {{ui:새로 만들기}}로 만든 세트에서는 {{ui:시트}} 목록 아래의 {{ui:빈 페이지 추가}}가 다른 페이지와 같은 페이지를 맨 끝에 하나 더 추가합니다. [빈 페이지로 시작](topic:open-a-plan-set#start-with-blank-pages)을 참고하십시오.

삽입된 페이지는 이름을 바꾸기 전까지 페이지 번호가 레이블이 됩니다. [시트 이름 바꾸기](topic:open-a-plan-set#rename-a-sheet)를 참고하십시오.

## 페이지 삭제

1. {{ui:페이지}}, 그다음 {{ui:페이지 삭제…}}를 선택하십시오.
2. 이 PDF의 페이지 번호를 입력하십시오. 예: `3` 또는 `2-4`. 열린 시트의 페이지가 미리 채워집니다.
3. {{ui:페이지 삭제}}를 선택하십시오. 그 페이지에 마크업이 있으면 MarkupCraft가 개수를 알리고 다시 묻습니다.

PDF에는 최소 한 페이지가 남습니다. 파일 전체를 제외하려면 세트를 닫고 필요한 파일을 다시 여십시오.

## 페이지 추출

{{ui:페이지}}, 그다음 {{ui:페이지 추출…}}을 선택하고 페이지를 입력하십시오. 페이지는 "<file> (pages 1-3).pdf"라는 이름의 새 PDF로 다운로드되며, 마크업은 계속 편집할 수 있는 댓글로 들어갑니다. 열린 파일은 그대로 남습니다.

## 알아 두면 좋은 내용

- **실행 취소는 페이지 변경에서 멈춥니다.** {{key:Mod+Z}}는 그 이후에 그린 마크업을 되돌리지만, 페이지 변경 자체나 그 이전의 내용은 되돌리지 않습니다. 원본 PDF에서 다시 시작하려면 저장하지 않고 닫으십시오.
- 페이지 번호는 세트 전체가 아니라 한 PDF의 페이지를 셉니다. 페이지를 이동해도 그 페이지는 자신의 파일 안에 남습니다.
- 바뀐 페이지는 저장되지 않은 작업입니다. {{ui:저장}}하면 재구성된 사본이 다운로드되며, 나갈 때 먼저 확인합니다.
