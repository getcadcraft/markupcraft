먼저 {{ui:선택}} 도구({{key:V}})를 사용하십시오. {{key:Esc}} 키를 눌러도 같은 곳으로 갑니다. 첫 번째 누르면 선택이 해제되고, 다음에 누르면 {{ui:선택}} 도구로 돌아갑니다.

## 마크업 고르기

:::mouse
- **마크업 하나:** 클릭합니다. 점선 상자와 핸들이 나타나고, {{ui:속성}}에 표시됩니다.
- **하나 추가하거나 제외:** {{key:Shift}} 키를 누른 채 클릭합니다.
- **창 안에 완전히 포함:** 시트의 빈 부분에서 왼쪽에서 오른쪽으로 드래그합니다. 상자 안에 완전히 들어간 마크업만 선택됩니다(실선 윤곽).
- **창에 닿는 항목:** 오른쪽에서 왼쪽으로 드래그합니다. 상자가 닿는 항목이 모두 선택됩니다(녹색 점선 윤곽).
- **이 시트의 모든 항목:** {{key:Mod+A}}를 누르거나, 도구 모음의 {{ui:편집}} 그룹에서 {{ui:더 보기}}를 누른 다음 {{ui:모두 선택}}을 선택합니다.
- **선택 없음:** 빈 곳을 클릭하거나 {{key:Esc}} 키를 누르거나, {{ui:더 보기}}를 누른 다음 {{ui:선택 해제}}를 선택합니다.
:::

:::touch
- **마크업 하나:** 탭합니다.
- **여러 개:** 시트의 빈 부분에서 한 손가락으로 드래그하여 창을 그립니다. 왼쪽에서 오른쪽으로 그리면 완전히 포함된 항목을, 오른쪽에서 왼쪽으로 그리면 닿는 항목을 선택합니다.
- {{key:Shift}} 키를 누른 채 탭하는 방법은 키보드가 연결된 경우에만 작동합니다. 키보드가 없으면 창을 사용하십시오.
- {{ui:선택}} 도구에서는 한 손가락으로 화면을 이동할 수 없습니다. 두 손가락을 사용하거나 {{ui:초점 이동}} 도구를 사용하십시오.
:::

파일과 함께 들어온 읽기 전용 코멘트는 회색 점선 상자로 표시되고 핸들이 없습니다. 선택하고 답글을 달 수 있지만 변경할 수는 없습니다.

## 이동 및 크기 조정

- **이동:** 선택한 마크업을 드래그합니다. {{key:Shift}} 키를 누른 채 이동하면 45° 배수 방향으로만 움직입니다. 여러 마크업을 선택하면 함께 이동합니다.
- **크기 조정:** 마크업 하나를 선택한 상태에서 핸들을 드래그합니다. 사각형 핸들은 상자 크기를 조정합니다({{key:Shift}} 키를 누르면 비율이 유지됩니다). 원형 핸들은 선, 폴리선, 다각형, 구름 또는 측정값의 모서리 점 하나를 이동합니다({{key:Shift}} 키를 누르면 45°). 마름모 핸들은 콜아웃의 끝과 꺾임을 이동합니다. 펜 획은 상자에 맞춰 크기가 조정됩니다.
- **미세 이동:** 화살표 키를 누르면 선택 항목이 화면 픽셀 한 칸씩 움직이며, {{key:Shift}} 키를 누른 채 누르면 10칸씩 움직입니다. 누를 때마다 실행 취소 단계 하나입니다.

## 내용이나 모양 바꾸기

- **텍스트, 콜아웃, 메모:** 마크업을 두 번 클릭하거나, {{key:Enter}} 키를 누르거나, {{ui:속성}}에서 {{ui:시트에서 편집}}을 선택합니다. 입력한 뒤 바깥을 클릭하거나 {{key:Mod+Enter}} 키를 누릅니다. {{key:Esc}} 키를 누르면 편집이 취소됩니다.
- **스탬프:** {{ui:속성}}에서 다른 스탬프를 선택합니다(두 번 클릭하면 {{ui:속성}}이 자동으로 열립니다).
- **스타일:** {{ui:속성}}의 "스타일" 아래에 있는 {{ui:색상}}, {{ui:선 너비}}, {{ui:채우기}}, {{ui:불투명도}}, {{ui:문자 크기}}. 여러 항목을 선택하면 {{ui:속성}}에 선택한 종류가 표시되며 한 번에 모두 바꿀 수 있습니다.

## 복사, 붙여넣기 및 복제

도구 모음의 {{ui:편집}} 그룹에는 {{ui:복사}}와 {{ui:붙여넣기}}가 있으며, {{ui:더 보기}} 메뉴에는 이 모든 명령과 각각의 단축키가 있습니다.

| 명령 | 키 | 동작 |
|---|---|---|
| {{ui:잘라내기}} | {{key:Mod+X}} | 선택한 마크업을 복사한 뒤 삭제합니다 |
| {{ui:복사}} | {{key:Mod+C}} | 선택한 마크업을 복사합니다 |
| {{ui:붙여넣기}} | {{key:Mod+V}} | 현재 시트에 복사본을 놓습니다(위치는 아래 참조) |
| {{ui:제자리에 붙여넣기}} | {{key:Mod+Shift+V}} | 복사한 바로 그 위치에 복사본을 놓습니다. 같은 시트에서는 원본 위에 놓이고, 다른 시트에서는 종이상의 같은 위치에 놓입니다 |
| {{ui:복제}} | {{key:Mod+D}} | 이전에 복사한 내용에는 영향을 주지 않고, 선택 항목의 복사본을 조금 아래 오른쪽에 만듭니다 |

**붙여넣기 위치:**

- 포인터가 시트 위에 있을 때 {{key:Mod+V}} 키를 누르면 복사본이 포인터 위치를 중심으로 놓입니다. 포인터를 옮긴 뒤 {{key:Mod+V}} 키를 다시 누르면 또 하나를 놓을 수 있습니다.
- {{ui:붙여넣기}} 버튼(이때 포인터는 도구 모음에 있습니다), 또는 포인터가 시트 밖에 있을 때 {{key:Mod+V}} 키를 누르면 복사본은 원본보다 조금 아래 오른쪽에 놓입니다. 같은 복사본을 붙여넣을 때마다 조금씩 더 이동하므로 복사본끼리 겹치지 않습니다. 다른 시트에서는 첫 붙여넣기가 원본이 있던 위치에 놓입니다. 그 위치가 보이지 않으면 복사본은 보기의 가운데에 놓입니다.
- {{key:Mod+V}} 키가 항상 원본 옆에 붙여넣도록 하려면, [MarkupCraft 설정](topic:settings)에서 {{ui:붙여넣기}} 아래의 {{ui:복사본 옆}}을 선택하십시오.

붙여넣은 마크업은 선택된 상태이므로 바로 드래그할 수 있습니다. 잘라내기, 붙여넣기, 복제는 각각 실행 취소 단계 하나입니다. {{key:Mod+Z}} 키를 누르면 붙여넣기 전체가 취소됩니다.

붙여넣은 복사본은 새 마크업입니다. 작성자로 내 이름이, 날짜로 오늘 날짜가 기록되고, 상태는 열림, 펀치 번호는 없고, 스레드는 비어 있습니다. 종류, 모양, 스타일, 텍스트, 코멘트는 그대로 가져옵니다. 파일과 함께 들어온 읽기 전용 코멘트는 복사하거나 잘라낼 수 없습니다.

**탭 사이:** 복사한 내용은 이 브라우저에도 보관되므로, 같은 브라우저의 다른 MarkupCraft 탭에서 붙여넣을 수 있습니다. 마크업을 복사해도 컴퓨터의 클립보드는 사용되지 않습니다. 따라서 다른 프로그램에 붙여넣을 수 없으며, 다른 곳에서 복사한 텍스트는 마크업으로 붙여넣어지지 않습니다.

**우클릭 메뉴:** 마크업(또는 빈 종이)을 우클릭하면 {{ui:잘라내기}}, {{ui:복사}}, {{ui:여기에 붙여넣기}}, {{ui:제자리에 붙여넣기}}, {{ui:복제}}, {{ui:삭제}}, {{ui:선택 항목을 스탬프로 저장…}}, {{ui:저장할 때 페이지에 평탄화}}, {{ui:여기에 그림 삽입…}}, {{ui:모두 선택}} 메뉴가 나타납니다. 선택되지 않은 마크업을 우클릭하면 먼저 선택됩니다. 오른쪽 버튼으로 드래그하면 여전히 화면이 이동합니다. 터치 화면에서는 마크업을 길게 누르면 같은 메뉴가 열립니다(텍스트에서는 텍스트 편집이 시작됩니다). 메뉴 키나 {{key:Shift+F10}} 키를 누르면 선택 위치에서 메뉴가 열립니다.

{{ui:페이지 내용}} 도구로 선택한 페이지 내용도 복사하고 붙여넣을 수 있습니다. 참조: [페이지 자체의 선, 그림, 텍스트 변경](topic:page-content).

페이지의 일부를 그림(사각형, 타원, 자유형 도형)으로 복사하거나, 다른 시트나 앱에 겹쳐 쓸 투명 오버레이로 복사하려면 [페이지 영역 또는 오버레이 복사](topic:copy-an-area)를 참조하십시오.

## 삭제

{{key:Delete}} 키 또는 {{key:Backspace}} 키를 누르거나, 도구 모음에서 {{ui:더 보기}}를 누른 다음 {{ui:삭제}}를 선택하거나, {{ui:속성}}의 {{ui:삭제}}를 선택하십시오. 상태 표시줄에 삭제된 개수가 표시됩니다. 파일에 들어 있던 읽기 전용 코멘트는 절대 삭제되지 않습니다("파일에 있는 그대로 유지").

## 실행 취소와 다시 실행

- {{key:Mod+Z}}는 실행을 취소하고, {{key:Mod+Y}} 또는 {{key:Mod+Shift+Z}}는 다시 실행합니다. 도구 모음에는 {{ui:실행 취소}}와 {{ui:다시 실행}}이 있습니다.
- 상태 표시줄에 취소된 작업이 표시됩니다("마크업 이동을 실행 취소했습니다.").
- 실행 취소는 마크업, 상태, 답글, 펀치 항목, 시트 축척, 시트 이름의 모든 변경을 포함하며 최대 500단계까지 가능합니다.
- 세트를 닫으면 실행 기록이 지워집니다.

## 다른 시트에 마크업 복사

같은 스탬프, 메모 또는 구름을 여러 시트에 넣으려면, 마크업(또는 여러 개의 마크업)을 선택하고 {{ui:속성}}에서 {{ui:다른 시트에 복사…}}를 선택합니다. 시트를 체크하거나 {{ui:모든 시트}}를 선택한 다음 {{ui:복사}}를 선택하십시오. 각 시트에는 페이지의 같은 위치에 내 이름이 기록된 복사본이 생깁니다. {{key:Mod+Z}} 키를 한 번 누르면 모두 제거됩니다.
