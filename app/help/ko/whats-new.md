MarkupCraft 0.6과 비교해 0.7에서 바뀐 내용입니다. 가장 큰 새 기능은 현장 기록입니다. RFI, 제출물, 작업 일지를 마크업과 함께 PDF 안에 보관합니다.

## 새 기능

### RFI, 제출물, 작업 일지

- **현장 탭.** {{ui:현장}} 탭을 열고 {{ui:RFI}}, {{ui:제출물}}, {{ui:작업 일지}} 중 하나를 선택합니다. RFI나 제출물이 놓일 시트 위치를 탭하거나 클릭하면 핀이 그 위치를 표시합니다. 작업 일지는 핀 없이 열려 있는 시트에 들어가며, {{ui:핀 배치}}로 나중에 핀을 추가하고 {{ui:핀 이동}}으로 어떤 핀이든 옮길 수 있습니다. 각 기록에는 고유 번호(RFI-0001, SUB-0001, LOG-0001), 제목, 내용, 상태, 담당자, 기한, 답글 스레드, 첨부 파일 이름 목록이 있습니다. [RFI, 제출물, 작업 일지 추적](topic:field-records)을 참고하십시오.
- **늦어진 항목 확인.** 목록을 유형, 상태, 기한(기한 초과, 7일 이내 기한, 기한 있음 또는 없음), 이 시트 또는 모든 시트, 문자 검색, {{ui:나에게 할당됨}}으로 걸러 볼 수 있습니다. 기한이 지났는데 아직 대기 중인 기록은 목록과 핀에 빨간색 **기한 초과**로 표시됩니다. [중요한 항목 찾기](topic:field-records#find-what-matters)를 참고하십시오.
- **CSV와 BCF.** {{ui:CSV}}는 목록의 기록을 스프레드시트로, {{ui:BCF}}는 BCF 토픽으로 저장하며 각 토픽에는 시트 위 해당 위치의 스냅샷이 들어갑니다. 둘 다 필터를 따릅니다. [내보내기](topic:field-records#export)를 참고하십시오.
- **오프라인 작업, 그리고 두 사본을 하나로.** 기록은 PDF 안에 저장되며 네트워크가 필요 없으므로, 현장의 태블릿에서 추가, 응답, 저장할 수 있습니다. 사무실로 돌아오면 {{ui:병합}}이 같은 PDF의 다른 사본에 있는 기록을 ID로 합치며, 실행 취소 한 단계로 처리됩니다. [저장, 오프라인, 사본 병합](topic:field-records#save-offline-and-merging-copies)을 참고하십시오.

### AI 어시스턴트

- **어시스턴트가 할 수 있는 일이 늘었습니다.** CadCraft Studio를 통해 연결한 자신의 어시스턴트가 이제 마크업 상태를 설정하고(`markup_status`, 스레드에 기록됨), 스레드에 답글을 달고(`markup_reply`), {{ui:마크업}} 목록을 CSV 또는 BCF로 내보낼 수 있습니다(`markups_export`, 필터가 적용된 목록 그대로). 각 변경은 실행 취소 한 단계이며 어시스턴트의 이름이 서명됩니다. [어시스턴트가 요청할 수 있는 것](topic:use-with-ai-assistants#what-an-assistant-can-ask-for)을 참고하십시오.

## 모든 앱에서

- **단위.** {{ui:설정}} › {{ui:일반}} › {{ui:단위}}에는 길이, 면적, 부피, 각도, 경사별로 목록이 하나씩 있으며, 단위 정의가 정하는 정확한 크기를 사용합니다(미국 측량 피트는 별도 단위입니다). 쓰지 않는 단위를 끄면 단위 목록에서 사라지고, 단위에 별표를 하면 새 작업이 그 단위로 시작합니다. 파일은 항상 자기 단위를 유지합니다. MarkupCraft에서는 {{ui:설정}} › {{ui:MarkupCraft}}의 측정 및 위치 단위와 보정 대화상자의 단위가 이 스위치를 따르고, 별표는 MarkupCraft 자체 설정을 저장하기 전까지 측정 단위를 정하며, 보정할 때 입력하는 실제 거리에는 `3 yd`나 `1.5 km`처럼 어떤 단위의 표기든 붙일 수 있습니다. [단위, 입력값, 단위 목록](common:unit-lists)을 참고하십시오.
- **더 조밀한 레이아웃과 정리되는 패널.** {{ui:설정}} › {{ui:일반}} › {{ui:레이아웃 밀도}} › {{ui:조밀하게}}를 선택하면 화면에 더 많은 내용이 들어갑니다(터치 화면과 휴대폰은 큰 버튼을 유지합니다). 각 측면 패널에는 얇은 제목 표시줄이 있습니다. 끌어서 고정하거나 플로팅으로 만들 수 있고, 다른 패널의 표시줄에 놓으면 탭으로 한 프레임을 공유하며, 핀으로 고정해 가장자리로 밀어 넣을 수도, 숨겼다가 가장자리에서 다시 불러올 수도 있습니다. [패널 배치](common:arrange-panels#make-the-layout-denser)를 참고하십시오.
- **대화상자 이동.** 대화상자의 제목 표시줄을 끌어 도면을 가리지 않는 곳으로 옮기면, 놓아 둔 위치에 그대로 다시 나타납니다. 제목 표시줄을 더블클릭하면 다시 가운데로 돌아옵니다. [대화상자 이동](common:arrange-panels#move-a-dialog)을 참고하십시오.
- **AI 어시스턴트용 레시피.** 자신의 어시스턴트에게 요청하는 열 가지 실제 사례(도면 정리, 세트 플롯, 도면 검사, 모델에 질문, 물량 합산, 파트 변형 시험 등)이며, 각각 호출하는 도구와 필요한 권한이 적혀 있고 테스트로 재현해 확인했습니다. 앱에는 AI가 들어 있지 않습니다. [AI 어시스턴트용 레시피](common:assistants-recipes)를 참고하십시오.
- **언어.** {{ui:설정}} › {{ui:일반}} › {{ui:언어}}에 **Português (Portugal)**가 새로 추가되었습니다. 이 언어와 **Português (Brasil)**, **Español (México)**, **Bahasa Indonesia**는 이제 앱의 모든 문구가 번역되어 있으며, 원어민 검토를 거치지 않은 초안입니다. 도움말 항목은 영어로 제공됩니다.
- **CadCraft Studio**는 업데이트 확인이 실패하면 단순히 "완료"라고 표시하는 대신 이유(시스템용 파일 없음, 네트워크 없음, 잘못된 서명)를 알려 주며, 닫아 둔 새로운 기능 카드는 더 새로운 릴리스가 나오기 전까지 다시 표시하지 않습니다.

## 이 버전에 아직 없는 것

- **0.7은 코드 서명이 되어 있지 않습니다.** 인증서 검증이 아직 끝나지 않아 서명과 Microsoft Store 패키지는 0.8로 미뤄졌습니다. getcadcraft.com/download에서 각 파일 옆의 SHA-256을 확인하십시오. Windows에서 SmartScreen이 설치 프로그램을 막으면 {{ui:추가 정보}}를 선택한 다음 {{ui:실행}}을 선택하십시오. Mac에서는 처음 한 번 CadCraft Studio를 마우스 오른쪽 버튼으로 클릭하고 {{ui:열기}}를 선택하십시오. CadCraft Studio는 아직 앱 스토어에 없으며 iPad나 iPhone용 빌드도 아직 없습니다.
- {{ui:단위}}의 각도와 경사 목록은 저장되지만 아직 이를 읽는 입력란이 없습니다.
- 현장 기록은 CadCraft Live TeamWork 세션에서 공유되지 않습니다(Live 세션은 마크업만 전달합니다). 사본은 {{ui:병합}}으로 합치십시오.
- 병합은 마지막으로 변경된 사본의 기록을 통째로 가져옵니다. 두 사람이 한 기록의 서로 다른 필드를 바꾸었다면 나중 사본의 필드가 우선합니다. 스레드와 첨부 파일 이름은 합쳐집니다.
- 첨부는 이름만 기록되며 파일은 원래 위치에 남아 있습니다. 기록용 팀, 알림, 클라우드 프로젝트는 없고, 어시스턴트에게는 아직 기록용 도구가 없습니다.
- 현장 기록은 브라우저에서 휴대폰과 태블릿 크기로 네트워크를 끊고 테스트했지만, 실제 태블릿에서 직접 확인하지는 않았습니다.
- 0.6부터 계속되는 항목: 페이지 객체를 임의의 각도로 회전, 페이지에 직접 새 도형 그리기, 줄의 글꼴이나 크기 변경, 여러 줄로 흐르는 문자. 페이지를 편집해 저장한 사본은 아직 Acrobat에서 열어 보지 않았습니다.
- 0.5부터 계속되는 항목: 페이지 변경(빈 페이지 추가 등)의 실행 취소, 스캔한 시트의 문자 읽기, 자신의 네트워크를 벗어난 Live 세션.

그 밖의 모든 항목은 [아직 만들지 않은 기능](topic:not-built-yet)에 있습니다.
