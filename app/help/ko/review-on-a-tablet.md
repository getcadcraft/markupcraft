MarkupCraft는 터치를 지원합니다. iPad(Safari 또는 Chrome), 터치스크린 노트북, 또는 최신 브라우저를 갖춘 Windows 또는 Android 태블릿에서 사용할 수 있습니다. 가로 방향에서 태블릿은 전체 레이아웃을 표시합니다.

## 제스처

| 제스처 | 기능 |
|---|---|
| 한 손가락 | 현재 도구로 그리거나, {{ui:선택}}으로 선택합니다 |
| 두 손가락, 벌리거나 모으기 | 두 손가락 사이를 중심으로 확대/축소합니다 |
| 두 손가락, 함께 움직이기 | 초점을 이동합니다. 한 번의 동작으로 확대/축소와 초점 이동을 함께 할 수 있습니다 |
| 그리는 중 두 번째 손가락 | 첫 번째 손가락이 시작한 동작을 취소하고 대신 확대/축소를 시작합니다 |
| 두 번 탭, 또는 길게 누르기 | 폴리선, 폴리곤, 자유 구름 또는 면적을 완료합니다 |
| {{ui:선택}}을 켠 상태에서 텍스트, 콜아웃 또는 메모를 길게 누르기 | 편집할 텍스트를 엽니다 |
| {{ui:초점 이동}}을 켠 상태에서 한 손가락 | 초점을 이동합니다 |

터치 화면에서는 도구 모음 버튼, 메뉴, 탭, 대화상자 버튼이 더 커서 손가락으로 쉽게 누를 수 있습니다.

## 손을 뗄 때 일어나는 일

핀치의 첫 번째 손가락이 흔적을 남기지 않도록, 일부 도구는 손가락을 **뗄 때** 동작하며, 닿을 때는 동작하지 않습니다:

- {{ui:수량}}: 점은 손을 뗄 때 추가됩니다.
- {{ui:메모}}: 메모는 손을 뗄 때 놓입니다.
- {{ui:폴리선}}, {{ui:폴리곤}}, {{ui:자유 구름}}, {{ui:면적}}: 각 점은 손을 뗄 때 추가됩니다.
- {{ui:선}}, {{ui:화살표}}, {{ui:길이}}, {{ui:보정}}: 시작점을 탭한 다음 끝점을 탭하면, 끝점은 손을 뗄 때 놓입니다.

손가락을 떼기 전에 조금이라도 미끄러지면 탭으로 인정되지 않으며 아무것도 추가되지 않습니다. 깔끔하게 탭하십시오. 바로잡으려면 {{ui:실행 취소}}를 사용하십시오.

드래그하는 도구({{ui:펜}}, {{ui:강조 표시}}, {{ui:구름}}, {{ui:사각형}}, {{ui:타원}}, {{ui:콜아웃}}, {{ui:문자}}, {{ui:스탬프}})는 닿는 순간 시작하며, 두 번째 손가락은 이를 취소합니다.

## 손가락으로 선택하기

- 마크업을 탭하면 선택되고, 드래그하면 이동하며, 핸들을 드래그하면 크기가 조정됩니다. 손가락이 시트에 닿은 뒤에는 마크업과 핸들이 더 큰 대상을 차지하며, 핸들도 더 크게 그려집니다.
- 빈 시트 위를 드래그하여 선택 창을 그리십시오(왼쪽에서 오른쪽: 완전히 안에 있는 항목, 오른쪽에서 왼쪽: 닿은 항목).
- {{ui:선택}}에서는 한 손가락으로 초점이 **이동하지 않습니다**. 두 손가락을 쓰거나 {{ui:초점 이동}}을 선택하십시오.

## 키보드가 필요한 기능

키보드가 없으면 {{key:Shift}}, {{key:Esc}}, {{key:Enter}}가 없습니다. 대신 다음과 같이 하십시오:

| 키보드 동작 | 키보드가 없을 때 |
|---|---|
| {{key:Esc}}로 취소하거나 {{ui:선택}}으로 돌아가기 | 도구 모음의 {{ui:선택}}을 탭 |
| {{key:Shift}}로 45° 선, 정사각형, 원 그리기 | 조심해서 그리고 핸들로 조정하십시오 |
| {{key:Shift}}-클릭으로 선택에 추가 | 선택 창을 사용하십시오 |
| {{key:Shift}}-클릭으로 수량 점 제거 | 잘못 탭한 직후 {{ui:실행 취소}} |
| {{key:Mod+Enter}}로 입력 완료 | 텍스트 상자 밖을 탭하십시오 |
| {{key:Enter}}로 폴리선 완료 또는 마크업 텍스트 편집 | 길게 누르거나, {{ui:속성}}의 {{ui:시트에서 편집}}을 사용하십시오 |
| {{key:Delete}} | 도구 모음 또는 {{ui:속성}}의 {{ui:삭제}} |
| {{key:Esc}}로 새 수량 그룹 시작 | {{ui:선택}}으로 빈 시트를 탭한 다음 {{ui:수량}}을 다시 탭하십시오 |

키보드 케이스나 블루투스 키보드를 연결하면 모든 단축키가 다시 사용 가능합니다. iPad에서는 ⌘ 키로 {{key:Mod+Z}}와 나머지 단축키를 사용할 수 있습니다.

터치에서는 버튼의 툴팁이 표시되지 않습니다. 각 도구의 단축키는 [키보드와 마우스](topic:keyboard)에 나와 있습니다.

## 스타일러스와 Apple Pencil

스타일러스(Apple Pencil, Surface Pen 등)는 마우스처럼 작동합니다. 그리고 선택하며, 닿는 즉시 동작합니다. 핀치와 초점 이동에는 손가락을 사용하십시오. 압력은 선 너비를 바꾸지 않습니다.

## iPad에서 열기와 저장

- {{ui:열기}}는 파일 선택기를 표시합니다: iCloud Drive, 내 iPad, 그리고 연결한 저장 공간 앱.
- {{ui:저장}}하면 다운로드할지 묻습니다. 사본은 파일 앱의 다운로드 폴더(또는 Safari 설정에서 지정한 폴더)에 저장됩니다.

## 태블릿에서 작업 안전하게 지키기

:::warning
iPad Safari는 저장되지 않은 작업이 있는 페이지를 떠나기 전에 경고하지 않으며, iPadOS는 메모리를 확보하려고 백그라운드에서 탭을 다시 로드할 수 있습니다. MarkupCraft는 브라우저에 복구 사본을 보관하고 다시 열 때 이를 제안합니다([작업 복구](common:recover) 참고). 하지만 **시트마다 또는 현장을 한 바퀴 돌 때마다 저장하십시오**. 비공개 탭은 사본을 보관하지 않습니다.
:::

- 이름, 도구 설정, 도구 상자는 컴퓨터에서와 마찬가지로 그 iPad의 해당 브라우저에 보관됩니다. [이 브라우저에 저장되는 항목](topic:browser-storage)을 참고하십시오.
- **신호가 없는 현장 방문 전에:** 아직 온라인일 때 iPad의 Safari(또는 Chrome)에서 MarkupCraft를 열고, 상단 표시줄에서 {{ui:오프라인용 저장}}을 선택하십시오. "오프라인 사용 준비 완료"가 표시될 때까지 기다리십시오(진행은 "저장 중 N/M"으로 표시되며, PDF 리더와 작성기는 약 6 MB입니다). 현장에서는 같은 주소나 그 책갈피를 여십시오. PDF를 열고, 마크업하고, 저장하는 작업은 연결 없이도 작동합니다. "오프라인 사용 불가"가 표시되면 비공개 탭에 있는 것이므로 일반 탭을 사용하십시오. [오프라인 작업](common:offline)을 참고하십시오.
- Safari는 몇 주 동안 사용하지 않은 오프라인 사본을 삭제합니다. 여행 전에 "오프라인 사용 준비 완료"를 클릭하고 "다시 저장(최신 버전 받기)"을 선택하십시오.
- 매우 큰 도면 세트는 메모리를 많이 사용합니다. 태블릿에서는 이번 방문에 필요한 시트만 여십시오.

## 휴대폰에서

작동은 하지만 화면이 작습니다. 부품들이 세로로 쌓이고(도구 모음, 시트, 상태 표시줄, 패널, 그다음 시트 목록), 도구 모음은 가로로 스크롤됩니다. 휴대폰은 보거나 간단한 메모를 추가하는 데 사용하고, 실제 검토는 태블릿이나 컴퓨터에서 하십시오.
