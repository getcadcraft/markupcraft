## 이 문서에서 배우는 내용

AI 어시스턴트(또는 직접 작성한 스크립트)가 MarkupCraft와 함께 작업하도록 설정하는 방법, 그리고 어시스턴트가 무엇을 건드릴 수 있는지 정하는 방법입니다.

MarkupCraft에는 **자체 AI가 없으며** 어디에도 아무것도 보내지 않습니다. 어시스턴트는 직접 준비합니다. 모델 컨텍스트 프로토콜(MCP)을 사용하는 프로그램이면 무엇이든 가능합니다. MarkupCraft는 도구만 제공하며, 어떤 도구를 줄지는 직접 고릅니다.

## 켜기

1. {{ui:Settings}}을 엽니다(앱 상단 표시줄의 톱니바퀴 또는 {{key:Mod+,}}). 그다음 {{ui:MarkupCraft}} 탭으로 이동합니다.
2. {{ui:Assistants}} 아래에서 **AI 어시스턴트와 스크립트가 MarkupCraft를 사용하도록 허용**을 체크합니다. 체크하기 전까지는 꺼져 있습니다.
3. 어시스턴트가 할 수 있는 작업을 고릅니다. **읽기**는 처음부터 체크되어 있습니다. **편집**, **저장**, **내보내기**는 필요할 때만 체크하십시오.

체크하지 않은 권한 밖의 도구는 어시스턴트에게 제공되지 않습니다. 어시스턴트가 그래도 요청하면 MarkupCraft가 거부하고 활동 기록에 남깁니다. 스위치를 끄면 모든 연결이 한꺼번에 끝납니다. {{ui:Reset MarkupCraft settings}}를 해도 꺼집니다.

## 어시스턴트 연결

어시스턴트는 이 컴퓨터의 **CadCraft Studio**를 통해 연결됩니다. Studio는 이 컴퓨터에서만 접근할 수 있는 작은 서버를 실행하며, 시작할 때마다 새로 만드는 토큰으로 보호됩니다. Studio에서 {{ui:Connect an assistant}}을 선택하고, 주소와 토큰을 어시스턴트에 복사합니다(Studio가 붙여넣을 정확한 설정을 보여 줍니다). 토큰은 절대 공유하지 마십시오.

:::note
브라우저 탭은 어시스턴트 연결을 열 수 없습니다. 브라우저 앱에서는 이 컴퓨터의 CadCraft Studio를 사용하기 전까지 스위치가 효과가 없습니다.
:::

## 주도권은 사용자에게 있습니다

- **모든 변경은 실행 취소 한 단계**이며, 어시스턴트 이름을 붙인 라벨로 표시됩니다(예: "Assistant: add cloudrect"). {{key:Mod+Z}}를 누르면 어시스턴트의 마지막 변경을 한꺼번에 되돌립니다.
- **연결되었는지 알 수 있습니다.** 연결되어 있는 동안 앱 상단 표시줄의 버튼에 어시스턴트 이름이 표시됩니다. 버튼을 클릭하면 어시스턴트가 할 수 있는 작업을 보거나 **연결 해제**할 수 있습니다.
- **활동.** {{ui:Settings}} › {{ui:MarkupCraft}} › {{ui:Assistants}} › {{ui:Activity}}에서 모든 호출을 볼 수 있습니다. 시각, 도구, 완료 또는 거부 여부가 나열됩니다. {{ui:Save the log}}을 선택하면 사본이 보관됩니다.

## 어시스턴트가 요청할 수 있는 것

| 도구 | 권한 | 기능 |
|---|---|---|
| `app_info`, `sheets_list` | 읽기 | 열린 세트, 각 세트의 시트, 시트별 마크업 개수 |
| `markups_list` | 읽기 | 마크업을 종류, 시트, 텍스트, 주석, 측정값, 상태, 작성자, 답글과 함께 나열하며, 시트, 상태, 종류 또는 작성자로 필터링 |
| `markup_add` | 편집 | 시트에 사각형, 구름, 타원, 문자 상자, 메모, 선 또는 화살표를 추가 |
| `markup_status`, `markup_reply` | 편집 | 마크업의 상태를 설정(스레드에 기록되며 어시스턴트 서명이 붙음). 스레드에 주석을 추가 |
| `markups_export` | 내보내기 | {{ui:Markups}} 목록이 보여 주는 내용(설정한 필터 그대로)을 CSV 또는 BCF로 내보냄. Studio에서는 허용한 폴더에 파일을 쓸 수 있음 |
| `tasks_list` | 읽기 | 작업으로 지정된 마크업: 담당자(사람 또는 어시스턴트), 마감일, 상태, 링크, 종료 방식. `assignee: "assistant"`는 어시스턴트를 기다리는 작업을 나열 |
| `task_set`, `task_clear` | 편집 | 마크업을 작업으로 만들거나 바꿈(제목, 담당자, 마감, 상태, 링크). 작업에서 해제 |
| `tasks_check` | 편집 | 연결된 도면 영역이나 모델 요소가 실제로 바뀐 작업을 닫음. 다른 앱에서 읽은 요소 상태를 전달 |
| `revisions_changes` | 읽기 | 열려 있는 두 도면 세트 사이에서 바뀐 내용을 평이하게 나열(직접 설명을 쓸 때 사용) |
| `pins_list`, `decision_add` | 읽기, 편집 | 음성 메모(길이, 작성자, 시각, 설명. 음성 자체와 텍스트 변환은 제외)와 결정 사항. 결정을 고정하고 이전 결정을 대체 |
| `redline_export`, `redline_answer` | 내보내기, 편집 | 도면 작성자용 레드라인 파일을 쓰고, 작성자의 답변을 적용 |

어시스턴트가 추가한 마크업의 작성자는 어시스턴트 프로그램이 스스로 정한 이름 뒤에 "(assistant)"가 붙거나, 검토자 이름을 설정한 뒤에는 "(assistant for <your name>)"로 표시됩니다. 상태 변경과 답글도 같은 방식으로 서명됩니다. 각 변경은 실행 취소 한 단계입니다. 주석이 달린 PDF 저장은 사용자가 직접 합니다. 평소처럼 {{ui:Save}}을 사용하십시오.

MarkupCraft를 열지 않고도 CadCraft MCP 서버가 지정한 폴더의 PDF 마크업을 나열할 수 있습니다(`markups_list`). `cadcraft info Set.pdf`는 명령행에 이를 출력합니다.

## 작동하지 않을 때

- **어시스턴트에 MarkupCraft 도구가 보이지 않음:** 이 창에서 스위치가 켜져 있는지, 그리고 Studio에서 이 창이 열려 있는지 확인하십시오.
- **"편집 권한이 필요합니다":** {{ui:Assistants}} 아래에서 **편집**을 체크한 다음 다시 요청하십시오.
- **"401" 또는 "token" 오류:** 토큰이 바뀌었습니다(Studio를 다시 시작했거나, {{ui:New token}}을 선택한 경우). 새 토큰을 어시스턴트 설정에 복사하십시오.
