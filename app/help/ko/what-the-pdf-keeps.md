마크업된 사본은 원본 PDF에 댓글(PDF 주석)을 추가한 것입니다. 페이지 자체, 즉 도면, 텍스트, 책갈피, 링크는 원래대로 복사됩니다.

## 마크업 유형별

| MarkupCraft | 저장 형식 | 다른 PDF 뷰어에서 보이는 모습 |
|---|---|---|
| 사각형, 상자 구름 | Square 주석 (구름: 구름 모양 테두리) | 사각형 또는 구름 댓글 |
| 타원 | Circle 주석 | 타원 댓글 |
| 폴리곤, 자유형 구름 | Polygon 주석 (구름: 구름 모양 테두리) | 폴리곤 또는 구름 댓글 |
| 폴리선 | PolyLine 주석 | 폴리선 댓글 |
| 선, 화살표 | Line 주석 (화살표: 닫힌 화살촉) | 선 또는 화살표 댓글 |
| 길이 | 측정값이 있는, 치수로 표시된 Line 주석 | 뷰어가 지원하면 길이 측정 |
| 면적 | 측정값이 있는, 면적으로 표시된 Polygon 주석 | 지원하면 면적 측정, 그렇지 않으면 폴리곤 |
| 개수 그룹 | 항목마다 고리가 있는 Ink 주석 하나, 텍스트는 "group: n" | Ink 댓글 |
| 펜, 형광펜 | Ink 주석 (형광펜은 그렇게 표시) | Ink 댓글 |
| 문자 | FreeText 주석 | 텍스트 상자 댓글 |
| 콜아웃 | 지시선이 있는 FreeText 주석 | 콜아웃 댓글 |
| 메모 | Text 주석 | 열면 텍스트가 나오는 스티커 메모 |
| 스탬프 | Stamp 주석 | 스탬프 댓글 |

모든 항목은 다음과 함께 저장됩니다:

- **고유 모양**: MarkupCraft가 화면에 그리는 그대로 그려지므로 어떤 뷰어에서도 같아 보이고 같게 인쇄되며, 펀치 번호 배지도 포함됩니다;
- **작성자**, **생성일과 수정일**, **제목**, **댓글 텍스트**(텍스트 상자와 콜아웃의 경우 텍스트와 댓글), **색상**, **불투명도**;
- 다른 프로그램이 무시하는 비공개 항목에 저장된 **MarkupCraft 세부 정보**(상태, 펀치 항목, 스타일과 유형)이므로 정확히 다시 열립니다.

## 스레드와 상태

- 각 답글은 해당 마크업에 연결된 답글 댓글로, 작성자, 날짜, 텍스트와 함께 저장됩니다. 답글은 시트에 자체 아이콘이 없습니다.
- 상태가 바뀔 때마다 검토 상태를 담은 답글로 저장됩니다. 다른 검토 도구는 이를 Accepted, Rejected 또는 Completed로 표시하며, Open은 상태 없음으로 저장됩니다.
- Open이 아닌 상태가 있는데 기록된 상태 변경이 없는 마크업에는 검토 상태 답글이 하나 추가되어, 다른 프로그램도 상태를 볼 수 있습니다.
- 원본 파일의 읽기 전용 댓글에 대한 답글도 같은 방식으로, 그 댓글에 연결되어 저장됩니다.

## 각 시트

- **축척:** 보정된 시트는 페이지를 덮는 측정 뷰포트(페이지 축척을 저장하는 표준 방법)와 MarkupCraft 자체의 보정 사본을 받습니다.
- **시트 번호:** {{ui:시트 이름 바꾸기}}에서 입력한 번호가 페이지 레이블이 됩니다. 파일의 어느 한 페이지에라도 레이블이 있으면 그 파일의 모든 페이지에 레이블이 붙습니다. 입력한 번호가 있으면 그 번호를, 없으면 기존 레이블을, 그것도 없으면 페이지 번호를 씁니다.
- **시트 제목:** 입력한 제목은 MarkupCraft용으로만 저장되며 다른 뷰어에는 보이지 않습니다.

## 텍스트와 문자

텍스트는 모든 PDF 뷰어에 있는 Helvetica 글꼴로 씁니다. 서유럽 문자 집합(Windows-1252) 밖의 문자는 사본에서 "?"로 인쇄됩니다. 저장 메시지에 그런 문자의 개수가 표시됩니다.

## 계산 시트와 근거

계산 시트와 근거는 파일 안의 `/MarkupCraftShell`이라는 비공개 항목에 보관됩니다. 다른 PDF 프로그램은 이를 무시합니다. 이전 버전의 MarkupCraft도 이를 무시하며, 그 파일을 다음에 저장할 때 삭제합니다.

## 원래 있던 댓글은 어떻게 되는가

이미 댓글이 있는 PDF를 열면:

- MarkupCraft의 댓글은 정확히 다시 읽힙니다. 다른 프로그램이 위치나 크기를 바꾸었다면 그 새 위치가 우선합니다.
- 다른 프로그램의 사각형, 타원, 선, 폴리선, 폴리곤, 잉크, 텍스트 상자, 스티커 메모는 편집 가능한 마크업이 됩니다. **저장하면 MarkupCraft가 원본을 제거하고, 팝업과 답글을 포함해 자기 방식으로 다시 씁니다.** 모양이 약간 바뀔 수 있습니다.
- 다른 프로그램의 검토 상태는 상태를 설정하며, 가장 최근 것이 우선합니다.
- 그 밖의 항목(텍스트 강조, 다른 프로그램의 스탬프와 특수 종류)은 사본에 **변경 없이 유지**되며 읽기 전용입니다.
- 링크와 양식 필드는 변경 없이 유지되며 목록에 나오지 않습니다.

같은 파일을 다시 저장해도 아무것도 두 번 생기지 않습니다. MarkupCraft가 읽은 마크업은 추가되는 것이 아니라 교체됩니다.

## 변경되지 않는 것

디스크에 있는 원본 파일은 절대 변경되지 않습니다. 사본은 크기 최적화를 하지 않으므로 원본보다 다소 클 수 있습니다. 보호된(암호화된) PDF는 저장할 수 없습니다.
