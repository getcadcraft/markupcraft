## 길이 입력

두 점으로 보정할 때는 실제 거리를 입력합니다. MarkupCraft는 다음 형식을 모두 인식합니다:

| 입력 | 의미 |
|---|---|
| `24'-0"` | 24피트 |
| `12' 6 1/2"` 또는 `12'-6 1/2"` | 12피트 6½인치 |
| `12' 6` | 12피트 6인치(인치 기호 생략) |
| `6"` 또는 `1/2"` | 인치 |
| `12.5'` 또는 `12.5 ft` | 12½피트 |
| `3 ft 6 in` | 3피트 6인치(feet, foot, inch, inches도 가능) |
| `3.5 m`, `90 cm`, `900 mm` | 미터법(meter, metre, millimeter, centimetre…도 가능) |
| `24` | 단위 없는 숫자. {{ui:Show lengths in}}에서 고른 단위로 입력됨 |

곡선 따옴표(’ ”)와 인치를 나타내는 두 개의 아포스트로피('')도 사용할 수 있습니다. 0이나 음수 길이는 거부됩니다.

:::warning
쉼표는 소수점으로 읽힙니다: `1,5 m`는 1.5미터입니다. 천 단위 구분 기호를 입력하지 마십시오. `1,200 mm`는 1.2밀리미터로 읽힙니다. `1200 mm`로 입력하십시오.
:::

## 길이와 면적 표시 방식

| {{ui:Show lengths in}} | 길이 표시 형식 | 면적 표시 형식 |
|---|---|---|
| {{ui:Feet and inches}} | `12'-6 1/2"`(1/16"로 반올림) | 제곱피트, 소수점 둘째 자리 |
| {{ui:Decimal feet}} | `12.54'`(소수점 둘째 자리) | 제곱피트, 소수점 둘째 자리 |
| {{ui:Inches}} | `150.5"`(소수점 둘째 자리까지) | 제곱인치, 소수점 첫째 자리 |
| {{ui:Meters}} | `3.820 m`(소수점 셋째 자리) | 제곱미터, 소수점 셋째 자리 |
| {{ui:Millimeters}} | `3820 mm`(정수 밀리미터) | 제곱밀리미터, 정수 |

면적의 둘레는 길이 형식을 사용합니다.

## 미리 설정된 축척

미리 설정된 축척은 PDF가 실제 인쇄 크기라고 가정합니다. CAD 프로그램이 플롯하는 방식처럼 1인치당 72 PDF 포인트입니다.

| 그룹 | 축척 | 길이 표시 단위 |
|---|---|---|
| 건축 | 1/32" = 1'-0", 1/16", 3/32", 1/8", 3/16", 1/4", 3/8", 1/2", 3/4", 1", 1 1/2", 3" = 1'-0" | 피트와 인치 |
| 공학 | 1" = 10', 20', 30', 40', 50', 60', 100' | 십진 피트 |
| 미터법 | 1:1, 1:5, 1:10, 1:20, 1:25, 1:50 | 밀리미터 |
| 미터법 | 1:100, 1:200, 1:250, 1:500, 1:1000 | 미터 |

미리 설정된 축척을 쓰면서 길이를 다른 단위로 보고 싶다면, 대신 두 점으로 보정하고 그곳에서 단위를 고르십시오.

## 다른 프로그램이 저장한 축척

PDF에 다른 프로그램이 페이지용으로 저장한 축척(페이지에 저장된 측정 축척)이 있으면, 그것이 피트, 인치, 미터, 센티미터 또는 밀리미터 단위일 때 MarkupCraft가 이를 사용합니다. 그 표시 이름은 파일에 적힌 그대로 나타납니다.

## 용지 위치

상태 표시줄에는 시트의 축척과 상관없이, 포인터가 용지 위에서 시트의 왼쪽 위 모서리로부터 몇 인치 떨어져 있는지 표시됩니다. Compare의 미세 이동 단계는 포인트 단위입니다(1인치당 72포인트).

## 정확도

측정의 정확도는 보정과 클릭의 정확도에 달려 있습니다. 찾을 수 있는 가장 긴 기지 치수로 보정하고, 끝점을 클릭할 때는 줌을 확대한 다음, 다른 치수 하나를 확인하십시오. 작성할 때 축척이 조정된 PDF("페이지에 맞춤" 플롯이나 절반 크기 세트)도 치수로 보정하면 정확하지만, 미리 설정된 축척으로는 그렇지 않습니다.
