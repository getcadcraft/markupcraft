도면의 새 판이 도착하면 슬립 시트로 검토를 새 판에 옮길 수 있습니다. 각 새 시트는 같은 번호를 가진 기존 시트의 마크업을 가져오고, 기존 시트에는 "대체됨" 스탬프가 찍힙니다.

## 슬립 시트 적용

1. 마크업이 들어 있는 현재 세트를 여십시오.
2. {{ui:페이지}}를 선택한 다음 {{ui:개정된 세트 슬립 시트…}}를 선택하고 새 PDF를 고르십시오. 새 PDF는 기존 세트 옆에 열립니다.
3. 대화상자에 새 시트마다 대체하는 기존 시트가 나열됩니다. 행의 체크를 해제하면 그 시트의 마크업은 원래 자리에 남습니다. 새 번호를 가진 시트에는 옮길 것이 없습니다.
4. 닫힌 마크업(수락됨, 거부됨, 완료됨)을 기존 시트에 남길지, 그리고 기존 시트에 스탬프를 찍을지 선택하십시오.
5. {{ui:마크업 옮기기}}를 선택하십시오.

결과: 마크업이 새 시트의 같은 위치에 답글, 상태, 작성자와 함께 나타납니다. 펀치 항목은 새 시트로 옮겨지며 번호를 유지합니다. 기존 시트는 붉은 "대체됨" 스탬프 아래에 마크업을 기록으로 보존합니다. 상태 표시줄에 옮겨진 내용이 요약됩니다.

{{ui:파일만 열기}}는 아무것도 옮기지 않고 새 세트만 엽니다. 예를 들어 먼저 비교해 보고 싶을 때 사용합니다. 참조: [두 개정판 비교](topic:compare-revisions).

## 시트가 맞춰지는 방식

- **시트 번호 기준**: 시트 목록에 표시되는 번호를 따릅니다. 즉 {{ui:시트 이름 바꾸기}}로 입력한 번호, PDF의 페이지 레이블, 또는 표제란의 번호입니다. 대소문자, 공백, 점, 대시는 무시됩니다. "A-101"과 "a101"은 일치합니다.
- 열린 두 파일에 같은 번호의 시트가 있으면 더 최신 것이 대체되므로, 판을 계속 바꾸며 슬립 시트를 적용할 수 있습니다.
- **스캔된 세트**에는 읽을 번호가 없습니다. 새 파일에 번호가 없으면, 페이지는 페이지 순서대로 같은 페이지 수를 가진 열린 파일과 맞춰집니다. 옮기기 전에 그 행들을 확인하십시오.

## 참고 사항

- {{key:Mod+Z}} 키를 한 번 누르면 슬립 시트 전체(복사본, 스탬프, 옮겨진 펀치 항목)가 취소됩니다. 새 파일은 열린 상태로 남습니다.
- 새 시트의 크기가 다르면 마크업이 페이지와 함께 축척 조정되며, 상태 표시줄에 확인해야 할 개수가 표시됩니다.
- 새 시트의 크기가 같고 축척이 없으면, 기존 시트의 축척이 함께 가져와집니다.
- 다른 프로그램이 만든 코멘트는 기존 시트에 남으며, 여기서는 읽기 전용입니다.
- 옮긴 마크업을 유지하려면 새 파일을 저장하십시오. 참조: [마크업된 PDF 저장](topic:save-the-marked-up-pdf).
