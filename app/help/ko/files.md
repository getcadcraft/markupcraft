## MarkupCraft가 여는 파일

| 파일 | 방법 | 결과 |
|---|---|---|
| PDF (`.pdf`) | {{ui:열기}}, {{key:Mod+O}}, 또는 시트 영역에 끌어다 놓기. 여러 개를 한꺼번에 열어도 됩니다. | 모든 페이지가 시트가 됩니다. 파일에 이미 들어 있는 마크업을 다시 읽어 옵니다(아래 참고). |
| 도구 상자 (`.json`) | {{ui:도구}} 탭, 그다음 {{ui:가져오기}} | 도구가 도구 상자에 추가됩니다. [도구 상자](topic:tool-chest)를 참고하십시오. |

그 밖의 파일은 상태 표시줄에 "MarkupCraft는 PDF 파일을 엽니다."라고 표시되며 열리지 않습니다. 여러 종류를 함께 끌어다 놓으면 PDF만 열리고, PDF가 아닌 파일이 몇 개였는지 상태 표시줄에 표시됩니다.

### PDF에 이미 들어 있는 마크업

- **MarkupCraft가 저장한 마크업**은 그대로 돌아옵니다. 유형, 스타일, 작성자, 날짜, 상태, 답글, 펀치 번호, 시트의 축척, 직접 입력한 시트 이름이 모두 복원됩니다.
- **다른 PDF 프로그램의 주석**도 읽습니다. 사각형, 타원, 선과 화살표, 폴리선, 폴리곤, 잉크(펜) 획, 문자 상자, 스티커 메모는 편집할 수 있는 일반 MarkupCraft 마크업이 됩니다. 이들의 답글과 검토 상태도 함께 가져옵니다.
- **그 밖의 모든 것**(문자를 선택해서 만든 문자 강조 표시, 다른 프로그램의 스탬프, 기타 종류)은 있는 그대로 읽기 전용으로 표시됩니다. 선택하거나 마크업 목록에서 보거나 답글을 달 수는 있지만, 이동, 변경, 삭제는 할 수 없습니다.
- 링크와 양식 필드는 건드리지 않으며 목록에도 나타나지 않습니다.
- 다른 프로그램이 저장한 축척(측정 뷰포트)은 MarkupCraft가 그 단위를 이해하면 시트의 축척으로 사용합니다.

### 열리지 않는 파일

- 암호가 필요한 PDF: '"name" 파일을 열려면 암호가 필요합니다. 보호되지 않은 복사본을 여십시오.'
- 손상된 파일 또는 실제로는 PDF가 아닌 파일: '"name" 파일을 PDF로 읽을 수 없습니다 (…)'.
- 열리지만 변경이 보호된 PDF는 문제없이 열립니다. 다만 저장은 거부됩니다(아래 참고).

여러 파일을 한꺼번에 열면 열 수 있는 파일은 열리고, 나머지는 "일부 파일을 열 수 없었습니다"라는 상자에 나열됩니다.

## MarkupCraft가 저장하는 파일

저장은 항상 새 파일을 **다운로드**하는 방식입니다. 웹 페이지는 컴퓨터에 있는 파일을 덮어쓸 수 없으며, MarkupCraft는 원본을 절대 변경하지 않습니다.

| 선택 | 결과 | 참고 |
|---|---|---|
| {{ui:저장}} ({{key:Mod+S}}) | "<name> (marked up).pdf" | 모든 마크업이 실제 PDF 주석으로 기록된 원본 PDF의 사본입니다. "(marked up)" 파일을 다시 저장해도 같은 이름이 유지되며 "(marked up) (marked up)"가 되지 않습니다. [마크업한 PDF 저장](topic:save-the-marked-up-pdf)을 참고하십시오. |
| {{ui:마크업}} 탭, 그다음 {{ui:CSV}} | "<name> markups.csv" | 목록에 표시된 대로의 마크업입니다(필터 적용). |
| {{ui:마크업}} 탭, 그다음 {{ui:BCF}} | "<name> markups.bcfzip" | BIM 협업 도구용 BCF 2.1이며, 마크업마다 스냅샷이 하나씩 들어갑니다. [BCF 기초](topic:bcf-basics)를 참고하십시오. |
| {{ui:펀치 리스트}} 탭, 그다음 {{ui:CSV 내보내기}} | "<name> punch list.csv" | 펀치 항목이 번호 순서로 들어갑니다. |
| {{ui:도구}} 탭, 그다음 {{ui:내보내기}} | "MarkupCraft tool chest.json" | 공유하거나 보관할 수 있는 도구 상자입니다. |

"<name>"은 처음 연 PDF의 파일 이름에서 ".pdf"를 뺀 것입니다.

CSV 파일은 어떤 스프레드시트에서도 열립니다. UTF-8이며 스프레드시트가 찾는 표식이 들어 있어 악센트가 있는 이름도 올바르게 표시됩니다. =, +, - 또는 @로 시작하는 셀에는 맨 앞에 아포스트로피가 붙어, 스프레드시트가 수식으로 실행하는 일이 없습니다.

## 다운로드가 저장되는 위치

브라우저에 따라 결정됩니다. 보통은 다운로드 폴더이며, 그렇게 설정해 두었다면 매번 묻습니다. [브라우저와 컴퓨터](common:browsers#what-differs-between-browsers)를 참고하십시오.

:::chromium
세트에서 변경된 파일을 모두 한꺼번에 저장하면 Chrome과 Edge가 이 사이트에서 여러 파일을 다운로드해도 되는지 물을 수 있습니다. {{ui:허용}}을 선택하십시오. 그렇지 않으면 첫 번째 사본만 받게 됩니다.
:::

:::safari
iPad에서는 Safari가 다운로드할 때마다 묻고, 파일은 파일 앱의 다운로드 폴더에 저장됩니다. Mac에서는 Safari 설정에서 지정한 폴더로 갑니다.
:::

## 온라인과 오프라인

- **PDF는 이 컴퓨터를 떠나지 않습니다.** 온라인이든 오프라인이든 마찬가지이며 어디로도 업로드되지 않습니다.
- PDF 리더는 PDF를 처음 열 때("PDF 리더를 불러오는 중…"), PDF 쓰기 도구는 처음 저장할 때("PDF 쓰기 도구를 불러오는 중…") 또는 이미 주석이 들어 있는 파일을 열 때 불러옵니다.
- 연결되어 있으면 둘 다 웹사이트에서 불러옵니다.
- **연결 없이 작업하려면** 온라인 상태일 때 맨 위 막대에서 {{ui:오프라인용 저장}}을 선택하십시오. 버튼에 "N / M 저장 중"이 표시되다가 "오프라인 사용 준비됨"으로 바뀝니다. 이 사본에는 PDF 리더와 PDF 쓰기 도구(합계 약 6 MB)와 이 도움말이 들어 있으므로, 이후에는 이 브라우저에서 PDF 열기, 마크업, 저장이 모두 오프라인으로 동작합니다.
- 버튼에 "저장하지 못했습니다"라고 표시되면 일부 파일이 다운로드되지 않은 것입니다. 연결을 확인하고 버튼을 다시 클릭하십시오. "오프라인 사용 불가"라고 표시되면 이 브라우저 창에는 오프라인 사본을 보관할 수 없습니다(비공개 창, 일부 관리형 컴퓨터). 일반 창을 사용하십시오.
- 사본을 업데이트하거나 삭제하려면 "오프라인 사용 준비됨"을 클릭한 뒤 "다시 저장 (최신 버전 받기)" 또는 "오프라인 사본 제거"를 선택하십시오. 자세한 내용은 [오프라인으로 작업하기](common:offline)에 있습니다.

:::offline
오프라인 상태입니다. 맨 위 막대에 "오프라인 사용 준비됨"이 표시되어 있으면 저장을 포함한 모든 기능이 동작합니다. 표시되어 있지 않고 이 탭에서 아직 저장한 적이 없다면 {{ui:저장}}이 "PDF 쓰기 도구를 불러올 수 없습니다"라는 메시지와 함께 실패할 수 있습니다. 마크업은 탭에 그대로 남아 있으므로 탭을 닫지 말고 다시 온라인이 된 뒤 {{ui:저장}}을 다시 선택하십시오.
:::

## 알아 둘 점

- 큰 도면 세트는 여는 데 시간이 걸립니다. MarkupCraft가 시트 번호를 찾으려고 모든 페이지의 문자를 읽기 때문입니다. 상태 표시줄에 진행되는 시트 수가 표시됩니다.
- 같은 PDF를 두 번 열면 그 시트가 두 번 추가됩니다. 이런 경우에는 세트를 닫고 다시 여십시오.
- {{ui:닫기}}는 열려 있는 모든 파일을 한꺼번에 닫습니다. 저장하지 않은 마크업이 있으면 {{ui:취소}}, {{ui:저장하지 않고 닫기}}, {{ui:먼저 사본 저장}} 중에서 묻습니다.
- 클라우드 저장은 아직 지원하지 않으며, 데스크톱 빌드도 아직 없습니다. PDF는 다른 프로젝트 파일과 함께 보관하고 평소처럼 백업하십시오. [파일이 저장되는 위치](common:your-files)를 참고하십시오.
