Пландар топтому көбүнчө дисциплинага бир PDF же барakka бир PDF болуп келет. MarkupCraft ачкан бардыгын **бир топтом** катары кабыл алат.

## Бирге ачуу

Файл тандагычта бардык PDFтерди бир жолу тандаңыз же алардын баарын барak аймагына таштаңыз. Кийинчерээк көбүрөөк кошуу үчүн аларды ушул жол менен ачыңыз; алар ачылган тартипте {{ui:Барактар}} тизмесинин аягына кошулат.

Натыйжа: «6 файл ачылды (топтомдо 84 барак).» Ар бир бет — барak. Барак номери бар барактарда аты астында «Барak A-101» көрсөтүлөт; башкаларында файл жана бет көрсөтүлөт.

Топтом катары сакталган файл жок: кийинки жолу ошол эле PDFтерди кайра ачыңыз (сактаган болсоңуз, «(marked up)» көчүрмөлөрүн).

## Бүт топтом боюнча

- **Барak табуу:** {{ui:Барактарды издөө}} ар бир файлдын барак номерлерин, барak аттарын жана файл аттарын издейт. {{key:PageUp}} жана {{key:PageDown}} бардык файлдардын бардык барактарын тартип менен аралайт.
- **Белгилөөлөр тизмеси:** {{ui:Белгилөөлөр}} өтмөгү бардык файлдардын белгилөөлөрүн тизмелейт. {{ui:Барak}} боюнча чыпкалап, тарыңыз. CSVде File тулкусу бар.
- **Punch тизмеси:** бүт топтом үчүн бир номерлөө.
- **Салыштыруу:** эски жана жаңы барak ар башка файлдардан болушу мүмкүн.
- **Көчүрүү жана чаптоо:** бир барakta {{key:Mod+C}}, башка барakta {{key:Mod+V}} — каалаган файлда. Көчүрмө барактагы ошол эле жерге, бир аз жылышып түшөт.

## Сактоо

{{ui:Сактоо}} тандаңыз. Бир нече файл ачык болсо, MarkupCraft сурайт:

- {{ui:Бул файл}}: сиз турган барakка тиешелүү файлдын белгиленген көчүрмөсү.
- {{ui:Өзгөрүүлөрү бар бардык файлдар}}: өзгөртүлгөн, сакталбаган ар бир файлдын көчүрмөсү. Ар бири өзүнчө жүктөлөт, аталышы: «<file name> (marked up).pdf».
- {{ui:Жокко чыгаруу}}

:::chromium
Бир нече файлды биринчи жолу бир учурда сактаганда, Chrome жана Edge бул сайтка бир нече файл жүктөөгө уруксат берүүнү сурашы мүмкүн. {{ui:Уруксат берүү}} тандаңыз; болбосо биринчи көчүрмө гана келет.
:::

:::safari
Safari ар бир файл үчүн бир жолудан сурашы мүмкүн. iPadде ар бир көчүрмө Files колдонмосуна барат.
:::

Белгилөөлөрү сакталган файл өзгөргөн деп эсептелбейт; калгандары дагы эсептелет.

CSV, BCF жана punch тизмесинин экспорту **биринчи** ачкан файлдын атынан аталат.

## Жабуу

{{ui:Жабуу}} бүт топтомду жабат; азырынча бир файлды гана жабуунун жолу жок. Сакталбаган нерсе болсо, сурайт:

- {{ui:Жокко чыгаруу}}: эч нерсе болбойт.
- {{ui:Сактабай жабуу}}: сакталбаган белгилөөлөр жоголот.
- {{ui:Адегенде көчүрмөлөрдү сактоо}}: өзгөртүлгөн ар бир файлды сактап, андан кийин жабат.

Жабуу артка кайтаруу тарыхын да тазалайт.

## Чоң топтомдор

- Барактардын номерлерин табуу үчүн ачканда ар бир баракт тексти окулат, ошондуктан 100 барактуу топтом убакытты алат. Статус тилкеси барактарды санап турат.
- Тизмедеги барak сүрөттөрү аларга сүрөт жетип келгенде тартылат.
- Ачык ар бир PDF браузер өтмөгүнүн эс тутумунда сакталат. Өтмөк жайлап калса, башка оор өтмөктөрдү жабыңыз же дисциплиналарды бирден карап чыгыңыз.
- Бир эле файлды эки жолу ачсаңыз, анын барактарынын эки көчүрмөсү болот. Ушундай болсо, {{ui:Жабуу}} тандап, топтомду кайра ачыңыз.
