Эки адам бир PDFти эки көчүрмөдө белгилейт. Алар ар башка белгилөөлөргө тийишкен болсо, көчүрмөлөрдү программа бириктирет, кол менен эмес.

## Ал кантип иштейт

MarkupCraft сактаган ар бир белгилөө PDF ичинде өз атын (идентификаторун) алып жүрөт, жана бул ат эч качан өзгөрбөйт. Бириктирүү белгилөөлөрдү файлдагы орду боюнча эмес, ошол ат боюнча издейт, анткени ар бир программа сактоодо орундарды кайра номерлейт. Эскертмелер жана жабык жеке эскертмелер ошол эле жол менен дал келтирилет.

Барактар эч качан өзгөртүлбөйт: эки көчүрмөдө бирдей барак саны болушу керек. Айырма болсо, бириктирүү сиздин көчүрмөңүздү өз абалында калтырат жана ушуну айтат, анткени барак кошуу же алып салуу адамдын иши.

## Орнотуу

Git үчүн бир репозиторийге бир жолу эки сап керек:

```
# .gitattributes
*.pdf merge=cadcraft

# бир жолу, ар бир компьютерде
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Git жок болсо, `cadcraft merge <base> <ours> <theirs> -o <result>` иштетиңиз. Fossil жана Mercurial ошол эле үч файлды өз бириктирүү куралынын жөндөөсүндө алат. Чиймеге кошо жүрүүчү тапшырма файлы (`<name>.markups.json`, караңыз: [Белгилөөнү тапшырма кылуу](topic:markups-that-act)) текст катары ошондой эле бириктирилет.

## Эрежелер

- Бир тарапта гана өзгөртүлгөн белгилөө алынат. Эки тарапта бирдей өзгөртүү бир жолу алынат.
- Эки жолу ар башка өзгөртүлгөн белгилөө — **карама-каршылык**: сиздин тарап калат, ал эми отчет экөөнү тең тизмелейт. Натыйжалуу файлды ачып, ошол белгилөөнү кол менен оңдоңуз.
- Бир тарапта кошулган белгилөө сакталат. Бир тарапта алынып салынган жана экинчисинде тийилбеген белгилөө алынып салынат. Бир тарапта алынып салынган, экинчисинде өзгөртүлгөн белгилөө: алынып салынат жана отчетто айтылат.
- Катмарлар, тилкелер, жазуулар жана эскертмелер ошол эле эрежелерди сактайт.
- Жабык жеке эскертмелер эч качан ачылбайт: эки тараптын блоктору өз абалында калат.

Бириктирилген файл сиздин көчүрмөңүздүн толук кайра жазылышы, MarkupCraftтын өз {{ui:Сактоо}} аракети сыяктуу. Эч нерсе жүктөлбөйт; баары сиздин компьютерде иштейт.
