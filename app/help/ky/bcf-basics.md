BCF (BIM Collaboration Format) — BIM куралдарынын ортосунда маселелерди өткөрүү үчүн ачык файл форматы. Көптөгөн модель координациясы жана долбоорлоо программалары `.bcfzip` файлын маселелердин тизмеси катары импорттой алат. MarkupCraft **BCF 2.1** форматында жазат.

## Бирин жасоо

1. {{ui:Белгилөөлөр}} өтмөгүн ачыңыз.
2. Тизмени жөнөтүүнү каалаган нерсеңиз боюнча чыпкалаңыз, мисалы {{ui:Абал}} "Ачык". Тизмедеги белгилөөлөр гана экспорттолот.
3. {{ui:BCF}} тандаңыз.
4. Ар бир белгилөөнүн сүрөттөлүшү жасалганча күтүңүз ("BCF үчүн сүрөттөлүштөр жасалууда (20дан 5)…").

Натыйжа: "<name> markups.bcfzip" жүктөлөт, ал эми абал тилкеси канча тема бар жана файлдын өлчөмү кандай экенин көрсөтөт.

## Ичинде эмне бар

Ар бир белгилөө бир **тема** болот:

| Тема талаасы | Эмне менен толтурулат |
|---|---|
| Title | Punch номери, маселе жана барак, мисалы "#4 Булут, A-101 — Кабат планы" |
| Type | Белгилөөнүн түрү (Булут, Чакыруу, Узундук…) |
| Status | Ачык, Кабыл алынган, Четке кагылган же Аякталган |
| Labels | Белгилөөнүн түрү жана барак |
| Author and dates | Белгилөөнүн автору, түзүлгөн жана өзгөртүлгөн даталар |
| Assigned to, due date | Punch элементинен, эгер ал бар болсо |
| Description | Анын тексти же штамп сөздөрү, өлчөнгөн маани, пикир, барак жана файл |
| Comments | Ар бир жооп үчүн бир, автору жана дата менен |
| Snapshot | Белгилөөнүн барактагы бөлүгүнүн сүрөтү |
| Viewpoint | Белгилөөнүн барактагы орду боюнча өйдөдөн көрүнүш |

Ошол эле белгилөөнү кайра экспорттоо ошол эле тема ID берет, ошондуктан BCF импорттогон куралы аны ошол эле маселе катары таный алат.

## Импорттогондо эмне кайтып келет

{{ui:BCF импорттоо}} BCF 2.0, 2.1 жана 3.0 файлдарын окуйт (buildingSMART'тын расмий 3.0 сынак файлдарынын 19унда текшерилген: ар бир тема окулган, үчүнүн тексти бар комментарийлери окулган). Өзүңүздүн теманы (ошол эле тема ID) болсо, жаңы комментарийлерди жооп катары кошот жана жаңы абалды алат. Башка ар бир тема белгиси же файл аты аныктаган барактагы эскертме болот, ал барак белгиси же файл аты боюнча табылбаса, ачык турган барактагы эскертме болот; анын аталышы, сүрөттөмөсү, дайындалган адам жана мөөнөтү эскертменин тексти катары, ал эми комментарийлери жооп катары болот.

| BCF темасында | MarkupCraft'та |
|---|---|
| Title, description, assignee, due date | Эскертменин тексти |
| Тексти бар комментарийлер | Жооптор |
| Status Open, Accepted, Rejected, Completed (Closed, Resolved, Done Completed катары эсептелет) | Белгилөөнүн абалы |
| Author and creation date | Эскертменин автору жана түзүлгөн дата |
| Camera position | Барактагы орун, тек белгиси же файл аты менен барагы байланышкан тема үчүн |
| Model selection, hidden parts, clipping planes, snapshots | Сакталбайт: барак аларды көрсөтө турган модель жок |

## Билүү керек чектер

- **Барак — модель эмес.** Көрүнүш белгилөөнүн кагаздагы ордун көрсөтөт, ал метр кагазда өлчөнөт. Ал BIM куралын модельдин ичиндеги жерге алып барбайт. Жерди табуу үчүн сүрөттөлүштү жана барактын атын колдонуңуз.
- **Абалдар жана түрлөр MarkupCraft'тын өзүнүкү** (Ачык, Кабыл алынган, Четке кагылган, Аякталган; Булут, Чакыруу…). Файл аларды BCF уруксат бергендей жарыялайт, бирок өз тизмелери бекитилген куралдар аларды салыштырып же эске албай коюшу мүмкүн.
- **Импорттоо комментарийлерди алып келет, модель көрүнүштөрүн эмес.** {{ui:BCF импорттоо}} экспорттогон белгилөөлөрүңүзгө жооптор жана абалдарды кошот, башка маселелерден эскертмелерди түзөт; модель камерасын көрсөтө албайт. Караңыз: [Белгилөөлөр тизмеси жана экспорт](topic:markups-list-and-export#import-bcf).
- Чийме карап чыгууда белгилөөлөрдү PDF катары кайтарып жөнөтүү көп учурда жөнөкөйрөөк. BCF — чийме комментарийлерин модель координациясынын жүрүшүнө киргизүү үчүн.
