BCF (BIM Collaboration Format) — BIM куралдарынын ортосунда маселелерди өткөрүү үчүн ачык файл форматы. Көптөгөн модель координация жана долбоорлоо программалары `.bcfzip` файлын маселелердин тизмеси катары импорттой алат. MarkupCraft **BCF 2.1** форматын жазат.

## Жасоо

1. {{ui:Белгилөөлөр}} өтмөгүн ачыңыз.
2. Тизмени жөнөткүңүз келген нерсеге чыпкалаңыз, мисалы {{ui:Абал}} "Ачык". Экспорттолот — тизмедеги белгилөөлөр гана.
3. {{ui:BCF}} тандаңыз.
4. Ар бир белгилөөнүн сүрөтү жасалып бүтүшүн күтүңүз ("BCF үчүн ар бир белгилөөнүн сүрөттөрү жасалууда (20дан 5)…").

Натыйжа: "<name> markups.bcfzip" жүктөлөт, ал эми статус тилкеси канча тема бар экенин жана файлдын өлчөмүн көрсөтөт.

## Ичинде эмнелер бар

Ар бир белгилөө бир **тема** болот:

| Теманын талаасы | Эмне менен толтурулат |
|---|---|
| Аталышы | Чекиттин номери, предмети жана барак, мисалы "#4 Булут, A-101 — Кабаттын плану" |
| Түрү | Белгилөөнүн түрү (Булут, Түшүндүрмө, Узундук…) |
| Абалы | Ачык, Кабыл алынган, Четке кагылган же Аяктаган |
| Белгилер | Белгилөөнүн түрү жана барак |
| Автор жана даталар | Белгилөөнүн автору, түзүлгөн жана өзгөртүлгөн даталар |
| Ээлик кылуучу, мөөнөтү | Пункттар тизмесиндеги элементтен, эгер ал бар болсо |
| Сүрөттөмө | Анын тексти же мөөрдүн сөздөрү, өлчөнгөн маани, пикир, барак жана файл |
| Пикирлер | Ар бир жооп үчүн бир, автору жана датасы менен |
| Сүрөт | Белгилөөнүн барактагы бөлүгүнүн сүрөтү |
| Көрүнүш | Белгилөөнүн барактагы ордунун өйдөдөн көрүнүшү |

Ошол эле белгилөөнү кайра экспорттоо ошол эле теманын ID'син берет, ошондуктан BCF импорттой турган курал аны ошол эле маселе катары таный алат.

## Билүү керек болгон чектөөлөр

- **Барак — модель эмес.** Көрүнүш белгилөөнүн кагаздагы ордун көрсөтөт, ал кагаз метрлеринде өлчөнөт. Ал BIM куралын моделдин ичиндеги жерге алып барбайт. Табуу үчүн сүрөттү жана барактын атын колдонуңуз.
- **Статустар жана түрлөр MarkupCraft'тын өзүнүкү** (Ачык, Кабыл алынган, Четке кагылган, Аяктаган; Булут, Түшүндүрмө…). Файл аларды BCF уруксат бергендей жарыялайт, бирок өз тизмеси бекитилген курал аларды салыштырып же элес алып койушу мүмкүн.
- **Импорттоо пикирлерди алып келет, модель көрүнүштөрүн эмес.** {{ui:BCF импорттоо}} экспорттолгон белгилөөлөргө жоопторду жана статустарды кошот, башка маселелер боюнча эскертмелерди жаратат; модель камерасын көрсөтө албайт. Караңыз [Белгилөөлөрдүн тизмеси жана экспорттоо](topic:markups-list-and-export#import-bcf).
- Чийме текшерүүлөр үчүн белгилөөлөрдү PDF катары кайтаруу көбүнчө жөнөкөй. BCF — чийме пикирлерин модель координациясынын агымына киргизүү үчүн.
