{{key:Mod}} менен жазылган ысык баскычтар Mac'те ⌘ же Control, Windows жана Linux'та Ctrl баскычын кабыл алат. Курал тамгалары кутуга текст терип жатпаганыңызда гана иштейт; текст терип жатканда тамгалар жөн гана тамгалар. Ошондой эле караңыз: [Баскычтар, чычкандар жана трекпадтар](common:keys).

## Тартып жатканда

| Баскыч же аракет | Ал эмне кылат |
|---|---|
| Тартып жатканда {{key:Shift}} | Сызыктар, жебелер, узундуктар жана полисызыктын капталдары 45° кадамдар менен; тик бурчтуктар, эллипстер жана кутулуу булуттар квадрат болот; калем менен бөлүп көрсөткүч бир түз штрих тартат |
| Эки жолу чыкылдатуу, {{key:Enter}} же оң чыкылдатуу | Полисызыкты, көп бурчтукту, эркин булутту же аянтты бүтүрөт |
| {{key:Backspace}} | Полисызыктын, көп бурчтуктун, эркин булуттун же аянттын акыркы чекитин алып салат |
| {{key:Esc}} | Тартып жаткандын баарын жокко чыгарат; эч нерсе жүрбөсө, тандоону тазалайт; эч нерсе тандалбаса, {{ui:Тандоо}} куралга кайтат |
| {{key:Mod+Enter}} | Текст, түшүндүрмө же эскертме кутусунда терүүнү бүтүрөт (же кутунун сыртын чыкылдатат) |
| Терип жатканда {{key:Esc}} | Терип жаткан текстти жокко чыгарат |
| {{ui:Саноо}} менен {{key:Shift}}-чыкылдатуу | Тандалган саноо тобунун эң жакын чекитин алып салат |

## Кесүү, көчүрүү жана чаптоо

Ушул эле буйруктар куралдар тилкесиндеги {{ui:Түзөтүү}} тобунда ({{ui:Көчүрүү}}, {{ui:Чаптоо}}) жана анын {{ui:Дагы}} менюсунда бар, ар биринин баскычы менен. Ар бири артка кайтаруунун бир кадамы. Караңыз: [Көчүрүү, чаптоо жана нускалоо](topic:select-and-edit#copy-paste-and-duplicate).

| Баскыч | Ал эмне кылат |
|---|---|
| {{key:Mod+X}} | Кесүү: тандалганды көчүрүп, өчүрөт |
| {{key:Mod+C}} | Тандалганды көчүрөт |
| {{key:Mod+V}} | Чаптоо. Көрсаткыч баракта турганда көчүрмө көрсөтүлгөн жерге ортого түшөт; башка учурда оригиналдын жанына. Жөндөөлөр аны ар дайым оригиналдын жанына чаптоого мүмкүн кылат. |
| {{key:Mod+Shift+V}} | Орунда чаптоо: баракчадагы ошол эле жерге, ушул же башка баракта |
| {{key:Mod+D}} | Тандалганды анын жанына нускалайт (буфер өзгөрбөйт) |

## Чоңойтуу жана жылдыруу

| Баскыч же аракет | Ал эмне кылат |
|---|---|
| Чычкан дөңгөлөгү | Көрсаткыч айланасында чоңойтот же кичирейтет (дөңгөлөк эч качан жылдырбайт) |
| {{key:Ctrl}} + дөңгөлөк | Тезирээк чоңойтот |
| {{key:Plus}} же {{key:Minus}} ({{key:Mod}} менен да) | Ортонун айланасында чоңойтот же кичирейтет; {{key:=}} плюс катарында иштейт |
| {{key:Mod+0}} | {{ui:Бетке ылайыктоо}} |
| {{key:Mod+9}} | {{ui:Туурасына ылайыктоо}} |
| Ортоңку баскыч менен сүйрөө | Жылдырат |
| Оң баскыч менен сүйрөө | Жылдырат (полисызыктын ортосунда болбогондо) |
| {{key:Space}} басып туруп сүйрөө | Жылдырат |
| Эч нерсе тандалбаганда жебе баскычтары | Жылдырат |
| {{key:Ctrl+Shift+F}} | Экран режими: кадимки, толук экран, панелдери жашырылган толук экран (бардык компьютерлерде Control баскычы) |

:::mac
**Трекпадда:** эки манжа менен жылдыруу чоңойтот. Кысуу Chrome, Edge жана Firefox'та дагы чоңойтот. {{key:Space}} басып туруп сүйрөңүз же {{ui:Көрүнүштү жылдыруу}} куралы менен жылдырыңыз. Эки манжа менен чыкылдатуу оң чыкылдатуу болуп, полисызыкты бүтүрөт. Бул жерде Control-чыкылдатуу оң чыкылдатуунун ордуна жөнөкөй чыкылдатуудай иштеши мүмкүн, ошондуктан эки манжа менен чыкылдатыңыз.
:::

## Браузер сактаган ысык баскычтар

- {{key:Mod+W}}, {{key:Mod+T}}, {{key:Mod+N}} жана {{key:Mod+Q}} браузерге таандык. Сакталбаган белгилөөлөр бар өтмөктү же терезени жапсаңыз, компьютерде браузердин «Сайттан чыгасызбы?» суроосунан кийин алар жоголот.
- Көпчүлүк браузерлер {{key:Mod+N}} баскычын жаңы терезе үчүн сактайт, ошондуктан браузердин өтмөгүндө өйдөдөгү тилкедеги {{ui:Жаңы}} колдонуңуз; иш үстөлүндөгү колдонмо жана Studio баскычты MarkupCraft'ка берет.
- MarkupCraft колдонмо клавиатураны алып турганда {{key:Mod+O}}, {{key:Mod+S}}, {{key:Mod+D}}, {{key:Mod+A}}, {{key:Mod+V}}, {{key:Mod+Shift+V}}, {{key:Mod+0}}, {{key:Mod+Plus}} жана {{key:Mod+Minus}} баскычтарын браузерден алып коёт, ал эми белгилөөлөр тандалганда {{key:Mod+C}} жана {{key:Mod+X}} баскычтарын да. {{key:Mod+,}} {{ui:Жөндөөлөр}} ачат. Бүт браузер баракчасын чоңойтуу үчүн браузердин менюсун колдонуңуз.
- Айрым браузерлерде {{key:Mod+9}} MarkupCraft аны көрбөй туруп, акыркы браузер өтмөгүнө өтөт. Ушундай болсо, баракчанын астындагы {{ui:Туурасына ылайыктоо}} колдонуңуз.
- Толук экрандагы {{key:Esc}} толук экрандан да чыгарат.

## Баскыч иштебесе

- **Кутуга текст терип жатасыз.** Адегенде баракты чыкылдатыңыз. (Тартуу куралы менен чыкылдатуу тартат; андан кийин {{key:Esc}} басыңыз же {{key:Mod+Z}} колдонуңуз.)
- **Диалог ачык.** Баскычтар диалог жабылганга чейин ошого барат.
- **Куралдар тилкесиндеги баскычты жаңы чыкылдаттыңыз**, ошондуктан жебе баскычтары же {{key:Space}} ошол баскычка таасир этет. Көрсаткычты баракка жылдырып, дөңгөлөктү же ортоңку баскычты колдонуңуз, же баскычтарды чыкылдатпай, курал тамгасын басыңыз.

## Жылдыруу командасы кайда

Жылдыруу командасы жок: белгилөөнү тандап, сүйрөңүз ({{key:Shift}} 45° кадамдарды сактайт). Пинди {{ui:Пинди жылдыруу}} менен, баракты {{ui:Баракты мурунураак жылдыруу}} же {{ui:Баракты кийинирээк жылдыруу}} менен жылдырасыз.
