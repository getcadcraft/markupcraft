MarkupCraft ޓަޗާއެކު މަސައްކަތްކުރެއެވެ: އައިޕެޑް (Safari ނުވަތަ Chrome) ގައި، ޓަޗް ސްކްރީން ލެޕްޓޮޕްގައި، ނުވަތަ Windows ނުވަތަ Android ޓެބްލެޓުގައި އަލުން ބްރައުޒަރާއެކު. ލޭންޑްސްކޭޕް ގޮތުގައި ޓެބްލެޓް ފުރިހަމަ ލޭއައުޓް ފެންނެވެ.

## ޖެސްޗާސް

| ޖެސްޗަރ | ކުރާ ކަން |
|---|---|
| އެއް އިނދެގަނޑު | ހާލަތު ޓޫލުން ޑްރޯ ކުރާ، ނުވަތަ {{ui:Select}} އިން ހޮވާ |
| ދެ އިނދެގަނޑު، ފެތުން ނުވަތަ ޕިންޗް | ދެ އިނދެގަނޑުގެ ތެރޭގައި ޒޫމް ކުރާ |
| ދެ އިނދެގަނޑު، އެއްކޮށް ހަރަކާތް | ޕޭން ކުރާ؛ ޒޫމް އަދި ޕޭން އެއް ހަރަކާތެއްގައި ކުރެވޭ |
| ޑްރޯ ކުރާއިރު ދެވަނަ އިނދެގަނޑެއް | ފުރަތަމަ އިނދެގަނޑު ފަށާ ކަން ކެންސަލް ކޮށް، ބަދަލުގައި ޒޫމް ފަށާ |
| ދެފަހަރު ޓެޕް، ނުވަތަ ފަހަރު ފިޓުން ހުރުން | ޕޮލިލައިން، ޕޮލިގަން، ފްރީ ކްލައުޑް ނުވަތަ އެރިއާ ނިމޭ |
| ޓެކްސްޓް، ކޯލްއައުޓް ނުވަތަ ނޯޓް މަތީގައި ފަހަރު ހުރުން، {{ui:Select}} ހިފާއިރު | ޓެކްސްޓް އެޑިޓް ކުރުމަށް ހުޅުވޭ |
| {{ui:Pan}} އޮންވެ ހުރުމުން އެއް އިނދެގަނޑު | ޕޭން ކުރޭ |

ޓަޗް ސްކްރީނުގައި ޓޫލްބާ ބަޓަންތައް، މެނޫތައް، ޓެބްތައް އަދި ޑައިލޮގް ބަޓަންތައް ބޮޑެވެ، އިނދެގަނޑުން އުވަންދެން ލަސް ނުވެއެވެ.

## ލިފްޓުން ކުރާ ކަންތައް

ފަހަތުން އުނދަގޫ ނުވުމަށް، ޕިންޗްގެ ފުރަތަމަ އިނދެގަނޑު ނިޝާން ނުދޭނެ ބައެއް ޓޫލްތައް ލިފްޓުން ކަންތައް ކުރެއެވެ، ޓަޗް ކުރާ ވަގުތު ނޫން:

- {{ui:Count}}: ޑޮޓް ލިފްޓުން އިތުރުވެއެވެ.
- {{ui:Note}}: ނޯޓް ލިފްޓުން ޖެހެއެވެ.
- {{ui:Polyline}}، {{ui:Polygon}}، {{ui:Free cloud}} އަދި {{ui:Area}}: ކޮންމެ ޕޮއިންޓެއް ލިފްޓުން އިތުރުވެއެވެ.
- {{ui:Line}}، {{ui:Arrow}}، {{ui:Length}} އަދި {{ui:Calibrate}}: ފުރަތަމަ ޓެޕް ކުރައްވައި، ދެވަނަ ޓެޕް ކުރުމުން، ނިމުން ލިފްޓުން ޖެހެއެވެ.

އިނދެގަނޑު ލިފްޓް ކުރުމުގެ ކުރިން ކުޑަ ސްލައިޑް ވިޔަސް، އެއީ ޓެޕެއް ނޫން އަދި އެއްވެސް ކަމެއް އިތުރުނުވެއެވެ. ޕާކޮށް ޓެޕް ކުރާށެވެ؛ ރަނގަޅު ކުރުމަށް {{ui:Undo}} ބޭނުންކުރާށެވެ.

ޑްރެގް ކުރާ ޓޫލްތައް ({{ui:Pen}}، {{ui:Highlight}}، {{ui:Cloud}}، {{ui:Rectangle}}، {{ui:Ellipse}}، {{ui:Callout}}، {{ui:Text}}، {{ui:Stamp}}) ޓަޗް ކުރާ ވަގުތުން ފަށާ؛ ދެވަނަ އިނދެގަނޑެއް ކެންސަލް ކުރެއެވެ.

## އިނދެގަނޑުން ހޮވުން

- މާކަޕެއް ޓެޕް ކޮށް ހޮވާ؛ ހަރަކާތް ކުރުމަށް ޑްރެގް ކުރާ؛ ސައިޒް ބަދަލުކުރުމަށް ހެންޑަލް ޑްރެގް ކުރާ. އިނދެގަނޑެއް ޝީޓް ޓަޗް ކުރުމުން، މާކަޕްތައް އަދި ހެންޑަލްތައް ބޮޑު ޓާގެޓެއް ލިބެއެވެ، އަދި ހެންޑަލްތައް ބޮޑަށް ފެންނާނެއެވެ.
- ހުސް ޝީޓުގައި ޑްރެގް ކޮށް ހޮވޭ ބޮކްސެއް ޑްރޯ ކުރާ (ސީދާ ކަނާރަށް: ތެރެއަށް ފުރިހަމަވާ؛ ޗައިން ކަނާރަށް: ޓަޗް ކުރާ).
- {{ui:Select}} ގައި އެއް އިނދެގަނޑަކުން ޕޭން ނުވެއެވެ. ދެ އިނދެގަނޑު، ނުވަތަ {{ui:Pan}} ހޮވާށެވެ.

## ކީބޯޑު ބޭނުންވާ ކަންތައް

ކީބޯޑެއް ނެތިފައި {{key:Shift}}، {{key:Esc}} ނުވަތަ {{key:Enter}} ނެތެވެ. އެގޮތުގައި ކުރާންވާ ކަންތައް:

| ކީބޯޑު ކަން | ކީބޯޑެއް ނެތި |
|---|---|
| {{key:Esc}} ކެންސަލް ކުރުމަށް ނުވަތަ Select ގެ ދިމާއަށް ދިއުމަށް | ޓޫލްބާގައި {{ui:Select}} ޓެޕް ކުރާ |
| {{key:Shift}} 45° ރޮނގު، ސްކްވެއާ ވަށަށް | ފާޑުން ޑްރޯ ކުރާ؛ ހެންޑަލްތައް އިން ރަނގަޅު ކުރާ |
| {{key:Shift}}-ކްލިކް ހޮވާ އިތުރުކުރުމަށް | ހޮވާ ބޮކްސް ބޭނުންކުރާ |
| {{key:Shift}}-ކްލިކް ކައުންޓް ޑޮޓް ފޮހެލުމަށް | ރަނގަޅު ނޫން ޓެޕަކަށްފަހު {{ui:Undo}} |
| {{key:Mod+Enter}} ޓައިޕް ކުރުން ނިމުމަށް | ޓެކްސްޓް ބޮކްސްގެ ބޭރުގައި ޓޭޕް ކުރާ |
| {{key:Enter}} ޕޮލިލައިން ނިމުމަށް، ނުވަތަ މާކަޕް ޓެކްސްޓް އެޑިޓް ކުރުމަށް | ޓަޗް ކޮށް ހިފާ، ނުވަތަ {{ui:Properties}} ގައި {{ui:Edit on the sheet}} |
| {{key:Delete}} | ޓޫލްބާގައި ނުވަތަ {{ui:Properties}} ގައި {{ui:Delete}} |
| {{key:Esc}} އިން އާ ކައުންޓް ގްރޫޕް ފަށާ | ހުސް ޝީޓް {{ui:Select}} އިން ޓެޕް ކޮށް، ދެން {{ui:Count}} އަލުން ޓެޕް ކުރާ |

ކީބޯޑް ކޭސް ނުވަތަ Bluetooth ކީބޯޑު ހުރިއިރު ހުރިހާ ޝޯޓްކަޓް ފެނޭ؛ އައިޕެޑުގައި ⌘ ކީ އިން {{key:Mod+Z}} އަދި އެހެން ކަންތައް ކުރެވޭ.

ޓަޗްގައި ޓޫލްތަކުގެ ޓޫލްޓިޕް ނުފެނޭ. ކޮންމެ ޓޫލުގެ ކީ [ކީބޯޑު އަދި މައުސް](topic:keyboard) ގައި ލިޔެވިފައި ވެއެވެ.

## ސްޓައިލަސް އަދި އެޕަލް ޕެންސިލް

ސްޓައިލަސް (އެޕަލް ޕެންސިލް، Surface Pen ފަދަ) މައުސް ފަދައިން ކުރެއެވެ: ޑްރޯ ކުރޭ، ހޮވޭ، އަދި ޓަޗް ދައްކާ ވަގުތުން ކަން ކުރެއެވެ. ޕިންޗް އަދި ޕޭން އަށް ފިންގަރު ބޭނުންކުރާށެވެ. ޕްރެޝަރ ލައިން ވިޑްތް ނުބަދަލުކުރެއެވެ.

## އައިޕެޑުގައި ހުޅުވުން އަދި ރައްކާކުރުން

- {{ui:Open}} ހުޅުވާ Files ޕިކަރެއް: iCloud Drive، On My iPad، އަދި ތިޔަ ގުޅިފައިވާ ރައްކާ އެޕްތައް.
- {{ui:Save}} ޑައުންލޯޑް ކުރުމަށް އެދޭ؛ ކޮޕީ Files އަށް ދާނެ، Downloads ގައި (ނުވަތަ Safari ސެޓިންގްސްގައި ސެޓް ކުރާ ފޯލްޑަރުގައި).

## ޓެބްލެޓުގައި ތިޔަ މަސައްކަތް ރައްކާކުރުން

:::warning
އައިޕެޑް Safari ނުވަތަ ރައްކާ ނުކުރި މަސައްކަތެއްގެ ޞަފްޙާ ދޫކޮށް ދާއިރު ދަންނަވާ ނުލާއެވެ، އަދި iPadOS މެމަރީ ފުރުމަށް ފަހަރުގައި ޓެބް ފޮނި ލޯޑުކުރެވޭނެއެވެ. MarkupCraft ބްރައުޒަރުގައި ރިކަވަރީ ކޮޕީއެއް ރައްކާކުރައްވައި، ތިޔަ އަލުން ހުޅުވާއިރު އެ ކޮޕީ ހުށަހަޅައެވެ ([ރިކަވަރ ކުރޭ](common:recover) ބަލާށެވެ)، ނަމަވެސް **ކޮންމެ ޝީޓަކަށް ނުވަތަ ކޮންމެ ހަރަކާތަކަށް ފަހު ރައްކާކުރާށެވެ**: ޕްރައިވެޓް ޓެބަކަށް ކޮޕީއެއް ނެތެވެ.
:::

- ތިޔަ ނަން، ޓޫލް ސެޓިންގްސް އަދި ޓޫލް ޗެސްޓް އެ އައިޕެޑުގެ ބްރައުޒަރުގައި ރައްކާވެ، ކޮމްޕިއުޓަރު ފަދައިން. [ބްރައުޒަރުގައި ރައްކާވާ ކަންތައް](topic:browser-storage) ބަލާށެވެ.
- **ސިގްނަލް ނެތް ސައިޓު ވިޒިޓަށް ކުރިން:** އޮންލައިންގައި ހުންނަ ވަގުތު، އައިޕެޑުގައި Safari (ނުވަތަ Chrome) ގައި MarkupCraft ހުޅުވައި، މަތީ ބާގައި {{ui:Save for offline}} ހޮވާށެވެ. "Offline ready" ކިޔާތަނަށް އިންތިޒާރު ކުރައްވާށެވެ ("Saving N of M" ގުނައެވެ؛ PDF ރީޑަރ އަދި ރައިޓަރ ~6 MB އެވެ). ސައިޓުގައި އެ އެޑްރެހަށް ނުވަތަ ބުކްމާކަށް ދާ؛ PDF ހުޅުވުން، މާކަޕްކުރުން އަދި ރައްކާކުރުން ކަނެކްޝަން ނެތިކަމުން ވެސް ކުރެވޭނެއެވެ. "Offline not available" ކިޔާނަމަ، ތިޔަ ޕްރައިވެޓް ޓެބްގައި ހުރީ؛ ނޯމަލް ޓެބެއް ބޭނުންކުރާށެވެ. [އޮފްލައިން މަސައްކަތްކުރުން](common:offline) ބަލާށެވެ.
- Safari ކޮންމެ އޮފްލައިން ކޮޕީއެއް ވިހެއް ވަގުތަކަށް ނޭނގި ނަމަ ނައްތާލެއެވެ. ދަތުރަށް ކުރިން "Offline ready" ކްލިކް ކޮށް "Save again (get the newest version)" ހޮވާށެވެ.
- ބޮޑު ޕްލޭން ސެޓްތައް ގިނަ މެމަރީ ބޭނުން ކުރެއެވެ. ޓެބްލެޓުގައި، ލަސް ނުވާނެ ސްކްރީން ނުވަތަ ދަތުރުގައި ބޭނުންވާ ޝީޓްތައް ނުލިބެނީ ހުޅުވާށެވެ.

## ފޯނުގައި

މަސައްކަތް ކުރެއެވެ، ނަމަވެސް ސްކްރީން ކުޑައެވެ: ބައިތައް ސްޓެކް ކުރެއެވެ (ޓޫލްބާ، ޝީޓް، ސްޓޭޓަސް ބާ، ޕެނަލްތައް، ދެން ޝީޓްތަކުގެ ލިސްޓް)، އަދި ޓޫލްބާ ގަޑިއިން ސްކްރޯލް ވެއެވެ. ފޯނު ބޭނުންކުރާށެވެ ބަލަން އަދި ކުޑަ ނޯޓަކަށް؛ ރަނގަޅު ރިވިއުއަށް ޓެބްލެޓް ނުވަތަ ކޮމްޕިއުޓަރު ބޭނުންކުރާށެވެ.
