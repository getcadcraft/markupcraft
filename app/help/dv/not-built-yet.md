MarkupCraft ތައްޔާރުކުރުމުގައި އޮވެއެވެ. މިއީ މިދުވަހުގެ ބިލްޑުން **ނުކުރާ** ކަންތައް، ރޭވުމަށްޓަކައި. މިއީ މިދުވަހުގެ ބިލްޑު ޚުޞޫޞުކޮށް ބަޔާންކުރާ ކަމެކެވެ، ވަޢުދުތަކެއް ނޫން.

## އެހެން މީހުންނާ މަސައްކަތްކުރުން

| އަދި ހަދާފައި ނެތް | މިއަދު ކުރާނެ ކަން |
|---|---|
| ކޮމްޕިއުޓަރު ދެމެދު ކްލައުޑް ރައްކާކުރުން އަދި ސިންކް | PDF ތައް ތިޔަ ޕްރޮޖެކްޓް ފައިލްތަކާއެކު ބާއްވާށެވެ. ކްލައުޑް ރައްކާކުރުން އަދި ނެތް. |
| ދެ މީހެއްގެ މާކަޕްތަކުގެ ކޮޕީ ޖޯޑުކުރުން | ރިވިއުވަރުންނާ ޝީޓްތައް ވަކިކުރާށެވެ، ނުވަތަ {{key:Mod+C}} އަދި {{key:Mod+V}} މެދުވެރިކޮށް މާކަޕް ގަނޑުން ކޮޕީކުރާށެވެ. RFIs، submittals އަދި daily logs ޖޯޑުވެއެވެ: [RFIs، submittals އަދި daily logs ޓްރެކްކުރޭ](topic:field-records) ބަލާށެވެ. |
| RFIs، submittals އަދި daily logs ގެ ޓީމްތައް، ނޯޓިފިކޭޝަންތަކާއި ކްލައުޑް ޕްރޮޖެކްޓްތައް | PDF އެހެން މީހަކަށް ފޮނުއްވައި، ކޮޕީތައް ޖޯޑުކުރުމަށް {{ui:Merge}} ބޭނުންކުރާށެވެ. |
| RFIs، submittals އަދި daily logs ލައިވް ސެޝަނެއްގައި | ކޮންމެ މީހަކު އެމީހުންގެ އަމިއްލަ ކޮޕީން މަސައްކަތްކުރެއެވެ؛ ކޮޕީތައް ޖޯޑުކުރުމަށް {{ui:Merge}} ބޭނުންކުރާށެވެ. |
| މީހަކުގެ ފީލްޑް ތަފާތު ފީލްޑްތަކުގެ ބަދަލު ދެމީހުން ޖޯޑުކުރުން | ފަހުން ބަދަލުކުރި ކޮޕީ އެ ރެކޯޑް މުޅިން ނިންމަވާލެވޭ (އެކަމުގެ ތަރުތީބާއި ފައިލް ނަންތައް ޖޯޑުވެއެވެ). ކޮން މީހަކު ކޮން ރެކޯޑް އެޑިޓްކުރާނެ ކަމަށް އެއްބަސްވާށެވެ. |
| RFIs، submittals އަދި daily logs ގެ އެސިސްޓަންޓް ޓූލްތައް | {{ui:Field}} ޓެބުގައި މަސައްކަތްކުރާށެވެ. އެސިސްޓަންޓުންނަށް މާކަޕް ބޭނުންކުރެވޭ: [AI އެސިސްޓަންޓާއެކު MarkupCraft ބޭނުންކުރޭ](topic:use-with-ai-assistants) ބަލާށެވެ. |
| ފޮނުއްވި ޖަވާބެއް އެޑިޓްކުރުން ނުވަތަ ފޮހެލުން | ވަގުތުން އަންހެނަށް ކުރިއަށް ދާށެވެ، ނުވަތަ އިސްލާޙުކުރާ ޖަވާބެއް އިތުރުކުރާށެވެ. |
| މާކަޕެއް ކާކު ހެދިކަން ބަދަލުކުރުން | ފަށާކުރީ ތިޔަ ނަން ސެޓްކުރާށެވެ. |

## މާކަޕްތައް

| އަދި ހަދާފައި ނެތް | މިއަދު ކުރާނެ ކަން |
|---|---|
| ފީލްޑް ހުރި ސްޓޭމްޕްތައް، ސެޓިފައިޑް ޑިޖިޓަލް ސޮއިތައް | އެކަނި ޓެކްސްޓް ސްޓޭމްޕެއް ބޭނުންކުރާށެވެ، އެއީ ތިޔަ ނަން އަދި ތާރީޚު ހިމެނޭ، ނުވަތަ ތިޔަ ސޮއީގެ ފޮޓޯއެއް. |
| ފޮޓޯ ނޫން ފައިލްތައް (ޑޮކިއުމަންޓް، ވީޑިއޯ) ގެހިތުން | އެ ފައިލްތައް PDF އާ އެކު ބާއްވައި، ކޮމެންޓުގައި ރެފަރ ކުރާށެވެ. |
| ވެބްސައިޓްތަކަށް ނުވަތަ ހުޅުވާފައި ނެތް ފައިލްތަކަށް ލިންކްތައް | އެޑްރެސް ނުވަތަ ފައިލް ނަން ކޮމެންޓުގައި ލިޔާށެވެ. |
| ރިވާޖު ސްޓޭޓަސް ސެޓްތައް | ހަތަރު ސްޓޭޓަސްތައް ބޭނުންކުރާށެވެ، އަދި އިތުރަށް މުއްދަތު ހަދާ ކަމަށް subject ބޭނުންކުރާށެވެ. |
| ފައިލާއެކު ކިޔަވާ ކިއުމަށް ކުރާ (ރީޑް-ހަދާ) ކޮމެންޓްތައް (ޓެކްސްޓް ހައިލައިޓް، އެހެން ޕްރޮގްރާމްތަކުގެ ސްޓޭމްޕްތައް) އެޑިޓްކުރުން | އެކަމަށް ޖަވާބު ދޭށެވެ، ނުވަތަ ކިޑު ކަމުގައި MarkupCraft މާކަޕެއް ޑްރޯކުރާށެވެ. |
| ޕްރެޝަރ-ސެންސިޓިވް ޕެން ސްޓްރޯކްސް | ލައިން ވިޑްތް ސެޓްކުރާށެވެ. |

## ޞަފްޙާގެ އަމިއްލަ ކޮންޓެންޓް

| އަދި ހަދާފައި ނެތް | މިއަދު ކުރާނެ ކަން |
|---|---|
| ޞަފްޙާގައި ޚަރުދަނާ ޝޭޕްތައް ސްޓްރެއިޓް ޑްރޯކުރުން | މާކަޕްތަކެއްގެ ގޮތުގައި ޑްރޯކޮށް، ދެން {{ui:Put into the page}} ކުރާށެވެ. [ޞަފްޙާގެ އަމިއްލަ ކޮންޓެންޓް ބަދަލުކުރޭ](topic:page-content) ބަލާށެވެ. |
| ޞަފްޙާގެ އޮބްޖެކްޓްތައް ކޮންމެ ކޮނެއް ނަށް ފެރުމް ކުރުން | ހަރަކާތްކުރާށެވެ އަދި ސައިޒް ބަދަލުކުރާށެވެ؛ ޞަފްޙާ މުޅި ފެރުމް ކުރާށެވެ {{ui:Pages}} އިން. |
| ލައިން ޓެކްސްޓުގެ ފޮންޓް ނުވަތަ ސައިޒް ބަދަލުކުރުން، ނުވަތަ ކިތަކެއް ލައިންތަކަށް ފެތޭ ޓެކްސްޓް | ބަސްތައް ލައިން ލައިންގެ ގޮތުން ބަދަލުކުރާށެވެ؛ އެހެން ފޮންޓެއްގައި އާ ބަސްތައް ބޭނުންނަމަ، ޓެކްސްޓް މާކަޕެއް އިތުރުކުރާށެވެ. |
| ސްކޭންކުރި ފޮޓޯގެ ތެރޭގައި އެޑިޓްކުރުން | ފޮޓޯ ބަދަލުކުރާށެވެ، ނުވަތަ މާކަޕް ކުރާށެވެ. |
| އެންކްރިޕްޓް ނުވަތަ ސޮއި ކުރެވިފައިވާ PDF އެޑިޓްކުރުން | ސޮއި ނުވާ ކޮޕީއެއް ހުށަހަޅާށެވެ؛ މާކަޕް ކޮންމެ PDF އަކަށް ވެއެވެ. |

## މިނުން

| އަދި ހަދާފައި ނެތް | މިއަދު ކުރާނެ ކަން |
|---|---|
| ރޭޑިއަސް މިނުން | {{ui:Arc}} ތަކެއް އޭގެ މަތީން ޑްރޯކުރާށެވެ، ނުވަތަ {{ui:Length}} ފުރާ މިނުން ނިޞްފުކޮށް ބަލާށެވެ. |
| ކަނޑުންކަނޑު ކުނޑާ ކަންތައްތަކުގެ ކޯނަރުތައް އެޑިޓްކުރުން | ކުނޑާ ކަންތައް ފޮހެލާ، އަލުން ޑްރޯކުރާށެވެ. |
| ޝީޓްތަކާ ގިންތިއަކަށް ހަމައެކަނި ސްކޭލެއް ދިނުން | ކޮންމެ ޝީޓް ކެލިބްރޭޓް ކުރާށެވެ؛ ޕްރީސެޓެއް ހޮވުމަށް ކޮންމެ ޝީޓަކަށް ސިކުންތު ކޭހެއް ނަގާ. |
| ޝީޓަކުގައި ސްކޭލް ގިންތި (ވިއުޕޯޓްސް) | ބޮޑަށް މިނޭ ޑްރޯއިންގަށް ކެލިބްރޭޓް ކުރާށެވެ. ޝީޓުގެ ސްކޭލް ބަދަލުކުރުމުން ހުރިހާ އެއްޗެއް ދިމާ ކުރެވޭ، އެހެންކަމުން އަލުން ކެލިބްރޭޓް ކުރުމުގެ ކުރިން ޑީޓެއިލް އަގުތައް ލިޔާށެވެ. |
| ޑްރޯއިންގުގެ ލައިންތަކަށް ސްނެޕް ކުރުން | ކްލިކް ކުރުމުގެ ކުރިން ޒޫމް ކުރާށެވެ، ނުވަތަ ދިގުމިންތަކާ ކޯނަތައް ޓައިޕްކުރާށެވެ ([ސްކޭލަށް ސްކެޗްކުރުން](topic:calibrate-and-measure#sketch-to-scale) ބަލާށެވެ). |
| އައިޓަމް، އެސެމްބްލީ އަދި އަގުތަކާއެކު ފުރިހަމަ ކޮންޓިޓީ ހިސާބު | TakeoffCraft ބޭނުންކުރާށެވެ، އެއީ CadCraft ޢާއިލާގެ ކޮންޓިޓީ ހިސާބު އެޕް. |
