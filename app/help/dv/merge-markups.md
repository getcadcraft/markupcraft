ދެ މީހުން އެއް PDF ދެ ކޮޕީއެއްގައި މާކަޕް ކުރެއެވެ. އެމީހުން ޓޫލް ވަކިވަކި މާކަޕްތަކަށް ތަސްލީމު ކުރެވިފައި ހުންނާނަމަ، ކޮޕީތައް ޕްރޮގްރާމަކުން މަރްޖް ކުރެވޭނެއެވެ، އަތުން ކުރުމުގެ ބަދަލުގައި.

## މިއީ ކިހިނެއް ކަންކަން ކޮށްދޭ

MarkupCraft ރައްކާ ކުރާ ކޮންމެ މާކަޕަކުން އޭގެ އަމިއްލަ ނަން (އައިޑީ) PDF ގެ ތެރޭގައި ހިފައެވެ، އަދި އެ ނަން ބަދަލު ނުވެއެވެ. މަރްޖް ކުރާއިރު ފައިލުގައި އެ މާކަޕްތައް ހޯދަނީ އެ ނަމުން، އެމީހުންގެ ތަނުން ނޫން، ސަބަބަކީ ކޮންމެ ޕްރޮގްރާމެއް ރައްކާ ކުރާ ވަގުތު ތަރުތީބު އާދެ ނަންބަރު ކުރެއެވެ. ނޯޓްތަކާއި ފާރޭދޭ ނޯޓްތައް ހަމަ ގޮތުން ހޯދެވެ.

ޝީޓްތައް ނުބަދަލުވެއެވެ: ދެ ކޮޕީއަށް ޞަފްޙާ އެއް ޢަދަދު ހުންނަންވާނެއެވެ. ތަފާތު ނަމަ މަރްޖް އިން ކަލޭގެފާނުގެ ކޮޕީ ހަމަ ހުރި ގޮތުގައި ބެހެއްޓުމާއި އެ ކަން ދައްކަނީ، ސަބަބަކީ ޞަފްޙާ އިތުރުކުރުމާއި ނައްޓުން މީހުންގެ ކަމެކެވެ.

## ހަމަޖެހުން

Git އަށް މަރްޖް ކުރުމަށް ކޮމްޕިއުޓަރަކުން ކޮންމެ ރިޕޯޒިޓަރީއަކަށް ތަފާތު ދެ ލައިން ބޭނުންވޭ:

```
# .gitattributes
*.pdf merge=cadcraft

# one time, on each computer
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Git ނޫނަމަ، `cadcraft merge <base> <ours> <theirs> -o <result>` ރަން ކުރޭ. Fossil އަދި Mercurial ވެސް އެ ތިން ފައިލް އެމީހުންގެ އަމިއްލަ މަރްޖް ޓޫލް ސެޓިންގުގައި ބޭނުންކުރެއެވެ. ޑްރޯއިންގާއެކު ދާ ޓާސްކް ފައިލް (`<name>.markups.json`، [ޢަމަލުކުރާ މާކަޕްތައް](topic:markups-that-act) ބަލާ) ހަމަ ގޮތުން، ސާދާ ޓެކްސްޓެއްގެ ގޮތުން މަރްޖް ވެއެވެ.

## ގަވާއިދު

- ސައިޑެއްގައި ބަދަލުވި މާކަޕް ނަގައެވެ. ދެ ސައިޑުން ހަމަ ބަދަލެއް ނަގައެވެ ނަމަ އެއް ފަހަރު ނަގައެވެ.
- ދެ ގޮތަކުން ބަދަލުވި އެއް މާކަޕް **ކޮންފްލިކްޓެއް** ކަމުގައި ވެއެވެ: ކަލޭގެފާނުގެ ސައިޑް ހުރެއެވެ، އަދި ރިޕޯޓުން ދެފަރާތް ލިސްޓުކުރެއެވެ. ނިމުން ޑޮކިއުމަންޓް ހުޅުވައި އެ މާކަޕް އަތުން ރަނގަޅުކުރޭ.
- ދެ ފަރާތުގެ އެއްފަރާތުން އިތުރުކުރެވުނު މާކަޕް ރައްކާ ވެއެވެ. އެއް ފަރާތުން ފޮހެލި އަދި އަނެއް ފަރާތުން ނުބަދަލުވި މާކަޕް ފޮހެލާފައި ވެއެވެ. އެއް ފަރާތުން ފޮހެލި އަދި އަނެއް ފަރާތުން ބަދަލުވި މާކަޕް: ފޮހެލާފައި، އަދި ރިޕޯޓް ކުރެވެއެވެ.
- ލޭޔަރތަކާއި ކޮލަމްތައް، ރެކޯޑްސް އަދި ނޯޓްތައް އެ ގަވާއިދަށް ތަބާ ވެއެވެ.
- ފާރޭދޭ ފަރާތުން ސީލް ކުރެވުނު ނޯޓްތައް ދެނެގަތެވޭނެ ނޫން: ދެ ފަރާތުގެ ބްލޮކްތައް ހަމަ ގޮތުގައި ރައްކާ ވެއެވެ.

މަރްޖް ކުރެވުނު ފައިލް ކަލޭގެފާނުގެ ކޮޕީ ފުރިހަމައަށް ލިޔުން، MarkupCraft ގެ އަމިއްލަ Save ފަދައިން. އެއްވެސް ކަމެއް އަޕްލޯޑް ނުވޭ؛ ހުރިހާ ކަމެއް ކަލޭގެފާނުގެ ކޮމްޕިއުޓަރުގައި ހިނގައެވެ.
