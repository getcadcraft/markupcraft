BCF (BIM Collaboration Format) އަކީ BIM ޓޫލްތަކުގެ ދެމެދު މައްސަލަތް ފޮނުވުމަށް ހުޅުވާ ފައިލް ފޯމެޓެކެވެ. ކޯޑިނޭޝަނާއި ތައްޔާރުކުރާ ޕްރޮގްރާމްތަކުގެ ގިނަ ބައެއް `.bcfzip` ފައިލަކަށް މައްސަލަތުގެ ލިސްޓެއް ގޮތުގައި އިމްޕޯޓް ކުރެވޭނެއެވެ. MarkupCraft ލިޔުއްވާނީ **BCF 2.1** އެވެ.

## ހަދާ ގޮތް

1. {{ui:Markups}} ޓެބް ހުޅުވާށެވެ.
2. ފޮނުވަން ބޭނުންވާ ކަންތައް ފިލްޓަރ ކުރޭ، މިސާލަކަށް {{ui:Status}} "ހުޅުވާ". ލިސްޓުކުރެވިފައިވާ މާކަޕްތައް އެކަނި އެކްސްޕޯޓް ކުރެވެއެވެ.
3. {{ui:BCF}} ޚިޔާރުކުރޭ.
4. ކޮންމެ މާކަޕެއްގެ ސްނެޕްޝޮޓް ހަދާ ހިނދު އިންތިޒާރު ކުރޭ ("BCF އަށް ސްނެޕްޝޮޓް ހަދަނީ (5 / 20)…").

ނަތީޖާ: "<name> markups.bcfzip" ޑައުންލޯޑް ވެއެވެ، އަދި ސްޓޭޓަސް ބާރުގައި ދައްކާނީ އެ ފައިލުގައި ހުންނަ ޓޮޕިކްތަކުގެ އަދަދާއި ފައިލްގެ ސައިޒެވެ.

## އޭގައި ހިމެނޭ ކަންތައް

ކޮންމެ މާކަޕެއް ހަދާނީ **ޓޮޕިކް** އެއް ގޮތުގައެވެ:

| ޓޮޕިކް ފީލްޑް | ފުރުވާ ގޮތް |
|---|---|
| ނަން | ޕަންޗް ނަންބަރު، މައުޟޫޢު އަދި ޝީޓް، މިސާލަކަށް "#4 ކްލައުޑް A-101 ގައި — ފްލޯ ޕްލޭން" |
| ބާވަތް | މާކަޕްގެ ބާވަތް (ކްލައުޑް، ކޯލްއައުޓް، ދިގުމިން…) |
| ސްޓޭޓަސް | ހުޅުވާ، ޤަބޫލުކުރެވިފައި، ރައްދުކުރެވިފައި، ނިމިފައި |
| ލޭބަލްތައް | މާކަޕްގެ ބާވަތާއި ޝީޓް |
| ލިޔުނިވެރި އަދި ތާރީޚުތައް | މާކަޕްގެ ލިޔުނިވެރި، ހެދި އަދި ބަދަލުކުރި ތާރީޚުތައް |
| ހަވާލުކުރެވިފައިވާ ފަރާތް، ނިމޭ ތާރީޚު | ޕަންޗް އައިޓަމުން، އޭގެ ހުންނަވާއިރު |
| ތަފްޞީލް | އޭގެ ޓެކްސްޓް ނުވަތަ ސްޓޭމްޕްގެ ލިޔުން، މިނުކުރެވުނު އަގު، ކޮމެންޓް، އަދި ޝީޓާއި ފައިލް |
| ކޮމެންޓްތައް | ޖަވާބެއްގެ ކޮންމެ އެއް ކޮމެންޓަކަށް، ލިޔުނިވެރި އަދި ތާރީޚާއެކު |
| ސްނެޕްޝޮޓް | މާކަޕް ޝީޓުގެ ބައިގައި ހުންނަ ފޮޓޯއެއް |
| ވިއުޕޮއިންޓް | މާކަޕް ޝީޓުގައި ހުންނަ ތަން މަތީން ފެންނަ ވިއު |

އެއް މާކަޕް އަލުން އެކްސްޕޯޓް ކުރުމުން އެއް ޓޮޕިކް އައިޑީ ލިބެއެވެ، އެހެންކަމުން BCF އިމްޕޯޓް ކުރާ ޓޫލަކަށް އެ މައްސަލަ އެއްޗެއް ކަމުގައި ދެނެގަނެވޭނެއެވެ.

## ދެނެގަތަން ވާ ސީމާތައް

- **ޝީޓް މޮޑެލް ނޫނެވެ.** ވިއުޕޮއިންޓް ދައްކަނީ މާކަޕުގެ ހުރި ތަން ޕޭޕަރުގައި، ޕޭޕަރުގެ މީޓަރުން މިނުކުރެވިފައެވެ. އެއީ BIM ޓޫލް މޮޑެލްގެ ތަނަކަށް ގެންދާ ކަމެއް ނޫނެވެ. ތަން ހޯދުމަށް ސްނެޕްޝޮޓް އަދި ޝީޓުގެ ނަން ބޭނުން ކުރޭ.
- **ސްޓޭޓަސްތަކާއި ބާވަތްތައް MarkupCraft ގެ އަމިއްލަ ކަންތައް ކަމުގައިވެއެވެ.** (ހުޅުވާ، ޤަބޫލުކުރެވިފައި، ރައްދުކުރެވިފައި، ނިމިފައި؛ ކްލައުޑް، ކޯލްއައުޓް…). ފައިލުން ވަނީ BCF ގަވާއިދާ އެއްގޮތަށް އެކަންކަން ދެއްކެވުމަށް، ނަމަވެސް އެމީހުންގެ އަމިއްލަ ސާބިތު ލިސްޓް ހުންނަ ޓޫލަކުން އެތަކެއް މެޕް ކުރެވޭނެ ނުވަތަ އެތަކެއް ނުބަލާނެއެވެ.
- **އިމްޕޯޓުން މޮޑެލް ވިއު ނުލިބޭ.** {{ui:Import BCF}} ން އެކްސްޕޯޓް ކުރި މާކަޕްތަކަށް ޖަވާބުތަކާއި ސްޓޭޓަސްތައް އިތުރު ކުރެވޭ، އަދި އެހެން މައްސަލަތަކުގެ ނޯޓްތައް ހަދާނެއެވެ؛ މޮޑެލްގެ ކެމެރާ ދައްކާ ނުކުރެވޭނެއެވެ. ބަލާށެވެ: [މާކަޕްތަކުގެ ލިސްޓް އަދި އެކްސްޕޯޓް](topic:markups-list-and-export#import-bcf).
- ޑްރޯއިން ރިވިއުތަކަށް މާކަޕްތައް PDF ގެ ގޮތުގައި ފޮނުވުން ގިނަ ފަހަރު ހާސަލެވެ. BCF ކަމަށް ނިމެވޭނީ ޑްރޯއިން ކޮމެންޓްތައް މޮޑެލް ކޯޑިނޭޝަން ވޯކްފްލޯއަށް ގެނެސްދިނުމަށެވެ.
