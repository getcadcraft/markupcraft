BCF (BIM Collaboration Format) އަކީ BIM ޓޫލްތަކުގެ ދެމެދުގައި ކަންކަން ފޮނުއްވުމަށް ހުޅުވާ ފައިލް ފޯމެޓެކެވެ. ގިނަ މޮޑެލް ކޯޑިނޭޝަން އަދި ލިޔުމުގެ ޕްރޯގްރާމްތަކުން `.bcfzip` ފައިލެއް ކަންކަމުގެ ލިސްޓެއްގެ ގޮތުގައި އިމްޕޯޓުކުރެވިދާނެއެވެ. MarkupCraft ލިޔެނީ **BCF 2.1** އެވެ.

## އެއް ހަދާ

1. {{ui:Markups}} ޓެބް ހުޅުވާ.
2. ލިސްޓް ފިލްޓަރ ކުރޭ، މިސާލަކަށް {{ui:Status}} "ހުޅުވާ". ފިލްޓަރ ކުރެވިފައިވާ މާކަޕްތައް ކޮށްލާ ނެރެވެއެވެ.
3. {{ui:BCF}} ޚިޔާރުކުރޭ.
4. ކޮންމެ މާކަޕަކަށް ސްނެޕްޝޮޓެއް ހަދަމުން ހުރޭ ("BCF އަށް ސްނެޕްޝޮޓްތައް ހަދަމުން (5 އިން 20)…").

ނަތީޖާ: "<name> markups.bcfzip" ޑައުންލޯޑް ވެއެވެ، އަދި ސްޓޭޓަސް ބާރުން ޓޮޕިކްސްގެ އަދަދާއި ފައިލްގެ ސައިޒް ދައްކައެވެ.

## އޭގައި ހުންނަ އެއްޗެހި

ކޮންމެ މާކަޕަކީ އެއް **ޓޮޕިކެއް** ވެއެވެ:

| ޓޮޕިކް ފީލްޑް | ފުރިގެންވާ ގޮތް |
|---|---|
| ޓައިޓަލް | ޕަންޗް ނަމްބަރު، މައުޟޫޢު އަދި ޝީޓް، މިސާލަކަށް "#4 ކްލައުޑް A-101 ގައި — ފްލޯ ޕްލޭން" |
| ބާވަތް | މާކަޕްގެ ބާވަތް (ކްލައުޑް، ކޯލްއައުޓް، ދިގުމިން…) |
| ސްޓޭޓަސް | ހުޅުވާ، ޤަބޫލުކުރެވިއްޖެ، ރައްދުކުރެވިއްޖެ ނުވަތަ ނިމިއްޖެ |
| ލޭބަލްތައް | މާކަޕްގެ ބާވަތާއި ޝީޓް |
| ލިޔުނިވެރިޔާއާއި ތާރީޚުތައް | މާކަޕްގެ ލިޔުނިވެރިޔާ، ހަދާފައިވާ އަދި ބަދަލުކުރެވިފައިވާ ތާރީޚުތައް |
| ދެވިފައިވާ މީހާ، ޑިއު ޑޭޓު | ޕަންޗް އައިޓަމުގެ ތެރެއިން، ނޫނީ އެއް ހުރެއްނަމަ |
| ޑިސްކްރިޝަން | އޭގެ ޓެކްސްޓް ނުވަތަ ސްޓޭމްޕް ލިޔުން، ޢަދަދު އަގު، ކޮމެންޓް، އަދި ޝީޓާއި ފައިލް |
| ކޮމެންޓްތައް | ކޮންމެ ރެޕްލައަކަށް އެއް، ލިޔުނިވެރިޔާއާއި ތާރީޚާއެކު |
| ސްނެޕްޝޮޓް | މާކަޕް ޝީޓުގެ އެ ބައިގައި ފެންނަ ފޮޓޯ |
| ވިއުޕޮއިންޓް | ޝީޓުގައި މާކަޕްގެ ތަނުގެ މަތީން ފެންނަ ފެންވަރު |

އެއް މާކަޕް އަލުން އެކްސްޕޯޓުކުރުމުން އެއް ޓޮޕިކް ID ލިބޭތީ، BCF އިމްޕޯޓުކުރާ ޓޫލަކަށް އެއީ އެއް ކަން ފެނޭ.

## އިމްޕޯޓުކުރުމުން ލިބޭ އެއްޗެހި

{{ui:BCF އިމްޕޯޓުކުރޭ}} ކިޔަވަނީ BCF 2.0، 2.1 އަދި 3.0 ފައިލްތަކެވެ (buildingSMART 3.0 ޓެސްޓް ފައިލް 19 ގައި ބަލައިގެން ފެންނަނީ: ކޮންމެ ޓޮޕިކެއް ކިޔަވާފައި، އަދި ޓެކްސްޓް ހުންނަ ތިން ޓޮޕިކުގެ ކޮމެންޓްތައް ކިޔަވާފައެވެ). ތިޔަބޭފުޅުގެ ޓޮޕިކެއް (އެއް ޓޮޕިކް ID) ނަމަ، އާ ކޮމެންޓްތައް ރެޕްލައިއަށް އިތުރުކޮށް، އާ ސްޓޭޓަސް ނެގެއެވެ. އެހެން ކޮންމެ ޓޮޕިކެއް ޝީޓުގައި ނޯޓެއް ކޮށްލާ، އެ ޝީޓަކީ ލޭބަލް ނުވަތަ ފައިލް ނަމުން ނިންމާފައިވާ ޝީޓެއް، ނޫނީ ހުޅުވާފައިވާ ޝީޓެވެ. ޓައިޓަލް، ޑިސްކްރިޝަން، ދެވިފައިވާ މީހާ އަދި ޑިއު ޑޭޓު ނޯޓުގެ ޓެކްސްޓް ވެއެވެ، އަދި ކޮމެންޓްތައް ރެޕްލައިތައް ވެއެވެ.

| BCF ޓޮޕިކުގައި | MarkupCraft ގައި |
|---|---|
| ޓައިޓަލް، ޑިސްކްރިޝަން، ދެވިފައިވާ މީހާ، ޑިއު ޑޭޓު | ނޯޓުގެ ޓެކްސްޓް |
| ޓެކްސްޓް ހުންނަ ކޮމެންޓްތައް | ރެޕްލައިތައް |
| ސްޓޭޓަސް Open، Accepted، Rejected، Completed (Closed، Resolved، Done ކައުންޓް ވެފައިވަނީ Completed ގެ ގޮތުގައި) | މާކަޕްގެ ސްޓޭޓަސް |
| ލިޔުނިވެރިޔާއާއި ހަދާ ތާރީޚު | ނޯޓުގެ ލިޔުނިވެރިޔާއާއި ތާރީޚު |
| ކެމެރާ ފޯޒިޝަން | ޝީޓުގައި ޖާގައެއް، ލޭބަލް ނުވަތަ ފައިލް ނަމުން ޝީޓާ ގުޅާފައިވާ ޓޮޕިކަށް ނަމަ ބަހައްޓާނީ |
| މޮޑެލް ސިލެކްޝަން، ހިމޭނުންތެރި ބައިތައް، ކްލިޕިންގ ޕްލޭންސް، ސްނެޕްޝޮޓްތައް | ނުބެހެއްޓެވޭ: ޝީޓަށް އެތަކެއް ދައްކަން މޮޑެލެއް ނެތް |

## ފެންނަ ހައްދުތައް

- **ޝީޓަކީ މޮޑެލެއް ނޫން.** ވިއުޕޮއިންޓް ދައްކަނީ މާކަޕް ކާޑުގެ މަތީގެ ތަން، ކާޑުގެ m އަޅުވާލުމުން. އެއީ BIM ޓޫލަކަށް މޮޑެލުގައި ތަނަކަށް ގެންދެވޭ ކަމެއް ނޫން. ތަން ހޯދަން ސްނެޕްޝޮޓާއި ޝީޓުގެ ނަން ބޭނުންކުރޭ.
- **ސްޓޭޓަސްތަކާއި ބާވަތްތައް MarkupCraft ގެ އަމިއްލަ ޝަކުލުން.** (Open، Accepted، Rejected، Completed؛ ކްލައުޑް، ކޯލްއައުޓް…) ފައިލް އެ ސްޓޭޓަސްތައް އަދި ބާވަތްތައް ބަޔާންކުރައެވެ، ނަމަވެސް އެންމެ ފިކްސްޑް ލިސްޓް ހުންނަ އެހެން ޓޫލެއް އެތަކެއް މެޕްކުރުން ނުވަތަ ފުރާފުރާ ނުބެލުން ކުރެވިދާނެއެވެ.
- **އިމްޕޯޓުކުރުމުން ލިބޭނީ ކޮމެންޓްތަކެވެ، މޮޑެލް ވިއުތައް ނޫން.** {{ui:BCF އިމްޕޯޓުކުރޭ}} އިން އެކްސްޕޯޓުކުރެވުނު މާކަޕްތަކަށް ރެޕްލައިތަކާއި ސްޓޭޓަސްތައް އިތުރުކުރައި، އެހެން ކަންކަމުން ނޯޓުތައް ހަދައެވެ؛ މޮޑެލް ކެމެރާ ދައްކަން އެއަށް ނުކުރެވޭ. ބަލާ [މާކަޕްތަކުގެ ލިސްޓު އަދި އެކްސްޕޯޓު](topic:markups-list-and-export#import-bcf).
- މާކަޕްތައް PDF އަކަށް ފޮނުވުން، ޑްރޯއިންގ ރިވިއު ކުރުމަށް ކޮށްވަނީ ފަސޭހަ ގޮތެވެ. BCF އަކީ ޑްރޯއިންގ ކޮމެންޓްތައް މޮޑެލް ކޯޑިނޭޝަން ވޯކްފްލޯއަށް ގެނެވޭ ޓޫލެވެ.
