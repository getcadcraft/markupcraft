MarkupCraft อยู่ระหว่างการพัฒนา นี่คือสิ่งที่เวอร์ชันปัจจุบันยัง **ไม่** ทำ เพื่อให้คุณวางแผนรองรับได้ ข้อมูลนี้อธิบายเวอร์ชันปัจจุบันเท่านั้น ไม่ใช่คำมั่นสัญญา

## การทำงานร่วมกับผู้อื่น

| ยังไม่ได้สร้าง | ทำอย่างนี้ได้ในวันนี้ |
|---|---|
| การบันทึกและซิงก์บนคลาวด์ระหว่างคอมพิวเตอร์ | เก็บไฟล์ PDF ไว้กับไฟล์โปรเจกต์ของคุณ การบันทึกบนคลาวด์ยังไม่พร้อมใช้งาน |
| การรวมสำเนามาร์กอัปของคนสองคนเข้าด้วยกัน | แบ่งแผ่นแบบให้ผู้ตรวจแต่ละคน หรือคัดลอกมาร์กอัปจำนวนไม่กี่รายการด้วย {{key:Mod+C}} และ {{key:Mod+V}} RFI, เอกสารส่งอนุมัติ (submittals) และบันทึกประจำวันรวมได้ ดู [ติดตาม RFI, เอกสารส่งอนุมัติ และบันทึกประจำวัน](topic:field-records) |
| ทีม การแจ้งเตือน และโปรเจกต์บนคลาวด์สำหรับ RFI และเอกสารส่งอนุมัติ | ส่งไฟล์ PDF ต่อ และใช้ {{ui:รวม}} เพื่อนำสำเนามารวมกัน |
| RFI, เอกสารส่งอนุมัติ และบันทึกประจำวันในเซสชัน Live | แต่ละคนทำงานบนสำเนาของตัวเอง แล้วนำสำเนามารวมกันด้วย {{ui:รวม}} |
| การรวมการเปลี่ยนแปลงของคนสองคนในฟิลด์ต่างกันของรายการเดียว | สำเนาที่แก้ไขทีหลังสุดจะชนะรายการนั้นทั้งรายการ (กระทู้และชื่อไฟล์แนบจะถูกรวมกัน) ตกลงกันว่าใครแก้ไขรายการใด |
| เครื่องมือผู้ช่วย AI สำหรับ RFI, เอกสารส่งอนุมัติ และบันทึกประจำวัน | ทำงานกับข้อมูลเหล่านี้ในแท็บ {{ui:ภาคสนาม}} ผู้ช่วยทำงานกับมาร์กอัปได้ ดู [ใช้ MarkupCraft กับผู้ช่วย AI](topic:use-with-ai-assistants) |
| การแก้ไขหรือลบการตอบกลับที่ส่งไปแล้ว | เลิกทำทันที หรือเพิ่มการตอบกลับที่แก้ไข |
| การเปลี่ยนว่ามาร์กอัปเป็นของใคร | ตั้งชื่อของคุณก่อนเริ่มงาน |

## มาร์กอัป

| ยังไม่ได้สร้าง | ทำอย่างนี้ได้ในวันนี้ |
|---|---|
| ตราประทับที่มีช่องกรอก ลายเซ็นดิจิทัลที่รับรองแล้ว | ใช้ตราประทับข้อความกำหนดเอง ซึ่งมีชื่อและวันที่ของคุณ หรือรูปลายเซ็นของคุณ |
| การแนบไฟล์อื่นที่ไม่ใช่รูปถ่าย (เอกสาร วิดีโอ) | เก็บไฟล์เหล่านั้นไว้ข้าง PDF และอ้างถึงในความคิดเห็น |
| ลิงก์ไปยังเว็บไซต์ หรือไฟล์ที่ไม่ได้เปิดอยู่ | เขียนที่อยู่หรือชื่อไฟล์ลงในความคิดเห็น |
| ชุดสถานะที่กำหนดเอง | ใช้สถานะทั้งสี่ และใช้หัวข้อสำหรับเรื่องอื่นที่มากกว่านั้น |
| การแก้ไขความคิดเห็นที่มาพร้อมไฟล์แบบอ่านอย่างเดียว (ไฮไลต์ข้อความ ตราประทับของโปรแกรมอื่น) | ตอบกลับความคิดเห็นเหล่านั้น หรือวาดมาร์กอัป MarkupCraft ไว้ข้างๆ |
| เส้นปากกาที่ตอบสนองต่อแรงกด | ตั้งความหนาเส้น |

## เนื้อหาของหน้าเอง

| ยังไม่ได้สร้าง | ทำอย่างนี้ได้ในวันนี้ |
|---|---|
| การวาดรูปร่างใหม่ลงบนหน้าโดยตรง | วาดเป็นมาร์กอัปก่อน แล้วเลือก {{ui:นำลงในหน้า}} ดู [เปลี่ยนเนื้อหาของหน้า](topic:page-content) |
| การหมุนวัตถุในหน้าไปเป็นมุมใดก็ได้ | ย้ายและปรับขนาดวัตถุ แล้วหมุนทั้งหน้าด้วย {{ui:หน้า}} |
| การเปลี่ยนแบบอักษรหรือขนาดของบรรทัดข้อความ หรือข้อความที่ไหลข้ามหลายบรรทัด | เปลี่ยนคำทีละบรรทัด หากต้องการคำใหม่ด้วยแบบอักษรอื่น ให้เพิ่มมาร์กอัปข้อความ |
| การแก้ไขสิ่งที่อยู่ในรูปสแกน | เปลี่ยนรูปภาพ หรือทำมาร์กอัปทับ |
| การแก้ไข PDF ที่เข้ารหัสหรือมีลายเซ็น | ขอสำเนาที่ไม่มีลายเซ็น มาร์กอัปใช้ได้กับ PDF ทุกไฟล์ |

## การวัด

| ยังไม่ได้สร้าง | ทำอย่างนี้ได้ในวันนี้ |
|---|---|
| การวัดรัศมี | วาด {{ui:ส่วนโค้ง}} ตามแนวนั้น หรือวัด {{ui:ความยาว}} ข้ามแล้วหารสอง |
| การแก้ไขมุมของช่องตัด | ลบช่องตัดแล้ววาดใหม่ |
| การใช้มาตราส่วนเดียวกับแผ่นแบบหลายแผ่นพร้อมกัน | ปรับเทียบแต่ละแผ่น การเลือกค่าที่ตั้งไว้ล่วงหน้าใช้เวลาหลายวินาทีต่อแผ่น |
| หลายมาตราส่วนในแผ่นเดียว (วิวพอร์ต) | ปรับเทียบตามแบบที่คุณวัดบ่อยที่สุด การเปลี่ยนมาตราส่วนของแผ่นจะวัดค่าทุกอย่างในแผ่นนั้นใหม่ ดังนั้นจดค่ารายละเอียดไว้ก่อนปรับเทียบใหม่ |
| การสแนปไปยังเส้นในแบบ | ซูมเข้าก่อนคลิก หรือพิมพ์ความยาวและมุม (ดู [ร่างตามมาตราส่วน](topic:calibrate-and-measure#sketch-to-scale)) |
| การคำนวณปริมาณแบบเต็มที่มีรายการ ชุดงาน และราคา | ใช้ TakeoffCraft แอปการคำนวณปริมาณในชุดผลิตภัณฑ์ CadCraft |

## แผ่นและไฟล์

| ยังไม่ได้สร้าง | ทำอย่างนี้ได้ในวันนี้ |
|---|---|
| การเลิกทำการเปลี่ยนหน้า (หมุน ย้าย แทรก ลบ) | ปิดโดยไม่บันทึก แล้วเปิด PDF ต้นฉบับอีกครั้ง ดู [พิมพ์ และเปลี่ยนหน้า](topic:pages-and-printing) |
| การปิดไฟล์เดียวในชุด | {{ui:ปิด}} จะปิดทั้งชุด เปิดไฟล์ที่ต้องการอีกครั้ง |
| การบันทึกชุดเป็นโปรเจกต์เพื่อเปิดใหม่ในขั้นตอนเดียว | เปิด PDF เดิมอีกครั้ง |
| การพิมพ์ตามมาตราส่วนที่เลือก หรือหลายแผ่นต่อหนึ่งหน้ากระดาษ | ใช้หน้าต่างการพิมพ์ของเบราว์เซอร์ หรือพิมพ์สำเนาที่บันทึกไว้จากโปรแกรมดู PDF อื่น |

## รายการและการส่งออก

| ยังไม่ได้สร้าง | ทำอย่างนี้ได้ในวันนี้ |
|---|---|
| การวางประเด็น BCF ที่นำเข้าที่ตำแหน่งในโมเดล | ประเด็นที่นำเข้าซึ่งไม่ผูกกับแผ่นใดจะซ้อนกันที่มุมซ้ายบน ให้ย้ายด้วยตนเอง |
| การนำเข้าชุดเครื่องมือจากโปรแกรมมาร์กอัปอื่น | สร้างเครื่องมือที่ต้องการใหม่ แล้วบันทึกลงกล่องเครื่องมือ และส่งออกให้สำนักงาน |

## เปรียบเทียบ

| ยังไม่ได้สร้าง | ทำอย่างนี้ได้ในวันนี้ |
|---|---|
| การเปรียบเทียบข้อความที่ตั้งด้วยแบบอักษร หรือรายการสิ่งที่เปลี่ยน | ใช้การซ้อนทับและแถบเลื่อน หรือ {{ui:เส้นที่เปลี่ยน}} สำหรับเส้นที่วาด |
| การเปรียบเทียบแผ่นสแกนตามเส้น | ใช้การซ้อนทับรูปภาพ |
| การจัดแนวทุกคู่โดยอัตโนมัติเมื่อเปรียบเทียบทั้งชุด | เปรียบเทียบคู่ที่เลื่อนไว้แยกต่างหาก แล้วใช้ {{ui:จัดแนวด้วยสองจุด}} |

## พาเนล

| ยังไม่ได้สร้าง | ทำอย่างนี้ได้ในวันนี้ |
|---|---|
| การย้ายแถบเครื่องมือหรือแถบสถานะ | เฉพาะพาเนลด้านข้างสองพาเนลเท่านั้นที่ย้ายได้ |

## แพลตฟอร์ม

- **เดสก์ท็อป:** MarkupCraft ทำงานในเบราว์เซอร์บน Mac, Windows, Linux และ iPad และใน CadCraft Studio แอปเดสก์ท็อปที่รวมทั้งแปดแอปไว้ในการติดตั้งเดียว
- MarkupCraft อยู่ระหว่างการพัฒนา ป้ายกำกับและพฤติกรรมอาจเปลี่ยนแปลง และวิธีใช้นี้จะเปลี่ยนตามไปด้วย
