MarkupCraft ใช้ได้กับการสัมผัส บน iPad (Safari หรือ Chrome) บนแล็ปท็อปหน้าจอสัมผัส หรือบนแท็บเล็ต Windows หรือ Android ที่มีเบราว์เซอร์รุ่นใหม่ ในแนวนอน แท็บเล็ตจะแสดงเลย์เอาต์เต็มรูปแบบ

## ท่าทาง

| ท่าทาง | ทำอะไร |
|---|---|
| นิ้วเดียว | วาดด้วยเครื่องมือปัจจุบัน หรือเลือกด้วย {{ui:เลือก}} |
| สองนิ้ว ถ่างหรือบีบ | ซูมรอบจุดระหว่างนิ้วของคุณ |
| สองนิ้ว เลื่อนไปด้วยกัน | แพน คุณซูมและแพนได้ในการเคลื่อนไหวเดียว |
| นิ้วที่สองขณะวาด | ยกเลิกสิ่งที่นิ้วแรกเริ่ม และเริ่มซูมแทน |
| แตะสองครั้ง หรือแตะค้าง | เสร็จสิ้นโพลีไลน์ รูปหลายเหลี่ยม เมฆอิสระ หรือพื้นที่ |
| แตะค้างข้อความ คอลเอาต์ หรือหมายเหตุ เมื่อใช้ {{ui:เลือก}} | เปิดข้อความเพื่อแก้ไข |
| นิ้วเดียวเมื่อเปิด {{ui:เลื่อนภาพ}} | แพน |

บนหน้าจอสัมผัส ปุ่มบนแถบเครื่องมือ เมนู แท็บ และปุ่มในกล่องโต้ตอบจะใหญ่ขึ้น จึงแตะได้ง่ายด้วยนิ้ว

## สิ่งที่เกิดขึ้นเมื่อปล่อยนิ้ว

เพื่อให้นิ้วแรกของการบีบไม่ทิ้งรอยไว้ เครื่องมือบางอย่างจะทำงานเมื่อคุณ **ปล่อย** นิ้ว ไม่ใช่ตอนสัมผัส:

- {{ui:นับ}}: จุดจะถูกเพิ่มเมื่อปล่อย
- {{ui:หมายเหตุ}}: หมายเหตุจะถูกวางเมื่อปล่อย
- {{ui:โพลีไลน์}}, {{ui:รูปหลายเหลี่ยม}}, {{ui:เมฆอิสระ}} และ {{ui:พื้นที่}}: แต่ละจุดจะถูกเพิ่มเมื่อปล่อย
- {{ui:เส้น}}, {{ui:ลูกศร}}, {{ui:ความยาว}} และ {{ui:ปรับเทียบ}}: เมื่อคุณแตะจุดเริ่มแล้วแตะจุดสิ้นสุด จุดสิ้นสุดจะถูกวางเมื่อปล่อย

หากนิ้วของคุณเลื่อนมากกว่าเล็กน้อยก่อนปล่อย จะไม่นับเป็นการแตะ และจะไม่มีอะไรถูกเพิ่ม แตะให้สะอาด หากต้องการแก้ไข ให้ใช้ {{ui:เลิกทำ}}

เครื่องมือที่คุณลาก ({{ui:ปากกา}}, {{ui:ไฮไลต์}}, {{ui:เมฆ}}, {{ui:สี่เหลี่ยม}}, {{ui:วงรี}}, {{ui:คอลเอาต์}}, {{ui:ข้อความ}}, {{ui:ตราประทับ}}) จะเริ่มทันทีที่คุณสัมผัส นิ้วที่สองจะยกเลิกมัน

## เลือกด้วยนิ้ว

- แตะมาร์กอัปเพื่อเลือก ลากเพื่อย้าย ลากจุดจับเพื่อปรับขนาด หลังจากนิ้วสัมผัสแผ่นแล้ว มาร์กอัปและจุดจับจะมีเป้าหมายที่ใหญ่ขึ้น และจุดจับจะวาดใหญ่ขึ้น
- ลากบนพื้นที่แผ่นว่างเพื่อวาดกรอบการเลือก (จากซ้ายไปขวา: อยู่ภายในทั้งหมด จากขวาไปซ้าย: แตะถึง)
- ใน {{ui:เลือก}} นิ้วเดียว **ไม่** แพน ให้ใช้สองนิ้ว หรือเลือก {{ui:เลื่อนภาพ}}

## สิ่งที่ต้องใช้คีย์บอร์ด

หากไม่มีคีย์บอร์ดจะไม่มี Shift, Esc หรือ Enter นี่คือสิ่งที่ควรทำแทน:

| การกระทำบนคีย์บอร์ด | เมื่อไม่มีคีย์บอร์ด |
|---|---|
| {{key:Esc}} เพื่อยกเลิกหรือกลับไป {{ui:เลือก}} | แตะ {{ui:เลือก}} บนแถบเครื่องมือ |
| {{key:Shift}} สำหรับเส้น 45° สี่เหลี่ยม และวงกลม | วาดอย่างระมัดระวัง แล้วปรับด้วยจุดจับ |
| {{key:Shift}}+คลิก เพื่อเพิ่มในการเลือก | ใช้กรอบการเลือก |
| {{key:Shift}}+คลิก เพื่อนำจุดนับออก | {{ui:เลิกทำ}} ทันทีหลังแตะผิด |
| {{key:Mod+Enter}} เพื่อจบการพิมพ์ | แตะนอกกล่องข้อความ |
| {{key:Enter}} เพื่อจบโพลีไลน์ หรือเพื่อแก้ไขข้อความของมาร์กอัป | แตะค้าง หรือ {{ui:แก้ไขบนแผ่นแบบ}} ใน {{ui:คุณสมบัติ}} |
| {{key:Delete}} | {{ui:ลบ}} บนแถบเครื่องมือ หรือใน {{ui:คุณสมบัติ}} |
| เริ่มกลุ่มการนับใหม่ด้วย {{key:Esc}} | แตะแผ่นว่างด้วย {{ui:เลือก}} แล้วแตะ {{ui:นับ}} อีกครั้ง |

คีย์บอร์ดแบบมีเคสหรือคีย์บอร์ดบลูทูธจะนำทางลัดทั้งหมดกลับมา บน iPad ปุ่ม ⌘ ใช้กับ {{key:Mod+Z}} และอื่นๆ ได้

บนหน้าจอสัมผัส ปุ่มจะไม่แสดงคำแนะนำ คีย์ของแต่ละเครื่องมือแสดงอยู่ใน [คีย์บอร์ดและเมาส์](topic:keyboard)

## ปากกาสไตลัสและ Apple Pencil

ปากกาสไตลัส (Apple Pencil, Surface Pen และอื่นๆ) ทำงานเหมือนเมาส์ วาดและเลือกได้ และทำงานทันทีเมื่อกดลง ใช้นิ้วสำหรับบีบและแพน แรงกดไม่เปลี่ยนความหนาของเส้น

## การเปิดและบันทึกบน iPad

- {{ui:เปิด}} แสดงตัวเลือกไฟล์ของ Files: iCloud Drive, On My iPad และแอปพื้นที่จัดเก็บใดๆ ที่คุณเชื่อมไว้
- {{ui:บันทึก}} จะขอดาวน์โหลด สำเนาจะไปอยู่ใน Files ภายใต้ Downloads (หรือโฟลเดอร์ที่ตั้งไว้ในการตั้งค่าของ Safari)

## รักษางานของคุณให้ปลอดภัยบนแท็บเล็ต

:::warning
iPad Safari จะไม่เตือนก่อนออกจากหน้าที่มีงานยังไม่ได้บันทึก และ iPadOS อาจโหลดแท็บใหม่เบื้องหลังเพื่อคืนหน่วยความจำ MarkupCraft เก็บสำเนากู้คืนไว้ในเบราว์เซอร์และเสนอให้เมื่อคุณเปิดอีกครั้ง (ดู [กู้คืนงานของคุณ](common:recover)) แต่ **ให้บันทึกหลังแต่ละแผ่นหรือหลังแต่ละรอบการเดินสำรวจ** เพราะแท็บส่วนตัวไม่เก็บสำเนาใดๆ
:::

- การตั้งชื่อ การตั้งค่าเครื่องมือ และกล่องเครื่องมือของคุณจะถูกเก็บไว้ในเบราว์เซอร์บน iPad เครื่องนั้น เหมือนบนคอมพิวเตอร์ ดู [สิ่งที่เก็บอยู่ในเบราว์เซอร์นี้](topic:browser-storage)
- **ก่อนไปไซต์งานที่ไม่มีสัญญาณ:** ขณะยังออนไลน์ ให้เปิด MarkupCraft ใน Safari (หรือ Chrome) บน iPad แล้วเลือก {{ui:บันทึกสำหรับออฟไลน์}} ที่แถบด้านบน รอจนขึ้นว่า "พร้อมใช้งานออฟไลน์" (จะมีการนับ "กำลังบันทึก N จาก M" ตัวอ่านและตัวเขียน PDF มีขนาดประมาณ 6 MB) ที่ไซต์งาน เปิดที่อยู่เดิมหรือบุ๊กมาร์กของมัน การเปิด ทำมาร์กอัป และบันทึก PDF ใช้ได้โดยไม่มีการเชื่อมต่อ หากขึ้นว่า "ใช้งานออฟไลน์ไม่ได้" แสดงว่าคุณอยู่ในแท็บส่วนตัว ให้ใช้แท็บปกติ ดู [ทำงานแบบออฟไลน์](common:offline)
- Safari จะลบสำเนาออฟไลน์ที่คุณไม่ได้ใช้มาหลายสัปดาห์ ก่อนการเดินทาง ให้คลิก "พร้อมใช้งานออฟไลน์" และเลือก "บันทึกอีกครั้ง (รับเวอร์ชันล่าสุด)"
- ชุดแผ่นขนาดใหญ่ใช้หน่วยความจำมาก บนแท็บเล็ต ให้เปิดเฉพาะแผ่นที่คุณต้องการสำหรับการเยี่ยมชม

## บนโทรศัพท์

ใช้ได้ แต่หน้าจอเล็ก ส่วนต่างๆ จะซ้อนกันเป็นชั้น (แถบเครื่องมือ แผ่น แถบสถานะ พาเนล แล้วจึงรายการแผ่นแบบ) และแถบเครื่องมือเลื่อนแนวนอนได้ ใช้โทรศัพท์เพื่อดูและเพิ่มหมายเหตุสั้นๆ และใช้แท็บเล็ตหรือคอมพิวเตอร์สำหรับการตรวจจริง
