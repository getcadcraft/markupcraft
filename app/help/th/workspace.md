MarkupCraft เต็มหน้าต่างเบราว์เซอร์ จากบนลงล่างและจากซ้ายไปขวา:

## แถบบนสุด

แถบบาง ๆ เหนือทุกอย่างเป็นของตระกูล CadCraft ไม่ใช่ของ MarkupCraft เอง มีสิ่งเหล่านี้:

- ชื่อแอปและเวอร์ชันที่คุณกำลังใช้
- {{ui:เกี่ยวกับ MarkupCraft}} ซึ่งเปิดหน้าของแอปบนเว็บไซต์
- {{ui:ช่วยเหลือ}} ซึ่งเปิดช่วยเหลือนี้ในพาเนลด้านข้าง (หรือกด {{key:F1}})
- {{ui:บันทึกสำหรับออฟไลน์}} ซึ่งเก็บ MarkupCraft ตัวอ่านและตัวเขียน PDF และช่วยเหลือนี้ไว้ในเบราว์เซอร์นี้ เพื่อให้เปิดได้โดยไม่ต้องมีการเชื่อมต่อ จากนั้นจะขึ้นว่า "พร้อมใช้ออฟไลน์" (ดู [การทำงานแบบออฟไลน์](common:offline))
- ปุ่มโหมดหน้าจอ ({{ui:เต็มหน้าจอ}}) และ
- {{ui:การตั้งค่า}} (หรือ {{key:Mod+,}}) โดยมีแท็บ {{ui:MarkupCraft}} สำหรับการตั้งค่าของแอปนี้ และ {{ui:ทั่วไป}} สำหรับการตั้งค่าที่ทุกแอป CadCraft ใช้ร่วมกัน (ดู [การตั้งค่า MarkupCraft](topic:settings)) และ
- {{ui:กระดาษ}} และ {{ui:โมเดล}} ธีมสว่างและมืด ใน {{ui:โมเดล}} แผ่นแบบจะวาดเป็นสว่างบนพื้นมืด มาร์กอัปของคุณคงสีของตัวเอง

ปุ่มโหมดหน้าจอ หรือ {{key:Ctrl+Shift+F}} สลับสามโหมด: ปกติ เต็มหน้าจอ และเต็มหน้าจอที่ซ่อนแถบ เมื่อซ่อนแถบ ให้เลื่อนตัวชี้ไปที่ขอบบนของหน้าจอ (หรือแตะตรงนั้น) แถบจะเลื่อนกลับมา ปุ่มลัดนี้ใช้ปุ่ม Control บนคอมพิวเตอร์ทุกเครื่อง รวมถึง Mac

:::note
ในโหมดเต็มหน้าจอ {{key:Esc}} ยังทำให้เบราว์เซอร์ออกจากโหมดเต็มหน้าจอด้วย หากคุณตั้งใจแค่ยกเลิกการวาด ให้กด {{key:Ctrl+Shift+F}} อีกครั้งเพื่อกลับสู่โหมดเต็มหน้าจอ
:::

## แถบเครื่องมือ

ใต้แถบบนสุด เครื่องมือถูกจัดเป็นกลุ่มและมีป้ายกำกับ:

| กลุ่ม | ปุ่ม |
|---|---|
| ไฟล์ | {{ui:เปิด}}, {{ui:บันทึก}}, {{ui:ปิด}} |
| เลือก | {{ui:เลือก}}, {{ui:เลื่อนภาพ}} |
| วาด | {{ui:ปากกา}}, {{ui:ไฮไลต์}}, {{ui:เส้น}}, {{ui:ลูกศร}}, {{ui:สี่เหลี่ยม}}, {{ui:วงรี}}, {{ui:โพลีไลน์}}, {{ui:รูปหลายเหลี่ยม}} |
| แก้ไขแบบ | {{ui:เมฆ}}, {{ui:เมฆอิสระ}} |
| คำอธิบาย | {{ui:คอลเอาต์}}, {{ui:ข้อความ}}, {{ui:หมายเหตุ}}, {{ui:ตราประทับ}} |
| วัด | {{ui:ปรับเทียบ}}, {{ui:ความยาว}}, {{ui:พื้นที่}}, {{ui:นับ}} |
| แก้ไข | {{ui:เลิกทำ}}, {{ui:ทำซ้ำ}}, {{ui:คัดลอก}}, {{ui:วาง}} และ {{ui:เพิ่มเติม}}: {{ui:ตัด}}, {{ui:คัดลอก}}, {{ui:วาง}}, {{ui:วางที่เดิม}}, {{ui:ทำสำเนา}}, {{ui:ลบ}}, {{ui:เลือกทั้งหมด}}, {{ui:ยกเลิกการเลือก}} |

เครื่องมือที่คุณกำลังใช้จะดูเหมือนถูกกดอยู่ วางตัวชี้เหนือปุ่มเพื่อดูปุ่มลัดของมัน (เช่น "สี่เหลี่ยม (R)") เมนู {{ui:เพิ่มเติม}} แสดงปุ่มลัดของแต่ละคำสั่งไว้ข้าง ๆ ปุ่มที่ใช้ไม่ได้ในขณะนั้นจะจางลง: {{ui:คัดลอก}} จนกว่าคุณจะเลือกมาร์กอัป {{ui:วาง}} จนกว่าจะมีสิ่งที่คัดลอกไว้ จุดเล็ก ๆ หลัง {{ui:บันทึก}} หมายความว่ามีมาร์กอัปบางชิ้นที่ยังไม่ได้บันทึก รายการปุ่มทั้งหมดอยู่ใน [คีย์บอร์ดและเมาส์](topic:keyboard)

เครื่องมือจะเปิดค้างอยู่หลังวาด คุณจึงวาดเมฆต่อกันหลายอันได้ กด {{key:Esc}} (สองครั้งหากมาร์กอัปใหม่ยังถูกเลือกอยู่) หรือ {{key:V}} เพื่อกลับไปที่ {{ui:เลือก}}

## รายการแผ่นแบบ (ซ้าย)

{{ui:แผ่นแบบ}} แสดงทุกหน้าของทุก PDF ที่เปิดอยู่ แต่ละแถวแสดงภาพย่อของแผ่นแบบ ชื่อ หมายเลขแผ่นแบบหรือไฟล์และหน้า และจำนวนมาร์กอัปที่มี ตัวเลขหลังหัวข้อคือจำนวนแผ่นแบบ

- คลิกแถวเพื่อแสดงแผ่นแบบนั้น
- พิมพ์ใน {{ui:ค้นหาแผ่นแบบ}} เพื่อกรองตามชื่อแผ่นแบบ หมายเลขแผ่นแบบ หรือชื่อไฟล์ กด {{key:Enter}} เพื่อเปิดรายการแรกที่ตรง

ชื่อแผ่นแบบมาจาก PDF เมื่อมีอยู่ ดู [เปิดชุดแบบและเลื่อนระหว่างแผ่นแบบ](topic:open-a-plan-set)

## พื้นที่แผ่นแบบ (กลาง)

แผ่นแบบที่คุณกำลังทำงานอยู่ ก่อนเปิดสิ่งใด จะแสดง "เปิดชุดแบบ" พร้อมปุ่ม {{ui:เปิด PDF}} วาง PDF ที่ใดก็ได้ตรงนี้เพื่อเปิด

ใต้แผ่นแบบมีแถบแคบที่มี:

- ลูกศรแผ่นแบบก่อนหน้าและถัดไป และ "3 จาก 12: A-101 — Floor plan" (วางตัวชี้เหนือเพื่อดูไฟล์และหน้า)
- ซูมออก ช่องซูม (พิมพ์เปอร์เซ็นต์แล้วกด {{key:Enter}} โดย 100% คือขนาดจริงบนหน้าจอทั่วไป) ซูมเข้า
- {{ui:พอดีหน้า}} และ {{ui:พอดีความกว้าง}}

แต่ละแผ่นแบบจำระดับซูมของตัวเองไว้ขณะที่ชุดแบบยังเปิดอยู่

เมื่อเปรียบเทียบแผ่นแบบสองแผ่น จะมีคำอธิบายสัญลักษณ์ปรากฏตรงนี้: "มีเฉพาะในแผ่นเก่า" "มีเฉพาะในแผ่นใหม่" และ "มีในทั้งสองแผ่น" ดู [เปรียบเทียบสองรุ่นของแบบ](topic:compare-revisions)

## พาเนล (ขวา)

ห้าแท็บ:

| แท็บ | สิ่งที่แสดง |
|---|---|
| {{ui:คุณสมบัติ}} | มาร์กอัปที่เลือก: ผู้เขียน วันที่ ค่าที่วัด สถานะ หัวเรื่อง ข้อความ ความคิดเห็น รูปแบบ การตอบกลับ และรายการตรวจแก้ไขของมัน เมื่อเปิดเครื่องมือวาดและไม่ได้เลือกอะไร จะแสดงการตั้งค่าที่มาร์กอัปใหม่จะใช้ เมื่อไม่ได้เลือกอะไรและเปิด {{ui:เลือก}} อยู่ จะแสดงแผ่นแบบ: หมายเลข ชื่อ ที่มาของชื่อ ขนาดกระดาษ มาตราส่วน และ {{ui:เปลี่ยนชื่อแผ่น}} |
| {{ui:มาร์กอัป}} | มาร์กอัปทุกชิ้นในชุดที่เปิดอยู่ พร้อมตัวกรอง และการส่งออก {{ui:CSV}} และ {{ui:BCF}} ดู [รายการมาร์กอัป](topic:markups-list-and-export) |
| {{ui:รายการตรวจแก้ไข}} | รายการตรวจแก้ไขที่มีหมายเลข พร้อมผู้รับผิดชอบ วันครบกำหนด และสถานะ ดู [ทำรายการตรวจแก้ไข](topic:punch-list) |
| {{ui:เครื่องมือ}} | กล่องเครื่องมือ: เครื่องมือที่บันทึกไว้พร้อมรูปแบบ ดู [กล่องเครื่องมือ](topic:tool-chest) |
| {{ui:เปรียบเทียบ}} | ซ้อนแผ่นแบบสองแผ่น ดู [เปรียบเทียบสองรุ่นของแบบ](topic:compare-revisions) |

## แถบสถานะ (ล่าง)

- ทางซ้าย ตำแหน่งของตัวชี้บนแผ่นแบบ เป็นนิ้ว (หรือมิลลิเมตร ใน [การตั้งค่า](topic:settings)) บนกระดาษ
- ตรงกลาง ข้อความ: สิ่งที่เครื่องมือรอรับต่อไป สิ่งที่เพิ่งบันทึก เหตุผลที่บางอย่างถูกปฏิเสธ **อ่านที่นี่เมื่อบางอย่างไม่เกิดขึ้น**
- ปุ่มมาตราส่วนของแผ่นแบบ ("ยังไม่ได้ปรับเทียบ" หรือมาตราส่วน) คลิกเพื่อตั้งมาตราส่วน ดู [ปรับเทียบแผ่นแบบและวัด](topic:calibrate-and-measure)
- ชื่อของคุณ ("ตั้งชื่อของคุณ" จนกว่าคุณจะใส่) คลิกเพื่อเปลี่ยน

## บนหน้าจอขนาดเล็ก

ต่ำกว่าความกว้างประมาณ 1180 พิกเซล พาเนลจะแคบลงและภาพย่อของแผ่นแบบจะเล็กลง บนหน้าจอขนาดโทรศัพท์ ส่วนต่าง ๆ จะเรียงซ้อนกัน: แถบเครื่องมือ (เลื่อนไปด้านข้างได้) แผ่นแบบ แถบสถานะ พาเนล แล้วรายการแผ่นแบบอยู่ล่างสุด แท็บเล็ตแนวนอนยังคงเลย์เอาต์เต็ม
