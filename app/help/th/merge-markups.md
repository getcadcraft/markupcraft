สองคนทำเครื่องหมายบนไฟล์ PDF เดียวกันในสองสำเนา หากแตะมาร์กอัปคนละชิ้น สำเนาทั้งสองสามารถรวมกันด้วยโปรแกรมแทนการทำด้วยมือ

## อะไรทำให้ใช้งานได้

มาร์กอัปทุกชิ้นที่ MarkupCraft บันทึกจะมีชื่อของตัวเอง (รหัส) อยู่ภายใน PDF และชื่อนั้นไม่เปลี่ยน การรวมจะค้นหามาร์กอัปด้วยชื่อนั้น ไม่ใช่ด้วยตำแหน่งในไฟล์ เพราะทุกโปรแกรมจัดลำดับตำแหน่งใหม่เมื่อบันทึก หมายเหตุและหมายเหตุส่วนตัวที่ปิดผนึกจะถูกจับคู่ด้วยวิธีเดียวกัน

แผ่นจะไม่ถูกแตะต้องเลย: สำเนาทั้งสองต้องมีจำนวนหน้าเท่ากัน หากต่างกัน การรวมจะเก็บสำเนาฝั่งนี้ไว้ตามเดิมและแจ้งให้ทราบ เพราะการเพิ่มหรือลบหน้าเป็นงานของคน

## ตั้งค่า

Git ต้องใช้สองบรรทัดหนึ่งครั้งต่อหนึ่งที่เก็บ:

```
# .gitattributes
*.pdf merge=cadcraft

# one time, on each computer
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

หากไม่ใช้ git ให้รัน `cadcraft merge <base> <ours> <theirs> -o <result>` Fossil และ Mercurial รับไฟล์สามไฟล์เดียวกันในการตั้งค่าเครื่องมือรวมของตัวเอง ไฟล์งาน (`<name>.markups.json` ดู [งานจากมาร์กอัป](topic:markups-that-act)) ที่มาพร้อมกับแบบจะถูกรวมในลักษณะเดียวกัน เป็นข้อความธรรมดา

## กฎ

- มาร์กอัปที่เปลี่ยนเพียงฝั่งเดียวจะถูกนำมา การเปลี่ยนแปลงแบบเดียวกันทั้งสองฝั่งจะถูกนำมาครั้งเดียว
- มาร์กอัปชิ้นเดียวกันที่เปลี่ยนสองแบบคือ **ความขัดแย้ง** ฝั่งนี้จะคงอยู่และรายงานจะแสดงทั้งสองฉบับ เปิดผลลัพธ์และแก้ไขมาร์กอัปนั้นด้วยมือ
- มาร์กอัปที่เพิ่มในฝั่งใดก็ได้จะถูกเก็บไว้ มาร์กอัปที่ลบในฝั่งหนึ่งและไม่ถูกแตะในอีกฝั่งจะถูกลบ ลบในฝั่งหนึ่งและเปลี่ยนในอีกฝั่ง: ลบและรายงาน
- เลเยอร์ คอลัมน์ บันทึก และหมายเหตุ ทำตามกฎเดียวกัน
- หมายเหตุส่วนตัวที่ปิดผนึกจะไม่ถูกเปิดเลย: บล็อกของทั้งสองฝั่งจะคงไว้ตามเดิม

ไฟล์ที่รวมแล้วคือการเขียนใหม่ทั้งหมดของสำเนาฝั่งนี้ เหมือนการบันทึกของ MarkupCraft เอง ไม่มีการอัปโหลดอะไรเลย ทุกอย่างทำงานบนคอมพิวเตอร์เครื่องนี้
