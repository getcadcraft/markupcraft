หากคุณตรวจแบบใน Bluebeam Revu (หรือแสดงความเห็นบน PDF ในโปรแกรม PDF บนเดสก์ท็อปอื่น) MarkupCraft ส่วนใหญ่จะคุ้นเคย ได้แก่ เมฆ คอลเอาต์ คลังเครื่องมือ รายการมาร์กอัป สถานะพร้อมการตอบกลับ การวัดที่ปรับเทียบแล้ว และโอเวอร์เลย์แผ่น ความแตกต่างใหญ่คือวิธีจัดการไฟล์ ดังนั้นให้อ่านหัวข้อถัดไป แม้คุณจะข้ามส่วนที่เหลือ

## ความแตกต่างห้าข้อที่สำคัญ

1. **การบันทึกจะสร้างไฟล์ใหม่** MarkupCraft ทำงานในเบราว์เซอร์และไม่สามารถเขียนทับ PDF บนดิสก์ของคุณได้ {{ui:Save}} จะดาวน์โหลด "<name> (marked up).pdf" และต้นฉบับยังคงเดิม ครั้งถัดไปให้เปิดสำเนา "(marked up)" และจัดการทำความสะอาดสำเนาเก่าด้วยตัวคุณเอง
2. **PDF จะถูกบันทึกเมื่อคุณบันทึก** จนกว่าจะบันทึก สำเนากู้คืนในเบราว์เซอร์นี้จะเก็บมาร์กอัปของคุณไว้ผ่านการขัดข้องหรือการปิดแท็บ และ MarkupCraft จะเสนอให้กู้คืนในครั้งหน้า นี่เป็นเพียงตาข่ายนิรภัย: บันทึก PDF เพื่อเก็บการตรวจไว้
3. **โปรไฟล์ของคุณอยู่ในเบราว์เซอร์** ชื่อผู้เขียน การตั้งค่าเครื่องมือ และคลังเครื่องมือเก็บไว้ในเบราว์เซอร์นี้บนคอมพิวเตอร์เครื่องนี้ เบราว์เซอร์หรือคอมพิวเตอร์อื่นจะเริ่มต้นใหม่ และการล้างข้อมูลเว็บไซต์จะลบข้อมูลเหล่านี้ ส่งออกคลังเครื่องมือของคุณเป็นข้อมูลสำรอง ดู [สิ่งที่เก็บไว้ในเบราว์เซอร์นี้](topic:browser-storage)
4. **ยังไม่มีเซสชันร่วมกัน** ยังไม่มีเซสชันการตรวจแบบสดที่ใช้ร่วมกัน และไม่มีโปรเจกต์บนคลาวด์ การตรวจจะเดินทางไปพร้อม PDF: บันทึก ส่งสำเนาไป คนถัดไปตอบกลับและบันทึก
5. **มาตราส่วนเป็นรายแผ่น และมีเพียงรายแผ่น** ไม่มีวิวพอร์ตภายในแผ่น และไม่มี "ใช้มาตราส่วนนี้กับทุกหน้า" ปรับเทียบทุกแผ่นที่คุณจะวัด

## นิสัยต่อนิสัย

| สิ่งที่คุณคุ้นเคย | ใน MarkupCraft |
|---|---|
| แผงภาพย่อ, ป้ายหน้า | {{ui:Sheets}} อยู่ทางซ้าย ชื่อมาจากป้ายหน้าหรืออ่านจากตารางชื่อเรื่อง แก้ไขด้วย {{ui:Rename sheet}} |
| เปิดหลาย PDF เป็นชุด | เปิดทั้งหมดพร้อมกัน จะกลายเป็นรายการเดียว ไม่มีการบันทึกไฟล์ชุด เปิด PDF เดิมอีกครั้งในครั้งหน้า |
| คลังเครื่องมือพร้อมชุดเครื่องมือ | แท็บ {{ui:Tools}}: คลังหนึ่งชุดต่อเบราว์เซอร์ เครื่องมือที่บันทึกพร้อมสไตล์และหัวเรื่อง แชร์ด้วย {{ui:Export}} และ {{ui:Import}} เป็นไฟล์ JSON ไม่สามารถนำเข้าไฟล์ชุดเครื่องมือจากโปรแกรมอื่นได้ |
| พาเนลคุณสมบัติ | แท็บ {{ui:Properties}}: สถานะ หัวเรื่อง ความเห็น สไตล์ การตอบกลับ และรายการจุดตรวจ รวมอยู่ในที่เดียว |
| รายการมาร์กอัปพร้อมคอลัมน์ | แท็บ {{ui:Markups}} พร้อมตัวกรองตามแผ่น ผู้เขียน สถานะ และประเภท ส่งออกเป็น CSV หรือ BCF ยังไม่มีคอลัมน์กำหนดเอง และยังไม่มีสรุปของ PDF หรือสมุดคำนวณ |
| สถานะและสถานะการตรวจ | {{ui:Status}}: เปิด, ยอมรับ, ปฏิเสธ, เสร็จสิ้น ไม่มีชุดสถานะกำหนดเอง บันทึกเป็นสถานะการตรวจมาตรฐาน |
| การตอบกลับบนมาร์กอัป | เธรด "การตอบกลับ" ใน {{ui:Properties}} โดยการเปลี่ยนสถานะจะถูกบันทึกไว้ในเธรด การตอบกลับที่ส่งแล้วแก้ไขไม่ได้ |
| ปรับเทียบ แล้วความยาว พื้นที่ การนับ | {{ui:Calibrate}}, {{ui:Length}} ({{key:M}}), {{ui:Area}} ({{key:Q}} ให้พื้นที่และเส้นรอบรูป), {{ui:Count}} ({{key:U}}) ยังไม่มีมุม รัศมี ปริมาตร ความยาวของโพลีไลน์ หรือช่องตัด |
| ซ้อนหน้า | แท็บ {{ui:Compare}}: สีแดงสำหรับเก่า สีน้ำเงินสำหรับใหม่ จัดแนวด้วยสองจุด ไม่มีการทำเมฆ "เปรียบเทียบเอกสาร" อัตโนมัติ |
| ตราประทับ | {{ui:Stamp}} มีตราประทับในตัวหกแบบและถ้อยคำกำหนดเอง ลงชื่อด้วยชื่อของคุณและวันที่ ยังไม่มีตราประทับแบบรูปภาพหรือลายเซ็น |
| การติดตามจุดตรวจหรือประเด็น | แท็บ {{ui:Punch list}}: รายการที่มีหมายเลข พร้อมผู้รับผิดชอบ วันครบกำหนด และสถานะ ส่งออกเป็น CSV |
| การทำงานร่วมกันแบบสด | ยังไม่พร้อมใช้งาน ส่ง PDF ที่บันทึกแล้วต่อไปเรื่อย ๆ |
| การรวมลงในหน้า (Flatten) | ยังไม่ได้สร้าง มาร์กอัปยังคงเป็นความเห็นที่ตัวดูอื่นแสดงและพิมพ์ได้ |
| เลเยอร์สำหรับมาร์กอัป | ยังไม่ได้สร้าง ใช้หัวเรื่อง ผู้เขียน และตัวกรองรายการเพื่อจัดเรียงความเห็น |
| ไฮเปอร์ลิงก์ระหว่างแผ่น | ยังไม่ได้สร้าง |
| กดสเปซบาร์เพื่อแพน ล้อเพื่อซูม | เหมือนกัน: กด {{key:Space}} ค้างไว้แล้วลาก ล้อจะซูมที่ตำแหน่งตัวชี้ ล้อไม่เคยเลื่อนหน้า |

## ปุ่มที่ต่างกัน

ปุ่มตัวอักษรเดี่ยวหลายตัวเป็นอย่างที่คุณคาดไว้ แต่ให้ตรวจสิ่งเหล่านี้ก่อนที่นิ้วจะทำไปโดยไม่รู้ตัว:

- {{key:K}} คือ {{ui:Callout}} และ {{key:Q}} คือ {{ui:Area}} หากคุณชินกับ Q สำหรับคอลเอาต์ ตรงนี้มันจะเริ่มพื้นที่แทน
- {{key:C}} คือ {{ui:Cloud}} แบบกล่อง; {{key:Shift+C}} คือ {{ui:Free cloud}}
- {{key:M}} คือ {{ui:Length}}, {{key:U}} คือ {{ui:Count}}, {{key:Y}} คือ {{ui:Polyline}}, {{key:G}} คือ {{ui:Polygon}}, {{key:I}} คือ {{ui:Highlight}}
- {{key:Mod+D}} ทำสำเนาการเลือก (แทนที่จะเป็นบุ๊กมาร์กของเบราว์เซอร์)
- {{key:Mod+Plus}} และ {{key:Mod+Minus}} ซูมแผ่น ไม่ใช่หน้าเบราว์เซอร์
- ปุ่มใดก็เปลี่ยนได้ ดูด้านล่าง

:::tip
หากนิ้วของคุณคุ้นกับ Bluebeam Revu ให้เลือกรูปแบบเมนู {{ui:PDF review}} ใน {{ui:Settings}} › {{ui:MarkupCraft}} › {{ui:Menus, keys and mouse}}: แถบเมนู (ไฟล์, แก้ไข, มุมมอง, เอกสาร, มาร์กอัป, วัด, หน้าต่าง) อยู่เหนือแถวเครื่องมือตรวจ โดย {{key:Q}} สำหรับคอลเอาต์ {{key:H}} สำหรับไฮไลต์เตอร์ {{key:N}} สำหรับรูปหลายเหลี่ยม และการวัดอยู่ที่ {{key:Alt+Shift}} กับตัวอักษร ปุ่มใดก็เปลี่ยนได้ที่นั่นเช่นกัน ดู [เมนู ปุ่ม และเมาส์](topic:menus-keys-and-mouse)
:::

รายการเต็มอยู่ใน [แป้นพิมพ์และเมาส์](topic:keyboard)

## สิ่งที่ทำงานต่างจากที่คุณอาจคาดไว้

- **เครื่องมือยังคงเปิดอยู่** หลังจากวาดเมฆ คุณจะยังวาดเมฆต่อไป {{key:Esc}} หนึ่งครั้งจะล้างการเลือก สองครั้งจะกลับไปที่ {{ui:Select}}
- **ข้อความและคอลเอาต์ต้องมีข้อความ** หากจบโดยไม่พิมพ์อะไร จะไม่มีการเพิ่มมาร์กอัป หมายเหตุจะเก็บเป็นว่างเปล่า
- **การวัดต้องมีมาตราส่วนก่อน** {{ui:Length}} และ {{ui:Area}} จะสลับไปที่ {{ui:Calibrate}} บนแผ่นที่ยังไม่ได้ปรับเทียบ และกลับมาหลังจากนั้น
- **ความเห็นจากโปรแกรมอื่น** สี่เหลี่ยมผืนผ้า วงรี เส้น โพลีไลน์ รูปหลายเหลี่ยม หมึก กล่องข้อความ และโน้ตแปะที่สร้างไว้ที่อื่นจะกลายเป็นมาร์กอัปของ MarkupCraft ที่แก้ไขได้ และจะถูกเขียนใหม่ตามแบบของ MarkupCraft เมื่อคุณบันทึก (รูปลักษณ์อาจเปลี่ยนเล็กน้อย) ไฮไลต์ข้อความ ตราประทับของโปรแกรมอื่น และประเภทพิเศษอื่น ๆ ยังคงเป็นอ่านอย่างเดียว: คุณตอบกลับได้ แต่เปลี่ยนไม่ได้
- **อักขระนอกตัวอักษรยุโรปตะวันตก** จะพิมพ์เป็น "?" ใน PDF ที่บันทึก ดู [บันทึก PDF ที่มีมาร์กอัป](topic:save-the-marked-up-pdf)
- **วันที่ของตราประทับ** ใช้เวลา UTC ดังนั้นตราประทับที่ทำดึกในทวีปอเมริกาอาจแสดงวันพรุ่งนี้
- **การวัดถูกนำไปด้วย** เป็นความเห็นการวัดมาตรฐาน และแต่ละแผ่นที่ปรับเทียบเก็บมาตราส่วนของตนไว้ ดังนั้นโปรแกรมที่อ่านการวัดของ PDF มักแสดงได้ ผลลัพธ์ที่แน่นอนขึ้นอยู่กับโปรแกรมนั้น

## การใช้ทั้งสองอย่าง

คุณสลับไปมาได้ ความเห็นที่ทำไว้ที่อื่นจะเปิดใน MarkupCraft และ PDF "(marked up)" เปิดในโปรแกรม PDF อื่นได้พร้อมมาร์กอัป การตอบกลับ และสถานะทุกอย่างที่มองเห็น สิ่งที่มีเพียง MarkupCraft อ่านกลับได้ (ผู้รับผิดชอบและวันครบกำหนดของจุดตรวจ สถานะรายการ) จะถูกเก็บไว้ในไฟล์เพื่อ MarkupCraft
