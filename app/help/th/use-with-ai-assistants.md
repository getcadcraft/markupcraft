## สิ่งที่คุณจะได้เรียนรู้

วิธีให้ผู้ช่วย AI (หรือสคริปต์ที่คุณเขียนเอง) ทำงานกับ MarkupCraft และวิธีตัดสินใจว่ามันแตะต้องอะไรได้บ้าง

MarkupCraft **ไม่มี AI ของตัวเอง** และไม่ส่งข้อมูลไปที่ใด คุณนำผู้ช่วยมาเอง: โปรแกรมใดก็ได้ที่รองรับ Model Context Protocol (MCP) MarkupCraft เพียงให้เครื่องมือแก่มัน และคุณเป็นผู้เลือกว่าจะให้อะไรบ้าง

## เปิดใช้งาน

1. เปิด {{ui:การตั้งค่า}} (ไอคอนเฟืองในแถบแอป หรือ {{key:Mod+,}}) แล้วไปที่แท็บ {{ui:MarkupCraft}}
2. ใต้ {{ui:ผู้ช่วย}} ทำเครื่องหมาย **ให้ผู้ช่วย AI และสคริปต์ใช้ MarkupCraft** ตัวเลือกนี้ปิดอยู่จนกว่าคุณจะเปิด
3. เลือกสิ่งที่มันทำได้: **อ่าน** ถูกทำเครื่องหมายไว้เป็นค่าเริ่มต้น ทำเครื่องหมาย **แก้ไข** **บันทึก** หรือ **ส่งออก** เฉพาะเมื่อคุณต้องการ

เครื่องมือที่อยู่นอกสิทธิ์ที่คุณทำเครื่องหมายจะไม่ถูกเสนอให้ผู้ช่วย และหากมันขอใช้ MarkupCraft จะปฏิเสธและบันทึกไว้ในบันทึกกิจกรรม การปิดสวิตช์จะยุติทุกการเชื่อมต่อในทันที {{ui:รีเซ็ตการตั้งค่า MarkupCraft}} ก็ปิดสวิตช์นี้ด้วย

## เชื่อมต่อผู้ช่วยของคุณ

ผู้ช่วยเชื่อมต่อผ่าน **CadCraft Studio** บนคอมพิวเตอร์ของคุณ: Studio รันเซิร์ฟเวอร์เล็กๆ ที่มีเพียงคอมพิวเตอร์เครื่องนี้เข้าถึงได้ และป้องกันด้วยโทเคนที่สร้างใหม่ทุกครั้งที่เริ่มทำงาน ใน Studio เลือก {{ui:เชื่อมต่อผู้ช่วย}} แล้วคัดลอกที่อยู่และโทเคนไปยังผู้ช่วยของคุณ (Studio จะแสดงการตั้งค่าที่ต้องวาง) อย่าแชร์โทเคนเด็ดขาด

:::note
แท็บเบราว์เซอร์ไม่สามารถเปิดการเชื่อมต่อให้ผู้ช่วยได้ ในแอปบนเบราว์เซอร์ สวิตช์จะไม่มีผลจนกว่าคุณจะใช้ CadCraft Studio บนคอมพิวเตอร์ของคุณ
:::

## คุณยังควบคุมอยู่

- **ทุกการเปลี่ยนแปลงเป็นหนึ่งขั้นของการเลิกทำ** ติดป้ายด้วยชื่อของผู้ช่วย (เช่น "ผู้ช่วย: เพิ่ม cloudrect") {{key:Mod+Z}} เรียกคืนการเปลี่ยนแปลงล่าสุดของผู้ช่วยทั้งหมด
- **คุณรู้เมื่อมีการเชื่อมต่อ** ปุ่มในแถบแอปจะระบุชื่อผู้ช่วยขณะเชื่อมต่ออยู่ คลิกเพื่อดูว่ามันทำอะไรได้ หรือเพื่อ **ตัดการเชื่อมต่อ**
- **กิจกรรม** {{ui:การตั้งค่า}} › {{ui:MarkupCraft}} › {{ui:ผู้ช่วย}} › {{ui:กิจกรรม}} แสดงทุกการเรียกใช้: เมื่อไร เครื่องมือใด สำเร็จหรือถูกปฏิเสธ {{ui:บันทึกบันทึกกิจกรรม}} เก็บสำเนาไว้

## ผู้ช่วยขอใช้อะไรได้บ้าง

| เครื่องมือ | สิทธิ์ | สิ่งที่ทำ |
|---|---|---|
| `app_info`, `sheets_list` | อ่าน | ชุดที่เปิดอยู่ แผ่น และจำนวนมาร์กอัปในแต่ละแผ่น |
| `markups_list` | อ่าน | มาร์กอัปพร้อมชนิด แผ่น ข้อความ คอมเมนต์ การวัด สถานะ ผู้เขียน และการตอบกลับ กรองตามแผ่น สถานะ ชนิด หรือผู้เขียนได้ |
| `markup_add` | แก้ไข | เพิ่มสี่เหลี่ยม เมฆ วงรี กล่องข้อความ หมายเหตุ เส้น หรือลูกศรลงบนแผ่น |
| `markup_status`, `markup_reply` | แก้ไข | ตั้งสถานะของมาร์กอัป (บันทึกในกระทู้ ลงชื่อโดยผู้ช่วย) เพิ่มคอมเมนต์ในกระทู้ |
| `markups_export` | ส่งออก | CSV หรือ BCF ของสิ่งที่รายการ {{ui:มาร์กอัป}} แสดง (ตามตัวกรองที่คุณตั้งไว้) ใน Studio สามารถเขียนไฟล์ลงโฟลเดอร์ที่คุณอนุญาตได้ |
| `tasks_list` | อ่าน | มาร์กอัปที่เป็นงาน: ผู้รับผิดชอบ (คนหรือผู้ช่วย) วันครบกำหนด สถานะ ลิงก์ และวิธีที่ปิดงาน `assignee: "assistant"` แสดงงานที่รอผู้ช่วย |
| `task_set`, `task_clear` | แก้ไข | ทำให้มาร์กอัปเป็นงาน หรือเปลี่ยนแปลงงาน (ชื่อ ผู้รับผิดชอบ กำหนดวัน สถานะ ลิงก์) และนำงานออก |
| `tasks_check` | แก้ไข | ปิดงานที่พื้นที่ของแบบหรือองค์ประกอบของโมเดลที่เชื่อมโยงเปลี่ยนไปจริง ส่งสถานะขององค์ประกอบที่คุณอ่านจากแอปอื่น |
| `revisions_changes` | อ่าน | รายการข้อความล้วนของสิ่งที่เปลี่ยนไประหว่างชุดแบบที่เปิดอยู่สองชุด เพื่อให้คุณเรียบเรียงด้วยคำของคุณเอง |
| `pins_list`, `decision_add` | อ่าน, แก้ไข | หมายเหตุเสียง (ความยาว ใคร เมื่อไร คำบรรยาย; ไม่มีเสียงและไม่มีการถอดความ) และการตัดสินใจ ปักการตัดสินใจ และแทนที่การตัดสินใจก่อนหน้าได้ |
| `redline_export`, `redline_answer` | ส่งออก, แก้ไข | เขียนไฟล์ redline สำหรับผู้ร่าง ใช้คำตอบของผู้ร่างกับมาร์กอัป |

มาร์กอัปที่ผู้ช่วยเพิ่มจะระบุชื่อมันเป็นผู้เขียน: ชื่อที่โปรแกรมผู้ช่วยตั้งให้ตัวเอง ตามด้วย "(assistant)" หรือ "(assistant for <ชื่อของคุณ>)" เมื่อคุณตั้งชื่อผู้ตรวจแล้ว การเปลี่ยนสถานะและการตอบกลับของมันก็ลงชื่อในลักษณะเดียวกัน แต่ละอย่างเป็นหนึ่งขั้นของการเลิกทำ การบันทึก PDF ที่มีมาร์กอัปยังเป็นหน้าที่ของคุณ: ใช้ {{ui:บันทึก}} ตามปกติ

โดยไม่ต้องเปิด MarkupCraft เซิร์ฟเวอร์ CadCraft MCP จะแสดงรายการมาร์กอัปของ PDF ในโฟลเดอร์ที่คุณระบุได้ (`markups_list`) และ `cadcraft info Set.pdf` จะพิมพ์ออกทางบรรทัดคำสั่ง

## หากมีบางอย่างไม่ทำงาน

- **ผู้ช่วยไม่เห็นเครื่องมือของ MarkupCraft:** ตรวจว่าสวิตช์เปิดอยู่ในหน้าต่างนี้ และหน้าต่างเปิดอยู่ใน Studio
- **"ต้องใช้สิทธิ์แก้ไข":** ทำเครื่องหมาย **แก้ไข** ใต้ {{ui:ผู้ช่วย}} แล้วขอใหม่อีกครั้ง
- **ข้อผิดพลาด "401" หรือ "token":** โทเคนเปลี่ยนไป (Studio เริ่มใหม่ หรือ {{ui:โทเคนใหม่}}) คัดลอกโทเคนใหม่ไปยังการตั้งค่าของผู้ช่วย
