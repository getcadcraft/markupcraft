ทางลัดที่เขียนด้วย {{key:Mod}} ใช้ได้ทั้ง ⌘ หรือ Control บน Mac และใช้ Ctrl บน Windows และ Linux ปุ่มตัวอักษรของเครื่องมือทำงานเฉพาะเมื่อไม่ได้พิมพ์อยู่ในช่อง ขณะพิมพ์ ตัวอักษรเป็นเพียงตัวอักษรธรรมดา ดูเพิ่มเติมที่ [ปุ่ม เมาส์ และแทร็คแพด](common:keys)

## ขณะวาด

| ปุ่มหรือการกระทำ | สิ่งที่เกิดขึ้น |
|---|---|
| {{key:Shift}} ขณะวาด | เส้น ลูกศร ความยาว และด้านของโพลีไลน์เลื่อนทีละ 45° สี่เหลี่ยมผืนผ้า วงรี และเมฆกรอบจะเป็นจัตุรัส ปากกาและไฮไลต์จะเป็นเส้นตรงเส้นเดียว |
| ดับเบิลคลิก {{key:Enter}} หรือคลิกขวา | จบโพลีไลน์ รูปหลายเหลี่ยม เมฆอิสระ หรือพื้นที่ |
| {{key:Backspace}} | ลบจุดสุดท้ายของโพลีไลน์ รูปหลายเหลี่ยม เมฆอิสระ หรือพื้นที่ |
| {{key:Esc}} | ยกเลิกสิ่งที่กำลังวาด เมื่อไม่มีอะไรค้างอยู่ จะยกเลิกการเลือก เมื่อไม่มีอะไรถูกเลือก จะกลับไปที่ {{ui:Select}} |
| {{key:Mod+Enter}} | จบการพิมพ์ในกล่องข้อความ คอลเอาต์ หรือหมายเหตุ (หรือคลิกนอกกล่อง) |
| {{key:Esc}} ขณะพิมพ์ | ยกเลิกข้อความที่กำลังพิมพ์ |
| คลิกด้วย {{key:Shift}} ขณะใช้ {{ui:Count}} | นำจุดที่ใกล้ที่สุดของกลุ่มนับที่เลือกออก |

## การเลือกและแก้ไข

| ปุ่มหรือการกระทำ | สิ่งที่เกิดขึ้น |
|---|---|
| คลิก | เลือกมาร์กอัป |
| {{key:Shift}}-คลิก | เพิ่มหรือนำมาร์กอัปออกจากการเลือก |
| ลากจากซ้ายไปขวาบนแผ่นว่าง | เลือกสิ่งที่อยู่ภายในกรอบทั้งหมด |
| ลากจากขวาไปซ้ายบนแผ่นว่าง | เลือกสิ่งที่กรอบแตะถึง |
| {{key:Mod+A}} | เลือกมาร์กอัปทั้งหมดในแผ่นนี้ |
| ลากมาร์กอัปที่เลือก | ย้ายมาร์กอัป ({{key:Shift}}: ตามขั้น 45°) |
| ลากจุดจับ | ปรับขนาดหรือปรับรูปร่าง ({{key:Shift}}: คงสัดส่วน หรือ 45°) |
| ปุ่มลูกศร | เลื่อนที่เลือกทีละ 1 พิกเซลของหน้าจอ ({{key:Shift}}: ทีละ 10) |
| ดับเบิลคลิก หรือ {{key:Enter}} | แก้ไขข้อความในกล่องข้อความ คอลเอาต์ หรือหมายเหตุ; สำหรับตราประทับ เปิด {{ui:Properties}} |
| {{key:Delete}} หรือ {{key:Backspace}} | ลบที่เลือก |
| {{key:Esc}} | ไม่เลือกอะไร |
| {{key:Mod+Z}} | เลิกทำ |
| {{key:Mod+Y}} หรือ {{key:Mod+Shift+Z}} | ทำซ้ำ |

## ตัด คัดลอก และวาง

คำสั่งเดียวกันอยู่ในกลุ่ม {{ui:Edit}} ของแถบเครื่องมือ ({{ui:Copy}}, {{ui:Paste}}) และในเมนู {{ui:More}} โดยแต่ละคำสั่งมีปุ่มลัดของตัวเอง แต่ละคำสั่งเป็นการเลิกทำหนึ่งขั้น ดู [คัดลอก วาง และทำสำเนา](topic:select-and-edit#copy-paste-and-duplicate)

| ปุ่ม | สิ่งที่เกิดขึ้น |
|---|---|
| {{key:Mod+X}} | ตัด: คัดลอกที่เลือกแล้วลบออก |
| {{key:Mod+C}} | คัดลอกที่เลือก |
| {{key:Mod+V}} | วาง เมื่อตัวชี้อยู่บนแผ่น สำเนาจะวางตรงกลางที่ตัวชี้ชี้อยู่ มิฉะนั้นจะวางถัดจากต้นฉบับ การตั้งค่าอาจทำให้วางถัดจากต้นฉบับเสมอ |
| {{key:Mod+Shift+V}} | วางที่เดิม: ตำแหน่งเดิมบนแผ่น ทั้งในแผ่นนี้หรือแผ่นอื่น |
| {{key:Mod+D}} | ทำสำเนาที่เลือกไว้ถัดจากต้นฉบับ (คลิปบอร์ดไม่เปลี่ยน) |

## สัมผัส

| ท่าทาง | สิ่งที่เกิดขึ้น |
|---|---|
| หนึ่งนิ้ว | วาดด้วยเครื่องมือปัจจุบัน หรือเลือก |
| สองนิ้ว | บีบเพื่อซูมรอบจุดกึ่งกลาง เลื่อนเพื่อเลื่อนภาพ |
| นิ้วที่สองระหว่างการลาก | ยกเลิกการลากและซูมแทน |
| แตะสองครั้ง | จบโพลีไลน์ รูปหลายเหลี่ยม เมฆอิสระ หรือพื้นที่ |

จุดนับ หมายเหตุ จุดของโพลีไลน์ และจุดที่สองของเครื่องมือสองจุด จะถูกวางเมื่อยกนิ้วขึ้น ดู [รีวิวบน iPad หรือจอสัมผัส](topic:review-on-a-tablet)
:::

## ทางลัดที่เบราว์เซอร์ยังเก็บไว้

- {{key:Mod+W}}, {{key:Mod+T}}, {{key:Mod+N}} และ {{key:Mod+Q}} เป็นของเบราว์เซอร์ การปิดแท็บหรือหน้าต่างที่มีมาร์กอัปยังไม่ได้บันทึกจะทำให้สูญหาย หลังจากที่เบราว์เซอร์ถามให้ยืนยันการออกจากไซต์บนคอมพิวเตอร์
- เบราว์เซอร์ส่วนใหญ่ใช้ {{key:Mod+N}} สำหรับหน้าต่างใหม่ ดังนั้นในแท็บเบราว์เซอร์ให้ใช้ {{ui:New}} บนแถบเครื่องมือ แอปเดสก์ท็อปและ Studio ส่งปุ่มนี้ให้ MarkupCraft
- MarkupCraft รับ {{key:Mod+O}}, {{key:Mod+S}}, {{key:Mod+D}}, {{key:Mod+A}}, {{key:Mod+V}}, {{key:Mod+Shift+V}}, {{key:Mod+0}}, {{key:Mod+Plus}} และ {{key:Mod+Minus}} ไปจากเบราว์เซอร์ขณะที่แอปมีคีย์บอร์ด และ {{key:Mod+C}} กับ {{key:Mod+X}} ขณะที่มีมาร์กอัปถูกเลือก {{key:Mod+,}} เปิด {{ui:Settings}} หากต้องการซูมทั้งหน้าเว็บของเบราว์เซอร์ ใช้เมนูของเบราว์เซอร์
- {{key:Mod+9}} อาจพาไปยังแท็บสุดท้ายของเบราว์เซอร์บางตัวก่อนที่ MarkupCraft จะรับได้ หากเกิดขึ้น ให้ใช้ {{ui:Fit width}} ใต้แผ่น
- {{key:Esc}} ในโหมดเต็มหน้าจอ ก็ออกจากเต็มหน้าจอ

## เมื่อปุ่มไม่ทำงาน

- **กำลังพิมพ์อยู่ในช่อง** คลิกที่แผ่นก่อน (การคลิกด้วยเครื่องมือวาดจะวาดขึ้นมา กด {{key:Esc}} ภายหลังหรือใช้ {{key:Mod+Z}})
- **กล่องโต้ตอบเปิดอยู่** ปุ่มจะไปที่กล่องโต้ตอบจนกว่าจะปิด
- **เพิ่งคลิกปุ่มบนแถบเครื่องมือ** ปุ่มลูกศรหรือ {{key:Space}} จะไปทำงานกับปุ่มนั้นแทน ให้วางตัวชี้บนแผ่นแล้วใช้ล้อหรือปุ่มกลาง หรือกดปุ่มตัวอักษรของเครื่องมือแทนการคลิกปุ่ม

## ตำแหน่งของการย้าย

ไม่มีคำสั่งย้ายแยกต่างหาก: เลือกมาร์กอัปแล้วลากได้เลย ({{key:Shift}} คงขั้น 45°) หมุดย้ายด้วย {{ui:Move pin}} และหน้าย้ายด้วย {{ui:Move page earlier}} หรือ {{ui:Move page later}}
