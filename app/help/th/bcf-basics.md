BCF (BIM Collaboration Format) เป็นรูปแบบไฟล์เปิดสำหรับส่งต่อประเด็นระหว่างเครื่องมือ BIM โปรแกรมประสานงานโมเดลและโปรแกรมสร้างโมเดลหลายตัวนำเข้าไฟล์ `.bcfzip` เป็นรายการประเด็นได้ MarkupCraft เขียนไฟล์เป็น **BCF 2.1**

## สร้างไฟล์

1. เปิดแท็บ {{ui:Markups}}
2. กรองรายการให้เหลือเฉพาะสิ่งที่ต้องการส่ง เช่น {{ui:Status}} "เปิด" เฉพาะมาร์กอัปที่อยู่ในรายการเท่านั้นที่จะถูกส่งออก
3. เลือก {{ui:BCF}}
4. รอขณะที่ระบบสร้างสแนปช็อตของแต่ละมาร์กอัป ("กำลังสร้างสแนปช็อตสำหรับ BCF (5 จาก 20)…")

ผลลัพธ์: ไฟล์ "<name> markups.bcfzip" จะถูกดาวน์โหลด และแถบสถานะจะบอกจำนวนหัวข้อในไฟล์และขนาดไฟล์

## มีอะไรอยู่ในไฟล์

มาร์กอัปแต่ละรายการจะกลายเป็น **หัวข้อ** หนึ่งหัวข้อ

| ช่องของหัวข้อ | เติมด้วย |
|---|---|
| Title | หมายเลขรายการ เรื่อง และแผ่น เช่น "#4 เมฆบน A-101 — ผังพื้น" |
| Type | ชนิดของมาร์กอัป (เมฆ, คอลเอาต์, ความยาว…) |
| Status | เปิด, ยอมรับ, ปฏิเสธ หรือ เสร็จสมบูรณ์ |
| Labels | ชนิดของมาร์กอัปและแผ่น |
| Author and dates | ผู้สร้างมาร์กอัป วันที่สร้าง และวันที่แก้ไข |
| Assigned to, due date | จากรายการงานของมาร์กอัป เมื่อมีรายการงาน |
| Description | ข้อความหรือถ้อยคำของตราประทับ ค่าที่วัดได้ ความคิดเห็น และแผ่นกับไฟล์ |
| Comments | หนึ่งรายการต่อการตอบกลับ พร้อมผู้เขียนและวันที่ |
| Snapshot | ภาพของมาร์กอัปบนส่วนของแผ่นนั้น |
| Viewpoint | มุมมองจากด้านบนของตำแหน่งมาร์กอัปบนแผ่น |

การส่งออกมาร์กอัปเดิมซ้ำจะให้รหัสหัวข้อเดิม เครื่องมือที่นำเข้า BCF จึงจำได้ว่าเป็นประเด็นเดียวกัน

## สิ่งที่กลับเข้ามาเมื่อนำเข้า

{{ui:Import BCF}} อ่านไฟล์ BCF 2.0, 2.1 และ 3.0 (ทดสอบกับไฟล์ทดสอบ buildingSMART 3.0 ทางการ 19 ไฟล์ อ่านได้ทุกหัวข้อ และอ่านความคิดเห็นของ 3 ไฟล์ที่มีข้อความ) สำหรับหัวข้อที่เป็นของคุณเอง (รหัสหัวข้อเดียวกัน) ระบบจะเพิ่มความคิดเห็นใหม่เป็นการตอบกลับ และนำสถานะใหม่มาใช้ หัวข้ออื่นทั้งหมดจะกลายเป็นหมายเหตุบนแผ่นที่ป้ายกำกับหรือชื่อไฟล์ระบุ มิฉะนั้นจะอยู่บนแผ่นที่เปิดอยู่ โดยมีชื่อเรื่อง คำอธิบาย ผู้รับผิดชอบ และวันกำหนดส่งเป็นข้อความของหมายเหตุ และความคิดเห็นเป็นการตอบกลับ

| ในหัวข้อ BCF | ใน MarkupCraft |
|---|---|
| Title, description, assignee, due date | ข้อความของหมายเหตุ |
| ความคิดเห็นที่มีข้อความ | การตอบกลับ |
| Status Open, Accepted, Rejected, Completed (Closed, Resolved, Done นับเป็น Completed) | สถานะของมาร์กอัป |
| Author and creation date | ผู้เขียนและวันที่สร้างของหมายเหตุ |
| ตำแหน่งกล้อง | ตำแหน่งบนแผ่น เฉพาะหัวข้อที่ผูกกับแผ่นด้วยป้ายกำกับหรือชื่อไฟล์ |
| Model selection, hidden parts, clipping planes, snapshots | ไม่ถูกเก็บไว้: แผ่นไม่มีโมเดลให้แสดงข้อมูลเหล่านี้ |

## ข้อจำกัดที่ควรทราบ

- **แผ่นไม่ใช่โมเดล** viewpoint ชี้ไปยังตำแหน่งของมาร์กอัปบนกระดาษ วัดเป็นเมตรของกระดาษ ไม่ได้พาเครื่องมือ BIM ไปยังตำแหน่งในโมเดล ใช้สแนปช็อตและชื่อแผ่นเพื่อหาจุดนั้น
- **สถานะและชนิดเป็นของ MarkupCraft เอง** (เปิด, ยอมรับ, ปฏิเสธ, เสร็จสมบูรณ์; เมฆ, คอลเอาต์…) ไฟล์ประกาศไว้ตามที่ BCF อนุญาต แต่เครื่องมือที่มีรายการตายตัวของตัวเองอาจแมปหรือไม่สนใจค่าเหล่านี้
- **การนำเข้าให้ความคิดเห็น ไม่ใช่มุมมองโมเดล** {{ui:Import BCF}} เพิ่มการตอบกลับและสถานะให้มาร์กอัปที่คุณส่งออก และสร้างหมายเหตุสำหรับประเด็นอื่น แต่แสดงมุมมองกล้องของโมเดลไม่ได้ ดู [รายการมาร์กอัปและการส่งออก](topic:markups-list-and-export#import-bcf)
- การส่งมาร์กอัปกลับเป็น PDF มักง่ายกว่าสำหรับการตรวจแบบ BCF ใช้เพื่อนำความคิดเห็นแบบจากแผ่นเข้าสู่กระบวนการประสานงานโมเดล
