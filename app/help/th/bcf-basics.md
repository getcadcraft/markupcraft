BCF (BIM Collaboration Format) คือรูปแบบไฟล์เปิดสำหรับส่งต่อประเด็นระหว่างเครื่องมือ BIM โปรแกรมสร้างและประสานงานโมเดลหลายตัวนำเข้าไฟล์ `.bcfzip` เป็นรายการประเด็นได้ MarkupCraft เขียนไฟล์ **BCF 2.1**

## สร้างไฟล์

1. เปิดแท็บ {{ui:Markups}}
2. กรองรายการให้ตรงกับที่ต้องการส่ง เช่น {{ui:Status}} "เปิด" จะส่งออกเฉพาะมาร์กอัปที่อยู่ในรายการเท่านั้น
3. เลือก {{ui:BCF}}
4. รอขณะที่ระบบสร้างภาพสแนปช็อตของแต่ละมาร์กอัป ("กำลังสร้างภาพสแนปช็อตสำหรับ BCF (5 จาก 20)…")

ผลลัพธ์: ไฟล์ "<name> markups.bcfzip" ถูกดาวน์โหลด และแถบสถานะจะบอกจำนวนหัวข้อในไฟล์และขนาดไฟล์

## สิ่งที่อยู่ในไฟล์

แต่ละมาร์กอัปจะกลายเป็น **หัวข้อ** หนึ่งรายการ:

| ช่องของหัวข้อ | เติมด้วย |
|---|---|
| Title | หมายเลขจุดตรวจ หัวเรื่อง และแผ่น เช่น "#4 เมฆบน A-101 — ผังพื้น" |
| Type | ชนิดของมาร์กอัป (เมฆ, คอลเอาต์, ความยาว…) |
| Status | เปิด, ยอมรับ, ปฏิเสธ หรือ เสร็จสิ้น |
| Labels | ชนิดของมาร์กอัปและแผ่น |
| Author and dates | ผู้สร้างมาร์กอัป วันที่สร้าง และวันที่แก้ไข |
| Assigned to, due date | มาจากรายการจุดตรวจของมาร์กอัป เมื่อมีรายการนั้น |
| Description | ข้อความหรือถ้อยคำของตราประทับ ค่าที่วัดได้ ความเห็น และแผ่นกับไฟล์ |
| Comments | หนึ่งรายการต่อการตอบกลับ พร้อมผู้เขียนและวันที่ |
| Snapshot | ภาพของมาร์กอัปในส่วนของแผ่น |
| Viewpoint | มุมมองจากด้านบนของตำแหน่งมาร์กอัปบนแผ่น |

การส่งออกมาร์กอัปเดิมซ้ำจะได้รหัสหัวข้อเดิม เครื่องมือที่นำเข้า BCF จึงจดจำได้ว่าเป็นประเด็นเดียวกัน

## ข้อจำกัดที่ควรรู้

- **แผ่นไม่ใช่โมเดล** Viewpoint ชี้ไปยังตำแหน่งของมาร์กอัปบนกระดาษ วัดเป็นเมตรของกระดาษ ไม่ได้พาเครื่องมือ BIM ไปยังจุดในโมเดล ใช้ภาพสแนปช็อตและชื่อแผ่นเพื่อหาจุดนั้น
- **สถานะและชนิดเป็นของ MarkupCraft เอง** (เปิด, ยอมรับ, ปฏิเสธ, เสร็จสิ้น; เมฆ, คอลเอาต์…) ไฟล์ประกาศไว้ตามที่ BCF อนุญาต แต่เครื่องมือที่มีรายการคงที่ของตัวเองอาจแมปหรือไม่สนใจค่าเหล่านี้
- **การนำเข้าได้เฉพาะความเห็น ไม่ใช่มุมมองของโมเดล** {{ui:Import BCF}} เพิ่มการตอบกลับและสถานะให้มาร์กอัปที่คุณส่งออก และสร้างหมายเหตุสำหรับประเด็นอื่น จึงไม่สามารถแสดงกล้องของโมเดลได้ ดู [รายการมาร์กอัปและการส่งออก](topic:markups-list-and-export#import-bcf)
- การส่งมาร์กอัปกลับเป็น PDF มักง่ายกว่าสำหรับการตรวจแบบ BCF ใช้สำหรับนำความเห็นบนแบบเข้าสู่กระบวนการประสานงานโมเดล
