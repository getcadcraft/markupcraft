สำเนาที่มีมาร์กอัปคือ PDF ต้นฉบับที่เพิ่มความคิดเห็น (PDF annotations) เข้าไป หน้ากระดาษเอง ภาพวาด ข้อความ บุ๊กมาร์ก และลิงก์ จะถูกคัดลอกไว้เหมือนเดิม

## มาร์กอัปแต่ละชนิด

| MarkupCraft | บันทึกเป็น | โปรแกรมดู PDF อื่นแสดง |
|---|---|---|
| สี่เหลี่ยมผืนผ้า, เมฆกล่อง | Square annotation (เมฆ: ขอบเป็นเมฆ) | ความคิดเห็นรูปสี่เหลี่ยมหรือเมฆ |
| วงรี | Circle annotation | ความคิดเห็นรูปวงรี |
| รูปหลายเหลี่ยม, เมฆอิสระ | Polygon annotation (เมฆ: ขอบเป็นเมฆ) | ความคิดเห็นรูปหลายเหลี่ยมหรือเมฆ |
| โพลีไลน์ | PolyLine annotation | ความคิดเห็นโพลีไลน์ |
| เส้น, ลูกศร | Line annotation (ลูกศร: หัวลูกศรปิด) | ความคิดเห็นเส้นหรือลูกศร |
| ความยาว | Line annotation ที่ทำเครื่องหมายเป็นไดเมนชัน พร้อมการวัด | การวัดความยาว ในที่ที่ตัวแสดงรองรับ |
| พื้นที่ | Polygon annotation ที่ทำเครื่องหมายเป็นพื้นที่ พร้อมการวัด | การวัดพื้นที่ ในที่ที่รองรับ มิฉะนั้นเป็นรูปหลายเหลี่ยม |
| กลุ่มการนับ | Ink annotation หนึ่งรายการ มีวงแหวนต่อรายการ ข้อความคือ "group: n" | ความคิดเห็นหมึก |
| ปากกา, ไฮไลเตอร์ | Ink annotation (ไฮไลเตอร์ทำเครื่องหมายไว้) | ความคิดเห็นหมึก |
| ข้อความ | FreeText annotation | ความคิดเห็นเป็นกล่องข้อความ |
| คอลเอาต์ | FreeText annotation พร้อมลีดเดอร์คอลเอาต์ | ความคิดเห็นคอลเอาต์ |
| หมายเหตุ | Text annotation | โน้ตแปะที่เปิดออกเป็นข้อความ |
| ตราประทับ | Stamp annotation | ความคิดเห็นตราประทับ |

ทุกชนิดถูกบันทึกพร้อม:

- **รูปลักษณ์ของตัวเอง** วาดตรงตามที่ MarkupCraft วาดบนหน้าจอ จึงดูเหมือนกันในทุกโปรแกรมและพิมพ์ออกมาเหมือนกัน รวมถึงป้ายหมายเลขตรวจแก้ไข
- **ผู้เขียน** **วันที่สร้างและวันที่แก้ไข** **หัวข้อ** **ข้อความความคิดเห็น** (สำหรับกล่องข้อความและคอลเอาต์ คือข้อความและความคิดเห็น) **สี** และ **ความทึบ**
- **รายละเอียด MarkupCraft** ในรายการส่วนตัวที่โปรแกรมอื่นไม่สนใจ ได้แก่ สถานะ รายการตรวจแก้ไข รูปแบบ และชนิด จึงเปิดกลับมาได้ตรงทุกอย่าง

## กระทู้และสถานะ

- การตอบกลับแต่ละครั้งถูกบันทึกเป็นความคิดเห็นการตอบกลับที่เชื่อมกับมาร์กอัป พร้อมผู้เขียน วันที่ และข้อความ การตอบกลับไม่มีไอคอนของตัวเองบนแผ่น
- การเปลี่ยนสถานะแต่ละครั้งถูกบันทึกเป็นการตอบกลับที่มีสถานะการตรวจทาน โปรแกรมตรวจทานอื่นแสดงเป็น Accepted, Rejected หรือ Completed ส่วน Open ถูกบันทึกเป็นไม่มีสถานะ
- มาร์กอัปที่มีสถานะอื่นที่ไม่ใช่ Open แต่ไม่มีบันทึกการเปลี่ยนสถานะ จะได้การตอบกลับสถานะการตรวจทานหนึ่งรายการ เพื่อให้โปรแกรมอื่นเห็นสถานะด้วย
- การตอบกลับบนความคิดเห็นแบบอ่านอย่างเดียวจากไฟล์ต้นฉบับจะถูกบันทึกในลักษณะเดียวกัน โดยเชื่อมกับความคิดเห็นนั้น

## แต่ละแผ่น

- **มาตราส่วน:** แผ่นที่สอบเทียบแล้วจะได้ viewport การวัดที่ครอบหน้ากระดาษ (วิธีมาตรฐานในการเก็บมาตราส่วนของหน้า) และสำเนาการสอบเทียบของ MarkupCraft เอง
- **หมายเลขแผ่น:** หมายเลขที่พิมพ์ด้วย {{ui:เปลี่ยนชื่อแผ่น}} จะกลายเป็นป้ายหน้า เมื่อหน้าใดหน้าหนึ่งของไฟล์มีป้าย ทุกหน้าของไฟล์นั้นจะได้ป้ายหนึ่งอัน: หมายเลขที่พิมพ์ ถ้าไม่มีก็ใช้ป้ายเดิม ถ้าไม่มีอีกก็ใช้หมายเลขหน้า
- **ชื่อแผ่น:** ชื่อที่พิมพ์จะถูกบันทึกไว้สำหรับ MarkupCraft เท่านั้น โปรแกรมดูอื่นไม่แสดง

## ข้อความและอักขระ

ข้อความเขียนด้วยฟอนต์ Helvetica ซึ่งทุกโปรแกรมดู PDF มี อักษรที่อยู่นอกชุด Western European (Windows-1252) จะพิมพ์เป็น "?" ในสำเนา และข้อความบันทึกจะนับจำนวนให้

## แผ่นคำนวณและเหตุผล

แผ่นคำนวณและเหตุผลเก็บไว้ในรายการส่วนตัวของ PDF ชื่อ `/MarkupCraftShell` โปรแกรม PDF อื่นไม่สนใจ MarkupCraft รุ่นเก่ากว่าก็ไม่สนใจเช่นกัน และจะลบทิ้งในครั้งถัดไปที่บันทึกไฟล์นั้น

## ความคิดเห็นที่มีอยู่แล้ว

เมื่อเปิด PDF ที่มีความคิดเห็นอยู่แล้ว:

- ความคิดเห็นของ MarkupCraft เองจะถูกอ่านกลับมาตรงทุกอย่าง ถ้าโปรแกรมอื่นย้ายหรือปรับขนาดความคิดเห็นหนึ่งรายการ ตำแหน่งใหม่จะเป็นตำแหน่งที่ใช้
- สี่เหลี่ยมผืนผ้า วงรี เส้น โพลีไลน์ รูปหลายเหลี่ยม หมึก กล่องข้อความ และโน้ตแปะจากโปรแกรมอื่นจะกลายเป็นมาร์กอัปที่แก้ไขได้ **เมื่อบันทึก MarkupCraft จะลบต้นฉบับและเขียนใหม่ด้วยวิธีของตัวเอง** พร้อมป๊อปอัปและการตอบกลับ รูปลักษณ์อาจเปลี่ยนเล็กน้อย
- สถานะการตรวจทานจากโปรแกรมอื่นจะตั้งสถานะ โดยอันที่ใหม่กว่าจะชนะ
- สิ่งอื่นทั้งหมด (ไฮไลต์ข้อความ ตราประทับของโปรแกรมอื่น และชนิดพิเศษ) จะ **คงไว้โดยไม่แตะต้อง** ในสำเนา เป็นแบบอ่านอย่างเดียว
- ลิงก์และช่องฟอร์มจะคงไว้โดยไม่แตะต้อง และไม่ถูกแสดงในรายการ

การบันทึกไฟล์เดิมซ้ำจะไม่ทำให้มีอะไรซ้ำ: มาร์กอัปที่ MarkupCraft อ่านมาจะถูกแทนที่ ไม่ถูกเพิ่มซ้ำ

## สิ่งที่ไม่เปลี่ยน

ไฟล์ต้นฉบับบนดิสก์ไม่ถูกเปลี่ยนเลย สำเนาไม่ได้ถูกปรับให้เล็กลง จึงอาจใหญ่กว่าต้นฉบับเล็กน้อย PDF ที่มีการป้องกัน (เข้ารหัส) ไม่สามารถบันทึกได้
