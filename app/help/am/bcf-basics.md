BCF (BIM የትብብር ቅርጸት) በBIM መሳሪያዎች መካከል ጉዳዮችን ለማስተላለፍ የሚያገለግል ክፍት የፋይል ቅርጸት ነው። ብዙ የሞዴል ማስተባበሪያና የንድፍ ፕሮግራሞች `.bcfzip` ፋይልን እንደ የጉዳዮች ዝርዝር ማስገባት ይችላሉ። MarkupCraft **BCF 2.1** ይጽፋል።

## አንድ መፍጠር

1. የ{{ui:Markups}} ትርን ይክፈቱ።
2. ዝርዝሩን ወደሚፈልጉት ይዘው ያጣሩ፤ ለምሳሌ {{ui:Status}} "Open"። ዝርዝሩ ውስጥ ያሉት ምልክቶች ብቻ ይላካሉ።
3. {{ui:BCF}} ይምረጡ።
4. ለእያንዳንዱ ምልክት ቅጽበታዊ ምስል እስኪሠራ ይጠብቁ ("ለBCF ቅጽበታዊ ምስሎችን በመሥራት ላይ (5 ከ 20)…")።

ውጤት: "<name> markups.bcfzip" ይወርዳል፤ የሁኔታ አሞሌው ስንት ርዕሶች እንዳሉት እና የፋይሉን መጠን ያሳያል።

## ውስጡ ያለው

እያንዳንዱ ምልክት አንድ **ርዕስ** ይሆናል።

| የርዕስ መስክ | የሚሞላው |
|---|---|
| ርዕስ | የማረሚያ ቁጥር፣ ጉዳይና ሉህ፤ ለምሳሌ "#4 Cloud on A-101 — Floor plan" |
| ዓይነት | የምልክቱ ዓይነት (Cloud, Callout, Length…) |
| ሁኔታ | Open, Accepted, Rejected ወይም Completed |
| መለያዎች | የምልክቱ ዓይነትና ሉሁ |
| ጸሐፊና ቀኖች | የምልክቱ ጸሐፊ፣ የተፈጠረበትና የተስተካከለበት ቀን |
| የተመደበለት፣ የመጨረሻ ቀን | ማረሚያ ንጥል ካለው፣ ከእሱ የሚወሰድ |
| መግለጫ | ጽሑፉ ወይም የማህተሙ ቃል፣ የተለካው እሴት፣ አስተያየቱ፣ እና ሉሁና ፋይሉ |
| አስተያየቶች | ለእያንዳንዱ ምላሽ አንድ፣ ከጸሐፊና ቀን ጋር |
| ቅጽበታዊ ምስል | ምልክቱ በሉሁ ላይ ያለበት ቦታ ምስል |
| የእይታ ነጥብ | የምልክቱ ቦታ በሉሁ ላይ ከላይ የሚታይ እይታ |

ተመሳሳዩን ምልክት እንደገና ሲልኩ ተመሳሳይ የርዕስ መለያ ይሰጠዋል፤ ስለዚህ BCF የሚያስገባ መሳሪያ ተመሳሳዩን ጉዳይ ማወቅ ይችላል።

## ማወቅ ያለብዎት ገደቦች

- **ሉህ ሞዴል አይደለም።** የእይታ ነጥቡ የምልክቱን ቦታ በወረቀቱ ላይ ያመለክታል፤ በወረቀት ላይ በሜትር ይለካል። BIM መሳሪያን ወደ ሞዴሉ ቦታ አያደርስም። ቦታውን ለማግኘት ቅጽበታዊ ምስሉንና የሉሁን ስም ይጠቀሙ።
- **ሁኔታዎችና ዓይነቶች የMarkupCraft የራሳቸው ናቸው** (Open, Accepted, Rejected, Completed፤ Cloud, Callout…)። ፋይሉ እንደሚፈቅደው ያስታውቃቸዋል፤ ነገር ግን የራሱ ቋሚ ዝርዝር ያለው መሳሪያ ሊያዛምዳቸው ወይም ሊተዋቸው ይችላል።
- **ማስገባት አስተያየቶችን ያመጣል እንጂ የሞዴል እይታዎችን አያመጣም።** {{ui:Import BCF}} ለላኩዋቸው ምልክቶች ምላሾችንና ሁኔታዎችን ይጨምራል፣ ለሌሎች ጉዳዮችም ማስታወሻ ይሰራል፤ የሞዴል ካሜራ ማሳየት አይችልም። ተመልከቱ [የምልክቶች ዝርዝርና ላክ](topic:markups-list-and-export#import-bcf)።
