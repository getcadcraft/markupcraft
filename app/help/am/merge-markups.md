ሁለት ሰዎች ተመሳሳዩን PDF በሁለት ቅጂዎች ምልክት ያደርጋሉ። የነኩት የተለያዩ ምልክቶች ከሆኑ ቅጂዎቹ በእጅ ሳይሆን በፕሮግራም ሊዋሃዱ ይችላሉ።

## እንዴት ይሠራል

MarkupCraft የሚያስቀምጠው እያንዳንዱ ምልክት የራሱን ስም (መለያውን) በPDF ውስጥ ይይዛል፤ ስሙ ፈጽሞ አይለወጥም። ውህደቱ ምልክቶችን በዚያ ስም ይፈልጋል፤ በፋይሉ ውስጥ ባላቸው ቦታ አይደለም፤ ምክንያቱም እያንዳንዱ ፕሮግራም ሲያስቀምጥ ቦታዎቹን እንደገና ይቆጥራል። ማስታወሻዎችና የታሸጉ የግል ማስታወሻዎች በተመሳሳይ መንገድ ይጣመራሉ።

ሉሆቹ በፍጹም አይነኩም፤ ሁለቱም ቅጂዎች ተመሳሳይ የገጽ ብዛት ሊኖራቸው ይገባል። ከለያዩ ውህደቱ የእርስዎን ቅጂ እንዳለ ያስቀራል እና ይላል፤ ምክንያቱም ገጾችን መጨመርና ማስወገድ የሰው ሥራ ነው።

## ማዋቀር

Git በእያንዳንዱ ማከማቻ አንድ ጊዜ ሁለት መስመሮች ያስፈልጉታል:

```
# .gitattributes
*.pdf merge=cadcraft

# አንድ ጊዜ፣ በእያንዳንዱ ኮምፒውተር ላይ
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

git ከሌለ `cadcraft merge <base> <ours> <theirs> -o <result>` ን ያስኪዱ። Fossil እና Mercurial ተመሳሳዩን ሦስት ፋይሎች በየራሳቸው የውህደት መሳሪያ ቅንብር ይወስዳሉ። ከሥዕሉ ጋር የሚጓዘው የተግባር ፋይል (`<name>.markups.json`፣ ተመልከት [ተግባር የሚያደርጉ ምልክቶች](topic:markups-that-act)) በተመሳሳይ መንገድ፣ እንደ ተራ ጽሑፍ ይዋሃዳል።

## ህጎቹ

- በአንድ ወገን ብቻ የተለወጠ ምልክት ይወሰዳል። በሁለቱም ወገን ያለው ተመሳሳይ ለውጥ አንድ ጊዜ ይወሰዳል።
- ተመሳሳይ ምልክት በሁለት መንገድ ከተለወጠ **ግጭት** ነው: የእርስዎ ወገን ይቀራል እና ሪፖርቱ ሁለቱንም ይዘረዝራል። ውጤቱን ይክፈቱና ያንን ምልክት በእጅ ያስተካክሉ።
- በማናቸውም ወገን የተጨመረ ምልክት ይቀራል። በአንድ ወገን የተሰረዘና በሌላው ያልተነካ ይሰረዛል። በአንድ ወገን የተሰረዘና በሌላው የተለወጠ: ይሰረዛል እና ይዘገባል።
- ንብርብሮች፣ አምዶች፣ መዝገቦችና ማስታወሻዎች ተመሳሳይ ህጎችን ይከተላሉ።
- የታሸጉ የግል ማስታወሻዎች ፈጽሞ አይከፈቱም: የሁለቱም ወገን ብሎኮች እንዳሉ ይቀራሉ።

የተዋሃደው ፋይል ልክ እንደ MarkupCraft የራሱ አስቀምጥ፣ የእርስዎን ቅጂ ሙሉ በሙሉ እንደገና መጻፍ ነው። ምንም አይጫንም፤ ሁሉም በእርስዎ ኮምፒውተር ላይ ይሠራል።
