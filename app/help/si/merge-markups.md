පුද්ගලයින් දෙදෙනෙක් එකම PDF පිටපත් දෙකකින් සලකුණු කරයි. ඔව්හු වෙනස් සලකුණු ස්පර්ශ කළ නම්, පිටපත් අතින් නොව වැඩසටහනකින් එක් කළ හැක.

## එය ක්‍රියා කරවන දේ

MarkupCraft සුරකින සෑම සලකුණකම PDF එක තුළ එහි තමන්ගේම නමක් (එහි ID) ඇත, සහ එම නම කිසිවිටෙක වෙනස් නොවේ. එක්කිරීම සලකුණු සොයන්නේ ඒ නමෙන්, ගොනුවේ ඒවායේ ස්ථානයෙන් නොව, මන්ද සෑම වැඩසටහනක්ම සුරකින විට ස්ථාන නැවත අංක කරයි. සටහන් සහ සීල් කළ පෞද්ගලික සටහන් ද එලෙසම ගැළපේ.

පත්‍ර කිසිවිටෙක ස්පර්ශ නොවේ: පිටපත් දෙකේම එකම පිටු ගණන තිබිය යුතුයි. ඒවා වෙනස් නම්, එක්කිරීම ඔබේ පිටපත එලෙසම තබා එය කියයි, මන්ද පිටු එකතු කිරීම හෝ ඉවත් කිරීම පුද්ගලයෙකුගේ වැඩකි.

## සකසන්න

Git හට එක් ගබඩාවකට වරක් රේඛා දෙකක් අවශ්‍යයි:

```
# .gitattributes
*.pdf merge=cadcraft

# එක් වරක්, සෑම පරිගණකයකම
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

git නැතිව, `cadcraft merge <base> <ours> <theirs> -o <result>` ධාවනය කරන්න. Fossil සහ Mercurial එකම ගොනු තුන ඒවායේම merge-tool සැකසීමේදී ගනී. ඇඳීමක් සමඟ එන කාර්ය ගොනුව (`<name>.markups.json`, බලන්න [ක්‍රියා කරන සලකුණු](topic:markups-that-act)) සාමාන්‍ය පෙළ ලෙස එලෙසම එක් වේ.

## නීති

- එක් පැත්තක පමණක් වෙනස් කළ සලකුණ ගනී. දෙපැත්තේම එකම වෙනස එක් වරක් ගනී.
- එම සලකුණ දෙආකාරයකට වෙනස් කළ විට එය **ගැටුමකි**: ඔබේ පැත්ත පවතී සහ වාර්තාවේ දෙකම ලැයිස්තුගත වේ. ප්‍රතිඵලය විවෘත කර එම සලකුණ අතින් නිවැරදි කරන්න.
- කුමන පැත්තේ හෝ එකතු කළ සලකුණ තබා ගනී. එක් පැත්තක ඉවත් කළ සහ අනෙක් පැත්තේ නොවෙනස් එකක් ඉවත් වේ. එක් පැත්තක ඉවත් කළ සහ අනෙක් පැත්තේ වෙනස් කළ: ඉවත් කර වාර්තා කරයි.
- ලේයර, තීරු, වාර්තා සහ සටහන් එම නීතිවලට අනුව යයි.
- සීල් කළ පෞද්ගලික සටහන් කිසිවිටෙක විවෘත නොවේ: දෙපැත්තේම කොටස් එලෙසම තබා ගනී.

එක්කළ ගොනුව ඔබේ පිටපතේ සම්පූර්ණ නැවත ලිවීමකි, MarkupCraft හි තමන්ගේ සුරැකීම මෙන්. කිසිවක් උඩුගත නොවේ; සියල්ල ඔබේ පරිගණකයේ ක්‍රියාත්මක වේ.
