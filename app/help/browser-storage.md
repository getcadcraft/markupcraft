MarkupCraft has no account and no server storage. A few small things are kept in your browser's storage for this website, and everything else lives in your files.

## What is kept in the browser

| What | Set where | Kept as |
|---|---|---|
| Your author name | The name button in the status bar, or {{ui:Settings}} | One name |
| MarkupCraft settings | {{ui:Settings}}, {{ui:MarkupCraft}} tab: color and line weight of new markups, where paste puts copies, units (see [MarkupCraft settings](topic:settings)) | One set |
| Tool settings | {{ui:Properties}} while a drawing tool is on: color, line, fill, opacity and text size per tool, the chosen stamp, the count group name | One set |
| Tool chest | The {{ui:Tools}} tab | Up to 500 tools |
| What you last copied | {{ui:Copy}} or {{ui:Cut}} | The copied markups, so another tab can paste them; replaced by the next copy |
| Stamp picture and signature | {{ui:Picture…}} and {{ui:My signature…}} in the stamp list | The last picture and your signature |
| Recovery copies | Kept for you while a PDF has unsaved markups | The PDF and its markups, removed when you save, close or discard it; kept up to 30 days |

## What that means

- **Per browser, per computer.** Chrome and Firefox on the same computer each have their own. Your laptop and the office desktop each have their own. Nothing syncs between them, even if you sign in to the browser.
- **Private and incognito windows** start empty and forget everything when they close.
- **Clearing site data erases it.** Clearing cookies and site data for this website, or for all sites, in the browser's settings removes your name, settings and chest. Some cleanup tools and some company policies do this automatically.
- **Nothing is uploaded.** These values never leave the computer, except your name inside the PDFs you save. Recovery copies stay in this browser too.

:::safari
Safari can delete a website's stored data after some weeks without a visit. Open MarkupCraft now and then, and keep an exported tool chest.
:::

## What is not kept in the browser

- **Your markups, for good.** They belong in the "(marked up)" PDF you save. The recovery copy is a safety net for a crash or a closed tab, not a place to keep work: it goes when you save, and clearing site data removes it. See [Recover your work](common:recover).
- **Your open files.** Each time you open MarkupCraft, open the PDFs again.
- **The sheet you were on, zoom, filters and undo history.** These last until you close the set or the tab.

## Back up and move your setup

- **Tool chest:** {{ui:Tools}}, then {{ui:Export}}. On the other browser or computer, {{ui:Tools}}, then {{ui:Import}}.
- **Name:** type it again on the other browser (click the name button in the status bar).
- **Tool settings:** set them again, or save each styled markup as a tool so it travels with the chest.

## Start fresh

To reset everything, clear this website's data in your browser's settings. Your name, settings and chest go; the six default tools come back.

## The offline copy

{{ui:Save for offline}} in the bar at the top stores the app's own files (with the PDF reader and writer, about 6 MB) in the browser too, separately from these settings. Clearing site data removes that copy as well; click "Offline ready" and choose "Remove the offline copy" to remove only it. See [Working offline](common:offline).

Cloud saving and sync between computers are not available yet.
