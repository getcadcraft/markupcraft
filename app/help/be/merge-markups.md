Два людзі адзнакоўваюць адзін PDF у дзвюх копіях. Калі яны закранулі розныя паметкі, копіі можна аб’яднаць праграмай, а не ўручную.

## Што ўсё робіць магчымым

Кожная паметка, якую захоўвае MarkupCraft, нясе ўласную назву (свой ідэнтыфікатар) унутры PDF, і назва ніколі не мяняецца. Аб’яднанне знаходзіць паметкі па гэтай назве, а не па месцы ў файле, бо кожная праграма перанумоўвае месцы пры захаванні. Заўвагі і запячатаныя прыватныя заўвагі супастаўляюцца так жа.

Аркушы ніколі не змяняюцца: абедзве копіі павінны мець аднолькавую колькасць старонак. Калі іх колькасць розная, аб’яднанне пакідае вашу копію такой, якая яна ёсць, і паведамляе пра гэта, бо даданне або выдаленне старонак — праца для чалавека.

## Наладзіць

Git патрэбны два радкі адзін раз на рэпазітар:

```
# .gitattributes
*.pdf merge=cadcraft

# адзін раз, на кожным камп’ютары
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Без git запусціце `cadcraft merge <base> <ours> <theirs> -o <result>`. Fossil і Mercurial прымаюць тыя ж тры файлы ў сваёй наладзе інструмента аб’яднання. Файл задач, які ідзе з чарцяжом (`<name>.markups.json`, гл. [Паметкі, якія дзейнічаюць](topic:markups-that-act)), аб’ядноўваецца так жа, як звычайны тэкст.

## Правілы

- Паметка, зменена толькі з аднаго боку, прымаецца. Аднолькавая змена з абодвух бакоў прымаецца адзін раз.
- Тая ж паметка, зменена двума спосабамі, — гэта **канфлікт**: ваш бок застаецца, а справаздача пералічвае абодва. Адкрыйце вынік і выпраўце гэтую паметку ўручную.
- Паметка, дададзеная з любога боку, захоўваецца. Тая, якую выдалілі з аднаго боку і не чапалі з другога, выдаляецца. Выдалена з аднаго боку, зменена з другога: выдаляецца і паведамляецца.
- Пласты, слупкі, запісы і заўвагі падпарадкоўваюцца тым жа правілам.
- Запячатаныя прыватныя заўвагі ніколі не адкрываюцца: блокі абодвух бакоў захоўваюцца такімі, якія яны ёсць.

Аб’яднаны файл — гэта поўны перазапіс вашай копіі, як звычайнае {{ui:Захаваць}} у MarkupCraft. Нішто не выкладваецца ў сетку; усё адбываецца на вашым камп’ютары.
