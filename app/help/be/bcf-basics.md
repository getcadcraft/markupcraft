BCF (BIM Collaboration Format) — адкрыты фармат файлаў для абмену пытаннямі паміж інструментамі BIM. Многія праграмы каардынацыі мадэляў і стварэння мадэляў могуць імпартаваць файл `.bcfzip` як спіс пытанняў. MarkupCraft запісвае **BCF 2.1**.

## Стварыць файл

1. Адкрыйце ўкладку {{ui:Паметкі}}.
2. Адфільтруйце спіс на тое, што хочаце адправіць, напрыклад {{ui:Статус}} «Адкрыта». Экспартуюцца толькі паметкі са спісу.
3. Выберыце {{ui:BCF}}.
4. Пачакайце, пакуль робіцца здымак кожнай паметкі («Стварэнне здымкаў для BCF (5 з 20)…»).

Вынік: спампоўваецца «<name> markups.bcfzip», а ў радку стану паказваецца, колькі тэм у файле і яго памер.

## Што ў ім ёсць

Кожная паметка становіцца адной **тэмай**.

| Поле тэмы | Што запаўняецца |
|---|---|
| Title | Нумар заўвагі, тэма і аркуш, напрыклад «#4 Воблака на A-101 — План паверха» |
| Type | Від паметкі (Воблака, Выноска, Даўжыня…) |
| Status | Адкрыта, Прынята, Адхілена або Завершана |
| Labels | Від паметкі і аркуш |
| Author and dates | Аўтар паметкі, даты стварэння і змянення |
| Assigned to, due date | З яе пункта заўваг, калі ён ёсць |
| Description | Яе тэкст або надпіс штампа, вымераная велічыня, каментарый, аркуш і файл |
| Comments | Адзін на кожны адказ, з аўтарам і датай |
| Snapshot | Выява паметкі на яе ўчастку аркуша |
| Viewpoint | Выгляд зверху на месца паметкі на аркушы |

Паўторны экспарт той самай паметкі дае той самы ID тэмы, таму інструмент, які імпартуе BCF, пазнае яе як тое самае пытанне.

## Што вяртаецца пры імпарце

{{ui:Імпартаваць BCF}} чытае файлы BCF 2.0, 2.1 і 3.0 (праверана на 19 афіцыйных тэставых файлах buildingSMART 3.0: прачытаныя ўсе тэмы і каментарыі трох з іх, што маюць тэкст). Для тэмы, якая належыць вам (той самы ID тэмы), ён дадае новыя каментарыі як адказы і бярэ новы статус. Любая іншая тэма становіцца нататкай на аркушы, названым яе меткай або назвай файла, а калі такога няма — на адкрытым аркушы. Яе назва, апісанне, выканаўца і тэрмін становяцца тэкстам нататкі, а каментарыі — адказамі.

| У тэме BCF | У MarkupCraft |
|---|---|
| Title, description, assignee, due date | Тэкст нататкі |
| Comments with text | Адказы |
| Status Open, Accepted, Rejected, Completed (Closed, Resolved, Done лічацца як Completed) | Статус паметкі |
| Author and creation date | Аўтар і дата нататкі |
| Camera position | Месца на аркушы, толькі для тэмы, звязанай з аркушам па меткі або назве файла |
| Model selection, hidden parts, clipping planes, snapshots | Не захоўваецца: у аркуша няма мадэлі, каб іх паказаць |

## Межы

- **Аркуш — не мадэль.** Кропка агляду паказвае на месца паметкі на паперы, вымераным у метрах паперы. Яна не вядзе інструмент BIM да месца ў мадэлі. Выкарыстоўвайце здымак і назву аркуша, каб знайсці месца.
- **Статусы і тыпы — уласныя для MarkupCraft** (Open, Accepted, Rejected, Completed; Cloud, Callout…). Файл іх абвяшчае, як дазваляе BCF, але інструмент з уласнымі фіксаванымі спісамі можа іх адлюстраваць інакш або ігнараваць.
- **Імпарт вяртае каментарыі, а не выгляды мадэлі.** {{ui:Імпартаваць BCF}} дадае адказы і статусы да экспартаваных вамі паметак і стварае нататкі з іншых пытанняў; ён не можа паказаць камеру мадэлі. Гл. [Спіс паметак і экспарт](topic:markups-list-and-export#import-bcf).
- Адпраўка паметак назад як PDF часта прасцей для праверкі чарцяжоў. BCF патрэбны, каб каментарыі да чарцяжа траплялі ў працэс каардынацыі мадэлі.
