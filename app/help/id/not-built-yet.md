MarkupCraft masih dalam pengembangan. Ini yang **tidak** dilakukan build saat ini, agar Anda bisa merencanakan pekerjaan. Ini menggambarkan build hari ini, bukan janji.

## Bekerja dengan orang lain

| Belum dibuat | Lakukan ini hari ini |
|---|---|
| Penyimpanan dan sinkronisasi cloud antarkomputer | Simpan PDF bersama file proyek Anda. Penyimpanan cloud belum tersedia. |
| Menggabungkan dua salinan markup dari dua orang | Bagi lembar di antara peninjau, atau salin beberapa markup dengan {{key:Mod+C}} dan {{key:Mod+V}}. RFI, submittal, dan log harian dapat digabung: lihat [Lacak RFI, submittal, dan log harian](topic:field-records). |
| Tim, notifikasi, dan proyek cloud untuk RFI dan submittal | Kirim PDF dan gunakan {{ui:Gabungkan}} untuk menggabungkan salinan. |
| RFI, submittal, dan log harian dalam sesi live | Setiap orang bekerja pada salinannya sendiri; gabungkan salinan dengan {{ui:Gabungkan}}. |
| Menggabungkan perubahan dua orang pada kolom berbeda dari satu catatan | Salinan yang terakhir diubah menang untuk catatan itu secara utuh (utas dan nama lampirannya digabungkan). Sepakati siapa yang mengedit catatan mana. |
| Alat asisten untuk RFI, submittal, dan log harian | Gunakan di tab {{ui:Lapangan}}. Asisten bisa bekerja dengan markup: lihat [Gunakan MarkupCraft dengan asisten AI](topic:use-with-ai-assistants). |
| Mengedit atau menghapus balasan yang sudah dikirim | Urungkan segera, atau tambahkan balasan koreksi. |
| Mengubah pembuat markup | Atur nama Anda sebelum mulai. |

## Markup

| Belum dibuat | Lakukan ini hari ini |
|---|---|
| Stempel dengan kolom isian, tanda tangan digital tersertifikasi | Gunakan stempel teks khusus, yang memuat nama dan tanggal Anda, atau gambar tanda tangan Anda. |
| Melampirkan file selain foto (dokumen, video) | Simpan di samping PDF dan rujuk dalam komentar. |
| Tautan ke situs web atau ke file yang tidak terbuka | Tulis alamat atau nama file dalam komentar. |
| Set status kustom | Gunakan empat status, dan subjek untuk hal yang lebih rumit. |
| Mengedit komentar yang datang bersama file sebagai hanya-baca (sorotan teks, stempel program lain) | Balas komentar tersebut, atau gambar markup MarkupCraft di sampingnya. |
| Goresan pena yang peka tekanan | Atur tebal garis. |

## Konten halaman itu sendiri

| Belum dibuat | Lakukan ini hari ini |
|---|---|
| Menggambar bentuk baru langsung ke halaman | Gambar sebagai markup, lalu {{ui:Masukkan ke halaman}}. Lihat [Ubah konten halaman itu sendiri](topic:page-content). |
| Memutar objek halaman ke sudut apa pun | Pindahkan dan ubah ukurannya; putar seluruh halaman dengan {{ui:Halaman}}. |
| Mengubah font atau ukuran satu baris teks, atau teks yang mengalir lebih dari satu baris | Ubah kata satu baris pada satu waktu; untuk kata baru dengan font lain, tambahkan markup teks. |
| Mengedit isi gambar hasil pindai | Ganti gambar, atau beri markup. |
| Mengedit PDF terenkripsi atau bertanda tangan | Minta salinan yang tidak ditandatangani; markup bekerja pada PDF apa pun. |

## Mengukur

| Belum dibuat | Lakukan ini hari ini |
|---|---|
| Pengukuran radius | Gambar {{ui:Busur}} di sepanjangnya, atau ukur {{ui:Panjang}} melintangnya lalu bagi dua. |
| Mengedit sudut potongan | Hapus potongan dan gambar ulang. |
| Menerapkan satu skala ke banyak lembar sekaligus | Kalibrasi setiap lembar; memilih preset membutuhkan beberapa detik per lembar. |
| Beberapa skala pada satu lembar (viewport) | Kalibrasi ke gambar yang paling sering Anda ukur. Mengubah skala lembar mengukur ulang semuanya di lembar itu, jadi catat nilai detail sebelum Anda mengkalibrasi ulang untuknya. |
| Snap ke garis dalam gambar | Perbesar sebelum mengklik, atau ketik panjang dan sudut (lihat [Sketsa sesuai skala](topic:calibrate-and-measure#sketch-to-scale)). |
| Perhitungan volume (takeoff) lengkap dengan item, rakitan, dan harga | Gunakan TakeoffCraft, aplikasi takeoff keluarga CadCraft. |

## Lembar dan file

| Belum dibuat | Lakukan ini hari ini |
|---|---|
| Membatalkan perubahan halaman (putar, pindahkan, sisipkan, hapus) | Tutup tanpa menyimpan dan buka lagi PDF asli. Lihat [Cetak, dan ubah halaman](topic:pages-and-printing). |
| Menutup satu file dari satu set | {{ui:Tutup}} menutup seluruh set; buka lagi file yang Anda perlukan. |
| Menyimpan set sebagai proyek untuk dibuka lagi sekaligus | Buka lagi PDF yang sama. |
| Mencetak dengan skala pilihan, atau beberapa lembar per kertas | Gunakan dialog pencetak peramban Anda, atau cetak salinan tersimpan dari penampil PDF lain. |

## Daftar dan ekspor

| Belum dibuat | Lakukan ini hari ini |
|---|---|
| Menempatkan isu BCF yang diimpor di posisi modelnya | Isu impor yang tidak terkait lembar ditumpuk di kiri atas: pindahkan. |
| Mengimpor set alat dari program markup lain | Bangun ulang alat yang Anda perlukan dan simpan ke kotak alat; ekspor kotak alat untuk kantor. |

## Bandingkan

| Belum dibuat | Lakukan ini hari ini |
|---|---|
| Membandingkan teks yang diatur dengan font, atau daftar perubahan | Gunakan overlay dan slider, atau {{ui:Garis yang berubah}} untuk garis yang digambar. |
| Membandingkan lembar hasil pindai berdasarkan garisnya | Gunakan overlay gambar. |
| Menyejajarkan setiap pasangan secara otomatis saat membandingkan seluruh set | Bandingkan satu pasangan yang bergeser secara terpisah dan gunakan {{ui:Sejajarkan dengan dua titik}}. |

## Panel

| Belum dibuat | Lakukan ini hari ini |
|---|---|
| Memindahkan bilah alat atau bilah status | Hanya dua panel samping yang bisa dipindahkan. |

## Platform

- **Desktop:** MarkupCraft berjalan di peramban pada Mac, Windows, Linux, dan iPad, dan di CadCraft Studio, aplikasi desktop dengan semua delapan aplikasi dalam satu instalasi.
- MarkupCraft masih dalam pengembangan. Label dan perilaku mungkin masih berubah, dan bantuan ini ikut berubah.
