இரண்டு நபர்கள் இரண்டு நகல்களில் ஒரே PDF ஐக் குறியிடுகிறார்கள். அவர்கள் வெவ்வேறு குறியீடுகளைத் தொட்டிருந்தால், நகல்களை கைமுறையாக அல்ல, ஒரு நிரல் இணைக்க முடியும்.

## அதை இயக்குவது எது

MarkupCraft சேமிக்கும் ஒவ்வொரு குறியீடும் PDF க்குள் தனது சொந்தப் பெயரை (அதன் அடையாள எண்) சுமக்கிறது, அந்தப் பெயர் ஒருபோதும் மாறாது. இணைப்பு குறியீடுகளை அவற்றின் பெயரால் தேடுகிறது, கோப்பில் அவற்றின் இடத்தால் அல்ல; ஏனெனில் ஒவ்வொரு நிரலும் சேமிக்கும்போது இடங்களை மறுஎண்ணிடுகிறது. குறிப்புகளும் மூடப்பட்ட தனிப்பட்ட குறிப்புகளும் அதே வழியில் பொருத்தப்படுகின்றன.

தாள்கள் ஒருபோதும் தொடப்படாது: இரு நகல்களிலும் ஒரே எண்ணிக்கையிலான பக்கங்கள் இருக்க வேண்டும். வேறுபட்டால், இணைப்பு உங்கள் நகலை அப்படியே வைத்திருக்கும், அதைச் சொல்லும்; ஏனெனில் பக்கங்களைச் சேர்ப்பதும் நீக்குவதும் ஒரு நபரின் வேலை.

## அமைப்பது

git க்கு ஒவ்வொரு களஞ்சியத்திற்கும் ஒருமுறை இரண்டு வரிகள் தேவை:

```
# .gitattributes
*.pdf merge=cadcraft

# ஒருமுறை, ஒவ்வொரு கணினியிலும்
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

git இல்லாமல், `cadcraft merge <base> <ours> <theirs> -o <result>` ஐ இயக்கு. Fossil மற்றும் Mercurial அதே மூன்று கோப்புகளை அவற்றின் சொந்த இணைப்புக் கருவி அமைப்பில் எடுக்கும். ஒரு வரைபடத்துடன் வரும் பணிக் கோப்பு (`<name>.markups.json`, பார்க்க [செயல்படும் குறியீடுகள்](topic:markups-that-act)) சாதாரண உரையாக அதே வழியில் இணையும்.

## விதிகள்

- ஒரு பக்கத்தில் மட்டும் மாற்றப்பட்ட குறியீடு எடுக்கப்படும். இரு பக்கங்களிலும் ஒரே மாற்றம் ஒருமுறை எடுக்கப்படும்.
- இரு வழிகளில் மாற்றப்பட்ட அதே குறியீடு ஒரு **முரண்பாடு**: உங்கள் பக்கம் இருக்கும், அறிக்கை இரண்டையும் பட்டியலிடும். முடிவை திறந்து அந்தக் குறியீட்டைக் கைமுறையாகச் சரி செய்.
- ஒரு பக்கத்தில் சேர்க்கப்பட்ட குறியீடு வைக்கப்படும். ஒரு பக்கத்தில் நீக்கப்பட்டு மறுபக்கத்தில் தொடப்படாததை நீக்கப்படும். ஒரு பக்கத்தில் நீக்கப்பட்டு மறுபக்கத்தில் மாற்றப்பட்டால்: அது நீக்கப்படும், மேலும் அறிக்கை செய்யப்படும்.
- அடுக்குகள், நெடுவரிசைகள், பதிவுகள் மற்றும் குறிப்புகள் அதே விதிகளைப் பின்பற்றும்.
- மூடப்பட்ட தனிப்பட்ட குறிப்புகள் ஒருபோதும் திறக்கப்படாது: இரு பக்கங்களின் தொகுதிகளும் அப்படியே வைக்கப்படும்.

இணைக்கப்பட்ட கோப்பு உங்கள் நகலின் முழு மீண்டும் எழுதுதல் ஆகும், MarkupCraft இன் சொந்த சேமிப்பைப் போல. எதுவும் பதிவேற்றப்படுவதில்லை; அனைத்தும் உங்கள் கணினியில் இயங்கும்.
