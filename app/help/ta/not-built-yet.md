MarkupCraft உருவாக்கத்தில் உள்ளது. தற்போதைய பதிப்பு **செய்யாதவை** இவை, அதற்கேற்ப நீங்கள் திட்டமிடலாம். இது இன்றைய பதிப்பை விவரிக்கிறது, வாக்குறுதிகளை அல்ல.

## பிறருடன் பணியாற்றுதல்

| இன்னும் உருவாக்கப்படவில்லை | இன்று இதைச் செய்யவும் |
|---|---|
| கணினிகளுக்கு இடையே மேகத்தில் சேமிப்பு மற்றும் ஒத்திசைவு | உங்கள் PDF கோப்புகளை திட்டக் கோப்புகளுடன் வைத்திருங்கள். மேகத்தில் சேமிப்பு இன்னும் கிடைக்கவில்லை. |
| இருவரின் குறியீடுகள் நகல்களை ஒன்றிணைத்தல் | தாள்களை மதிப்பாய்வாளர்களிடையே பிரித்துக்கொள்ளுங்கள், அல்லது {{key:Mod+C}} மற்றும் {{key:Mod+V}} மூலம் சில குறியீடுகளை நகலெடுங்கள். RFI, சமர்ப்பிப்புகள் மற்றும் தினசரிப் பதிவுகள் ஒன்றிணையும்: [RFI, சமர்ப்பிப்புகள் மற்றும் தினசரிப் பதிவுகளைக் கண்காணி](topic:field-records) ஐப் பார்க்கவும். |
| RFI, சமர்ப்பிப்புகளுக்கான குழுக்கள், அறிவிப்புகள் மற்றும் மேகத் திட்டங்கள் | PDF கோப்பை அனுப்பி, நகல்களை ஒன்றிணைக்க {{ui:ஒன்றிணை}} ஐப் பயன்படுத்துங்கள். |
| நேரடி அமர்வில் RFI, சமர்ப்பிப்புகள் மற்றும் தினசரிப் பதிவுகள் | ஒவ்வொருவரும் தனது சொந்த நகலில் வேலை செய்கிறார்; {{ui:ஒன்றிணை}} மூலம் நகல்களை இணைக்கவும். |
| ஒரு பதிவின் வெவ்வேறு புலங்களில் இருவரின் மாற்றங்களை ஒன்றிணைத்தல் | கடைசியாக மாற்றிய நகல் அந்தப் பதிவை முழுமையாக வைத்துக்கொள்ளும் (அதன் திரி மற்றும் இணைப்புப் பெயர்கள் சேர்க்கப்படும்). யார் எந்தப் பதிவைத் திருத்துவது என்று முன்கூட்டியே ஒப்புக்கொள்ளுங்கள். |
| RFI, சமர்ப்பிப்புகள் மற்றும் தினசரிப் பதிவுகளுக்கான உதவியாளர் கருவிகள் | அவற்றை {{ui:களம்}} தாவலில் பயன்படுத்துங்கள். உதவியாளர்கள் குறியீடுகளுடன் வேலை செய்யலாம்: [உதவியாளருடன் MarkupCraft ஐப் பயன்படுத்து](topic:use-with-ai-assistants) ஐப் பார்க்கவும். |
| அனுப்பிய பிறகு பதிலைத் திருத்துவது அல்லது நீக்குவது | உடனே செயல்தவிர்க்கவும், அல்லது திருத்தும் பதிலைச் சேர்க்கவும். |
| குறியீட்டின் ஆசிரியரை மாற்றுவது | தொடங்கும் முன் உங்கள் பெயரை அமைக்கவும். |

## குறியீடுகள்

| இன்னும் உருவாக்கப்படவில்லை | இன்று இதைச் செய்யவும் |
|---|---|
| நிரப்பும் புலங்களுடன் முத்திரைகள், சான்றளிக்கப்பட்ட டிஜிட்டல் கையொப்பங்கள் | உங்கள் பெயரும் தேதியும் இருக்கும் தனிப்பயன் உரை முத்திரையைப் பயன்படுத்துங்கள், அல்லது உங்கள் கையொப்பப் படத்தைப் பயன்படுத்துங்கள். |
| புகைப்படங்களைத் தவிர மற்ற கோப்புகளை இணைத்தல் (ஆவணங்கள், காணொளிகள்) | அவற்றை PDF உடன் வைத்திருந்து கருத்தில் குறிப்பிடுங்கள். |
| இணையதளங்களுக்கான அல்லது திறக்கப்படாத கோப்புகளுக்கான இணைப்புகள் | முகவரி அல்லது கோப்புப் பெயரை கருத்தில் எழுதுங்கள். |
| தனிப்பயன் நிலைத் தொகுப்புகள் | நான்கு நிலைகளைப் பயன்படுத்துங்கள்; மற்றவற்றுக்கு பொருளைப் பயன்படுத்துங்கள். |
| கோப்புடன் வந்த படிக்க-மட்டும் கருத்துகளைத் திருத்துதல் (உரை முன்னிலைப்படுத்தல்கள், பிற நிரல்களின் முத்திரைகள்) | அவற்றுக்குப் பதிலளியுங்கள், அல்லது அருகில் MarkupCraft குறியீட்டை வரையுங்கள். |
| அழுத்தத்துக்கு உணர்திறன் கொண்ட பேனா கோடுகள் | கோட்டுத் தடிமனை அமையுங்கள். |

## பக்கத்தின் சொந்த உள்ளடக்கம்

| இன்னும் உருவாக்கப்படவில்லை | இன்று இதைச் செய்யவும் |
|---|---|
| பக்கத்துக்குள் நேரடியாகப் புதிய வடிவங்களை வரைதல் | அவற்றைக் குறியீடுகளாக வரையுங்கள், பிறகு {{ui:பக்கத்துக்குள் வை}}. பார்க்கவும் [பக்கத்தின் சொந்த உள்ளடக்கத்தை மாற்று](topic:page-content). |
| பக்கப் பொருட்களை எந்தக் கோணத்துக்கும் திருப்புதல் | நகர்த்தி அளவை மாற்றுங்கள்; முழுப் பக்கத்தையும் {{ui:பக்கங்கள்}} மூலம் திருப்புங்கள். |
| உரை வரியின் எழுத்துரு அல்லது அளவை மாற்றுதல், அல்லது பல வரிகளில் பரவும் உரை | சொற்களை ஒரு வரியாக மாற்றுங்கள்; வேறு எழுத்துருவில் புதிய சொற்களுக்கு உரைக் குறியீட்டைச் சேருங்கள். |
| ஸ்கேன் செய்யப்பட்ட படத்தின் உள்ளடக்கத்தைத் திருத்துதல் | படத்தை மாற்றுங்கள், அல்லது அதில் குறியீடு இடுங்கள். |
| குறியாக்கம் செய்யப்பட்ட அல்லது கையொப்பமிடப்பட்ட PDF களைத் திருத்துதல் | கையொப்பமிடாத நகலைக் கேளுங்கள்; குறியீடுகள் எந்த PDF இலும் வேலை செய்யும். |

## அளவிடுதல்

| இன்னும் உருவாக்கப்படவில்லை | இன்று இதைச் செய்யவும் |
|---|---|
| ஆர அளவீடுகள் | அதனுடன் {{ui:வில்}} ஒன்றை வரையுங்கள், அல்லது {{ui:நீளம்}} அளவிட்டு குறுக்காக அளந்து அதைப் பாதியாக்குங்கள். |
| வெட்டுப்பகுதியின் மூலைகளைத் திருத்துதல் | வெட்டுப்பகுதிகளை நீக்கி மீண்டும் வரையுங்கள். |
| ஒரே நேரத்தில் பல தாள்களுக்கு ஒரே அளவை பொருத்துதல் | ஒவ்வொரு தாளையும் அளவுத்திருத்தம் செய்யுங்கள்; முன்னமைவைத் தேர்ந்தெடுக்க ஒவ்வொரு தாளுக்கும் சில வினாடிகள் ஆகும். |
| ஒரு தாளில் பல அளவுகள் (காட்சிச் சாளரங்கள்) | நீங்கள் அதிகம் அளவிடும் வரைபடத்துக்கு அளவுத்திருத்தம் செய்யுங்கள். தாளின் அளவை மாற்றினால் அதிலுள்ள அனைத்தும் மீண்டும் அளக்கப்படும், அதனால் மறு அளவுத்திருத்தத்துக்கு முன் விவர மதிப்புகளை எழுதி வையுங்கள். |
| வரைபடத்தின் கோடுகளுக்கு ஒட்டுதல் | கிளிக் செய்வதற்கு முன் பெரிதாக்குங்கள், அல்லது நீளங்களையும் கோணங்களையும் தட்டச்சிடுங்கள் (பார்க்கவும் [அளவுக்கேற்ப வரைதல்](topic:calibrate-and-measure#sketch-to-scale)). |
| உருப்படிகள், தொகுப்புகள் மற்றும் விலைகளுடன் முழு அளவுக் கணக்கீடு | CadCraft குடும்பத்தின் அளவுக் கணக்கீட்டு நிரலான TakeoffCraft ஐப் பயன்படுத்துங்கள். |

## தாள்களும் கோப்புகளும்

| இன்னும் உருவாக்கப்படவில்லை | இன்று இதைச் செய்யவும் |
|---|---|
| பக்க மாற்றத்தைச் செயல்தவிர்த்தல் (சுழற்று, நகர்த்து, செருகு, நீக்கு) | சேமிக்காமல் மூடி, அசல் PDF ஐ மீண்டும் திறங்கள். பார்க்கவும் [அச்சிடு, பக்கங்களை மாற்று](topic:pages-and-printing). |
| ஒரு தொகுப்பின் ஒரு கோப்பை மூடுதல் | {{ui:மூடு}} முழுத் தொகுப்பையும் மூடும்; தேவையான கோப்புகளை மீண்டும் திறங்கள். |
| ஒரே படியில் மீண்டும் திறக்கும் திட்டமாகத் தொகுப்பைச் சேமித்தல் | அதே PDF களை மீண்டும் திறங்கள். |
| தேர்ந்த அளவில் அச்சிடுதல், அல்லது ஒரு தாளில் பல தாள்கள் | உங்கள் உலாவியின் அச்சுப்பொறி உரையாடலைப் பயன்படுத்துங்கள், அல்லது சேமித்த நகலை வேறு PDF பார்வையாளரில் இருந்து அச்சிடுங்கள். |
