BCF (BIM Collaboration Format) என்பது BIM கருவிகளுக்கு இடையே சிக்கல்களைக் கொண்டுசெல்லும் ஒரு திறந்த கோப்பு வடிவம். பல மாதிரி ஒருங்கிணைப்பு மற்றும் வடிவமைப்பு நிரல்கள் `.bcfzip` கோப்பை சிக்கல்களின் பட்டியலாக இறக்குமதி செய்ய முடியும். MarkupCraft **BCF 2.1** வடிவில் எழுதுகிறது.

## ஒன்றை உருவாக்கு

1. {{ui:குறியீடுகள்}} தாவலைத் திறக்கவும்.
2. நீங்கள் அனுப்ப விரும்புவதற்கு பட்டியலை வடிகட்டவும், எடுத்துக்காட்டாக {{ui:நிலை}} "Open". பட்டியலில் உள்ள குறியீடுகள் மட்டுமே ஏற்றுமதி செய்யப்படும்.
3. {{ui:BCF}} ஐத் தேர்ந்தெடுக்கவும்.
4. ஒவ்வொரு குறியீட்டுக்கும் ஸ்னாப்ஷாட் எடுக்கப்படும் வரை காத்திருக்கவும் ("BCF க்காக ஸ்னாப்ஷாட்கள் எடுக்கப்படுகின்றன (20 இல் 5)…").

முடிவு: "<name> markups.bcfzip" பதிவிறக்கம் ஆகும், மேலும் நிலைப்பட்டை அதில் எத்தனை தலைப்புகள் உள்ளன என்பதையும் கோப்பின் அளவையும் காட்டும்.

## அதில் என்ன இருக்கிறது

ஒவ்வொரு குறியீடும் ஒரு **தலைப்பாக** மாறுகிறது:

| தலைப்புப் புலம் | நிரப்பப்படுவது |
|---|---|
| தலைப்பு | குறியீட்டு எண், பொருள் மற்றும் தாள், எடுத்துக்காட்டாக "#4 Cloud on A-101 — Floor plan" |
| வகை | குறியீட்டு வகை (Cloud, Callout, Length…) |
| நிலை | Open, Accepted, Rejected அல்லது Completed |
| குறிச்சொற்கள் | குறியீட்டு வகையும் தாளும் |
| ஆசிரியர் மற்றும் தேதிகள் | குறியீட்டின் ஆசிரியர், உருவாக்கிய மற்றும் மாற்றிய தேதிகள் |
| ஒப்படைக்கப்பட்டவர், கெடு தேதி | அதற்கு ஒரு பட்டியல் உருப்படி இருந்தால், அதிலிருந்து |
| விளக்கம் | அதன் உரை அல்லது முத்திரையின் சொல், அளவிடப்பட்ட மதிப்பு, கருத்து, மற்றும் தாள் மற்றும் கோப்பு |
| கருத்துகள் | ஒவ்வொரு பதிலுக்கும் ஒன்று, ஆசிரியர் மற்றும் தேதியுடன் |
| ஸ்னாப்ஷாட் | தாளின் அதன் பகுதியில் குறியீட்டின் படம் |
| பார்வைக் கோணம் | தாளில் குறியீடு இருக்கும் இடத்தின் மேலிருந்து கீழான பார்வை |

அதே குறியீட்டை மீண்டும் ஏற்றுமதி செய்தால் அதே தலைப்பு அடையாளம் கிடைக்கும், எனவே BCF ஐ இறக்குமதி செய்யும் கருவி அதை அதே சிக்கல் என அடையாளம் காண முடியும்.

## இறக்குமதி செய்யும்போது திரும்ப வருவது

{{ui:BCF ஐ இறக்குமதி செய்}} BCF 2.0, 2.1 மற்றும் 3.0 கோப்புகளைப் படிக்கும் (அதிகாரப்பூர்வ buildingSMART 3.0 சோதனைக் கோப்புகளில் 19 இல் சரிபார்க்கப்பட்டது: ஒவ்வொரு தலைப்பும் படிக்கப்பட்டது, உரையுடைய மூன்றின் கருத்துகளும் படிக்கப்பட்டன). உங்களுடையதான ஒரு தலைப்புக்கு (அதே தலைப்பு அடையாளம்) புதிய கருத்துகளைப் பதில்களாகச் சேர்க்கும், புதிய நிலையை எடுத்துக்கொள்ளும். மற்ற எந்தத் தலைப்பும் அதன் லேபிள் அல்லது கோப்புப் பெயர் குறிப்பிடும் தாளில் ஒரு குறிப்பாக மாறும், அல்லது அப்போது திறந்திருக்கும் தாளில் மாறும். அதன் தலைப்பு, விளக்கம், ஒப்படைக்கப்பட்டவர் மற்றும் கெடு தேதி குறிப்பின் உரையாகவும், அதன் கருத்துகள் பதில்களாகவும் மாறும்.

| BCF தலைப்பில் | MarkupCraft இல் |
|---|---|
| தலைப்பு, விளக்கம், ஒப்படைக்கப்பட்டவர், கெடு தேதி | குறிப்பின் உரை |
| உரையுடைய கருத்துகள் | பதில்கள் |
| நிலை Open, Accepted, Rejected, Completed (Closed, Resolved, Done ஆகியவை Completed எனக் கணக்கிடப்படும்) | குறியீட்டின் நிலை |
| ஆசிரியர் மற்றும் உருவாக்கிய தேதி | குறிப்பின் ஆசிரியர் மற்றும் தேதி |
| கேமரா நிலை | தாளில் ஓர் இடம், லேபிள் அல்லது கோப்புப் பெயர் மூலம் தாளுடன் இணைக்கப்பட்ட தலைப்புக்கு மட்டும் |
| மாதிரித் தேர்வு, மறைக்கப்பட்ட பாகங்கள், வெட்டும் தளங்கள், ஸ்னாப்ஷாட்கள் | வைக்கப்படாது: தாளில் அவற்றைக் காட்ட மாதிரி எதுவும் இல்லை |

## தெரிந்துகொள்ள வேண்டிய வரம்புகள்

- **தாள் ஒரு மாதிரி அல்ல.** பார்வைக் கோணம் காகிதத்தில் குறியீட்டின் நிலையைக் காட்டுகிறது, காகிதத்தில் m அளவில் அளவிடப்படுகிறது. அது BIM கருவியை மாதிரியில் ஓர் இடத்துக்கு கொண்டு செல்லாது. அந்த இடத்தைக் கண்டறிய ஸ்னாப்ஷாட்டையும் தாளின் பெயரையும் பயன்படுத்தவும்.
- **நிலைகளும் வகைகளும் MarkupCraft இன் சொந்தமானவை** (Open, Accepted, Rejected, Completed; Cloud, Callout…). BCF அனுமதிப்பதுபோல கோப்பு அவற்றை அறிவிக்கும், ஆனால் தங்களுடைய நிலையான பட்டியல்கள் கொண்ட கருவி அவற்றை மாற்றலாம் அல்லது புறக்கணிக்கலாம்.
- **இறக்குமதி செய்வது கருத்துகளைக் கொண்டுவரும், மாதிரிப் பார்வைகளை அல்ல.** {{ui:BCF ஐ இறக்குமதி செய்}} நீங்கள் ஏற்றுமதி செய்த குறியீடுகளுக்கு பதில்களையும் நிலைகளையும் சேர்க்கும், மற்ற சிக்கல்களுக்கு குறிப்புகளை உருவாக்கும்; அது மாதிரி கேமராவைக் காட்ட முடியாது. பார்க்கவும் [குறியீட்டுப் பட்டியல் மற்றும் ஏற்றுமதி](topic:markups-list-and-export#import-bcf).
- PDF ஆக குறியீடுகளை திருப்பி அனுப்புவது வரைபட மதிப்பாய்வுகளுக்கு பெரும்பாலும் எளிது. BCF என்பது வரைபடக் கருத்துகளை மாதிரி ஒருங்கிணைப்புப் பணிப்பாய்வுக்குக் கொண்டுவருவதற்கு.
