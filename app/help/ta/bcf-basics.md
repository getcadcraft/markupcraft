BCF (BIM Collaboration Format) என்பது BIM கருவிகளுக்கு இடையே சிக்கல்களை அனுப்புவதற்கான ஒரு திறந்த கோப்பு வடிவம். பல மாதிரி ஒருங்கிணைப்பு மற்றும் வடிவமைப்பு நிரல்கள் `.bcfzip` கோப்பை சிக்கல்களின் பட்டியலாக இறக்குமதி செய்ய முடியும். MarkupCraft **BCF 2.1** ஐ எழுதுகிறது.

## உருவாக்குதல்

1. {{ui:குறியீடுகள்}} தாவலைத் திறக்கவும்.
2. நீங்கள் அனுப்ப விரும்புவதற்கு பட்டியலை வடிகட்டவும், எடுத்துக்காட்டாக {{ui:நிலை}} "திறந்தது". பட்டியலிடப்பட்ட குறியீடுகள் மட்டுமே ஏற்றுமதி செய்யப்படும்.
3. {{ui:BCF}} ஐத் தேர்ந்தெடுக்கவும்.
4. ஒவ்வொரு குறியீட்டின் படம்பிடிப்பையும் உருவாக்கும்போது காத்திருக்கவும் ("BCF க்கான படம்பிடிப்புகளை உருவாக்குகிறது (20 இல் 5)…").

முடிவு: "<name> markups.bcfzip" பதிவிறக்கப்படும், மேலும் நிலைப்பட்டி அதில் எத்தனை தலைப்புகள் உள்ளன மற்றும் கோப்பின் அளவு என்ன என்பதைக் காட்டும்.

## அதில் என்ன உள்ளது

ஒவ்வொரு குறியீடும் ஒரு **தலைப்பாக** மாறுகிறது:

| தலைப்புப் புலம் | நிரப்பப்படுவது |
|---|---|
| தலைப்பு | குறியீட்டு எண், பொருள் மற்றும் தாள், எடுத்துக்காட்டாக "#4 A-101 இல் மேகம் — தளவரைபடம்" |
| வகை | குறியீட்டு வகை (மேகம், சுட்டுக்குறிப்பு, நீளம்…) |
| நிலை | திறந்தது, ஏற்கப்பட்டது, நிராகரிக்கப்பட்டது அல்லது முடிந்தது |
| லேபிள்கள் | குறியீட்டு வகை மற்றும் தாள் |
| ஆசிரியர் மற்றும் தேதிகள் | குறியீட்டின் ஆசிரியர், உருவாக்கிய மற்றும் மாற்றிய தேதிகள் |
| ஒதுக்கப்பட்டவர், காலக்கெடு | அதன் பஞ்ச் உருப்படியிலிருந்து, அது இருந்தால் |
| விளக்கம் | அதன் உரை அல்லது முத்திரை வாசகம், அளவிடப்பட்ட மதிப்பு, கருத்து, மற்றும் தாள் மற்றும் கோப்பு |
| கருத்துகள் | ஒவ்வொரு பதிலுக்கும் ஒன்று, ஆசிரியர் மற்றும் தேதியுடன் |
| படம்பிடிப்பு | தாளின் அதன் பகுதியில் குறியீட்டின் படம் |
| காட்சிக்கோணம் | தாளில் குறியீட்டின் இடத்தின் மேலிருந்தான பார்வை |

அதே குறியீட்டை மீண்டும் ஏற்றுமதி செய்தால் அதே தலைப்பு ID கிடைக்கும், எனவே BCF ஐ இறக்குமதி செய்யும் கருவி அதை அதே சிக்கலாக அடையாளம் காண முடியும்.

## தெரிந்து கொள்ள வேண்டிய வரம்புகள்

- **தாள் ஒரு மாதிரி அல்ல.** காட்சிக்கோணம் குறியீட்டின் நிலையை காகிதத்தில் சுட்டிக்காட்டுகிறது, அது காகிதத்தின் மீட்டர் அளவில் அளக்கப்படுகிறது. BIM கருவியை மாதிரியில் ஒரு இடத்திற்கு அது கொண்டு செல்லாது. இடத்தைக் கண்டறிய படம்பிடிப்பையும் தாளின் பெயரையும் பயன்படுத்தவும்.
- **நிலைகளும் வகைகளும் MarkupCraft-இன் சொந்தமானவை** (திறந்தது, ஏற்கப்பட்டது, நிராகரிக்கப்பட்டது, முடிந்தது; மேகம், சுட்டுக்குறிப்பு…). BCF அனுமதிப்பதால் கோப்பு அவற்றை அறிவிக்கிறது, ஆனால் தனக்கென நிலையான பட்டியல்களைக் கொண்ட கருவி அவற்றை வேறு பொருத்தலாம் அல்லது புறக்கணிக்கலாம்.
- **இறக்குமதி செய்வது கருத்துகளைக் கொண்டுவரும், மாதிரிக் காட்சிகளை அல்ல.** {{ui:BCF ஐ இறக்குமதி செய்}} நீங்கள் ஏற்றுமதி செய்த குறியீடுகளுக்கு பதில்களையும் நிலைகளையும் சேர்க்கிறது, மற்ற சிக்கல்களுக்கு குறிப்புகளை உருவாக்குகிறது; அது மாதிரி கேமராவைக் காட்ட முடியாது. [குறியீடுகள் பட்டியல் மற்றும் ஏற்றுமதி](topic:markups-list-and-export#import-bcf) ஐப் பார்க்கவும்.
- வரைபட மதிப்பாய்வுகளுக்கு குறியீடுகளை PDF ஆக அனுப்புவது பெரும்பாலும் எளிதானது. வரைபடக் கருத்துகளை மாதிரி ஒருங்கிணைப்புப் பணிப்பாய்வுக்குள் கொண்டுசெல்வதற்கு BCF.
