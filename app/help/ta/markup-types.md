## ஒவ்வொரு குறியீடும் கொண்டிருப்பது

| புலம் | அதை எங்கே பார்ப்பீர்கள் |
|---|---|
| ஆசிரியர் | {{ui:Properties}}, பட்டியல், முத்திரையின் இரண்டாவது வரி, பிற PDF பார்வையாளர்கள் |
| உருவாக்கியது மற்றும் மாற்றியது | {{ui:Properties}} (உங்கள் நேர மண்டலத்தில்), பட்டியல், CSV |
| நிலை | திறந்தது, ஏற்கப்பட்டது, நிராகரிக்கப்பட்டது அல்லது நிறைவடைந்தது |
| பொருள் | குறுகிய பெயர்; இயல்பாக வகை ("மேகம்", "உரைப் பெட்டி", "நீள அளவீடு") |
| கருத்து | நீண்ட குறிப்புகள். ஒரு குறிப்புக்கு, அதன் உரையே அதன் கருத்து. |
| உரை | உரைப் பெட்டிகளும் சுட்டுக்குறிப்புகளும் மட்டும் |
| பதில்கள் | உரையாடல், நிலை மாற்றங்களுடன் |
| குறைபாட்டு உருப்படி | எண், ஒப்படைக்கப்பட்டவர், கெடு நாள், உருப்படி நிலை, குறைபாட்டுப் பட்டியலில் சேர்க்கப்படும்போது |
| பாணி | வண்ணம், கோட்டுத் தடிமன், நிரப்பு மற்றும் நிரப்பு ஒளிபுகாமை (மூடிய வடிவங்கள், உரை மற்றும் சுட்டுக்குறிப்புகள்), ஒளிபுகாமை, உரை அளவு (உரை, சுட்டுக்குறிப்புகள் மற்றும் அளவீடுகள்) |

## படிக்க-மட்டும் கருத்துகள்

கோப்புடன் வந்த, MarkupCraft திருத்த முடியாத கருத்துகள் (உரை சிறப்பம்சங்கள், பிற நிரல்களின் முத்திரைகள் மற்றும் பிற சிறப்பு வகைகள்) "மற்றவை" வகையுடனும் "படிக்க மட்டும்" நிலைச் சிப்புடனும் பட்டியலிடப்படும். அவை கோப்பு கொடுக்கும் அதே தோற்றத்தையே வைத்திருக்கும். நீங்கள் அவற்றைத் தேர்ந்தெடுக்கலாம், அவற்றின் ஆசிரியர், பொருள் மற்றும் கருத்தைப் பார்க்கலாம், அவற்றுக்குப் பதிலளிக்கலாம்.

## இன்னும் உருவாக்கப்படவில்லை

கோப்பு இணைப்புகள் இன்னும் உருவாக்கப்படவில்லை. எந்தக் குறியீடும் ஒரு தாளுடன் இணைக்கப்படலாம்; பார்க்க: [தாள் இணைப்புகள்](topic:sheet-links). படங்களும் கையொப்பங்களும் {{ui:Stamp}} கருவியுடன் வைக்கப்படும்; பார்க்க: [முத்திரைகளும் குறிப்புகளும்](topic:stamps-and-notes). பார்க்க [இன்னும் உருவாக்கப்படாதவை](topic:not-built-yet).
