{{key:Mod}} உடன் உள்ள குறுக்குவழிகள் Mac இல் ⌘ அல்லது Control, Windows மற்றும் Linux இல் Ctrl ஆகிய இரண்டில் எதையும் ஏற்கும். கருவி எழுத்துகள் பெட்டியில் நீங்கள் தட்டச்சு செய்யாதபோது மட்டுமே வேலை செய்யும்; தட்டச்சு செய்யும்போது எழுத்துகள் வெறும் எழுத்துகளே. மேலும் பார்க்க: [விசைகள், சுட்டிகள் மற்றும் டிராக்பேட்கள்](common:keys).

## வரையும்போது

| விசை அல்லது செயல் | அது என்ன செய்கிறது |
|---|---|
| வரையும்போது {{key:Shift}} | கோடுகள், அம்புகள், நீளங்கள் மற்றும் பலகோடு பக்கங்களை 45° படிகளில்; செவ்வகங்கள், நீள்வட்டங்கள் மற்றும் பெட்டி மேகங்களைச் சதுரமாக்கும்; பேனா மற்றும் முன்னிலைப்படுத்தியை ஒரே நேர் கோடாக்கும் |
| இருமுறை கிளிக், {{key:Enter}} அல்லது வலது கிளிக் | பலகோடு, பலகோணம், தன்னிச்சை மேகம் அல்லது பரப்பளவை முடி |
| {{key:Backspace}} | பலகோடு, பலகோணம், தன்னிச்சை மேகம் அல்லது பரப்பளவின் கடைசிப் புள்ளியை அகற்று |
| {{key:Esc}} | நீங்கள் வரைவதை ரத்துசெய்; எதுவும் நடைபெறாதபோது தேர்வை நீக்கு; எதுவும் தேர்ந்தெடுக்கப்படாதபோது {{ui:Select}} கருவிக்குத் திரும்பு |
| {{key:Mod+Enter}} | உரைப் பெட்டி, சுட்டுக்குறிப்பு அல்லது குறிப்பில் தட்டச்சு செய்வதை முடி (அல்லது அதற்கு வெளியே கிளிக் செய்) |
| தட்டச்சு செய்யும்போது {{key:Esc}} | நீங்கள் தட்டச்சு செய்து கொண்டிருந்த உரையை ரத்துசெய் |
| {{ui:Count}} கருவியுடன் {{key:Shift}}-கிளிக் | தேர்ந்த எண்ணிக்கைக் குழுவின் அருகிலுள்ள புள்ளியை அகற்று |

## தேர்ந்தெடுத்தல் மற்றும் திருத்துதல்

| கிளிக் | ஒரு குறியீட்டைத் தேர்ந்தெடு |

| வெற்றுத் தாளில் இடமிருந்து வலமாக இழு | சாளரத்திற்குள் முழுமையாக உள்ளதைத் தேர்ந்தெடு |
| வெற்றுத் தாளில் வலமிருந்து இடமாக இழு | சாளரம் தொடும் அனைத்தையும் தேர்ந்தெடு |

| ஒரு கைப்பிடியை இழு | அளவை மாற்று அல்லது வடிவத்தை மாற்று ({{key:Shift}}: விகிதங்களைப் பேணு, அல்லது 45°) |
| அம்புக்குறி விசைகள் | தேர்வை ஒரு திரைப் பிக்சல் நகர்த்து ({{key:Shift}}: பத்து) |
| இருமுறை கிளிக், அல்லது {{key:Enter}} | உரைப் பெட்டி, சுட்டுக்குறிப்பு அல்லது குறிப்பின் உரையைத் திருத்து; முத்திரைக்கு, {{ui:Properties}} ஐத் திற |

| {{key:Esc}} | எதையும் தேர்ந்தெடுக்காதே |

| {{key:Mod+Y}} அல்லது {{key:Mod+Shift+Z}} | மீண்டும்செய் |

## வெட்டு, நகலெடு மற்றும் ஒட்டு

அதே கட்டளைகள் கருவிப்பட்டையின் {{ui:Edit}} குழுவிலும் ({{ui:Copy}}, {{ui:Paste}}) அதன் {{ui:More}} பட்டியிலும் உள்ளன; ஒவ்வொன்றுக்கும் அதன் விசையுடன். ஒவ்வொன்றும் ஒரே செயல்தவிர் படியாகும். பார்க்க: [நகலெடு, ஒட்டு மற்றும் நகலாக்கு](topic:select-and-edit#copy-paste-and-duplicate).

| விசை | அது என்ன செய்கிறது |
|---|---|
| {{key:Mod+X}} | வெட்டு: தேர்வை நகலெடுத்து அதை நீக்கு |
| {{key:Mod+C}} | தேர்வை நகலெடு |
| {{key:Mod+V}} | ஒட்டு. சுட்டி தாளின் மீது இருந்தால், நகல் சுட்டி காட்டும் இடத்தின் மையத்தில் வரும்; இல்லையெனில் அசலின் அருகில். அமைப்புகளில் எப்போதும் அசலின் அருகில் ஒட்டும்படி அமைக்கலாம். |
| {{key:Mod+Shift+V}} | அதே இடத்தில் ஒட்டு: தாளில் அதே இடத்தில், இந்தத் தாளிலோ அல்லது மற்றொன்றிலோ |
| {{key:Mod+D}} | தேர்வை அதன் அருகில் நகலாக்கு (இடைநிலைப் பலகை தொடப்படாது) |

## பெரிதாக்குதல் மற்றும் நகர்த்துதல்

| விசை அல்லது செயல் | அது என்ன செய்கிறது |
|---|---|
| சுட்டி உருளை | சுட்டியைச் சுற்றி உள்ளே அல்லது வெளியே பெரிதாக்கு (உருளை ஒருபோதும் உருட்டாது) |
| {{key:Ctrl}} + உருளை | வேகமாகப் பெரிதாக்கு |
| {{key:Plus}} அல்லது {{key:Minus}} ({{key:Mod}} உடனும்) | நடுவைச் சுற்றி உள்ளே அல்லது வெளியே பெரிதாக்கு; {{key:=}} பிளஸ் போலச் செயல்படும் |
| {{key:Mod+0}} | {{ui:Fit page}} |
| {{key:Mod+9}} | {{ui:Fit width}} |
| நடு பொத்தானுடன் இழு | நகர்த்து |
| வலது பொத்தானுடன் இழு | நகர்த்து (பலகோட்டின் நடுவில் இல்லாதபோது) |
| {{key:Space}}-ஐ அழுத்திப் பிடித்து இழு | நகர்த்து |

| {{key:Ctrl+Shift+F}} | திரை முறை: சாதாரண, முழுத் திரை, பட்டிகள் மறைக்கப்பட்ட முழுத் திரை (ஒவ்வொரு கணினியிலும் Control விசை) |

:::mac
**டிராக்பேடில்:** இரு விரல் உருட்டல் பெரிதாக்கும். Chrome, Edge மற்றும் Firefox இல் கிள்ளுதலும் பெரிதாக்கும். {{key:Space}} அழுத்திப் பிடித்து இழுத்து நகர்த்து, அல்லது {{ui:Pan}} கருவியைப் பயன்படுத்து. இரு விரல் கிளிக் என்பது வலது கிளிக், அது பலகோட்டையும் முடிக்கும். இங்கே Control-கிளிக் வலது கிளிக்குப் பதிலாக சாதாரணக் கிளிக்காகச் செயல்படலாம், எனவே இரு விரல் கிளிக்கைப் பயன்படுத்து.
:::

## உலாவி வைத்திருக்கும் குறுக்குவழிகள்

- {{key:Mod+W}}, {{key:Mod+T}}, {{key:Mod+N}} மற்றும் {{key:Mod+Q}} உலாவிக்குச் சொந்தமானவை. சேமிக்காத குறியீடுகளுடன் தாவலையோ சாளரத்தையோ மூடினால், கணினியில் உலாவியின் "தளத்திலிருந்து வெளியேறவா?" கேள்விக்குப் பிறகு அவை இழக்கப்படும்.
- பெரும்பாலான உலாவிகள் {{key:Mod+N}} ஐப் புதிய சாளரத்திற்கு வைத்துக்கொள்ளும், எனவே உலாவித் தாவலில் கருவிப்பட்டையில் உள்ள {{ui:New}} ஐப் பயன்படுத்து; டெஸ்க்டாப் ஆப்பும் Studio உம் அந்த விசையை MarkupCraft க்கு அனுப்பும்.
- MarkupCraft விசைப்பலகையைப் பெற்றிருக்கும்போது, ஆப் உள்ளபோது {{key:Mod+O}}, {{key:Mod+S}}, {{key:Mod+D}}, {{key:Mod+A}}, {{key:Mod+V}}, {{key:Mod+Shift+V}}, {{key:Mod+0}}, {{key:Mod+Plus}} மற்றும் {{key:Mod+Minus}} ஐ உலாவியிடமிருந்து எடுத்துக்கொள்கிறது; குறியீடுகள் தேர்ந்தெடுக்கப்பட்டிருக்கும்போது {{key:Mod+C}} மற்றும் {{key:Mod+X}} ஐயும். {{key:Mod+,}} {{ui:Settings}} ஐத் திறக்கும். முழு உலாவிப் பக்கத்தையும் பெரிதாக்க, உலாவியின் பட்டியைப் பயன்படுத்து.
- சில உலாவிகளில் {{key:Mod+9}} MarkupCraft பார்ப்பதற்கு முன் கடைசி உலாவித் தாவலுக்குத் தாவும். அப்படி நடந்தால், தாளின் கீழ் உள்ள {{ui:Fit width}} ஐப் பயன்படுத்து.
- முழுத் திரையில் {{key:Esc}} முழுத் திரையிலிருந்தும் வெளியேறும்.

## விசை எதுவும் செய்யாதபோது

- **நீங்கள் ஒரு பெட்டியில் தட்டச்சு செய்கிறீர்கள்.** முதலில் தாளில் கிளிக் செய். (வரைதல் கருவியுடன் கிளிக் செய்தால் அது வரையும்; பின்னர் {{key:Esc}} அழுத்து, அல்லது {{key:Mod+Z}} ஐப் பயன்படுத்து.)
- **ஓர் உரையாடல் திறந்துள்ளது.** அது மூடும் வரை விசைகள் உரையாடலுக்குச் செல்லும்.
- **கருவிப்பட்டை பொத்தானில் கிளிக் செய்தீர்கள்.** அதனால் அம்புக்குறி விசைகளும் {{key:Space}} உம் அந்தப் பொத்தானில் செயல்படும். சுட்டியைத் தாளின் மீது நகர்த்தி உருளை அல்லது நடு பொத்தானைப் பயன்படுத்து, அல்லது பொத்தான்களைக் கிளிக் செய்வதற்குப் பதிலாக ஒரு கருவி எழுத்தை அழுத்து.

## நகர்த்துதல் எங்கே உள்ளது

நகர்த்து என்ற கட்டளை எதுவும் இல்லை: ஒரு குறியீட்டைத் தேர்ந்தெடுத்து இழு ({{key:Shift}} 45° படிகளைப் பேணும்). ஒரு குண்டூசி {{ui:Move pin}} மூலம் நகர்த்தப்படும், ஒரு பக்கம் {{ui:Move page earlier}} அல்லது {{ui:Move page later}} மூலம் நகர்த்தப்படும்.
