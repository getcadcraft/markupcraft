Jede Markierung speichert, wer sie erstellt hat und wann. Stempel zeigen den Namen („Von Ana Ruiz, 10. Okt. 2026“), Antworten zeigen ihn, die Markierungsliste kann danach filtern, und andere PDF-Betrachter zeigen ihn als Autor des Kommentars.

## Angemeldet: der Name Ihres Kontos

Sind Sie bei Ihrem CadCraft-Konto angemeldet, verwendet MarkupCraft den Namen Ihres Kontos und fragt nie danach. Markierungen, Antworten, Stempel und die Statusleiste zeigen ihn. In {{ui:Einstellungen}} › {{ui:MarkupCraft}} › {{ui:Ihr Name}} steht „Aus Ihrem Konto (Ihr Name)“.

- Um einen anderen Namen zu verwenden, wählen Sie {{ui:Anderen Namen verwenden}} und geben ihn ein. Ein eingegebener Name gilt ab dann.
- Um zum Namen Ihres Kontos zurückzukehren, wählen Sie {{ui:Meinen Kontonamen verwenden}}.

Nur der Name wird verwendet, nie Ihre E-Mail-Adresse. Ändern Sie Ihren Namen auf der Website, zeigt MarkupCraft ihn beim nächsten Öffnen an.

## Das erste Mal (abgemeldet)

Sind Sie nicht angemeldet, öffnet sich beim ersten Wählen eines Zeichenwerkzeugs ein Feld „Ihr Name auf Markierungen“.

1. Geben Sie Ihren Namen so ein, wie Prüfer ihn sehen sollen (bis zu 80 Zeichen).
2. Wählen Sie {{ui:Speichern}}.

Ergebnis: Ihr Name erscheint rechts in der Statusleiste, und jede neue Markierung trägt ihn.

Wählen Sie {{ui:Jetzt nicht}}, werden Markierungen ohne Autor erstellt („Nicht erfasst“ in {{ui:Eigenschaften}}), und Stempel zeigen nur das Datum. MarkupCraft fragt beim nächsten Öffnen erneut.

## Ändern

1. Klicken Sie auf Ihren Namen (oder „Namen festlegen“) rechts in der Statusleiste.
2. Geben Sie den neuen Namen ein und wählen Sie {{ui:Speichern}}.

Oder öffnen Sie {{ui:Einstellungen}} ({{key:Mod+,}}), bleiben Sie auf der Registerkarte {{ui:MarkupCraft}} und geben Sie ihn unter {{ui:Ihr Name}} ein. Siehe [MarkupCraft-Einstellungen](topic:settings).

Nur ab jetzt erstellte Markierungen erhalten den neuen Namen. Bereits gezeichnete Markierungen behalten den Namen, mit dem sie erstellt wurden; der Autor einer bestehenden Markierung kann nicht geändert werden.

## Wo der Name gespeichert wird

Ihr Name wird **in diesem Browser auf diesem Computer** gespeichert (der lokale Speicher des Browsers für diese Website). Das heißt:

- Ein anderer Browser auf demselben Computer oder derselbe Browser auf einem anderen Computer fragt erneut.
- Ein privates Fenster fragt jedes Mal und vergisst den Namen beim Schließen.
- Löschen Sie die Daten dieser Website (Cookies und Websitedaten) in den Browser-Einstellungen, ist der Name vergessen.
- Nichts wird übertragen. Der Name verlässt diesen Computer nur in den PDFs, die Sie speichern.

:::safari
Safari kann die gespeicherten Daten einer Website löschen, wenn sie längere Zeit nicht besucht wurde. Fragt MarkupCraft erneut nach Ihrem Namen, liegt das daran.
:::

Teilen sich mehrere Personen einen Computer und eine Browser-Anmeldung, sollte jede vor dem Start den Namen in der Statusleiste prüfen, da er gemeinsam genutzt wird.

Siehe auch [Was in diesem Browser bleibt](topic:browser-storage).
