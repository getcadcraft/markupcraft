Das Werkzeug {{ui:Bogen}} ({{key:O}}) zeichnet einen Kreisbogen. Neben den üblichen drei Klicks bietet es zehn Möglichkeiten, den Bogen festzulegen, für den Fall, dass Sie den Radius, den Winkel oder den Mittelpunkt kennen, statt eines Punktes auf der Kurve.

## Was Sie tun

Wählen Sie das Werkzeug {{ui:Bogen}}, wählen Sie eine {{ui:Bogenmethode}} und zeichnen Sie den Bogen mit Klicks oder eingetippten Zahlen.

## Schritte

1. Wählen Sie {{ui:Bogen}} in den Werkzeugen unter {{ui:Zeichnen}} oder drücken Sie {{key:O}}.
2. Wählen Sie im Feld über der Seite die Methode unter {{ui:Bogenmethode}}: {{ui:3-Punkt}}, {{ui:Anfang, Mittelpunkt, Ende}}, {{ui:Anfang, Mittelpunkt, Winkel}}, {{ui:Anfang, Mittelpunkt, Länge}}, {{ui:Anfang, Ende, Winkel}}, {{ui:Anfang, Ende, Richtung}}, {{ui:Anfang, Ende, Radius}}, {{ui:Mittelpunkt, Anfang, Ende}}, {{ui:Mittelpunkt, Anfang, Winkel}} oder {{ui:Mittelpunkt, Anfang, Länge}}.
3. Folgen Sie der Aufforderung in der Statuszeile Schritt für Schritt. Jeder Schritt fordert Sie auf, den Anfang, einen Punkt, durch den der Bogen läuft, den Mittelpunkt oder das Ende anzuklicken.
4. Wenn der Schritt einen Winkel, eine Sehnenlänge, eine Richtung oder einen Radius verlangt, bewegen Sie den Zeiger und klicken Sie, oder tippen Sie die Zahl ein und drücken Sie {{key:Enter}}.
5. Der Bogen entsteht, wenn der letzte Schritt erledigt ist. Wählen Sie ihn aus und gestalten Sie ihn in {{ui:Eigenschaften}} wie jede andere Markierung um.

## Gut zu wissen

- {{key:Esc}} bricht den Bogen ab; {{key:Backspace}} macht den letzten Schritt rückgängig.
- Ein Minuszeichen dreht einen Winkel oder eine Länge im Uhrzeigersinn. Bei einem Radius nimmt ein Minuszeichen den langen Weg herum. Eine Richtung wird in Grad angegeben: rechts ist 0, oben ist 90.
- Wenn die Punkte keinen Bogen ergeben können (drei Punkte auf einer Linie, zwei Punkte an derselben Stelle, ein Radius, der das andere Ende nicht erreicht), sagt die Statuszeile es; wählen Sie einen anderen Punkt.
- Siehe [Markierungsarten](topic:markup-types) für die anderen Zeichenwerkzeuge.
