MarkupCraft befindet sich in der Entwicklung. Hier steht, was die aktuelle Version **nicht** kann, damit Sie es einplanen können. Es beschreibt die heutige Version, keine Versprechen.

## Zusammenarbeit mit anderen

| Noch nicht umgesetzt | Heute so vorgehen |
|---|---|
| Cloud-Speicherung und Synchronisation zwischen Computern | Bewahren Sie die PDFs bei Ihren Projektdateien auf. Cloud-Speicherung ist noch nicht verfügbar. |
| Zusammenführen der Kopien zweier Personen mit Markierungen | Teilen Sie die Blätter unter den Prüfern auf, oder kopieren Sie einige Markierungen mit {{key:Mod+C}} und {{key:Mod+V}} hinüber. RFIs, Eingaben und Tagesberichte lassen sich zusammenführen: siehe [RFIs, Eingaben und Tagesberichte verfolgen](topic:field-records). |
| Teams, Benachrichtigungen und Cloud-Projekte für RFIs und Eingaben | Geben Sie die PDF weiter und verwenden Sie {{ui:Zusammenführen}}, um Kopien zusammenzuführen. |
| RFIs, Eingaben und Tagesberichte in einer Live-Sitzung | Jede Person arbeitet an ihrer eigenen Kopie; führen Sie die Kopien mit {{ui:Zusammenführen}} zusammen. |
| Zusammenführen der Änderungen zweier Personen an verschiedenen Feldern eines Datensatzes | Der zuletzt geänderte Stand gewinnt den Datensatz als Ganzes (Unterhaltung und Anhangsnamen werden zusammengeführt). Legen Sie fest, wer welchen Datensatz bearbeitet. |
| Assistenz-Werkzeuge für RFIs, Eingaben und Tagesberichte | Arbeiten Sie damit im Reiter {{ui:Baustelle}}. Assistenten können mit Markierungen arbeiten: siehe [MarkupCraft mit einem KI-Assistenten verwenden](topic:use-with-ai-assistants). |
| Bearbeiten oder Löschen einer Antwort nach dem Senden | Machen Sie es sofort rückgängig, oder fügen Sie eine korrigierende Antwort hinzu. |
| Ändern, von wem eine Markierung stammt | Legen Sie Ihren Namen fest, bevor Sie anfangen. |

## Markierungen

| Noch nicht umgesetzt | Heute so vorgehen |
|---|---|
| Stempel mit Ausfüllfeldern, zertifizierte digitale Signaturen | Verwenden Sie einen eigenen Textstempel, der Ihren Namen und das Datum enthält, oder ein Bild Ihrer Unterschrift. |
| Anhängen anderer Dateien als Fotos (Dokumente, Videos) | Bewahren Sie sie neben der PDF auf und verweisen Sie im Kommentar darauf. |
| Links zu Websites oder zu Dateien, die nicht geöffnet sind | Schreiben Sie die Adresse oder den Dateinamen in den Kommentar. |
| Benutzerdefinierte Statussätze | Verwenden Sie die vier Status und für alles Weitere den Betreff. |
| Bearbeiten von Kommentaren, die mit der Datei als schreibgeschützt kamen (Texthervorhebungen, Stempel anderer Programme) | Antworten Sie darauf, oder zeichnen Sie eine MarkupCraft-Markierung daneben. |
| Druckstärke-sensitive Stiftstriche | Legen Sie die Linienstärke fest. |

## Der eigene Inhalt der Seite

| Noch nicht umgesetzt | Heute so vorgehen |
|---|---|
| Neue Formen direkt in die Seite zeichnen | Zeichnen Sie sie als Markierungen und übernehmen Sie sie dann mit {{ui:In die Seite übernehmen}}. Siehe [Eigenen Inhalt der Seite ändern](topic:page-content). |
| Seitenobjekte in beliebige Winkel drehen | Verschieben und skalieren Sie sie; drehen Sie die ganze Seite mit {{ui:Seiten}}. |
| Schriftart oder Größe einer Textzeile ändern, oder Text, der über mehrere Zeilen läuft | Ändern Sie die Wörter jeweils eine Zeile; für neuen Text in einer anderen Schrift fügen Sie eine Textmarkierung hinzu. |
| Inhalt eines gescannten Bildes bearbeiten | Ersetzen Sie das Bild oder markieren Sie es. |
| Verschlüsselte oder signierte PDFs bearbeiten | Bitten Sie um eine unsignierte Kopie; Markierungen funktionieren mit jeder PDF. |

## Messen

| Noch nicht umgesetzt | Heute so vorgehen |
|---|---|
| Radiusmessungen | Zeichnen Sie einen {{ui:Bogen}} entlang, oder messen Sie die {{ui:Länge}} quer und halbieren Sie sie. |
| Ecken einer Aussparung bearbeiten | Entfernen Sie die Aussparungen und zeichnen Sie sie neu. |
| Einen Maßstab auf viele Blätter gleichzeitig anwenden | Kalibrieren Sie jedes Blatt; das Auswählen einer Voreinstellung dauert pro Blatt einige Sekunden. |
| Mehrere Maßstäbe auf einem Blatt (Ansichtsfenster) | Kalibrieren Sie auf die Zeichnung, die Sie am häufigsten messen. Wenn Sie den Maßstab eines Blatts ändern, werden alle Messungen darauf neu berechnet; notieren Sie Detailwerte, bevor Sie neu kalibrieren. |
| Einrasten an Linien in der Zeichnung | Zoomen Sie vor dem Klicken hinein, oder geben Sie Längen und Winkel ein (siehe [Maßstäblich skizzieren](topic:calibrate-and-measure#sketch-to-scale)). |
| Eine vollständige Mengenermittlung mit Positionen, Kalkulationsbausteinen und Preisen | Verwenden Sie TakeoffCraft, die Mengenermittlungs-App der CadCraft-Familie. |

## Blätter und Dateien

| Noch nicht umgesetzt | Heute so vorgehen |
|---|---|
| Rückgängig machen einer Seitenänderung (drehen, verschieben, einfügen, löschen) | Ohne Speichern schließen und das ursprüngliche PDF erneut öffnen. Siehe [Drucken und Seiten ändern](topic:pages-and-printing). |
| Schließen einer Datei aus einem Satz | {{ui:Schließen}} schließt den ganzen Satz; öffnen Sie die benötigten Dateien erneut. |
| Einen Satz als Projekt speichern, das sich mit einem Schritt wieder öffnen lässt | Öffnen Sie dieselben PDFs erneut. |
| Drucken in einem gewählten Maßstab oder mehrere Blätter pro Papier | Verwenden Sie den Druckdialog Ihres Browsers, oder drucken Sie die gespeicherte Kopie aus einem anderen PDF-Betrachter. |

## Listen und Exporte

| Noch nicht umgesetzt | Heute so vorgehen |
|---|---|
| Importierte BCF-Themen an ihrer Modellposition platzieren | Importierte Themen, die keinem Blatt zugeordnet sind, liegen oben links gestapelt: verschieben Sie sie. |
| Werkzeugsätze aus anderen Markierungsprogrammen importieren | Bauen Sie die benötigten Werkzeuge neu auf und speichern Sie sie in der Werkzeugkiste; exportieren Sie diese für das Büro. |

## Vergleichen

| Noch nicht umgesetzt | Heute so vorgehen |
|---|---|
| Text vergleichen, der in einer Schrift gesetzt ist, oder eine Liste der Änderungen | Verwenden Sie die Überlagerung und den Schieber, oder {{ui:Geänderte Linien}} für gezeichnete Linien. |
| Gescannte Blätter anhand ihrer Linien vergleichen | Verwenden Sie die Bildüberlagerung. |
| Jedes Paar automatisch ausrichten, wenn ein ganzer Satz verglichen wird | Vergleichen Sie ein verschobenes Paar einzeln und verwenden Sie {{ui:An zwei Punkten ausrichten}}. |

## Bereiche

| Noch nicht umgesetzt | Heute so vorgehen |
|---|---|
| Die Symbolleiste oder die Statusleiste verschieben | Nur die beiden seitlichen Bereiche lassen sich verschieben. |

## Plattformen

- **Desktop:** MarkupCraft läuft im Browser auf Mac, Windows, Linux und iPad sowie in CadCraft Studio, der Desktop-App mit allen acht Apps in einer Installation.
- MarkupCraft befindet sich in der Entwicklung. Beschriftungen und Verhalten können sich noch ändern, und diese Hilfe ändert sich mit ihnen.
