Ihre Arbeitsnotizen müssen nicht auf der Zeichnung stehen oder an den Kunden gelangen. Es gibt drei Arten von Hilfe hier, und Sie können sie gemeinsam verwenden.

## Die Ablagefläche

Der Bereich um das Blatt ist eine Ablagefläche. Alles, was Sie dort zeichnen oder einfügen, gilt als Notiz und wird daher nie gedruckt.

1. Öffnen Sie {{ui:Notizen}} und wählen Sie {{ui:Ablagefläche anzeigen}}, um so weit herauszuzoomen, dass um das Blatt Platz ist.
2. Zeichnen, schreiben oder fügen Sie neben dem Blatt mit einem beliebigen Werkzeug ein.
3. Um einen Teil der Zeichnung im Blick zu behalten, wählen Sie {{ui:Momentaufnahme auf die Ablagefläche}}, ziehen Sie über den Bereich und wählen Sie {{ui:Auf die Ablagefläche}}. Ein Bild erscheint neben dem Blatt in seiner Größe auf dem Papier.

Momentaufnahmen sind Bilder: Sie ändern sich nicht, wenn sich das Blatt ändert.

## Notizen ein- und ausblenden

Eine Notiz ist eine Markierung, die sich mit einem Schalter ein- und ausblenden lässt.

- Damit neue Markierungen zu Notizen werden, stellen Sie {{ui:Neue Markierungen sind}} in {{ui:Notizen}} ein.
- Um eine Markierung zu ändern, wählen Sie sie aus und verwenden Sie {{ui:Diese Markierung ist}} in {{ui:Eigenschaften}}.
- Um alle Notizen aus- oder einzublenden, drücken Sie **Shift+H** oder verwenden Sie {{ui:Notizen}} in der Leiste unter dem Blatt.

Notizen werden nicht gedruckt und sind in reduzierten Kopien, Listen, Zusammenfassungen und Exporten nicht enthalten; andere PDF-Betrachter zeigen sie nicht an. Ihre gespeicherte PDF behält sie für das nächste Öffnen. Wer diese Datei in MarkupCraft öffnet, kann ihre Notizen sehen; verwenden Sie daher für alles, was nur Sie lesen sollen, eine private Notiz.

## Private Notizen

Eine private Notiz ist mit einer Passphrase verschlüsselt, die nur Sie kennen. Niemand sonst kann sie in einer Ansicht lesen.

1. Wählen Sie in {{ui:Notizen}} {{ui:Passphrase festlegen}}.
2. Stellen Sie {{ui:Neue Markierungen sind}} auf {{ui:Eine private Notiz}} ein, oder ändern Sie eine Markierung in {{ui:Eigenschaften}}.

Auf Ihren anderen Geräten öffnen Sie die Datei und entsperren Sie sie mit derselben Passphrase. Kollegen können die Datei öffnen und speichern, ohne Ihre Notizen zu verlieren, und nichts zeigt ihnen, dass eine private Notiz vorhanden ist.

**Eine vergessene Passphrase lässt sich nicht wiederherstellen.** Niemand, auch wir nicht, kann Ihre privaten Notizen ohne sie öffnen.

Private Notizen werden nicht an Personen in einer Live-Sitzung oder an Assistenten gesendet, und sie können nicht in die Zwischenablage kopiert werden. Auf einem gemeinsam genutzten Computer lassen Sie {{ui:Auf diesem Gerät entsperrt bleiben}} ausgeschaltet und verwenden {{ui:Sperren}}, wenn Sie den Platz verlassen. Solange sie entsperrt ist, kann jeder an Ihrem Computer sie sehen.

Eine frühere Kopie einer Datei, die Sie gespeichert haben, bevor Sie eine Markierung privat gemacht haben, enthält diese Markierung noch. Senden Sie die neue Kopie, nicht die alte.

## Die Datei an jemanden senden

Wählen Sie in {{ui:Notizen}} {{ui:Bereinigte Kopie speichern}}, oder wählen Sie Datei, dann Seiten. Die Kopie behält Ihre normalen Markierungen und enthält keine Notizen, keine privaten Notizen und nichts von der Ablagefläche. Gedruckte und reduzierte Kopien lassen sie ebenfalls aus.
