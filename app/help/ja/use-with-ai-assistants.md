## 学べること

AIアシスタント（またはご自身で作成したスクリプト）に MarkupCraft を操作させる方法と、そのアシスタントが操作できる範囲を決める方法を説明します。

MarkupCraft には独自の AI は**なく**、どこにも何も送信しません。アシスタントはユーザーご自身でご用意します。Model Context Protocol（MCP）に対応したプログラムであれば、何でも使えます。MarkupCraft はアシスタントにツールを提供するだけで、どのツールを提供するかはユーザーが選びます。

## 有効にする

1. {{ui:Settings}}（アプリバーの歯車、または {{key:Mod+,}}）を開き、{{ui:MarkupCraft}} タブに移動します。
2. {{ui:Assistants}} の下で、**AIアシスタントとスクリプトによるMarkupCraftの利用を許可** にチェックを入れます。初期状態ではオフです。
3. 許可する操作を選びます。**読み取り** は最初からチェックされています。**編集**、**保存**、**書き出し** は必要なときだけチェックしてください。

チェックしていない権限のツールは、アシスタントには提示されません。アシスタントがそれでも要求した場合、MarkupCraft は拒否し、アクティビティログに記録します。スイッチをオフにすると、すべての接続が同時に終了します。{{ui:MarkupCraftの設定をリセット}} を選んでも、オフになります。

## アシスタントを接続する

アシスタントは、お使いのコンピューター上の **CadCraft Studio** を経由して接続します。Studio は、このコンピューターからのみ到達できる小さなサーバーを起動します。このサーバーは、Studio が起動するたびに作成されるトークンで保護されます。Studio で {{ui:アシスタントを接続}} を選び、アドレスとトークンをアシスタントにコピーしてください（貼り付けるべき正確な設定が Studio に表示されます）。トークンは決して共有しないでください。

:::note
ブラウザーのタブでは、アシスタントのための接続を開けません。ブラウザー版のアプリでは、お使いのコンピューター上の CadCraft Studio を使うまで、このスイッチは効果がありません。
:::

## 主導権は常にユーザーにあります

- **すべての変更は元に戻す1回の操作になります。** アシスタントの名前を付けて表示されます（例: 「アシスタント: add cloudrect」）。{{key:Mod+Z}} を押すと、アシスタントの直前の変更を一括で取り消せます。
- **接続されているかが分かります。** アプリバーのボタンは、接続中のアシスタントの名前を表示します。クリックすると、許可された操作を確認したり、**切断** したりできます。
- **アクティビティ。** {{ui:Settings}} › {{ui:MarkupCraft}} › {{ui:Assistants}} › {{ui:Activity}} に、すべての呼び出しが表示されます（いつ、どのツールが、完了したか拒否されたか）。{{ui:Save the log}} でコピーを保存できます。

## アシスタントが要求できるもの

| ツール | 権限 | 内容 |
|---|---|---|
| `app_info`、`sheets_list` | 読み取り | 開いているセット、そのシート、各シートのマークアップ数 |
| `markups_list` | 読み取り | マークアップの種類、シート、テキスト、コメント、計測値、ステータス、作成者、返信。シート、ステータス、種類、作成者で絞り込み |
| `markup_add` | 編集 | 長方形、雲マーク、楕円、テキストボックス、注記、線、矢印をシートに追加 |
| `markup_status`、`markup_reply` | 編集 | マークアップのステータスを設定（スレッドに記録され、アシスタントの署名付き）。スレッドにコメントを追加 |
| `markups_export` | 書き出し | {{ui:Markups}} の一覧が表示している内容の CSV または BCF（設定した絞り込み条件どおり）。Studio では、許可したフォルダーにファイルを書き込めます |
| `tasks_list` | 読み取り | タスクであるマークアップ: 担当者（人またはアシスタント）、期限日、状態、リンク、完了方法。`assignee: "assistant"` を指定すると、アシスタントの作業待ちの項目を一覧表示 |
| `task_set`、`task_clear` | 編集 | マークアップをタスクにする、または変更する（タイトル、担当者、期限、状態、リンク）。タスクを解除 |
| `tasks_check` | 編集 | 関連する図面範囲やモデル要素が実際に変更されたタスクを完了にします。他のアプリから読み取った要素の状態を渡します |
| `revisions_changes` | 読み取り | 開いている2つの図面セットの間で変更された内容の平易な一覧。自分の言葉でまとめるため |
| `pins_list`、`decision_add` | 読み取り、編集 | 音声メモ（長さ、作成者、日時、キャプション。音声やテキスト化された内容は含まない）と決定事項。決定事項をピン留めし、以前のものを置き換え |
| `redline_export`、`redline_answer` | 書き出し、編集 | 製図担当者向けの赤入れファイルを書き出し、製図担当者の回答を反映 |

アシスタントが追加したマークアップには、アシスタントプログラムが自身に付けた名前に「(assistant)」を付けたもの、またはレビュー担当者名を設定後は「(assistant for <お名前>)」が作成者として記録されます。そのステータス変更と返信も同じ形式で署名されます。各操作は1回の元に戻す操作になります。マークアップ付きPDFの保存は、いつもどおりユーザーが {{ui:Save}} で行います。

MarkupCraft を開かなくても、CadCraft MCP サーバーは、指定したフォルダー内の PDF のマークアップを一覧表示できます（`markups_list`）。また、`cadcraft info Set.pdf` はマークアップをコマンドラインに表示します。

## うまくいかない場合

- **アシスタントに MarkupCraft のツールが見えない:** このウィンドウでスイッチがオンになっているか、またそのウィンドウが Studio で開いているかを確認してください。
- **「編集の権限が必要です」:** {{ui:Assistants}} で **編集** にチェックを入れてから、もう一度依頼してください。
- **「401」や「token」のエラー:** トークンが変わりました（Studio が再起動された、または {{ui:新しいトークン}} を選んだ）。新しいトークンをアシスタントの設定にコピーしてください。
