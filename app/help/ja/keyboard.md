{{key:Mod}} を使うショートカットは、Mac では ⌘ キーでも Control キーでも使え、Windows と Linux では Ctrl キーで使えます。ツールの文字キーは、ボックスに入力していないときだけ働きます。入力中は、文字キーはただの文字として入力されます。あわせて参照: [キー、マウス、トラックパッド](common:keys)。

## 作図中

| キーまたは操作 | 働き |
|---|---|
| 作図中の {{key:Shift}} | 線分、矢印、長さ、ポリラインの辺を 45° 刻みにします。長方形、楕円、ボックス型の雲マークは正方形（楕円なら円）にします。ペンとハイライターは、直線の1本のストロークにします。 |
| ダブルクリック、{{key:Enter}}、または右クリック | ポリライン、ポリゴン、フリー雲マーク、面積の作図を完了します。 |
| {{key:Backspace}} | ポリライン、ポリゴン、フリー雲マーク、面積の最後の点を取り除きます。 |
| {{key:Esc}} | 作図中のものを取り消します。作図中のものがなければ選択を解除します。何も選択されていなければ、{{ui:Select}}に戻ります。 |
| {{key:Mod+Enter}} | テキストボックス、コールアウト、注記の入力を完了します（外側をクリックしても完了します）。 |
| 入力中の {{key:Esc}} | 入力中の文字を取り消します。 |
| {{ui:Count}} を使った {{key:Shift}}-クリック | 選択した個数グループの、もっとも近い点を取り除きます。 |

## 選択と編集

| キーまたは操作 | 働き |
|---|---|
| クリック | マークアップを選択します。 |
| {{key:Shift}}-クリック | マークアップを選択に追加、または選択から外します。 |
| 何もないシートの上で左から右へドラッグ | 枠内に完全に含まれるものを選択します（窓選択）。 |
| 何もないシートの上で右から左へドラッグ | 枠に触れたものを選択します（交差選択）。 |
| {{key:Mod+A}} | このシート上のすべてのマークアップを選択します。 |
| 選択したマークアップをドラッグ | 移動します（{{key:Shift}}: 45° 刻み）。 |
| ハンドルをドラッグ | サイズ変更または形状変更します（{{key:Shift}}: 縦横比を保つ、または 45° 刻み）。 |
| 矢印キー | 選択を画面上で1ピクセルずつ動かします（{{key:Shift}}: 10ピクセル）。 |
| ダブルクリック、または {{key:Enter}} | テキストボックス、コールアウト、注記の文字を編集します。スタンプの場合は、{{ui:Properties}}を開きます。 |
| {{key:Delete}} または {{key:Backspace}} | 選択を削除します。 |
| {{key:Esc}} | 何も選択しません。 |
| {{key:Mod+Z}} | 元に戻す |
| {{key:Mod+Y}} または {{key:Mod+Shift+Z}} | やり直し |

## 切り取り、コピー、貼り付け

同じコマンドは、ツールバーの{{ui:Edit}}グループ（{{ui:Copy}}、{{ui:Paste}}）と、その{{ui:More}}メニューにもあります。それぞれにキーが割り当てられています。いずれも、元に戻す操作1回で取り消せます。参照: [コピー、貼り付け、複製](topic:select-and-edit#copy-paste-and-duplicate)。

| キー | 働き |
|---|---|
| {{key:Mod+X}} | 切り取り: 選択をコピーして削除します。 |
| {{key:Mod+C}} | 選択をコピーします。 |
| {{key:Mod+V}} | 貼り付けます。ポインターがシート上にあるときは、ポインターが指す位置を中心にコピーが配置されます。それ以外のときは、元のものの横に配置されます。設定で、常に元のものの横に貼り付けるようにもできます。 |
| {{key:Mod+Shift+V}} | 同じ位置に貼り付け: 同じシート、またはほかのシートの同じ位置に貼り付けます。 |
| {{key:Mod+D}} | 選択を横に複製します（クリップボードの内容は変わりません）。 |

## ズームとパン

| キーまたは操作 | 働き |
|---|---|
| マウスホイール | ポインターの位置を中心にズームインまたはズームアウトします（ホイールでスクロールすることはありません）。 |
| {{key:Ctrl}} + ホイール | より速くズームします。 |
| {{key:Plus}} または {{key:Minus}}（{{key:Mod}} と併用も可） | 画面の中央を中心にズームインまたはズームアウトします。{{key:=}} も {{key:Plus}} として使えます。 |
| {{key:Mod+0}} | {{ui:Fit page}} |
| {{key:Mod+9}} | {{ui:Fit width}} |
| 中ボタンでドラッグ | パンします。 |
| 右ボタンでドラッグ | パンします（ポリラインの作図中でないとき）。 |
| {{key:Space}} を押したままドラッグ | パンします。 |
| 何も選択していないときの矢印キー | パンします。 |
| {{key:Ctrl+Shift+F}} | 画面モード: 通常、全画面表示、バーを隠した全画面表示（どのコンピューターでも Control キー） |

:::mac
**トラックパッドでは:** 2本指のスクロールでズームします。Chrome、Edge、Firefox では、ピンチでもズームできます。{{key:Space}} を押したままドラッグするか、{{ui:Pan}}ツールでパンします。2本指のクリックは右クリックとなり、ポリラインを完了します。ここでは {{key:Ctrl}}+クリックが右クリックではなく通常のクリックとして扱われることがあるため、2本指のクリックを使ってください。
:::

## タッチ

| ジェスチャー | 働き |
|---|---|
| 1本指 | 現在のツールで作図するか、選択します。 |
| 2本指 | 中央を中心にピンチでズームし、動かしてパンします。 |
| ストローク中に2本目の指 | ストロークを取り消し、代わりにズームします。 |
| ダブルタップ | ポリライン、ポリゴン、フリー雲マーク、面積の作図を完了します。 |

個数マークの点、注記、ポリラインの点、2点ツールの2点目は、指を離したときに配置されます。参照: [iPadまたはタッチスクリーンでのレビュー](topic:review-on-a-tablet)。
:::

## ブラウザーが保持するショートカット

- {{key:Mod+W}}、{{key:Mod+T}}、{{key:Mod+N}}、{{key:Mod+Q}} はブラウザーのものです。保存されていないマークアップがあるままタブやウィンドウを閉じると、その変更は失われます。コンピューターでは、ブラウザーの「このサイトを離れますか？」の確認の後に失われます。
- ほとんどのブラウザーは {{key:Mod+N}} を新しいウィンドウに使うため、ブラウザーのタブでは、ツールバーの{{ui:New}}を使ってください。デスクトップアプリと Studio では、このキーは MarkupCraft に渡されます。
- アプリがキーボードを使っている間は、{{key:Mod+O}}、{{key:Mod+S}}、{{key:Mod+D}}、{{key:Mod+A}}、{{key:Mod+V}}、{{key:Mod+Shift+V}}、{{key:Mod+0}}、{{key:Mod+Plus}}、{{key:Mod+Minus}} は、ブラウザーの代わりに MarkupCraft が受け取ります。マークアップを選択しているときは、{{key:Mod+C}} と {{key:Mod+X}} も受け取ります。{{key:Mod+,}} で{{ui:Settings}}を開きます。ブラウザーのページ全体をズームするには、ブラウザーのメニューを使ってください。
- 一部のブラウザーでは、MarkupCraft が受け取る前に {{key:Mod+9}} が最後のブラウザータブへ移動します。その場合は、シートの下にある{{ui:Fit width}}を使ってください。
- 全画面表示中の {{key:Esc}} でも、全画面表示を終了します。

## キーが働かないとき

- **ボックスに入力中です。** 先にシートをクリックしてください。（作図ツールでクリックすると作図されます。その後 {{key:Esc}} を押すか、{{key:Mod+Z}} を使ってください。）
- **ダイアログが開いています。** 閉じるまで、キー操作はダイアログに送られます。
- **ツールバーのボタンをクリックしたところです。** そのため、矢印キーや {{key:Space}} はそのボタンに対して働きます。ポインターをシート上に移動し、ホイールか中ボタンを使うか、ボタンをクリックする代わりにツールの文字キーを押してください。

## 移動の場所

「移動」コマンドはありません。マークアップを選択してドラッグしてください（{{key:Shift}} を使うと 45° 刻みを保てます）。ピンは{{ui:Move pin}}で、ページは{{ui:Move page earlier}}または{{ui:Move page later}}で移動します。
