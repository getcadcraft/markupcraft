MarkupCraftは開発中です。ここでは現在のビルドで**できない**ことをまとめています。計画の参考にしてください。これは現在のビルドについての説明であり、約束ではありません。

## 他の人との共同作業

| まだ作成されていません | 今日の対応 |
|---|---|
| コンピューター間でのクラウド保存と同期 | PDFはプロジェクトのファイルと一緒に保管してください。クラウド保存はまだ利用できません。 |
| 2人分のマークアップのコピーの統合 | シートを校閲者で分担するか、{{key:Mod+C}}と{{key:Mod+V}}で数件のマークアップを別のコピーへ貼り付けてください。RFI、提出書類、日報は統合できます: [RFI、提出書類、日報を追跡](topic:field-records)を参照してください。 |
| RFIと提出書類のチーム、通知、クラウドプロジェクト | PDFを渡し、{{ui:マージ}}でコピーをまとめてください。 |
| ライブセッション中のRFI、提出書類、日報 | 各自が自分のコピーで作業します。{{ui:マージ}}でコピーをまとめてください。 |
| 1つのレコードの異なる欄に対する2人の変更の統合 | 後から変更したコピーが、そのレコード全体として優先されます（スレッドと添付ファイル名は結合されます）。どのレコードを誰が編集するか決めてください。 |
| RFI、提出書類、日報のアシスタント機能 | {{ui:現場}}タブで作業してください。アシスタントはマークアップを扱えます: [AIアシスタントとMarkupCraftを使う](topic:use-with-ai-assistants)を参照してください。 |
| 送信後の返信の編集または削除 | すぐに{{ui:元に戻す}}するか、訂正の返信を追加してください。 |
| マークアップの作成者の変更 | 作業を始める前に自分の名前を設定してください。 |

## マークアップ

| まだ作成されていません | 今日の対応 |
|---|---|
| 入力欄付きのスタンプ、電子署名 | 名前と日付が入るカスタムテキストスタンプ、またはご自身の署名の画像を使ってください。 |
| 写真以外のファイル（文書、動画）の添付 | PDFと一緒に保管し、コメントでそのファイルを参照してください。 |
| Webサイトへのリンク、または開いていないファイルへのリンク | コメントに住所またはファイル名を書いてください。 |
| カスタムのステータスセット | 4つのステータスを使い、それ以上の内容は件名に書いてください。 |
| ファイルに読み取り専用として付いていたコメント（テキストのハイライト、他のプログラムのスタンプ）の編集 | それに返信するか、その横にMarkupCraftのマークアップを描いてください。 |
| 筆圧に応じたペンのストローク | 線の太さを設定してください。 |

## ページ自体の内容

| まだ作成されていません | 今日の対応 |
|---|---|
| ページに図形を直接描くこと | マークアップとして描いてから、{{ui:ページに入れる}}を使ってください。[ページ内容を変更する](topic:page-content)を参照してください。 |
| ページのオブジェクトを任意の角度に回転すること | 移動してサイズを変更してください。ページ全体は{{ui:ページ}}で回転します。 |
| 1行の文字の書体やサイズの変更、または複数行にまたがる文字 | 単語を1行ずつ変更してください。別の書体で新しい文字を入れるには、文字のマークアップを追加してください。 |
| スキャンされた画像の内部の編集 | 画像を差し替えるか、マークアップを付けてください。 |
| 暗号化された、または署名されたPDFの編集 | 署名のないコピーを依頼してください。マークアップはどのPDFでも使えます。 |

## 計測

| まだ作成されていません | 今日の対応 |
|---|---|
| 半径の計測 | それに沿って{{ui:円弧}}を描くか、{{ui:長さ}}で直径を計測して半分にしてください。 |
| 切り抜きの角の編集 | 切り抜きを削除し、描き直してください。 |
| 多数のシートに一度に1つの縮尺を適用すること | シートごとに{{ui:校正}}してください。プリセットを選ぶと、シートごとに数秒かかります。 |
| 1枚のシートに複数の縮尺（ビューポート） | 最も多く計測する図面に合わせて校正してください。シートの縮尺を変更すると、その上のすべてを再計測するため、再校正する前に詳細の値を書き留めてください。 |
| 図面の線へのスナップ | クリックする前に拡大するか、長さと角度を入力してください（[縮尺に合わせてスケッチ](topic:calibrate-and-measure#sketch-to-scale)を参照）。 |
| 項目、アセンブリ、単価を含む完全な拾い出し | TakeoffCraftを使ってください。CadCraftファミリーの拾い出しアプリです。 |

## シートとファイル

| まだ作成されていません | 今日の対応 |
|---|---|
| ページの変更（回転、移動、挿入、削除）の取り消し | 保存せずに閉じ、元のPDFを開き直してください。[印刷し、ページを変更する](topic:pages-and-printing)を参照してください。 |
| セットの1つのファイルを閉じること | {{ui:閉じる}}はセット全体を閉じます。必要なファイルを開き直してください。 |
| セットをプロジェクトとして保存し、1回の操作で開き直すこと | 同じPDFを開き直してください。 |
| 選んだ縮尺での印刷、または1枚の用紙への複数シートの印刷 | ブラウザーの印刷ダイアログを使うか、保存したコピーを別のPDFビューアーから印刷してください。 |

## 一覧と書き出し
