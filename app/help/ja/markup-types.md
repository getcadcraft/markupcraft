## ツール

| ツールバー | キー | 描き方 | 初期の見た目 | 保存したPDF内 |
|---|---|---|---|---|
| {{ui:Pen}} | {{key:P}} | ドラッグ | 赤、1.5 pt | インク |
| {{ui:Highlight}} | {{key:I}} | ドラッグ | 黄色、幅14 pt、透過、下にあるものに色を付ける | インク（ハイライターのストロークとしてマーク） |
| {{ui:Line}} | {{key:L}} | ドラッグ、または始点と終点をクリック | 赤、2 pt | 線分 |
| {{ui:Arrow}} | {{key:A}} | ドラッグ、または始点と終点をクリック | 赤、2 pt、終点に閉じた矢じり | 矢じり付きの線分 |
| {{ui:Arc}} | {{key:O}} | 始点、弧上の点、終点の順にクリック | 赤、2 pt | 弧に沿ったポリライン |
| {{ui:Rectangle}} | {{key:R}} | ボックスをドラッグ | 赤、2 pt、塗りつぶしなし | 正方形 |
| {{ui:Ellipse}} | {{key:E}} | ボックスをドラッグ | 赤、2 pt、塗りつぶしなし | 円 |
| {{ui:Polyline}} | {{key:Y}} | 点をクリックし、ダブルクリックで完了 | 赤、2 pt | ポリライン |
| {{ui:Polygon}} | {{key:G}} | 点をクリックし、ダブルクリックで完了 | 赤、2 pt、塗りつぶしなし | ポリゴン |
| {{ui:Cloud}} | {{key:C}} | ボックスをドラッグ | 赤、1.5 pt の波形の弧 | 雲状の枠線の正方形 |
| {{ui:Free cloud}} | {{key:Shift+C}} | 点をクリックし、ダブルクリックで完了 | 赤、1.5 pt の波形の弧 | 雲状の枠線のポリゴン |
| {{ui:Callout}} | {{key:K}} | 点で押し、文字の位置までドラッグして入力 | 赤の文字と引出線、1 pt、12 pt の文字 | 引出線付きの文字ボックス |
| {{ui:Text}} | {{key:T}} | クリック、またはボックスをドラッグして入力 | 赤、12 pt の文字、枠なし | 文字ボックス |
| {{ui:Note}} | {{key:N}} | クリックして入力 | 黄色の注記アイコン | 付箋 |
| {{ui:Stamp}} | {{key:S}} | スタンプを選び、クリックまたはドラッグ | 枠付きの大文字と「署名: <name>、<date>」。意味に応じて色付け | スタンプ |
| {{ui:Length}} | {{key:M}} | 始点と終点をクリック（縮尺が必要） | 青の寸法線（目盛りと長さ付き） | 寸法としてマークされた線分（計測値付き） |
| {{ui:Angle}} | {{key:X}} | 一方の辺の端、角、もう一方の辺の端の順にクリック | 青い辺、角の小さな弧、角度（度） | 角度を文字として持つポリライン |
| {{ui:Area}} | {{key:Q}} | 角をクリックし、ダブルクリックで完了（縮尺が必要） | 青い輪郭、薄い青の塗りつぶし、面積と周長 | 面積としてマークされた、計測値付きのポリゴン |
| {{ui:Count}} | {{key:U}} | 各項目をクリック | オレンジの番号付きの点と「group: n」タグ | グループごとに1つのインクコメント、項目ごとに1つの丸 |

タッチでは、「ダブルクリックで完了」はダブルタップになり、「クリック」は指を離したときに動作するタップになります（点、注記、個数で使います）。

## すべてのマークアップが持つ情報

| 項目 | 表示場所 |
|---|---|
| 作成者 | {{ui:Properties}}、一覧、スタンプの2行目、ほかのPDFビューアー |
| 作成日時と更新日時 | {{ui:Properties}}（お使いのタイムゾーン）、一覧、CSV |
| ステータス | 未対応、承認、却下、完了 |
| 件名 | 短いラベル。初期値は種類ごと（「雲マーク」「文字ボックス」「長さの計測」） |
| コメント | 長めのメモ。注記の場合は、その文字がコメントになります。 |
| 文字 | 文字ボックスとコールアウトのみ |
| 返信 | スレッドと、ステータスの変更 |
| 手直し項目 | 番号、担当者、期限、項目のステータス（手直し一覧に追加したとき） |
| スタイル | 色、線の太さ、塗りつぶしと塗りつぶしの不透明度（閉じた図形、文字、コールアウト）、不透明度、文字サイズ（文字、コールアウト、計測） |

## 読み取り専用のコメント

ファイルに含まれていて、MarkupCraft では編集できないコメント（テキストのハイライト、ほかのプログラムのスタンプ、その他の特殊な種類）は、種類「その他」、ステータスチップ「読み取り専用」として一覧に表示されます。ファイルで与えられた見た目をそのまま保ちます。選択して、作成者、件名、コメントを確認したり、返信したりできます。

## まだ作成されていません

ファイルの添付は、まだ作成されていません。どのマークアップもシートへリンクできます。参照: [シートへのリンク](topic:sheet-links)。画像と署名は{{ui:Stamp}}ツールで配置します。参照: [スタンプと注記](topic:stamps-and-notes)。参照: [まだ作成されていない機能](topic:not-built-yet)。
