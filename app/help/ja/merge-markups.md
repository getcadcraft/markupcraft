2人が、同じPDFを2つのコピーでマークアップします。異なるマークアップを編集していれば、コピーを手作業ではなくプログラムで統合できます。

## 仕組み

MarkupCraft が保存するすべてのマークアップは、PDF の中に独自の名前（ID）を持ち、その名前は変わりません。統合は、ファイル内の位置ではなく、この名前でマークアップを探します。どのプログラムも保存時に位置の番号を振り直すためです。注記と封印された非公開の注記も、同じ方法で対応付けられます。

シートは一切変更されません。2つのコピーのページ数は同じでなければなりません。ページ数が異なる場合、統合は自分のコピーをそのまま残し、その旨を伝えます。ページの追加や削除は、人が行う作業だからです。

## 設定

Git では、リポジトリごとに1回、2行の設定が必要です:

```
# .gitattributes
*.pdf merge=cadcraft

# 1回だけ、各コンピューターで
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

git を使わない場合は、`cadcraft merge <base> <ours> <theirs> -o <result>` を実行します。Fossil と Mercurial も、それぞれのマージツールの設定で同じ3つのファイルを指定します。図面に付随するタスクファイル（`<name>.markups.json`、参照: [動作するマークアップ](topic:markups-that-act)）は、プレーンテキストとして同じ方法で統合されます。

## ルール

- 一方の側だけで変更されたマークアップは採用されます。両方の側で同じ変更がされた場合は、1回だけ採用されます。
- 同じマークアップが2通りに変更された場合は、**競合**です。自分の側の内容が残り、レポートには両方が一覧されます。結果を開いて、そのマークアップを手作業で修正してください。
- どちらかの側で追加されたマークアップは残ります。一方の側で削除され、もう一方の側で変更されていないものは削除されます。一方の側で削除され、もう一方の側で変更されたものは、削除され、レポートに記載されます。
- レイヤー、列、記録、注記も同じルールに従います。
- 封印された非公開の注記は決して開かれません。両方の側のブロックは、そのまま残ります。

統合後のファイルは、MarkupCraft独自の保存と同様に、自分のコピーを全体として書き換えたものです。何もアップロードされず、すべてお使いのコンピューター上で実行されます。
