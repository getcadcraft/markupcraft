MarkupCraftはブラウザーのウィンドウいっぱいに表示されます。上から下、左から右の順に説明します。

## 最上部のバー

すべての上にある細いバーは、MarkupCraft自体ではなくCadCraftファミリーに属するものです。次の項目があります。

- アプリ名と、実行中のバージョン。
- {{ui:MarkupCraftについて}}: Webサイトのアプリのページを開きます。
- {{ui:ヘルプ}}: このヘルプをサイドパネルに開きます ({{key:F1}}キーでも可)。
- {{ui:オフライン用に保存}}: MarkupCraft、そのPDFリーダーとライター、このヘルプをこのブラウザーに保存し、接続なしで開けるようにします。完了すると「オフライン対応済み」と表示されます ([オフラインで使う](common:offline)を参照)。
- 画面モードのボタン ({{ui:全画面表示}})。
- {{ui:設定}} ({{key:Mod+,}}でも可): このアプリ固有の設定を行う{{ui:MarkupCraft}}タブと、CadCraftのすべてのアプリが共有する設定の{{ui:全般}}タブがあります ([MarkupCraftの設定](topic:settings)を参照)。
- {{ui:ペーパー}}と{{ui:モデル}}: 明るいテーマと暗いテーマです。{{ui:モデル}}では、シートは暗い背景に明るく描かれ、マークアップは各自の色を保ちます。

画面モードのボタン、または{{key:Ctrl+Shift+F}}で、通常、全画面表示、バーを隠した全画面表示の3つのモードを順に切り替えます。バーを隠しているときは、ポインターを画面の上端に動かす (またはそこをタップする) と、バーが戻ります。このショートカットは、Macを含むすべてのコンピューターでControlキーを使います。

:::note
全画面表示では、{{key:Esc}}キーでブラウザーも全画面表示を終了します。描画の取り消しだけが目的だった場合は、もう一度{{key:Ctrl+Shift+F}}を押すと全画面表示に戻れます。
:::

## ツールバー

最上部のバーの下に、ラベル付きでグループ分けされたツールが並びます。

| グループ | ボタン |
|---|---|
| ファイル | {{ui:開く}}、{{ui:保存}}、{{ui:閉じる}} |
| 選択 | {{ui:選択}}、{{ui:パン}} |
| 作図 | {{ui:ペン}}、{{ui:ハイライト}}、{{ui:線分}}、{{ui:矢印}}、{{ui:長方形}}、{{ui:楕円}}、{{ui:ポリライン}}、{{ui:ポリゴン}} |
| 修正 | {{ui:雲マーク}}、{{ui:フリー雲マーク}} |
| 注釈 | {{ui:コールアウト}}、{{ui:文字}}、{{ui:注記}}、{{ui:スタンプ}} |
| 計測 | {{ui:校正}}、{{ui:長さ}}、{{ui:面積}}、{{ui:個数}} |
| 編集 | {{ui:元に戻す}}、{{ui:やり直し}}、{{ui:コピー}}、{{ui:貼り付け}}、{{ui:その他}}: {{ui:切り取り}}、{{ui:コピー}}、{{ui:貼り付け}}、{{ui:同じ位置に貼り付け}}、{{ui:複製}}、{{ui:削除}}、{{ui:すべて選択}}、{{ui:選択解除}} |

使用中のツールは押された状態で表示されます。ボタンにポインターを合わせると、そのキーが表示されます (例: 「長方形 (R)」)。{{ui:その他}}メニューには、各コマンドのキーが横に並びます。現在使えないボタンは薄く表示されます。マークアップを選択するまで{{ui:コピー}}、何かをコピーするまで{{ui:貼り付け}}がそうです。{{ui:保存}}の後ろに小さな点があるときは、まだ保存されていないマークアップがあります。キーの全一覧は[キーボードとマウス](topic:keyboard)にあります。

ツールは描画後もオンのままなので、雲マークを続けて何個でも描けます。{{ui:選択}}に戻るには、{{key:Esc}}を押す (新しいマークアップがまだ選択されているときは2回) か、{{key:V}}を押します。

## シート一覧 (左)

{{ui:シート}}には、開いているすべてのPDFのすべてのページが並びます。各行には、シートの小さな画像、名前、シート番号またはファイルとページ、マークアップの数が表示されます。見出しの後ろの数は、シートの枚数です。

- 行をクリックすると、そのシートが表示されます。
- {{ui:シートを検索}}に入力すると、シート名、シート番号、ファイル名で絞り込めます。{{key:Enter}}キーで最初の一致を開きます。

シート名は、PDFに含まれていればそこから取られます。[図面セットを開いてシート間を移動する](topic:open-a-plan-set)を参照してください。

## シート領域 (中央)

作業中のシートです。何も開いていないときは、「図面セットを開く」と{{ui:PDFを開く}}ボタンが表示されます。ここにPDFをドロップすると開けます。

シートの下の細いバーには、次のものがあります。

- 前後のシートへの矢印と、「3/12: A-101 — Floor plan」の表示 (ポインターを合わせるとファイルとページが表示されます)。
- 縮小、ズームボックス (パーセンテージを入力して{{key:Enter}}キー。100%は一般的な画面での実寸)、拡大。
- {{ui:ページに合わせる}}と{{ui:幅に合わせる}}。

各シートのズームは、セットを開いている間、シートごとに記憶されます。

2つのシートを比較すると、ここに凡例として「古いシートのみ」「新しいシートのみ」「両方に存在」が表示されます。[2つの改訂版を比較する](topic:compare-revisions)を参照してください。

## パネル (右)

5つのタブがあります。

| タブ | 表示内容 |
|---|---|
| {{ui:プロパティ}} | 選択したマークアップの、作成者、日付、計測値、ステータス、件名、テキスト、コメント、スタイル、返信、手直し項目。描画ツールがオンで何も選択していないときは、新しいマークアップに使う設定。何も選択せず{{ui:選択}}がオンのときは、シートの、番号、タイトル、名前の取得元、用紙サイズ、縮尺、{{ui:シート名を変更}}。 |
| {{ui:マークアップ}} | 開いているセット内のすべてのマークアップ。フィルターと、{{ui:CSV}}・{{ui:BCF}}の書き出し付き。[マークアップ一覧](topic:markups-list-and-export)を参照。 |
| {{ui:手直し一覧}} | 担当者、期限、ステータス付きの、番号付き手直し項目。[手直し一覧を作る](topic:punch-list)を参照。 |
| {{ui:ツール}} | ツールチェスト: スタイル付きで保存したツール。[ツールチェスト](topic:tool-chest)を参照。 |
| {{ui:比較}} | 2つのシートの重ね合わせ。[2つの改訂版を比較する](topic:compare-revisions)を参照。 |

## ステータスバー (下)

- 左: シート上のポインターの位置を、用紙上のインチ ([設定](topic:settings)でミリメートルにも変更可) で表示します。
- 中央: メッセージ。ツールが次に求めているもの、いま保存したもの、何かが拒否された理由。**何かが起きないときは、ここを読んでください。**
- シートの縮尺ボタン (「未校正」、または縮尺)。クリックして縮尺を設定します。[シートを校正して計測する](topic:calibrate-and-measure)を参照。
- あなたの名前 (入力するまでは「名前を設定」)。クリックして変更します。

## 小さな画面では

幅がおよそ1180ピクセルを下回ると、パネルが狭くなり、シートの画像が小さくなります。スマートフォンのサイズの画面では、各部分が縦に積み重なります。ツールバー (横にスクロール)、シート、ステータスバー、パネル、そして一番下にシート一覧の順です。横向きのタブレットでは、完全なレイアウトのままです。
