MarkupCraft 0.9 で変わった点を、0.8.1 と比べて示します。中心となる考え方は、作業メモをクライアントが受け取るページに残さないことと、図面セット全体を一度にリンクできることです。

## 新機能

### メモ、ペーストボード、非公開メモ

- **ペーストボード。** 各シートの周囲の領域は作業机です。シートの横に描いたもの、入力したもの、貼り付けたものはすべてメモになり、印刷されることはありません。広く見るには {{ui:ペーストボードを表示}} を選択します。図面の一部の画像をシートの横に置くには、{{ui:ペーストボードにスナップショット}} を選択し、枠をドラッグしてから {{ui:ペーストボードへ}} を選択します。スナップショットは画像なので、シートが変わっても変更されません。詳しくは [メモ、ペーストボード、非公開メモ](topic:notes-and-pasteboard) を参照してください。
- **メモの表示と非表示。** どのマークアップもメモにできます。{{ui:メモ}} タブの {{ui:新しいマークアップは}} か、{{ui:プロパティ}} の {{ui:このマークアップは}} で設定します。{{key:Shift+H}} を押すか、シートの下にある {{ui:メモ}} のスイッチで、すべてのメモを一度に表示または非表示にできます。メモは印刷、フラット化したコピー、一覧、書き出しから除外され、ほかのPDFリーダーでは表示されません。保存したPDFには、次にMarkupCraftで開いたときのためにメモが残ります。
- **非公開メモ。** {{ui:パスフレーズを設定}} を選択し、マークアップを {{ui:非公開の注記}} にします。メモは10文字以上のパスフレーズでファイル内に暗号化されます。復元の方法はありません。パスフレーズがなければ、当社を含め誰も開けません。{{ui:ロック}} を選択すると非公開メモが隠れます。{{ui:このデバイスではロック解除したままにする}} は初期設定ではオフです。
- **きれいなコピーを保存。** {{ui:注記のないコピーを保存}} は、すべてのメモ、非公開メモ、ペーストボード上のすべてを削除します。クライアントに送るファイルに使ってください。

### セット全体をリンク

- **一括リンク。** {{ui:ページ}} › {{ui:一括リンク…}} を選択するか、{{ui:シート}} パネルの {{ui:テキストを検索}} の下にある {{ui:シートのコールアウトにリンク…}} を選択します。手順1では、各シートの番号と名前を表題欄から読み取ったとおりに一覧表示します。誤りがあれば修正してください。手順2では、見つかったコールアウトを一覧表示します（例: `3/A-501`、`DETAIL 2 ON A-501`）。{{ui:リンク予定}} には各コールアウトのシートとビューが表示され、{{ui:未リンク}} には、開いているシートに存在しない番号が表示されます。{{ui:リンクを作成}} を選択すると、すべてを1回の元に戻す操作で作成します。追補や番号の振り直しのあとで、もう一度実行できます。手作業で作ったリンクは変更されません。ビュー付きのリンクはPDFリンクとして保存されるため、ほかのリーダーでも詳細図が開けます。詳しくは [シートのリンク](topic:sheet-links) を参照してください。

### 作図

- **円弧、10の方法。** {{ui:円弧}} ツール（{{key:O}}）には、ページ上に {{ui:円弧の方法}} のボックスが表示され、円弧を描く10の方法を選べます。角度、長さ、半径、方向はクリックするか入力できます。詳しくは [10の方法で円弧を描く](topic:draw-an-arc) を参照してください。

### 共同作業

- **レビュー担当者に追従。** Liveセッションでは、相手の名前の横にある {{ui:追従}} を選ぶと、自分の表示が相手と一緒に動きます。自分でパンやズームを行うと追従は止まります。ホストは {{ui:全員に自分への追従を求める}} を選択できます。参加者一覧には、各参加者の色、名前、いるシート、最後に編集した日時が表示されます。詳しくは [Liveセッションで別のレビュー担当者に追従する](topic:follow-in-live) を参照してください。

## すべてのアプリ

- ツールチップは Bootstrap のツールチップです。開始時のヒントは閉じられ、タブ列はあふれるとスクロールします。ブラウザーのタブ名は `<document> — MarkupCraft | CadCraft` と表示されます。
- 複数のセクションを持つパネルは、1つを開くと他を閉じます（カーソルの横のロックで1つを開いたままにできます）。設定のスイッチでこの動作をオフにできます。
- 各アプリは、ライブラリオブジェクトの既定のコレクションから始まります。
- 重さと温度の単位は、単位の設定で利用できます。

## 修正済み

- **削除したマークアップが、保存したPDF内で読めなくなりました。** 以前は、削除または書き換えた注釈をページから取り除いても、テキストを含むオブジェクトがファイルに残っていました。現在は保存時にそれらのオブジェクトも削除されます。以前のビルドで保存されたファイルは、もう一度保存するまでそれらを保持しています。

## 正直な制限

- 一括リンクは、当社の検証用セットで試しました。実際のセットではバブルの描き方がさまざまなため、クライアントのセットではビューが一部漏れる場合があります。スキャンされたシートは、先に {{ui:文字を読み取り(OCR)…}} が必要です。
- メモ、非公開メモ、ペーストボードは、ヘッドレスブラウザーと当社のファイルで検証しました。大規模な実際のベクターセットや、実際の2人によるLiveセッションでは検証していません。パスフレーズの変更はまだ作成されていません。0.9より古いビルドではメモは表示されません。
- クラスビューは参加者一覧です。実際の教師と生徒による検証は行っていません。
- 英語以外の言語は、母語話者が確認するまで機械翻訳の下書きです。
- Windows のインストーラーにはコード署名がありません（{{ui:詳細情報}} を選択し、その後 {{ui:そのまま実行}} を選択）。macOS のディスクイメージは公証されていません（右クリックして開く）。

## 以前: 0.8 と 0.8.1

MarkupCraft 0.8 と 0.8.1 で変わった点を、0.7 と比べて示します。大きな新機能は、マークアップをタスクにできることです。タスクは、誰か、またはご自身のアシスタントが行い、図面が実際に変わると自動的に閉じます。

### 新機能

**動くマークアップ**

- **マークアップをタスクにする。** 1つ以上のマークアップを選択し、{{ui:タスク}} タブを開いて {{ui:選択をタスクにする}} を選択します。タスクには、タイトル、作業する人（または接続したアシスタント）、任意の期限日、状態があります。また、シート上の位置とスレッドも保持します。詳しくは [マークアップをタスクにする](topic:markups-that-act) を参照してください。
- **自動で閉じるタスク。** タスクは、マークアップ内の図面を監視できます。シートの新しいリビジョンを開いて {{ui:今すぐ確認}} を選択します。その範囲の線が髪の毛ほどでも変わっていれば、タスクは完了になり、マークアップは完了になり、スレッドに変更内容のメモが付きます。新しい日付スタンプや、1.5ポイント未満しか動いていない線は対象になりません。タスクはモデル要素を監視することもできます。アシスタントが `tasks_check` で要素を報告し、その後の報告が異なる場合、または要素が削除された場合に、タスクが閉じます。1回の元に戻す操作で再度開けます。
- **見つける。** {{ui:タスク}} の一覧は、状態と担当者で絞り込めます。{{ui:期限超過}} も選べます。{{ui:担当}} を選び、次に {{ui:アシスタント}} を選ぶと、アシスタントの作業を確認できます。期限日を過ぎたタスクは、問題パネルに警告として表示されます。{{ui:CSV}} は一覧を書き出します。タスクはマークアップと一緒にPDFに保存され、ほかのマークアップの属性と同じようにLiveでも共有されます。

**変更点を一覧で**

- **変更点を一覧表示。** {{ui:比較}} タブを開き、{{ui:セット全体を比較}} を選択して、前後のファイルを選び、{{ui:変更点を一覧表示}} を選択します。一覧の先頭には件数が表示され、変更された各シートが最も大きな変更から順に並びます。各シートについて、位置、大きさ（校正済みのシートでは実際の単位と紙のインチの両方）、線が追加されたか削除されたか、そこにあるマークアップの数、現れた語句や消えた語句が表示されます。{{ui:一覧をコピー}} はクリップボードにコピーし、{{ui:CSV}} は変更1件ごとに1行を書き出します。詳しくは [リビジョン間の変更点を文章で一覧にする](topic:what-changed-in-words) を参照してください。

**音声メモと決定事項**

- **音声メモ。** {{ui:メモ}} タブで {{ui:音声メモを録音}} を選択し、次に {{ui:録音を停止}} を選択します。録音は2分で自動的に停止します。メモはシートの中央にピン留めされ、ドラッグして正しい位置に移動し、{{ui:プロパティ}} にキャプションを入力できます。一覧の {{ui:再生}} で再生します。録音はPDF内に保存されます。
- **決定事項。** {{ui:決定事項をピン留め}} は、シートに1、2文の決定事項を書き込みます。以前の決定事項を置き換える場合は、{{ui:置き換える対象}} でそれを選びます。以前の決定事項は残り、「置き換え済み」と表示されて、新しい決定事項を指します。1回の元に戻す操作で取り消せます。詳しくは [音声メモと決定事項をシートにピン留めする](topic:voice-notes-and-decisions) を参照してください。

**リビジョンへの朱書き**

- **送って回答を受け取る。** {{ui:タスク}} タブで {{ui:リビジョンへの朱書き}} を開き、マークアップの対象となるリビジョンを入力して、{{ui:朱書きファイルを書き出し}} を選択します。`.redline.json` ファイルが得られ、開いている各マークアップが1項目ずつ含まれます。項目には、シート、位置（シートに対する割合で示すため、別の大きさで再出力しても合います）、文言、作成者、スレッド、タスクが含まれます。変更を描く人は、`.redline-answers.json` ファイルで「承認」「却下」「完了」のいずれかを返答します。{{ui:回答ファイルを読み込み…}} を選ぶと、各マークアップにその状態と製図者のメモが設定され、1回の元に戻す操作にまとめられます。詳しくは [朱書きとしてマークアップを製図者に送る](topic:redline-to-revision) を参照してください。

**AIアシスタント**

- **ツールが増えました。** CadCraft Studio で接続したアシスタントは、タスクの一覧（`tasks_list`）、タスクの作成または変更（`task_set`）、タスクの取り外し（`task_clear`）、新しいリビジョンや要素に対するタスクの確認（`tasks_check`）、開いている2つの図面セットの間の変更点の一覧（`revisions_changes`）を行えます。アシスタントは、AIアシスタントのスイッチで選んだツールだけを使え、各変更は1回の元に戻す操作になります。詳しくは [AIアシスタントとMarkupCraftを使う](topic:use-with-ai-assistants) を参照してください。

### すべてのアプリ

- **言語。** CadCraft Studio は54の言語に対応しました。新しく10言語を追加しました。リトアニア語、ラトビア語、ボスニア語、マラーティー語、テルグ語、アルバニア語、アフリカーンス語、フィリピン語、スワヒリ語、ウズベク語です。英語以外の言語はすべて、母語話者が確認するまで機械翻訳の下書きです。
- **入力デバイス。** {{ui:設定}} › {{ui:グローバル}} › {{ui:入力デバイス}} では、トラックパッド、マウスの側面ボタン、ペン、指のタップ、3Dマウス、ゲームコントローラー、MIDIコントローラーの動作を、すべてのアプリまたはこのアプリだけに設定できます。何も変更しない限り、すべてのデバイスは従来どおり動作します。詳しくは [トラックパッド、3Dマウス、コントローラーを使う](common:input-devices) を参照してください。
- **ツールバーの行数。** {{ui:設定}} › {{ui:全般}} › {{ui:ツールバーの行数}} には {{ui:折り返し}}（既定）、{{ui:2行}}、{{ui:1行}} があり、図面の表示領域を広く使えます。詳しくは [パネルを配置する](common:arrange-panels) を参照してください。
- **プロパティグリッド。** マークアップのスタイル欄は、共通のグリッドを使います。折りたためるカテゴリーと、ラベル列と値列があります。
- **問題パネル。** 期限超過のタスクなど、アプリからの警告は、1つの問題パネルにまとめられます。
- **Liveとアドオン。** Liveセッションについては [Liveで共同作業する](common:work-together-live) で説明しています。アカウントに紐づくアドオンの一覧は、[アドオンの基本とアカウントの一覧](common:addons-basics) にあります。
- **AIを接続する。** CadCraft Studio は、ご自身のアシスタントのためのハブです。一度接続すれば、8つのアプリすべてで使えます。アプリ自体はAIを含みません。

### 0.8.1 での修正

- **Studio は、実行中に言語を切り替えられます。** 以前は、デスクトップアプリとパッケージ版は英語のままでした。これはまだすべてのプラットフォームで検証されていません。言語が変わらない場合はお知らせください。
- Studio 0.8 のインストールには、{{ui:設定}} › {{ui:更新}} から 0.8.1 が提供されます。

### このバージョンではまだ未対応

- **コード署名がありません。** Windows のインストーラーと macOS の .dmg には、まだ署名がありません。Windows で SmartScreen がインストーラーを止めた場合は、{{ui:詳細情報}} を選択し、次に {{ui:そのまま実行}} を選択してください。Mac では CadCraft Studio を右クリックして {{ui:開く}} を選択します。ストア版のビルドは保留中です。
- **AIの接続は一部が未完成です。** Studio 内でのワンクリック接続、ブラウザーアシスタント用のホスト型コネクター、Studio 内でのご自身の API キーは、このリリースでは保証していません。タスクのループは検証済みですが、実際のアシスタントではまだ検証していません。
- **タスクの確認には同じページサイズが必要です。** 別のサイズで再出力したシートは一致しないため、そのタスクは閉じません。シートはシート番号、またはページの位置で対応付けられます。
- **音声メモは録音のみです。** 文字起こしはなく、アシスタントが見るのはメモの長さ、作成者、キャプションだけで、音声は見えません。録音はヘッドレスブラウザーの仮想マイクで試しました。スマートフォン、タブレット、ノートパソコンの実際のマイクでの確認はまだです。
- **PDF内の計算シートと理由** は、ファイル内の非公開エントリーに保存されます。以前のMarkupCraftはそのエントリーを無視し、次回の保存時に削除します。そのため、そのようなファイルは 0.8 以降で開いて保存してください。
- **製図者側の朱書き。** CadCraft が朱書きファイルを読み込んで回答する機能は、まだ作成されていません。
- **ほかの言語。** タミル語のアプリバーは 528 px はみ出しています。

ほかのすべての項目は [まだ作成されていない機能](topic:not-built-yet) にあります。その前のリリースについては [0.7の新機能](topic:whats-new-0-7) を参照してください。
