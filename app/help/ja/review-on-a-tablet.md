MarkupCraftはタッチに対応しています。iPad（SafariまたはChrome）、タッチスクリーンのノートパソコン、または最新のブラウザーを使ったWindowsまたはAndroidのタブレットで動作します。横向きでは、タブレットは全体のレイアウトを表示します。

## ジェスチャー

| ジェスチャー | 動作 |
|---|---|
| 指1本 | 現在のツールで描く、または{{ui:選択}}で選択する |
| 指2本、広げるかつまむ | 指の間の位置を中心にズームする |
| 指2本を一緒に動かす | パンする。ズームとパンを1回の動きで行えます |
| 描画中に2本目の指 | 1本目の指が開始した操作を取り消し、代わりにズームを開始する |
| ダブルタップ、またはタッチして押し続ける | ポリライン、ポリゴン、フリー雲マーク、面積を完了する |
| {{ui:選択}}で文字、コールアウト、注記をタッチして押し続ける | その文字を編集できるように開く |
| {{ui:パン}}をオンにして指1本 | パンする |

タッチスクリーンでは、ツールバーのボタン、メニュー、タブ、ダイアログのボタンが大きくなり、指で押しやすくなります。

## 指を離したときの動作

ピンチの最初の指が跡を残さないよう、一部のツールは、タッチしたときではなく、指を**離した**ときに動作します:

- {{ui:個数}}: 点は離したときに追加されます。
- {{ui:注記}}: メモは離したときに配置されます。
- {{ui:ポリライン}}、{{ui:ポリゴン}}、{{ui:フリー雲マーク}}、{{ui:面積}}: 各点は離したときに追加されます。
- {{ui:線分}}、{{ui:矢印}}、{{ui:長さ}}、{{ui:校正}}: 始点をタップし、次に終点をタップすると、終点は離したときに配置されます。

指が少しでも大きく滑ってから離すと、タップとは見なされず、何も追加されません。きちんとタップしてください。修正するには{{ui:元に戻す}}を使ってください。

ドラッグで使うツール（{{ui:ペン}}、{{ui:ハイライト}}、{{ui:雲マーク}}、{{ui:長方形}}、{{ui:楕円}}、{{ui:コールアウト}}、{{ui:文字}}、{{ui:スタンプ}}）は、触れた瞬間に始まります。2本目の指がそれらを取り消します。

## 指で選択する

- マークアップをタップして選択します。ドラッグして移動し、ハンドルをドラッグしてサイズを変更します。指がシートに触れると、マークアップとハンドルは大きな操作対象になり、ハンドルは大きく描かれます。
- 空いたシート上でドラッグして選択ウィンドウを描きます（左から右: 完全に内側；右から左: 触れるもの）。
- {{ui:選択}}では、指1本ではパンは**されません**。指2本を使うか、{{ui:パン}}を選んでください。

## キーボードが必要なこと

キーボードがないと、{{key:Shift}}、{{key:Esc}}、{{key:Enter}}はありません。代わりに次のようにしてください:

| キーボードの操作 | キーボードがない場合 |
|---|---|
| {{key:Esc}}で取り消す、または{{ui:選択}}に戻る | ツールバーの{{ui:選択}}をタップ |
| 45°の線、正方形、円に{{key:Shift}} | 慎重に描き、ハンドルで調整 |
| {{key:Shift}}+クリックで選択に追加 | 選択ウィンドウを使う |
| {{key:Shift}}+クリックで個数の点を削除 | 誤ったタップの直後に{{ui:元に戻す}} |
| {{key:Mod+Enter}}で入力を完了 | テキストボックスの外をタップ |
| {{key:Enter}}でポリラインを完了する、またはマークアップの文字を編集する | タッチして押し続ける、または{{ui:プロパティ}}の{{ui:シート上で編集}} |
| {{key:Delete}} | ツールバーまたは{{ui:プロパティ}}の{{ui:削除}} |
| {{key:Esc}}で新しい個数グループを開始 | {{ui:選択}}で空のシートをタップし、次に{{ui:個数}}を再びタップ |

キーボードケースまたはBluetoothキーボードを使うと、すべてのショートカットが戻ります。iPadでは、⌘キーで{{key:Mod+Z}}などが使えます。

ボタンは、タッチでは、ツールチップを表示しません。各ツールのキーは[キーボードとマウス](topic:keyboard)に載っています。

## スタイラスとApple Pencil

スタイラス（Apple Pencil、Surface Penなど）はマウスと同様に動作し、描画と選択を行い、接触した時点ですぐに動作します。ピンチとパンには指を使ってください。筆圧によって線の太さは変わりません。

## iPadでの開く・保存

- {{ui:開く}}は、Filesのピッカーを表示します: iCloud Drive、このiPad内、および接続したストレージアプリ。
- {{ui:保存}}はダウンロードを求めます。コピーはFilesの「ダウンロード」（またはSafariの設定で指定したフォルダー）に入ります。

## タブレットで作業を安全に保つ

:::warning
iPadのSafariは、未保存の作業があるページを離れる前に警告しません。また、iPadOSはメモリを空けるためにバックグラウンドでタブを再読み込みすることがあります。MarkupCraftはブラウザー内に復元用コピーを保持し、次に開いたときにそれを戻すことを提案します（[作業内容を復元](common:recover)を参照）。ただし、**シートごと、または現場を回るたびに保存してください**。プライベートタブではコピーは保持されません。
:::

- 名前、ツールの設定、ツールチェストは、コンピューターの場合と同様に、そのiPadのそのブラウザーに保存されます。[このブラウザーに保存されるもの](topic:browser-storage)を参照してください。
- **電波のない現場に行く前に:** まだオンラインの間に、iPadのSafari（またはChrome）でMarkupCraftを開き、上部のバーで{{ui:オフライン用に保存}}を選んでください。「オフラインで利用可能」と表示されるまで待ちます（「N / M 保存中」と数えます。PDFリーダーとライターは約6 MBです）。現場では同じアドレス、またはそのブックマークを開いてください。PDFを開く、マークアップする、保存するという操作は、接続なしでできます。「オフラインでは利用できません」と表示される場合はプライベートタブにいるため、通常のタブを使ってください。[オフラインでの作業](common:offline)を参照してください。
- Safariは、数週間使用していないオフラインのコピーを削除します。出張前には「オフラインで利用可能」をクリックし、「再保存（最新版を取得）」を選んでください。
- 非常に大きなプランセットは多くのメモリを使います。タブレットでは、訪問に必要なシートだけを開いてください。

## スマートフォンでは

動作しますが、画面が小さいです。部品は縦に積み重なり（ツールバー、シート、ステータスバー、パネル、そしてシート一覧の順）、ツールバーは横にスクロールします。スマートフォンは確認や簡単なメモの追加に使い、実際のレビューはタブレットまたはコンピューターで行ってください。
