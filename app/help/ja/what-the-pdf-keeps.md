変更版のコピーは、元のPDFに注釈（PDFのコメント）を追加したものです。ページ自体、その図面、文字、しおり、リンクは元のまま複製されます。

## 各マークアップ

| MarkupCraft | 保存形式 | 他のPDFビューアーでの表示 |
|---|---|---|
| 長方形、ボックス雲形 | Square注釈（雲形: 雲状の枠線） | 長方形または雲形のコメント |
| 楕円 | Circle注釈 | 楕円のコメント |
| ポリゴン、フリー雲形 | Polygon注釈（雲形: 雲状の枠線） | ポリゴンまたは雲形のコメント |
| ポリライン | PolyLine注釈 | ポリラインのコメント |
| 線、矢印 | Line注釈（矢印: 閉じた矢じり） | 線または矢印のコメント |
| 長さ | 寸法としてマークされたLine注釈（計測値付き） | 対応しているビューアーでは長さの計測 |
| 面積 | 面積としてマークされたPolygon注釈（計測値付き） | 対応していれば面積の計測、そうでなければポリゴン |
| 個数グループ | 1つのInk注釈、項目ごとに1つのリング。テキストは「group: n」 | Inkのコメント |
| ペン、蛍光ペン | Ink注釈（蛍光ペンはその旨をマーク） | Inkのコメント |
| テキスト | FreeText注釈 | テキストボックスのコメント |
| コールアウト | 引出線付きのFreeText注釈 | コールアウトのコメント |
| 注記 | Text注釈 | 本文を開く付箋 |
| スタンプ | Stamp注釈 | スタンプのコメント |

すべてのマークアップは、次の内容とともに保存されます。

- **それ自体の見た目。** MarkupCraftが画面上で描くとおりに描画されるため、どのビューアーでも同じに見え、同じように印刷されます。手直し番号のバッジも含みます。
- **作成者**、**作成日と更新日**、**件名**、**コメント文**（テキストボックスとコールアウトでは本文とコメント）、**色**、**不透明度**。
- **MarkupCraftの詳細。** 他のプログラムが無視する非公開の項目に、状態、手直し項目、スタイルと種類を保存するため、正確に開き直せます。

## スレッドと状態

- 各返信は、そのマークアップに紐づく返信コメントとして、作成者、日付、本文とともに保存されます。返信は図面上に独自のアイコンを持ちません。
- 状態の変更は、レビュー状態を伴う返信として保存されます。他のレビューツールでは承認、却下、完了として表示されます。「未処理」は状態なしとして保存されます。
- 状態が「未処理」以外なのに状態変更の記録がないマークアップには、レビュー状態の返信が1件付くため、他のプログラムでも状態が見えます。
- 元のファイルにある読み取り専用のコメントへの返信も、同様に、そのコメントに紐づけて保存されます。

## 各シート

- **縮尺:** 校正されたシートには、ページ全体を覆う計測ビューポート（ページ縮尺を保存する標準的な方法）と、MarkupCraft独自の校正のコピーが付きます。
- **シート番号:** {{ui:シート名を変更}} で入力した番号がページラベルになります。ファイル内のいずれかのページにラベルがあれば、そのファイルの全ページにラベルが付きます。入力された番号があればそれを、なければ元のラベルを、それもなければページ番号を使います。
- **シートタイトル:** 入力したタイトルはMarkupCraft用にのみ保存されます。他のビューアーには表示されません。

## 文字と文字種

文字は、どのPDFビューアーにもあるHelveticaで書き込まれます。Western European（Windows-1252）の範囲外の文字は、コピーでは「?」として表示されます。保存時のメッセージにその数が示されます。

## 計算シートと根拠

計算シートと根拠は、PDFの `/MarkupCraftShell` という非公開の項目に保存されます。他のPDFプログラムはこれを無視します。古いMarkupCraftもこれを無視し、次回そのファイルを保存する際に削除します。

## 既存のコメントの扱い

すでにコメントが付いたPDFを開くと、次のようになります。

- MarkupCraft独自のコメントは正確に読み戻されます。他のプログラムが移動またはサイズ変更した場合は、その新しい位置が優先されます。
- 他のプログラムの長方形、楕円、線、ポリライン、ポリゴン、インク、テキストボックス、付箋は、編集可能なマークアップになります。**保存すると、MarkupCraftは元の注釈を削除し、ポップアップと返信を含めて独自の形式で書き直します。** 見た目が少し変わることがあります。
- 他のプログラムのレビュー状態は、状態を設定します。新しいものが優先されます。
- それ以外（テキストのハイライト、他のプログラムのスタンプ、その他の特殊な種類）は、コピーに**そのまま残され**、読み取り専用になります。
- リンクとフォームフィールドはそのまま残され、一覧には表示されません。

同じファイルを再度保存しても、何も重複しません。MarkupCraftが読み込んだマークアップは追加されず、置き換えられます。

## 変更されないもの

ディスク上の元のファイルは決して変更されません。コピーはサイズの最適化を行わないため、元のファイルよりやや大きくなることがあります。保護された（暗号化された）PDFは保存できません。
