## セットを開く

1. ツールバーの{{ui:開く}}を選ぶか、{{key:Mod+O}}を押してください。
2. ファイル選択ダイアログで、セットのすべてのPDFを選択し（{{pick:mac=⌘を押しながら各ファイルをクリック|windows linux=Ctrlを押しながら各ファイルをクリック}}、またはShiftで範囲を選択）、確定してください。
   または、{{pick:mac=Finder|windows=エクスプローラー|linux=お使いのファイルマネージャー}}からファイルをシート領域へドラッグしてください。ドラッグ中は「ドロップしてPDFを開く」と表示されます。
3. ステータスバーに「<file>を開いています…」と表示される間お待ちください。大きいファイルでは「(60枚中10枚)」のように件数が表示されます。

結果: {{ui:シート}}の一覧には、開いた順にすべてのファイルのすべてのページが表示され、ステータスバーには「3つのファイルを開きました（セット内42枚のシート）。」のような表示が出ます。ファイルにすでにコメントがあった場合は、読み込んだ件数も加わります。

後からファイルを追加するには、同じ方法で開いてください。一覧の末尾に追加されます。

## 白紙ページから始める

図面なしでスケッチやメモを取るには、PDFを開く代わりに白紙ページを作ってください:

1. ツールバーの{{ui:新規}}、または開始画面の{{ui:白紙ページから始める}}を選ぶか、ブラウザーが許可する場合は{{key:Mod+N}}を押してください（デスクトップアプリとStudioでは常に使えます）。
2. {{ui:用紙サイズ}}を選びます: Letter、Tabloid、ANSI B、ARCH D、ARCH E、A4、A3、A1のいずれか、および{{ui:縦}}または{{ui:横}}。
3. {{ui:グリッド}}を選びます: {{ui:なし}}、{{ui:点}}、{{ui:方眼}}。グリッドは、インチ用紙では1/4 inごとに、1 inごとに太い線が引かれます。メートル法の用紙では5 mmごとに、10 mmごとに太い線が引かれます。グリッドはページに印刷されます。
4. 作成する{{ui:ページ}}の数を1から20の間で入力し、{{ui:作成}}を選んでください。

結果: 「Untitled-1.pdf」（続いて「Untitled-2.pdf」など）という名前の新しいPDFが、ほかのファイルと同様に開きます。これはこのコンピューター上で作成されたものです。すべてのツールが使え、{{ui:保存}}を選ぶと「Untitled-1 (marked up).pdf」がダウンロードされます。MarkupCraftは次回のために選択内容を記憶します。

ページには縮尺がありません。ステータスバーには「校正されていません」と表示されます。グリッドは縮尺ではありません。計測するには、先にシートを校正するか縮尺を選んでください。[計測と校正](topic:calibrate-and-measure)を参照してください。

白紙のセットにページを追加するには、そのシートのいずれかを開き、{{ui:シート}}の一覧の下にある{{ui:白紙ページを追加}}を選んでください。新しいページは同じ用紙とグリッドで、末尾に追加されます。ほかのページの変更と同様に、元に戻すことはできません。[印刷し、ページを変更する](topic:pages-and-printing)を参照してください。

## シートの名前の付けられ方

MarkupCraftは各シートに「<sheet number> — <title>」という名前を付けます。例: 「A-101 — Floor plan」。以下のうち最初に見つかったものを使います:

1. {{ui:シート名を変更}}で入力した名前（下記）
2. PDFの作成者が設定している場合は、PDF自体のページラベル（例: 「A-101」）
3. 表題欄: MarkupCraftはページのテキストを読み、シート番号らしいもの（A-101、A1.01、M-201A、KA1-1）を探します。右下の角、右端の帯、下端の帯を優先し、その近くで最も大きい文字をタイトルとして使います。
4. それ以外の場合は、ファイル名とページ: 「Plans — page 3」

どの方法が使われたかを確認するには、{{key:Esc}}を押して何も選択されていない状態にし、{{ui:選択}}をオンにして、{{ui:プロパティ}}を見てください。「読み取り元」に「ページラベル」、「表題欄」、「ファイル名」、「手入力」のいずれかが表示されます。

:::note
スキャンされたシートや、文字が線として書き出されたPDFには、読み取れるテキストがありません。名前を変更するまでは、ファイルとページの名前が付きます。MarkupCraftはまだ画像からテキストを読み取れません。
:::

## シート間を移動する

- {{ui:シート}}の一覧でシートをクリックします。
- 次のシートは{{key:PageDown}}、前のシートは{{key:PageUp}}を押すか、シートの下のバーにある矢印を使ってください。
- {{ui:シートを検索}}に入力してください: 番号の一部（「A-2」）、タイトルの単語（「roof」）、またはファイル名。入力すると一覧が絞り込まれます（「42枚中4枚」）。最初の一致を開くには{{key:Enter}}を押してください。ボックスを空にすると、すべてのシートが再び表示されます。

各シートは、セットを閉じるまで自分のズームと位置を保持します。

## ズームとパン

:::mouse
- **ズーム:** シートの上でホイールを回してください。ポインターの位置を中心にズームします。または{{key:Plus}}と{{key:Minus}}（{{key:Mod}}と併用も可）を押すか、ズームボタンを使ってください。ズームの欄に正確な割合を入力できます。
- **全体表示:** {{ui:ページに合わせる}}（{{key:Mod+0}}）でシート全体を表示し、{{ui:幅に合わせる}}（{{key:Mod+9}}）で幅いっぱいに表示します。
- **パン:** ホイールボタンでドラッグするか、右ボタンでドラッグするか、{{key:Space}}を押しながらドラッグするか、{{ui:パン}}（{{key:H}}）を選んでからドラッグしてください。何も選択していないときは、矢印キーでもシートを動かせます。
:::

:::mac mouse
Macのトラックパッドでは、2本指のスクロールでズームします（シートはスクロールしません）。パンするには、{{key:Space}}を押しながら1本指でドラッグするか、{{key:H}}を押して{{ui:パン}}に切り替えてください。ピンチはChrome、Edge、Firefoxでズームします。
:::

:::touch
- **ズームとパン:** シートに2本の指を置きます。指を広げるかつまむと、2本の指の間の位置を中心にズームし、一緒に動かすとパンします。両方が同時に行われます。
- **1本指でパン:** 先に{{ui:パン}}を選んでください。ほかのツールでは、1本指で描く、または選択します。
- {{ui:ページに合わせる}}と{{ui:幅に合わせる}}は、シートの下のバーにあります。
:::

シート全体よりずっと遠くまでズームアウトでき、6400%まで拡大できます。動きを止めると、少し後にシートが鮮明に描き直されます。

## しおり

シートの{{ui:シート}}パネルの上部にある{{ui:しおり}}は、開いているシートが属するPDFのしおり（アウトライン）を表示します。1つ選ぶと、そのページへ移動します。鉛筆アイコンでしおりの名前を変更し、×印で削除します。{{ui:シートから作成}}は、シートごとに1つのしおりを作り、シートの一覧に表示される名前（シート番号とタイトル）が付きます。{{ui:このシートに追加}}は、表示しているシートのしおりを1つ追加します。変更はファイルの未保存の作業の一部です。{{ui:保存}}でコピーに書き込まれ、どのPDFビューアーでも表示されます。

## 表示を回転する

シートの下のバーの右側にある2つの回転ボタンで、表示を90度ずつ、どちらの向きにも回転できます。横向きに描かれたシートに使います。回転するのは表示だけです。PDFとマークアップはそのままで、次のシートは各PDFの向きで開きます（各シートは、セットを開いている間は自分の回転を記憶します）。回転した表示で追加した文字は、見えているとおりに正しい向きで読めます。保存されたPDFのページ自体を回転するには、{{ui:ページ}}の{{ui:ページを時計回りに回転}}を使ってください。[印刷し、PDFのページを変更する](topic:pages-and-printing)を参照してください。

## シート名を変更する

シートの名前が誤っているか、ない場合:

1. シートを表示します。
2. {{key:Esc}}を押して何も選択されていない状態にし、{{ui:選択}}ツールをオンにします。{{ui:プロパティ}}にシートが表示されます。
3. {{ui:シート名を変更}}を選んでください。
4. {{ui:シート番号}}と{{ui:タイトル}}を入力し、{{ui:保存}}を選んでください。

結果: シートの一覧、シートの下のバー、マークアップの一覧がすべて新しい名前を使います。「読み取り元」には「手入力」と表示されます。名前の変更は{{key:Mod+Z}}で元に戻せます。

ファイルの内容に戻すには、{{ui:シート名を変更}}をもう一度開き、両方の欄を空にして{{ui:保存}}を選んでください。

保存すると、入力したシート番号がPDFのページラベルになるため、他のPDFビューアーのページ欄にも「A-101」と表示されます。ファイル内のいずれかのページに番号を付けると、そのファイルのすべてのページにコピー内でラベルが付きます（入力した番号、なければ元のラベル、それもなければページ番号）。入力したタイトルはMarkupCraftには保持されますが、他のビューアーには表示されません。

## PDFをTakeoffCraftへ送る、またはここに取り込む

TakeoffCraftが同じ場所で開いている場合（ラボ、Try、またはオンラインのアプリ）、シートの下のバーに{{ui:TakeoffCraftで開く}}があります。これを選ぶと、ここで開いたのと同じ状態のシートのPDFが、新しいタブでTakeoffCraftに開きます。数量を計測できます。マークアップはここに残るため、通常どおり保存してください。

TakeoffCraftの{{ui:MarkupCraft}}ボタンは、逆方向に同じことをします。{{ui:開く}}を選んだかのように、PDFがここで開きます。ブラウザーが新しいタブをブロックした場合は、このサイトのポップアップを許可してから、ボタンをもう一度選んでください。
