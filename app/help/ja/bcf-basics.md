BCF（BIM Collaboration Format）は、BIMツール間で課題を受け渡すためのオープンなファイル形式です。多くのモデル調整ツールやオーサリングツールは、`.bcfzip` ファイルを課題の一覧として読み込めます。MarkupCraft は **BCF 2.1** で書き出します。

## 作成する

1. {{ui:Markups}} タブを開きます。
2. 送りたいものに一覧を絞り込みます。例: {{ui:Status}} が「オープン」。一覧に表示されているマークアップだけが書き出されます。
3. {{ui:BCF}} を選びます。
4. 各マークアップのスナップショットが作成されるまで待ちます（「BCF 用のスナップショットを作成しています (5/20)…」）。

結果: 「<name> markups.bcfzip」がダウンロードされ、ステータスバーにトピックの数とファイルサイズが表示されます。

## 含まれる内容

各マークアップが 1 つの**トピック**になります。

| トピックの項目 | 設定される内容 |
|---|---|
| タイトル | 手直し番号、件名、シート。例: 「#4 A-101 の雲マーク — 平面図」 |
| 種類 | マークアップの種類（雲マーク、コールアウト、長さ…） |
| ステータス | オープン、承認、却下、完了のいずれか |
| ラベル | マークアップの種類とシート |
| 作成者と日付 | マークアップの作成者、作成日時、更新日時 |
| 担当者、期限 | 手直し項目がある場合は、その担当者と期限 |
| 説明 | 文字またはスタンプの文言、計測値、コメント、シートとファイル |
| コメント | 返信ごとに 1 件。作成者と日付付き |
| スナップショット | シート上の該当部分にあるマークアップの画像 |
| ビューポイント | シート上のマークアップの位置を真上から見た表示 |

同じマークアップを再度書き出すと、同じトピック ID になります。そのため、BCF を読み込めるツールは、それを同じ課題として認識できます。

## 知っておくべき制限

- **シートはモデルではありません。** ビューポイントは、マークアップのシート上の位置を、紙面上のメートル単位で測って示します。BIM ツールをモデル内の場所へ移動させるわけではありません。スナップショットとシート名を使って場所を探してください。
- **ステータスと種類は MarkupCraft 独自のものです**（オープン、承認、却下、完了。雲マーク、コールアウトなど）。BCF で認められているとおり、ファイルにはこれらが記録されますが、独自の固定リストを持つツールでは、対応付けされたり無視されたりすることがあります。
- **読み込みでは、モデルの視点ではなくコメントが取り込まれます。** {{ui:Import BCF}} は、書き出したマークアップに返信とステータスを追加し、ほかの課題はメモとして作成します。モデルのカメラを表示することはできません。[マークアップ一覧と書き出し](topic:markups-list-and-export#import-bcf) を参照してください。
- 図面のレビューでは、マークアップを PDF で返送する方が簡単なことがよくあります。BCF は、図面へのコメントをモデル調整のワークフローに取り込むためのものです。
