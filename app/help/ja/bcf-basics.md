BCF（BIM Collaboration Format）は、BIMツール間で課題をやり取りするためのオープンなファイル形式です。多くのモデル調整ツールやオーサリングツールは、`.bcfzip` ファイルを課題の一覧として読み込めます。MarkupCraft は **BCF 2.1** で書き出します。

## 作成方法

1. {{ui:マークアップ}} タブを開きます。
2. 送りたい内容に一覧を絞り込みます。たとえば {{ui:ステータス}} を「未対応」にします。一覧に表示されているマークアップだけが書き出されます。
3. {{ui:BCF}} を選択します。
4. 各マークアップのスナップショットを作成する間お待ちください（「BCF用にスナップショットを作成しています (20件中5件)…」）。

結果: 「<name> markups.bcfzip」がダウンロードされ、ステータスバーに含まれるトピックの数とファイルサイズが表示されます。

## 含まれる内容

各マークアップが1つの **トピック** になります。

| トピックの項目 | 入力内容 |
|---|---|
| タイトル | 手直し番号、件名、シート。例: 「#4 A-101の雲マーク — 平面図」 |
| 種類 | マークアップの種類（雲マーク、コールアウト、長さなど） |
| ステータス | 未対応、承認、却下、または完了 |
| ラベル | マークアップの種類とシート |
| 作成者と日付 | マークアップの作成者、作成日時、更新日時 |
| 担当、期限日 | 手直し項目がある場合、その項目から |
| 説明 | マークアップの文字またはスタンプの文言、計測値、コメント、シートとファイル |
| コメント | 返信ごとに1件。作成者と日付付き |
| スナップショット | シート上の該当部分のマークアップの画像 |
| ビューポイント | シート上でマークアップがある位置の真上からの表示 |

同じマークアップを再度書き出すと、同じトピックIDになります。そのため、BCFを読み込むツールは、それを同じ課題として認識できます。

## 読み込み時に戻ってくる内容

{{ui:BCFを読み込む}} は、BCF 2.0、2.1、3.0 のファイルを読み込みます（公式の buildingSMART 3.0 テストファイル19件で確認済みです。すべてのトピックを読み込め、テキストのあるコメントが3件ありました）。自分のトピック（同じトピックID）の場合は、新しいコメントを返信として追加し、新しいステータスを反映します。それ以外のトピックは、ラベルまたはファイル名が示すシートの注記になります。シートが特定できない場合は、開いているシートの注記になります。注記のテキストにはタイトル、説明、担当者、期限日が使われ、そのコメントは返信になります。

| BCFトピックの項目 | MarkupCraft での扱い |
|---|---|
| タイトル、説明、担当者、期限日 | 注記のテキスト |
| テキストのあるコメント | 返信 |
| ステータス（Open、Accepted、Rejected、Completed。Closed、Resolved、Done は Completed として扱う） | マークアップのステータス |
| 作成者と作成日 | 注記の作成者と日付 |
| カメラ位置 | ラベルまたはファイル名でシートに関連付けられたトピックに限り、シート上の位置 |
| モデルの選択、非表示の部分、クリッピング平面、スナップショット | 保持されません。シートにはモデルがないため、表示できません |

## 知っておくべき制限

- **シートはモデルではありません。** ビューポイントが示すのは、紙面上のマークアップの位置で、紙面上のメートル(m)で測ります。BIMツールをモデル内の場所まで移動させるものではありません。スナップショットとシート名を使って場所を探してください。
- **ステータスと種類は MarkupCraft 独自のものです。** （未対応、承認、却下、完了。雲マーク、コールアウトなど）。BCFで許可されているとおり、ファイルにはこれらが記載されますが、独自の固定リストを持つツールでは、対応付けられるか、無視される場合があります。
- **読み込みで得られるのはモデルのビューではなくコメントです。** {{ui:BCFを読み込む}} は、書き出したマークアップに返信とステータスを追加し、ほかの課題は注記として作成します。モデルのカメラ位置を表示することはできません。詳しくは [マークアップ一覧と書き出し](topic:markups-list-and-export#import-bcf) を参照してください。
- 図面のレビューには、マークアップをPDFで返す方が簡単な場合がよくあります。BCFは、図面へのコメントをモデル調整の作業に取り込むためのものです。
