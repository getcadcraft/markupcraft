MarkupCraft 0.6 と比べて 0.7 で変わった点です。大きな新機能は現場記録です。RFI、提出書類、日報を、マークアップと並べてPDF内に保存します。

## 新機能

### RFI、提出書類、日報

- **現場タブ。** {{ui:現場}} タブを開き、{{ui:RFI}}、{{ui:提出書類}}、{{ui:日報}} のいずれかを選びます。RFIや提出書類を置くべきシートをタップまたはクリックすると、ピンがその場所を示します。日報は、ピンなしで開いているシートに置かれます（{{ui:ピンを配置}} で後から追加し、{{ui:ピンを移動}} で任意のピンを動かせます）。各記録には固有の番号（RFI-0001、SUB-0001、LOG-0001）、タイトル、本文、状態、担当者、期限日、返信スレッド、添付ファイル名の一覧があります。[現場記録を追跡する](topic:field-records) を参照してください。
- **遅れているものを確認。** 一覧を、種類、状態、期限日（期限超過、7日以内に期限、期限日あり／なし）、このシートまたは全シート、テキスト検索、{{ui:自分が担当}} で絞り込めます。期限日を過ぎてもまだ待機中の記録は、一覧とそのピンの上で、赤い**期限超過**として表示されます。[重要なものを見つける](topic:field-records#find-what-matters) を参照してください。
- **CSVとBCF。** {{ui:CSV}} は一覧の記録を表計算ファイルとして書き出し、{{ui:BCF}} は各記録をシート上の位置のスナップショット付きのBCFトピックとして書き出します。どちらも絞り込みに従います。[書き出し](topic:field-records#export) を参照してください。
- **オフラインと、2つのコピーを1つに。** 記録はPDF内に保存され、ネットワークを必要としないため、現場のタブレットで記録の追加、回答、保存ができます。事務所に戻ったら、{{ui:マージ}} で同じPDFの別のコピーの記録を、IDで結合できます。結合は1回の元に戻す操作になります。[保存、オフライン、コピーの統合](topic:field-records#save-offline-and-merging-copies) を参照してください。

### AIアシスタント

- **アシスタントにできることが増えました。** CadCraft Studio経由で接続した自分のアシスタントは、マークアップの状態を設定し（`markup_status`、そのスレッドに記録されます）、スレッドに返信し（`markup_reply`）、{{ui:マークアップ}} の一覧をCSVまたはBCFで書き出せます（`markups_export`、フィルターで表示中の内容）。各変更は1回の元に戻す操作で、アシスタントの名前が付きます。[アシスタントに依頼できること](topic:use-with-ai-assistants#what-an-assistant-can-ask-for) を参照してください。

## すべてのアプリで

- **単位。** {{ui:設定}} › {{ui:全般}} › {{ui:単位}} には、長さ、面積、体積、角度、勾配のそれぞれに一覧があり、単位の定義どおりの正確なサイズが並びます（米国測量フィートは独自の単位です）。使わない単位はオフにすると単位一覧から消え、星印を付けると新しい作業はその単位で始まります。ファイルは常に、そのファイル自身の単位を保持します。MarkupCraftでは、{{ui:設定}} › {{ui:MarkupCraft}} の計測と位置の単位、および校正ダイアログの単位がこのスイッチに従います。星印は、MarkupCraft自身の設定を保存するまで計測の単位を決めます。校正時に入力する実距離には、`3 yd` や `1.5 km` のように、任意の単位記号を付けられます。[単位、入力値、単位一覧](common:unit-lists) を参照してください。
- **密度の高いレイアウトと、片付くパネル。** {{ui:設定}} › {{ui:全般}} › {{ui:レイアウトの密度}} › {{ui:コンパクト}} で、画面により多くのものが収まります（タッチ画面とスマートフォンでは大きなボタンのままです）。各サイドパネルには細いタイトルバーがあります。ドラッグしてパネルをドッキングまたはフローティングにし、別のパネルのバーにドロップすると1つの枠をタブで共有し、ピン留めして端へ滑らせ、非表示にして端から呼び戻せます。[パネルを配置する](common:arrange-panels#make-the-layout-denser) を参照してください。
- **ダイアログが移動できます。** ダイアログのタイトルバーをドラッグして図面の邪魔にならない位置へ動かせます。離れた位置に戻ると、そこに戻ります。タイトルバーをダブルクリックすると、再び中央に配置されます。[ダイアログを移動する](common:arrange-panels#move-a-dialog) を参照してください。
- **AIアシスタント向けのレシピ。** 自分のアシスタントへの10の作業例（図面の整理、図面一式の印刷、図面の確認、モデルへの質問、拾い出しの集計、部品のバリエーションの試行など）を、呼び出すツールと必要な権限とともに掲載しています。各例はテストで再現されています。アプリ自体にはAIは含まれません。[AIアシスタント向けのレシピ](common:assistants-recipes) を参照してください。
- **言語。** {{ui:設定}} › {{ui:全般}} › {{ui:言語}} に **Português (Portugal)** が追加されました。これと **Português (Brasil)**、**Español (México)**、**Bahasa Indonesia** は、アプリのすべての語句が揃いましたが、ネイティブ話者による確認前の下書きです。ヘルプトピックは英語のままです。
- **CadCraft Studio** は、更新確認が失敗した理由（お使いのシステム向けのファイルがない、ネットワークがない、署名が不正など）を「完了」だけでなく示すようになりました。また、閉じた「新機能」カードは、新しいリリースが出るまで再表示されなくなりました。

## このバージョンではまだ対応していない項目

- **0.7にはコード署名がありません。** 署名と Microsoft Store パッケージは、証明書の検証がまだ完了していないため、0.8に延期されました。getcadcraft.com/download の各ファイルの横にあるSHA-256を確認してください。Windowsで SmartScreen がインストーラーを止めた場合は、{{ui:詳細情報}} を選び、次に {{ui:実行}} を選んでください。Macでは、初回に CadCraft Studio を右クリックして {{ui:開く}} を選んでください。CadCraft Studio はまだアプリストアにはなく、iPad や iPhone 向けのビルドもまだありません。
- {{ui:単位}} の角度と勾配の一覧は保存されますが、それを読み取るものはまだありません。
- 現場記録は、CadCraft Studio のライブセッションでは共有されません（ライブセッションはマークアップのみを扱います）。{{ui:マージ}} を使って、コピーをまとめてください。
- マージでは、最後に変更されたコピーの記録が丸ごと採用されます。2人が同じ記録の別々の欄を変更していた場合は、後のコピーの欄が優先されます。返信と添付ファイル名は結合されます。
- 添付はファイル名のみで、ファイル自体は元の場所に残ります。記録用のチーム、通知、クラウドプロジェクトはなく、アシスタントにはまだ記録用のツールがありません。
- 現場記録は、ネットワークを切断した状態でスマートフォンとタブレットのサイズのブラウザーでテストしましたが、実機のタブレットではまだ手動で確認していません。
- 0.6から引き続き未対応: ページ上のオブジェクトを任意の角度に回すこと、新しい図形をページに直接描くこと、線のフォントやサイズを変えること、複数行にまたがるテキスト。ページを編集した保存コピーは、まだAcrobatで開いて確認していません。
- 0.5から引き続き未対応: ページの変更（空白ページの追加など）の元に戻すこと、スキャンされたシートからの文字の読み取り、お使いのネットワーク外でのライブセッション。

その他の項目は[まだ作成されていない項目](topic:not-built-yet)にあります。
