Bluebeam Revu（または別のデスクトップ PDF プログラム）で図面をレビューしたり PDF にコメントを付けたりしている場合、MarkupCraft のほとんどは使い慣れた感じになるでしょう。雲マーク、コールアウト、ツールチェスト、マークアップ一覧、返信付きのステータス、校正済みの計測、シートのオーバーレイなどがあります。大きな違いはファイルの扱い方なので、ほかを読み飛ばす場合でも、次のセクションは読んでください。

## 重要な 5 つの違い

1. **保存すると新しいファイルが作られます。** MarkupCraft はブラウザーで動作し、ディスク上の PDF を上書きすることはできません。{{ui:Save}} は「<name> (marked up).pdf」をダウンロードし、元の PDF はそのまま残ります。次回は「(marked up)」のコピーを開き、古いコピーは自分で整理してください。
2. **PDF は保存したときに保存されます。** それまでは、このブラウザー内の復元用コピーが、クラッシュやタブを閉じた場合にもマークアップを保持し、次回に復元を提案します。これは安全策です。レビューを残すには PDF を保存してください。
3. **プロファイルはブラウザーに保存されます。** 作成者名、ツールの設定、ツールチェストは、このコンピューターのこのブラウザーに保存されます。別のブラウザーまたはコンピューターでは最初からになり、サイトデータを消去すると削除されます。ツールチェストは書き出してバックアップしてください。[このブラウザーに保存される内容](topic:browser-storage) を参照してください。
4. **共有セッションはまだありません。** ライブの共有レビューセッションやクラウドプロジェクトはありません。レビューは PDF とともに移動します。保存し、コピーを送り、次の人が返信して保存します。
5. **縮尺はシートごとであり、シート単位の設定のみです。** シート内のビューポートや、「この縮尺をすべてのページに適用」はありません。計測するシートごとに校正してください。

## 慣れた操作と対応

| 慣れている操作 | MarkupCraft での操作 |
|---|---|
| サムネイルパネル、ページラベル | 左側の {{ui:Sheets}}。名前はページラベルから取得されるか、表題欄から読み取られます。修正は {{ui:Rename sheet}} で行います。 |
| 複数の PDF をセットとして開く | まとめて開きます。1 つの一覧になります。セットファイルは保存されません。次回は同じ PDF を開いてください。 |
| ツールセットを持つツールチェスト | {{ui:Tools}} タブ: ブラウザーごとに 1 つのチェスト。スタイルと件名付きで保存されたツール。{{ui:Export}} と {{ui:Import}} で JSON ファイルとして共有します。他のプログラムのツールセットファイルは読み込めません。 |
| プロパティパネル | {{ui:Properties}} タブ: ステータス、件名、コメント、スタイル、返信、手直し項目を 1 か所にまとめて表示します。 |
| 列を持つマークアップ一覧 | フィルター（シート、作成者、ステータス、種類）付きの {{ui:Markups}} タブ。CSV または BCF で書き出せます。カスタム列や、PDF またはワークブックの概要はまだありません。 |
| ステータスとレビュー状態 | {{ui:Status}}: オープン、承認、却下、完了。独自のステータスセットはありません。標準のレビュー状態として保存されます。 |
| マークアップへの返信 | {{ui:Properties}} の「返信」スレッド。ステータスの変更がそこに記録されます。送信済みの返信は編集できません。 |
| 校正してから長さ、面積、個数 | {{ui:Calibrate}}、{{ui:Length}}（{{key:M}}）、{{ui:Area}}（{{key:Q}}、面積と周長を表示）、{{ui:Count}}（{{key:U}}）。角度、半径、体積、ポリラインの長さ、切り抜きは、まだありません。 |
| ページのオーバーレイ | {{ui:Compare}} タブ: 古い版は赤、新しい版は青。2 点で位置合わせ。「文書の比較」による自動的な雲マークはありません。 |
| スタンプ | {{ui:Stamp}}: 組み込みのスタンプが 6 種類とカスタム文言があり、作成者名と日付で署名されます。画像や署名のスタンプはまだありません。 |
| 手直しまたは課題の追跡 | {{ui:Punch list}} タブ: 担当者、期限、ステータス付きの番号付き項目。CSV で書き出せます。 |
| ライブの共同作業セッション | まだ利用できません。保存した PDF を回覧してください。 |
| 描き込み（Flatten） | まだ作成されていません。マークアップは、他のビューアーで表示・印刷できるコメントとして残ります。 |
| マークアップのレイヤー | まだ作成されていません。件名、作成者、一覧のフィルターを使ってコメントを分類してください。 |
| シート間のハイパーリンク | まだ作成されていません。 |
| スペースキーでパン、ホイールでズーム | 同じです。{{key:Space}} キーを押しながらドラッグし、ホイールでポインター位置を拡大します。ホイールでページがスクロールすることはありません。 |

## 違いのあるキー

1 文字キーの多くは想定どおりですが、指が先に動く前に次を確認してください:

- {{key:K}} は {{ui:Callout}}、{{key:Q}} は {{ui:Area}} です。コールアウトに Q を使い慣れている場合、ここでは面積の計測が始まります。
- {{key:C}} は四角い {{ui:Cloud}}、{{key:Shift+C}} は {{ui:Free cloud}} です。
- {{key:M}} は {{ui:Length}}、{{key:U}} は {{ui:Count}}、{{key:Y}} は {{ui:Polyline}}、{{key:G}} は {{ui:Polygon}}、{{key:I}} は {{ui:Highlight}} です。
- {{key:Mod+D}} は選択範囲を複製します（ブラウザーのブックマークではありません）。
- {{key:Mod+Plus}} と {{key:Mod+Minus}} はシートを拡大・縮小し、ブラウザーのページは拡大縮小しません。
- どのキーも変更できます。下記を参照してください。

:::tip
Bluebeam Revu に慣れている場合は、{{ui:Settings}} › {{ui:MarkupCraft}} › {{ui:Menus, keys and mouse}} で {{ui:PDF review}} のメニュースタイルを選んでください。メニューバー（ファイル、編集、表示、文書、マークアップ、計測、ウィンドウ）と、レビューツールの一覧が表示されます。{{key:Q}} で雲マーク付きコールアウト、{{key:H}} でハイライター、{{key:N}} でポリゴン、{{key:Alt+Shift}} と文字キーで計測を使えます。どのキーも変更できます。[メニュー、キー、マウス](topic:menus-keys-and-mouse) を参照してください。
:::

すべてのキーは [キーボードとマウス](topic:keyboard) にまとめられています。

## 想定と異なる動作

- **ツールはオンのままです。** 雲マークを描いた後も、引き続き雲マークを描きます。{{key:Esc}} を 1 回押すと選択が解除され、2 回押すと {{ui:Select}} に戻ります。
- **テキストとコールアウトには文字が必要です。** 何も入力せずに完了すると、マークアップは追加されません。注記は空のまま残ります。
- **計測には先に縮尺が必要です。** 未校正のシートで {{ui:Length}} や {{ui:Area}} を選ぶと {{ui:Calibrate}} に切り替わり、その後、元の操作に戻ります。
- **他のプログラムからのコメント。** 他のプログラムで作られた長方形、楕円、線、ポリライン、ポリゴン、インク、テキストボックス、付箋は、編集可能な MarkupCraft のマークアップになり、保存時に MarkupCraft の方法で書き直されます（見た目が多少変わることがあります）。テキストハイライト、他のプログラムのスタンプ、その他の特殊な種類は読み取り専用のままです。返信はできますが、変更はできません。
- **西ヨーロッパの文字以外の文字は**、保存した PDF では「?」として印刷されます。[マークアップ済み PDF の保存](topic:save-the-marked-up-pdf) を参照してください。
- **スタンプの日付は UTC を使用します。** そのため、アメリカ大陸の夜遅くに作成されたスタンプが、翌日の日付で表示されることがあります。
- **計測値は標準の計測コメントとして引き継がれます。** 校正済みの各シートは縮尺を保持するため、PDF の計測値を扱えるプログラムで通常は表示できます。正確な動作はそのプログラムによります。

## 両方を併用する

行き来できます。他のプログラムで作られたコメントは MarkupCraft で開き、「(marked up)」の PDF は、すべてのマークアップ、返信、ステータスが表示された状態で他の PDF プログラムで開けます。MarkupCraft だけが読み戻せる情報（手直しの担当者と期限、項目のステータス）は、MarkupCraft 用にファイル内に保持されます。
