## Ինչ կսովորեք

Ինչպես թույլ տալ AI օգնականին (կամ ձեր գրած սկրիպտին) աշխատել MarkupCraft-ի հետ, և ինչպես որոշել, ինչին կարող է դիպչել։

MarkupCraft-ն **չունի սեփական AI** և ոչինչ ոչ մի տեղ չի ուղարկում։ Օգնականը դուք եք բերում. ցանկացած ծրագիր, որն աջակցում է Model Context Protocol (MCP)-ին։ MarkupCraft-ը միայն տրամադրում է նրան գործիքներ, իսկ ընտրում եք դուք, թե որոնք։

## Միացնել

1. Բացեք {{ui:Settings}} (հավելվածի գոտու անիվակը, կամ {{key:Mod+,}}) և անցեք {{ui:MarkupCraft}} ներդիրին։
2. {{ui:Assistants}} բաժնում նշեք **Թույլ տալ AI օգնականներին և սկրիպտներին օգտագործել MarkupCraft-ը**։ Այն անջատված է, մինչև դա չանեք։
3. Ընտրեք, թե ինչ կարող է անել. **Read**-ը սկզբում նշված է. նշեք **Edit**, **Save** կամ **Export** միայն երբ դրանք պետք են։

Նշած թույլտվություններից դուրս գտնվող գործիքները օգնականին չեն առաջարկվում, և եթե այն այնուամենայնիվ խնդրի, MarkupCraft-ը մերժում է և գրանցում գործունեության մատյանում։ Անջատիչը անջատելը միանգամից ավարտում է բոլոր կապերը. {{ui:Reset MarkupCraft settings}}-ը նույնպես անջատում է այն։

## Միացնել ձեր օգնականին

Օգնականները միանում են ձեր համակարգչի **CadCraft Studio**-ով. Studio-ն աշխատեցնում է փոքր սերվեր, որին հասանելի է միայն այս համակարգիչը, և որը պաշտպանված է յուրաքանչյուր մեկնարկի ժամանակ ստեղծված թոքենով։ Studio-ում ընտրեք {{ui:Connect an assistant}} և պատճենեք հասցեն ու թոքենը ձեր օգնականի մեջ (Studio-ն ցույց է տալիս տեղադրվող ճշգրիտ կարգավորումները)։ Երբեք մի կիսվեք թոքենով։

:::note
Դիտարկիչի ներդիրը չի կարող օգնականի համար կապ բացել. դիտարկիչի հավելվածներում անջատիչը ազդեցություն չունի, մինչև չօգտագործեք CadCraft Studio-ն ձեր համակարգչում։
:::

## Դուք մնում եք վերահսկողության մեջ

- **Յուրաքանչյուր փոփոխությունը մեկ հետարկման քայլ է**, պիտակավորված օգնականի անունով (օրինակ՝ «Assistant: add cloudrect»)։ {{key:Mod+Z}}-ը հետ է վերցնում օգնականի վերջին փոփոխությունը ամբողջությամբ։
- **Դուք գիտեք, երբ այն միացված է։** Հավելվածի գոտու կոճակը ցույց է տալիս օգնականի անունը, երբ այն միացված է. սեղմեք այն, որպեսզի տեսնեք, թե ինչ կարող է անել, կամ **Անջատել**-ով անջատեք այն։
- **Գործունեություն.** {{ui:Settings}} › {{ui:MarkupCraft}} › {{ui:Assistants}} › {{ui:Activity}}-ը ցուցակում է յուրաքանչյուր կանչ. երբ, ո՞ր գործիքը, կատարվել է թե մերժվել։ {{ui:Save the log}} պահում է մատյանի պատճենը։

## Ինչ կարող է խնդրել օգնականը

| Գործիք | Թույլտվություն | Ինչ է անում |
|---|---|---|
| `app_info`, `sheets_list` | Read | Բաց հավաքածուները, դրանց թերթերը և յուրաքանչյուրում նշումների քանակը |
| `markups_list` | Read | Նշումները՝ տեսակով, թերթով, տեքստով, մեկնաբանությամբ, չափումով, կարգավիճակով, հեղինակով և պատասխաններով, ֆիլտրված թերթով, կարգավիճակով, տեսակով կամ հեղինակով |
| `markup_add` | Edit | Թերթին ավելացնում է ուղղանկյուն, ամպ, էլիպս, տեքստային տուփ, գրառում, գիծ կամ սլաք |
| `markup_status`, `markup_reply` | Edit | Սահմանում է նշման կարգավիճակը (գրանցվում է իր շարքում, ստորագրված օգնականի կողմից). ավելացնում է մեկնաբանություն շարքին |
| `markups_export` | Export | {{ui:Markups}} ցանկի սեփական CSV կամ BCF՝ ցանկի ցուցադրածի համար (ֆիլտրերով, ինչպես դուք եք սահմանել). Studio-ում այն կարող է ֆայլը գրել ձեր թույլատրած թղթապանակում |
| `tasks_list` | Read | Նշումները, որոնք առաջադրանքներ են. կատարող (անձ կամ օգնական), վերջնաժամկետ, վիճակ, հղում, ինչպես է փակվել։ `assignee: "assistant"`-ը ցուցակում է օգնականի սպասող աշխատանքը |
| `task_set`, `task_clear` | Edit | Նշումը դարձնում է առաջադրանք կամ փոխում այն (վերնագիր, կատարող, վերջնաժամկետ, վիճակ, հղում). հանում է առաջադրանքը |
| `tasks_check` | Edit | Փակում է առաջադրանքները, որոնց կապված գծագրի տարածքը կամ մոդելի տարրը իրականում փոխվել է. փոխանցում է տարրերի վիճակները, որոնք կարդացել եք մյուս ծրագրից |
| `revisions_changes` | Read | Երկու բաց հատակագծային հավաքածուների միջև փոխված բաների պարզ ցանկ, որ ձեր բառերով ներկայացնեք |
| `pins_list`, `decision_add` | Read, Edit | Ձայնային գրառումներ (տևողություն, ով, երբ, ենթագիր. երբեք ձայնը, առանց տեքստի) և որոշումներ. ամրացնում է որոշումը և փոխարինում նախորդը |
| `redline_export`, `redline_answer` | Export, Edit | Գրում է redline ֆայլը նախագծողի համար. կիրառում է նախագծողի պատասխանները |

Օգնականի ավելացրած նշումը որպես հեղինակ նշում է այն անունը, որը օգնականի ծրագիրը տալիս է իրեն, որին հաջորդում է «(assistant)», կամ «(assistant for <your name>)», երբ սահմանել եք վերանայողի անունը։ Նրա կարգավիճակի փոփոխություններն ու պատասխանները նույն կերպ են ստորագրվում։ Յուրաքանչյուրը մեկ հետարկման քայլ է։ Նշված PDF-ի պահելը մնում է ձեզ. օգտագործեք {{ui:Save}}-ը սովորականի պես։

MarkupCraft-ը չբացելով՝ CadCraft MCP սերվերը ցուցակում է PDF-ի նշումները ձեր նշած թղթապանակում (`markups_list`), իսկ `cadcraft info Set.pdf`-ը տպում է դրանք հրամանի տողում։

## Եթե ինչ-որ բան չի աշխատում

- **Օգնականը MarkupCraft գործիքներ չի տեսնում.** ստուգեք, որ անջատիչը միացված է այս պատուհանում, և որ պատուհանը բաց է Studio-ում։
- **«Պահանջում է խմբագրման թույլտվություն»․** նշեք **Edit**-ը {{ui:Assistants}} բաժնում, ապա կրկին հարցրեք։
- **«401» կամ «token» սխալներ.** թոքենը փոխվել է (Studio-ն վերամեկնարկվել է, կամ {{ui:New token}})։ Պատճենեք նորը օգնականի կարգավորումներում։
