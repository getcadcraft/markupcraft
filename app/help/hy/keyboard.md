{{key:Mod}}-ով դյուրանցումները աշխատում են և ⌘-ով, և Control-ով Mac-ում, իսկ Windows-ում և Linux-ում՝ Ctrl-ով։ Գործիքների տառերը աշխատում են միայն այն ժամանակ, երբ չեք գրում որևէ վանդակում. գրելու ընթացքում տառերը պարզապես տառեր են։ Տե՛ս նաև [Ստեղներ, մկնիկներ և թրեքփեդներ](common:keys)։

## Նկարելու ընթացքում

| Ստեղն կամ գործողություն | Ինչ է անում |
|---|---|
| {{key:Shift}} նկարելիս | Գծերը, սլաքները, երկարությունները և բազմագծի կողմերը՝ 45° քայլերով. ուղղանկյունները, էլիպսները և վանդակային ամպերը՝ քառակուսի. գրիչը և նշագրիչը՝ մեկ ուղիղ գիծ |
| Կրկնակի սեղմում, {{key:Enter}} կամ աջ սեղմում | Ավարտել բազմագիծը, բազմանկյունը, ազատ ամպը կամ մակերեսը |
| {{key:Backspace}} | Հեռացնել բազմագծի, բազմանկյան, ազատ ամպի կամ մակերեսի վերջին կետը |
| {{key:Esc}} | Չեղարկել նկարվողը. եթե ոչինչ չի ընթանում, մաքրել ընտրությունը. եթե ոչինչ ընտրված չէ, վերադառնալ {{ui:Select}}-ին |
| {{key:Mod+Enter}} | Ավարտել տեքստի վանդակում, նշիչում կամ գրառումում գրելը (կամ սեղմել դրանից դուրս) |
| {{key:Esc}} գրելու ընթացքում | Չեղարկել գրվող տեքստը |
| {{key:Shift}}-ով սեղմում {{ui:Count}}-ով | Հեռացնել ընտրված հաշվարկի խմբի ամենամոտ կետը |

## Ընտրում և խմբագրում

| Ստեղն կամ գործողություն | Ինչ է անում |
|---|---|
| Սեղմում | Ընտրել նշում |
| {{key:Shift}}-ով սեղմում | Ավելացնել կամ հանել նշումը ընտրությունից |
| Քաշել ձախից աջ դատարկ թերթի վրա | Ընտրել այն, ինչ ամբողջությամբ գտնվում է պատուհանում |
| Քաշել աջից ձախ դատարկ թերթի վրա | Ընտրել այն, ինչին դիպչում է պատուհանը |
| {{key:Mod+A}} | Ընտրել այս թերթի բոլոր նշումները |
| Քաշել ընտրված նշումը | Տեղափոխել այն ({{key:Shift}}՝ 45° քայլերով) |
| Քաշել բռնակը | Փոխել չափը կամ ձևը ({{key:Shift}}՝ պահպանել համամասնությունը կամ 45°) |
| Սլաքների ստեղներ | Տեղաշարժել ընտրությունը մեկ էկրանային պիքսելով ({{key:Shift}}՝ տասը) |
| Կրկնակի սեղմում կամ {{key:Enter}} | Խմբագրել տեքստի վանդակի, նշիչի կամ գրառման տեքստը. կնիքի դեպքում՝ բացել {{ui:Properties}} |
| {{key:Delete}} կամ {{key:Backspace}} | Ջնջել ընտրությունը |
| {{key:Esc}} | Ընտրություն չանել |
| {{key:Mod+Z}} | {{ui:Undo}} |
| {{key:Mod+Y}} կամ {{key:Mod+Shift+Z}} | Կրկնել |

## Կտրել, պատճենել և տեղադրել

Նույն հրամանները կան գործիքագոտու {{ui:Edit}} խմբում ({{ui:Copy}}, {{ui:Paste}}) և դրա {{ui:More}} մենյուում՝ յուրաքանչյուրը իր ստեղնով։ Յուրաքանչյուրը մեկ հետարկման քայլ է։ Տե՛ս [Պատճենել, տեղադրել և կրկնօրինակել](topic:select-and-edit#copy-paste-and-duplicate)։

| Ստեղն | Ինչ է անում |
|---|---|
| {{key:Mod+X}} | Կտրել. պատճենել ընտրությունը և ջնջել այն |
| {{key:Mod+C}} | Պատճենել ընտրությունը |
| {{key:Mod+V}} | Տեղադրել։ Երբ ցուցիչը թերթի վրա է, պատճենը տեղադրվում է այնտեղ, ուր նշում է. հակառակ դեպքում՝ բնօրինակի կողքին։ Կարգավորումներով կարելի է դարձնել, որ միշտ տեղադրվի բնօրինակի կողքին։ |
| {{key:Mod+Shift+V}} | Տեղադրել նույն տեղում. թերթի նույն կետում, այս կամ մեկ այլ թերթում |
| {{key:Mod+D}} | Կրկնօրինակել ընտրությունը դրա կողքին (սեղմատախտակը չի փոխվում) |

## Մասշտաբ և տեղաշարժ

| Ստեղն կամ գործողություն | Ինչ է անում |
|---|---|
| Մկնիկի անիվ | Մեծացնել կամ փոքրացնել ցուցիչի շուրջ (անիվը երբեք չի ոլորում) |
| {{key:Ctrl}} + անիվ | Արագ մասշտաբավորում |
| {{key:Plus}} կամ {{key:Minus}} (նաև {{key:Mod}}-ով) | Մեծացնել կամ փոքրացնել կենտրոնի շուրջ. {{key:=}}-ը աշխատում է որպես plus |
| {{key:Mod+0}} | {{ui:Fit page}} |
| {{key:Mod+9}} | {{ui:Fit width}} |
| Քաշել միջին կոճակով | Տեղաշարժ |
| Քաշել աջ կոճակով | Տեղաշարժ (երբ բազմագծի մեջտեղում չեք) |
| Պահել {{key:Space}}-ը և քաշել | Տեղաշարժ |
| Սլաքների ստեղներ, երբ ոչինչ ընտրված չէ | Տեղաշարժ |
| {{key:Ctrl+Shift+F}} | Էկրանի ռեժիմ՝ սովորական, լրիվ էկրան, լրիվ էկրան՝ թաքցված գոտիներով (Control ստեղնը բոլոր համակարգիչներում) |

:::mac
**Թրեքփեդի վրա.** երկու մատով ոլորումը մասշտաբավորում է։ Քաշեք մատները՝ մեծացնելու համար. Chrome-ում, Edge-ում և Firefox-ում նույնպես։ Տեղաշարժեք {{key:Space}}-ը պահած քաշելով կամ {{ui:Pan}} գործիքով։ Երկու մատով սեղմումը աջ սեղմում է և ավարտում բազմագիծը։ Այստեղ Control-սեղմումը կարող է աշխատել որպես պարզ սեղմում, ոչ թե աջ սեղմում, ուստի օգտագործեք երկու մատով սեղմում։
:::

## Հպում

| Ժեստ | Ինչ է անում |
|---|---|
| Մեկ մատ | Նկարել ընթացիկ գործիքով կամ ընտրել |
| Երկու մատ | Մատների սեղմումը մասշտաբավորում է մատների մեջտեղի շուրջ, շարժումը՝ տեղաշարժում |
| Երկրորդ մատը գծի ընթացքում | Չեղարկում է գիծը և փոխարենը մասշտաբավորում |
| Կրկնակի հպում | Ավարտել բազմագիծը, բազմանկյունը, ազատ ամպը կամ մակերեսը |

Հաշվարկի կետերը, գրառումները, բազմագծի կետերը և երկու կետով գործիքի երկրորդ կետը տեղադրվում են, երբ մատը բարձրանում է։ Տե՛ս [Վերանայում iPad-ի կամ հպաէկրանի վրա](topic:review-on-a-tablet)։
:::

## Դյուրանցումներ, որոնք պահում է դիտարկիչը

- {{key:Mod+W}}, {{key:Mod+T}}, {{key:Mod+N}} և {{key:Mod+Q}}-ն պատկանում են դիտարկիչին։ Չպահված նշումներով ներդիրը կամ պատուհանը փակելը կկորցնի դրանք՝ համակարգչում դիտարկիչի «Լքե՞լ կայքը» հարցից հետո։
- Շատ դիտարկիչներ {{key:Mod+N}}-ը պահում են նոր պատուհանի համար, ուստի դիտարկիչի ներդիրում օգտագործեք գործիքագոտու {{ui:New}}-ը. աշխատասեղանի հավելվածը և Studio-ն ստեղնը փոխանցում են MarkupCraft-ին։
- MarkupCraft-ը {{key:Mod+O}}, {{key:Mod+S}}, {{key:Mod+D}}, {{key:Mod+A}}, {{key:Mod+V}}, {{key:Mod+Shift+V}}, {{key:Mod+0}}, {{key:Mod+Plus}} և {{key:Mod+Minus}}-ը վերցնում է դիտարկիչից, երբ հավելվածը ունի ստեղնաշարը, իսկ {{key:Mod+C}}-ն ու {{key:Mod+X}}-ը՝ երբ նշումներն ընտրված են։ {{key:Mod+,}}-ը բացում է {{ui:Settings}}-ը։ Ամբողջ դիտարկիչի էջը մասշտաբավորելու համար օգտագործեք դիտարկիչի մենյուն։
- {{key:Mod+9}}-ը որոշ դիտարկիչներում նախ թռչում է վերջին ներդիր, մինչև MarkupCraft-ը այն կտեսնի։ Եթե դա տեղի ունենա, օգտագործեք թերթի տակ գտնվող {{ui:Fit width}}-ը։
- Լրիվ էկրանում {{key:Esc}}-ը նաև դուրս է բերում լրիվ էկրանից։

## Երբ ստեղնը ոչինչ չի անում

- **Գրում եք վանդակում։** Նախ սեղմեք թերթի վրա։ (Նկարող գործիքով սեղմելը նկարում է. հետո սեղմեք {{key:Esc}} կամ օգտագործեք {{key:Mod+Z}}։)
- **Երկխոսության վանդակ է բաց։** Ստեղները անցնում են երկխոսությանը, մինչև այն փակվի։
- **Նոր սեղմել եք գործիքագոտու կոճակ**, և սլաքների ստեղները կամ {{key:Space}}-ը ազդում են այդ կոճակի վրա։ Տեղափոխեք ցուցիչը թերթի վրա և օգտագործեք անիվը կամ միջին կոճակը, կամ սեղմեք գործիքի տառը՝ կոճակներ սեղմելու փոխարեն։

## Որտեղ է Move-ը

Move հրաման չկա. ընտրեք նշումը և քաշեք այն ({{key:Shift}}-ը պահում է 45° քայլերը)։ Նշիչը տեղափոխվում է {{ui:Move pin}}-ով, իսկ էջը՝ {{ui:Move page earlier}}-ով կամ {{ui:Move page later}}-ով։
