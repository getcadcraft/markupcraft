Uma kufika ukushicilelwa okusha kwemidwebo, ukufaka-ishidi kuhambisa ukubuyekeza kwakho kuso: ishidi ngalinye elisha lithatha amamaka eshidi lakudala elinenombolo efanayo, futhi ishidi lakudala lishiywa ngesitembu esithi "Esesikiwe".

## Faka ishidi

1. Vula isethi yamanje, namamaka akho.
2. Khetha {{ui:Amakhasi}}, bese {{ui:Faka isethi eshintshiwe…}}, bese ukhetha ama-PDF amasha. Avula eduze kwesethi endala.
3. Ibhokisi lidweba ishidi ngalinye elisha nelishidi lakudala elilishintshayo. Susa ukukhetha komugqa ukuze ushiye amamaka eshidi leyo lapho ekhona. Amashidi anenombolo entsha awanalutho lokuthwala.
4. Khetha ukuthi ufuna yini ukushiya amazwana avaliwe (Yamukelwe, Yenqatshiwe, Iqediwe) emashidini akudala, nokuthi ufuna yini ukufaka isitembu emashidini akudala.
5. Khetha {{ui:Thwala amamaka phambili}}.

Umphumela: amamaka avela emashidini amasha endaweni efanayo, nezimpendulo, izimo nabambhali bawo. Into yesijeziso ihamba iye eshidini elisha ibambe inombolo yayo. Amashidi akudala agcina amamaka awo njengerekhodi, ngaphansi kwesitembu esibomvu esithi "Esesikiwe". Ibha yesimo ifingqa okuhanjisiwe.

{{ui:Vula amafayela kuphela}} ivula isethi entsha ingathwali lutho, njengokuthi uqhathanise kuqala. Bheka [Qhathanisa izinguquko ezimbili](topic:compare-revisions).

## Indlela amashidi ahlanganiswa ngayo

- **Ngenombolo yeshidi**, njengoba uhlu lwamashidi luyibonisa: inombolo oyiqamba nge-{{ui:Qamba kabusha ishidi}}, inombolo yephepha le-PDF, noma ibhulokhi yesihloko. Amacala, izikhala, amachashazi nedashi azinakubaluleka: "A-101" ihambisana ne-"a101".
- Uma amafayela amabili avuliwe enombolo efanayo yeshidi, eyamuva iyashintshwa, ukuze ukwazi ukufaka-ishidi ukushicilelwa ngakunye.
- **Amasethi askeniwe** awanamanani okufunda. Uma ifayela elisha lingenawo, amakhasi ahlanganiswa ngolandelelano lwawo namakhasi efayela elivuliwe elinenani elifanayo lamakhasi. Hlola lezo zimpawu ngaphambi kokuthwala.

## Okuwusizo

- Ukucindezela {{key:Mod+Z}} kukodwa kuhlehlisa konke ukufaka-ishidi: amakhophi, izitembu namathuluzi ahanjisiwe. Amafayela amasha ahlala evuliwe.
- Uma ishidi elisha lingosayizi ohlukile, amamaka alinganiswa ngekhasi, futhi ibha yesimo iyasho ukuthi mangaki okufanele uwahlole.
- Isikali seshidi lakudala siyahamba nalo uma ishidi elisha lifana ngosayizi futhi lingenaso.
- Amazwana enziwe ezinye izinhlelo ahlala emashidini akudala: awafundeki kuphela lapha.
- Londoloza amafayela amasha ukuze ugcine amamaka athuthiwe. Bheka [Londoloza i-PDF enokumakiwe](topic:save-the-marked-up-pdf).
