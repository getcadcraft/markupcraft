MarkupCraft isathuthukiswa. Lokhu kuchaza okungenziwa yile nguqulo yamanje **akwenzi**, ukuze ukwazi ukuhlela ngakho. Kuchaza inguqulo yamanje, hhayi izethembiso.

## Ukusebenza nabanye abantu

| Akukakhiwa | Yenza lokhu namuhla |
|---|---|
| Ukugcina ngefu nokuvumelanisa phakathi kwamakhompyutha | Gcina ama-PDF ndawonye namafayela ephrojekthi yakho. Ukugcina ngefu akukatholakali okwamanje. |
| Ukuhlanganisa amakhophi amamaki abantu ababili | Hlukanisa amashidi phakathi kwabahloli, noma kopisha amamaki ambalwa nge-{{key:Mod+C}} ne-{{key:Mod+V}}. Ama-RFI, izinikezelo namalogi ansuku ayahlanganiswa: bona [Landelela ama-RFI, izinikezelo namalogi ansuku](topic:field-records). |
| Amaqembu, izaziso namaphrojekthi efu ama-RFI nezinikezelo | Dlulisela i-PDF bese usebenzisa {{ui:Hlanganisa}} ukuze uhlanganise amakhophi. |
| Ama-RFI, izinikezelo namalogi ansuku ngesikhathi seseshini ephilayo | Umuntu ngamunye usebenza ngekhophi yakhe; hlanganisa amakhophi nge-{{ui:Hlanganisa}}. |
| Ukuhlanganisa izinguquko zabantu ababili ezingxenyeni ezahlukene zerekhodi elilodwa | Ikhophi eshintshwe ekugcineni yiyo eba yirekhodi lonke (izintambo zayo namagama amafayela ayahlanganiswa). Vumelanani ukuthi ubani ohlela yiphi irekhodi. |
| Amathuluzi wosizo wama-RFI, izinikezelo namalogi ansuku | Sebenza nawo ku-{{ui:Inkundla}}. Abasizi bangasebenza namamaki: bona [Sebenzisa MarkupCraft nomsizi we-AI](topic:use-with-ai-assistants). |
| Ukuhlela noma ukusula impendulo esesithunyelwe | Hlehlisa masinyane, noma engeza impendulo elungisayo. |
| Ukushintsha ukuthi ubani ongumniniwe wemaki | Setha igama lakho ngaphambi kokuqala. |

## Amamaki

| Akukakhiwa | Yenza lokhu namuhla |
|---|---|
| Izitembu ezinezindawo zokugcwalisa, izitembu zesignisha ezigunyaziwe ngedijithali | Sebenzisa isitembu sombhalo esingokwezifiso, esiqukethe igama lakho nosuku, noma isithombe sesignisha yakho. |
| Ukuheha amafayela angewona izithombe (amadokhumenti, amavidiyo) | Gcina alo ecaleni kwe-PDF bese uwabhekisela kuwo ekuphawuleni. |
| Izixhumanisi zamawebhusayithi noma zamafayela angavulekile | Bhala ikheli noma igama lefayela ekuphawuleni. |
| Amasethi wezimo wangokwezifiso | Sebenzisa izimo ezine, nesihloko kunoma yini engaphezulu. |
| Ukuhlela amakhomenti afika nefayela njengokufundeka kuphela (okugqamisiwe kombhalo, izitembu zezinye izinhlelo) | Phendula kuwo, noma dweba imaki ye-MarkupCraft eduze kwawo. |
| Imigqa yepeni ecindezelwa ngesandla | Setha ububanzi bomugqa. |

## Okuqukethwe kwekhasi ngokwalo

| Akukakhiwa | Yenza lokhu namuhla |
|---|---|
| Ukudweba izimo ezintsha ngqo ekhasini | Zidwebe njengamamaki, bese {{ui:Faka ekhasini}}. Bona [Shintsha okuqukethwe kwekhasi](topic:page-content). |
| Ukuzungezisa izinto zekhasi zibe yinoma iyiphi i-engeli | Zihambise futhi uzilungise ngosayizi; zungezisa ikhasi lonke nge-{{ui:Amakhasi}}. |
| Ukushintsha ifonti noma usayizi wombhalo womugqa, noma umbhalo ogeleza emigqeni eminingi | Shintsha amagama umugqa ngamunye; ukuze ubhale amagama amasha ngefonti esahlukile, engeza imaki yombhalo. |
| Ukuhlela okusemkhatheni kwesithombe esiskenisiwe | Shintsha isithombe, noma usiphawule. |
| Ukuhlela ama-PDF abethelwe noma asayinwe | Cela ikhophi engasayinwanga; amamaki asebenza kunoma yiliphi i-PDF. |

## Ukulinganisa

| Akukakhiwa | Yenza lokhu namuhla |
|---|---|
| Ukulinganisa iradiyasi | Dweba {{ui:Ijika}} eduze kwalo, noma linganisa {{ui:Ubude}} kusukela kolunye uhlangothi kuya kolunye bese uhlukanisa ngamabili. |
| Ukuhlela amakhona ezikhala zokusika | Susa izikhala zokusika bese uzidweba futhi. |
| Ukusebenzisa isikali esisodwa emashidini amaningi ngesikhathi esisodwa | Linganisa ishidi ngalinye; ukukhetha isethingi esilungiselelwe kuthatha imizuzwana embalwa ishidi ngalinye. |
| Izikali ezimbalwa ekhasini elilodwa (ama-viewport) | Linganisa ngokudweba ojwayele ukukulinganisa kakhulu. Ukushintsha isikali seshidi kuphinde kulinganise konke kuwo, ngakho bhala amanani emininingwane ngaphambi kokuphinda ulinganise. |
| Ukuncamela imigqa emdwebeni | Sondeza ngaphambi kokuchofoza, noma thayipha amabanga nama-engeli (bona [Skesha ngesikali](topic:calibrate-and-measure#sketch-to-scale)). |
| Ukubala okuphelele ngezinto, izakhiwo namanani | Sebenzisa i-TakeoffCraft, uhlelo lokubala lomndeni we-CadCraft. |

## Amashidi namafayela

| Akukakhiwa | Yenza lokhu namuhla |
|---|---|
| Ukuhlehlisa ushintsho lwekhasi (zungezisa, hambisa, faka, susa) | Vala ungagcinanga bese uvula i-PDF yakho yokuqala futhi. Bona [Phrinta nokushintsha amakhasi](topic:pages-and-printing). |
| Ukuvala ifayela elilodwa lesethi | {{ui:Vala}} uvala isethi yonke; vula kabusha amafayela odinga. |
| Ukugcina isethi njengephrojekthi ukuze uyivule ngesinyathelo esisodwa | Vula ama-PDF afanayo futhi. |
| Ukuphrinta ngesikali esikhethiwe, noma amashidi amaningi ephepheni elilodwa | Sebenzisa ingxoxo yesiphrinta sesiphequluli sakho, noma phrinta ikhophi egciniwe kusuka kwesinye isiboneli se-PDF. |
