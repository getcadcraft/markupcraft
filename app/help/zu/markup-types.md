## Konke ukumaka kuqukethe

| Inkambu | Lapho ukubona khona |
|---|---|
| Umbhali | Endaweni ethi {{ui:Properties}}, uhlu, umugqa wesibili wesitembu, ezinye izibukeli ze-PDF |
| Kudalwe nakushintshwe | Endaweni ethi {{ui:Properties}} (isikhathi sakho sendawo), uhlu, i-CSV |
| Isimo | Kuvuliwe, Kwamukelwe, Kwenqatshiwe noma Kuqedile |
| Isihloko | Ilebula emfushane; okuzenzakalelayo ngokohlobo ("Ifu", "Ibhokisi lombhalo", "Isilinganiso sobude") |
| Amazwana | Amanothi amade. Ku-inothi, umbhalo walo ungumzwana walo |
| Umbhalo | Amabhokisi ombhalo nezichazi kuphela |
| Izimpendulo | Uchungechunge, nezinguquko zesimo |
| Into yokulungisa | Inombolo, umuntu obekiwe, usuku lokuphela, isimo sento, uma yengezwa ohlwini lokulungisa |
| Isitayela | Umbala, ububanzi bomugqa, ukugcwaliswa nokukhanya kokugcwalisa (izimo ezivaliwe, umbhalo nezichazi), ukukhanya, usayizi wombhalo (umbhalo, izichazi nezilinganiso) |

## Amazwana angashintshwa

Amazwana afika nefayela futhi i-MarkupCraft engakwazi ukuwahlela (okuqaqanjiswe ngombhalo, izitembu zezinye izinhlelo nezinye izinhlobo ezikhethekile) ohlwini ngohlobo "Okunye" nethegi yesimo ethi "Kufundeka kuphela". Agcina ukubukeka okunikezwa wufayela. Ungawakhetha, ubone umbhali wawo, isihloko namazwana awo, futhi uphendule kuwo.
