Ikhophi emakiwe iyi-PDF yokuqala enezimvo (izichasiselo ze-PDF) ezengeziwe. Amakhasi ngokwawo, imidwebo yawo, umbhalo, izimpawu zamabhukumaki kanye nezixhumanisi ikopishwa njengoba zinjalo.

## Ukumaka ngakunye

| MarkupCraft | Ilondolozwa njenge | Ezinye izibukeli ze-PDF zibonisa |
|---|---|---|
| Unxande, ifu lebhokisi | Square annotation (ifu: umbedo onamafu) | Izimvo zexande noma zefu |
| Ieliphsi | Circle annotation | Izimvo zeliphsi |
| Upolygoni, ifu lokhululeko | Polygon annotation (ifu: umbedo onamafu) | Izimvo zepolygoni noma zefu |
| Iphola-layini | PolyLine annotation | Izimvo zephola-layini |
| Umugqa, umcibisholo | Line annotation (umcibisholo: ikhanda elivaliwe) | Izimvo zomugqa noma zomcibisholo |
| Ubude | Line annotation ephawulwe njengesilinganiso, nesilinganiso | Isilinganiso sobude, lapho isibukeli sisekela khona |
| Indawo | Polygon annotation ephawulwe njengendawo, nesilinganiso | Isilinganiso sendawo, lapho sisekelwa khona; kungenjalo upolygoni |
| Iqembu lokubala | Ink annotation eyodwa, indilinga ngalinye; umbhalo wayo ngu-"group: n" | Izimvo zenki |
| Ipeni, isibonisi | Ink annotation (isibonisi siphawulwe njengaso) | Izimvo zenki |
| Umbhalo | FreeText annotation | Izimvo zebhokisi lombhalo |
| Isichasiso | FreeText annotation nomugqa wesichasiso | Izimvo zesichasiso |
| Inothi | Text annotation | Inothi elincamelayo elivula libonise umbhalo waso |
| Isitembu | Stamp annotation | Izimvo zesitembu |

Yonke ilondolozwa ne:

- **ukubukeka kwayo okuqondile**, kudweba njengoba i-MarkupCraft iyidweba esikrinini, ukuze ibukeke ifana kunoma yisiphi isibukeli futhi iphrinte ifana, kuhlanganise nesibonakalisi senombolo ye-punch;
- **umbhali**, **izinsuku zokudalwa nokushintshwa**, **isihloko**, **umbhalo wezimvo** (ebhokisini lombhalo nasezichasisweni, umbhalo kanye nezimvo), **umbala** kanye **nokuqina kombala**;
- **imininingwane yayo ye-MarkupCraft** endaweni yangasese ezinye izinhlelo ziyinaki: isimo, into ye-punch, isitayela nohlobo, ukuze ivulwe futhi ngokuqondile.

## Izintambo nezimo

- Impendulo ngayinye ilondolozwa njengezimvo zempendulo exhunywe kokumakiwe kwayo, nombhali wayo, usuku nombhalo wayo. Izimpendulo azinaso isithonjana sazo ebhodini.
- Ushintsho ngalunye lwesimo lulondolozwa njengempendulo ethwala isimo sokubuyekeza. Ezinye izinsiza zokubuyekeza zibonisa njenge-Accepted, Rejected noma Completed; i-Evulekile ilondolozwa ngaphandle kwesimo.
- Okumakiwe okunesimo esingesiyo Evulekile kodwa okungenaso ushintsho olurekhodiwe lwesimo kuthola impendulo eyodwa yesimo sokubuyekeza, ukuze nezinye izinhlelo zibone isimo nazo.
- Izimpendulo ezizimvo zokufunda kuphela zefayela lokuqala zilondolozwa ngendlela efanayo, zixhunywe kuleyo mvo.

## Ishidi ngalinye

- **Isikali:** ishidi elilinganisiwe linikezwa ukubukwa kwesilinganiso okumboza ikhasi (indlela ejwayelekile yokulondoloza isikali sekhasi) nekhophi ye-MarkupCraft yokulinganisa.
- **Inombolo yeshidi:** inombolo otayipha ngayo nge-{{ui:Qamba kabusha ishidi}} iba ilebula yekhasi. Uma noma yikuphi ikhasi lefayela linayo, wonke amakhasi alelo fayela athola ilebula: inombolo otayiphile, noma ilebula yakudala, noma inombolo yekhasi.
- **Isihloko seshidi:** isihloko otayiphile silondolozelwa i-MarkupCraft kuphela; ezinye izibukeli azisibonisi.

## Umbhalo nezinhlamvu

Umbhalo ubhalwa ngefonti i-Helvetica, eyatholakala kuwo wonke amasibukeli e-PDF. Izinhlamvu ezingaphandle kwesethi yase-Western European (Windows-1252) ziphrintwa njengo-"?" ekhophini; umlayezo wokulondoloza uzibala.

## Amashidi okubala nezizathu

Amashidi okubala nezizathu agcinwa endaweni yangasese ye-PDF ebizwa ngokuthi `/MarkupCraftShell`. Ezinye izinhlelo ze-PDF ziyinaki. Ne-MarkupCraft endala iyinaki futhi iyisusa ngesikhathi ilondoloza lelo fayela ngokulandelayo.

## Okwenzeka ezimvweni ezaziseyikhona

Uma uvula i-PDF enezimvo ngaphambili:

- Izimvo ze-MarkupCraft ziyafundwa ngqo. Uma olunye uhlelo lusune noma lulinganise enye, indawo yayo entsha iyonqoba.
- Amabhokisi, amaeliphsi, imigqa, iphola-layini, upolygoni, inki, amabhokisi ombhalo namanothi azinhlelo zabanye aba okumakiwe ayahleleka. **Uma ulondoloza, i-MarkupCraft isusa okokuqala ibuye iwabhale futhi ngendlela yayo**, kanye namafasitela avelayo nezimpendulo zawo. Ukubukeka kwawo kungashintsha kancane.
- Izimo zokubuyekeza zezinye izinhlelo zibeka isimo; eyamuva yonqoba.
- Konke okunye (ukukhanyisa umbhalo, izitembu zezinye izinhlelo nezinhlobo ezikhethekile) **kugcinwa kungathintekile** ekhophini, kufundeka kuphela.
- Izixhumanisi namasimu efomu ziyagcinwa zingathintekile futhi azidwetshwa ohlwini.

Ukulondoloza ifayela elifanayo futhi akusoze kuphindaphindeke noma yini: okumakiwe i-MarkupCraft eyifundile kuyashintshwa, akungezwa futhi.

## Okungashintshiwe

Ifayela lakho lokuqala ediskini alikaze lishintshwe. Ikhophi alilungiswanga ngosayizi, ngakho ingaba nkulu kancane kunokoqobo. Ama-PDF avikelwe (abethelwe) awakwazi ukulondolozwa.
