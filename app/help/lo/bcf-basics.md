BCF (BIM Collaboration Format) ແມ່ນຮູບແບບໄຟລ໌ເປີດສຳລັບສົ່ງບັນຫາລະຫວ່າງເຄື່ອງມື BIM. ໂປຣແກຣມປະສານງານ ແລະ ອອກແບບໂມເດວຫຼາຍໂປຣແກຣມສາມາດນຳເຂົ້າໄຟລ໌ `.bcfzip` ເປັນລາຍການບັນຫາໄດ້. MarkupCraft ຂຽນ **BCF 2.1**.

## ວິທີສ້າງ

1. ເປີດແຖບ {{ui:ມາກອັບ}}.
2. ກັ່ນຕອງລາຍການໃຫ້ເປັນສິ່ງທີ່ທ່ານຕ້ອງການສົ່ງ, ຕົວຢ່າງ {{ui:ສະຖານະ}} "ເປີດ". ມີແຕ່ການໝາຍທີ່ຢູ່ໃນລາຍການເທົ່ານັ້ນທີ່ຖືກສົ່ງອອກ.
3. ເລືອກ {{ui:BCF}}.
4. ລໍຖ້າໃນຂະນະທີ່ມັນສ້າງພາບຖ່າຍຂອງແຕ່ລະການໝາຍ ("ກຳລັງສ້າງພາບຖ່າຍສຳລັບ BCF (5 ຈາກ 20)…").

ຜົນທີ່ໄດ້: "<name> markups.bcfzip" ຖືກດາວໂຫຼດ, ແລະ ແຖບສະຖານະບອກຈຳນວນຫົວຂໍ້ທີ່ມີ ແລະ ຂະໜາດໄຟລ໌.

## ມີຫຍັງຢູ່ໃນນັ້ນ

ແຕ່ລະການໝາຍກາຍເປັນ **ຫົວຂໍ້** ໜຶ່ງ:

| ຊ່ອງຂອງຫົວຂໍ້ | ຕື່ມດ້ວຍ |
|---|---|
| ຊື່ | ເລກ Punch, ຫົວຂໍ້ ແລະ ແຜ່ນ, ເຊັ່ນ "#4 ເມກໃນ A-101 — ແຜນຜັງຊັ້ນ" |
| ປະເພດ | ຊະນິດຂອງການໝາຍ (ເມກ, Callout, ຄວາມຍາວ…) |
| ສະຖານະ | ເປີດ, ຍອມຮັບ, ປະຕິເສດ ຫຼື ສຳເລັດ |
| ປ້າຍກຳກັບ | ຊະນິດຂອງການໝາຍ ແລະ ແຜ່ນ |
| ຜູ້ສ້າງ ແລະ ວັນທີ | ຜູ້ສ້າງການໝາຍ, ວັນທີສ້າງ ແລະ ວັນທີແກ້ໄຂ |
| ຜູ້ຮັບຜິດຊອບ, ກຳນົດເວລາ | ມາຈາກລາຍການ Punch ຂອງມັນ ເມື່ອມີ |
| ຄຳອະທິບາຍ | ຂໍ້ຄວາມ ຫຼື ຖ້ອຍຄຳຕາປະທັບ, ຄ່າທີ່ວັດໄດ້, ຄຳເຫັນ ແລະ ແຜ່ນ ກັບໄຟລ໌ |
| ຄຳເຫັນ | ໜຶ່ງອັນຕໍ່ການຕອບກັບ, ພ້ອມຜູ້ສ້າງ ແລະ ວັນທີ |
| ພາບຖ່າຍ | ຮູບຂອງການໝາຍໃນສ່ວນຂອງແຜ່ນ |
| ມຸມມອງ | ມຸມມອງຈາກເທິງລົງຂອງບ່ອນທີ່ການໝາຍຢູ່ໃນແຜ່ນ |

ການສົ່ງອອກການໝາຍດຽວກັນອີກຄັ້ງຈະໄດ້ ID ຫົວຂໍ້ດຽວກັນ, ດັ່ງນັ້ນເຄື່ອງມືທີ່ນຳເຂົ້າ BCF ສາມາດຈຳໄດ້ວ່າເປັນບັນຫາດຽວກັນ.

## ສິ່ງທີ່ກັບເຂົ້າມາເມື່ອນຳເຂົ້າ

{{ui:ນຳເຂົ້າ BCF}} ອ່ານໄຟລ໌ BCF 2.0, 2.1 ແລະ 3.0 (ກວດກັບໄຟລ໌ທົດສອບທາງການ buildingSMART 3.0 ຈຳນວນ 19 ໄຟລ໌: ອ່ານທຸກຫົວຂໍ້ ແລະ ຄຳເຫັນຂອງ 3 ອັນທີ່ມີຂໍ້ຄວາມ). ສຳລັບຫົວຂໍ້ທີ່ເປັນຂອງທ່ານ (ID ຫົວຂໍ້ດຽວກັນ) ມັນຈະເພີ່ມຄຳເຫັນໃໝ່ເປັນການຕອບກັບ ແລະ ໃຊ້ສະຖານະໃໝ່. ຫົວຂໍ້ອື່ນທັງໝົດຈະກາຍເປັນໝາຍເຫດຢູ່ໃນແຜ່ນທີ່ປ້າຍກຳກັບ ຫຼື ຊື່ໄຟລ໌ລະບຸ, ຖ້າບໍ່ມີກໍຢູ່ໃນແຜ່ນທີ່ເປີດຢູ່, ໂດຍມີຊື່, ຄຳອະທິບາຍ, ຜູ້ຮັບຜິດຊອບ ແລະ ກຳນົດເວລາເປັນຂໍ້ຄວາມຂອງໝາຍເຫດ ແລະ ຄຳເຫັນເປັນການຕອບກັບ.

| ໃນຫົວຂໍ້ BCF | ໃນ MarkupCraft |
|---|---|
| ຊື່, ຄຳອະທິບາຍ, ຜູ້ຮັບຜິດຊອບ, ກຳນົດເວລາ | ຂໍ້ຄວາມຂອງໝາຍເຫດ |
| ຄຳເຫັນທີ່ມີຂໍ້ຄວາມ | ການຕອບກັບ |
| ສະຖານະ Open, Accepted, Rejected, Completed (Closed, Resolved, Done ນັບເປັນ Completed) | ສະຖານະຂອງການໝາຍ |
| ຜູ້ສ້າງ ແລະ ວັນທີສ້າງ | ຜູ້ສ້າງ ແລະ ວັນທີຂອງໝາຍເຫດ |
| ຕຳແໜ່ງກ້ອງ | ຕຳແໜ່ງໃນແຜ່ນ, ສະເພາະຫົວຂໍ້ທີ່ຜູກກັບແຜ່ນດ້ວຍປ້າຍກຳກັບ ຫຼື ຊື່ໄຟລ໌ |
| ການເລືອກໂມເດວ, ພາກທີ່ຊ່ອນ, ລະນາບຕັດ, ພາບຖ່າຍ | ບໍ່ໄດ້ເກັບໄວ້: ແຜ່ນບໍ່ມີໂມເດວໃຫ້ສະແດງພວກມັນ |

## ຂໍ້ຈຳກັດທີ່ຄວນຮູ້

- **ແຜ່ນບໍ່ແມ່ນໂມເດວ.** ມຸມມອງຊີ້ໄປທີ່ຕຳແໜ່ງຂອງການໝາຍເທິງເຈ້ຍ, ວັດເປັນແມັດ (m) ຂອງເຈ້ຍ. ມັນບໍ່ສາມາດພາເຄື່ອງມື BIM ໄປຍັງຈຸດໃນໂມເດວໄດ້. ໃຊ້ພາບຖ່າຍ ແລະ ຊື່ແຜ່ນເພື່ອຊອກຫາຈຸດນັ້ນ.
- **ສະຖານະ ແລະ ປະເພດເປັນຂອງ MarkupCraft ເອງ** (ເປີດ, ຍອມຮັບ, ປະຕິເສດ, ສຳເລັດ; ເມກ, Callout…). ໄຟລ໌ປະກາດໄວ້ ຕາມທີ່ BCF ອະນຸຍາດ, ແຕ່ເຄື່ອງມືທີ່ມີລາຍການຄົງທີ່ຂອງຕົນເອງອາດຈະແມັບ ຫຼື ບໍ່ສົນໃຈພວກມັນ.
- **ການນຳເຂົ້າໄດ້ຄຳເຫັນ, ບໍ່ແມ່ນມຸມມອງໂມເດວ.** {{ui:ນຳເຂົ້າ BCF}} ເພີ່ມການຕອບກັບ ແລະ ສະຖານະໃຫ້ການໝາຍທີ່ທ່ານສົ່ງອອກ, ແລະ ສ້າງໝາຍເຫດສຳລັບບັນຫາອື່ນ; ມັນບໍ່ສາມາດສະແດງກ້ອງໂມເດວໄດ້. ເບິ່ງ [ລາຍການການໝາຍ ແລະ ການສົ່ງອອກ](topic:markups-list-and-export#import-bcf).
- ການສົ່ງການໝາຍກັບຄືນເປັນ PDF ມັກຈະງ່າຍກວ່າສຳລັບການກວດແບບ. BCF ແມ່ນສຳລັບການນຳຄຳເຫັນແບບເຂົ້າໄປໃນຂັ້ນຕອນປະສານງານໂມເດວ.
