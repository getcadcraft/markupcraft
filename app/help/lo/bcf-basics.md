BCF (BIM Collaboration Format) ແມ່ນຮູບແບບໄຟລ໌ເປີດສຳລັບສົ່ງປະເດັນລະຫວ່າງເຄື່ອງມື BIM. ຫຼາຍໂປຣແກຣມປະສານງານໂມເດວ ແລະ ໂປຣແກຣມສ້າງແບບ ສາມາດນຳເຂົ້າໄຟລ໌ `.bcfzip` ເປັນລາຍການປະເດັນໄດ້. MarkupCraft ຂຽນ **BCF 2.1**.

## ສ້າງໄຟລ໌

1. ເປີດແຖບ {{ui:ການໝາຍ}}.
2. ກັ່ນຕອງລາຍການໃຫ້ເຫຼືອສິ່ງທີ່ທ່ານຕ້ອງການສົ່ງ, ຕົວຢ່າງ {{ui:ສະຖານະ}} "ເປີດ". ມີແຕ່ການໝາຍທີ່ຢູ່ໃນລາຍການເທົ່ານັ້ນທີ່ຈະຖືກສົ່ງອອກ.
3. ເລືອກ {{ui:BCF}}.
4. ລໍຖ້າໃນຂະນະທີ່ມັນສ້າງພາບຖ່າຍຂອງແຕ່ລະການໝາຍ ("ກຳລັງສ້າງພາບຖ່າຍສຳລັບ BCF (5 ໃນ 20)…").

ຜົນ: "<name> markups.bcfzip" ຖືກດາວໂຫລດ, ແລະ ແຖບສະຖານະບອກຈຳນວນຫົວຂໍ້ທີ່ມີ ແລະ ຂະໜາດໄຟລ໌.

## ມີຫຍັງໃນໄຟລ໌

ແຕ່ລະການໝາຍກາຍເປັນ **ຫົວຂໍ້** ໜຶ່ງອັນ:

| ຊ່ອງຂໍ້ມູນຫົວຂໍ້ | ເຕີມດ້ວຍ |
|---|---|
| Title | ໝາຍເລກກວດແກ້, ເລື່ອງ ແລະ ແຜ່ນ, ຕົວຢ່າງ "#4 ເມກໃນ A-101 — ແຜນຜັງ" |
| Type | ປະເພດການໝາຍ (ເມກ, ຄຳອະທິບາຍ, ຄວາມຍາວ…) |
| Status | ເປີດ, ຍອມຮັບ, ປະຕິເສດ ຫຼື ສຳເລັດ |
| Labels | ປະເພດການໝາຍ ແລະ ແຜ່ນ |
| Author and dates | ຜູ້ສ້າງການໝາຍ, ວັນທີສ້າງ ແລະ ວັນທີແກ້ໄຂ |
| Assigned to, due date | ຈາກລາຍການກວດແກ້ຂອງມັນ ເມື່ອມີ |
| Description | ຂໍ້ຄວາມ ຫຼື ຂໍ້ຄວາມຕາປະທັບ, ຄ່າທີ່ວັດໄດ້, ຄຳເຫັນ, ແຜ່ນ ແລະ ໄຟລ໌ |
| Comments | ໜຶ່ງອັນຕໍ່ການຕອບກັບ, ພ້ອມຜູ້ຕອບ ແລະ ວັນທີ |
| Snapshot | ຮູບຂອງການໝາຍໃນສ່ວນຂອງແຜ່ນ |
| Viewpoint | ມຸມມອງຈາກເທິງລົງລຸ່ມຂອງຕຳແໜ່ງການໝາຍໃນແຜ່ນ |

ການສົ່ງອອກການໝາຍດຽວກັນອີກຄັ້ງຈະໃຫ້ ID ຫົວຂໍ້ດຽວກັນ, ດັ່ງນັ້ນເຄື່ອງມືທີ່ນຳເຂົ້າ BCF ສາມາດຈຳໄດ້ວ່າເປັນປະເດັນດຽວກັນ.

## ຂໍ້ຈຳກັດທີ່ຄວນຮູ້

- **ແຜ່ນບໍ່ແມ່ນໂມເດວ.** Viewpoint ຊີ້ໄປຍັງຕຳແໜ່ງຂອງການໝາຍເທິງເຈ້ຍ, ວັດເປັນແມັດຂອງເຈ້ຍ. ມັນບໍ່ພາເຄື່ອງມື BIM ໄປຍັງຈຸດໃນໂມເດວ. ໃຊ້ພາບຖ່າຍ ແລະ ຊື່ແຜ່ນເພື່ອຊອກຫາຈຸດ.
- **ສະຖານະ ແລະ ປະເພດເປັນຂອງ MarkupCraft ເອງ** (ເປີດ, ຍອມຮັບ, ປະຕິເສດ, ສຳເລັດ; ເມກ, ຄຳອະທິບາຍ…). ໄຟລ໌ປະກາດພວກມັນຕາມທີ່ BCF ອະນຸຍາດ, ແຕ່ເຄື່ອງມືທີ່ມີລາຍການຄົງທີ່ຂອງຕົນເອງອາດຈັບຄູ່ ຫຼື ບໍ່ສົນໃຈພວກມັນ.
- **ການນຳເຂົ້າໄດ້ຄຳເຫັນ ບໍ່ແມ່ນມຸມມອງໂມເດວ.** {{ui:Import BCF}} ເພີ່ມການຕອບກັບ ແລະ ສະຖານະໃຫ້ການໝາຍທີ່ທ່ານສົ່ງອອກ, ແລະ ສ້າງບັນທຶກຂອງປະເດັນອື່ນ; ມັນບໍ່ສາມາດສະແດງກ້ອງຂອງໂມເດວໄດ້. ເບິ່ງ [ລາຍການການໝາຍ ແລະ ການສົ່ງອອກ](topic:markups-list-and-export#import-bcf).
- ການສົ່ງການໝາຍກັບຄືນເປັນ PDF ມັກຈະງ່າຍກວ່າສຳລັບການກວດແບບ. BCF ແມ່ນສຳລັບການນຳຄຳເຫັນແບບເຂົ້າໄປໃນຂັ້ນຕອນການປະສານງານໂມເດວ.
