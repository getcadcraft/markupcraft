## ສິ່ງທີ່ MarkupCraft ເປີດ

| ໄຟລ໌ | ວິທີ | ສິ່ງທີ່ເກີດຂຶ້ນ |
|---|---|---|
| PDF (`.pdf`) | {{ui:Open}}, {{key:Mod+O}}, ຫຼື ວາງໃສ່ພື້ນທີ່ແຜ່ນ. ເປີດຫຼາຍໄຟລ໌ພ້ອມກັນກໍໄດ້. | ທຸກໜ້າກາຍເປັນແຜ່ນ. ການໝາຍທີ່ມີຢູ່ແລ້ວໃນໄຟລ໌ຈະຖືກອ່ານກັບຄືນມາ (ເບິ່ງດ້ານລຸ່ມ). |
| ກ່ອງເຄື່ອງມື (`.json`) | ແຖບ {{ui:Tools}}, ຈາກນັ້ນ {{ui:Import}} | ເຄື່ອງມືຈະຖືກເພີ່ມເຂົ້າກ່ອງເຄື່ອງມືຂອງທ່ານ. ເບິ່ງ [ກ່ອງເຄື່ອງມື](topic:tool-chest). |

ໄຟລ໌ອື່ນທັງໝົດຈະຖືກປະຕິເສດພ້ອມຂໍ້ຄວາມ "MarkupCraft ເປີດໄຟລ໌ PDF ໄດ້." ໃນແຖບສະຖານະ. ຖ້າທ່ານວາງໄຟລ໌ປົນກັນ, ໄຟລ໌ PDF ຈະເປີດ ແລະ ແຖບສະຖານະຈະບອກວ່າມີກີ່ໄຟລ໌ທີ່ບໍ່ແມ່ນ PDF.

### ການໝາຍທີ່ມີຢູ່ແລ້ວໃນ PDF

- **ການໝາຍທີ່ MarkupCraft ບັນທຶກໄວ້** ຈະກັບມາຄືເກົ່າທຸກຢ່າງ: ປະເພດ, ຮູບແບບ, ຜູ້ຂຽນ, ວັນທີ, ສະຖານະ, ການຕອບກັບ, ໝາຍເລກຈຸດກວດ, ມາດຕາສ່ວນຂອງແຜ່ນ ແລະ ຊື່ແຜ່ນທີ່ທ່ານພິມໄວ້.
- **ຄຳເຫັນຈາກໂປຣແກຣມ PDF ອື່ນ** ກໍຖືກອ່ານເຊັ່ນກັນ. ສີ່ຫຼ່ຽມ, ວົງຮີ, ເສັ້ນ ແລະ ລູກສອນ, ໂພລີລາຍ, ໂພລີກອນ, ເສັ້ນປາກກາ (ink), ກ່ອງຂໍ້ຄວາມ ແລະ ບັນທຶກຕິດ ຈະກາຍເປັນການໝາຍປົກກະຕິຂອງ MarkupCraft ທີ່ແກ້ໄຂໄດ້. ການຕອບກັບ ແລະ ສະຖານະການທົບທວນຂອງພວກມັນກໍມານຳ.
- **ອັນອື່ນ** (ການໄຮໄລ້ຂໍ້ຄວາມທີ່ເຮັດໂດຍການເລືອກຂໍ້ຄວາມ, ຕາປະທັບຂອງໂປຣແກຣມອື່ນ ແລະ ປະເພດອື່ນ) ຈະສະແດງຕາມເດີມ ໂດຍໝາຍວ່າອ່ານຢ່າງດຽວ. ທ່ານສາມາດເລືອກ, ເບິ່ງມັນໃນລາຍການການໝາຍ ແລະ ຕອບກັບໄດ້, ແຕ່ຍ້າຍ, ປ່ຽນ ຫຼື ລຶບບໍ່ໄດ້.
- ລິ້ງ ແລະ ຊ່ອງຟອມຈະບໍ່ຖືກແຕະຕ້ອງ ແລະ ຈະບໍ່ຖືກລະບຸໄວ້.
- ມາດຕາສ່ວນທີ່ບັນທຶກໂດຍໂປຣແກຣມອື່ນ (viewport ການວັດແທກ) ຈະຖືກໃຊ້ເປັນມາດຕາສ່ວນຂອງແຜ່ນ ເມື່ອ MarkupCraft ເຂົ້າໃຈໜ່ວຍຂອງມັນ.

### ໄຟລ໌ທີ່ເປີດບໍ່ໄດ້

- PDF ທີ່ຕ້ອງໃຊ້ລະຫັດຜ່ານ: '"name" ຕ້ອງໃຊ້ລະຫັດຜ່ານເພື່ອເປີດ. ເປີດສຳເນົາທີ່ບໍ່ມີການປ້ອງກັນ.'
- ໄຟລ໌ເສຍຫາຍ ຫຼື ບໍ່ແມ່ນ PDF ແທ້: '"name" ອ່ານເປັນ PDF ບໍ່ໄດ້ (…)'.
- PDF ທີ່ເປີດໄດ້ແຕ່ຖືກປ້ອງກັນການປ່ຽນແປງ ຈະເປີດໄດ້ປົກກະຕິ. ແຕ່ການບັນທຶກຈະຖືກປະຕິເສດ (ເບິ່ງດ້ານລຸ່ມ).

ເມື່ອເປີດຫຼາຍໄຟລ໌ພ້ອມກັນ, ໄຟລ໌ທີ່ໃຊ້ໄດ້ຈະເປີດ ແລະ ກ່ອງທີ່ມີຊື່ "Some files did not open" ຈະລາຍການໄຟລ໌ອື່ນ.

## ສິ່ງທີ່ MarkupCraft ບັນທຶກ

ການບັນທຶກແມ່ນ **ການດາວໂຫຼດ** ໄຟລ໌ໃໝ່ສະເໝີ. ໜ້າເວັບບໍ່ສາມາດຂຽນທັບໄຟລ໌ໃນຄອມພິວເຕີຂອງທ່ານໄດ້, ແລະ MarkupCraft ບໍ່ເຄີຍປ່ຽນໄຟລ໌ຕົ້ນສະບັບຂອງທ່ານ.

| ທ່ານເລືອກ | ທ່ານຈະໄດ້ | ໝາຍເຫດ |
|---|---|---|
| {{ui:Save}} ({{key:Mod+S}}) | "<name> (marked up).pdf" | ສຳເນົາຂອງ PDF ຕົ້ນສະບັບ ພ້ອມການໝາຍທຸກອັນທີ່ຂຽນເປັນຄຳເຫັນ PDF ແທ້. ການບັນທຶກໄຟລ໌ "(marked up)" ອີກຄັ້ງຈະຮັກສາຊື່ເດີມ; ມັນຈະບໍ່ກາຍເປັນ "(marked up) (marked up)". ເບິ່ງ [ບັນທຶກ PDF ທີ່ໝາຍໄວ້](topic:save-the-marked-up-pdf). |
| ແຖບ {{ui:Markups}}, ຈາກນັ້ນ {{ui:CSV}} | "<name> markups.csv" | ການໝາຍຕາມທີ່ລາຍການສະແດງ (ຕົວກອງນຳໃຊ້ດ້ວຍ). |
| ແຖບ {{ui:Markups}}, ຈາກນັ້ນ {{ui:BCF}} | "<name> markups.bcfzip" | BCF 2.1 ສຳລັບເຄື່ອງມືປະສານງານ BIM, ມີຮູບໜຶ່ງອັນຕໍ່ການໝາຍ. ເບິ່ງ [ພື້ນຖານ BCF](topic:bcf-basics). |
| ແຖບ {{ui:Punch list}}, ຈາກນັ້ນ {{ui:Export CSV}} | "<name> punch list.csv" | ລາຍການກວດແກ້ຕາມລຳດັບໝາຍເລກ. |
| ແຖບ {{ui:Tools}}, ຈາກນັ້ນ {{ui:Export}} | "MarkupCraft tool chest.json" | ກ່ອງເຄື່ອງມືຂອງທ່ານ, ເພື່ອແບ່ງປັນ ຫຼື ເກັບໄວ້. |

"<name>" ແມ່ນຊື່ໄຟລ໌ PDF ທີ່ເປີດກ່ອນໝົດ ໂດຍບໍ່ມີ ".pdf".

ໄຟລ໌ CSV ເປີດໄດ້ໃນໂປຣແກຣມສເປຣດຊີດໃດກໍໄດ້. ມັນເປັນ UTF-8 ພ້ອມເຄື່ອງໝາຍທີ່ສເປຣດຊີດຊອກຫາ, ດັ່ງນັ້ນຊື່ທີ່ມີເຄື່ອງໝາຍສຽງຈະສະແດງຖືກຕ້ອງ. ເຊວທີ່ເລີ່ມດ້ວຍ =, +, - ຫຼື @ ຈະມີເຄື່ອງໝາຍ ' ນຳໜ້າ ເພື່ອໃຫ້ສເປຣດຊີດບໍ່ດຳເນີນການເປັນສູດ.

## ບ່ອນທີ່ການດາວໂຫຼດໄປ

ເບຣາວເຊີຂອງທ່ານເປັນຜູ້ກຳນົດ: ປົກກະຕິແມ່ນໂຟນເດີ Downloads, ຫຼື ມັນຈະຖາມທຸກຄັ້ງຖ້າທ່ານຕັ້ງໄວ້ແບບນັ້ນ. ເບິ່ງ [ເບຣາວເຊີ ແລະ ຄອມພິວເຕີ](common:browsers#what-differs-between-browsers).

:::chromium
ເມື່ອທ່ານບັນທຶກທຸກໄຟລ໌ທີ່ປ່ຽນແປງໃນຊຸດດຽວພ້ອມກັນ, Chrome ແລະ Edge ອາດຖາມວ່າເວັບໄຊນີ້ອະນຸຍາດໃຫ້ດາວໂຫຼດຫຼາຍໄຟລ໌ຫຼືບໍ່. ເລືອກ {{ui:Allow}}, ບໍ່ດັ່ງນັ້ນທ່ານຈະໄດ້ພຽງສຳເນົາທຳອິດເທົ່ານັ້ນ.
:::

## ອອນລາຍ ແລະ ອອບໄລນ໌

- **PDF ຂອງທ່ານບໍ່ເຄີຍອອກຈາກຄອມພິວເຕີເຄື່ອງນີ້**, ບໍ່ວ່າອອນໄລນ໌ ຫຼື ອອບໄລນ໌. ບໍ່ມີການອັບໂຫຼດໄປບ່ອນໃດເລີຍ.
- ຕົວອ່ານ PDF ຈະຖືກໂຫຼດຄັ້ງທຳອິດທີ່ທ່ານເປີດ PDF ("ກຳລັງໂຫຼດຕົວອ່ານ PDF…"), ແລະ ຕົວຂຽນ PDF ຈະຖືກໂຫຼດຄັ້ງທຳອິດທີ່ທ່ານບັນທຶກ ("ກຳລັງໂຫຼດຕົວຂຽນ PDF…") ຫຼື ເປີດໄຟລ໌ທີ່ມີຄຳເຫັນຢູ່ແລ້ວ.
- ເມື່ອມີການເຊື່ອມຕໍ່, ທັງສອງຈະໂຫຼດຈາກເວັບໄຊ.
- **ເພື່ອເຮັດວຽກໂດຍບໍ່ມີການເຊື່ອມຕໍ່,** ເລືອກ {{ui:Save for offline}} ໃນແຖບດ້ານເທິງຂະນະທີ່ທ່ານອອນໄລນ໌. ປຸ່ມຈະນັບ "ກຳລັງບັນທຶກ N ຈາກ M" ແລ້ວຂຶ້ນວ່າ "ພ້ອມອອບໄລນ໌". ສຳເນົານັ້ນລວມເຖິງຕົວອ່ານ PDF, ຕົວຂຽນ PDF (ປະມານ 6 MB ທັງໝົດ) ແລະ ວິທີໃຊ້ນີ້, ດັ່ງນັ້ນຫຼັງຈາກນັ້ນ ການເປີດ, ການໝາຍ ແລະ ການບັນທຶກ PDF ທັງໝົດຈະໃຊ້ໄດ້ແບບອອບໄລນ໌ໃນເບຣາວເຊີນີ້.
- ຖ້າປຸ່ມຂຶ້ນວ່າ "ບັນທຶກບໍ່ໄດ້", ມີບາງໄຟລ໌ທີ່ດາວໂຫຼດບໍ່ສຳເລັດ: ກວດການເຊື່ອມຕໍ່ ແລ້ວກົດອີກຄັ້ງ. ຖ້າມັນຂຶ້ນວ່າ "ອອບໄລນ໌ບໍ່ມີ", ໜ້າຕ່າງເບຣາວເຊີນີ້ບໍ່ສາມາດເກັບສຳເນົາອອບໄລນ໌ໄດ້ (ໜ້າຕ່າງສ່ວນຕົວ ແລະ ບາງຄອມພິວເຕີທີ່ຖືກຈັດການ); ໃຫ້ໃຊ້ໜ້າຕ່າງປົກກະຕິ.
- ເພື່ອອັບເດດ ຫຼື ລຶບສຳເນົາ, ກົດ "ພ້ອມອອບໄລນ໌" ແລ້ວເລືອກ "ບັນທຶກອີກຄັ້ງ (ເອົາເວີຊັນໃໝ່ສຸດ)" ຫຼື "ລຶບສຳເນົາອອບໄລນ໌". ເພີ່ມເຕີມໃນ [ເຮັດວຽກແບບອອບໄລນ໌](common:offline).

:::offline
ທ່ານກຳລັງອອບໄລນ໌. ຖ້າແຖບດ້ານເທິງຂຶ້ນວ່າ "ພ້ອມອອບໄລນ໌", ທຸກຢ່າງໃຊ້ໄດ້, ລວມທັງການບັນທຶກ. ຖ້າບໍ່ແມ່ນ ແລະ ທ່ານຍັງບໍ່ໄດ້ບັນທຶກໃນແຖບນີ້, {{ui:Save}} ອາດລົ້ມເຫຼວດ້ວຍຂໍ້ຄວາມ "ຕົວຂຽນ PDF ໂຫຼດບໍ່ໄດ້". ການໝາຍຂອງທ່ານຍັງຢູ່ໃນແຖບ: ໃຫ້ເປີດແຖບໄວ້, ກັບມາອອນໄລນ໌, ແລ້ວເລືອກ {{ui:Save}} ອີກຄັ້ງ.
