ປຸ່ມລັດທີ່ຂຽນດ້ວຍ {{key:Mod}} ໃຊ້ໄດ້ທັງ ⌘ ຫຼື Control ເທິງ Mac, ແລະ Ctrl ເທິງ Windows ແລະ Linux. ປຸ່ມອັກສອນຂອງເຄື່ອງມືໃຊ້ໄດ້ພຽງເວລາທີ່ທ່ານບໍ່ໄດ້ພິມຢູ່ໃນກ່ອງ; ເວລາພິມ ອັກສອນກໍເປັນແຕ່ອັກສອນທຳມະດາ. ເບິ່ງເພີ່ມເຕີມ [ປຸ່ມ, ເມົ້າ ແລະ ແທຣັກແພດ](common:keys).

## ເວລາແຕ້ມ

| ປຸ່ມ ຫຼື ການກະທຳ | ມັນເຮັດຫຍັງ |
|---|---|
| {{key:Shift}} ເວລາແຕ້ມ | ເສັ້ນ, ລູກສອນ, ຄວາມຍາວ ແລະ ດ້ານຂອງໂພລີລາຍ ປັບເປັນຂັ້ນ 45°; ສີ່ຫຼ່ຽມ, ວົງຮີ ແລະ ກ່ອງເມກເປັນຈັດຕຸລັດ; ປາກກາ ແລະ ໄຮໄລ້ເປັນເສັ້ນຊື່ເສັ້ນດຽວ |
| ຄລິກສອງຄັ້ງ, {{key:Enter}} ຫຼື ຄລິກຂວາ | ຈົບໂພລີລາຍ, ໂພລີກອນ, ເມກອິດສະຫຼະ ຫຼື ພື້ນທີ່ |
| {{key:Backspace}} | ລຶບຈຸດສຸດທ້າຍຂອງໂພລີລາຍ, ໂພລີກອນ, ເມກອິດສະຫຼະ ຫຼື ພື້ນທີ່ |
| {{key:Esc}} | ຍົກເລີກສິ່ງທີ່ກຳລັງແຕ້ມ; ຖ້າບໍ່ມີຫຍັງກຳລັງດຳເນີນຢູ່, ລຶບການເລືອກ; ຖ້າບໍ່ໄດ້ເລືອກຫຍັງ, ກັບໄປ {{ui:Select}} |
| {{key:Mod+Enter}} | ຈົບການພິມໃນກ່ອງຂໍ້ຄວາມ, ຄຳອະທິບາຍ ຫຼື ບັນທຶກ (ຫຼື ຄລິກນອກກ່ອງ) |
| {{key:Esc}} ເວລາພິມ | ຍົກເລີກຂໍ້ຄວາມທີ່ກຳລັງພິມ |
| ຄລິກດ້ວຍ {{key:Shift}} ກັບ {{ui:Count}} | ລຶບຈຸດທີ່ໃກ້ທີ່ສຸດຂອງກຸ່ມການນັບທີ່ເລືອກ |

## ຕັດ, ສຳເນົາ ແລະ ວາງ

ຄຳສັ່ງດຽວກັນນີ້ຢູ່ໃນກຸ່ມ {{ui:Edit}} ຂອງແຖບເຄື່ອງມື ({{ui:Copy}}, {{ui:Paste}}) ແລະ ໃນເມນູ {{ui:More}}, ແຕ່ລະອັນມີປຸ່ມຂອງມັນ. ທຸກອັນເປັນຂັ້ນຕອນຍ້ອນກັບດຽວ. ເບິ່ງ [ສຳເນົາ, ວາງ ແລະ ເຮັດສຳເນົາ](topic:select-and-edit#copy-paste-and-duplicate).

| ປຸ່ມ | ມັນເຮັດຫຍັງ |
|---|---|
| {{key:Mod+X}} | ຕັດ: ສຳເນົາການເລືອກ ແລ້ວລຶບມັນ |
| {{key:Mod+C}} | ສຳເນົາການເລືອກ |
| {{key:Mod+V}} | ວາງ. ຖ້າຕົວຊີ້ຢູ່ເທິງແຜ່ນ, ສຳເນົາຈະຢູ່ກາງບ່ອນທີ່ຕົວຊີ້; ບໍ່ດັ່ງນັ້ນຈະຢູ່ຂ້າງຕົ້ນສະບັບ. ການຕັ້ງຄ່າສາມາດເຮັດໃຫ້ວາງຢູ່ຂ້າງຕົ້ນສະບັບສະເໝີ. |
| {{key:Mod+Shift+V}} | ວາງໃນຈຸດເດີມ: ຕຳແໜ່ງດຽວກັນໃນແຜ່ນ, ໃນແຜ່ນນີ້ ຫຼື ແຜ່ນອື່ນ |
| {{key:Mod+D}} | ເຮັດສຳເນົາການເລືອກຢູ່ຂ້າງມັນ (ຄລິບບອດບໍ່ຖືກແຕະຕ້ອງ) |

|---|---|

## ຊູມ ແລະ ເລື່ອນ

| ປຸ່ມ ຫຼື ການກະທຳ | ມັນເຮັດຫຍັງ |
|---|---|
| ລໍ້ເມົ້າ | ຊູມເຂົ້າ ຫຼື ອອກຮອບຕົວຊີ້ (ລໍ້ບໍ່ເລື່ອນໜ້າ) |
| {{key:Ctrl}} + ລໍ້ | ຊູມໄວຂຶ້ນ |
| {{key:Plus}} ຫຼື {{key:Minus}} (ກັບ {{key:Mod}} ກໍໄດ້) | ຊູມເຂົ້າ ຫຼື ອອກຈາກກາງ; {{key:=}} ໃຊ້ໄດ້ຄືກັບ {{key:Plus}} |
| {{key:Mod+0}} | {{ui:Fit page}} |
| {{key:Mod+9}} | {{ui:Fit width}} |
| ລາກດ້ວຍປຸ່ມກາງ | ເລື່ອນມຸມມອງ |
| ລາກດ້ວຍປຸ່ມຂວາ | ເລື່ອນມຸມມອງ (ເມື່ອທ່ານບໍ່ໄດ້ຢູ່ກາງໂພລີລາຍ) |
| ກົດ {{key:Space}} ຄ້າງໄວ້ ແລ້ວລາກ | ເລື່ອນມຸມມອງ |
| ປຸ່ມລູກສອນເວລາບໍ່ໄດ້ເລືອກຫຍັງ | ເລື່ອນມຸມມອງ |

:::mac
**ເທິງແທຣັກແພດ:** ການເລື່ອນສອງນິ້ວຊູມ. ການບີບກໍຊູມເຂົ້າໃນ Chrome, Edge ແລະ Firefox. ເລື່ອນດ້ວຍການກົດ {{key:Space}} ຄ້າງໄວ້ ແລ້ວລາກ, ຫຼື ດ້ວຍເຄື່ອງມື {{ui:Pan}}. ການຄລິກສອງນິ້ວແມ່ນຄລິກຂວາ ແລະ ຈົບໂພລີລາຍ. ການກົດ Control ຄລິກອາດເປັນແຕ່ຄລິກທຳມະດາ ບໍ່ແມ່ນຄລິກຂວາ, ສະນັ້ນໃຫ້ໃຊ້ການຄລິກສອງນິ້ວ.
:::

## ປຸ່ມລັດທີ່ເບຣາວເຊີເກັບໄວ້

- {{key:Mod+W}}, {{key:Mod+T}}, {{key:Mod+N}} ແລະ {{key:Mod+Q}} ເປັນຂອງເບຣາວເຊີ. ການປິດແທັບ ຫຼື ໜ້າຕ່າງທີ່ມີການໝາຍທີ່ຍັງບໍ່ໄດ້ບັນທຶກຈະເຮັດໃຫ້ສູນເສຍມັນ, ຫຼັງຈາກຄຳຖາມ "Leave site?" ຂອງເບຣາວເຊີໃນຄອມພິວເຕີ.
- ເບຣາວເຊີສ່ວນໃຫຍ່ເກັບ {{key:Mod+N}} ໄວ້ສຳລັບໜ້າຕ່າງໃໝ່, ສະນັ້ນໃນແທັບເບຣາວເຊີ ໃຫ້ໃຊ້ {{ui:New}} ໃນແຖບເຄື່ອງມື; ແອັບເດັສທັອບ ແລະ Studio ສົ່ງປຸ່ມນີ້ໃຫ້ MarkupCraft.
- MarkupCraft ເອົາ {{key:Mod+O}}, {{key:Mod+S}}, {{key:Mod+D}}, {{key:Mod+A}}, {{key:Mod+V}}, {{key:Mod+Shift+V}}, {{key:Mod+0}}, {{key:Mod+Plus}} ແລະ {{key:Mod+Minus}} ອອກຈາກເບຣາວເຊີ ໃນຂະນະທີ່ແອັບມີແປ້ນພິມ, ແລະ {{key:Mod+C}} ກັບ {{key:Mod+X}} ໃນຂະນະທີ່ມີການໝາຍຖືກເລືອກ. {{key:Mod+,}} ເປີດ {{ui:Settings}}. ເພື່ອຊູມທັງໜ້າເບຣາວເຊີ, ໃຫ້ໃຊ້ເມນູຂອງເບຣາວເຊີ.
- {{key:Mod+9}} ອາດໄປແທັບເບຣາວເຊີສຸດທ້າຍໃນບາງເບຣາວເຊີ ກ່ອນທີ່ MarkupCraft ຈະເຫັນມັນ. ຖ້າເກີດຂຶ້ນ, ໃຫ້ໃຊ້ {{ui:Fit width}} ຢູ່ໃຕ້ແຜ່ນ.
- {{key:Esc}} ໃນໂໝດເຕັມຈໍ ກໍອອກຈາກໂໝດເຕັມຈໍ.

## ເມື່ອປຸ່ມບໍ່ເຮັດຫຍັງ

- **ທ່ານກຳລັງພິມໃນກ່ອງ.** ໃຫ້ຄລິກໃສ່ແຜ່ນກ່ອນ. (ການຄລິກດ້ວຍເຄື່ອງມືແຕ້ມຈະແຕ້ມ; ກົດ {{key:Esc}} ຫຼັງຈາກນັ້ນ ຫຼື ໃຊ້ {{key:Mod+Z}} ເພື່ອຍ້ອນກັບ.)
- **ມີກ່ອງໂຕ້ຕອບເປີດຢູ່.** ປຸ່ມຕ່າງໆຈະໄປທີ່ກ່ອງໂຕ້ຕອບຈົນກວ່າມັນຈະປິດ.
- **ທ່ານຄລິກປຸ່ມແຖບເຄື່ອງມືກ່ອນໜ້ານີ້.** ຫຼັງຈາກນັ້ນ, ປຸ່ມລູກສອນ ຫຼື {{key:Space}} ຈະໄປກະທົບປຸ່ມນັ້ນແທນ. ໃຫ້ຍ້າຍຕົວຊີ້ໄປເທິງແຜ່ນ ແລ້ວໃຊ້ລໍ້ ຫຼື ປຸ່ມກາງ, ຫຼື ກົດອັກສອນຂອງເຄື່ອງມືແທນການຄລິກປຸ່ມ.
