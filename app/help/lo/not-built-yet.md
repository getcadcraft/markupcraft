MarkupCraft ຍັງຢູ່ໃນການພັດທະນາ. ນີ້ແມ່ນສິ່ງທີ່ການສ້າງປັດຈຸບັນ **ບໍ່** ເຮັດ ເພື່ອໃຫ້ທ່ານວາງແຜນໄດ້. ມັນອະທິບາຍການສ້າງໃນມື້ນີ້ ບໍ່ແມ່ນຄຳສັນຍາ.

## ການເຮັດວຽກກັບຄົນອື່ນ

| ຍັງບໍ່ມີ | ເຮັດແບບນີ້ໃນມື້ນີ້ |
|---|---|
| ການບັນທຶກແບບຄລາວ ແລະ ການຊິງລະຫວ່າງຄອມພິວເຕີ | ເກັບໄຟລ໌ PDF ໄວ້ກັບໄຟລ໌ໂຄງການຂອງທ່ານ. ການບັນທຶກແບບຄລາວຍັງບໍ່ມີ. |
| ການລວມສຳເນົາການໝາຍຂອງສອງຄົນເຂົ້າກັນ | ແບ່ງແຜ່ນໃຫ້ຜູ້ກວດແຕ່ລະຄົນ, ຫຼື ສຳເນົາການໝາຍບໍ່ຫຼາຍໂດຍໃຊ້ {{key:Mod+C}} ແລະ {{key:Mod+V}}. RFI, ໃບສົ່ງຂອງ ແລະ ບັນທຶກປະຈຳວັນສາມາດລວມກັນໄດ້: ເບິ່ງ [ຕິດຕາມ RFI, ໃບສົ່ງຂອງ ແລະ ບັນທຶກປະຈຳວັນ](topic:field-records). |
| ທີມ, ການແຈ້ງເຕືອນ ແລະ ໂຄງການຄລາວສຳລັບ RFI ແລະ ໃບສົ່ງຂອງ | ສົ່ງ PDF ຕໍ່ໄປ ແລະ ໃຊ້ {{ui:ລວມ}} ເພື່ອນຳສຳເນົາມາລວມກັນ. |
| RFI, ໃບສົ່ງຂອງ ແລະ ບັນທຶກປະຈຳວັນໃນເຊດຊັນສົດ | ແຕ່ລະຄົນເຮັດວຽກກັບສຳເນົາຂອງຕົນເອງ; ນຳສຳເນົາມາລວມກັນດ້ວຍ {{ui:ລວມ}}. |
| ການລວມການປ່ຽນແປງຂອງສອງຄົນໃນຊ່ອງທີ່ຕ່າງກັນຂອງບັນທຶກດຽວ | ສຳເນົາທີ່ແກ້ໄຂຫຼ້າສຸດຈະຊະນະບັນທຶກນັ້ນທັງໝົດ (ກະທູ້ ແລະ ຊື່ໄຟລ໌ແນບຈະຖືກຕໍ່ເຂົ້າກັນ). ຕົກລົງກັນກ່ອນວ່າໃຜແກ້ບັນທຶກໃດ. |
| ເຄື່ອງມືຜູ້ຊ່ວຍສຳລັບ RFI, ໃບສົ່ງຂອງ ແລະ ບັນທຶກປະຈຳວັນ | ເຮັດວຽກກັບພວກມັນໃນແທັບ {{ui:ພາກສະໜາມ}}. ຜູ້ຊ່ວຍສາມາດເຮັດວຽກກັບການໝາຍໄດ້: ເບິ່ງ [ໃຊ້ MarkupCraft ກັບຜູ້ຊ່ວຍ AI](topic:use-with-ai-assistants). |
| ການແກ້ໄຂ ຫຼື ລຶບການຕອບກັບຫຼັງຈາກສົ່ງແລ້ວ | ຍ້ອນກັບທັນທີ, ຫຼື ເພີ່ມການຕອບກັບທີ່ແກ້ໄຂ. |
| ການປ່ຽນຜູ້ທີ່ເປັນຜູ້ສ້າງການໝາຍ | ຕັ້ງຊື່ຂອງທ່ານກ່ອນເລີ່ມ. |

|---|---|

## ການວັດແທກ

| ຍັງບໍ່ມີ | ເຮັດແບບນີ້ໃນມື້ນີ້ |
|---|---|
| ການວັດລັດສະໝີ | ແຕ້ມ {{ui:ເສັ້ນໂຄ້ງ}} ຕາມມັນ, ຫຼື ວັດ {{ui:ຄວາມຍາວ}} ຂ້າມ ແລ້ວຕັດເຄິ່ງ. |
| ແກ້ໄຂມຸມຂອງຮູຕັດ | ລຶບຮູຕັດອອກ ແລ້ວແຕ້ມໃໝ່. |
| ໃຊ້ມາດຕາສ່ວນດຽວກັບຫຼາຍແຜ່ນພ້ອມກັນ | ປັບມາດຕາແຕ່ລະແຜ່ນ; ການເລືອກຄ່າທີ່ຕັ້ງໄວ້ໃຊ້ເວລາສອງສາມວິນາທີຕໍ່ແຜ່ນ. |
| ຫຼາຍມາດຕາສ່ວນໃນແຜ່ນດຽວ (ວິວພອດ) | ປັບໃຫ້ກົງກັບແບບທີ່ທ່ານວັດຫຼາຍທີ່ສຸດ. ການປ່ຽນມາດຕາສ່ວນຂອງແຜ່ນຈະວັດໃໝ່ທຸກຢ່າງໃນແຜ່ນ, ສະນັ້ນຈົດຄ່າລາຍລະອຽດໄວ້ກ່ອນປັບໃໝ່. |
| ດູດເກາະເຂົ້າກັບເສັ້ນໃນແບບແຕ້ມ | ຊູມເຂົ້າກ່ອນຄລິກ, ຫຼື ພິມຄວາມຍາວ ແລະ ມຸມ (ເບິ່ງ [ແຕ້ມຮ່າງຕາມມາດຕາສ່ວນ](topic:calibrate-and-measure#sketch-to-scale)). |
| ການຖອດປະລິມານເຕັມຮູບແບບ ພ້ອມລາຍການ, ການປະກອບ ແລະ ລາຄາ | ໃຊ້ TakeoffCraft, ແອັບການຖອດປະລິມານໃນຄອບຄົວ CadCraft. |
