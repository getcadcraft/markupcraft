MarkupCraft ເຮັດວຽກກັບການສຳຜັດ: ໃນ iPad (Safari ຫຼື Chrome), ໃນແລັບທັອບໜ້າຈໍສຳຜັດ, ຫຼື ໃນແທັບເລັດ Windows ຫຼື Android ທີ່ມີບຣາວເຊີຫຼ້າສຸດ. ໃນແນວນອນ ແທັບເລັດສະແດງຮູບແບບເຕັມ.

## ທ່າທາງ

| ທ່າທາງ | ມັນເຮັດຫຍັງ |
|---|---|
| ນິ້ວດຽວ | ແຕ້ມດ້ວຍເຄື່ອງມືປັດຈຸບັນ, ຫຼື ເລືອກດ້ວຍ {{ui:ເລືອກ}} |
| ສອງນິ້ວ, ກາງອອກ ຫຼື ບີບ | ຊູມອ້ອມຈຸດລະຫວ່າງນິ້ວຂອງທ່ານ |
| ສອງນິ້ວ, ເລື່ອນພ້ອມກັນ | ເລື່ອນ; ທ່ານສາມາດຊູມ ແລະ ເລື່ອນໃນການເຄື່ອນໄຫວດຽວ |
| ນິ້ວທີ່ສອງຂະນະແຕ້ມ | ຍົກເລີກສິ່ງທີ່ນິ້ວທຳອິດເລີ່ມ ແລະ ເລີ່ມຊູມແທນ |
| ແຕະສອງຄັ້ງ, ຫຼື ແຕະຄ້າງ | ສຳເລັດເສັ້ນໂພລີ, ໂພລີກອນ, ເມກອິດສະຫຼະ ຫຼື ພື້ນທີ່ |
| ແຕະຄ້າງຂໍ້ຄວາມ, ຄຳອະທິບາຍ ຫຼື ໝາຍເຫດ, ດ້ວຍ {{ui:ເລືອກ}} | ເປີດຂໍ້ຄວາມຂອງມັນເພື່ອແກ້ໄຂ |
| ນິ້ວດຽວດ້ວຍ {{ui:ເລື່ອນ}} ເປີດ | ເລື່ອນ |

ໃນໜ້າຈໍສຳຜັດ ປຸ່ມແຖບເຄື່ອງມື, ເມນູ, ແທັບ ແລະ ປຸ່ມກ່ອງໂຕ້ຕອບຈະໃຫຍ່ຂຶ້ນ, ເພື່ອໃຫ້ແຕະດ້ວຍນິ້ວໄດ້ງ່າຍ.

## ສິ່ງທີ່ເກີດຂຶ້ນເມື່ອຍົກນິ້ວ

ເພື່ອໃຫ້ນິ້ວທຳອິດຂອງການບີບບໍ່ທິ້ງຮອຍ, ເຄື່ອງມືບາງອັນເຮັດວຽກເມື່ອທ່ານ **ຍົກ** ນິ້ວ, ບໍ່ແມ່ນເມື່ອແຕະ:

- {{ui:ນັບ}}: ຈຸດຖືກເພີ່ມເມື່ອຍົກ.
- {{ui:ບັນທຶກ}}: ໝາຍເຫດຖືກວາງເມື່ອຍົກ.
- {{ui:ໂພລີລາຍ}}, {{ui:ໂພລີກອນ}}, {{ui:ເມກອິດສະຫຼະ}} ແລະ {{ui:ພື້ນທີ່}}: ແຕ່ລະຈຸດຖືກເພີ່ມເມື່ອຍົກ.
- {{ui:ເສັ້ນ}}, {{ui:ລູກສອນ}}, {{ui:ຄວາມຍາວ}} ແລະ {{ui:ປັບມາດຕາ}}: ເມື່ອທ່ານແຕະຈຸດເລີ່ມ ແລ້ວແຕະຈຸດສິ້ນສຸດ, ຈຸດສິ້ນສຸດຖືກວາງເມື່ອຍົກ.

ຖ້ານິ້ວຂອງທ່ານເລື່ອນຫຼາຍກວ່າເລັກນ້ອຍກ່ອນຍົກ, ມັນບໍ່ນັບເປັນການແຕະ ແລະ ບໍ່ມີອັນໃດຖືກເພີ່ມ. ແຕະໃຫ້ສະອາດ; ເພື່ອແກ້ໄຂ, ໃຊ້ {{ui:ຍ້ອນກັບ}}.

ເຄື່ອງມືທີ່ທ່ານລາກ ({{ui:ປາກກາ}}, {{ui:ໄຮໄລ້}}, {{ui:ເມກ}}, {{ui:ສີ່ຫຼ່ຽມ}}, {{ui:ວົງຮີ}}, {{ui:ຄຳອະທິບາຍ}}, {{ui:ຂໍ້ຄວາມ}}, {{ui:ຕາປະທັບ}}) ເລີ່ມທັນທີທີ່ທ່ານແຕະ; ນິ້ວທີ່ສອງຈະຍົກເລີກພວກມັນ.

## ເລືອກດ້ວຍນິ້ວ

- ແຕະການໝາຍເພື່ອເລືອກມັນ; ລາກມັນເພື່ອຍ້າຍ; ລາກຈຸດຈັບເພື່ອປ່ຽນຂະໜາດ. ຫຼັງຈາກນິ້ວແຕະແຜ່ນ, ການໝາຍ ແລະ ຈຸດຈັບຈະມີເປົ້າໝາຍໃຫຍ່ຂຶ້ນ ແລະ ຈຸດຈັບຈະແຕ້ມໃຫຍ່ຂຶ້ນ.
- ລາກຂ້າມແຜ່ນທີ່ວ່າງເພື່ອແຕ້ມໜ້າຕ່າງການເລືອກ (ຈາກຊ້າຍໄປຂວາ: ຢູ່ໃນກ່ອງທັງໝົດ; ຈາກຂວາໄປຊ້າຍ: ແຕະ).
- ໃນ {{ui:ເລືອກ}}, ນິ້ວດຽວ **ບໍ່** ເລື່ອນ. ໃຊ້ສອງນິ້ວ, ຫຼື ເລືອກ {{ui:ເລື່ອນ}}.

## ສິ່ງທີ່ຕ້ອງໃຊ້ແປ້ນພິມ

ບໍ່ມີແປ້ນພິມ ກໍບໍ່ມີ {{key:Shift}}, {{key:Esc}} ຫຼື {{key:Enter}}. ນີ້ແມ່ນສິ່ງທີ່ຕ້ອງເຮັດແທນ:

| ການກະທຳດ້ວຍແປ້ນພິມ | ຖ້າບໍ່ມີແປ້ນພິມ |
|---|---|
| {{key:Esc}} ເພື່ອຍົກເລີກ ຫຼື ກັບໄປ ເລືອກ | ແຕະ {{ui:ເລືອກ}} ໃນແຖບເຄື່ອງມື |
| {{key:Shift}} ເພື່ອເສັ້ນ 45°, ສີ່ຫຼ່ຽມ ແລະ ວົງມົນ | ແຕ້ມຢ່າງລະມັດລະວັງ; ປັບດ້ວຍຈຸດຈັບ |
| Shift+ຄລິກ ເພື່ອເພີ່ມເຂົ້າການເລືອກ | ໃຊ້ໜ້າຕ່າງການເລືອກ |
| Shift+ຄລິກ ເພື່ອເອົາຈຸດນັບອອກ | {{ui:ຍ້ອນກັບ}} ທັນທີຫຼັງແຕະຜິດ |
| {{key:Mod+Enter}} ເພື່ອສຳເລັດການພິມ | ແຕະນອກກ່ອງຂໍ້ຄວາມ |
| {{key:Enter}} ເພື່ອສຳເລັດເສັ້ນໂພລີ, ຫຼື ແກ້ໄຂຂໍ້ຄວາມຂອງການໝາຍ | ແຕະຄ້າງ, ຫຼື {{ui:ແກ້ໄຂໃນແຜ່ນ}} ໃນ {{ui:ຄຸນສົມບັດ}} |
| {{key:Delete}} | {{ui:ລຶບ}} ໃນແຖບເຄື່ອງມື ຫຼື ໃນ {{ui:ຄຸນສົມບັດ}} |
| ເລີ່ມກຸ່ມນັບໃໝ່ດ້ວຍ {{key:Esc}} | ແຕະແຜ່ນວ່າງດ້ວຍ {{ui:ເລືອກ}}, ແລ້ວແຕະ {{ui:ນັບ}} ອີກຄັ້ງ |

ແປ້ນພິມແບບມີກ່ອງ ຫຼື ແປ້ນ Bluetooth ນຳທາງລັດທັງໝົດກັບມາ; ໃນ iPad, ປຸ່ມ ⌘ ໃຊ້ໄດ້ກັບ {{key:Mod+Z}} ແລະ ອື່ນໆ.

ປຸ່ມບໍ່ສະແດງຄຳແນະນຳເມື່ອສຳຜັດ. ປຸ່ມລັດຂອງແຕ່ລະເຄື່ອງມືຢູ່ໃນ [ແປ້ນພິມ ແລະ ເມົ້າ](topic:keyboard).

## ປາກກາສະຕາຍລັສ ແລະ Apple Pencil

ປາກກາສະຕາຍລັສ (Apple Pencil, Surface Pen ແລະ ອື່ນໆ) ເຮັດວຽກຄືເມົ້າ: ມັນແຕ້ມ ແລະ ເລືອກ, ແລະ ເຮັດທັນທີເມື່ອແຕະລົງ. ໃຊ້ນິ້ວສຳລັບບີບ ແລະ ເລື່ອນ. ແຮງກົດບໍ່ປ່ຽນຄວາມໜາເສັ້ນ.

## ເປີດ ແລະ ບັນທຶກໃນ iPad

- {{ui:ເປີດ}} ສະແດງຕົວເລືອກໄຟລ໌ຂອງ Files: iCloud Drive, On My iPad ແລະ ແອັບເກັບຂໍ້ມູນໃດກໍໄດ້ທີ່ທ່ານເຊື່ອມຕໍ່ແລ້ວ.
- {{ui:ບັນທຶກ}} ຖາມເພື່ອດາວໂຫຼດ; ສຳເນົາຈະໄປຢູ່ໃນ Files, ພາຍໃຕ້ Downloads (ຫຼື ໂຟນເດີທີ່ຕັ້ງໄວ້ໃນການຕັ້ງຄ່າ Safari).

## ຮັກສາວຽກຂອງທ່ານໃຫ້ປອດໄພໃນແທັບເລັດ

:::warning
iPad Safari ບໍ່ເຕືອນທ່ານກ່ອນອອກຈາກໜ້າທີ່ມີວຽກທີ່ຍັງບໍ່ໄດ້ບັນທຶກ, ແລະ iPadOS ອາດໂຫຼດແທັບຄືນໃນພື້ນຫຼັງເພື່ອປ່ອຍໜ່ວຍຄວາມຈຳ. MarkupCraft ເກັບສຳເນົາກູ້ຄືນໄວ້ໃນບຣາວເຊີ ແລະ ສະເໜີໃຫ້ເມື່ອທ່ານເປີດອີກຄັ້ງ (ເບິ່ງ [ກູ້ຄືນວຽກຂອງທ່ານ](common:recover)), ແຕ່ **ບັນທຶກຫຼັງແຕ່ລະແຜ່ນ ຫຼື ຫຼັງແຕ່ລະຮອບການເດີນສຳຫຼວດ**: ແທັບສ່ວນຕົວບໍ່ເກັບສຳເນົາໄວ້.

- ຊື່ຂອງທ່ານ, ການຕັ້ງຄ່າເຄື່ອງມື ແລະ ຕູ້ເຄື່ອງມືຖືກເກັບໄວ້ໃນບຣາວເຊີນັ້ນໃນ iPad ນັ້ນ, ຄືກັບໃນຄອມພິວເຕີ. ເບິ່ງ [ສິ່ງທີ່ເກັບໄວ້ໃນບຣາວເຊີນີ້](topic:browser-storage).
- **ກ່ອນເຂົ້າໄປໃນສະຖານທີ່ທີ່ບໍ່ມີສັນຍານ:** ໃນຂະນະທີ່ຍັງອອນລາຍ, ເປີດ MarkupCraft ໃນ Safari (ຫຼື Chrome) ໃນ iPad ແລ້ວເລືອກ {{ui:ບັນທຶກສຳລັບອອບໄລນ໌}} ໃນແຖບດ້ານເທິງ. ລໍຖ້າຈົນກວ່າມັນຈະບອກວ່າ "ພ້ອມອອບໄລນ໌" (ມັນນັບ "ກຳລັງບັນທຶກ N ຈາກ M"; ໂປຣແກຣມອ່ານ ແລະ ຂຽນ PDF ປະມານ 6 MB). ໃນສະຖານທີ່, ເປີດທີ່ຢູ່ດຽວກັນ ຫຼື ບຸກມາກຂອງມັນ: ການເປີດ, ການໝາຍ ແລະ ການບັນທຶກ PDF ໃຊ້ໄດ້ໂດຍບໍ່ມີການເຊື່ອມຕໍ່. ຖ້າມັນບອກວ່າ "ອອບໄລນ໌ບໍ່ມີ", ທ່ານຢູ່ໃນແທັບສ່ວນຕົວ; ໃຫ້ໃຊ້ແທັບປົກກະຕິ. ເບິ່ງ [ເຮັດວຽກແບບອອບໄລນ໌](common:offline).
- Safari ລຶບສຳເນົາອອບໄລນ໌ທີ່ທ່ານບໍ່ໄດ້ໃຊ້ເປັນເວລາຫຼາຍອາທິດ. ກ່ອນການເດີນທາງ, ກົດ "ພ້ອມອອບໄລນ໌" ແລ້ວເລືອກ "ບັນທຶກອີກຄັ້ງ (ເອົາລຸ້ນຫຼ້າສຸດ)".
- ຊຸດແຜນຜັງຂະໜາດໃຫຍ່ໃຊ້ໜ່ວຍຄວາມຈຳຫຼາຍ. ໃນແທັບເລັດ, ເປີດສະເພາະແຜ່ນທີ່ທ່ານຕ້ອງການສຳລັບການເຂົ້າໄປນັ້ນ.

## ໃນໂທລະສັບ

ໃຊ້ໄດ້, ແຕ່ໜ້າຈໍນ້ອຍ: ສ່ວນຕ່າງໆຈະຊ້ອນກັນ (ແຖບເຄື່ອງມື, ແຜ່ນ, ແຖບສະຖານະ, ແຜງ, ແລ້ວລາຍການແຜ່ນ), ແລະ ແຖບເຄື່ອງມືເລື່ອນໄປດ້ານຂ້າງ. ໃຊ້ໂທລະສັບເພື່ອເບິ່ງ ແລະ ເພີ່ມໝາຍເຫດດ່ວນ, ແລະ ໃຊ້ແທັບເລັດ ຫຼື ຄອມພິວເຕີສຳລັບການກວດຈິງ.
