## ບັນທຶກ

1. ເລືອກ {{ui:ບັນທຶກ}} ໃນແຖບເຄື່ອງມື ຫຼື ກົດ {{key:Mod+S}}.
2. ຖ້າເປີດຫຼາຍໄຟລ໌ຢູ່, ໃຫ້ເລືອກ {{ui:ໄຟລ໌ນີ້}} (ໄຟລ໌ຂອງແຜ່ນທີ່ທ່ານຢູ່) ຫຼື {{ui:ທຸກໄຟລ໌ທີ່ປ່ຽນແປງ}}. ແຕ່ລະສຳເນົາຈະດາວໂຫຼດແຍກກັນ.
3. ລໍຖ້າໃຫ້ "ກຳລັງບັນທຶກ <file>…" ສຳເລັດ. ການບັນທຶກຄັ້ງທຳອິດໃນແຕ່ລະເຊດຊັນຈະໂຫຼດຕົວຂຽນ PDF ນຳ.

ຜົນ: ເບຣາວເຊີຂອງທ່ານດາວໂຫຼດ "<name> (marked up).pdf" ແລະ ແຖບສະຖານະລາຍງານວ່າ: 'Saved A-Plans (marked up).pdf (24 markups, 18.2 MB). The original file is unchanged.' ຈຸດຫຼັງ {{ui:ບັນທຶກ}} ຈະຫາຍໄປ.

**ໄຟລ໌ PDF ຕົ້ນສະບັບຂອງທ່ານບໍ່ເຄີຍຖືກປ່ຽນແປງ.** MarkupCraft ຂຽນໄຟລ໌ໃໝ່. ໄຟລ໌ນັ້ນຈະໄປຢູ່ໃສຂຶ້ນກັບການຕັ້ງຄ່າການດາວໂຫຼດຂອງເບຣາວເຊີ (ເບິ່ງ [ໄຟລ໌ທີ່ MarkupCraft ເປີດ ແລະ ບັນທຶກ](topic:files#where-downloads-go)).

## ສືບຕໍ່ເຮັດວຽກໃນພາຍຫຼັງ

ເປີດສຳເນົາ "(marked up)" ຄັ້ງຕໍ່ໄປ, ບໍ່ແມ່ນໄຟລ໌ຕົ້ນສະບັບ. ທຸກຢ່າງຈະກັບມາແກ້ໄຂໄດ້: ການໝາຍ, ສະຖານະ, ຄຳຕອບ, ລາຍການ punch, ມາດຕາສ່ວນຂອງແຕ່ລະແຜ່ນ ແລະ ຊື່ແຜ່ນທີ່ທ່ານພິມໄວ້. ເມື່ອບັນທຶກອີກຄັ້ງ ຈະດາວໂຫຼດໄຟລ໌ທີ່ມີຊື່ "(marked up)" ດຽວກັນ; ເບຣາວເຊີອາດເພີ່ມເລກເຊັ່ນ "(1)" ຖ້າດາວໂຫຼດເກົ່າຍັງຢູ່ໃນໂຟນເດີ. ທ່ານຕ້ອງແທນທີ່ ຫຼື ເກັບກວາດສຳເນົາເກົ່າເອງ.

MarkupCraft ບໍ່ບັນທຶກ PDF ໃຫ້ເອງ. ໃນຂະນະທີ່ທ່ານເຮັດວຽກ ມັນເກັບສຳເນົາກູ້ຄືນໄວ້ໃນເບຣາວເຊີນີ້, ສະນັ້ນຖ້າເກີດຂໍ້ຜິດພາດ ຫຼື ປິດແທັບ ການໝາຍຂອງທ່ານຈະບໍ່ຫາຍ: ຄັ້ງຕໍ່ໄປທີ່ເປີດ MarkupCraft ມັນຈະຖາມວ່າ "ກູ້ຄືນວຽກຂອງທ່ານບໍ?". ເບິ່ງ [ກູ້ຄືນວຽກຂອງທ່ານ](common:recover). ຢ່າງໃດກໍຕາມ ໃຫ້ບັນທຶກກ່ອນປິດ; ຖ້າທ່ານພະຍາຍາມອອກໂດຍມີການໝາຍທີ່ຍັງບໍ່ໄດ້ບັນທຶກ ເບຣາວເຊີຈະຖາມ "ອອກຈາກເວັບໄຊທ໌?" ກ່ອນ (iPad Safari ບໍ່ຖາມ).

## ໂປຣແກຣມອ່ານ PDF ອື່ນເຫັນຫຍັງ

ທຸກການໝາຍຖືກຂຽນເປັນຄຳເຫັນ PDF ມາດຕະຖານ (annotation) ພ້ອມກັບການແຕ້ມຂອງມັນເອງ, ສະນັ້ນໂປຣແກຣມເບິ່ງ PDF ໃດກໍສະແດງ, ພິມ ແລະ ລາຍຊື່ມັນໃນແຜງຄຳເຫັນໄດ້:

- **ໜ້າຕາຄືເດີມ** ກັບໃນ MarkupCraft: ເມກທີ່ມີຂອບໂຄ້ງ, ຫົວລູກສອນ, ຕາປະທັບ, ຈຸດນັບ, ປ້າຍເລກ punch, ປ້າຍວັດແທກ.
- **ລາຍລະອຽດເປັນມາດຕະຖານ:** ຜູ້ຂຽນ, ວັນທີ, ຫົວຂໍ້, ຂໍ້ຄວາມຄຳເຫັນ ແລະ ສີ.
- **ເມກ** ເປັນຄຳເຫັນສີ່ຫຼ່ຽມ ຫຼື ຫຼາຍແຈ ທີ່ມີຂອບເປັນເມກ; **ກ່ອງຂໍ້ຄວາມ** ແລະ **ເຄື່ອງໝາຍອ້າງອີງ** ເປັນຄຳເຫັນກ່ອງຂໍ້ຄວາມ; **ໝາຍເຫດ** ເປັນໂນດຕິດ; ເສັ້ນປາກກາ ແລະ ປາກກາໄຮໄລທ໌ ເປັນ ink; **ຕາປະທັບ** ເປັນຄຳເຫັນຕາປະທັບ.
- **ຄວາມຍາວ ແລະ ເນື້ອທີ່** ເປັນຄຳເຫັນການວັດແທກ, ແລະ ແຕ່ລະແຜ່ນທີ່ປັບມາດຕະຖານຈະມີມາດຕະຖານສ່ວນຂອງມັນ, ສະນັ້ນໂປຣແກຣມທີ່ເຂົ້າໃຈການວັດແທກສາມາດສະແດງຄ່າໄດ້.
- **ການຕອບກັບ** ເປັນຄຳຕອບຕໍ່ຄຳເຫັນ, ແລະ **ສະຖານະ** ເປັນສະພາບການກວດ (Open ສະແດງເປັນບໍ່ມີສະຖານະ).
- **ເລກແຜ່ນ** ທີ່ທ່ານພິມໄວ້ຈະກາຍເປັນປ້າຍໜ້າທີ່ໂປຣແກຣມອື່ນສະແດງ.

ມີບາງຢ່າງທີ່ມີແຕ່ MarkupCraft ອ່ານກັບຄືນໄດ້: ຜູ້ຮັບມອບໝາຍ ແລະ ວັນກຳນົດຂອງລາຍການ punch, ສະຖານະລາຍການ ແລະ ລາຍລະອຽດຮູບແບບບາງຢ່າງ. ໂປຣແກຣມອື່ນຈະເກັບໄວ້ ເວັ້ນແຕ່ມັນຂຽນຄຳເຫັນໃໝ່.

ໃນໂປຣແກຣມອື່ນ, ຄຳເຫັນສາມາດຍ້າຍ ຫຼື ແກ້ໄຂໄດ້ເໝືອນທົ່ວໄປ. ຖ້າມີຄົນເຮັດແບບນັ້ນ ແລະ ສົ່ງໄຟລ໌ກັບມາ, MarkupCraft ຈະໃຊ້ຕຳແໜ່ງໃໝ່ຂອງຄຳເຫັນເມື່ອເປີດໄຟລ໌.

ລາຍລະອຽດເຕັມ: [ສິ່ງທີ່ຖືກເກັບໄວ້ໃນ PDF](topic:what-the-pdf-keeps).

## ຕົວອັກສອນທີ່ພິມອອກເປັນ "?"

ຂໍ້ຄວາມການໝາຍຖືກຂຽນດ້ວຍຟອນ Helvetica ມາດຕະຖານທີ່ທຸກໂປຣແກຣມເບິ່ງ PDF ມີ. ມັນຄອບຄຸມຕົວອັກສອນອັງກິດ ແລະ ເອີຣົບຕາເວັນຕົກ (é, ñ, ü, ø ແລະ ອື່ນໆ), ແຕ່ບໍ່ຄອບຄຸມລະບົບອັກສອນອື່ນ, ສັນຍາລັກນອກຊຸດນີ້ ຫຼື ອີໂມຈິ. ຕົວອັກສອນເຫຼົ່ານັ້ນສະແດງໄດ້ດີໃນ MarkupCraft ແຕ່ຈະພິມເປັນ "?" ໃນສຳເນົາທີ່ບັນທຶກ, ແລະ ຂໍ້ຄວາມບັນທຶກຈະນັບໃຫ້: "3 characters outside the Western European set print as "?" in the copy." ໃຫ້ສະກົດຄຳເຫຼົ່ານັ້ນອອກເປັນຄຳເຕັມ ຫຼື ໃຊ້ຄຳທົດແທນທີ່ງ່າຍ (ເຊັ່ນ "dia." ແທນສັນຍາລັກເສັ້ນຜ່າສູນກາງ).

## ໄຟລ໌ທີ່ບັນທຶກບໍ່ໄດ້

- **PDF ທີ່ມີການປ້ອງກັນ:** "This PDF is protected (encrypted), so a marked-up copy cannot be written. Ask for an unprotected copy." ທ່ານຍັງສາມາດກວດເບິ່ງໃນໜ້າຈໍໄດ້, ສົ່ງອອກ CSV ແລະ BCF ໄດ້.
- ຖ້າການບັນທຶກລົ້ມເຫຼວດ້ວຍເຫດຜົນອື່ນ, ກ່ອງ "Could not save <file>" ຈະສະແດງເຫດຜົນ. ການໝາຍຂອງທ່ານຍັງຢູ່ໃນແທັບ; ຈະບໍ່ມີຫຍັງຫາຍຈົນກວ່າທ່ານຈະປິດແທັບນັ້ນ.

## ການລວມເຂົ້າໃນໜ້າ ແລະ ການພິມ

ຍັງບໍ່ມີການລວມເຂົ້າໃນໜ້າ (ການເຜົາການໝາຍລົງໃນໜ້າ) ແລະ ຍັງບໍ່ມີຄຳສັ່ງພິມ. ເພື່ອພິມ, ໃຫ້ເປີດສຳເນົາທີ່ບັນທຶກໃນໂປຣແກຣມເບິ່ງ PDF ໃດກໍໄດ້ ແລ້ວພິມໂດຍໃຫ້ແສດງຄຳເຫັນ.
