ສອງຄົນໝາຍ PDF ດຽວກັນໃນສອງສຳເນົາ. ຖ້າພວກເຂົາແຕະຕ້ອງການໝາຍຕ່າງກັນ, ສຳເນົາທັງສອງສາມາດລວມໂດຍໂປຣແກຣມແທນທີ່ຈະລວມດ້ວຍມື.

## ສິ່ງທີ່ເຮັດໃຫ້ມັນເຮັດວຽກ

ທຸກການໝາຍທີ່ MarkupCraft ບັນທຶກມີຊື່ຂອງມັນເອງ (id ຂອງມັນ) ຢູ່ໃນ PDF, ແລະ ຊື່ນັ້ນບໍ່ປ່ຽນ. ການລວມຈະຊອກການໝາຍດ້ວຍຊື່ນັ້ນ, ບໍ່ແມ່ນຕາມຕຳແໜ່ງໃນໄຟລ໌, ເພາະທຸກໂປຣແກຣມຈະນັບໝາຍເລກຕຳແໜ່ງໃໝ່ເມື່ອມັນບັນທຶກ. ໝາຍເຫດ ແລະ ໝາຍເຫດສ່ວນຕົວທີ່ຖືກປິດໄວ້ກໍຖືກຈັບຄູ່ດ້ວຍວິທີດຽວກັນ.

ແຜ່ນຈະບໍ່ຖືກແຕະຕ້ອງ: ສຳເນົາທັງສອງຕ້ອງມີຈຳນວນໜ້າເທົ່າກັນ. ຖ້າມັນແຕກຕ່າງກັນ, ການລວມຈະຮັກສາສຳເນົາຂອງທ່ານໄວ້ຕາມເດີມ ແລະ ແຈ້ງໃຫ້ຮູ້, ເພາະການເພີ່ມ ຫຼື ລຶບໜ້າເປັນວຽກຂອງຄົນ.

## ຕັ້ງຄ່າ

Git ຕ້ອງການສອງບັນທັດໜຶ່ງຄັ້ງຕໍ່ repository:

```
# .gitattributes
*.pdf merge=cadcraft

# ເທື່ອດຽວ, ໃນແຕ່ລະຄອມພິວເຕີ
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

ຖ້າບໍ່ໃຊ້ git, ໃຫ້ແລ່ນ `cadcraft merge <base> <ours> <theirs> -o <result>`. Fossil ແລະ Mercurial ໃຊ້ໄຟລ໌ສາມອັນດຽວກັນໃນການຕັ້ງຄ່າເຄື່ອງມືລວມຂອງພວກມັນເອງ. ໄຟລ໌ວຽກທີ່ມາກັບແບບແຕ້ມ (`<name>.markups.json`, ເບິ່ງ [ການໝາຍທີ່ເຮັດວຽກ](topic:markups-that-act)) ຖືກລວມຄືກັນ, ເປັນຂໍ້ຄວາມທຳມະດາ.

## ກົດ

- ການໝາຍທີ່ປ່ຽນແປງພຽງດ້ານໜຶ່ງຈະຖືກເອົາ. ການປ່ຽນແປງດຽວກັນທັງສອງດ້ານຖືກເອົາພຽງຄັ້ງດຽວ.
- ການໝາຍດຽວກັນທີ່ປ່ຽນແປງສອງທາງຄືເກີດ **ຂັດແຍ້ງ**: ດ້ານຂອງທ່ານຈະຢູ່ຕໍ່ໄປ ແລະ ລາຍງານຈະລະບຸທັງສອງດ້ານ. ເປີດຜົນລວມ ແລ້ວແກ້ການໝາຍນັ້ນດ້ວຍມື.
- ການໝາຍທີ່ເພີ່ມໃສ່ດ້ານໃດກໍໄດ້ຈະຖືກເກັບໄວ້. ອັນທີ່ຖືກລຶບໃນດ້ານໜຶ່ງ ແລະ ບໍ່ຖືກແຕະຕ້ອງອີກດ້ານ ຈະຖືກລຶບ. ຖືກລຶບດ້ານໜຶ່ງ ແລະ ຖືກປ່ຽນແປງອີກດ້ານ: ຖືກລຶບ ແລະ ລາຍງານ.
- ເລເຢີ, ຖັນ, ບັນທຶກ ແລະ ໝາຍເຫດ ປະຕິບັດຕາມກົດດຽວກັນ.
- ໝາຍເຫດສ່ວນຕົວທີ່ຖືກປິດໄວ້ຈະບໍ່ຖືກເປີດເລີຍ: ບລັອກຂອງທັງສອງດ້ານຈະຖືກເກັບໄວ້ຕາມເດີມ.

ໄຟລ໌ທີ່ລວມແລ້ວແມ່ນການຂຽນທັບທັງໝົດຂອງສຳເນົາຂອງທ່ານ, ເໝືອນການບັນທຶກຂອງ MarkupCraft ເອງ. ບໍ່ມີຫຍັງຖືກອັບໂຫຼດ; ທຸກຢ່າງເຮັດວຽກຢູ່ໃນຄອມພິວເຕີຂອງທ່ານ.
