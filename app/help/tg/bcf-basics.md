BCF (Формати ҳамкории BIM) як формати кушодаи файл барои интиқоли масъалаҳо байни абзорҳои BIM аст. Бисёре аз барномаҳои ҳамоҳангсозии модел ва муаллифӣ метавонанд файли `.bcfzip`-ро ҳамчун рӯйхати масъалаҳо ворид кунанд. MarkupCraft **BCF 2.1** менависад.

## Эҷод кардан

1. Варақаи {{ui:Қайдҳо}}-ро кушоед.
2. Рӯйхатро ба он чизе, ки мехоҳед фиристед, филтр кунед, масалан {{ui:Ҳолат}} «Кушода». Танҳо қайдҳои дар рӯйхат будаашон содир мешаванд.
3. {{ui:BCF}}-ро интихоб кунед.
4. Сабр кунед, то аз ҳар қайд сурати лаҳзавӣ гирифта шавад («Сурати лаҳзавӣ барои BCF сохта мешавад (5 аз 20)…»).

Натиҷа: «<name> markups.bcfzip» зеркашӣ мешавад ва дар сатри ҳолат шумораи мавзӯъҳо ва андозаи файл навишта мешавад.

## Дар он чӣ ҳаст

Ҳар қайд як **мавзӯъ** мешавад:

| Майдони мавзӯъ | Бо чӣ пур мешавад |
|---|---|
| Сарлавҳа | Рақами камбудӣ, мавзӯъ ва варақ, масалан «#4 Абр дар A-101 — Плани фарш» |
| Намуд | Намуди қайд (Абр, Ишорат, Дарозӣ…) |
| Ҳолат | Кушода, Қабул шуда, Рад шуда ё Анҷом ёфта |
| Нишонаҳо | Намуди қайд ва варақ |
| Муаллиф ва санаҳо | Муаллифи қайд, санаҳои эҷод ва тағйирёбӣ |
| Ба кӣ супорида шудааст, мӯҳлат | Аз банди рӯйхати камбудиҳо, вақте ки дорад |
| Тавсиф | Матн ё матни мӯҳр, арзиши ченкардашуда, шарҳ, варақ ва файл |
| Шарҳҳо | Як шарҳ барои ҳар ҷавоб, бо муаллиф ва сана |
| Сурати лаҳзавӣ | Тасвири қайд дар қисми варақи худ |
| Намуд | Манзараи болоӣ аз ҷойи қайд дар варақ |

Содироти дубораи ҳамон қайд ҳамон ID-и мавзӯъро медиҳад, аз ин рӯ абзоре, ки BCF-ро ворид мекунад, онро ҳамчун ҳамон масъала эътироф мекунад.

## Маҳдудиятҳо

- **Варақ модел нест.** Намуд ба ҷойи қайд дар коғази варақ ишора мекунад ва бо метри коғаз чен карда мешавад. Ин абзори BIM-ро ба ҷойе дар модел намебарад. Барои ёфтани ҷой сурати лаҳзавӣ ва номи варақро истифода баред.
- **Ҳолатҳо ва намудҳо ҳамон MarkupCraft-анд** (Кушода, Қабул шуда, Рад шуда, Анҷом ёфта; Абр, Ишорат…). Файл онҳоро эълон мекунад, тавре ки BCF иҷозат медиҳад, аммо абзоре, ки рӯйхатҳои собити худро дорад, метавонад онҳоро мувофиқ кунад ё нодида гирад.
- **Ворид кардан шарҳҳоро меорад, на намуди модел.** {{ui:BCF ворид кардан}} ҷавобҳо ва ҳолатҳоро ба қайдҳои содиршуда илова мекунад ва дигар масъалаҳоро ҳамчун ёддошт сабт мекунад; он камераи моделро нишон дода наметавонад. Ба [Рӯйхати қайдҳо ва содирот](topic:markups-list-and-export#import-bcf) нигаред.
- Барои баррасии нақшаҳо фиристодани қайдҳо ҳамчун PDF аксар вақт осонтар аст. BCF барои ворид кардани шарҳҳои нақша ба ҷараёни ҳамоҳангсозии модел хизмат мекунад.
