BCF (BIM Collaboration Format) формати кушодаи файл барои интиқоли масъалаҳо миёни абзорҳои BIM аст. Бисёре аз барномаҳои ҳамоҳангсозӣ ва муаллифии модел метавонанд файли `.bcfzip`-ро ҳамчун рӯйхати масъалаҳо ворид кунанд. MarkupCraft **BCF 2.1** менависад.

## Сохтани файл

1. Варақаи «{{ui:Markups}}»-ро кушоед.
2. Рӯйхатро барои он чизе, ки мехоҳед фиристед, филтр кунед, масалан {{ui:Status}} «Кушода». Танҳо қайдҳои дар рӯйхат будаашон содир мешаванд.
3. «{{ui:BCF}}»-ро интихоб кунед.
4. То он ки аз ҳар қайд сурат гирифта шавад, интизор шавед («Making snapshots for BCF (5 of 20)…»).

Натиҷа: «<name> markups.bcfzip» зеркашӣ мешавад ва рӯйхати ҳолат шумораи мавзӯъҳо ва андозаи файлро нишон медиҳад.

## Дар он чӣ ҳаст

Ҳар қайд як **мавзӯъ** мешавад:

| Майдони мавзӯъ | Пур мешавад бо |
|---|---|
| Унвон | Рақами банд, мавзӯъ ва варақ, масалан «#4 Абр дар A-101 — Нақшаи фарш» |
| Намуд | Навъи қайд (Абр, Ишора, Дарозӣ…) |
| Ҳолат | Кушода, Қабул шуда, Рад шуда ё Анҷомёфта |
| Нишонаҳо | Навъи қайд ва варақ |
| Муаллиф ва санаҳо | Муаллифи қайд, санаҳои сохта ва тағйирёфтааш |
| Супоридашуда ба, санаи муҳлат | Аз банди пайгирии он, агар дошта бошад |
| Тавсиф | Матн ё мазмуни муҳр, арзиши ченшуда, шарҳ, варақ ва файл |
| Шарҳҳо | Ҳар посух бо муаллиф ва сана |
| Сурат | Тасвири қайд дар қисми варақаш |
| Нуқтаи дид | Намуди болоӣ аз ҷойи қайд дар варақ |

Содироти дубораи ҳамон қайд ҳамон ID-и мавзӯъро медиҳад, то абзори BCF-воридкунанда онро ҳамчун ҳамон масъала эътироф кунад.

## Чӣ ҳангоми ворид кардан бармегардад

«{{ui:Import BCF}}» файлҳои BCF 2.0, 2.1 ва 3.0-ро мехонад (санҷида дар 19 файли расмии озмоишии buildingSMART 3.0: ҳар мавзӯъ хонда шуд ва шарҳҳои се файле, ки матн доранд). Барои мавзӯъе, ки аз они шумост (ҳамон ID-и мавзӯъ), шарҳҳои нав ҳамчун посух илова мешаванд ва ҳолати нав гирифта мешавад. Ҳар мавзӯъи дигар ёддошт дар варақе мешавад, ки нишона ё номи файлаш ишора мекунад, ё дар варақи кушода, бо унвон, тавсиф, масъул ва санаи муҳлат ҳамчун матни ёддошт ва шарҳҳояш ҳамчун посух.

| Дар мавзӯи BCF | Дар MarkupCraft |
|---|---|
| Унвон, тавсиф, масъул, санаи муҳлат | Матни ёддошт |
| Шарҳҳои матндор | Посухҳо |
| Ҳолати Open, Accepted, Rejected, Completed (Closed, Resolved, Done ҳамчун Completed ҳисоб мешаванд) | Ҳолати қайд |
| Муаллиф ва санаи сохтан | Муаллиф ва сана барои ёддошт |
| Ҷойгиршавии камера | Ҷой дар варақ, танҳо барои мавзӯе, ки бо нишона ё номи файл ба варақ пайваст аст |
| Интихоби модел, қисмҳои пинҳоншуда, садаҳои бурида, суратҳо | Нигоҳ дошта намешаванд: варақ модели нишон додан надорад |

## Маҳдудиятҳои муҳим

- **Варақ модел нест.** Нуқтаи дид ба ҷойи қайд дар коғаз ишора мекунад ва бо миллиметри коғаз чен карда мешавад. Абзори BIM ба ҷойи дар модел бурда наметавонад. Барои ёфтани ҷой аз сурат ва номи варақ истифода баред.
- **Ҳолатҳо ва намудҳо худи MarkupCraft-анд** (Кушода, Қабул шуда, Рад шуда, Анҷомёфта; Абр, Ишора…). Файл онҳоро ҳамчун BCF иҷозат медиҳад эълон мекунад, аммо абзори бо рӯйхатҳои пурраи худаш метавонад онҳоро мутобиқ кунад ё нодида гирад.
- **Ворид кардан шарҳҳоро меоварад, на намуди моделро.** «{{ui:Import BCF}}» посухҳо ва ҳолатҳоро ба қайдҳое, ки содир кардаед, илова мекунад ва дигар масъалаҳоро ёддошт месозад; камераи моделро нишон дода наметавонад. Ниг. [Рӯйхати қайдҳо ва содирот](topic:markups-list-and-export#import-bcf).
- Барои баррасии нақшаҳо фиристодани қайдҳо ҳамчун PDF одатан осонтар аст. BCF барои ворид кардани шарҳҳои нақша ба ҷараёни ҳамоҳангсозии модел хизмат мекунад.
