Нусхаи қайдгузоришуда PDF-и аслӣ аст, ки бо шарҳҳо (аннотатсияҳои PDF) илова шудааст. Саҳифаҳо, нақшаҳои онҳо, матн, ишорабандҳо ва пайвандҳо мисли пештара нусха бардошта мешаванд.

## Ҳар қайд

| MarkupCraft | Ҳамчун захира мешавад | Дигар бинандаҳои PDF нишон медиҳанд |
|---|---|---|
| Росткунҷа, абри қуттӣ | Аннотатсияи Square (абр: ҳошияи абрнок) | Шарҳи росткунҷа ё абр |
| Эллипс | Аннотатсияи Circle | Шарҳи эллипс |
| Бисёркунҷа, абри озод | Аннотатсияи Polygon (абр: ҳошияи абрнок) | Шарҳи бисёркунҷа ё абр |
| Полихат | Аннотатсияи PolyLine | Шарҳи полихат |
| Хат, тир | Аннотатсияи Line (тир: нӯги баста) | Шарҳи хат ё тир |
| Дарозӣ | Аннотатсияи Line ҳамчун андоза, бо ченак | Ченаки дарозӣ, дар ҷое ки бинанда дастгирӣ мекунад |
| Масоҳат | Аннотатсияи Polygon ҳамчун масоҳат, бо ченак | Ченаки масоҳат, дар ҷое ки дастгирӣ мешавад; вагарна бисёркунҷа |
| Гурӯҳи шумора | Як аннотатсияи Ink, ҳалқа барои ҳар ашё; матнаш «group: n» | Шарҳи Ink |
| Қалам, маркер | Аннотатсияи Ink (маркер ҳамчун маркер қайд шудааст) | Шарҳи Ink |
| Матн | Аннотатсияи FreeText | Шарҳи қуттии матн |
| Выноска | Аннотатсияи FreeText бо хатчаи выноска | Шарҳи выноска |
| Ёддошт | Аннотатсияи Text | Ёддошти часпанак, ки бо матнаш кушода мешавад |
| Мӯҳр | Аннотатсияи Stamp | Шарҳи мӯҳр |

Ҳар кадом бо инҳо захира мешавад:

- **намуди худаш**, ки мисли дар экран MarkupCraft кашида мешавад, аз ин рӯ дар ҳар бинанда ҳамин тавр менамояд ва ҳамин тавр чоп мешавад, бо нишони рақами punch;
- **муаллиф**, **санаҳои эҷод ва тағйирёбӣ**, **мавзӯъ**, **матни шарҳ** (барои қуттиҳои матн ва выноскаҳо матн ва шарҳ), **ранг** ва **шаффофӣ**;
- **ҷузъиёти MarkupCraft** дар қайди хусусӣ, ки барномаҳои дигар нодида мегиранд: ҳолат, ашёи punch, сабк ва навъ, то ки дақиқан дубора кушода шавад.

## Ришта ва ҳолатҳо

- Ҳар ҷавоб ҳамчун шарҳи ҷавоб, ки ба қайди худ пайваст аст, бо муаллиф, сана ва матн захира мешавад. Ҷавобҳо дар варақ нишони худро надоранд.
- Ҳар тағйири ҳолат ҳамчун ҷавоб бо ҳолати баррасӣ захира мешавад. Дигар абзорҳои баррасӣ онро ҳамчун Қабул шуд, Рад шуд ё Анҷом ёфт нишон медиҳанд; Кушода ҳамчун ҳолати холӣ захира мешавад.
- Қайде, ки ҳолаташ ғайр аз Кушода аст, вале ягон тағйири ҳолат сабт нашудааст, як ҷавоби ҳолати баррасӣ мегирад, то барномаҳои дигар ҳолатро низ бубинанд.
- Ҷавобҳо ба шарҳҳои танҳоихон аз файли аслӣ ҳамин тавр захира мешаванд, ба он шарҳ пайваста.

## Ҳар варақ

- **Миқёс:** варақи калибршуда як вьюпорти ченкунӣ мегирад, ки саҳифаро фаро мегирад (роҳи стандартии захираи миқёси саҳифа) ва нусхаи худи MarkupCraft-и калибровка.
- **Рақами варақ:** рақаме, ки бо {{ui:Rename sheet}} навишта шудааст, нишони саҳифа мешавад. Вақте ки ягон саҳифаи файл нишон дорад, ҳар саҳифаи он файл нишон мегирад: рақами навиштаашро, агар набошад нишони кӯҳнаашро, ва агар ин ҳам набошад рақами саҳифаро.
- **Унвони варақ:** унвони навишташуда танҳо барои MarkupCraft захира мешавад; дигар бинандаҳо онро нишон намедиҳанд.

## Матн ва аломатҳо

Матн бо Helvetica навишта мешавад, ки ҳар бинандаи PDF дорад. Ҳарфҳое, ки аз маҷмӯаи Аврупои Ғарбӣ (Windows-1252) берунанд, дар нусха ҳамчун «?» чоп мешаванд; паёми захира онҳоро шумора мекунад.

## Варақҳои ҳисоб ва сабабҳо

Варақҳои ҳисоб ва сабабҳо дар ҷузъи хусусии PDF бо номи `/MarkupCraftShell` нигоҳ дошта мешаванд. Барномаҳои дигари PDF онро нодида мегиранд. MarkupCraft-и кӯҳна низ онро нодида мегирад ва вақти дигар захира кардани он файл онро мепартояд.

## Шарҳҳое, ки аллакай буданд

Вақте ки PDF-е бо шарҳҳо кушода мешавад:

- Шарҳҳои худи MarkupCraft дақиқан хонда мешаванд. Агар барномаи дигар онро ҷойиваз ё андоза карда бошад, ҷойи нави он ғолиб аст.
- Росткунҷаҳо, эллипсҳо, хатҳо, полихатҳо, бисёркунҷаҳо, Ink, қуттиҳои матн ва ёддоштҳои часпанак аз барномаҳои дигар қайдҳои таҳриршаванда мешаванд. **Ҳангоми захира, MarkupCraft аслҳоро нест мекунад ва онҳоро бо роҳи худаш аз нав менависад**, бо поп-апҳо ва ҷавобҳояшон. Намуди онҳо каме тағйир ёфта метавонад.
- Ҳолатҳои баррасӣ аз барномаҳои дигар ҳолатро муқаррар мекунанд; охиринаш ғолиб аст.
- Ҳама чизи дигар (ҷудокунии матн, мӯҳрҳои барномаҳои дигар ва навъҳои махсус) **дастнаӯзар** дар нусха, танҳоихон нигоҳ дошта мешавад.
- Пайвандҳо ва майдонҳои форма дастнаӯзар нигоҳ дошта мешаванд ва рӯйхат намешаванд.

Захираи дубораи ҳамон файл ҳеҷ чизро дучанд намекунад: қайдҳое, ки MarkupCraft хондааст, иваз мешаванд, илова намешаванд.

## Чӣ тағйир намеёбад

Файли аслии шумо дар диск ҳеҷ гоҳ тағйир намеёбад. Нусха барои андоза оптимизатсия нашудааст, аз ин рӯ метавонад аз аслӣ каме калонтар бошад. PDF-и муҳофизатшуда (рамзгузоришуда) захира карда намешавад.
