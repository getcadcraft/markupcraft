Ду нафар як PDF-ро дар ду нусха қайд мекунанд. Агар онҳо қайдҳои гуногунро таҳрир карда бошанд, нусхаҳоро метавон барнома якҷо кунад, на бо дасти худ.

## Чӣ онро кор мекунад

Ҳар қайде, ки MarkupCraft захира мекунад, номи худро (идентификатори худ) дар дохили PDF дорад ва ин ном ҳеҷ гоҳ тағйир намеёбад. Якҷоякунӣ қайдҳоро бо ҳамин ном меёбад, на бо ҷойгиршавиашон дар файл, зеро ҳар барнома ҳангоми захира ҷойҳоро аз нав рақамгузорӣ мекунад. Ёддоштҳо ва ёддоштҳои хусусии мӯҳршуда низ ҳамин тавр мувофиқ карда мешаванд.

Варақҳо ҳеҷ гоҳ даст намехӯранд: ҳарду нусха бояд ба ҳамин шумораи саҳифа дошта бошанд. Агар фарқ кунанд, якҷоякунӣ нусхаи шуморо ҳамон тавр нигоҳ медорад ва инро мегӯяд, зеро илова ё хориҷ кардани саҳифаҳо кори инсон аст.

## Танзим кунед

Git ду сатрро як бор барои ҳар анбор лозим дорад:

```
# .gitattributes
*.pdf merge=cadcraft

# one time, on each computer
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Бе git, `cadcraft merge <base> <ours> <theirs> -o <result>`-ро иҷро кунед. Fossil ва Mercurial ҳамин се файлро дар танзимоти абзори якҷоякунии худашон қабул мекунанд. Файли вазифае, ки бо нақша меояд (`<name>.markups.json`, нигаред ба [Қайдҳои амалкунанда](topic:markups-that-act)), ҳамин тавр ҳамчун матни оддӣ якҷо мешавад.

## Қоидаҳо

- Қайде, ки танҳо дар як тараф тағйир ёфтааст, гирифта мешавад. Ҳамон тағйир дар ҳарду тараф як бор гирифта мешавад.
- Ҳамон қайд ду роҳ тағйир ёфтааст — ин **низоъ** аст: тарафи шумо мемонад ва гузориш ҳарду тарафро номбар мекунад. Натиҷаро кушоед ва он қайдро бо дасти худ дуруст кунед.
- Қайде, ки дар як тараф илова шудааст, нигоҳ дошта мешавад. Қайде, ки дар як тараф нест шуда ва дар тарафи дигар тағйир наёфтааст, нест карда мешавад. Дар як тараф нест шуда ва дар тарафи дигар тағйир ёфта: нест карда мешавад ва гузориш дода мешавад.
- Қабатҳо, сутунҳо, сабтҳо ва ёддоштҳо ҳамин қоидаҳоро пайравӣ мекунанд.
- Ёддоштҳои хусусии мӯҳршуда ҳеҷ гоҳ кушода намешаванд: блокҳои ҳарду тараф ҳамон тавр нигоҳ дошта мешаванд.

Файли якҷоишуда бознависии пурраи нусхаи шумо аст, мисли Захиракунии худи MarkupCraft. Ҳеҷ чиз боргузорӣ намешавад; ҳама дар компютери шумо анҷом меёбад.
