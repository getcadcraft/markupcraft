MarkupCraft дар ҳоли таҳия аст. Ин он чизест, ки нусхаи ҷорӣ **наметавонад** иҷро кунад, то шумо барномарезӣ карда тавонед. Он нусхаи имрӯзаро тавсиф мекунад, на ваъдаҳоро.

## Кор бо дигарон

| Ҳанӯз сохта нашудааст | Имрӯз ин корро кунед |
|---|---|
| Захираи абрӣ ва ҳамоҳангсозӣ байни компютерҳо | Файлҳои PDF-ро бо файлҳои лоиҳаи худ нигоҳ доред. Захираи абрӣ ҳанӯз дастрас нест. |
| Якҷоя кардани нусхаҳои қайдгузориҳои ду нафар | Варақҳоро байни санҷандагон тақсим кунед, ё чанд қайдгузориро бо {{key:Mod+C}} ва {{key:Mod+V}} нусхабардорӣ кунед. RFI, аризаҳо ва рӯзномаҳои рӯзона якҷоя мешаванд: нигаред ба [Пайгирии RFI, аризаҳо ва рӯзномаҳои рӯзона](topic:field-records). |
| Дастаҳо, огоҳиномаҳо ва лоиҳаҳои абрӣ барои RFI ва аризаҳо | Файлро фиристед ва барои якҷоя кардани нусхаҳо {{ui:Якҷоя кардан}}-ро истифода баред. |
| RFI, аризаҳо ва рӯзномаҳои рӯзона дар сессияи зинда | Ҳар кас бо нусхаи худаш кор мекунад; нусхаҳоро бо {{ui:Якҷоя кардан}} якҷоя кунед. |
| Якҷоя кардани тағйироти ду нафар дар майдонҳои гуногуни як сабт | Нусхаи охирин тағйирёфта сабти пурраро ба худ мегирад (ришта ва номи замимаҳо якҷоя мешаванд). Пешакӣ мувофиқа кунед, ки кадом сабтро кӣ таҳрир мекунад. |
| Ҳамроҳони ёрдамчӣ барои RFI, аризаҳо ва рӯзномаҳои рӯзона | Бо онҳо дар забонаи {{ui:Майдон}} кор кунед. Ёрдамчиҳо бо қайдгузориҳо кор карда метавонанд: нигаред ба [Истифодаи MarkupCraft бо ёрдамчии AI](topic:use-with-ai-assistants). |
| Таҳрир ё нест кардани посух пас аз фиристодан | Фавран {{ui:Баргардондан}} кунед, ё посухи тасҳеҳкунанда илова кунед. |
| Тағйир додани муаллифи қайдгузорӣ | Пеш аз оғоз номи худро гузоред. |

## Қайдгузорӣ

| Ҳанӯз сохта нашудааст | Имрӯз ин корро кунед |
|---|---|
| Мӯҳрҳо бо майдонҳои пуркунӣ, имзоҳои рақамии тасдиқшуда | Мӯҳри матни фармоишӣ истифода баред, ки номи шумо ва санаро дар худ дорад, ё тасвири имзои худро. |
| Замимаи файлҳо ғайр аз акс (ҳуҷҷатҳо, видеоҳо) | Онҳоро дар паҳлӯи PDF нигоҳ доред ва дар шарҳ ба онҳо ишора кунед. |
| Пайвандҳо ба вебсайтҳо ё ба файлҳое, ки кушода нестанд | Суроға ё номи файлро дар шарҳ нависед. |
| Маҷмӯаҳои фармоишии ҳолат | Чор ҳолатро истифода баред, ва барои ҳар чизи бештар мавзӯъро. |
| Таҳрири шарҳҳое, ки бо файл омадаанд ва танҳо хондан доранд (нишондиҳии матн, мӯҳрҳои барномаҳои дигар) | Ба онҳо посух диҳед, ё дар паҳлӯи онҳо қайдгузории MarkupCraft кашед. |
| Хатҳои қалами ҳассос ба фишор | Паҳнои хатро танзим кунед. |

## Мундариҷаи худи саҳифа

| Ҳанӯз сохта нашудааст | Имрӯз ин корро кунед |
|---|---|
| Кашидани шаклҳои нав мустақим ба саҳифа | Онҳоро ҳамчун қайдгузорӣ кашед, сипас {{ui:Ба саҳифа гузоштан}}. Нигаред ба [Тағйир додани мундариҷаи худи саҳифа](topic:page-content). |
| Чарх задани объектҳои саҳифа ба ҳар кунҷ | Онҳоро кӯчонед ва андоза кунед; тамоми саҳифаро бо {{ui:Саҳифаҳо}} чарх занед. |
| Тағйир додани хат ва андозаи матни як сатр, ё матне, ки дар чанд сатр ҷорӣ мешавад | Калимаҳоро як сатр дар як вақт тағйир диҳед; барои калимаҳои нав бо хати дигар, қайдгузории матн илова кунед. |
| Таҳрири мундариҷаи тасвири сканшуда | Тасвирро иваз кунед ё қайд гузоред. |
| Таҳрири PDF-и рамзгузоришуда ё имзошуда | Нусхаи бе имзо пурсед; қайдгузориҳо дар ҳар PDF кор мекунанд. |

## Чен кардан

| Ҳанӯз сохта нашудааст | Имрӯз ин корро кунед |
|---|---|
| Ченкунии радиус | Дар бораи он {{ui:Камон}} кашед, ё диаметрро бо {{ui:Дарозӣ}} чен кунед ва ба ду тақсим кунед. |
| Таҳрири кунҷҳои бурида | Бурришҳоро хориҷ кунед ва дубора кашед. |
| Татбиқи як миқёс ба якчанд варақ якбора | Ҳар варақро {{ui:Калибровка}} кунед; интихоби пешфарз ҳар варақ тақрибан чанд сония мегирад. |
| Чанд миқёс дар як варақ (паноҳои намоиш) | Ба нақшае калибровка кунед, ки бештар чен мекунед. Тағйири миқёси варақ ҳамаи ченкуниҳои онро аз нав мекунад, бинобар ин пеш аз калибровкаи нав қиматҳои тафсилотро нависед. |
| Ба хатҳои нақша часпидан | Пеш аз клик калонтар кунед, ё дарозиҳо ва кунҷҳоро нависед (нигаред ба [Эскиз бо миқёс](topic:calibrate-and-measure#sketch-to-scale)). |
| Ҳисоби ҳаҷми пурраи корҳо бо ашёҳо, маҷмӯаҳо ва нархҳо | {{ui:TakeoffCraft}}-ро истифода баред, барномаи ҳисоби ҳаҷми корҳо аз оилаи CadCraft. |

## Варақҳо ва файлҳо

| Ҳанӯз сохта нашудааст | Имрӯз ин корро кунед |
|---|---|
| Баргардондани тағйироти саҳифа (чарх, кӯчонидан, ворид, нест кардан) | Бе захира пӯшед ва PDF-и аслиро аз нав кушоед. Нигаред ба [Чоп ва тағйири саҳифаҳо](topic:pages-and-printing). |
| Пӯшидани як файли маҷмӯа | {{ui:Пӯшидан}} тамоми маҷмӯаро мепӯшад; файлҳои заруриро аз нав кушоед. |
| Захира кардани маҷмӯа ҳамчун лоиҳа барои кушодан дар як қадам | PDF-ҳоро аз нав кушоед. |
| Чоп бо миқёси интихобшуда ё чанд варақ дар як коғаз | Диалоги чопгари браузери худро истифода баред, ё нусхаи захирашударо аз бинандаи дигари PDF чоп кунед. |

## Рӯйхатҳо ва содирот

| Ҳанӯз сохта нашудааст | Имрӯз ин корро кунед |
|---|---|
| Ҷойгир кардани мушкилоти воридшудаи BCF дар мавқеи модели онҳо | Мушкилоти воридшуда, ки ба ягон варақ пайваст нестанд, дар боло-чап ҷамъ мешаванд: онҳоро кӯчонед. |
| Воридкунии маҷмӯаҳои абзорҳо аз барномаҳои дигари қайдгузорӣ | Абзорҳои заруриро аз нав созед ва ба сандуқ захира кунед; онро барои идора содир кунед. |

## Платформаҳо

- **Мизи корӣ:** MarkupCraft дар браузер дар Mac, Windows, Linux ва iPad, ва дар CadCraft Studio — барномаи мизи корӣ, ки ҳар ҳашт барномаро дар як насб дорад — кор мекунад.
- MarkupCraft дар ҳоли таҳия аст. Номҳои тугмаҳо ва рафтор метавонанд тағйир ёбанд, ва ин роҳнамо низ бо онҳо тағйир меёбад.
