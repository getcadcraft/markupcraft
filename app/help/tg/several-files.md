Маҷмӯаи нақшаҳо аксар вақт ҳамчун як PDF барои ҳар фан ё як PDF барои ҳар варақ меояд. MarkupCraft ҳама чизеро, ки шумо мекушоед, **як маҷмӯа** ҳисоб мекунад.

## Якҷоя кушодан

Ҳамаи PDF-ҳоро дар интихобкунандаи файл якбора интихоб кунед ё ба минтақаи варақ партоед. Барои илова кардани бештар баъдтар, онҳоро ҳамин тавр кушоед; онҳо дар охири феҳристи {{ui:Варақҳо}} ба тартиби кушодан ҳамроҳ мешаванд.

Натиҷа: «Кушода шуд 6 файл (84 варақ дар маҷмӯа).» Ҳар саҳифа варақ аст. Варақҳо бо рақами варақ дар зери номашон «Варақ A-101»-ро нишон медиҳанд; дигарон файл ва саҳифаро нишон медиҳанд.

Файли маҷмӯаи захиршуда нест: дафъаи дигар, ҳамон PDF-ҳоро дубора кушоед (нусхаҳои «(marked up)», агар захира карда бошед).

## Дар тамоми маҷмӯа

- **Ёфтани варақ:** {{ui:Ҷустуҷӯи варақҳо}} рақамҳои варақ, номҳои варақ ва номи файлҳои ҳар файлро меҷӯяд. {{key:PageUp}} ва {{key:PageDown}} ҳамаи варақҳои ҳамаи файлҳоро ба тартиб тай мекунанд.
- **Феҳристи қайдҳо:** {{ui:Қайдҳо}} қайдҳои ҳар файлро нишон медиҳад. Барои маҳдуд кардан бо {{ui:Варақ}} филтр кунед. CSV сутуни File дорад.
- **Феҳристи punch:** як рақамгузорӣ барои тамоми маҷмӯа.
- **Муқоиса:** варақи кӯҳна ва нав метавонанд аз файлҳои гуногун бошанд.
- **Нусхабардорӣ ва гузоштан:** {{key:Mod+C}} дар як варақ ва {{key:Mod+V}} дар варақи дигар, дар ҳар файл. Нусха ба ҳамон ҷой дар саҳифа, каме фосила меафтад.

## Захира кардан

{{ui:Захира кардан}}-ро интихоб кунед. Вақте ки бештар аз як файл кушода аст, MarkupCraft мепурсад:

- {{ui:Ин файл}}: нусхаи қайдгузоришудаи файли варақе, ки шумо дар он ҳастед.
- {{ui:Ҳар файли тағйирёфта}}: нусхаи ҳар файле, ки тағйироти захиранашуда дорад. Ҳар кадом алоҳида зеркашида мешавад, ҳамчун «<file name> (marked up).pdf».
- {{ui:Бекор кардан}}

:::chromium
Вақте ки бори аввал якчанд файлро якбора захира мекунед, Chrome ва Edge метавонанд пурсанд, ки оё ин сайт иҷозат дорад файлҳои зиёдро зеркашад. {{ui:Иҷозат додан}}-ро интихоб кунед; вагарна фақат нусхаи аввал меояд.
:::

:::safari
Safari метавонад барои ҳар файл як бор бипурсад. Дар iPad ҳар нусха ба барномаи Files меояд.
:::

Файле, ки қайдҳояш захира шудааст, дигар тағйирёфта ҳисоб намешавад; дигарон то ҳол ҳастанд.

Содироти CSV, BCF ва феҳристи punch ба номи **аввалин** файле, ки кушодаед, номгузорӣ мешаванд.

## Пӯшидан

{{ui:Пӯшидан}} тамоми маҷмӯаро мебандад; ҳоло роҳе нест, ки танҳо як файлро бибанд. Агар чизе захира нашуда бошад, мепурсад:

- {{ui:Бекор кардан}}: ҳеҷ чиз рӯй намедиҳад.
- {{ui:Бе захира пӯшидан}}: қайдҳои захиранашуда гум мешаванд.
- {{ui:Аввал нусхаҳоро захира кардан}}: ҳар файли тағйирёфтаро захира мекунад, сипас мебандад.

Пӯшидан таърихи баргардониро низ тоза мекунад.

## Маҷмӯаҳои калон

- Матни ҳар саҳифа ҳангоми кушодан хонда мешавад, то рақамҳои варақро ёбад, бинобар ин маҷмӯаи 100-варақӣ вақт мегирад. Панели ҳолат варақҳоро ҳангоми гузаштан ҳисоб мекунад.
- Тасвирҳои варақ дар феҳрист ҳангоми гардиш ба онҳо кашида мешаванд.
- Ҳар PDF-и кушодашуда дар хотираи варақаи браузер нигоҳ дошта мешавад. Агар варақа суст шавад, варақаҳои вазнини дигарро бипӯшед ё як фанро дар як вақт баррасӣ кунед.
- Кушодани ҳамон як файл ду маротиба ба шумо ду нусхаи варақҳояшро медиҳад. Агар ин рӯй диҳад, {{ui:Пӯшидан}}-ро интихоб кунед ва маҷмӯаро дубора кушоед.
