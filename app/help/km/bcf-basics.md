BCF (BIM Collaboration Format) គឺជាទម្រង់ឯកសារបើកចំហសម្រាប់បញ្ជូនបញ្ហារវាងឧបករណ៍ BIM។ កម្មវិធីសម្របសម្រួលម៉ូដែល និងនិពន្ធជាច្រើនអាចនាំចូលឯកសារ `.bcfzip` ជាបញ្ជីបញ្ហា។ MarkupCraft សរសេរ **BCF 2.1**។

## បង្កើតមួយ

1. បើកផ្ទាំង {{ui:Markups}}។
2. ត្រងបញ្ជីឱ្យត្រូវនឹងអ្វីដែលអ្នកចង់ផ្ញើ ឧទាហរណ៍ {{ui:Status}} "Open"។ មានតែការសម្គាល់ដែលបានរាយប៉ុណ្ណោះដែលត្រូវបាននាំចេញ។
3. ជ្រើសរើស {{ui:BCF}}។
4. រង់ចាំខណៈពេលដែលវាធ្វើរូបថតនៃការសម្គាល់នីមួយៗ ("Making snapshots for BCF (5 of 20)…")។

លទ្ធផល៖ "<name> markups.bcfzip" ត្រូវបានទាញយក ហើយរបារស្ថានភាពបញ្ជាក់ចំនួនប្រធានបទដែលវាមាន និងទំហំឯកសារ។

## មានអ្វីនៅក្នុងនោះ

ការសម្គាល់នីមួយៗក្លាយជា **ប្រធានបទ** មួយ៖

| វាលប្រធានបទ | បំពេញដោយ |
|---|---|
| ចំណងជើង | លេខបញ្ជី ប្រធានបទ និងសន្លឹក ឧទាហរណ៍ "#4 Cloud on A-101 — Floor plan" |
| ប្រភេទ | ប្រភេទការសម្គាល់ (ពពក, ចំណារចង្អុល, ប្រវែង…) |
| ស្ថានភាព | បើក, ទទួលយក, បដិសេធ ឬ បានបញ្ចប់ |
| ស្លាក | ប្រភេទការសម្គាល់ និងសន្លឹក |
| អ្នកនិពន្ធ និងកាលបរិច្ឆេទ | អ្នកនិពន្ធការសម្គាល់ កាលបរិច្ឆេទបង្កើត និងកាលបរិច្ឆេទកែប្រែ |
| ចាត់ឱ្យ កាលកំណត់ | ពីធាតុបញ្ជីកែតម្រូវរបស់វា នៅពេលវាមាន |
| ពិពណ៌នា | អត្ថបទ ឬពាក្យត្រា តម្លៃដែលបានវាស់ មតិយោបល់ និងសន្លឹកនិងឯកសារ |
| មតិយោបល់ | មួយសម្រាប់ការឆ្លើយតបនីមួយៗ ជាមួយអ្នកនិពន្ធ និងកាលបរិច្ឆេទ |
| រូបថត | រូបភាពនៃការសម្គាល់នៅផ្នែករបស់វានៅលើសន្លឹក |
| ទិដ្ឋភាព | ទិដ្ឋភាពពីលើចុះក្រោមនៃទីតាំងការសម្គាល់នៅលើសន្លឹក |

ការនាំចេញការសម្គាល់តែមួយម្ដងទៀតផ្តល់ ID ប្រធានបទដូចគ្នា ដូច្នេះឧបករណ៍ដែលនាំចូល BCF អាចស្គាល់វាថាជាបញ្ហាតែមួយ។

## ដែនកំណត់ត្រូវដឹង

- **សន្លឹកមិនមែនជាម៉ូដែលទេ។** ទិដ្ឋភាពចង្អុលទៅទីតាំងការសម្គាល់នៅលើក្រដាស ដែលវាស់ជាម៉ែត្រនៃក្រដាស។ វាមិនអាចនាំឧបករណ៍ BIM ទៅកន្លែងណាមួយនៅក្នុងម៉ូដែលបានទេ។ សូមប្រើរូបថត និងឈ្មោះសន្លឹកដើម្បីរកកន្លែង។
- **ស្ថានភាព និងប្រភេទគឺជារបស់ MarkupCraft ផ្ទាល់។** (បើក, ទទួលយក, បដិសេធ, បានបញ្ចប់; ពពក, ចំណារចង្អុល…)។ ឯកសារប្រកាសពួកវា ដូចដែល BCF អនុញ្ញាត ប៉ុន្តែឧបករណ៍ដែលមានបញ្ជីថេររបស់ខ្លួនអាចផែនទី ឬមិនអើពើពួកវា។
- **ការនាំចូលនាំមកតែមតិយោបល់ មិនមែនទិដ្ឋភាពម៉ូដែលទេ។** {{ui:Import BCF}} បន្ថែមការឆ្លើយតប និងស្ថានភាពទៅការសម្គាល់ដែលអ្នកបាននាំចេញ ហើយធ្វើកំណត់ចំណាំនៃបញ្ហាផ្សេងទៀត; វាមិនអាចបង្ហាញកាមេរ៉ាម៉ូដែលបានទេ។ សូមមើល [បញ្ជីការសម្គាល់ និងការនាំចេញ](topic:markups-list-and-export#import-bcf)។
- ការផ្ញើការសម្គាល់ត្រឡប់ជា PDF ជារឿយៗសាមញ្ញជាងសម្រាប់ការពិនិត្យគំនូរ។ BCF សម្រាប់នាំមតិយោបល់គំនូរចូលក្នុងដំណើរការសម្របសម្រួលម៉ូដែល។
