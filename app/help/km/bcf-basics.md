BCF (BIM Collaboration Format) គឺជាទម្រង់ឯកសារបើកចំហសម្រាប់ផ្ទេរបញ្ហារវាងឧបករណ៍ BIM។ កម្មវិធីសម្របសម្រួលម៉ូដែល និងការរចនាជាច្រើនអាចនាំចូលឯកសារ `.bcfzip` ជាបញ្ជីបញ្ហាបាន។ MarkupCraft សរសេរ **BCF 2.1**។

## បង្កើតមួយ

1. បើក {{ui:ការសម្គាល់}} ។
2. ត្រងបញ្ជីឱ្យសមនឹងអ្វីដែលអ្នកចង់ផ្ញើ ឧទាហរណ៍ {{ui:ស្ថានភាព}} "បើក"។ មានតែការសម្គាល់ដែលបានបង្ហាញប៉ុណ្ណោះដែលត្រូវបាននាំចេញ។
3. ជ្រើសរើស {{ui:BCF}} ។
4. រង់ចាំខណៈដែលវាធ្វើរូបថតនៃការសម្គាល់នីមួយៗ ("កំពុងធ្វើរូបថតសម្រាប់ BCF (5 ក្នុង 20)…")។

លទ្ធផល៖ "<name> markups.bcfzip" ត្រូវបានទាញយក ហើយរបារស្ថានភាពបង្ហាញចំនួនប្រធានបទដែលវាមាន និងទំហំឯកសារ។

## មាននៅក្នុងនោះអ្វីខ្លះ

ការសម្គាល់នីមួយៗក្លាយជា **ប្រធានបទ** មួយ៖

|---|---|
| ចំណងជើង | លេខ Punch ប្រធានបទ និងសន្លឹក ឧទាហរណ៍ "#4 ពពក នៅ A-101 — ប្លង់ជាន់" |
| ប្រភេទ | ប្រភេទការសម្គាល់ (ពពក, ការចង្អុលបង្ហាញ, ប្រវែង…) |
| ស្ថានភាព | បើក, ទទួលយក, បដិសេធ ឬ បានបញ្ចប់ |
| ស្លាក | ប្រភេទការសម្គាល់ និងសន្លឹក |
| អ្នកនិពន្ធ និងកាលបរិច្ឆេទ | អ្នកនិពន្ធការសម្គាល់ និងកាលបរិច្ឆេទបង្កើត និងកែប្រែ |
| ចាត់ឱ្យ, ថ្ងៃកំណត់ | ពីធាតុ Punch របស់វា នៅពេលមាន |
| ការពិពណ៌នា | អត្ថបទ ឬពាក្យត្រាកំណត់ តម្លៃដែលបានវាស់ មតិយោបល់ និងសន្លឹក និងឯកសារ |
| មតិយោបល់ | មួយសម្រាប់ការឆ្លើយតបនីមួយៗ ជាមួយអ្នកនិពន្ធ និងកាលបរិច្ឆេទ |
| រូបថត | រូបភាពនៃការសម្គាល់នៅផ្នែករបស់វានៅលើសន្លឹក |
| ទិដ្ឋភាព | ទិដ្ឋភាពពីលើចុះក្រោមនៃទីតាំងការសម្គាល់នៅលើសន្លឹក |

ការនាំចេញការសម្គាល់ដដែលម្ដងទៀតផ្ដល់លេខសម្គាល់ប្រធានបទដូចគ្នា ដូច្នេះឧបករណ៍ដែលនាំចូល BCF អាចស្គាល់វាថាជាបញ្ហាដដែល។

## អ្វីដែលត្រឡប់មកវិញពេលនាំចូល

{{ui:នាំចូល BCF}} អានឯកសារ BCF 2.0, 2.1 និង 3.0 (បានពិនិត្យលើឯកសារសាកល្បងផ្លូវការ buildingSMART 3.0 ចំនួន 19៖ ប្រធានបទគ្រប់ទាំងអស់ត្រូវបានអាន ហើយមតិយោបល់របស់បីដែលមានអត្ថបទ)។ សម្រាប់ប្រធានបទដែលជារបស់អ្នក (លេខសម្គាល់ប្រធានបទដូចគ្នា) វាបន្ថែមមតិយោបល់ថ្មីជាការឆ្លើយតប ហើយយកស្ថានភាពថ្មី។ ប្រធានបទផ្សេងទៀតទាំងអស់ក្លាយជាកំណត់ចំណាំនៅលើសន្លឹកដែលស្លាក ឬឈ្មោះឯកសាររបស់វាដាក់ឈ្មោះ បើមិនដូច្នេះទេ នៅលើសន្លឹកដែលកំពុងបើក ដោយមានចំណងជើង ការពិពណ៌នា អ្នកទទួលខុសត្រូវ និងថ្ងៃកំណត់ ជាអត្ថបទនៃកំណត់ចំណាំ ហើយមតិយោបល់របស់វាជាការឆ្លើយតប។

| នៅក្នុងប្រធានបទ BCF | នៅក្នុង MarkupCraft |
|---|---|
| ចំណងជើង, ការពិពណ៌នា, អ្នកទទួលខុសត្រូវ, ថ្ងៃកំណត់ | អត្ថបទនៃកំណត់ចំណាំ |
| មតិយោបល់ដែលមានអត្ថបទ | ការឆ្លើយតប |
| ស្ថានភាព Open, Accepted, Rejected, Completed (Closed, Resolved, Done រាប់ជា Completed) | ស្ថានភាពនៃការសម្គាល់ |
| អ្នកនិពន្ធ និងកាលបរិច្ឆេទបង្កើត | អ្នកនិពន្ធ និងកាលបរិច្ឆេទនៃកំណត់ចំណាំ |
| ទីតាំងកាមេរ៉ា | ទីតាំងនៅលើសន្លឹក តែសម្រាប់ប្រធានបទដែលភ្ជាប់ទៅសន្លឹកតាមស្លាក ឬឈ្មោះឯកសារ |
| ជម្រើសម៉ូដែល ផ្នែកលាក់ យន្តហោះកាត់ រូបថត | មិនបានរក្សាទុកទេ៖ សន្លឹកគ្មានម៉ូដែលឱ្យបង្ហាញវានៅ |

## ដែនកំណត់ដែលត្រូវដឹង

- **សន្លឹកមិនមែនជាម៉ូដែលទេ។** ទិដ្ឋភាពចង្អុលទៅទីតាំងការសម្គាល់នៅលើក្រដាស ដែលវាស់ជាមេត្រនៃក្រដាស។ វាមិនអាចនាំឧបករណ៍ BIM ទៅកន្លែងមួយក្នុងម៉ូដែលបានទេ។ ប្រើរូបថត និងឈ្មោះសន្លឹកដើម្បីស្វែងរកកន្លែងនោះ។
- **ស្ថានភាព និងប្រភេទគឺជារបស់ MarkupCraft។** (Open, Accepted, Rejected, Completed; Cloud, Callout…)។ ឯកសារប្រកាសវា ដូចដែល BCF អនុញ្ញាត ប៉ុន្តែឧបករណ៍ដែលមានបញ្ជីថេររបស់ខ្លួនអាចផ្លាស់ប្ដូរ ឬមិនអើពើពួកវា។
- **ការនាំចូលនាំយកមតិយោបល់ មិនមែនទិដ្ឋភាពម៉ូដែលទេ។** {{ui:នាំចូល BCF}} បន្ថែមការឆ្លើយតប និងស្ថានភាពទៅការសម្គាល់ដែលអ្នកបាននាំចេញ ហើយធ្វើកំណត់ចំណាំសម្រាប់បញ្ហាផ្សេងទៀត; វាមិនអាចបង្ហាញកាមេរ៉ាម៉ូដែលបានទេ។ សូមមើល [បញ្ជីការសម្គាល់ និងការនាំចេញ](topic:markups-list-and-export#import-bcf)។
- ការផ្ញើការសម្គាល់ត្រឡប់ជា PDF ជារឿយៗសាមញ្ញជាងសម្រាប់ការត្រួតពិនិត្យប្លង់។ BCF សម្រាប់ដាក់មតិយោបល់លើប្លង់ចូលក្នុងលំហូរការងារសម្របសម្រួលម៉ូដែល។
