មនុស្សពីរនាក់សម្គាល់ PDF តែមួយនៅក្នុងច្បាប់ចម្លងពីរ។ ប្រសិនបើពួកគេប៉ះការសម្គាល់ផ្សេងគ្នា ច្បាប់ចម្លងអាចត្រូវបានបញ្ចូលដោយកម្មវិធីមួយ ជំនួសឱ្យដោយដៃ។

## អ្វីដែលធ្វើឱ្យវាដំណើរការ

ការសម្គាល់ទាំងអស់ដែល MarkupCraft រក្សាទុក ផ្ទុកឈ្មោះរបស់ខ្លួន (លេខសម្គាល់របស់វា) នៅក្នុង PDF ហើយឈ្មោះនោះមិនផ្លាស់ប្ដូរឡើយ។ ការបញ្ចូលមើលការសម្គាល់តាមឈ្មោះនោះ មិនមែនតាមទីតាំងរបស់វានៅក្នុងឯកសារទេ ដោយសារកម្មវិធីគ្រប់ដួងកំណត់លេខទីតាំងឡើងវិញពេលពួកវារក្សាទុក។ កំណត់ចំណាំ និងកំណត់ចំណាំឯកជនដែលបានបិទជិត ត្រូវបានផ្គូផ្គងតាមរបៀបដូចគ្នា។

សន្លឹកមិនត្រូវបានប៉ះឡើយ៖ ច្បាប់ចម្លងទាំងពីរត្រូវតែមានចំនួនទំព័រដូចគ្នា។ បើពួកវាខុសគ្នា ការបញ្ចូលរក្សាច្បាប់ចម្លងរបស់អ្នកដូចដែលវាស្ថិតនៅ ហើយប្រាប់អ្នកដូច្នេះ ព្រោះការបន្ថែម ឬលុបទំព័រជាការងាររបស់មនុស្ស។

## រៀបចំ

Git ត្រូវការពីរបន្ទាត់ម្ដងក្នុងមួយ repository៖

```
# .gitattributes
*.pdf merge=cadcraft

# one time, on each computer
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

ដោយគ្មាន git ដំណើរការ `cadcraft merge <base> <ours> <theirs> -o <result>`។ Fossil និង Mercurial យកឯកសារបីដូចគ្នាក្នុងការកំណត់ឧបករណ៍បញ្ចូលរបស់ពួកវាផ្ទាល់។ ឯកសារកិច្ចការដែលមកជាមួយគំនូរ (`<name>.markups.json`, សូមមើល [ការសម្គាល់ដែលធ្វើការ](topic:markups-that-act)) បញ្ចូលតាមរបៀបដូចគ្នា ជាអត្ថបទធម្មតា។

## វិធានការ

- ការសម្គាល់ដែលបានផ្លាស់ប្ដូរតែនៅម្ខាង ត្រូវបានយក។ ការផ្លាស់ប្ដូរដូចគ្នានៅទាំងពីរខាង ត្រូវបានយកតែមួយដង។
- ការសម្គាល់ដែលបានផ្លាស់ប្ដូរតាមពីរវិធីគឺជា**ជម្លោះ**៖ ផ្នែករបស់អ្នកនៅតែ ហើយរបាយការណ៍រាយទាំងពីរ។ បើកលទ្ធផល ហើយកែការសម្គាល់នោះដោយដៃ។
- ការសម្គាល់ដែលបានបន្ថែមនៅម្ខាងណាក៏ត្រូវបានរក្សា។ ការសម្គាល់ដែលបានលុបនៅម្ខាង ហើយមិនបានប៉ះនៅម្ខាងទៀត ត្រូវបានលុប។ បានលុបនៅម្ខាង ហើយបានផ្លាស់ប្ដូរនៅម្ខាងទៀត៖ បានលុប និងត្រូវបានរាយការណ៍។
- ស្រទាប់ ជួរឈរ កំណត់ត្រា និងកំណត់ចំណាំ ធ្វើតាមវិធានដូចគ្នា។
- កំណត់ចំណាំឯកជនដែលបានបិទជិតមិនត្រូវបានបើកឡើយ៖ ប្លុកនៃទាំងពីរខាងត្រូវបានរក្សាដូចដែលវាស្ថិតនៅ។

ឯកសារដែលបានបញ្ចូលគឺជាការសរសេរឡើងវិញពេញលេញនៃច្បាប់ចម្លងរបស់អ្នក ដូចជា Save របស់ MarkupCraft ផ្ទាល់។ គ្មានអ្វីត្រូវបានផ្ទុកឡើងទេ; ទាំងអស់ដំណើរការនៅលើកុំព្យូទ័ររបស់អ្នក។
