MarkupCraft נמצאת בפיתוח. להלן מה שהגרסה הנוכחית **לא** עושה, כדי שתוכלו לתכנן סביב זה. המסמך מתאר את הגרסה של היום, ולא הבטחות.

## עבודה עם אנשים אחרים

| טרם נבנה | לעשות היום |
|---|---|
| שמירה בענן וסנכרון בין מחשבים | שמרו את קבצי ה-PDF לצד קבצי הפרויקט. שמירה בענן עדיין אינה זמינה. |
| מיזוג העותקים של שני אנשים של הסימונים | חלקו את הגיליונות בין הסוקרים, או העתיקו כמה סימונים בעזרת {{key:Mod+C}} ו-{{key:Mod+V}}. בקשות מידע (RFI), הגשות ויומני עבודה כן ממוזגים: ראו [מעקב אחר RFI, הגשות ויומני עבודה](topic:field-records). |
| צוותים, התראות ופרויקטים בענן ל-RFI ולהגשות | העבירו את ה-PDF הלאה, והשתמשו במיזוג כדי לאחד את העותקים. |
| בקשות מידע (RFI), הגשות ויומני עבודה בסשן חי | כל אחד עובד על העותק שלו; הביאו את העותקים יחד באמצעות {{ui:Merge}}. |
| מיזוג השינויים של שני אנשים בשדות שונים של רשומה אחת | העותק ששונה לאחרונה גובר על הרשומה כולה (שרשור התגובות ושמות הקבצים המצורפים מאוחדים). הסכימו מי עורך איזו רשומה. |
| כלי עוזר ל-RFI, להגשות וליומני עבודה | עבדו איתם בכרטיסיית {{ui:Field}}. עוזרי AI יכולים לעבוד עם סימונים: ראו [שימוש ב-MarkupCraft עם עוזר AI](topic:use-with-ai-assistants). |
| עריכה או מחיקה של תגובה לאחר שליחתה | בטלו מיד, או הוסיפו תגובת תיקון. |
| שינוי המחבר של סימון | הגדירו את השם שלכם לפני שמתחילים. |

## סימונים

| טרם נבנה | לעשות היום |
|---|---|
| חותמות עם שדות למילוי, חתימות דיגיטליות מאושרות | השתמשו בחותמת טקסט מותאמת אישית, הכוללת את שמכם ואת התאריך, או בתמונה של החתימה שלכם. |
| צירוף קבצים שאינם תמונות (מסמכים, סרטונים) | שמרו אותם לצד ה-PDF והפנו אליהם בהערה. |
| קישורים לאתרים או לקבצים שאינם פתוחים | כתבו את הכתובת או את שם הקובץ בהערה. |
| קבוצות סטטוס מותאמות אישית | השתמשו בארבעת הסטטוסים, ובנושא לכל דבר נוסף. |
| עריכת הערות שהגיעו עם הקובץ כקריאה בלבד (הדגשות טקסט, חותמות של תוכנות אחרות) | השיבו להן, או שרטטו סימון MarkupCraft לצדן. |
| קווי עט רגישי ללחץ | הגדירו את עובי הקו. |

## התוכן של העמוד עצמו

| טרם נבנה | לעשות היום |
|---|---|
| שרטוט צורות חדשות ישירות לתוך העמוד | שרטטו אותן כסימונים, ואז בחרו {{ui:Put into the page}}. ראו [שינוי התוכן של העמוד עצמו](topic:page-content). |
| סיבוב אובייקטים של העמוד בכל זווית | הזיזו ושנו את הגודל שלהם; סובבו את כל העמוד בעזרת {{ui:Pages}}. |
| שינוי גופן או גודל של שורת טקסט, או טקסט הנמשך על פני כמה שורות | שנו את המילים שורה אחר שורה; למילים חדשות בגופן אחר, הוסיפו סימון טקסט. |
| עריכת מה שבתוך תמונה סרוקה | החליפו את התמונה, או סמנו אותה. |
| עריכת קובצי PDF מוצפנים או חתומים | בקשו עותק לא חתום; סימונים פועלים על כל PDF. |

## מדידה

| טרם נבנה | לעשות היום |
|---|---|
| מדידות רדיוס | שרטטו {{ui:Arc}} לאורכו, או מדדו את {{ui:Length}} לאורך הקוטר וחלקו בשתיים. |
| עריכת פינות החור | מחקו את החורים ושרטטו אותם מחדש. |
| החלת קנה מידה אחד על גיליונות רבים בבת אחת | כיילו כל גיליון; בחירת הגדרה מוכנה לוקחת כמה שניות לכל גיליון. |
| כמה קני מידה בגיליון אחד (חלונות תצוגה) | כיילו לפי השרטוט שאתם מודדים הכי הרבה. שינוי קנה המידה של גיליון מודד מחדש הכול בו, לכן רשמו ערכי פרטים לפני שתכיילו מחדש עבורם. |
| נעיצה לקווים בשרטוט | התקרבו לפני הלחיצה, או הקלידו אורכים וזוויות (ראו [שרטוט לפי קנה מידה](topic:calibrate-and-measure#sketch-to-scale)). |
| הוצאת כמויות מלאה עם סעיפים, מכלולים ומחירים | השתמשו ב-TakeoffCraft, אפליקציית הוצאת הכמויות של משפחת CadCraft. |

## גיליונות וקבצים

| טרם נבנה | לעשות היום |
|---|---|
| ביטול שינוי עמוד (סיבוב, הזזה, הוספה, מחיקה) | סגרו בלי לשמור ופתחו מחדש את ה-PDF המקורי. ראו [הדפסה ושינוי עמודים](topic:pages-and-printing). |
| סגירת קובץ אחד מתוך הסט | הפקודה {{ui:Close}} סוגרת את כל הסט; פתחו מחדש את הקבצים שאתם צריכים. |
| שמירת סט כפרויקט לפתיחה מחדש בשלב אחד | פתחו מחדש את אותם קובצי PDF. |
| הדפסה בקנה מידה נבחר, או כמה גיליונות בדף | השתמשו בתיבת הדו-שיח של המדפסת בדפדפן שלכם, או הדפיסו את העותק השמור מתוכנת צפייה ב-PDF אחרת. |

## רשימות וייצוא

| טרם נבנה | לעשות היום |
|---|---|
| הצבת נושאי BCF מיובאים במיקום שלהם במודל | נושאים מיובאים שאינם משויכים לגיליון מסודרים בפינה השמאלית העליונה: העבירו אותם. |
| ייבוא קבוצות כלים מתוכנות סימון אחרות | בנו מחדש את הכלים שאתם צריכים ושמרו אותם בארגז הכלים; ייצאו אותו למשרד. |

## השוואה

| טרם נבנה | לעשות היום |
|---|---|
| השוואת טקסט מוגדר בגופן, או רשימת השינויים | השתמשו בשכבת-על ובמחוון, או ב{{ui:Changed lines}} עבור קווים מצוירים. |
| השוואת גיליונות סרוקים לפי הקווים שלהם | השתמשו בשכבת התמונה. |
| יישור אוטומטי של כל זוג בעת השוואת סט שלם | השוו זוג שהוזז בנפרד, והשתמשו ב{{ui:Align by two points}}. |

## חלוניות

| טרם נבנה | לעשות היום |
|---|---|
| הזזת סרגל הכלים או שורת המצב | רק שתי החלוניות הצדדיות זזות. |

## פלטפורמות

- **שולחן עבודה:** MarkupCraft פועלת בדפדפן ב-Mac, ב-Windows, ב-Linux וב-iPad, וכן ב-CadCraft Studio, יישום שולחני ובו כל שמונה היישומים בהתקנה אחת.
- MarkupCraft נמצאת בפיתוח. תוויות והתנהגות עשויות להשתנות עוד, והעזרה הזו תשתנה יחד איתן.
