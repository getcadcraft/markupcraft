BCF (BIM Collaboration Format) — BIM құралдары арасында мәселелерді беруге арналған ашық файл форматы. Көптеген модельді үйлестіру және жобалау бағдарламалары `.bcfzip` файлын мәселелер тізімі ретінде импорттай алады. MarkupCraft **BCF 2.1** форматында жазады.

## Жасау

1. {{ui:Markups}} қойындысын ашыңыз.
2. Тізімді жібергіңіз келетін нәрсеге сүзіңіз, мысалы, {{ui:Status}} «Ашық». Экспортқа тек тізімдегі белгілеулер кіреді.
3. {{ui:BCF}} таңдаңыз.
4. Әр белгілеудің суретін жасағанша күтіңіз («BCF үшін суреттер жасалуда (5/20)…»).

Нәтиже: «<name> markups.bcfzip» жүктеліп алынады, ал күй жолағында тақырыптар саны мен файл өлшемі көрсетіледі.

## Ішінде не бар

Әр белгілеу бір **тақырыпқа** айналады:

| BCF тақырып өрісі | Мазмұны |
|---|---|
| Тақырып | Кемшілік нөмірі, тақырыбы және парақ, мысалы «#4 Бұлт, A-101 — Жоспар» |
| Түрі | Белгілеу түрі (Бұлт, Айқындама, Ұзындық…) |
| Мәртебе | Ашық, Қабылданған, Қабылданбаған немесе Аяқталған |
| Таңбалар | Белгілеу түрі және парақ |
| Автор және күндер | Белгілеу авторы, жасалған және өзгертілген күндер |
| Тағайындалған, мерзімі | Кемшілік элементінен, бар болса |
| Сипаттама | Мәтіні немесе мөрдің мәтіні, өлшенген мән, түсініктеме, парақ пен файл |
| Түсініктемелер | Әр жауап үшін бір, автормен және күнімен |
| Сурет | Белгілеудің парақтағы бөлігінің суреті |
| Көрініс нүктесі | Белгілеудің парақтағы орнының жоғарыдан көрінісі |

Бірдей белгілеуді қайта экспорттау бірдей тақырып ID береді, сондықтан BCF импорттайтын құрал оны бір мәселе ретінде таниды.

## BCF импорттағанда не қайтып келеді

{{ui:Import BCF}} BCF 2.0, 2.1 және 3.0 файлдарын оқиды (19 ресми buildingSMART 3.0 сынақ файлында тексерілген: әр тақырып оқылды, мәтіні бар үш тақырыптың түсініктемелері оқылды). Өзіңіздің тақырыбыңыз болса (бірдей тақырып ID), жаңа түсініктемелерді жауап ретінде қосады және жаңа күйді қабылдайды. Басқа кез келген тақырып — оның белгісі немесе файл атауы көрсеткен парақтағы жазба болады, ал ол көрсетілмеген болса, ашық парақтағы жазба. Тақырыбы, сипаттамасы, тағайындалған адамы және мерзімі жазбаның мәтіні болады, ал түсініктемелері жауап болады.

| BCF тақырыбында | MarkupCraft-та |
|---|---|
| Тақырып, сипаттама, тағайындалған адам, мерзім | Жазбаның мәтіні |
| Мәтіні бар түсініктемелер | Жауаптар |
| Күй Open, Accepted, Rejected, Completed (Closed, Resolved, Done — Completed деп саналады) | Белгілеудің күйі |
| Автор және жасалған күн | Жазбаның авторы және күні |
| Камера орны | Парақтағы орын, тек белгісі немесе файл атауы арқылы парақпен байланысқан тақырып үшін |
| Модель таңдауы, жасырын бөліктер, кесу жазықтықтары, суреттер | Сақталмайды: парақта оларды көрсететін модель жоқ |

## Білу керек шектеулер

- **Парақ — модель емес.** Көрініс нүктесі белгілеудің қағаздағы орнын қағаз метрімен өлшейді. Ол BIM құралын модельдегі орынға апармайды. Орынды табу үшін суретті және парақ атауын пайдаланыңыз.
- **Күйлер мен түрлер MarkupCraft-тікі** (Ашық, Қабылданған, Қабылданбаған, Аяқталған; Бұлт, Айқындама…). Файл оларды BCF рұқсат еткендей жариялайды, бірақ өз тізімдері бекітілген құрал оларды салыстыруы немесе елемеуі мүмкін.
- **Импорттағанда модель көрінісі емес, түсініктемелер келеді.** {{ui:Import BCF}} экспортталған белгілеулерге жауаптар мен күйлерді қосады және басқа мәселелерден жазбалар жасайды; модель камерасын көрсете алмайды. Қараңыз: [Белгілер тізімі және экспорт](topic:markups-list-and-export#import-bcf).
- Сызбаларды шолу үшін белгілеулерді PDF түрінде қайтару көбіне қарапайым. BCF — сызба түсініктемелерін модельді үйлестіру жұмысына енгізуге арналған.
