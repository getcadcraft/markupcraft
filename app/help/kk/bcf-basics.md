BCF (BIM бірлесіп жұмыс форматы) — BIM құралдары арасында мәселелерді беруге арналған ашық файл форматы. Көптеген модельді үйлестіру және жобалау бағдарламалары `.bcfzip` файлын мәселелер тізімі ретінде импорттай алады. MarkupCraft **BCF 2.1** форматында жазады.

## Жасау

1. {{ui:Markups}} қойындысын ашыңыз.
2. Тізімді жібергіңіз келетін нәрсеге сүзгілеңіз, мысалы {{ui:Status}} «Ашық». Тек тізімдегі белгілеулер экспортталады.
3. {{ui:BCF}} таңдаңыз.
4. Әр белгілеудің суретін жасағанша күтіңіз («BCF үшін суреттер жасалуда (5 / 20)…»).

Нәтиже: «<name> markups.bcfzip» жүктеліп алынады, ал күй жолағында тақырыптар саны мен файл өлшемі көрсетіледі.

## Ішінде не бар

Әр белгілеу бір **тақырыпқа** айналады:

| Тақырып өрісі | Немен толтырылады |
|---|---|
| Атауы | Түзету нөмірі, тақырыбы және парақ, мысалы «#4 Бұлт A-101 парағында — Еден жоспары» |
| Түрі | Белгілеу түрі (Бұлт, Түсіндірме, Ұзындық…) |
| Мәртебесі | Ашық, Қабылданған, Қабылданбаған немесе Аяқталған |
| Белгілер | Белгілеу түрі және парақ |
| Автор және күндер | Белгілеу авторы, құрылған және өзгертілген күндері |
| Тағайындалған адам, мерзімі | Түзету элементінен, егер болса |
| Сипаттама | Мәтіні немесе мөрдің мәтіні, өлшенген мән, пікір, парақ және файл |
| Пікірлер | Әр жауап үшін бір, автормен және күнімен |
| Сурет | Белгілеудің парақтағы бөлігіндегі суреті |
| Көрініс | Белгілеудің парақтағы орнының жоғарыдан көрінісі |

Дәл осы белгілеуді қайта экспорттау бірдей тақырып ID береді, сондықтан BCF импорттайтын құрал оны бірдей мәселе ретінде таниды.

## Білуге тиісті шектеулер

- **Парақ — модель емес.** Көрініс белгілеудің парақтағы орнына бағытталады, ол қағаз метрімен өлшенеді. Ол BIM құралын модельдегі орынға апармайды. Орынды табу үшін суретті және парақ атауын пайдаланыңыз.
- **Мәртебелер мен түрлер — MarkupCraft-тікі** (Ашық, Қабылданған, Қабылданбаған, Аяқталған; Бұлт, Түсіндірме…). Файл оларды BCF рұқсат еткендей жариялайды, бірақ өз тізімдері бекітілген құрал оларды салыстырып немесе елемеуі мүмкін.
- **Импорттау модель көріністерін емес, пікірлерді әкеледі.** {{ui:Import BCF}} экспорттаған белгілеулеріңізге жауаптар мен мәртебелерді қосады және басқа мәселелер бойынша жазбалар жасайды; модельдің камерасын көрсете алмайды. Қараңыз: [Белгілеулер тізімі және экспорт](topic:markups-list-and-export#import-bcf).
- Сызба шолуы үшін белгілеулерді PDF ретінде қайтару көбіне қарапайымырақ. BCF — сызба пікірлерін модельді үйлестіру жұмысына жеткізуге арналған.
