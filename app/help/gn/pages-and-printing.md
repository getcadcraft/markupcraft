Menú {{ui:Páginas}} grupo {{ui:Archivo}}-pe omba'apo PDF oĩva hoja abierta rehe. Ne PDF ko computadora-pe ndojemoambiméi: cambio oguarda copia-pe guardáva.

## Imprimir

1. Eapreta {{key:Mod+P}}, térã eiporavo {{ui:Páginas}}, upéi {{ui:Imprimir…}}.
2. Hoja mbohapy abierto oguerekóramo, eiporavo mba'e imprimir: {{ui:Esta hoja}}, opa página ko archivo-pe, set entero, térã páginas emoĩva (por ejemplo `1-3, 5`).
3. Eiporavo {{ui:Imprimir}}. Navegador impresora diálogo ojepyrũ: eiporavo impresora, papel ha escala upe-pe.

Anotaciones imprimíva ohechaukahágui hoja-pe: oñemboguete impresora-pe oguejy copia páginas-pe. Ambue programa-kuéra comentario oimprime PDF ohechaukáicha.

:::safari firefox
Navegador ndaikatúi imprimi página-gui, hojakuéra oñemoĩ PDF pestaña pyahu-pe. Imprimí upégui.
:::

## Girar una página

Eiporavo {{ui:Páginas}}, upéi {{ui:Girar página en sentido horario}} térã {{ui:Girar página en sentido antihorario}}. Hoja abierta oguejy cuarto giro. Anotaciones oguarda hoja-pe oĩha haguéicha, ha texto ojapo ojegira página ndive upévare sigue vertical.

## Mover una página

Eiporavo {{ui:Páginas}}, upéi {{ui:Mover página antes}} térã {{ui:Mover página después}}. Hoja abierta oĩta ambue vecino ndive ipropio PDF-pe. Anotaciones, escala ha número de hoja oheja ndive.

## Insertar páginas

- {{ui:Insertar páginas de un PDF…}} oipe'a opa página ambue PDF-gui hoja abierta rapykue.
- {{ui:Insertar una página en blanco}} oipe'a página vacía tamaño igual hoja abierta rapykue, boceto ha nota-rã. {{ui:Nuevo}}-gui ojapo set-pe, cuadrícula ichupe ojeguerú.
- {{ui:Nuevo}}-gui ojapo set-pe, {{ui:Agregar una página en blanco}} {{ui:Hojas}} lista guýpe oipe'a peteĩ página ambue ichupe ha oho ipahápe. Ehecha [Empezar con una página en blanco](topic:open-a-plan-set#start-with-blank-pages).

Insertado página oguerekóta número etiqueta ojerrenombra peve. Ehecha [Renombrar una hoja](topic:open-a-plan-set#rename-a-sheet).

## Borrar páginas

1. Eiporavo {{ui:Páginas}}, upéi {{ui:Borrar páginas…}}.
2. Emoĩ páginas número ko PDF-pe, ejemplo `3` térã `2-4`. Hoja abierta página oñemoĩ.
3. Eiporavo {{ui:Borrar páginas}}. Página anotación oguerekóramo, MarkupCraft ohechauka cuánto ha oñeporandu jey.

PDF oguarda peteĩ página ao. Archivo entero borra haguã, ojejoko set ha eabre archivo ndekoha.

## Extraer páginas

Eiporavo {{ui:Páginas}}, upéi {{ui:Extraer páginas…}}, ha emoĩ páginas. Ojeguejy PDF pyahu-pe "<archivo> (pages 1-3).pdf" nombre-pe, anotaciones comentario-icha ojeguerúva ojejapy haguã. Archivo abierto oguarda haguéicha.

## Ojeporu porã

- **Deshacer oñemoĩ página cambio rehe.** {{key:Mod+Z}} oheja anotaciones oñemoĩ rire, ndojehejái página cambio ni mba'eve ojepyrũ ramo. Ejoko ndaguardái ha ejepyrũ jey ne PDF original-gui.
- Número de página oñeporandu peteĩ PDF rehe, ndaha'éi set entero. Página mboyve oguarda ipropio archivo-pe.
- Página cambio ndoguardavéiva: {{ui:Guardar}} ojeguarda copia ojapóva, ha ejoko mboyve oporandu.
