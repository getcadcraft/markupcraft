Plano pyahu issue oúva, hoja separadora revisión ojeporu: hoja pyahu peteĩ peteĩ hoja vieja mismo número anotación ojeguerova, ha hoja vieja "Reemplazado" sello ojeguarda.

## Hoja separadora

1. Set actual ejeporu, nde anotación ndive.
2. {{ui:Páginas}} elegí, upéi {{ui:Hoja separadora para un conjunto revisado…}}, ha PDF pyahu elegí. Vieja ndive oñepyrũ.
3. Diálogo peteĩ peteĩ hoja pyahu ha hoja vieja ohechauka ojeikóva. Fila ndejoko: hoja anotación ojeikóva ndejoko. Número pyahu hoja ndaipóri ojeguerova.
4. Cerrado anotación (Aceptado, Rechazado, Completado) vieja hoja-pe ndejoko térã, vieja hoja sello ojapo térã.
5. {{ui:Llevar anotaciones adelante}} elegí.

Ojehu: anotación pyahu hoja mismo tenonde, respuesta, estado ha autor ndive oñemoĩ. Punch item pyahu hoja-pe ojeguerova ha número ojeguarda. Vieja hoja anotación registro ojeguarda, "Reemplazado" sello pe'ỹ ndive. Barra de estado ojeguerova omombe'u.

{{ui:Solo abrir los archivos}} set pyahu ojeporu, mba'eve ndojeguerova, por ejemplo comparar ántes. Ehecha [Comparar dos revisiones](topic:compare-revisions).

## Hoja ojejuhu

- **Hoja número rehe**, {{ui:Renombrar hoja}} ndive emoĩ número, PDF página etiqueta térã bloque título. Mayúscula, espacio, punto ha guión ndojeporu: "A-101" ha "a101" mismo.
- Archivo mokõi hoja mismo número oguereko jave, pyahu ojepyta. Upéva issue issue ojepyta ikatu.
- **Escaneado set** número ndaipóri. Archivo pyahu número ndaipóri jave, página órden-pe archivo ojeporu página cantidad mismo. Ejepe'a fila ántes ojeguerova.

## Oñeikuaa porã

- Peteĩ {{key:Mod+Z}} slip-sheet opavave ombogue: kopia, sello ha punch item. Archivo pyahu ojeporu.
- Hoja pyahu tamaño iñambue jave, anotación página ndive ojeisãmba; barra de estado ojerovia ojerevisa hetave.
- Vieja hoja escala pyahu tamaño mismo ha escala ndaipóri jave, ojeguerova.
- Ambue programa ojapo comentario vieja hoja-pe ojekuaa; ko'ápe lectura-solamente.
- Pyahu archivo guardado ojeguarda ojeguerova anotación. Ehecha [Guardar el PDF con anotaciones](topic:save-the-marked-up-pdf).
