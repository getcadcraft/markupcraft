MarkupCraft oñemoĩ desarrollo-pe. Ko'ã ohechauka mba'e ko versión actual **ndojapói**, ikatu replanifica haguã. Ohechauka ko versión ko'ẽrõ, ndaha'éi promesa.

## Ambue ndive ñamba'apo

| Ndojapóiva'ekue | Ko'ẽrõ ejapo |
|---|---|
| Guardado en nube ha sincronización entre computadoras | Umi PDF-kuéra ñongatu umi archivo de proyecto ndive. Guardado en nube ndaipóri ko'ẽrõ. |
| Mokõi persona-kuéra copia anotaciones-kuéra ojoaju | Eparti hoja-kuéra revisor-kuéra ndive, térã ejoaju mbohapy anotación {{key:Mod+C}} ha {{key:Mod+V}} ndive. Umi RFI, submittal ha daily log ojoaju: ehecha [Track RFIs, submittals and daily logs](topic:field-records). |
| Equipos, notificaciones ha proyectos en nube para RFI ha submittal | Pasá PDF-pe ha eporu {{ui:Merge}} ojoaju haguã copias. |
| RFI, submittal ha daily log sesión en vivo-pe | Tuichave persona ojapo ipropio copia-pe; eru copias {{ui:Merge}} ndive. |
| Mokõi persona-kuéra cambio ojoaju campo diferente registro-pe | Copia ojapo last ganá registro entero (umi hilo ha archivo adjunto nombre ojoaju). Ejapo acuerdo mavapa oñemyatyro registro. |
| Herramienta asistente RFI, submittal ha daily log-pe | Emba'apo {{ui:Field}} pestaña-pe. Asistente-kuéra ikatu omba'apo anotación-pe: ehecha [Use MarkupCraft with an AI assistant](topic:use-with-ai-assistants). |
| Respuesta ojevy ha omboriahúpe ojeheja térã ojeheja | Eru {{ui:Undo}} peteĩ jave, térã epoi respuesta ojoaju mbohasa. |
| Mavapa anotación ojapo chupe ojeheja | Ejapo ne rery ante eñepyrũ. |

## Anotaciones

| Ndojapóiva'ekue | Ko'ẽrõ ejapo |
|---|---|
| Sellos ndive campo ojekuatia, firma digital certificada | Eporu sello texto ojapo, ohasa ne rery ha fecha, térã ne firma imagen. |
| Ojegueru archivo PDF ndaha'éiva (documento, video) | Eguarda chupe PDF rovape ha emombe'u comentario-pe. |
| Enlace web térã archivo ndojehévavaekue | Ejeho dirección térã archivo nombre comentario-pe. |
| Estado personalizado | Eporu mokõiva'ẽ estado, ha asunto mba'e ambue rehegua. |
| Comentario ojegueru archivo ndive solo lectura-pe (texto resaltado, ambue programa-kuéra sello) | Ejapo respuesta chupe térã ejapo anotación MarkupCraft chupe ape-pe. |
| Lápiz presión ndive trazo | Eñongatu grosor de línea. |

## Contenido ipropio de la página

| Ndojapóiva'ekue | Ko'ẽrõ ejapo |
|---|---|
| Ejapo forma nueva página-pe tuichaite | Ejapo chupe anotación-kuéra ndive, upéi {{ui:Put into the page}}. Ehecha [Change the page's own content](topic:page-content). |
| Objeto página ojapo mba'eve ángulo-pe | Eme'ẽ ha emoñe'ẽ chupe; eru página entero {{ui:Pages}} ndive. |
| Cambio de fuente térã tamaño línea texto-pe, térã texto ojapo líneas hasýva | Ejapo texto línea-pe; nuevo texto ambue fuente-pe, eagrega anotación texto. |
| Ojeporu ojejapóva imagen escaneada | Ejapo imagen ambue, térã ejapo anotación chupe. |
| PDF ojehepyma térã firmado ojejapo | Eporandu copia ndaha'éiva firma; anotación-kuéra oñemba'apo mba'e PDF-pe. |

## Medición

| Ndojapóiva'ekue | Ko'ẽrõ ejapo |
|---|---|
| Medición de radio | Ejapo {{ui:Arc}} hendive, térã emedí {{ui:Length}} ha eguejy umi mokõi. |
| Ejapo mba'e ángulo cut-out-pe | Emboguete cut-out-kuéra ha ejapo jey. |
| Ojapo escala peteĩ-pe hoja hetavéva | Calibrá hoja peteĩ-peteĩ; preset ojepuru ojepyrũ segundo sapy'ỹi hoja-pe. |
| Escala hetave hoja peteĩ-pe (viewport) | Calibrá umi plano emedi tuichaiterei. Escala ojambia jave hoja, oñemedi opa mba'e; eguarda valor detalle reraity ante recalibrá. |
| Ojojoapy línea plano-pe | Ejapo zoom ante ejapo, térã ejeporu longitud ha ángulo (ehecha [Sketch to scale](topic:calibrate-and-measure#sketch-to-scale)). |
| Takeoff completo ítem, ensamble ha precio ndive | Eporu TakeoffCraft, aplicación takeoff de la familia CadCraft. |
