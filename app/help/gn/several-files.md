Plano conjunto oúva peteĩ PDF peteĩ disciplina-pe térã peteĩ hoja-pe. MarkupCraft opavave ojeporu oñeñandu **peteĩ set**.

## Peteĩ jey ojeporu

Archivo selector-pe opavave PDF peteĩ jey elegí, térã hoja ári opavave soltá. Ambue añadi jave, peteĩ peteĩ oipuru; {{ui:Hojas}} lista ári ojeporu ojeikóva oúva ojeporu órden-pe.

Ojehu: "Ojeporu 6 archivo (84 hoja set-pe)." Opavave página hoja. Hoja número oguereko "Hoja A-101" nombre ryepýpe; ambue archivo ha página ohechauka.

"Set" archivo ndaipóri: ko'ẽro, PDF-kuéra jey ojeporu (guardado "(marked up)" kopia, reñongatu jave).

## Opavave set-pe

- **Hoja juhu:** {{ui:Buscar hojas}} hoja número, hoja nombre ha archivo nombre ojeporu opavave archivo-pe. {{key:PageUp}} ha {{key:PageDown}} opavave archivo hoja ojeporu órden-pe.
- **Anotación lista:** {{ui:Anotaciones}} tab opavave archivo anotación ohechauka. {{ui:Hoja}} ojeguejy ojejuhu. CSV-pe Archivo columna oguereko.
- **Punch lista:** set-pe peteĩ número.
- **Comparar:** hoja vieja ha pyahu ambue archivo-gui oiko hendaitéva.
- **Copiar ha pegar:** hoja peteĩ-pe {{key:Mod+C}}, ambue hoja-pe {{key:Mod+V}}, archivo guive. Kopia página mismo tenonde, peteĩ ñepyrũ ojejoko.

## Guardar

{{ui:Guardar}} eiporavo. Archivo hetave ojeporu jave, MarkupCraft ojeporeka:

- {{ui:Este archivo}}: nde hoja archivo anotado kopia.
- {{ui:Cada archivo cambiado}}: archivo kopia ojeguarda cambio ndoguardáva. Peteĩ peteĩ ojejuhu, "<archivo nombre> (marked up).pdf".
- {{ui:Cancelar}}

:::chromium
Archivo hetave peteĩ jey guardar jave, Chrome ha Edge ojeporeka ko sitio-pe archivo hetave ojejuhu hag̃ua. {{ui:Permitir}} eiporavo; ambue jave peteĩ kopia ojeguerohory.
:::

:::safari
Safari peteĩ peteĩ archivo jave peteĩ jey ojeporeka. iPad-pe peteĩ peteĩ kopia Archivos app-pe ojehupyty.
:::

Anotación guardado archivo ndaiporã cambio; ambue cambio-pe ojeikuaa.

CSV, BCF ha punch lista exportación **primer** archivo nombre ndive ojapo.

## Cerrar

{{ui:Cerrar}} opavave set ojepe'a; peteĩ archivo ndojepe'ai ko'ẽro. Guardado ndaiporã jave ojeporeka:

- {{ui:Cancelar}}: ndojejapói mba'eve.
- {{ui:Cerrar sin guardar}}: guardado anotación ojepoi.
- {{ui:Guardar copias primero}}: opavave cambio archivo ojeguarda, upéi ojepe'a.

Cerrar oñemboguejy deshacer historial.

## Set tuichavéva

- Opavave página texto ojeikuaa hoja número ojuhu hag̃ua, 100 hoja set-pe mboyve. Barra de estado hoja ojeikuaa.
- Lista-pe hoja ojapo ojehecha jave.
- Peteĩ PDF tab memoria-pe ojeguarda. Tab pe'a jave, ambue pesado tab ojepe'a térã disciplina peteĩ jey ehecha.
- Archivo mokõi jey ojeporu, hoja mokõi ojeikuaa. Upéva ojehu jave, {{ui:Cerrar}} ejapytĩ ha set ejeporu jey.
