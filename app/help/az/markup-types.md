## Hər qeydin daşıdıqları

| Sahə | Haradan görürsünüz |
|---|---|
| Müəllif | {{ui:Xüsusiyyətlər}}, siyahı, ştampın ikinci sətri, digər PDF baxıcıları |
| Yaradılma və dəyişdirilmə | {{ui:Xüsusiyyətlər}} (sizin saat qurşağınız), siyahı, CSV |
| Status | Açıq, Qəbul edilib, Rədd edilib və ya Tamamlanıb |
| Mövzu | Qısa etiket; növə görə defolt olur ("Bulud", "Mətn qutusu", "Uzunluq ölçməsi") |
| Şərh | Daha uzun qeydlər. Qeyd üçün onun mətni şərhdir. |
| Mətn | Yalnız mətn qutuları və çağırışlar |
| Cavablar | Söhbət, status dəyişiklikləri ilə |
| Nöqsan elementi | Nömrə, məsul şəxs, son tarix, element statusu, nöqsan siyahısına əlavə edildikdə |
| Üslub | Rəng, xəttin eni, doldurma və doldurmanın şəffaflığı (bağlı formalar, mətn və çağırışlar), şəffaflıq, mətnin ölçüsü (mətn, çağırışlar və ölçmələr) |

## Yalnız oxumaq üçün şərhlər

Faylla birlikdə gələn və MarkupCraft-ın redaktə edə bilmədiyi şərhlər (mətn vurğulamaları, digər proqramların ştampları və digər xüsusi növlər) "Digər" növü və "Yalnız oxumaq üçün" status çipi ilə siyahılanır. Onlar faylın verdiyi görünüşü tam saxlayır. Onları seçə, müəllifini, mövzusunu və şərhini görə və onlara cavab verə bilərsiniz.
