Dinadala ng flattened na kopya ang mga markup bilang bahagi ng drawing, hindi bilang komento. Eksaktong ipinapakita ito ng bawat viewer at printer, at walang makapaglilipat, makapag-e-edit o makakapagbura nito. Gamitin ito para sa final na issue; panatilihin ang karaniwang markup na kopya para sa review.

## I-save ang flattened na kopya

1. Buksan ang isang sheet ng file na nais mong i-flatten.
2. Piliin ang {{ui:Mga pahina}}, saka ang {{ui:I-save ang flattened na kopya…}}.
3. Piliin ang {{ui:Bawat markup sa file na ito}}, o, kapag may napiling markup, ang mga iyon lang. Mananatiling komento sa kopya ang iba.
4. Piliin ang {{ui:I-save ang kopya}}.

Resulta: dina-download ng browser mo ang "<name> (flattened).pdf". Nananatiling mae-edit ang mga markup sa MarkupCraft, at hindi nagbabago ang orihinal mong PDF.

## I-flatten ang ilang markup sa bawat pag-save

Para gawing bahagi ng pahina ang isang larawan, pirma o anumang markup sa kopyang sine-save mo, piliin ito at lagyan ng tsek ang {{ui:I-flatten sa pahina kapag na-save}} sa {{ui:Properties}} (o piliin ito sa right-click menu). Dito, nananatili itong markup: maaari mo pa rin itong ilipat, baguhin ang laki o burahin. Sa bawat pag-save (at kapag nag-e-extract ng mga pahina), iginuguhit ito sa mismong pahina, at sinasabi ng status bar kung ilan ang nagawa. Alisin ang tsek para i-save itong muli bilang markup.

## Dapat malaman

- Hindi pinananatili sa kopya ang mga reply, status at punch item ng flattened na markup: larawan na lang ito ng markup sa kasalukuyan.
- Nananatiling komento ang mga komentong kasama ng file mula sa ibang program.
- Sa bawat pag-print, awtomatikong ginagawang flattened ang kopya para sa iyo. Tingnan ang [I-print, at baguhin ang mga pahina](topic:pages-and-printing).
