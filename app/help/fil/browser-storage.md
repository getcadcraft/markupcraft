Walang account at walang server storage ang MarkupCraft. Ang ilang maliliit na bagay ay nakalagay sa storage ng browser mo para sa website na ito, at ang iba ay nasa mga file mo.

## Ano ang nakalagay sa browser

| Ano | Saan itinatakda | Nakalagay bilang |
|---|---|---|
| Pangalan mo bilang author | Ang name button sa status bar, o {{ui:Mga setting}} | Isang pangalan |
| Mga setting ng MarkupCraft | {{ui:Mga setting}}, {{ui:MarkupCraft}} tab: kulay at kapal ng linya ng mga bagong markup, saan ilalagay ng paste ang mga kopya, mga unit (tingnan ang [MarkupCraft settings](topic:settings)) | Isang set |
| Mga setting ng tool | {{ui:Properties}} habang naka-on ang drawing tool: kulay, linya, fill, opacity at laki ng teksto kada tool, ang napiling stamp, ang pangalan ng count group | Isang set |
| Tool chest | Ang {{ui:Mga tool}} tab | Hanggang 500 tool |
| Ang huling kinopya mo | {{ui:Kopyahin}} o {{ui:Gupitin}} | Ang mga kinopyang markup, para ma-paste sila ng ibang tab; napapalitan ng susunod na kopya |
| Larawan ng stamp at pirma | {{ui:Larawan…}} at {{ui:Ang pirma ko…}} sa listahan ng stamp | Ang huling larawan at ang pirma mo |
| Mga recovery copy | Itinatago para sa iyo habang may markup na hindi pa na-save ang PDF | Ang PDF at mga markup nito, tinatanggal kapag na-save, isinara o itinapon mo ito; itinatago hanggang 30 araw |

## Ano ang ibig sabihin nito

- **Kada browser, kada computer.** Magkahiwalay ang Chrome at Firefox sa iisang computer. Magkahiwalay din ang laptop mo at ang office desktop. Walang nagsi-sync sa pagitan nila, kahit naka-sign in ka sa browser.
- **Ang private at incognito window ay nagsisimulang walang laman** at nakakalimot ng lahat kapag isinara.
- **Binubura ng pag-clear ng site data ang lahat.** Ang pag-clear ng cookies at site data para sa website na ito, o para sa lahat ng site, sa settings ng browser ay nag-aalis ng pangalan, setting, at chest mo. May ilang cleanup tool at company policy na awtomatikong gumagawa nito.
- **Walang ina-upload.** Hindi umaalis sa computer ang mga value na ito, maliban sa pangalan mo sa loob ng mga PDF na sine-save mo. Nananatili rin sa browser na ito ang mga recovery copy.

:::safari
Maaaring burahin ng Safari ang nakaimbak na data ng isang website pagkatapos ng ilang linggong hindi nabisita. Buksan paminsan-minsan ang MarkupCraft, at magtabi ng na-export na tool chest.
:::

## Ano ang hindi nakalagay sa browser

- **Ang mga markup mo, pangmatagalan.** Dapat nasa "(marked up)" PDF na sine-save mo ang mga ito. Ang recovery copy ay pang-salbabida lang sa crash o nakasarang tab, hindi lugar para itago ang trabaho: nawawala ito kapag na-save mo, at binubura ito ng pag-clear ng site data. Tingnan ang [Recover your work](common:recover).
- **Ang mga bukas mong file.** Sa bawat pagbukas ng MarkupCraft, buksan muli ang mga PDF.
- **Ang sheet na kinaroroonan mo, zoom, mga filter at undo history.** Tumatagal ang mga ito hanggang isara mo ang set o ang tab.

## I-back up at ilipat ang setup mo

- **Tool chest:** {{ui:Mga tool}}, saka {{ui:I-export}}. Sa ibang browser o computer, {{ui:Mga tool}}, saka {{ui:I-import}}.
- **Pangalan:** i-type ulit sa ibang browser (i-click ang name button sa status bar).
- **Mga setting ng tool:** itakda ulit, o i-save ang bawat naka-style na markup bilang tool para dumala ito kasama ng chest.

## Magsimula ulit

Para i-reset ang lahat, i-clear ang data ng website na ito sa settings ng browser mo. Mawawala ang pangalan, mga setting, at chest mo; babalik ang anim na default na tool.

## Ang offline copy

Ang {{ui:I-save para sa offline}} sa bar sa itaas ay nag-iimbak din ng sariling file ng app (kasama ang PDF reader at writer, mga 6 MB) sa browser, hiwalay sa mga setting na ito. Binubura ng pag-clear ng site data ang copy na ito din; i-click ang "Handa na offline" at piliin ang "Alisin ang offline copy" para alisin lang ito. Tingnan ang [Working offline](common:offline).

Hindi pa available ang cloud saving at sync sa pagitan ng mga computer.
