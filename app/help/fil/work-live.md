## Ano ang matututunan mo

Ano ang nangyayari sa mga markup habang ilang tao ang nagre-review ng iisang plan set sa parehong oras. Sinisimulan at sinasalihan ng CadCraft Studio ang Live TeamWork session (I-share ang live, Sumali); tungkol sa mismong set ang pahinang ito.

## Lahat ay nagma-markup nang sabay

Ang mga PDF ng host ay dumarating sa lahat ng sumasali, kaya pareho kayong tumitingin sa parehong sheet. Gumuhit, ilipat, baguhin ang estilo at burahin ang mga markup gaya ng dati. Agad lumalabas ang sarili mong pagbabago; ang sa ibang tao ay lumalabas makalipas ang sandali pagkatapos nilang gawin ang mga ito.

- **Dalawang tao ang nagbago ng iisang markup:** magkaibang bagay (isa ang color, ang isa ang line weight) ay parehong napapanatili. Ang parehong bagay ay mapupunta sa mas huling pagbabago.
- **Mga reply:** nananatili sa thread ang reply ng lahat, ayon sa pagkakasulat. Ganoon din ang paglalakbay ng mga status.
- **Mga scale at pangalan ng sheet** na itinakda ng sinuman ay nalalapat sa lahat.
- **Hindi kailanman nauulit ang punch number:** kung dalawang tao ang magdaragdag ng punch item sa parehong sandali, babawiin ang isa sa kanila at maaari niya itong idagdag muli.

Sa iyo lamang nananatili ang: mga layer na itinago o nilock mo, custom column, ang view, ang tool mo, at ang pangalan mo bilang author.

## Tingnan kung sino ang nasaan

May sariling color ang bawat reviewer. Sa sheet na tinitingnan mo, makikita mo ang pointer ng iba kasama ang kanilang mga pangalan, at isang may tuldok na kahon sa kulay nila sa paligid ng mga markup na pinili nila. May strip ng mga reviewer sa kanang itaas ng sheet: ipinapakita nito kung aling sheet ang kinaroroonan ng bawat isa, at ang pag-click sa pangalan ay dadalhin ka sa sheet na iyon.

Sa listahan ng markup, may tuldok sa color ng reviewer sa tabi ng pangalan ng author, kaya makikita mo agad kung sino ang sumulat ng alin. Hinahanap ng filter ng author ang mga markup ng isang reviewer. I-save ang PDF at dala ng bawat markup ang author nito, kaya ang na-review na set ay nagpapakita kung sino ang sumulat ng alin.

Para lang sa session ang mga pointer at color; hindi ito naka-save sa PDF.

## Kapag binawi ang isang pagbabago

Sinusuri ng kopya ng host ang bawat pagbabago. Ang hindi maisasama ay binabawi sa screen mo, at sinasabi ng status bar kung bakit, halimbawa kapag may nagbura ng markup na iyon bago ka pa.

## Ang I-undo ay nag-u-undo ng sarili mong gawa

{{key:Mod+Z}} ang nag-u-undo ng sarili mong huling pagbabago at iniiwan ang sa iba. Kapag may nagbago na ng parehong bagay mula noon, walang iu-undo at sinasabi ng status bar kung sino.

## Sumali mula sa browser

Maaaring i-scan ng kasamahang walang Studio ang larawan sa ilalim ng code ng host gamit ang phone, tablet o computer sa parehong network. Bubukas ang MarkupCraft sa browser at mapupunan ng plan set ng host kapag pinapasok ka na ng host. Pinapayagan ng invite link ang isang tao na sumali mula sa ibang network: kailangan ng host ng Team Cloud Plan seat para sa app, libre ang pagsali ng lahat ng iba, at gumagana ang link habang bukas ang session ng host.

## Kapag natapos ang session

Ang host lamang ang nagsa-save ng mga marked-up na PDF. Ang iba ay may hindi naka-save na kopya: i-save ito kung gusto mo itong itago.

:::note
Ang mga PDF na bubuksan mo pagkatapos sumali ay mananatili sa sarili mong screen: hindi ito natatanggap ng iba.
:::
