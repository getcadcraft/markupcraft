Ang MarkupCraft ay para sa pagrepaso ng mga drawing: nagbubukas ka ng mga PDF na set ng plano, minamarkahan ang mga ito ng cloud, callout, text, stamp at sukat, sinusubaybayan ang status ng bawat komento, at nagse-save ng kopya ng PDF na kayang ipakita ng anumang PDF viewer.

Tumatakbo ito sa web browser mo. Binubuksan ang mga PDF mo sa sarili mong computer at **hindi kailanman ina-upload**. Ang pag-save ay nagda-download ng bagong kopya; hindi nababago ang orihinal mong file.

:::note
Ginagawa pa ang MarkupCraft. Inilalarawan ng help ang build na ginagamit mo. Ang mga bagay na hindi pa nito kayang gawin ay nakalista sa [Ano ang hindi pa nagagawa](topic:not-built-yet).
:::

## Ang kailangan mo

- Bagong bersyon ng Chrome, Edge, Firefox o Safari sa Mac, Windows o Linux na computer, o Safari o Chrome sa iPad. Tingnan ang [Mga browser at computer](common:browsers).
- Isa o higit pang PDF file. Ang buong set ng plano ay puwedeng isang PDF o marami.
- Pinakakomportable ang mouse na may wheel. Gumagana rin ang trackpad, at gayundin ang touch screen (tingnan ang [Pagrepaso sa iPad o touch screen](topic:review-on-a-tablet)).

## Ang unang pagrepaso mo sa sampung hakbang

1. Buksan ang MarkupCraft sa browser mo. Nakasulat sa gitna ng screen ang "Buksan ang set ng plano".
2. Piliin ang {{ui:Open PDFs}} (o ang {{ui:Open}} sa kaliwang dulo ng toolbar, o pindutin ang {{key:Mod+O}}), pumili ng isa o higit pang PDF, at kumpirmahin.
   Puwede mo ring i-drag ang mga PDF mula sa {{pick:mac=Finder|windows=File Explorer|linux=ang file manager ng iyong computer}} at i-drop sa bahagi ng sheet.
   Sa unang pagkakataon, sinasabi ng status bar sa ibaba ang "Dine-load ang PDF reader…". Pagkatapos, nagiging sheet ang bawat pahina sa listahan ng {{ui:Sheets}} sa kaliwa, at pinupuno ng unang sheet ang gitna.
3. I-click ang isang sheet sa listahan para ipakita ito. I-ikot ang mouse wheel sa ibabaw ng sheet para mag-zoom in sa kinaroroonan ng pointer.
4. Piliin ang {{ui:Cloud}} sa grupong {{ui:Revise}} ng toolbar (o pindutin ang {{key:C}}).
   Sa unang pagpili mo ng drawing tool, magtatanong ang MarkupCraft ng pangalan mo. I-type ito at piliin ang {{ui:Save}}. Itinatala ito ng bawat markup. (Higit pa sa [Itakda ang pangalan ng may-akda](topic:set-your-name).)
5. I-drag ang kahon sa palibot ng bahaging gusto mong markahan. Lumilitaw ang pulang revision cloud at napipili ito.
6. Piliin ang {{ui:Callout}} sa grupong {{ui:Annotate}} (o pindutin ang {{key:K}}). Pindutin ang bagay na tinuturo mo, i-drag papunta sa lugar kung saan dapat ang text, at bitawan.
7. I-type ang komento mo sa kahong lumilitaw. I-click kahit saan sa labas ng kahon (o pindutin ang {{key:Mod+Enter}}) para tapusin.
8. Pindutin ang {{key:Esc}} nang dalawang beses: minsan para alisin ang pagpili, minsan para bumalik sa tool na {{ui:Select}}. I-click ang cloud. Ipinapakita ng tab na {{ui:Properties}} sa kanan kung sino ang gumawa nito, kailan, at ang {{ui:Status}} nito.
9. Piliin ang {{ui:Save}} sa toolbar (o pindutin ang {{key:Mod+S}}).
   Dina-download ng browser mo ang kopyang may pangalang gaya ng "A-Plans (marked up).pdf". Inililista ng status bar kung ilang markup ang naisulat.
10. Buksan ang kopyang iyon sa anumang PDF viewer para suriin: naroon ang cloud at callout, bilang normal na PDF comment na may pangalan mo.

Para magpatuloy sa ibang pagkakataon, buksan ang kopyang "(marked up)" sa MarkupCraft. Bumabalik na maaari nang i-edit ang mga markup mo, kasama ang kanilang status, sagot at punch number.

## Online at offline

:::online
Online ka. Dine-load ng MarkupCraft ang PDF reader nito sa unang beses mong magbukas ng PDF, at ang PDF writer nito sa unang beses mong mag-save. Para makapagtrabaho nang walang koneksyon sa susunod (sa site visit, sa eroplano), piliin ang {{ui:Save for offline}} sa bar sa itaas ngayon at hintayin ang "Offline ready". Kasama sa kopya ang PDF reader at writer, kaya gagana na offline ang pagbubukas at pag-save ng mga PDF. Tingnan ang [Pagtatrabaho offline](common:offline).
:::

:::offline
Offline ka. Kung sinasabi ng bar sa itaas ang "Offline ready", na-save ang MarkupCraft para magamit offline sa browser na ito at gumagana ang lahat: pagbubukas, pag-markup, pagsukat, pag-save. Kung hindi, gamitin ang mga nakarga na sa tab na ito at huwag i-reload ang pahina hangga't hindi ka bumabalik sa online. Tingnan ang [Pagtatrabaho offline](common:offline).
:::

## Ang naaalala ng app, at ang hindi

- **Nasa PDF na sine-save mo ang mga markup mo.** Walang anumang itinatago sa server. Hindi awtomatikong sine-save ng app ang PDF, pero nagtatago ito ng kopya ng pagbawi sa browser na ito hanggang sine-save mo. I-save bago isara ang tab; magtatanong muna ang browser kung susubukan mong umalis na may hindi pa nase-save na markup (maliban sa iPad, tingnan ang [Pagrepaso sa iPad o touch screen](topic:review-on-a-tablet)).
- **Ang pangalan mo, ang mga istilo ng tool mo at ang tool chest mo** ay nananatili sa browser na ito sa computer na ito. Ang ibang browser o computer ay magsisimula nang bago, at ang pagbura sa site data ng browser ay nagtatanggal sa mga ito. Tingnan ang [Ano ang nananatili sa browser na ito](topic:browser-storage).
- Hindi pa available ang cloud saving at mga sesyon ng pagrepaso na ibinabahagi sa mga tao.
