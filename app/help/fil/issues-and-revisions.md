## Ang gagawin mo

Magtrabaho mula sa parehong kasaysayan ng issue gaya ng iba pang team. Tingnan kung aling mga sheet ang lumabas sa aling revision, at itala ang nangyayari sa site laban sa issue na kinabibilangan nito.

## Mga hakbang

1. Buksan ang **Mga issue at revision**.
2. Piliin ang **Basahin ang kasaysayan ng issue** at pumili ng `.issues.json` na file na na-save mula sa BimCraft o ibang app. Idinadagdag sa iyo ang mga issue at record nito. Walang napapalitan.
3. Piliin ang **Magdagdag ng record** para sa site instruction, shop drawing, markup set, naka-link na model o note. Piliin ang issue na kinalalagyan nito at ang status nito. Itinatala ang file na pipiliin mo ayon sa pangalan, laki at SHA-256 nito; nananatili sa dating lugar ang file.
4. Ipinapakita ng **Drawing changelog** ang isang hilera para sa bawat sheet at isang kolumn para sa bawat issue. Ang revision na nasa loob ng bracket ay muling inilabas nang walang pagbabago.
5. Sine-save ng **I-download ang changelog (CSV)** ang mga issue, talaan ng sheet at mga record. Sumusulat ang **I-save ang kasaysayan ng issue** ng file na nababasa ng ibang app.

## Dapat malaman

- Ang **Itala ang mga napiling markup** ay nilalagay ang mga napili mong markup laban sa pinakahuling issue. Naitatala ang cloud bilang revision cloud sa revision ng issue na iyon. Piliin ang **Ipakita** sa tabi ng record para tumalon dito.
- Ang **Itala ang isang issue** ay naglalabas ng mga sheet mong may markup. Pagkatapos, sinasabi ng **Mga pagbabago mula noon** kung aling mga sheet ang namarkahan pagkatapos ng issue na iyon.
- Naka-save ang kasaysayan sa loob ng PDF na may markup. Hindi ito bahagi ng I-undo.
- Ang pagbasa sa parehong file nang dalawang beses ay walang idinadagdag na dalawang beses. Kapag parehong record ang hawak ng dalawang kopya, ang mas bago ang itinatabi.
