Sa isang Live session, maaari mong gawing sundan ang view ng isang kasamahan, halimbawa ng guro na ginagabayan ang klase sa isang sheet. Tungkol sa pagsunod ang pahinang ito; ang pagsisimula at pagsali sa session ay ginagawa sa CadCraft Studio, tingnan ang [Sabay na suriin ang isang plan set gamit ang Live TeamWork](topic:work-live).

## Ang gagawin mo

Sundan ang isang tao, itigil ang pagsunod, at (bilang host) hilingin sa lahat na sundan ka.

## Mga hakbang

1. Sa isang Live session, buksan ang listahan ng mga tao. Ipinapakita nito ang kulay at pangalan ng bawat tao.
2. Piliin ang {{ui:Sundan}} sa tabi ng pangalan ng taong susundan. Nagbabasa ang status line ng {{ui:Sinusundan}} at pangalan nila, at gumagalaw ang view mo kasabay ng kanila.
3. Para tumigil, piliin ang {{ui:Itigil ang pagsunod}}, o i-pan o i-zoom lang ang sarili mong view: humihinto ang pagsunod nang kusa.
4. Bilang host, piliin ang {{ui:Sabihan ang lahat na sundan ako}} para hilingin sa buong grupo na sundan ka. Piliin ang {{ui:Itigil ang paghiling sa lahat na sundan ako}} para tapusin ito.

## Dapat malaman

- Ipinapakita ng bawat tao ang sheet na kinaroroonan nila at kung kailan ang huli nilang edit, para makita ng guro kung sino ang may progreso.
- Kung ang taong sinusundan mo ay nasa view na hindi maaaring sundan, o nasa ibang sheet, ang status line ang magsasabi kung nasaan sila.
- Ang pagsunod ay nagbabago lang sa view mo. Walang nasa-save sa file.
- Hindi pa nasusubukan ang class view kasama ang totoong guro at mga estudyante.
