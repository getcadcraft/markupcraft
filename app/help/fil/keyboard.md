## Habang gumuguhit

| Key o aksyon | Ano ang ginagawa |
|---|---|
| {{key:Shift}} habang gumuguhit | Mga linya, arrow, haba at gilid ng polyline sa 45° na hakbang; nagiging parisukat ang rectangle, ellipse at box cloud; isang tuwid na stroke ang pen at highlighter |
| Double-click, {{key:Enter}} o right-click | Tapusin ang polyline, polygon, free cloud o area |
| {{key:Backspace}} | Alisin ang huling punto ng polyline, polygon, free cloud o area |
| {{key:Esc}} | Kanselahin ang iginuguhit; kapag walang ginagawa, burahin ang pagpili; kapag walang napili, bumalik sa {{ui:Piliin}} |
| {{key:Mod+Enter}} | Tapusin ang pag-type sa text box, callout o note (o mag-click sa labas nito) |
| {{key:Esc}} habang nagta-type | Kanselahin ang tekstong tina-type |
| {{key:Shift}}-click gamit ang {{ui:Bilang}} | Alisin ang pinakamalapit na tuldok ng napiling count group |

## Cut, copy at paste

Parehong utos ang nasa grupong {{ui:I-edit}} ng toolbar ({{ui:Kopyahin}}, {{ui:I-paste}}) at sa menu nitong {{ui:Iba pa}}, bawat isa ay may kanyang key. Bawat isa ay iisang hakbang ng undo. Tingnan ang [Kopyahin, i-paste at i-duplicate](topic:select-and-edit#copy-paste-and-duplicate).

| Key | Ano ang ginagawa |
|---|---|
| {{key:Mod+X}} | Cut: kopyahin ang pagpili at burahin ito |
| {{key:Mod+C}} | Kopyahin ang pagpili |
| {{key:Mod+V}} | I-paste. Kapag nasa sheet ang pointer, nasa gitna ng itinuturo nito ang kopya; kung hindi, katabi ng orihinal. Maaaring itakda sa mga setting na laging katabi ng orihinal ang paste. |
| {{key:Mod+Shift+V}} | I-paste sa parehong lugar: ang eksaktong puwesto sa sheet, sa sheet na ito o sa iba |
| {{key:Mod+D}} | I-duplicate ang pagpili sa tabi nito (hindi nagagalaw ang clipboard) |

## Zoom at pan

| Key o aksyon | Ano ang ginagawa |
|---|---|
| Mouse wheel | Mag-zoom in o out sa paligid ng pointer (hindi kailanman nag-i-scroll ang wheel) |
| {{key:Ctrl}} + wheel | Mas mabilis na zoom |
| {{key:Plus}} o {{key:Minus}} (kasama rin ang {{key:Mod}}) | Mag-zoom in o out sa gitna; gumagana rin ang {{key:=}} bilang plus |
| {{key:Mod+0}} | {{ui:Kasyaan ang pahina}} |
| {{key:Mod+9}} | {{ui:Kasyaan ang lapad}} |
| I-drag gamit ang middle button | Pan |
| I-drag gamit ang right button | Pan (kapag wala ka sa gitna ng polyline) |
| Hawakan ang {{key:Space}} at i-drag | Pan |
| Arrow keys kapag walang napili | Pan |
| {{key:Ctrl+Shift+F}} | Screen mode: normal, full screen, full screen na nakatago ang mga bar (Control key sa bawat computer) |

:::mac
**Sa trackpad:** ang two-finger scrolling ay nagzu-zoom. Nagzu-zoom din ang pinch sa Chrome, Edge at Firefox. Mag-pan gamit ang {{key:Space}} habang nagda-drag, o gamit ang tool na {{ui:Pan}}. Ang two-finger click ay right-click at tinatapos ang polyline. Maaaring ituring ng Control-click dito na simpleng click sa halip na right-click, kaya gamitin ang two-finger click.
:::

:::touch
## Touch

| Gesture | Ano ang ginagawa |
|---|---|
| Isang daliri | Gumuhit gamit ang kasalukuyang tool, o pumili |
| Dalawang daliri | I-pinch para mag-zoom sa gitna nila, galaw para mag-pan |
| Ikalawang daliri habang may stroke | Kinakansela ang stroke at nag-zoom na lang |
| Double-tap | Tapusin ang polyline, polygon, free cloud o area |

Ang bilang ng tuldok, note, punto ng polyline at ikalawang punto ng two-point tool ay inilalagay pag-angat ng daliri. Tingnan ang [Review sa iPad o touch screen](topic:review-on-a-tablet).
:::

## Mga shortcut na pinananatili ng browser

- {{key:Mod+W}}, {{key:Mod+T}}, {{key:Mod+N}} at {{key:Mod+Q}} ay sa browser. Ang pagsasara ng tab o window na may hindi pa na-save na markup ay magkakawala sa mga ito, pagkatapos ng tanong ng browser na "Leave site?" sa computer.
- Karamihan ng browser ay nagtatalaga ng {{key:Mod+N}} sa bagong window, kaya sa browser tab, gamitin ang {{ui:Bago}} sa toolbar; ipinapasa ng desktop app at ng Studio ang key sa MarkupCraft.
- Kinukuha ng MarkupCraft ang {{key:Mod+O}}, {{key:Mod+S}}, {{key:Mod+D}}, {{key:Mod+A}}, {{key:Mod+V}}, {{key:Mod+Shift+V}}, {{key:Mod+0}}, {{key:Mod+Plus}} at {{key:Mod+Minus}} mula sa browser habang may keyboard ang app, at ang {{key:Mod+C}} at {{key:Mod+X}} habang may napiling markup. Ang {{key:Mod+,}} ay nagbubukas ng {{ui:Mga setting}}. Para mag-zoom sa buong browser page, gamitin ang menu ng browser.
- Ang {{key:Mod+9}} ay tumatalon sa huling browser tab sa ilang browser bago ito makita ng MarkupCraft. Kung mangyari iyon, gamitin ang {{ui:Kasyaan ang lapad}} sa ilalim ng sheet.
- Ang {{key:Esc}} sa full screen ay lumalabas din sa full screen.

## Kapag walang nangyari sa key

- **Nagta-type ka sa kahon.** I-click muna ang sheet. (Gumuguhit ang click kapag may drawing tool; pindutin ang {{key:Esc}} pagkatapos, o gamitin ang {{key:Mod+Z}}.)
- **May bukas na dialog.** Napupunta ang mga key sa dialog hanggang magsara ito.
- **Kaka-click mo lang sa toolbar button** at ang arrow keys o {{key:Space}} ay gumagana sa button na iyon. Ilipat ang pointer sa sheet at gamitin ang wheel o middle button, o pindutin ang tool letter sa halip na mag-click sa mga button.

## Saan makikita ang Move

Walang Move command: pumili ng markup at i-drag ito ({{key:Shift}} ang nagpapanatili ng 45° na hakbang). Ang pin ay inililipat gamit ang {{ui:Ilipat ang pin}}, at ang pahina gamit ang {{ui:Ilipat ang pahina pauna}} o {{ui:Ilipat ang pahina pahuli}}.
