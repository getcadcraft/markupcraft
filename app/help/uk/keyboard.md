Комбінації, записані як {{key:Mod}}, працюють із ⌘ або Control на Mac і з Ctrl у Windows та Linux. Клавіші інструментів працюють лише тоді, коли ви не вводите текст у полі; під час введення літери є просто літерами. Див. також [Клавіші, миші та трекпади](common:keys).

## Під час малювання

| Клавіша або дія | Що робить |
|---|---|
| {{key:Shift}} під час малювання | Лінії, стрілки, довжини та сторони полілінії йдуть кроками 45°; прямокутники, еліпси та рамки хмар стають квадратними; олівець і маркер малюють одну пряму лінію |
| Подвійне клацання, {{key:Enter}} або клацання правою кнопкою | Завершує полілінію, багатокутник, вільну хмару або область |
| {{key:Backspace}} | Видаляє останню точку полілінії, багатокутника, вільної хмари або області |
| {{key:Esc}} | Скасовує те, що малюєте; якщо нічого не малюється, знімає вибір; якщо нічого не вибрано, повертає до інструмента {{ui:Select}} |
| {{key:Mod+Enter}} | Завершує введення в текстовому полі, виносці або примітці (або клацання поза ним) |
| {{key:Esc}} під час введення | Скасовує текст, який ви вводили |
| {{key:Shift}}-клацання з {{ui:Count}} | Прибирає найближчу точку вибраної групи підрахунку |

## Вибір і редагування

| Клавіша або дія | Що робить |
|---|---|
| Клацання | Вибирає розмітку |
| {{key:Shift}}-клацання | Додає розмітку до вибору або прибирає її |
| Перетягування зліва направо по порожньому аркушу | Вибирає те, що повністю всередині вікна |
| Перетягування справа наліво по порожньому аркушу | Вибирає те, чого торкається вікно |
| {{key:Mod+A}} | Вибирає всю розмітку на цьому аркуші |
| Перетягування вибраної розмітки | Переміщує її ({{key:Shift}}: кроками 45°) |
| Перетягування маркера | Змінює розмір або форму ({{key:Shift}}: зберігає пропорції або кут 45°) |
| Клавіші зі стрілками | Зсуває вибране на один піксель екрана ({{key:Shift}}: на десять) |
| Подвійне клацання або {{key:Enter}} | Редагує текст текстового поля, виноски або примітки; для штампа відкриває {{ui:Properties}} |
| {{key:Delete}} або {{key:Backspace}} | Видаляє вибране |
| {{key:Esc}} | Знімає вибір |
| {{key:Mod+Z}} | Скасувати дію |
| {{key:Mod+Y}} або {{key:Mod+Shift+Z}} | Повторити дію |

## Вирізання, копіювання та вставлення

Ті самі команди є в групі {{ui:Edit}} на панелі інструментів ({{ui:Copy}}, {{ui:Paste}}) і в меню {{ui:More}}, кожна з власною клавішею. Кожна з них — один крок скасування. Див. [Копіювання, вставлення та дублювання](topic:select-and-edit#copy-paste-and-duplicate).

| Клавіша | Що робить |
|---|---|
| {{key:Mod+X}} | Вирізати: копіює вибране і видаляє його |
| {{key:Mod+C}} | Копіювати вибране |
| {{key:Mod+V}} | Вставити. Якщо вказівник на аркуші, копія з’являється по центру там, куди він вказує; інакше — поруч з оригіналом. У налаштуваннях можна зробити так, щоб вставлення завжди було поруч з оригіналом. |
| {{key:Mod+Shift+V}} | Вставити на місце: у те саме місце на аркуші, на цьому або іншому аркуші |
| {{key:Mod+D}} | Дублювати вибране поруч із ним (буфер обміну не змінюється) |

## Масштаб і зсув

| Клавіша або дія | Що робить |
|---|---|
| Коліщатко миші | Масштабує (збільшує або зменшує) навколо вказівника (колесо ніколи не прокручує) |
| {{key:Ctrl}} + колесо | Масштабує швидше |
| {{key:Plus}} або {{key:Minus}} (також із {{key:Mod}}) | Збільшує або зменшує навколо центру; {{key:=}} працює як плюс |
| {{key:Mod+0}} | {{ui:Fit page}} |
| {{key:Mod+9}} | {{ui:Fit width}} |
| Перетягування середньою кнопкою | Зсув |
| Перетягування правою кнопкою | Зсув (якщо ви не посеред полілінії) |
| Утримуйте {{key:Space}} і перетягуйте | Зсув |
| Клавіші зі стрілками, коли нічого не вибрано | Зсув |
| {{key:Ctrl+Shift+F}} | Режим екрана: звичайний, повноекранний, повноекранний із прихованими панелями (клавіша Control на кожному комп’ютері) |

:::mac
**На трекпаді:** прокручування двома пальцями масштабує. Щипок також масштабує в Chrome, Edge і Firefox. Зсувайте, утримуючи {{key:Space}} під час перетягування, або інструментом {{ui:Pan}}. Клацання двома пальцями — це клацання правою кнопкою, і воно завершує полілінію. Клацання з Control тут може працювати як звичайне клацання, а не як клацання правою кнопкою, тому користуйтеся клацанням двома пальцями.
:::

## Сенсорний екран

| Жест | Що робить |
|---|---|
| Один палець | Малює поточним інструментом або вибирає |
| Два пальці | Щипок масштабує навколо їхньої середини, рух — зсуває |
| Другий палець під час штриха | Скасовує штрих і натомість масштабує |
| Подвійне торкання | Завершує полілінію, багатокутник, вільну хмару або область |

Точки підрахунку, примітки, точки полілінії та друга точка інструмента з двома точками ставляться, коли палець відривається від екрана. Див. [Перегляд на iPad або сенсорному екрані](topic:review-on-a-tablet).
:::

## Комбінації, які зберігає браузер

- {{key:Mod+W}}, {{key:Mod+T}}, {{key:Mod+N}} і {{key:Mod+Q}} належать браузеру. Закриття вкладки або вікна з незбереженою розміткою призводить до втрати змін після запитання браузера «Залишити сайт?» на комп’ютері.
- Більшість браузерів зберігають {{key:Mod+N}} для нового вікна, тож у вкладці браузера використовуйте {{ui:New}} на панелі інструментів; настільний застосунок і Studio передають клавішу в MarkupCraft.
- MarkupCraft забирає в браузера {{key:Mod+O}}, {{key:Mod+S}}, {{key:Mod+D}}, {{key:Mod+A}}, {{key:Mod+V}}, {{key:Mod+Shift+V}}, {{key:Mod+0}}, {{key:Mod+Plus}} і {{key:Mod+Minus}}, поки застосунок має клавіатуру, а {{key:Mod+C}} і {{key:Mod+X}} — коли вибрано розмітку. {{key:Mod+,}} відкриває {{ui:Settings}}. Щоб масштабувати всю сторінку браузера, скористайтеся меню браузера.
- {{key:Mod+9}} у деяких браузерах переходить до останньої вкладки раніше, ніж MarkupCraft його побачить. Якщо так, скористайтеся {{ui:Fit width}} під аркушем.
- {{key:Esc}} у повноекранному режимі також виходить із нього.

## Коли клавіша нічого не робить

- **Ви вводите текст у полі.** Спершу клацніть на аркуші. (Клацання інструментом малювання щось малює; після цього натисніть {{key:Esc}} або використайте {{key:Mod+Z}}.)
- **Відкрите діалогове вікно.** Клавіші надходять до діалогу, доки він не закриється.
- **Ви щойно клацнули кнопку на панелі інструментів**, і клавіші зі стрілками або {{key:Space}} діють на цю кнопку. Наведіть вказівник на аркуш і скористайтеся колесом або середньою кнопкою або натисніть літеру інструмента замість клацання кнопок.

## Де перемістити

Окремої команди «Перемістити» немає: виберіть розмітку й перетягніть її ({{key:Shift}} зберігає кроки 45°). Мітку переміщують інструментом {{ui:Move pin}}, а сторінку — командами {{ui:Move page earlier}} або {{ui:Move page later}}.
