Двоє людей розмічають той самий PDF у двох копіях. Якщо вони торкнулися різної розмітки, копії може об’єднати програма, а не людина вручну.

## Як це працює

Кожна розмітка, яку зберігає MarkupCraft, несе власну назву (її ідентифікатор) всередині PDF, і ця назва ніколи не змінюється. Злиття знаходить розмітку за цією назвою, а не за її місцем у файлі, бо кожна програма перенумеровує місця під час збереження. Примітки та приватні запечатані примітки зіставляються так само.

Аркуші ніколи не змінюються: обидві копії мають мати однакову кількість сторінок. Якщо їх кількість різна, злиття залишає вашу копію без змін і каже про це, бо додавання або видалення сторінок — робота людини.

## Налаштування

Git потребує двох рядків один раз для кожного репозиторію:

```
# .gitattributes
*.pdf merge=cadcraft

# один раз на кожному комп’ютері
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Без git виконайте `cadcraft merge <base> <ours> <theirs> -o <result>`. Fossil і Mercurial беруть ті самі три файли в налаштуванні власного інструмента злиття. Файл завдань, що супроводжує креслення (`<name>.markups.json`, див. [Розмітка, що діє](topic:markups-that-act)), зливається так само, як простий текст.

## Правила

- Розмітка, змінена лише з одного боку, береться. Та сама зміна з обох боків береться один раз.
- Та сама розмітка, змінена двома способами, — це **конфлікт**: ваша сторона лишається, а звіт перелічує обидві. Відкрийте результат і виправте цю розмітку вручну.
- Розмітка, додана з будь-якого боку, зберігається. Та, що видалена з одного боку і не змінена з іншого, видаляється. Видалена з одного боку і змінена з іншого: видаляється і звітується.
- Шари, стовпці, записи та примітки підпорядковуються тим самим правилам.
- Приватні запечатані примітки ніколи не відкриваються: блоки обох сторін зберігаються як є.

Злитий файл — це повний перезапис вашої копії, як і власне збереження MarkupCraft. Нічого не вивантажується; усе працює на вашому комп’ютері.
