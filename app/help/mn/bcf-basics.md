BCF (BIM Collaboration Format) нь BIM хэрэгслүүдийн хооронд асуудлуудыг дамжуулах нээлттэй файлын формат юм. Загвар зохицуулах болон загвар боловсруулах олон программ `.bcfzip` файлыг асуудлуудын жагсаалт болгон импортлож чадна. MarkupCraft **BCF 2.1** форматаар бичдэг.

## Нэгийг үүсгэх

1. {{ui:Тэмдэглэгээнүүд}} табыг нээнэ.
2. Жагсаалтаа илгээх зүйлдээ шүүнэ, жишээ нь {{ui:Статус}} "Нээлттэй" гэж. Зөвхөн жагсаалтад байгаа тэмдэглэгээнүүд экспортлогдоно.
3. {{ui:BCF}} сонгоно.
4. Тэмдэглэгээ бүрийн агшинг үүсгэж дуустал хүлээнэ ("BCF-д зориулж агшин үүсгэж байна (5 / 20)…").

Үр дүн: "<name> markups.bcfzip" татагдана, статус мөр нь хэдэн сэдэвтэй болохыг болон файлын хэмжээг харуулна.

## Агуулга

Тэмдэглэгээ бүр нэг **сэдэв** болно:

| Сэдвийн талбар | Юугаар дүүрэх |
|---|---|
| Гарчиг | Дугаар, сэдэв, хуудас, жишээ нь "#4 A-101 дээрх үүл — Давхрын план" |
| Төрөл | Тэмдэглэгээний төрөл (Үүл, Тэмдэгт, Урт…) |
| Статус | Нээлттэй, Зөвшөөрсөн, Татгалзсан эсвэл Дууссан |
| Шошгууд | Тэмдэглэгээний төрөл ба хуудас |
| Зохиогч ба огноо | Тэмдэглэгээний зохиогч, үүсгэсэн ба өөрчилсөн огноо |
| Хариуцсан, дуусах хугацаа | Заалтын зүйлээс, байгаа тохиолдолд |
| Тайлбар | Түүний текст эсвэл тэмдгийн үг, хэмжсэн утга, сэтгэгдэл, хуудас ба файл |
| Сэтгэгдлүүд | Хариу бүрт нэг, зохиогч ба огнооны хамт |
| Агшин | Тэмдэглэгээний зураг хуудасны өөрийн хэсэгт |
| Харагдацын цэг | Тэмдэглэгээний байрлалын дээрээс харсан харагдац хуудсан дээр |

Тэмдэглэгээг дахин экспортлоход ижил сэдвийн ID гарна, тиймээс BCF импортлодог хэрэгсэл үүнийг ижил асуудал гэж таньж чадна.

## Импортлоход юу буцаж орох вэ

{{ui:BCF импортлох}} нь BCF 2.0, 2.1 ба 3.0 файлуудыг уншина (албан ёсны buildingSMART 3.0 туршилтын 19 файл дээр шалгасан: бүх сэдвийг уншсан, текст бүхий гурван файлын сэтгэгдлийг уншсан). Таны өөрийн сэдэв (ижил сэдвийн ID) бол шинэ сэтгэгдлийг хариу болгон нэмж, шинэ статусыг авна. Бусад сэдэв нь шошго эсвэл файлын нэрээр нэрлэгдсэн хуудсан дээрх тэмдэглэл болно, үгүй бол нээлттэй хуудсан дээр. Гарчиг, тайлбар, хариуцагч, дуусах хугацаа нь тэмдэглэлийн текст болж, сэтгэгдлүүд нь хариу болно.

| BCF сэдэв дээр | MarkupCraft дээр |
|---|---|
| Гарчиг, тайлбар, хариуцагч, дуусах хугацаа | Тэмдэглэлийн текст |
| Текстэй сэтгэгдлүүд | Хариунууд |
| Статус Open, Accepted, Rejected, Completed (Closed, Resolved, Done нь Completed гэж тооцогдоно) | Тэмдэглэгээний статус |
| Зохиогч ба үүсгэсэн огноо | Тэмдэглэлийн зохиогч ба огноо |
| Камерын байрлал | Хуудсан дээрх газар, зөвхөн шошго эсвэл файлын нэрээр хуудастай холбогдсон сэдэвт |
| Загварын сонголт, нуусан хэсгүүд, огтлох хавтгайнууд, агшингууд | Хадгалагдахгүй: хуудсан дээр харуулах загвар байхгүй |

## Анхаарах хязгаарууд

- **Хуудас бол загвар биш.** Харагдацын цэг нь тэмдэглэгээний байрлалыг цаасан дээр, цаасны метрээр хэмжинэ. Энэ нь BIM хэрэгслийг загварын тодорхой газар хүргэдэггүй. Олох газраа агшин болон хуудасны нэрээр хайна.
- **Статус ба төрлүүд нь MarkupCraft-ийн өөрийнх.** (Нээлттэй, Зөвшөөрсөн, Татгалзсан, Дууссан; Үүл, Тэмдэгт…) Файл нь BCF-ийн зөвшөөрснөөр тэдгээрийг зарладаг ч өөрийн тогтмол жагсаалттай хэрэгсэл тэдгээрийг өөр утгад зураглах эсвэл үл тоомсорлож болно.
- **Импортлоход сэтгэгдэл авчирна, загварын харагдац биш.** {{ui:BCF импортлох}} нь таны экспортлосон тэмдэглэгээнд хариу ба статус нэмж, бусад асуудлыг тэмдэглэл болгоно; загварын камерыг харуулж чадахгүй. Үзэх: [Тэмдэглэгээний жагсаалт ба экспорт](topic:markups-list-and-export#import-bcf).
- Зургийн хяналтын хувьд тэмдэглэгээг PDF-ээр буцааж илгээх нь ихэвчлэн хялбар байдаг. BCF нь зургийн сэтгэгдлийг загвар зохицуулах ажлын урсгалд оруулахад зориулагдсан.
