BCF (BIM Collaboration Format) нь BIM хэрэгслүүдийн хооронд асуудал дамжуулах нээлттэй файлын формат юм. Олон загвар зохицуулах болон загвар бүтээх програм `.bcfzip` файлыг асуудлын жагсаалт болгон импортлож чадна. MarkupCraft **BCF 2.1** форматаар бичдэг.

## Нэг файл үүсгэх

1. {{ui:Тэмдэглэгээнүүд}} табыг нээнэ.
2. Жагсаалтаа илгээх зүйлдээ шүүнэ, жишээ нь {{ui:Статус}} "Нээлттэй". Зөвхөн жагсаалтад орсон тэмдэглэгээг экспортлоно.
3. {{ui:BCF}}-г сонгоно.
4. Тэмдэглэгээ бүрийн агшилтыг үүсгэж дуустал хүлээнэ ("BCF-д агшилт үүсгэж байна (5 / 20)…").

Үр дүн: `<name> markups.bcfzip` файл татагдаж, статус мөрд хэдэн сэдэвтэй болон файлын хэмжээ харагдана.

## Юу багтдаг вэ

Тэмдэглэгээ бүр нэг **сэдэв** болно:

| Сэдвийн талбар | Юугаар бөглөгдөх |
|---|---|
| Гарчиг | Дугаар, сэдэв, хуудас, жишээ нь "#4 Үүл, A-101 — План" |
| Төрөл | Тэмдэглэгээний төрөл (Үүл, Дуудлага, Урт…) |
| Статус | Нээлттэй, Зөвшөөрсөн, Татгалзсан эсвэл Дууссан |
| Шошгууд | Тэмдэглэгээний төрөл ба хуудас |
| Зохиогч ба огноо | Тэмдэглэгээний зохиогч, үүсгэсэн ба өөрчилсөн огноо |
| Хариуцагч, дуусах огноо | Засварын зүйлээс, байвал |
| Тайлбар | Текст эсвэл тамгын үг, хэмжсэн утга, сэтгэгдэл, хуудас ба файл |
| Сэтгэгдлүүд | Хариу бүрт нэг, зохиогч ба огнооны хамт |
| Агшилт | Тэмдэглэгээ хуудасных нь өөрийн хэсэгт байгаа зураг |
| Viewpoint | Тэмдэглэгээний байрлалыг хуудсан дээр дээрээс харсан харагдац |

Тэмдэглэгээг дахин экспортлоход ижил сэдвийн ID гарна, тиймээс BCF импортлодог хэрэгсэл үүнийг ижил асуудал гэж таньж чадна.

## Анхаарах хязгаарлалтууд

- **Хуудас бол загвар биш.** Viewpoint нь тэмдэглэгээний байрлалыг цаасан дээр, цаасны метрээр заана. Энэ нь BIM хэрэгслийг загварын тодорхой газар хүргэдэггүй. Олох газраа агшилт болон хуудасны нэрээр хайна.
- **Статус ба төрлүүд нь MarkupCraft-ийнх.** (Нээлттэй, Зөвшөөрсөн, Татгалзсан, Дууссан; Үүл, Дуудлага…) Файл нь BCF-ийн зөвшөөрснөөр тэдгээрийг зарладаг ч өөрийн тогтмол жагсаалттай хэрэгсэл тэдгээрийг шилжүүлж эсвэл үл тоомсорлож болно.
- **Импортлох нь хариу ба статусыг авчирдаг, загварын харагдацыг биш.** {{ui:BCF импортлох}} нь экспортолсон тэмдэглэгээнд хариу ба статус нэмж, бусад асуудлыг тэмдэглэл болгож оруулдаг; загварын камерыг харуулж чадахгүй. Үзэх: [Тэмдэглэгээний жагсаалт ба экспорт](topic:markups-list-and-export#import-bcf).
- Зургийн засвар хяналтын хувьд тэмдэглэгээг PDF-ээр буцаах нь ихэвчлэн хялбар. BCF нь зургийн сэтгэгдлийг загвар зохицуулалтын ажлын урсгалд оруулахад зориулагдсан.
