## Юу сурах вэ

AI туслах (эсвэл өөрийн бичсэн скрипт)-ийг MarkupCraft-тай хэрхэн ажиллуулах, мөн түүнд юуд хүрч болохыг хэрхэн шийдэх талаар.

MarkupCraft-д **өөрийн AI байхгүй** бөгөөд юуг ч хаа нэгтээ илгээдэггүй. Туслахаа та өөрөө авчирна: Model Context Protocol (MCP)-ийг ярьдаг аль ч программ. MarkupCraft зөвхөн түүнд багаж өгнө, та аль нь вэ гэдгийг сонгоно.

## Асаах

1. {{ui:Тохиргоо}}-г нээнэ (аппын дээд мөрний араа эсвэл {{key:Mod+,}}) ба {{ui:MarkupCraft}} табанд орно.
2. {{ui:Туслахууд}} доор **AI туслах болон скриптүүдэд MarkupCraft ашиглуулах** гэснийг тэмдэглэнэ. Энэ нь эхлээд унтраалттай байна.
3. Юу хийж болохыг сонгоно: **Унших** эхлээд тэмдэглэгдсэн байна; **Засах**, **Хадгалах** эсвэл **Экспортлох**-ыг зөвхөн хэрэгтэй үед тэмдэглэнэ.

Зөвшөөрлөөр тэмдэглээгүй багажийг туслахад харуулахгүй, хэрвээ туслах тэр багажийг хүсвэл MarkupCraft татгалзаж, үйл ажиллагааны бүртгэлд бичнэ. Унтраалтыг унтраавал бүх холболт нэг дор тасарна; {{ui:MarkupCraft-ийн тохиргоог шинэчлэх}} үүнийг бас унтраана.

## Туслахаа холбох

Туслахууд таны компьютер дээрх **CadCraft Studio**-ээр холбогдоно: Studio нь зөвхөн энэ компьютер хүрч чадах жижиг сервер ажиллуулна, түүнийг эхлэх бүрт үүсгэдэг токон хамгаална. Studio дээр {{ui:Туслах холбох}}-ыг сонгоод хаяг ба токныг туслахдаа хуулна (Studio яг юу буулгахаа харуулна). Токноо хэзээ ч бүү хуваалцаарай.

:::note
Вэб таб туслахад холболт нээж чадахгүй: вэб аппуудад унтраалт ямар ч нөлөөгүй, та компьютер дээрх CadCraft Studio-г ашиглахаас өмнө.
:::

## Та хяналттай байна

- **Өөрчлөлт бүр нэг буцаах алхам**, туслахын нэрээр нэрлэгдсэн (жишээ нь "Туслах: cloudrect нэмэх"). {{key:Mod+Z}} туслахын сүүлийн өөрчлөлтийг бүхэлд нь буцаана.
- **Холбогдсон эсэхийг та мэднэ.** Аппын дээд мөрний товч холбогдсон үед туслахын нэрийг харуулна; дарвал юу хийж болохыг харах эсвэл **Салгах** боломжтой.
- **Үйл ажиллагаа.** {{ui:Тохиргоо}} › {{ui:MarkupCraft}} › {{ui:Туслахууд}} › {{ui:Үйл ажиллагаа}} дуудлага бүрийг жагсаана: хэзээ, аль багаж, хийгдсэн эсвэл татгалзсан. {{ui:Бүртгэлийг хадгалах}} нь хуулбарыг хадгална.

## Туслахаас юу хүсч болох вэ

| Багаж | Зөвшөөрөл | Юу хийдэг |
|---|---|---|
| `app_info`, `sheets_list` | Унших | Нээлттэй багцууд, тэдгээрийн хуудсууд ба хуудас бүрт хэдэн тэмдэглэгээ байгаа |
| `markups_list` | Унших | Тэмдэглэгээнүүд: төрөл, хуудас, текст, сэтгэгдэл, хэмжилт, статус, зохиогч ба хариултууд; хуудас, статус, төрөл эсвэл зохиогчоор шүүнэ |
| `markup_add` | Засах | Хуудсанд тэгш өнцөгт, үүл, эллипс, текст хайрцаг, тэмдэглэл, шугам эсвэл сум нэмнэ |
| `markup_status`, `markup_reply` | Засах | Тэмдэглэгээний статус тавина (хэлхээнд бүртгэгдэж, туслахын гарын үсгээр); хэлхээнд сэтгэгдэл нэмнэ |
| `markups_export` | Экспортлох | {{ui:Тэмдэглэгээнүүд}} жагсаалтын өөрийн CSV эсвэл BCF, жагсаалт харуулж буй зүйлийг (таны тавьсан шүүлтүүрээр); Studio дээр таны зөвшөөрсөн хавтасанд файл бичиж болно |
| `tasks_list` | Унших | Даалгавар болсон тэмдэглэгээнүүд: хариуцагч (хүн эсвэл туслах), хугацааны өдөр, төлөв, холбоос, хаагдсан арга. `assignee: "assistant"` нь туслахад хүлээгдэж буй ажлыг жагсаана |
| `task_set`, `task_clear` | Засах | Тэмдэглэгээг даалгавар болгох эсвэл өөрчлөх (гарчиг, хариуцагч, хугацаа, төлөв, холбоос); даалгаврыг арилгана |
| `tasks_check` | Засах | Холбогдсон зургийн хэсэг эсвэл загварын элемент үнэхээр өөрчлөгдсөн даалгавруудыг хаана; гадны программаас уншсан элементийн төлвийг дамжуулна |
| `revisions_changes` | Унших | Нээлттэй хоёр төлөвлөгөөний багцын хооронд юу өөрчлөгдсөн жагсаалт, өөрийн үгээр бичихэд зориулсан |
| `pins_list`, `decision_add` | Унших, Засах | Дуу тэмдэглэл (урт, хэн, хэзээ, тайлбар; дуу эсвэл текст биш) ба шийдвэрүүд; шийдвэр бэхэлж, өмнөхийг солино |
| `redline_export`, `redline_answer` | Экспортлох, Засах | Зохиогчид зориулсан редлайн файл бичнэ; зохиогчийн хариултуудыг хэрэгжүүлнэ |

Туслахын нэмсэн тэмдэглэгээ нь зохиогчоор өөрийгөө нэрлэнэ: туслах программын өөртөө өгсөн нэр, араас нь "(туслах)", эсвэл таныг шалгагчийн нэрээ тохируулсны дараа "(<таны нэр>-ийн туслах)". Түүний статус өөрчлөлт ба хариултууд ижил байдлаар гарын үсэгтэй. Бүр нэг буцаах алхам. PDF-ийн тэмдэглэсэн хуулбарыг хадгалах нь танд үлдэнэ: {{ui:Хадгалах}}-ыг ердийнх шигээ ашиглана.

MarkupCraft-ыг нээхгүйгээр CadCraft MCP сервер таны нэрлэсэн хавтас дахь PDF-ийн тэмдэглэгээнүүдийг жагсаана (`markups_list`), мөн `cadcraft info Set.pdf` нь тэдгээрийг командын мөрөнд хэвлэнэ.

## Юу нэг зүйл ажиллахгүй бол

- **Туслах MarkupCraft-ийн багажийг харахгүй байна:** энэ цонхонд унтраалт асаалттай байгаа эсэхийг, мөн энэ цонх Studio дээр нээлттэй байгааг шалгана уу.
- **"засах зөвшөөрөл шаардлагатай":** {{ui:Туслахууд}} доор **Засах**-ыг тэмдэглээд дахин асуугаарай.
- **"401" эсвэл "токон" алдаа:** токон өөрчлөгдсөн байна (Studio дахин эхэлсэн, эсвэл {{ui:Шинэ токон}}). Шинэ токныг туслахын тохиргоонд хуулна уу.
