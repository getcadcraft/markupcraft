MarkupCraft хөгжүүлэлтийн шатанд байна. Энд одоогийн хувилбар **хийдэггүй** зүйлсийг жагсаав, та төлөвлөлтөө хийхдээ тэдгээрийг харгалзаарай. Энэ нь амлалт биш, харин одоогийн хувилбарыг тайлбарлаж байгаа юм.

## Бусадтай хамтран ажиллах

| Одоогоор бэлэн биш | Өнөөдөр хийх зүйл |
|---|---|
| Компьютерүүдийн хооронд үүлэн хадгалалт ба синк | PDF файлуудаа төслийн файлуудтайгаа хамт хадгална уу. Үүлэн хадгалалт одоогоор боломжгүй. |
| Хоёр хүний тэмдэглэгээний хуулбарыг нэгтгэх | Хуудсуудыг хянагчдын дунд хуваарилах, эсвэл цөөн тэмдэглэгээг {{key:Mod+C}} ба {{key:Mod+V}}-ээр хуулна уу. RFI, илгээлт ба өдрийн тэмдэглэл нэгддэг: харна уу [RFI, илгээлт ба өдрийн тэмдэглэлийг хянах](topic:field-records). |
| Баг, мэдэгдэл, RFI ба илгээлтэд зориулсан үүлэн төслүүд | PDF-ээ дамжуулж, хуулбаруудыг нэгтгэхийн тулд {{ui:Нэгтгэх}}-ийг ашиглана уу. |
| Шууд хуралдаан дахь RFI, илгээлт ба өдрийн тэмдэглэл | Хүн бүр өөрийн хуулбар дээр ажиллана; хуулбаруудыг {{ui:Нэгтгэх}}-ээр нэгтгэнэ үү. |
| Нэг бүртгэлийн өөр талбарт хоёр хүний өөрчлөлтийг нэгтгэх | Хамгийн сүүлд өөрчилсөн хуулбар тэр бүртгэлийг бүхэлд нь давна (хариултын хэлхээ ба хавсралтын нэрс нийлнэ). Аль бүртгэлийг ххэн засахаа тохиролцоно уу. |
| RFI, илгээлт ба өдрийн тэмдэглэлд зориулсан туслах хэрэгслүүд | {{ui:Талбар}} табд тэдгээртэй ажиллана уу. Туслахууд тэмдэглэгээтэй ажиллаж чадна: харна уу [MarkupCraft-г хиймэл оюуны туслахтай ашиглах](topic:use-with-ai-assistants). |
| Илгээсний дараа хариултыг засах эсвэл устгах | Шууд буцаана уу, эсвэл засах хариулт нэмнэ үү. |
| Тэмдэглэгээний зохиогчийг өөрчлөх | Эхлэхээсээ өмнө нэрээ тохируулна уу. |

## Тэмдэглэгээнүүд

| Одоогоор бэлэн биш | Өнөөдөр хийх зүйл |
|---|---|
| Бөглөх талбартай тамга, баталгаат дижитал гарын үсэг | Нэр ба огнооны мэдээлэлтэй захиалгат текст тамга, эсвэл гарын үсгийнхээ зургийг ашиглана уу. |
| Фото бус файл (баримт бичиг, видео) хавсаргах | Тэдгээрийг PDF-ийн хажууд хадгалж, сэтгэгдэлд нь дурдана уу. |
| Вэбсайт эсвэл нээгдээгүй файлын холбоос | Сэтгэгдэлд хаяг эсвэл файлын нэрийг бичнэ үү. |
| Захиалгат статусын багц | Дөрвөн статусыг ашиглана уу; илүү зүйлд сэдвийг ашиглана уу. |
| Файлтай хамт ирсэн сэтгэгдлийг (текст тодруулга, бусад программын тамга) зөвхөн унших байдлаар засах | Тэдэнд хариулах, эсвэл тэдний хажууд MarkupCraft тэмдэглэгээ зурна уу. |
| Даралтад мэдрэг үзгийн зурвас | Шугамын зузааныг тохируулна уу. |

## Хуудасны өөрийн агуулга

| Одоогоор бэлэн биш | Өнөөдөр хийх зүйл |
|---|---|
| Шинэ хэлбэрийг шууд хуудсанд зурах | Тэмдэглэгээ болгон зурж, дараа нь {{ui:Хуудсанд оруулах}}-ыг дарна уу. Харна уу [Хуудасны өөрийн агуулгыг өөрчлөх](topic:page-content). |
| Хуудасны объектуудыг ямар ч өнцгөөр эргүүлэх | Тэдгээрийг зөөж, хэмжээг нь өөрчилнө үү; бүх хуудсыг {{ui:Хуудсууд}}-аар эргүүлнэ үү. |
| Текст мөрийн фонт эсвэл хэмжээг өөрчлөх, эсвэл олон мөрөнд урсах текст | Үгсийг мөр мөрөөр нь өөрчилнө үү; өөр фонтоор шинэ үг оруулах бол текст тэмдэглэгээ нэмнэ үү. |
| Скан хийсэн зургийн дотор юуг засах | Зургийг солих эсвэл тэмдэглэгээ зурна уу. |
| Шифрлэгдсэн эсвэл гарын үсэгтэй PDF-ийг засах | Гарын үсэггүй хуулбар хүсэх; тэмдэглэгээ ямар ч PDF дээр ажиллана. |

## Хэмжилт

| Одоогоор бэлэн биш | Өнөөдөр хийх зүйл |
|---|---|
| Радиусын хэмжилт | Дагуу нь {{ui:Нум}} зурах, эсвэл {{ui:Урт}}-ыг хэмжээд хагасыг нь авна уу. |
| Тайралтын булангуудыг засах | Тайралтуудыг устгаад дахин зурна уу. |
| Олон хуудсанд нэг масштаб хэрэглэх | Хуудас бүрийг тохируулна уу; бэлэн тохиргоо сонгоход хуудас тутамд хэдэн секунд зарцуулагдана. |
| Нэг хуудсанд хэд хэдэн масштаб (харагдацын талбай) | Хамгийн их хэмждэг зурагт тохируулна уу. Хуудасны масштаб өөрчлөгдөхөд түүн дээрх бүх зүйл дахин хэмжигдэх тул дахин тохируулахаасаа өмнө дэлгэрэнгүй утгуудаа бичиж авна уу. |
| Зурган дээрх шугамд наалдах | Дарахаасаа өмнө томруулна уу, эсвэл урт ба өнцгийг бичнэ үү (харна уу [Эскизийг масштабаар зурах](topic:calibrate-and-measure#sketch-to-scale)). |
| Зүйл, угсралт ба үнэтэй бүрэн ажлын тоо хэмжээ | TakeoffCraft-ийг ашиглана уу, энэ бол CadCraft-ийн гэр бүлийн ажлын тоо хэмжээний апп. |

## Хуудас ба файлууд

| Одоогоор бэлэн биш | Өнөөдөр хийх зүйл |
|---|---|
| Хуудасны өөрчлөлтийг буцаах (эргүүлэх, зөөх, оруулах, устгах) | Хадгалахгүйгээр хаагаад эх PDF-ээ дахин нээнэ үү. Харна уу [Хэвлэх ба PDF-ийн хуудсуудыг өөрчлөх](topic:pages-and-printing). |
| Багцын нэг файлыг хаах | {{ui:Хаах}} нь бүх багцыг хаана; хэрэгтэй файлуудаа дахин нээнэ үү. |
| Багцыг төсөл болгон хадгалаад нэг алхамаар дахин нээх | Ижил PDF-үүдийг дахин нээнэ үү. |
| Сонгосон масштабтай хэвлэх, эсвэл нэг цаасанд хэд хэдэн хуудас хэвлэх | Хөтчийн принтерийн харилцах цонхыг ашиглана уу, эсвэл хадгалсан хуулбарыг өөр PDF үзэгчээс хэвлэнэ үү. |

| Бусад тэмдэглэгээний программаас хэрэгслийн багц импортлох | Хэрэгтэй хэрэгслүүдээ дахин үүсгэж, багажийн хайрцагт хадгална уу; оффисдоо экспортлоорой. |

## Платформууд

- **Ширээний компьютер:** MarkupCraft хөтөч дотор Mac, Windows, Linux болон iPad дээр ажиллана, мөн найман аппыг нэг суулгалтад агуулсан ширээний программ CadCraft Studio дотор ажиллана.
- MarkupCraft хөгжүүлэлтийн шатанд байна. Шошго ба үйлдэл өөрчлөгдөж болох ба энэ тусламж мөн түүнтэй хамт өөрчлөгдөнө.
