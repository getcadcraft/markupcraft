دوه کسان یو PDF په دوو کاپیو کې نښه کوي. که دوی بېلې نښې لمس کړې وي، کاپي کیدای شي د یو پروګرام لخوا یوځای شي، نه په لاس.

## دا څنګه کار کوي

هره نښه چې MarkupCraft یې خوندي کوي، خپل نوم (ID) په PDF کې لري، او دا نوم هېڅکله نه بدلېږي. یوځای کول نښې د همدې نوم له مخې ومومي، نه د دوی د ځای له مخې په فایل کې، ځکه هر پروګرام کله چې خوندي کوي ځایونه بیا شمیري. یادښتونه او ټنې شوي شخصي یادښتونه هم په همدې ډول جوړه کیږي.

پاڼې هېڅکله نه بدلېږي: دواړه کاپي باید د پاڼو یو شان شمېر ولري. که توپیر ولري، یوځای کول ستاسو کاپي همداسې ساتي او دا وایي، ځکه پاڼې اضافه یا لرې کول د یوه کس دنده ده.

## دا جوړه کړئ

Git د هر مخزن لپاره یوځل دوه کرښې غواړي:

```
# .gitattributes
*.pdf merge=cadcraft

# یو ځل، هر کمپیوټر کې
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

له git پرته، `cadcraft merge <base> <ours> <theirs> -o <result>` وچلوئ. Fossil او Mercurial همدا درې فایلونه په خپل د یوځای کولو وسیلې امستنه کې اخلي. د دندې فایل چې له نقشې سره ملګری دی (`<name>.markups.json`، وګورئ [نښه دنده وګرځوئ](topic:markups-that-act)) همداسې یوځای کیږي، د ساده متن په توګه.

## قواعد

- یوه نښه چې یوازې په یو اړخ بدله شي، اخیستل کیږي. همدغه بدلون په دواړو اړخونو کې یو ځل اخیستل کیږي.
- یوه نښه چې په دوو لارو بدله شوې وي یو **ټکر** دی: ستاسو اړخ پاتې کیږي او راپور دواړه لیست کوي. پایله خلاصه کړئ او هغه نښه په لاس سمه کړئ.
- یوه نښه چې په یو اړخ اضافه شي ساتل کیږي. هغه چې په یو اړخ لرې شي او بل اړخ کې بې بدلونه وي، لرې کیږي. په یو اړخ لرې شوې او بل اړخ کې بدله شوې: لرې کیږي او راپور کیږي.
- لایې، کالمونه، ریکارډونه او یادښتونه ورته قواعد تعقیبوي.
- ټنې شوي شخصي یادښتونه هېڅکله نه پرانستل کیږي: د دواړو اړخونو بلاکونه لکه څنګه چې دي ساتل کیږي.

یوځای شوې فایل ستاسو کاپي بشپړ بیا لیکل دی، لکه د MarkupCraft خپل خوندي کول. هېڅ نه پورته کیږي؛ ټول ستاسو په کمپیوټر کې چلېږي.
