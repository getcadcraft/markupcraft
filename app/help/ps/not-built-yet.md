MarkupCraft اوس په پرمختګ کې دی. دا هغه څه دي چې د اوسنۍ نسخې لخوا **نه** ترسره کېږي، ترڅو تاسو پرې پلان جوړ کړئ. دا د نسخې اوسنی حالت بیانوي، نه وعدې.

## د نورو خلکو سره کار کول

| لا جوړ شوی نه دی | نن دا وکړئ |
|---|---|
| د کمپیوټرونو ترمنځ د کلاوډ ساتنه او همغږي | PDF ګانې د خپلو پروژې فایلونو سره وساتئ. د کلاوډ ساتنه لا شتون نلري. |
| د دوو کسانو د نښو کاپي یوځای کول | پاڼې د بیاکتونکو ترمنځ ووېشئ، یا د {{key:Mod+C}} او {{key:Mod+V}} سره یو څو نښې نورو ته کاپي کړئ. RFIs، سپارنې او ورځنۍ راپورونه یوځای کېږي: وګورئ [د RFIs، سپارنو او ورځنیو راپورونو تعقیب](topic:field-records). |
| د RFIs، سپارنو او ټیمونو، خبرتیاوو او کلاوډ پروژو لپاره | PDF بل ته ولېږئ او د {{ui:Merge}} سره کاپي یوځای کړئ. |
| RFIs، سپارنې او ورځنۍ راپورونه په ژوندۍ ناسته کې | هر څوک د خپل کاپي سره کار کوي؛ کاپي د {{ui:Merge}} سره یوځای کړئ. |
| د یو ریکارډ مختلفو ساحو کې د دوو کسانو بدلونونو یوځای کول | وروستۍ بدلې شوې کاپي دا ریکارډ په بشپړ ډول ساتي (د هغې لړۍ او ضمیمو نومونه یوځای کېږي). وټاکئ چې کوم ریکارډ چا سموي. |
| د RFIs، سپارنو او ورځنیو راپورونو لپاره د مرستندوي وسایل | دوی د {{ui:Field}} ټب کې وکاروئ. مرستندویان کولی شي له نښو سره کار وکړي: وګورئ [د AI مرستندوي سره MarkupCraft کارول](topic:use-with-ai-assistants). |
| یو ځواب چې لېږل شوی وي سمول یا ړنګول | سمدلاسه بېرته کړئ، یا یو سمونکی ځواب اضافه کړئ. |
| د نښې لیکوال بدلول | له پیل مخکې خپل نوم وټاکئ. |

## نښې

| لا جوړ شوی نه دی | نن دا وکړئ |
|---|---|
| د ډکولو وړ ساحې لرونکي سټمپونه، تصدیق شوي ډیجیټل لاسلیکونه | یو دودیز متني سټمپ وکاروئ چې ستاسو نوم او نېټه لري، یا د خپل لاسلیک انځور. |
| د PDF نه بل فایلونه ضمیمه کول (اسناد، ویډیوګانې) | دوی د PDF سره یوځای وساتئ او په تبصره کې یې یادونه وکړئ. |
| د ویب پاڼو یا نه خلاصو فایلونو لینکونه | پته یا د فایل نوم په تبصره کې ولیکئ. |
| دودیز د حالت سیټونه | څلور حالتونه وکاروئ، او د نورو لپاره موضوع. |
| هغه تبصرې سمول چې د فایل سره راغلي او یوازې د لوستلو وړ دي (د متن روښانه کول، نورو پروګرامونو سټمپونه) | ورته ځواب ووایاست، یا د MarkupCraft نښه د دوی ترڅنګ ونقشوئ. |
| د فشار حساس قلم خطونه | د کرښې پلنوالی وټاکئ. |
