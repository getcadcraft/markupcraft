BCF (BIM Collaboration Format) د BIM وسیلو ترمنځ د مسلو لېږدولو لپاره یوه خلاصه فایل بڼه ده. ډېری ماډل همغږي او جوړونې پروګرامونه کولی شي د `.bcfzip` فایل د مسلو د لیست په توګه واردې کړي. MarkupCraft **BCF 2.1** لیکي.

## جوړول

1. د {{ui:نښې}} ټب پرانیزئ.
2. لیست داسې فلټر کړئ چې هغه څه ولري چې لېږل غواړئ، د بېلگې په توګه {{ui:حالت}} "پرانیستل". یوازې په لیست کې نښې صادرېږي.
3. {{ui:BCF}} وټاکئ.
4. د هرې نښې عکس جوړېدو ته انتظار وکړئ ("BCF لپاره عکسونه جوړېږي (5 له 20)…").

پایله: "<name> markups.bcfzip" ډاونلوډېږي، او د حالت بار ښيي چې څو موضوعات لري او د فایل اندازه څومره ده.

## څه شتون لري

هره نښه یو **موضوع** جوړوي:

| د موضوع ساحه | ډکېږي له |
|---|---|
| سرلیک | د پنچ شمېره، موضوع او پاڼه، د بېلگې په توګه "#4 ابر په A-101 — د فرش پلان" |
| ډول | د نښې ډول (ابر، حوالې، اوږدوالی…) |
| حالت | پرانیستل، منل شوی، ردشوی یا بشپړ شوی |
| لیبلونه | د نښې ډول او پاڼه |
| لیکوال او نیټې | د نښې لیکوال، د جوړېدو او بدلېدو نیټې |
| ټاکل شوی، پای نیټه | د هغې پنچ توکي څخه، کله چې یې ولري |
| تشریح | د هغې متن یا مهر عبارت، اندازه شوی ارزښت، تبصره، پاڼه او فایل |
| تبصرې | له هر ځواب سره یوه، د لیکوال او نیټې سره |
| عکس | د نښې انځور د پاڼې په خپله برخه کې |
| د کتنې ټکی | د نښې ځای د پاڼې له پورته لید |

د ورته نښې بیا صادرول ورته د موضوع ID ورکوي، نو هغه وسیله چې BCF واردوي کولی شي دا د ورته مسلې په توګه وپېژني.

## واردولو کې څه بېرته راځي

{{ui:BCF واردول}} د BCF 2.0، 2.1 او 3.0 فایلونه لولي (د buildingSMART 19 رسمي 3.0 ازموینې فایلونو کې وڅېړل شو: هر موضوع ولوستل شو، او د دریو هغو تبصرې چې متن لري). د یوه موضوع لپاره چې ستاسو ده (ورته موضوع ID)، نوي تبصرې د ځوابونو په توګه اضافه کوي او نوی حالت اخلي. نور هر موضوع د هغې پاڼې یادښت کېږي چې لیبل یا فایل نوم یې نومي؛ که نه، پرانېستې پاڼې ته. سرلیک، تشریح، ټاکل شوی کس او پای نیټه د یادښت متن کېږي، او تبصرې د ځوابونو په توګه.

| په BCF موضوع کې | په MarkupCraft کې |
|---|---|
| سرلیک، تشریح، ټاکل شوی کس، پای نیټه | د یادښت متن |
| متن لرونکي تبصرې | ځوابونه |
| حالت پرانیستل، منل شوی، ردشوی، بشپړ شوی (Closed، Resolved او Done بشپړ شوی ګڼل کېږي) | د نښې حالت |
| لیکوال او د جوړېدو نیټه | د یادښت لیکوال او نیټه |
| د کیمرې ځای | د پاڼې یو ځای، یوازې هغه موضوع لپاره چې د لیبل یا فایل نوم له مخې پاڼې ته تړلې وي |
| د ماډل ټاکنه، پټ برخې، د پرې کولو الوتکې، عکسونه | نه ساتل کېږي: پاڼه ماډل نه لري چې دا وښیي |

## پیژندل شوې محدودیتونه

- **پاڼه ماډل نه ده.** د کتنې ټکی د نښې ځای په کاغذ کې ښیي، چې د کاغذ په مترو اندازه شوی. دا BIM وسیله ماډل کې یو ځای ته نه وړي. د ځای موندلو لپاره عکس او د پاڼې نوم وکاروئ.
- **حالتونه او ډولونه د MarkupCraft خپل دي** (پرانیستل، منل شوی، ردشوی، بشپړ شوی؛ ابر، حوالې…). فایل یې اعلانوي، لکه څنګه چې BCF اجازه ورکوي، خو هغه وسیله چې خپل ثابت لیستونه لري ممکن یې نقشه کړي یا له پامه وغورځوي.
- **واردول تبصرې راولي، نه د ماډل لیدونه.** {{ui:BCF واردول}} ستاسو صادر شوو نښو ته ځوابونه او حالتونه اضافه کوي، او د نورو مسلو لپاره یادښتونه جوړوي؛ دا د ماډل کیمره نشي ښودلی. وګورئ [د نښو لیست او صادرول](topic:markups-list-and-export#import-bcf).
- د نقشې بیاکتنو لپاره نښې د PDF په توګه بیرته لېږل ډېر وخت ساده وي. BCF د دې لپاره دی چې د نقشې تبصرې د ماډل همغږي کاري بهیر ته ورسېږي.
