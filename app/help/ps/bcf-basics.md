BCF (د BIM همکارۍ بڼه) یوه خلاصه فایل بڼه ده چې مسلې د BIM وسیلو ترمنځ لیږدوي. ډیری ماډل همغړیتیا او جوړونې پروګرامونه کولای شي `.bcfzip` فایل د مسلو د لیست په توګه واردکړي. MarkupCraft **BCF 2.1** لیکي.

## یو فایل جوړول

1. د {{ui:Markups}} ټب پرانیزئ.
2. لیست داسې فلټر کړئ چې لیږل غواړئ، د بېلګې په توګه {{ui:Status}} "باز". یوازې لیست شوې نښې صادرېږي.
3. {{ui:BCF}} وټاکئ.
4. د هرې نښې لنډ عکس جوړیدو پر مهال صبر وکړئ ("د BCF لپاره لنډ عکسونه جوړیږي (5 له 20)…").

پایله: "<name> markups.bcfzip" ډاونلوډ کېږي، او د حالت بار وایي چې څو موضوعات لري او د فایل اندازه څومره ده.

## په کې څه شتون لري

هره نښه یو **موضوع** کېږي:

| د موضوع ساحه | ډکېږي له |
|---|---|
| سرلیک | د پنچ شمېره، موضوع او پاڼه، د بېلګې په توګه "#4 ابر په A-101 — د پوړ پلان" |
| ډول | د نښې ډول (ابر، یادونه، اوږدوالی…) |
| حالت | باز، منل شوی، رد شوی یا بشپړ |
| نښې | د نښې ډول او پاڼه |
| لیکوال او نیټې | د نښې لیکوال، د جوړولو او بدلولو نیټې |
| ګومارل شوی، د سپارنې نیټه | د خپل پنچ توکي څخه، کله چې یې ولري |
| تشریح | متن یا د مهر متن، اندازه شوې ارزښت، تبصره، پاڼه او فایل |
| تبصرې | هر ځواب لپاره یوه، د لیکوال او نیټې سره |
| لنډ عکس | د نښې انځور د پاڼې په خپله برخه کې |
| د لید ټکی | د نښې ځای د پاڼې له پورته لید |

بیا صادرول د نښې ورته موضوع ID ورکوي، نو هغه وسیله چې BCF واردوي کولی شي پیژني چې ورته مسله ده.

## پام وړ محدودیتونه

- **پاڼه ماډل نه ده.** د لید ټکی د نښې ځای په کاغذ کې ښیي، چې په کاغذ کې د متره پر بنسټ اندازه کېږي. دا BIM وسیله ماډل کې ځای ته نه بیایي. د ځای موندلو لپاره لنډ عکس او د پاڼې نوم وکاروئ.
- **حالتونه او ډولونه د MarkupCraft خپل دي** (باز، منل شوی، رد شوی، بشپړ؛ ابر، یادونه…). فایل یې اعلانوي، لکه څنګه چې BCF اجازه ورکوي، خو هغه وسیله چې خپل ثابت لیستونه لري، شاید دوی واړوي یا نظرانداز یې کړي.
- **واردول تبصرې راولي، نه د ماډل لیدونه.** {{ui:Import BCF}} ځوابونه او حالتونه هغو نښو ته اضافه کوي چې صادر کړي دي، او د نورو مسلو یادښتونه جوړوي؛ دا د ماډل کیمره نشي ښودلی. وګورئ [د نښو لیست او صادرول](topic:markups-list-and-export#import-bcf).
- د نقشې بیاکتنې لپاره نښې د PDF په توګه بیرته لېږل ډیر وخت ساده وي. BCF د دې لپاره دی چې د نقشې تبصرې د ماډل همغړیتیا کاري بهیر ته ورسوي.
