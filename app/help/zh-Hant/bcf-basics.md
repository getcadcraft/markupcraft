BCF（BIM 協作格式）是一種開放的檔案格式，用於在 BIM 工具之間傳遞問題。許多模型協調與建模程式可以將 `.bcfzip` 檔案匯入為問題清單。MarkupCraft 寫出的是 **BCF 2.1**。

## 製作檔案

1. 開啟{{ui:Markups}}索引標籤。
2. 篩選清單，只保留要送出的內容，例如{{ui:Status}}為「未結」。只有清單中的項目會被匯出。
3. 選擇{{ui:BCF}}。
4. 等待程式為每個標記製作快照（「正在為BCF製作快照（第 5 個，共 20 個）……」）。

結果：下載「<name> markups.bcfzip」，狀態列會顯示其中的主題數量與檔案大小。

## 檔案內容

每個標記會成為一個**主題**。

| 主題欄位 | 填入內容 |
|---|---|
| 標題 | 缺失清單編號、主題與圖紙，例如「#4 A-101 上的雲形 — 平面圖」 |
| 類型 | 標記種類（雲形、註解框、長度……） |
| 狀態 | 未結、已接受、已拒絕或已完成 |
| 標籤 | 標記種類與圖紙 |
| 作者與日期 | 標記的作者、建立日期與修改日期 |
| 指派給、到期日 | 來自其缺失清單項目（若有） |
| 描述 | 其文字或圖章用字、量測值、說明，以及圖紙與檔案 |
| 留言 | 每則回覆一則，含作者與日期 |
| 快照 | 標記在其所在圖紙部分的圖片 |
| 視點 | 標記在圖紙上所在位置的俯視圖 |

再次匯出同一個標記會得到相同的主題ID，因此可以匯入BCF的工具能辨識它是同一個問題。

## 匯入時會帶回什麼

{{ui:Import BCF}}可讀取 BCF 2.0、2.1 與 3.0 檔案（已以 19 個 buildingSMART 官方 3.0 測試檔確認：每個主題都能讀取，且其中三個有文字的留言也都能讀取）。若主題是本程式匯出的標記（主題ID相同），會將新留言加為回覆，並採用新的狀態。其他主題會成為其標籤或檔案名稱所指定圖紙上的附註；若沒有指定，則成為目前開啟圖紙上的附註。附註文字為其標題、描述、指派對象與到期日，其留言則成為回覆。

| BCF 主題中的內容 | 在 MarkupCraft 中 |
|---|---|
| 標題、描述、指派對象、到期日 | 附註的文字 |
| 含文字的留言 | 回覆 |
| 狀態 Open、Accepted、Rejected、Completed（Closed、Resolved、Done 視為 Completed） | 標記的狀態 |
| 作者與建立日期 | 附註的作者與日期 |
| 攝影機位置 | 圖紙上的位置，僅限透過標籤或檔案名稱與圖紙相關的主題 |
| 模型選取、隱藏的零件、剖切平面、快照 | 不保留：圖紙上沒有可供顯示的模型 |

## 需注意的限制

- **圖紙不是模型。** 視點指向標記在紙上的位置，以紙上的公尺為單位量測。它無法帶 BIM 工具前往模型中的某個位置。請使用快照與圖紙名稱找出位置。
- **狀態與類型是MarkupCraft自己的定義**（未結、已接受、已拒絕、已完成；雲形、註解框……）。檔案會依 BCF 規定宣告這些值，但具有自身固定清單的工具可能會對應或忽略它們。
- **匯入帶回的是留言，不是模型視角。** {{ui:Import BCF}}會為本程式匯出的標記加入回覆與狀態，並為其他問題建立附註；它無法顯示模型攝影機。請參閱 [標註清單與匯出](topic:markups-list-and-export#import-bcf)。
- 對圖紙審閱而言，以 PDF 寄回標記通常較為簡單。BCF 適用於將圖紙上的留言帶入模型協調流程。
