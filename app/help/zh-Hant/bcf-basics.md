BCF（BIM協作格式）是一種開放的檔案格式，用於在 BIM 工具之間傳遞問題。許多模型協調與建模程式可以將 `.bcfzip` 檔案匯入為問題清單。MarkupCraft 寫出的是 **BCF 2.1**。

## 建立一個檔案

1. 開啟{{ui:Markups}}索引標籤。
2. 篩選清單，只保留要傳送的項目，例如{{ui:Status}}為「Open」。只會匯出清單中的標記。
3. 選擇{{ui:BCF}}。
4. 等候程式為每個標記建立快照（「正在為 BCF 建立快照（第5個，共20個）…」）。

結果：「<name> markups.bcfzip」會下載，狀態列會顯示其中的主題數量與檔案大小。

## 檔案內容

每個標記會成為一個**主題**：

| 主題欄位 | 填入內容 |
|---|---|
| 標題 | 缺失編號、主旨與圖紙，例如「#4 A-101 上的雲形框 — 平面圖」 |
| 類型 | 標記的種類（雲形框、引註、長度…） |
| 狀態 | Open、Accepted、Rejected 或 Completed |
| 標籤 | 標記的種類與圖紙 |
| 作者與日期 | 標記的作者，以及建立與修改日期 |
| 指派對象、到期日 | 來自其缺失項目（如有） |
| 描述 | 其文字或圖章內容、量測值、註解，以及圖紙與檔案 |
| 註解 | 每則回覆一筆，附作者與日期 |
| 快照 | 標記在其圖紙所在位置的圖片 |
| 視點 | 標記在圖紙上位置的俯視檢視 |

重新匯出同一個標記會得到相同的主題 ID，因此支援 BCF 的匯入工具能辨識它是同一個問題。

## 需注意的限制

- **圖紙不是模型。** 視點指向標記在紙上的位置，以紙上的公尺計量。它無法讓 BIM 工具跳到模型中的某個位置。請使用快照與圖紙名稱來找到該位置。
- **狀態與類型是 MarkupCraft 自訂的**（Open、Accepted、Rejected、Completed；雲形框、引註…）。檔案會依 BCF 的規定宣告這些值，但有固定清單的工具可能會對應或忽略它們。
- **匯入帶入的是註解，而非模型視角。**{{ui:Import BCF}}會為你匯出的標記新增回覆與狀態，並為其他問題建立附註；它無法顯示模型的攝影機視角。請見 [標記清單與匯出](topic:markups-list-and-export#import-bcf)。
- 對於圖紙審閱，通常以 PDF 寄回標記較為簡單。BCF 適用於將圖紙上的註解帶入模型協調流程。
