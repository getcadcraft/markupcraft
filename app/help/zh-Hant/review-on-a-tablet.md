MarkupCraft 支援觸控：可在 iPad（Safari 或 Chrome）、觸控螢幕筆電，或使用新版瀏覽器的 Windows 或 Android 平板上使用。平板橫向時會顯示完整版面。

## 手勢

| 手勢 | 功能 |
|---|---|
| 單指 | 使用目前工具繪製，或使用{{ui:選取}}選取 |
| 雙指，張開或捏合 | 以兩指之間的位置為中心縮放 |
| 雙指，並攏移動 | 平移；可在一次動作中同時縮放與平移 |
| 繪製時再加一根手指 | 取消第一根手指開始的動作，改為縮放 |
| 連續點按兩下，或按住 | 完成折線、多邊形、自由雲形線或區域 |
| 在{{ui:選取}}狀態下按住文字、引註或便利貼 | 開啟其文字以便編輯 |
| 開啟{{ui:平移}}時的單指 | 平移 |

在觸控螢幕上，工具列按鈕、功能表、索引標籤與對話方塊按鈕會更大，方便用手指點選。

## 放開時的動作

為了讓捏合的第一根手指不會留下標記，部分工具會在你**放開**手指時才生效，而非觸碰時：

- {{ui:計數}}：放開時加入圓點。
- {{ui:便利貼}}：放開時放置便利貼。
- {{ui:折線}}、{{ui:多邊形}}、{{ui:自由雲形線}}與{{ui:面積}}：放開時加入每個點。
- {{ui:直線}}、{{ui:箭頭}}、{{ui:長度}}與{{ui:校正}}：點按起點再點按終點時，終點於放開時放置。

若手指在放開前滑動超過一點，便不算點按，也不會加入任何內容。請乾淨地點按；如需更正，請使用{{ui:復原}}。

需要拖曳的工具（{{ui:手繪}}、{{ui:螢光筆}}、{{ui:雲形框}}、{{ui:矩形}}、{{ui:橢圓}}、{{ui:引註}}、{{ui:文字}}、{{ui:印章}}）會在觸碰時立即開始；第二根手指會取消它們。

## 用手指選取

- 點按標記即可選取；拖曳即可移動；拖曳控點即可調整大小。手指碰觸圖紙後，標記與控點的點選範圍會變大，控點也會畫得更大。
- 在空白圖紙上拖曳，可繪製選取框（由左至右：完全位於框內；由右至左：與框相交）。
- 在{{ui:選取}}中，單指**不會**平移。請使用雙指，或選擇{{ui:平移}}。

## 需要鍵盤的操作

沒有鍵盤就沒有 {{key:Shift}}、{{key:Esc}} 或 {{key:Enter}}。以下是替代做法：

| 鍵盤操作 | 沒有鍵盤時 |
|---|---|
| {{key:Esc}} 取消或回到{{ui:選取}} | 點按工具列中的{{ui:選取}} |
| {{key:Shift}} 用於 45° 線條、正方形與圓 | 小心繪製；用控點調整 |
| {{key:Shift}}+點擊以加入選取 | 使用選取框 |
| {{key:Shift}}+點擊以移除計數圓點 | 點錯後立即{{ui:復原}} |
| {{key:Mod+Enter}} 完成輸入 | 點按文字方塊外部 |
| {{key:Enter}} 完成折線，或編輯標記文字 | 按住，或在{{ui:屬性}}中使用{{ui:在圖紙上編輯}} |
| {{key:Delete}} | 工具列或{{ui:屬性}}中的{{ui:刪除}} |
| 以 {{key:Esc}} 開始新的計數群組 | 用{{ui:選取}}點按空白圖紙，然後再點按{{ui:計數}} |

配有鍵盤的保護殼或藍牙鍵盤可恢復所有快速鍵；在 iPad 上，⌘ 鍵可用於 {{key:Mod+Z}} 及其他快速鍵。

觸控時按鈕不會顯示工具提示。各工具的快速鍵列於[鍵盤與滑鼠](topic:keyboard)。

## 手寫筆與 Apple Pencil

手寫筆（Apple Pencil、Surface Pen 等）的運作方式與滑鼠相同：可繪製與選取，並在觸碰時立即生效。雙指縮放與平移請使用手指。筆壓不會改變線寬。

## 在 iPad 上開啟與儲存

- {{ui:開啟}}會顯示「檔案」選擇器：iCloud 雲碟、我的 iPad，以及已連接的任何儲存應用程式。
- {{ui:儲存}}會要求下載；副本會存入「檔案」中的「下載項目」（或 Safari 設定中指定的資料夾）。

## 在平板上保護工作內容

:::warning
iPad 的 Safari 在離開含有未儲存工作的頁面時不會發出警告，且 iPadOS 可能會在背景重新載入分頁以釋放記憶體。MarkupCraft 會在瀏覽器中保留復原副本，並在重新開啟時提供還原（請見[復原尚未儲存的內容](common:recover)），但**每完成一張圖紙或每次巡視後都要儲存**：隱私瀏覽分頁不會保留任何副本。
:::

- 名稱、工具設定與工具箱會保留在該 iPad 的瀏覽器中，與電腦相同。請見[留在此瀏覽器中的內容](topic:browser-storage)。
- **在沒有訊號的現場之前：**在仍連上網路時，於 iPad 上以 Safari（或 Chrome）開啟 MarkupCraft，並在頂端列選擇{{ui:儲存供離線使用}}。請等待顯示「可離線使用」（期間會顯示「儲存中 N/M」；PDF 閱讀與寫入元件約 6 MB）。到現場後，開啟相同的網址或其書籤即可：開啟、標記與儲存 PDF 都不需要連線。若顯示「無法離線使用」，表示目前在隱私瀏覽分頁中；請改用一般分頁。請見[離線工作](common:offline)。
- Safari 會在數週未使用後移除離線副本。出門前，請點按「可離線使用」，並選擇「重新儲存（取得最新版本）」。
- 非常大型的圖紙集會佔用大量記憶體。在平板上，只開啟此次巡視所需的圖紙。

## 在手機上

可以使用，但螢幕較小：各部分會堆疊排列（工具列、圖紙、狀態列、面板，最後是圖紙清單），且工具列可左右捲動。手機適合用來查看內容，或快速加入一則便利貼；正式審閱請使用平板或電腦。
