## 學習內容

如何讓 AI 助理（或自行撰寫的指令稿）與 MarkupCraft 搭配運作，以及決定它可以操作哪些內容。

MarkupCraft **本身沒有 AI**，也不會將任何內容傳送到別處。助理需自行提供：任何能使用模型內容協定（MCP）的程式皆可。MarkupCraft 只會提供工具，由使用者決定開放哪些工具。

## 啟用

1. 開啟{{ui:設定}}（應用程式列上的齒輪，或{{key:Mod+,}}），並前往{{ui:MarkupCraft}}索引標籤。
2. 在{{ui:助理}}下勾選**允許 AI 助理與指令稿使用 MarkupCraft**。在勾選之前此功能為關閉。
3. 選擇其可執行的操作：**讀取**預設已勾選；只有在需要時才勾選**編輯**、**儲存**或**匯出**。

未勾選之權限所對應的工具不會提供給助理；若助理仍要求使用，MarkupCraft 會拒絕並記錄於活動紀錄中。關閉此開關會立即中斷所有連線；{{ui:重設 MarkupCraft 設定}}也會將其關閉。

## 連接助理

助理會透過您電腦上的**CadCraft Studio**連線：Studio 會執行一個僅本機可存取的小型伺服器，並以每次啟動時產生的權杖保護。在 Studio 中選擇{{ui:連接助理}}，並將位址與權杖複製到助理中（Studio 會顯示要貼上的確切設定）。切勿分享權杖。

:::note
瀏覽器分頁無法為助理開啟連線：在瀏覽器版本中，此開關在使用電腦上的 CadCraft Studio 之前不會生效。
:::

## 一切仍由使用者掌控

- **每項變更都是一個復原步驟**，並以助理的名稱標示（例如「Assistant: add cloudrect」）。{{key:Mod+Z}}會一次撤回助理的最後一項變更。
- **會顯示是否已連線。** 應用程式列中的按鈕會在助理連線時標示其名稱；點按即可查看其權限，或予以**中斷連線**。
- **活動紀錄。** {{ui:設定}} › {{ui:MarkupCraft}} › {{ui:助理}} › {{ui:活動}} 會列出每次呼叫：時間、工具，以及完成或被拒絕。{{ui:儲存紀錄}}可保留一份副本。

## 助理可以請求的權限

| 工具 | 權限 | 功能 |
|---|---|---|
| `app_info`、`sheets_list` | 讀取 | 已開啟的圖紙集、其圖紙，以及每張圖紙的標註數量 |
| `markups_list` | 讀取 | 標註的類型、圖紙、文字、註解、量測、狀態、作者與回覆，可依圖紙、狀態、類型或作者篩選 |
| `markup_add` | 編輯 | 在圖紙上新增矩形、雲形框、橢圓、文字方塊、便利貼、直線或箭頭 |
| `markup_status`、`markup_reply` | 編輯 | 設定標註的狀態（記錄於其回覆串中，並以助理簽名）；在回覆串中新增註解 |
| `markups_export` | 匯出 | {{ui:標註}}清單本身的 CSV 或 BCF，內容為清單目前所顯示的項目（依設定的篩選條件）；在 Studio 中，可將檔案寫入已允許的資料夾 |
| `tasks_list` | 讀取 | 屬於任務的標註：負責人（人員或助理）、到期日、狀態、連結與完成方式。`assignee: "assistant"` 會列出等待助理處理的工作 |
| `task_set`、`task_clear` | 編輯 | 將標註設為任務或變更其內容（標題、負責人、到期日、狀態、連結）；取消任務 |
| `tasks_check` | 編輯 | 當連結的圖面區域或模型元素確實變更時，關閉該任務；傳入從其他應用程式讀取的元素狀態 |
| `revisions_changes` | 讀取 | 兩個已開啟的圖紙集之間變更內容的純文字清單，以便自行整理成文字 |
| `pins_list`、`decision_add` | 讀取、編輯 | 語音附註（長度、人員、時間、說明文字；不含聲音與逐字稿）與決定事項；釘選決定並取代較早的決定 |
| `redline_export`、`redline_answer` | 匯出、編輯 | 為繪圖人員寫出紅線檔案；套用繪圖人員的回覆 |

助理新增的標註會以作者身分記錄：即助理程式為自己取的名稱，後面加上「(助理)」；或在設定了審閱者姓名後，加上「(助理，<姓名>)」。其狀態變更與回覆也以相同方式簽名。每一項均為一個復原步驟。儲存附有標記的 PDF 仍由使用者自行執行：照常使用{{ui:儲存}}即可。

不開啟 MarkupCraft，CadCraft MCP 伺服器也能列出指定資料夾中 PDF 的標註（`markups_list`），而 `cadcraft info Set.pdf` 會在命令列上印出這些標註。

## 若出現問題

- **助理看不到 MarkupCraft 工具：** 確認此視窗中的開關已開啟，且此視窗已在 Studio 中開啟。
- **「needs the edit permission」（需要編輯權限）：** 在{{ui:助理}}下勾選**編輯**，然後再次要求。
- **「401」或「token」（權杖）錯誤：** 權杖已變更（Studio 重新啟動，或按下{{ui:新權杖}}）。將新的權杖複製到助理的設定中。
