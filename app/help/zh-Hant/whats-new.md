本文說明 MarkupCraft 0.9 相較於 0.8.1 的變更。主要概念是：你的工作附註不會出現在客戶收到的圖紙上，而且整組圖紙可以一次完成連結。

## 新增

### 附註、貼板與私人附註

- **貼板。** 每張圖紙周圍的區域就是一張桌面：在圖紙旁繪製、輸入或貼上的任何內容都是附註，且永遠不會列印。選擇{{ui:顯示貼板}}可縮小檢視以騰出空間，或選擇{{ui:快照到貼板}}，拖曳出一個方框，再選擇{{ui:到貼板}}，即可在圖紙旁放置該部分圖面的圖片。快照是一張圖片，不會隨圖紙改變。請參閱 [附註、貼板與私人附註](topic:notes-and-pasteboard)。
- **顯示與隱藏附註。** 任何標記都可以是附註：在{{ui:附註}}索引標籤中設定{{ui:新增的標記為}}，或在{{ui:屬性}}中設定{{ui:此標記為}}。{{key:Shift+H}}或圖紙下方的{{ui:附註}}切換開關可同時隱藏或顯示所有附註。列印、扁平化副本、清單與匯出時都不會包含附註，其他 PDF 閱讀器也不會顯示。已儲存的 PDF 會保留附註，下次用 MarkupCraft 開啟時仍可看到。
- **私人附註。** 選擇{{ui:設定密碼}}，再將標記設為{{ui:私人附註}}。該附註會以至少 10 個字元的密碼加密儲存在檔案中，且無法復原：包括我們在內，任何人都無法在沒有密碼的情況下開啟。{{ui:鎖定}}會收起私人附註；{{ui:在此裝置上保持解鎖}}預設為關閉。
- **儲存乾淨副本。** {{ui:儲存乾淨副本}}會移除所有附註、私人附註以及貼板上的所有內容。請將此檔案用於寄給客戶的版本。

### 整組連結

- **批次連結。** 選擇{{ui:頁面}} › {{ui:批次連結…}}，或在{{ui:圖紙}}面板中，於{{ui:搜尋文字}}下方選擇{{ui:連結圖紙標註…}}。第 1 步會列出每張圖紙從標題欄讀取到的編號與名稱；如有錯誤請加以修正。第 2 步會列出找到的圖紙標註，例如 `3/A-501` 或 `DETAIL 2 ON A-501`。{{ui:將連結}}會顯示每個標註對應的圖紙與檢視，{{ui:未連結}}會列出沒有任何已開啟圖紙對應的編號，{{ui:建立連結}}則會在一個復原步驟中建立全部連結。增補或重新編號之後可再次執行；手動建立的連結永遠不會被更改。含檢視的連結會儲存為 PDF 連結，因此其他閱讀器也能開啟該細部圖。請參閱 [圖紙連結](topic:sheet-links)。

### 繪圖

- **圓弧，十種方法。** {{ui:圓弧}}工具（{{key:O}}）現在會在圖面上方顯示{{ui:圓弧方法}}方塊，提供十種繪製圓弧的方式，角度、長度、半徑與方向都可以點選或輸入。請參閱 [以十種方式繪製圓弧](topic:draw-an-arc)。

### 協同作業

- **跟隨檢視者。** 在 Live 工作階段中，選擇某人姓名旁的{{ui:跟隨}}，你的檢視就會跟著對方移動；自己平移或縮放即會停止跟隨。主持人可選擇{{ui:要求所有人跟隨我}}。人員清單會顯示每位成員的顏色、姓名、所在圖紙，以及其最後一次編輯的時間。請參閱 [在 Live 工作階段中跟隨其他檢視者](topic:follow-in-live)。

## 所有應用程式

- 工具提示為 Bootstrap 工具提示，起始提示可以關閉，索引標籤列溢出時可捲動，瀏覽器索引標籤標題格式為 `<document> — MarkupCraft | CadCraft`。
- 含多個區段的面板會開啟一個區段並關閉其他區段（游標旁的鎖定圖示可保持一個區段開啟）；設定中的開關可關閉此行為。
- 每個應用程式都以一組預設的程式庫物件開始。
- 設定中的單位提供重量與溫度單位。

## 修正

- **已刪除的標記不再保留在已儲存的 PDF 中。** 過去儲存時，已刪除或改寫的註解會從頁面上移除，但物件及其文字仍留在檔案中。現在儲存時會刪除這些物件。由較早版本儲存的檔案，要再次儲存後才會移除。

## 目前的限制

- 批次連結僅在我們自己的測試圖紙組上測試過。真實圖紙組的標註圈繪方式多種多樣，因此在客戶的圖紙組上可能會漏掉部分檢視。掃描圖紙需先執行{{ui:讀取文字（OCR）…}}。
- 附註、私人附註與貼板是在無頭瀏覽器及我們自己的檔案中測試，並未使用大型真實向量圖紙組，也未在真正的兩人 Live 工作階段中測試。變更密碼功能尚未實作。0.9 之前的版本不會顯示附註。
- 班級檢視即人員清單；尚未與真實的教師及學生一起測試。
- 英文以外的語言在母語人士審閱前皆為機器草稿。
- Windows 安裝程式未經程式碼簽署（選擇「更多資訊」，再選「仍要執行」）；macOS 磁碟映像未經公證（按右鍵後選擇「開啟」）。

## 較早版本：0.8 與 0.8.1

本文說明 MarkupCraft 0.8 與 0.8.1 相較於 0.7 的變更。最大的新功能是：標記可以成為工作，由某人或你自己的助理執行，並且當圖面真正變更時會自動關閉。

### 新增

**會執行的標記**

- **將標記設為工作。** 選取一個或多個標記，開啟{{ui:工作}}索引標籤並選擇{{ui:將選取內容變成工作}}。工作包含標題、負責人（人員或你連接的助理）、選填的到期日與狀態，並會保留其在圖紙上的位置與回覆串。請參閱 [將標記設為工作](topic:markups-that-act)。
- **工作會自動關閉。** 工作可以監看其標記內的圖面。開啟圖紙的較新修訂版並選擇{{ui:立即檢查}}：若該區域的線條變動超過少許，工作會標記為完成，其標記會變為已完成，且回覆串中的附註會說明變更內容。新增的日期戳記，或移動不到 1.5 點的線條，不計入變更。工作也可以改為監看模型元素：你的助理以 `tasks_check` 回報該元素，之後若回報內容不同，或元素已被刪除，工作即會關閉。一個復原步驟可重新開啟工作。
- **尋找工作。** 依狀態及指派對象篩選{{ui:工作}}清單，包括{{ui:已逾期}}；選擇{{ui:指派給}}，再選擇{{ui:助理}}，即可查看等待你的助理處理的項目。超過到期日的工作會以警告顯示於問題面板。{{ui:CSV}}會匯出清單。工作與標記一同儲存於 PDF 中，並像其他標記屬性一樣透過 Live 傳送。

**變更內容，以純文字清單呈現**

- **列出變更。** 開啟{{ui:比對}}索引標籤，再選擇{{ui:比對整組圖紙}}，選取較早與較晚的檔案，然後選擇{{ui:列出變更}}。清單先顯示數量，接著依變更幅度由大到小列出每張變更的圖紙：位於圖紙的何處、變更大小（同時以實際單位及校正圖紙上的紙張英吋表示）、線條是否新增或刪除、該處有多少個標記，以及出現或消失了哪些文字。{{ui:複製清單}}會將清單放到剪貼簿，{{ui:CSV}}則會為每個變更寫入一列。請參閱 [列出修訂版之間的變更](topic:what-changed-in-words)。

**語音附註與決定**

- **語音附註。** 在{{ui:附註}}索引標籤中選擇{{ui:錄製語音附註}}，然後選擇{{ui:停止錄音}}；錄音滿兩分鐘會自動停止。附註會固定在圖紙中央，你可將其拖曳到適當位置，並在{{ui:屬性}}中輸入說明文字；清單中的{{ui:播放}}可播放。錄音會儲存於 PDF 內。
- **決定。** {{ui:釘選決定}}會在圖紙上寫下一兩句話。若它取代較早的決定，請在{{ui:取代}}中選取該決定：舊決定會保留，標示為已取代，並指向新決定。一個復原步驟即可將其還原。請參閱 [在圖紙上釘選語音附註與決定](topic:voice-notes-and-decisions)。

**紅線轉修訂版**

- **傳送與回覆。** 在{{ui:工作}}索引標籤中開啟{{ui:紅線轉修訂版}}，輸入標記所對應的修訂版，然後選擇{{ui:匯出紅線檔案}}。你會得到一個 `.redline.json` 檔案，每個未完成的標記各一筆：圖紙、位置（以圖紙比例的分數表示，因此以其他尺寸重新出圖仍能對齊）、文字、作者、回覆串及其工作。進行修改的人會在 `.redline-answers.json` 檔案中回覆「已接受」、「已拒絕」或「完成」；{{ui:載入回覆檔案…}}會為每個標記設定該狀態及繪圖者的附註，作為一個復原步驟。請參閱 [將標記以紅線傳送給繪圖者](topic:redline-to-revision)。

**AI 助理**

- **更多工具。** 透過 CadCraft Studio 連接的助理可以列出工作（`tasks_list`）、建立或變更工作（`task_set`）、移除工作（`task_clear`）、依較新修訂版或某元素檢查工作（`tasks_check`），並讀取兩個已開啟的圖紙集之間的變更純文字清單（`revisions_changes`）。助理只能使用你在「助理」開關下勾選的工具，且每次變更都是一個復原步驟。請參閱 [與 AI 助理搭配使用 MarkupCraft](topic:use-with-ai-assistants)。

### 所有應用程式

- **語言。** CadCraft Studio 現在提供 54 種語言。新增十種：立陶宛語、拉脫維亞語、波士尼亞語、馬拉地語、泰盧固語、阿爾巴尼亞語、南非荷蘭語、菲律賓語、斯瓦希里語與烏茲別克語。所有非英文語言在母語人士審閱前皆為機器草稿。
- **輸入裝置。** {{ui:設定}} › {{ui:全域}} › {{ui:輸入裝置}}可設定觸控板、滑鼠側邊按鍵、觸控筆、手指點按、3D 滑鼠、遊戲控制器或 MIDI 控制器的作用，可套用於所有應用程式，或僅套用於此應用程式。在你變更任何設定之前，所有裝置都與之前相同。請參閱 [使用觸控板、3D 滑鼠或控制器](common:input-devices)。
- **工具列列數。** {{ui:設定}} › {{ui:一般}} › {{ui:工具列列數}}提供{{ui:自動換行}}（預設）、{{ui:2列}}與{{ui:1列}}，讓圖面獲得更多空間。請參閱 [安排面板](common:arrange-panels)。
- **屬性格線。** 標記的樣式欄位使用共用格線，其類別可摺疊，並具有標籤欄與值欄。
- **問題面板。** 應用程式的警告，例如逾期的工作，會集中在一個問題面板中。
- **Live 與外掛。** Live 工作階段說明請見 [與他人即時協作](common:work-together-live)；依你的帳戶列出的外掛清單請見 [外掛與帳戶清單](common:addons-basics)。
- **連接你的 AI。** CadCraft Studio 是你自有助理的中心：連接一次即可供全部八個應用程式使用。這些應用程式本身不包含任何 AI。

### 0.8.1 中已修正

- **Studio 可在執行時切換語言。** 過去桌面應用程式及打包版本會保持英文。此功能尚未在所有平台上測試：若語言未變更，請告訴我們。
- Studio 0.8 安裝版會透過{{ui:設定}} › {{ui:更新}}提供 0.8.1 更新。

### 尚未納入此版本

- **未經程式碼簽署。** Windows 安裝程式與 macOS .dmg 尚未有簽章。在 Windows 上，若 SmartScreen 阻擋安裝程式，請選擇{{ui:更多資訊}}，再選擇{{ui:仍要執行}}。在 Mac 上，於 CadCraft Studio 按右鍵並選擇{{ui:開啟}}。商店版本暫緩。
- **連接 AI 仍有未完成之處。** 在 Studio 內一鍵連接、供瀏覽器助理使用的託管連接器，以及在 Studio 內使用你自己的 API 金鑰，均不保證於本版本提供。工作流程已測試，但尚未與真實助理測試。
- **工作檢查需相同的頁面尺寸。** 以其他尺寸重新出圖的圖紙將無法對應，因此其工作不會關閉。圖紙依圖紙編號配對，若無則依頁面位置配對。
- **語音附註僅為錄音。** 沒有文字稿，助理只能看到附註的長度、作者與說明文字，聽不到聲音。錄音曾在無頭瀏覽器中以假麥克風測試；真實麥克風在手機、平板或筆電上的表現仍待確認。
- **PDF 中的計算表與理由**保存在檔案的私有項目中。較舊的 MarkupCraft 會忽略該項目，並在下次儲存時將其移除，因此請以 0.8 或更新版本開啟並儲存此類檔案。
- **紅線的繪圖者端。** CadCraft 讀取紅線檔案並回覆的功能尚未實作。
- **其他語言。** 泰米爾語的應用程式列溢出 528 px。

其餘內容請見[尚未實作的功能](topic:not-built-yet)。上一版請見[0.7 新功能](topic:whats-new-0-7)。
