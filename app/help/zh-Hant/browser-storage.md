MarkupCraft 沒有帳戶，也沒有伺服器端的儲存空間。少量資料會存放在瀏覽器為本網站保留的儲存空間中，其餘內容都在你的檔案裡。

## 瀏覽器中儲存的內容

| 項目 | 設定位置 | 儲存形式 |
|---|---|---|
| 作者名稱 | 狀態列中的名稱按鈕，或{{ui:Settings}} | 一個名稱 |
| MarkupCraft 設定 | {{ui:Settings}}，{{ui:MarkupCraft}}索引標籤：新標記的顏色與線寬、貼上時複本的放置位置、單位（請見 [MarkupCraft 設定](topic:settings)） | 一組 |
| 工具設定 | 繪圖工具開啟時，於{{ui:Properties}}中設定：各工具的顏色、線條、填滿、不透明度與文字大小、所選印章、計數群組名稱 | 一組 |
| 工具箱 | {{ui:Tools}}索引標籤 | 最多500個工具 |
| 最近複製的內容 | {{ui:Copy}}或{{ui:Cut}} | 已複製的標記，讓其他分頁可以貼上；下次複製時會被取代 |
| 印章圖片與簽名 | 印章清單中的{{ui:Picture…}}與{{ui:My signature…}} | 最後使用的圖片與簽名 |
| 復原複本 | PDF 有尚未儲存的標記時自動保留 | PDF 與其標記；儲存、關閉或捨棄該 PDF 時會移除；最多保留30天 |

## 這代表什麼

- **每個瀏覽器、每台電腦各自獨立。** 同一台電腦上的 Chrome 與 Firefox 各自有獨立的資料。你的筆電與辦公室桌機也各自獨立。即使在瀏覽器登入，各裝置之間也不會同步。
- **私密視窗與無痕視窗**一開始是空的，關閉後會忘記所有內容。
- **清除網站資料會刪除這些內容。** 在瀏覽器設定中清除此網站的 Cookie 與網站資料，或清除所有網站的資料，會移除作者名稱、設定與工具箱。部分清理工具與公司政策會自動執行此動作。
- **不會上傳任何內容。** 這些值不會離開這台電腦，但你儲存的 PDF 內所含的名稱除外。復原複本也只保留在此瀏覽器中。

:::safari
Safari 若數週未造訪某網站，可能會刪除該網站的已儲存資料。請不時開啟 MarkupCraft，並保留已匯出的工具箱。
:::

## 不會儲存在瀏覽器中的內容

- **你的標記（永久保存）。** 標記應保存在你儲存的「(marked up)」PDF 中。復原複本只是當機或關閉分頁時的安全網，並非用來保存工作的地方：儲存後就會移除，清除網站資料也會刪除它。請見 [復原尚未儲存的內容](common:recover)。
- **你開啟的檔案。** 每次開啟 MarkupCraft 時，都要重新開啟 PDF。
- **目前的圖紙、縮放、篩選與復原歷程。** 這些會保留到關閉該圖紙集或分頁為止。

## 備份並移轉設定

- **工具箱：**{{ui:Tools}}，然後{{ui:Export}}。在另一個瀏覽器或電腦上，{{ui:Tools}}，然後{{ui:Import}}。
- **名稱：**在另一個瀏覽器上重新輸入（點選狀態列中的名稱按鈕）。
- **工具設定：**重新設定，或將每個已設定樣式的標記儲存為工具，讓它隨工具箱一起移動。

## 重新開始

若要全部重設，請在瀏覽器設定中清除此網站的資料。名稱、設定與工具箱會被移除；六個預設工具會重新出現。

## 離線複本

頂端列中的{{ui:Save for offline}}也會將應用程式本身的檔案（包含 PDF 讀取與寫入功能，約6 MB）儲存在瀏覽器中，與這些設定分開。清除網站資料也會移除該複本；若只想移除它，請點選「已可離線使用」，再選擇「移除離線複本」。請見 [離線工作](common:offline)。

雲端儲存與電腦之間的同步目前尚未實作。
