MarkupCraft 用於審閱圖面：開啟 PDF 圖紙集，用雲形框、引註、文字、圖章與量測加註標記，追蹤每則註解的狀態，並儲存一份任何 PDF 檢視器都能顯示的 PDF 副本。

它在你的網頁瀏覽器中執行。你的 PDF 在自己的電腦上開啟，**絕不會上傳**。儲存時會下載一份新副本，原始檔案不會變動。

:::note
MarkupCraft 仍在開發中。本說明描述的是你目前執行的版本。尚未實作的功能列在[尚未實作的項目](topic:not-built-yet)。
:::

## 需要準備的東西

- Mac、Windows 或 Linux 電腦上較新的 Chrome、Edge、Firefox 或 Safari，或 iPad 上的 Safari 或 Chrome。見[瀏覽器與電腦](common:browsers)。
- 一個或多個 PDF 檔案。整套圖紙可以是一個 PDF，也可以是許多個。
- 附滾輪的滑鼠最為順手。觸控板可用，觸控螢幕也可以（見[在 iPad 或觸控螢幕上審閱](topic:review-on-a-tablet)）。

## 十個步驟完成第一次審閱

1. 在瀏覽器中開啟 MarkupCraft。畫面中央顯示「開啟一套平面圖」。
2. 選擇{{ui:開啟 PDF}}（或工具列最左端的{{ui:開啟}}，或按{{key:Mod+O}}），選取一個或多個 PDF 並確認。
   也可以從{{pick:mac=Finder|windows=檔案總管|linux=檔案管理員}}拖曳 PDF，放到圖紙區。
   第一次開啟時，底部的狀態列會顯示「正在載入 PDF 讀取器…」。接著每一頁都會成為左側{{ui:圖紙}}清單中的一張圖紙，第一張圖紙會填滿中央。
3. 在清單中按一下圖紙即可顯示。在圖紙上轉動滑鼠滾輪，會以指標所在位置為中心縮放。
4. 在工具列的{{ui:修訂}}群組中選擇{{ui:雲形框}}（或按{{key:C}}）。
   第一次選取繪圖工具時，MarkupCraft 會詢問你的名稱。輸入後選擇{{ui:儲存}}。每個標記都會記錄此名稱。（詳見[設定作者名稱](topic:set-your-name)。）
5. 拖曳出要標示的區域範圍。會出現紅色的修訂雲形框並呈選取狀態。
6. 在{{ui:註記}}群組中選擇{{ui:引註}}（或按{{key:K}}）。在你要指出的位置按下，拖曳到文字要放置的位置後放開。
7. 在出現的方塊中輸入註解。在方塊外任意處按一下（或按{{key:Mod+Enter}}）即可完成。
8. 按兩次{{key:Esc}}：第一次清除選取，第二次回到{{ui:選取}}工具。按一下雲形框。右側的{{ui:屬性}}索引標籤會顯示建立者、建立時間，以及它的{{ui:狀態}}。
9. 在工具列選擇{{ui:儲存}}（或按{{key:Mod+S}}）。
   瀏覽器會下載一份名稱類似「A-Plans (marked up).pdf」的副本。狀態列會列出寫入了多少個標記。
10. 用任何 PDF 檢視器開啟該副本來檢查：雲形框與引註都在，是帶有你名稱的一般 PDF 註解。

之後要繼續工作時，在 MarkupCraft 中開啟「(marked up)」副本。你的標記會連同狀態、回覆與缺失編號一起還原，並可編輯。

## 線上與離線

:::online
目前在線上。MarkupCraft 在你第一次開啟 PDF 時載入 PDF 讀取器，第一次儲存時載入 PDF 寫入器。若之後要在沒有網路連線的情況下工作（到工地現場、在飛機上），請現在選擇頂端列的{{ui:儲存供離線使用}}，並等到顯示「可離線使用」。該副本包含 PDF 讀取器與寫入器，因此之後開啟與儲存 PDF 都能離線運作。見[離線工作](common:offline)。
:::

:::offline
目前離線。若頂端列顯示「可離線使用」，表示 MarkupCraft 已儲存供這個瀏覽器離線使用，一切都能運作：開啟、加註標記、量測、儲存。若沒有，請使用這個索引標籤中已載入的內容，並且在重新連上網路之前不要重新整理頁面。見[離線工作](common:offline)。
:::

## 程式會記住什麼，不會記住什麼

- **你的標記存在你儲存的 PDF 中。**伺服器上不保留任何內容。程式不會自行儲存 PDF，但在你儲存之前，會在這個瀏覽器中保留一份復原副本。關閉索引標籤前請先儲存；若在有尚未儲存的標記時嘗試離開，瀏覽器會先詢問（iPad 除外，見[在 iPad 或觸控螢幕上審閱](topic:review-on-a-tablet)）。
- **你的名稱、工具樣式與工具箱**留在這台電腦的這個瀏覽器中。換一個瀏覽器或電腦就會從頭開始，清除瀏覽器的網站資料也會一併移除。見[瀏覽器中保留的內容](topic:browser-storage)。
- 雲端儲存與多人共用的審閱工作階段目前尚未提供。
