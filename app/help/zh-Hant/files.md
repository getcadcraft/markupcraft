## MarkupCraft 開啟的檔案

| 檔案 | 方式 | 結果 |
|---|---|---|
| PDF（`.pdf`） | {{ui:開啟}}、{{key:Mod+O}}，或拖放到圖紙區。可一次開啟多個。 | 每一頁成為一張圖紙。檔案中已有的標記會重新讀入（見下方）。 |
| 工具箱（`.json`） | {{ui:工具}}索引標籤，再按{{ui:匯入}} | 工具會加入你的工具箱。見[工具箱](topic:tool-chest)。 |

其他檔案一律拒絕，狀態列會顯示「MarkupCraft 僅開啟 PDF 檔案。」。若同時拖放不同類型的檔案，PDF 會開啟，狀態列會說明有幾個檔案不是 PDF。

### PDF 中已有的標記

- **MarkupCraft 儲存的標記**會原樣還原：類型、樣式、作者、日期、狀態、回覆、缺失編號、圖紙的比例，以及你輸入的圖紙名稱。
- **其他 PDF 程式的註解**也會讀入。矩形、橢圓、直線與箭頭、折線、多邊形、手繪（筆）線條、文字方塊與便利貼，會成為一般可編輯的 MarkupCraft 標記，其回覆與審閱狀態一併帶入。
- **其他一切**（選取文字所做的文字螢光標示、其他程式的圖章，以及其他類型）依原樣顯示，並標示為唯讀。可以選取、在標記清單中檢視並回覆，但無法移動、變更或刪除。
- 連結與表單欄位保持原狀，不會列出。
- 其他程式儲存的比例（量測視埠），若 MarkupCraft 看得懂其單位，就會當作該圖紙的比例使用。

### 無法開啟的檔案

- 需要密碼的 PDF：「name」開啟時需要密碼。請開啟未加密的副本。
- 已損毀或其實不是 PDF 的檔案：無法將「name」讀取為 PDF（……）。
- 可開啟但受到防止修改保護的 PDF 能正常開啟，但儲存會被拒絕（見下方）。

同時開啟多個檔案時，能開啟的會照常開啟，另有名為「部分檔案無法開啟」的方塊列出其餘檔案。

## MarkupCraft 儲存的檔案

儲存一律是**下載**一份新檔案。網頁無法覆寫你電腦上的檔案，MarkupCraft 也絕不會更動你的原始檔。

| 你選擇 | 你得到 | 附註 |
|---|---|---|
| {{ui:儲存}}（{{key:Mod+S}}） | 「<name> (marked up).pdf」 | 原始 PDF 的副本，每個標記都寫入為真正的 PDF 註解。再次儲存「(marked up)」檔案時沿用同一名稱，不會變成「(marked up) (marked up)」。見[儲存加註標記的 PDF](topic:save-the-marked-up-pdf)。 |
| {{ui:標註}}索引標籤，再按{{ui:CSV}} | 「<name> markups.csv」 | 依清單所列的標記（篩選條件有效）。 |
| {{ui:標註}}索引標籤，再按{{ui:BCF}} | 「<name> markups.bcfzip」 | 供 BIM 協調工具使用的 BCF 2.1，每個標記一張快照。見[BCF 基礎](topic:bcf-basics)。 |
| {{ui:缺失清單}}索引標籤，再按{{ui:匯出 CSV}} | 「<name> punch list.csv」 | 依編號順序排列的缺失項目。 |
| {{ui:工具}}索引標籤，再按{{ui:匯出}} | 「MarkupCraft tool chest.json」 | 你的工具箱，供分享或保存。 |

「<name>」是第一個已開啟 PDF 的檔名，不含「.pdf」。

CSV 檔案可用任何試算表開啟。檔案為 UTF-8，並帶有試算表會尋找的標記，所以帶重音符號的名稱能正確顯示。以 =、+、- 或 @ 開頭的儲存格會加上前置單引號，避免試算表把它當成公式執行。

## 下載的檔案存到哪裡

由瀏覽器決定：通常是「下載」資料夾；若你設定為每次詢問，則每次都會詢問。見[瀏覽器與電腦](common:browsers#what-differs-between-browsers)。

:::chromium
一次儲存一組檔案中所有已變更的檔案時，Chrome 與 Edge 可能會詢問此網站是否可以下載多個檔案。請選擇{{ui:允許}}，否則只會得到第一份副本。
:::

:::safari
在 iPad 上，Safari 每次下載前都會詢問，並把檔案放進「檔案」App 的「下載項目」中。在 Mac 上，檔案會存到 Safari 設定中指定的資料夾。
:::

## 線上與離線

- **你的 PDF 絕不會離開這台電腦**，不論線上或離線，都沒有任何上傳。
- PDF 讀取器在第一次開啟 PDF 時載入（「正在載入 PDF 讀取器…」），PDF 寫入器則在第一次儲存（「正在載入 PDF 寫入器…」）或開啟已含註解的檔案時載入。
- 有網路連線時，兩者都從網站載入。
- **要在沒有網路連線時工作**，請在線上時選擇頂端列的{{ui:儲存供離線使用}}。按鈕會顯示「儲存中 N/M」，然後顯示「可離線使用」。該副本包含 PDF 讀取器與 PDF 寫入器（合計約 6 MB）以及這份說明，之後在這個瀏覽器中，開啟、加註標記與儲存 PDF 都能離線運作。
- 若按鈕顯示「無法儲存」，表示有些檔案沒有下載成功：請檢查網路連線並再按一次。若顯示「無法離線使用」，表示這個瀏覽器視窗無法保留離線副本（私密視窗與部分受管理的電腦）；請改用一般視窗。
- 要更新或移除該副本，請按「可離線使用」，再選擇「重新儲存（取得最新版本）」或「移除離線副本」。詳見[離線工作](common:offline)。

:::offline
目前離線。若頂端列顯示「可離線使用」，一切都能運作，包括儲存。若沒有顯示，且在這個索引標籤中尚未儲存過，{{ui:儲存}}可能會失敗並顯示「無法載入 PDF 寫入器」。你的標記仍留在索引標籤中：請保持開啟、重新連上網路，再選擇{{ui:儲存}}。
:::

## 須知

- 大型圖紙集需要一些時間開啟：MarkupCraft 會讀取每一頁的文字以找出圖號。狀態列會隨進度計算圖紙數。
- 同一份 PDF 開啟兩次，其圖紙會加入兩次。若發生這種情況，請關閉該圖紙集後重新開啟。
- {{ui:關閉}}會一次關閉所有已開啟的檔案。若有檔案含尚未儲存的標記，會詢問：{{ui:取消}}、{{ui:不儲存直接關閉}}或{{ui:先儲存副本}}。
- 尚無雲端儲存，也尚無桌面版。請把 PDF 與其他專案檔案放在一起，並照常備份。見[檔案的去向](common:your-files)。
