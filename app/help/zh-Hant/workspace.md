MarkupCraft 佈滿整個瀏覽器視窗。由上到下、由左到右依序為：

## 最上方的列

最上方那條細長列屬於 CadCraft 系列，並非 MarkupCraft 本身。上面有：

- 應用程式名稱與目前執行的版本，
- {{ui:關於MarkupCraft}}，開啟網站上此應用程式的頁面，
- {{ui:說明}}，在側邊面板中開啟這份說明（或按{{key:F1}}），
- {{ui:儲存供離線使用}}，把 MarkupCraft、其 PDF 讀取器與寫入器以及這份說明保存在這個瀏覽器中，讓它在沒有網路連線時也能開啟；完成後會顯示「可離線使用」（見[離線工作](common:offline)），
- 螢幕模式按鈕（{{ui:全螢幕}}），以及
- {{ui:設定}}（或{{key:Mod+,}}），其中{{ui:MarkupCraft}}索引標籤是此應用程式本身的設定，{{ui:一般}}則是所有 CadCraft 應用程式共用的設定（見 [MarkupCraft 設定](topic:settings)），以及
- {{ui:圖紙}}與{{ui:模型}}，即淺色與深色主題。在{{ui:模型}}中，圖紙以深底淺色繪出；你的標記保有自己的顏色。

螢幕模式按鈕或{{key:Ctrl+Shift+F}}會依序切換三種模式：一般、全螢幕，以及隱藏各列的全螢幕。隱藏各列時，把指標移到螢幕上緣（或在該處點一下），各列就會滑回。此快速鍵在每種電腦上都使用 Control 鍵，Mac 也一樣。

:::note
在全螢幕中，{{key:Esc}}也會讓瀏覽器離開全螢幕。若你只是要取消繪製，請再按一次{{key:Ctrl+Shift+F}}回到全螢幕。
:::

## 工具列

頂端列下方的工具分組並加上標示：

| 群組 | 按鈕 |
|---|---|
| 檔案 | {{ui:開啟}}、{{ui:儲存}}、{{ui:關閉}} |
| 選取 | {{ui:選取}}、{{ui:平移}} |
| 繪製 | {{ui:手繪}}、{{ui:螢光筆}}、{{ui:直線}}、{{ui:箭頭}}、{{ui:矩形}}、{{ui:橢圓}}、{{ui:折線}}、{{ui:多邊形}} |
| 修訂 | {{ui:雲形框}}、{{ui:自由雲形線}} |
| 註記 | {{ui:引註}}、{{ui:文字}}、{{ui:便利貼}}、{{ui:印章}} |
| 量測 | {{ui:校正}}、{{ui:長度}}、{{ui:面積}}、{{ui:計數}} |
| 編輯 | {{ui:復原}}、{{ui:取消復原}}、{{ui:複製}}、{{ui:貼上}}，以及{{ui:更多}}：{{ui:剪下}}、{{ui:複製}}、{{ui:貼上}}、{{ui:原位貼上}}、{{ui:製作副本}}、{{ui:刪除}}、{{ui:全選}}、{{ui:取消全選}} |

正在使用的工具看起來是按下的狀態。把指標停在按鈕上可以看到它的按鍵（例如「矩形（R）」）；{{ui:更多}}功能表會在每個指令旁列出其按鍵。目前無法作用的按鈕會變暗：選取標記之前，{{ui:複製}}無法使用；複製任何內容之前，{{ui:貼上}}無法使用。{{ui:儲存}}後方的小圓點表示有些標記尚未儲存。完整的按鍵清單見[鍵盤與滑鼠](topic:keyboard)。

工具在繪製後仍維持啟用，因此可以連續畫出多個雲形框。按{{key:Esc}}（若新標記仍在選取中則按兩次）或{{key:V}}可回到{{ui:選取}}。

## 圖紙清單（左側）

{{ui:圖紙}}列出每個已開啟 PDF 的每一頁。每一列顯示圖紙的小圖、名稱、圖號或檔案與頁碼，以及它有多少個標記。標題後面的數字是圖紙數。

- 按一下某一列即可顯示該圖紙。
- 在{{ui:搜尋圖紙}}中輸入，可依圖紙名稱、圖號或檔名篩選。按{{key:Enter}}開啟第一個符合的項目。

圖紙名稱若 PDF 內有就取自 PDF。見[開啟圖紙集並在圖紙間切換](topic:open-a-plan-set)。

## 圖紙區（中央）

你正在處理的圖紙。尚未開啟任何檔案時，會顯示「開啟一套平面圖」與一個{{ui:開啟 PDF}}按鈕。把 PDF 拖放到此處任何位置即可開啟。

圖紙下方有一條窄列，包含：

- 上一張與下一張圖紙的箭頭，以及「3／12：A-101 — 平面圖」（把指標停在上面可看到檔案與頁碼），
- 縮小、縮放方塊（輸入百分比後按{{key:Enter}}；在一般螢幕上 100% 即實際大小）、放大，
- {{ui:符合頁面}}與{{ui:符合寬度}}。

圖紙集開啟期間，每張圖紙都會記住自己的縮放比例。

比對兩張圖紙時，這裡會出現圖例：「僅見於舊圖紙」、「僅見於新圖紙」與「兩者皆有」。見[比對兩個版次](topic:compare-revisions)。

## 面板（右側）

共有五個索引標籤：

| 索引標籤 | 顯示內容 |
|---|---|
| {{ui:屬性}} | 所選的標記：作者、日期、量測值、狀態、主旨、文字、註解、樣式、其回覆與缺失項目。啟用繪圖工具且未選取任何東西時，顯示新標記將使用的設定。未選取任何東西且{{ui:選取}}為啟用時，顯示圖紙：編號、標題、名稱的讀取來源、紙張大小、比例與{{ui:重新命名圖紙}}。 |
| {{ui:標註}} | 已開啟圖紙集中的所有標記，附篩選條件，以及{{ui:CSV}}與{{ui:BCF}}匯出。見[標記清單](topic:markups-list-and-export)。 |
| {{ui:缺失清單}} | 帶編號的缺失項目，含指派對象、到期日與狀態。見[製作缺失清單](topic:punch-list)。 |
| {{ui:工具}} | 工具箱：已儲存且帶有樣式的工具。見[工具箱](topic:tool-chest)。 |
| {{ui:比對}} | 疊合兩張圖紙。見[比對兩個版次](topic:compare-revisions)。 |

## 狀態列（底部）

- 左側是指標在圖紙上的位置，以紙張上的英吋計（或在[設定](topic:settings)中改為公釐）。
- 中間是訊息：工具接下來需要什麼、剛剛儲存了什麼、為什麼被拒絕。**當某件事沒有發生時，請看這裡。**
- 圖紙的比例按鈕（「未校正」，或比例值）。按一下可設定比例。見[校正圖紙並量測](topic:calibrate-and-measure)。
- 你的名稱（在你設定之前，會顯示設定名稱的提示）。按一下可變更。

## 在小螢幕上

寬度低於約 1180 像素時，面板會變窄，圖紙縮圖也會縮小。在手機大小的螢幕上，各部分會堆疊：工具列（可左右捲動）、圖紙、狀態列、面板，最後是底部的圖紙清單。橫向的平板電腦則維持完整版面。
