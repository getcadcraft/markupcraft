## 輸入長度

以兩點校正時，要輸入實際距離。MarkupCraft 能讀取以下所有格式：

| 輸入內容 | 代表 |
|---|---|
| `24'-0"` | 24英尺 |
| `12' 6 1/2"` 或 `12'-6 1/2"` | 12英尺6½英寸 |
| `12' 6` | 12英尺6英寸（省略英寸符號） |
| `6"` 或 `1/2"` | 英寸 |
| `12.5'` 或 `12.5 ft` | 12½英尺 |
| `3 ft 6 in` | 3英尺6英寸（也可用 feet、foot、inch、inches） |
| `3.5 m`、`90 cm`、`900 mm` | 公制（也可用 meter、metre、millimeter、centimetre 等） |
| `24` | 純數字，以{{ui:長度顯示單位}}中選擇的單位為準 |

彎引號（’ ”）與兩個單引號（''）表示英寸也可使用。零長度與負長度會被拒絕。

:::warning
逗號會被當作小數點：`1,5 m` 代表 1.5公尺。勿輸入千分位分隔符號：`1,200 mm` 會被讀成 1.2毫米。應輸入 `1200 mm`。
:::

## 長度與面積的顯示方式

| {{ui:長度顯示單位}} | 長度顯示為 | 面積顯示為 |
|---|---|---|
| {{ui:英尺與英寸}} | `12'-6 1/2"`，捨入至 1/16" | 平方英尺，兩位小數 |
| {{ui:十進位英尺}} | `12.54'`，兩位小數 | 平方英尺，兩位小數 |
| {{ui:英寸}} | `150.5"`，最多兩位小數 | 平方英寸，一位小數 |
| {{ui:公尺}} | `3.820 m`，三位小數 | 平方公尺，三位小數 |
| {{ui:毫米}} | `3820 mm`，整數毫米 | 平方毫米，整數 |

面積的周長使用長度格式。

## 預設比例

預設比例假設 PDF 為其完整列印尺寸：每英寸72個 PDF 點，與 CAD 程式輸出時相同。

| 群組 | 比例 | 長度顯示單位 |
|---|---|---|
| 建築 | 1/32" = 1'-0"、1/16"、3/32"、1/8"、3/16"、1/4"、3/8"、1/2"、3/4"、1"、1 1/2"、3" = 1'-0" | {{ui:英尺與英寸}} |
| 工程 | 1" = 10'、20'、30'、40'、50'、60'、100' | {{ui:十進位英尺}} |
| 公制 | 1:1、1:5、1:10、1:20、1:25、1:50 | {{ui:毫米}} |
| 公制 | 1:100、1:200、1:250、1:500、1:1000 | {{ui:公尺}} |

若要使用預設比例但以其他單位顯示長度，改以兩點校正，並在該處選擇單位。

## 其他程式儲存的比例

若 PDF 已為某頁儲存了其他程式的比例（頁面上儲存的量測比例），且該比例為英尺、英寸、公尺、公分或毫米，MarkupCraft 會使用它。其標籤會依檔案所述顯示。

## 紙面位置

狀態列會顯示指標在紙面上的位置，以英寸計、從圖紙左上角起算，與圖紙比例無關。Compare 的微調步距以點為單位（每英寸72點）。

## 精確度

量測的精確度取決於校正與點按的準確性。以能找到的最長已知尺寸進行校正，放大後點按其端點，然後再檢查另一個尺寸。製作時已縮放的 PDF（「符合頁面」列印或半尺寸的圖紙集）在以某一尺寸校正後仍然準確，但不能使用預設比例。
