## 繪製時

| 按鍵或操作 | 功能 |
|---|---|
| 繪製時按{{key:Shift}} | 直線、箭頭、長度與折線的邊以 45° 為間隔；矩形、橢圓與方框雲形都會成為正方形；手繪與螢光筆則為一筆直線 |
| 連按兩下、按{{key:Enter}}或按滑鼠右鍵 | 完成折線、多邊形、自由雲形線或面積 |
| {{key:Backspace}} | 移除折線、多邊形、自由雲形線或面積的最後一個點 |
| {{key:Esc}} | 取消正在繪製的內容；若沒有進行中的操作，則清除選取；若未選取任何物件，則回到{{ui:選取}} |
| {{key:Mod+Enter}} | 完成文字方塊、引註或便利貼中的輸入（或點選其外部） |
| 輸入時按{{key:Esc}} | 取消正在輸入的文字 |
| 使用{{ui:計數}}時按住{{key:Shift}}點選 | 移除所選計數群組中最近的一個點 |

## 選取與編輯

| 按鍵或操作 | 功能 |
|---|---|
| 點選 | 選取一個標記 |
| 按住{{key:Shift}}點選 | 將標記加入選取集或從中移除 |
| 在空白圖紙上由左向右拖曳 | 選取完全位於視窗內的物件 |
| 在空白圖紙上由右向左拖曳 | 選取被視窗碰觸到的物件 |
| {{key:Mod+A}} | 選取此圖紙上的所有標記 |
| 拖曳已選取的標記 | 移動它（按住{{key:Shift}}：沿 45° 為間隔移動） |
| 拖曳控點 | 調整大小或變更形狀（按住{{key:Shift}}：維持比例或 45°） |
| 方向鍵 | 將選取內容微調一個螢幕像素（按住{{key:Shift}}：十個像素） |
| 連按兩下，或按{{key:Enter}} | 編輯文字方塊、引註或便利貼的文字；若為印章，則開啟{{ui:屬性}} |
| {{key:Delete}}或{{key:Backspace}} | 刪除選取集 |
| {{key:Esc}} | 取消所有選取 |
| {{key:Mod+Z}} | {{ui:復原}} |
| {{key:Mod+Y}}或{{key:Mod+Shift+Z}} | 取消復原 |

## 剪下、複製與貼上

相同的指令也位於工具列的{{ui:編輯}}群組（{{ui:複製}}、{{ui:貼上}}）及其{{ui:更多}}功能表中，各自附有快速鍵。每一項都是單一的復原步驟。請參閱[複製、貼上與建立副本](topic:select-and-edit#copy-paste-and-duplicate)。

| 按鍵 | 功能 |
|---|---|
| {{key:Mod+X}} | 剪下：複製選取集並將其刪除 |
| {{key:Mod+C}} | 複製選取集 |
| {{key:Mod+V}} | 貼上。若指標位於圖紙上，副本會置中於指標所指之處；否則貼在原物件旁。{{ui:設定}}中可設定為一律貼在原物件旁。 |
| {{key:Mod+Shift+V}} | 原位貼上：貼在圖紙上的相同位置，可為此圖紙或另一張圖紙 |
| {{key:Mod+D}} | 在選取集旁建立副本（剪貼簿內容不變） |

## 縮放與平移

| 按鍵或操作 | 功能 |
|---|---|
| 滑鼠滾輪 | 以指標為中心放大或縮小（滾輪不會捲動） |
| {{key:Ctrl}} + 滾輪 | 較快速地縮放 |
| {{key:Plus}}或{{key:Minus}}（也可搭配{{key:Mod}}） | 以畫面中央為中心放大或縮小；{{key:=}}也可作為加號使用 |
| {{key:Mod+0}} | {{ui:符合頁面}} |
| {{key:Mod+9}} | {{ui:符合寬度}} |
| 以中鍵拖曳 | 平移 |
| 以右鍵拖曳 | 平移（當你不在折線繪製中途時） |
| 按住{{key:Space}}並拖曳 | 平移 |
| 未選取任何物件時按方向鍵 | 平移 |
| {{key:Ctrl+Shift+F}} | 螢幕模式：一般、全螢幕、隱藏列的全螢幕（在每台電腦上皆使用 Control 鍵） |

:::mac
**在觸控板上：**雙指捲動可縮放。在 Chrome、Edge 與 Firefox 中捏合也可縮放。按住{{key:Space}}並拖曳，或使用{{ui:平移}}工具來平移。雙指點按等同於按滑鼠右鍵，並可結束折線。在此處按住 Control 再點按，可能只會作為一般點選而非右鍵，因此請使用雙指點按。
:::

## 觸控

| 手勢 | 功能 |
|---|---|
| 單指 | 以目前工具繪製，或選取 |
| 雙指 | 捏合可圍繞兩指中間縮放，移動則可平移 |
| 繪製過程中加入第二根手指 | 取消該筆畫，改為縮放 |
| 連點兩下 | 完成折線、多邊形、自由雲形線或面積 |

點數、便利貼、折線點，以及兩點式工具的第二點，會在手指抬起時放置。請參閱[在 iPad 或觸控螢幕上審閱](topic:review-on-a-tablet)。
:::

## 瀏覽器保留的快速鍵

- {{key:Mod+W}}、{{key:Mod+T}}、{{key:Mod+N}}與{{key:Mod+Q}}屬於瀏覽器。若在有尚未儲存的標記時關閉分頁或視窗，這些標記會遺失；在電腦上，瀏覽器會先詢問「離開網站？」。
- 多數瀏覽器將{{key:Mod+N}}保留給新視窗，因此在瀏覽器分頁中請使用工具列中的{{ui:新增}}；桌面應用程式與 Studio 會將此按鍵交給 MarkupCraft。
- 應用程式擁有鍵盤焦點時，MarkupCraft 會從瀏覽器接管{{key:Mod+O}}、{{key:Mod+S}}、{{key:Mod+D}}、{{key:Mod+A}}、{{key:Mod+V}}、{{key:Mod+Shift+V}}、{{key:Mod+0}}、{{key:Mod+Plus}}與{{key:Mod+Minus}}；選取標記時也會接管{{key:Mod+C}}與{{key:Mod+X}}。{{key:Mod+,}}會開啟{{ui:設定}}。若要改為縮放整個瀏覽器頁面，請使用瀏覽器的功能表。
- 部分瀏覽器會在 MarkupCraft 接收到前，先將{{key:Mod+9}}跳至最後一個瀏覽器分頁。若發生這種情況，請使用圖紙下方的{{ui:符合寬度}}。
- 在全螢幕中按{{key:Esc}}也會離開全螢幕。

## 按鍵無作用時

- **正在方塊中輸入。**請先點選圖紙。（以繪圖工具點選會直接繪製；之後請按{{key:Esc}}，或使用{{key:Mod+Z}}。）
- **已開啟對話方塊。**按鍵會送至對話方塊，直到其關閉為止。
- **剛點選了工具列按鈕**，此時方向鍵或{{key:Space}}會改由該按鈕處理。請將指標移到圖紙上，改用滾輪或中鍵；或按工具字母，而非點選按鈕。

## 移動功能的位置

沒有「移動」指令：請選取標記並拖曳它（按住{{key:Shift}}可維持 45° 的間隔）。圖釘請使用{{ui:移動圖釘}}移動，頁面則使用{{ui:將頁面前移}}或{{ui:將頁面後移}}。
