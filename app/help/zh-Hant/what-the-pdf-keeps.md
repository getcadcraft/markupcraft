標記後的複本是在原始 PDF 上加入註解（PDF 註解）。頁面本身、其圖形、文字、書籤與連結，都會依原樣複製。

## 每個標記

| MarkupCraft | 儲存為 | 其他 PDF 檢視器顯示 |
|---|---|---|
| 矩形、方框雲形 | 方形註解（雲形：雲狀邊框） | 矩形或雲形註解 |
| 橢圓 | 圓形註解 | 橢圓註解 |
| 多邊形、自由雲形 | 多邊形註解（雲形：雲狀邊框） | 多邊形或雲形註解 |
| 聚合線 | PolyLine 註解 | 聚合線註解 |
| 直線、箭頭 | 直線註解（箭頭：封閉箭頭） | 直線或箭頭註解 |
| 長度 | 標示為標註並附帶量測值的直線註解 | 長度量測（若檢視器支援） |
| 面積 | 標示為面積並附帶量測值的多邊形註解 | 面積量測（若支援）；否則為多邊形 |
| 計數群組 | 一個墨跡註解，每個項目一個圓環；其文字為 "group: n" | 墨跡註解 |
| 畫筆、螢光筆 | 墨跡註解（螢光筆會標示為螢光） | 墨跡註解 |
| 文字 | 自由文字註解 | 文字方塊註解 |
| 註解框 | 附註解引線的自由文字註解 | 註解框註解 |
| 附註 | 文字註解 | 便利貼，開啟後顯示其文字 |
| 圖章 | 圖章註解 | 圖章註解 |

每個標記都會連同以下內容一併儲存：

- **各自的外觀**：依 MarkupCraft 在螢幕上的繪製方式儲存，因此在任何檢視器中外觀相同，列印結果也一樣，包括缺失編號徽章；
- **作者**、**建立與修改日期**、**主旨**、**註解文字**（文字方塊與註解框則包括文字及註解）、**顏色**與**不透明度**；
- **其 MarkupCraft 詳細資料**：存放於其他程式會忽略的私有項目中，包括狀態、缺失項目、樣式與類型，以便精確地重新開啟。

## 回覆串與狀態

- 每則回覆都會儲存為連結至其標記的回覆註解，包含作者、日期與文字。回覆在圖紙上沒有自己的圖示。
- 每次狀態變更都會儲存為帶有審閱狀態的回覆。其他審閱工具會將其顯示為 Accepted、Rejected 或 Completed；「開啟」則不儲存任何審閱狀態。
- 狀態不是「開啟」、但沒有記錄狀態變更的標記，會加入一則審閱狀態回覆，讓其他程式也能看到該狀態。
- 原始檔案中唯讀註解的回覆，會以相同方式儲存，並連結至該註解。

## 每張圖紙

- **比例：**已校正的圖紙會取得涵蓋整頁的量測視埠（儲存頁面比例的標準方式），以及 MarkupCraft 自己保存的校正副本。
- **圖紙編號：**以{{ui:重新命名圖紙}}輸入的編號會成為頁面標籤。若檔案中有任何一頁具有標籤，該檔案的每一頁都會取得標籤：優先使用輸入的編號，否則使用原有標籤，再否則使用頁碼。
- **圖紙標題：**輸入的標題只會為 MarkupCraft 儲存；其他檢視器不會顯示。

## 文字與字元

文字以 Helvetica 字型寫入，所有 PDF 檢視器都有此字型。西歐字元集（Windows-1252）以外的字母，在複本中會顯示為「?」；儲存訊息會計算這些字元的數量。

## 計算表與理由

計算表與理由存放於 PDF 中名為 `/MarkupCraftShell` 的私有項目。其他 PDF 程式會忽略它。較舊版的 MarkupCraft 也會忽略它，並會在下次儲存該檔案時將其移除。

## 原本已有的註解會怎麼處理

開啟已有註解的 PDF 時：

- MarkupCraft 自己的註解會精確讀回。若其他程式移動或調整了大小，則以其新位置為準。
- 其他程式的矩形、橢圓、直線、聚合線、多邊形、墨跡、文字方塊與便利貼，會成為可編輯的標記。**儲存時，MarkupCraft 會移除原始註解，並以自己的方式重新寫入**，連同其彈出視窗與回覆。外觀可能略有不同。
- 其他程式的審閱狀態會設定標記的狀態；以最新的為準。
- 其他所有項目（文字螢光標示、其他程式的圖章及特殊類型）都會**原封不動地保留**在複本中，且為唯讀。
- 連結與表單欄位會原封不動地保留，且不會列在清單中。

再次儲存同一檔案時絕不會重複：MarkupCraft 讀取的標記會被取代，而非重新加入。

## 不會變更的內容

磁碟上的原始檔案絕不會被變更。複本未針對檔案大小進行最佳化，因此可能比原始檔案稍大。受保護（已加密）的 PDF 無法儲存。
