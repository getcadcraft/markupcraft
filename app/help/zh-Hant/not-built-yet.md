MarkupCraft 仍在開發中。以下列出目前版本「尚未」提供的功能，方便規劃。內容描述的是目前版本，並非承諾。

## 與其他人協作

| 尚未實作 | 目前可以這樣做 |
|---|---|
| 電腦之間的雲端儲存與同步 | 將 PDF 與專案檔案放在一起。雲端儲存尚無法使用。 |
| 合併兩人的標記副本 | 依圖紙分配給各位審閱者，或用 {{key:Mod+C}} 與 {{key:Mod+V}} 複製少數標記。RFI、送審文件與施工日誌可以合併：請見[追蹤 RFI、送審文件與施工日誌](topic:field-records)。 |
| RFI 與送審文件的團隊、通知與雲端專案 | 將 PDF 轉交他人，再使用{{ui:合併}}匯整副本。 |
| 即時協作中的 RFI、送審文件與施工日誌 | 每人處理自己的副本，再使用{{ui:合併}}匯整副本。 |
| 合併兩人對同一筆記錄不同欄位的變更 | 最後變更的副本會整筆取代該筆記錄（其回覆串與附件名稱會併在一起）。請先約定由誰編輯哪一筆記錄。 |
| RFI、送審文件與施工日誌的助理工具 | 在{{ui:現場}}索引標籤中處理。助理可以處理標記：請見[在MarkupCraft中使用AI助理](topic:use-with-ai-assistants)。 |
| 編輯或刪除已送出的回覆 | 立即復原，或另外新增一則更正回覆。 |
| 變更標記的作者 | 開始前先設定名稱。 |

## 標記

| 尚未實作 | 目前可以這樣做 |
|---|---|
| 可填寫欄位的圖章、認證數位簽章 | 使用自訂文字圖章（可含姓名與日期），或簽名圖片。 |
| 附加照片以外的檔案（文件、影片） | 與 PDF 放在一起，並在註解中提及。 |
| 連結到網站或未開啟的檔案 | 在註解中寫下網址或檔案名稱。 |
| 自訂狀態組合 | 使用四種狀態，其他內容寫在主旨中。 |
| 編輯隨檔案附帶的唯讀註解（文字螢光標示、其他程式的圖章） | 回覆這些註解，或在旁邊繪製 MarkupCraft 標記。 |
| 依筆壓變化的筆跡 | 設定線寬。 |

## 圖紙本身的內容

| 尚未實作 | 目前可以這樣做 |
|---|---|
| 直接在頁面中繪製新圖形 | 先繪製為標記，再使用{{ui:放入頁面}}。請見[變更頁面本身的內容](topic:page-content)。 |
| 將頁面物件旋轉到任意角度 | 移動與調整大小；要旋轉整頁，請使用{{ui:頁面}}。 |
| 變更單行文字的字型或大小，或跨多行的文字 | 逐行修改文字；若要以其他字型加入新文字，請新增文字標記。 |
| 編輯掃描圖片內的內容 | 替換圖片，或對其加上標記。 |
| 編輯加密或已簽署的 PDF | 索取未簽署的副本；標記適用於任何 PDF。 |

## 量測

| 尚未實作 | 目前可以這樣做 |
|---|---|
| 半徑量測 | 沿著半徑繪製{{ui:圓弧}}，或量測橫跨的{{ui:長度}}後再除以二。 |
| 編輯開孔的角落 | 刪除開孔後重新繪製。 |
| 一次對多張圖紙套用同一比例 | 逐張校正；選取預設比例每張圖紙需要數秒。 |
| 同一張圖紙上有多種比例（視埠） | 依最常量測的圖形校正。變更圖紙比例會重新量測其上所有內容，因此重新校正前請先記下細部數值。 |
| 鎖點到圖形中的線條 | 點擊前先放大，或輸入長度與角度（請見[依比例繪製草圖](topic:calibrate-and-measure#sketch-to-scale)）。 |
| 含項目、組合與單價的完整數量計算 | 使用 TakeoffCraft（CadCraft 系列的數量計算程式）。 |

## 圖紙與檔案

| 尚未實作 | 目前可以這樣做 |
|---|---|
| 復原頁面變更（旋轉、移動、插入、刪除） | 不儲存直接關閉，再重新開啟原始 PDF。請見[列印與變更頁面](topic:pages-and-printing)。 |
| 關閉圖紙集中的單一檔案 | {{ui:關閉}}會關閉整個圖紙集；需要的檔案請重新開啟。 |
| 將圖紙集儲存為專案，以便一次重新開啟 | 重新開啟相同的 PDF。 |
| 以指定比例列印，或一張紙列印多張圖紙 | 使用瀏覽器的印表機對話方塊，或從其他 PDF 檢視器列印儲存後的副本。 |

## 清單與匯出

| 尚未實作 | 目前可以這樣做 |
|---|---|
| 將匯入的 BCF 問題放到模型中的位置 | 未對應任何圖紙的匯入問題會堆疊在左上角，請手動移動。 |
| 匯入其他標記程式的工具組 | 重建所需工具並儲存到工具箱；再匯出給辦公室使用。 |

## 比較

| 尚未實作 | 目前可以這樣做 |
|---|---|
| 比較以字型排版的文字，或變更清單 | 使用疊合與滑桿，或使用{{ui:變更的線條}}（針對繪製的線條）。 |
| 依線條比較掃描圖紙 | 使用圖片疊合。 |
| 比較整個圖紙集時自動對齊每一組 | 單獨比較有偏移的一組，並使用{{ui:以兩點對齊}}。 |

## 面板

| 尚未實作 | 目前可以這樣做 |
|---|---|
| 移動工具列或狀態列 | 只有兩側面板可以移動。 |

## 平台

- **桌面版：**MarkupCraft 可在 Mac、Windows、Linux 與 iPad 的瀏覽器中執行，也可在 CadCraft Studio（一次安裝八個應用程式的桌面應用程式）中使用。
- MarkupCraft 仍在開發中。標籤與行為可能會變更，本說明也會隨之更新。
