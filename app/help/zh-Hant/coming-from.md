若使用 Bluebeam Revu 審閱圖紙（或在其他桌面 PDF 程式中為 PDF 加上註解），MarkupCraft 大部分功能會很熟悉：雲形框、註解框、工具箱、標記清單、含回覆的狀態、已校正的量測，以及圖紙疊合。檔案處理方式是最大的差異，因此即使略過其餘部分，也請閱讀下一節。

## 最重要的五項差異

1. **儲存會建立新檔案。** MarkupCraft 在瀏覽器中執行，無法覆寫磁碟上的 PDF。{{ui:Save}}會下載「<name> (marked up).pdf」，原始檔案維持不變。下次請開啟「(marked up)」副本，並自行整理舊的副本。
2. **PDF 在儲存時才會寫入。** 在此之前，此瀏覽器中的復原複本會在當機或關閉分頁時保留標記，且 MarkupCraft 下次會提供復原。它只是安全網：請儲存 PDF 以保留審閱內容。
3. **個人檔案存在瀏覽器中。** 作者名稱、工具設定與工具箱都儲存在這台電腦的這個瀏覽器中。其他瀏覽器或電腦會從空白開始，清除網站資料則會刪除它們。請將工具箱匯出作為備份。請見 [此瀏覽器中儲存的內容](topic:browser-storage)。
4. **尚未支援共用工作階段。** 目前沒有即時共用的審閱工作階段，也沒有雲端專案。審閱內容會隨 PDF 傳遞：儲存、寄送副本，下一位審閱者回覆並儲存。
5. **比例以圖紙為單位，且僅限於圖紙。** 圖紙內沒有視埠，也沒有「將此比例套用至所有頁面」的功能。請校正每張要量測的圖紙。

## 逐項對照

| 習慣的做法 | 在 MarkupCraft 中 |
|---|---|
| 縮圖面板、頁面標籤 | 左側為{{ui:Sheets}}。名稱取自頁面標籤，或從標題欄讀取；可用{{ui:Rename sheet}}修正。 |
| 將多個 PDF 開為圖紙集 | 一次全部開啟，會合併為一份清單。不會儲存組合檔案：下次請再開啟相同的 PDF。 |
| 含工具組的工具箱 | {{ui:Tools}}索引標籤：每個瀏覽器有一個工具箱，儲存的工具包含樣式與主旨。可透過{{ui:Export}}與{{ui:Import}}以 JSON 檔案分享。無法匯入其他程式的工具組檔案。 |
| 屬性面板 | {{ui:Properties}}索引標籤：狀態、主旨、註解、樣式、回覆與缺失項目集中在一處。 |
| 含欄位的標記清單 | {{ui:Markups}}索引標籤，可依圖紙、作者、狀態與類型篩選。可匯出 CSV 或 BCF。尚不支援自訂欄位，也尚未提供 PDF 或活頁簿摘要。 |
| 狀態與審閱狀態 | {{ui:Status}}：Open、Accepted、Rejected、Completed。不支援自訂狀態集。會以標準審閱狀態儲存。 |
| 標記上的回覆 | {{ui:Properties}}中的「回覆」回覆串，其中會記錄狀態變更。已送出的回覆無法編輯。 |
| 校正，再量測長度、面積與計數 | {{ui:Calibrate}}、{{ui:Length}}（{{key:M}}）、{{ui:Area}}（{{key:Q}}，可得面積與周長）、{{ui:Count}}（{{key:U}}）。尚不支援角度、半徑、體積、聚合線長度或切除區。 |
| 疊合頁面 | {{ui:Compare}}索引標籤：舊版為紅色、新版為藍色，可依兩點對齊。不支援自動為「比對文件」加雲形框。 |
| 圖章 | {{ui:Stamp}}，內建六款印章，並可自訂文字，會附上簽署者名稱與日期。尚不支援圖片或簽名印章。 |
| 缺失或問題追蹤 | {{ui:Punch list}}索引標籤：含編號項目，包括負責人、到期日與狀態；可匯出 CSV。 |
| 即時協作工作階段 | 尚未實作。請傳送已儲存的 PDF。 |
| 合併 | 尚未實作。標記會保留為其他檢視程式可顯示與列印的註解。 |
| 標記的圖層 | 尚未實作。請使用主旨、作者與清單篩選器來整理註解。 |
| 圖紙之間的超連結 | 尚未實作。 |
| 空白鍵平移、滾輪縮放 | 相同：按住{{key:Space}}並拖曳；滾輪會以指標位置為中心縮放。滾輪不會捲動頁面。 |

## 快速鍵的差異

許多單一字母的按鍵與預期相同，但在手指自動操作之前，請先確認下列按鍵：

- {{key:K}}為{{ui:Callout}}，{{key:Q}}為{{ui:Area}}。若習慣用 Q 建立引註，在這裡會開始量測面積。
- {{key:C}}為方形的{{ui:Cloud}}；{{key:Shift+C}}為{{ui:Free cloud}}。
- {{key:M}}為{{ui:Length}}、{{key:U}}為{{ui:Count}}、{{key:Y}}為{{ui:Polyline}}、{{key:G}}為{{ui:Polygon}}、{{key:I}}為{{ui:Highlight}}。
- {{key:Mod+D}}會建立所選項目的副本（而非瀏覽器的「加入書籤」）。
- {{key:Mod+Plus}}與{{key:Mod+Minus}}會縮放圖紙，而非瀏覽器頁面。
- 任何按鍵都可以變更，請見下方。

:::tip
若已習慣 Bluebeam Revu，請在{{ui:Settings}} › {{ui:MarkupCraft}} › {{ui:Menus, keys and mouse}}中選擇{{ui:PDF review}}功能表樣式：功能表列（檔案、編輯、檢視、文件、標記、量測、視窗）位於一排審閱工具上方，{{key:Q}}為引註、{{key:H}}為螢光筆、{{key:N}}為多邊形，量測功能則搭配{{key:Alt+Shift}}與一個字母。任何按鍵也都可以在該處變更。請見 [功能表、快速鍵與滑鼠](topic:menus-keys-and-mouse)。
:::

完整清單請見 [鍵盤與滑鼠](topic:keyboard)。

## 與預期不同的運作方式

- **工具會保持開啟。** 畫完一個雲形框後，仍會繼續繪製雲形框。按一次{{key:Esc}}會清除選取，按兩次會回到{{ui:Select}}。
- **文字與引註需要有內容。** 若未輸入任何文字就結束，不會新增標記。附註則會保留為空白。
- **量測前需要先設定比例。** 在未校正的圖紙上，{{ui:Length}}與{{ui:Area}}會切換為{{ui:Calibrate}}，完成後再切換回來。
- **其他程式的註解。** 在其他地方建立的矩形、橢圓、直線、聚合線、多邊形、墨跡、文字方塊與便利貼，會成為可編輯的 MarkupCraft 標記，並在儲存時以 MarkupCraft 的方式重新寫入（外觀可能會略有變化）。文字螢光標示、其他程式的印章與其他特殊類型則為唯讀：可回覆，但無法變更。
- **西歐字母以外的字元**在儲存的 PDF 中會以「?」顯示。請見 [儲存已標記的 PDF](topic:save-the-marked-up-pdf)。
- **印章日期**使用 UTC，因此在美洲地區傍晚晚些時候製作的印章，可能會顯示隔天的日期。
- **量測會以標準量測註解的形式保留**，且每張已校正的圖紙都會保留其比例，因此能讀取 PDF 量測的程式通常可以顯示這些量測。實際行為取決於該程式。

## 同時使用兩者

兩者可以來回切換。在其他地方製作的註解可在 MarkupCraft 中開啟，而「(marked up)」PDF 可在其他 PDF 程式中開啟，並顯示所有標記、回覆與狀態。只有 MarkupCraft 會讀回的資料（缺失項目的負責人與到期日、項目狀態），則會保留在檔案中，供 MarkupCraft 使用。
