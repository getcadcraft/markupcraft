以下是 MarkupCraft 0.9 相較於 0.8.1 的變更內容。主要概念是：工作附註不會出現在交給客戶的頁面上，而且整組圖紙可以一次連結完成。

## 新功能

### 附註、貼板與私人附註

- **貼板。** 每張圖紙周圍的區域是一張工作桌：在圖紙旁繪製、輸入或貼上的任何內容都是附註，且絕不會列印。選擇{{ui:Show the pasteboard}}可縮小檢視以騰出空間，或選擇{{ui:Snapshot to the pasteboard}}，拖曳一個方框，再選擇{{ui:To the pasteboard}}，即可在圖紙旁放入部分圖面的圖片。快照是一張圖片，不會隨圖紙變動而改變。請參閱 [附註、貼板與私人附註](topic:notes-and-pasteboard)。
- **顯示與隱藏附註。** 任何標記都可以成為附註：在{{ui:Notes}}索引標籤中設定{{ui:New markups are}}，或在{{ui:Properties}}中設定{{ui:This markup is}}。{{key:Shift+H}}或圖紙下方的{{ui:Notes}}開關，可一次隱藏或顯示所有附註。附註不會列入列印、合併後的副本、清單與匯出中，其他 PDF 閱讀器也不會顯示。儲存的 PDF 會保留附註，供下次在MarkupCraft中開啟時使用。
- **私人附註。** 選擇{{ui:Set a passphrase}}，然後將標記設為{{ui:A private note}}。它會以至少 10 個字元的密碼加密儲存在檔案中，且無法復原：包括我們在內，沒有任何人能在沒有密碼的情況下開啟。{{ui:Lock}}會將私人附註收起來；{{ui:Stay unlocked on this device}}預設為關閉。
- **儲存乾淨副本。** {{ui:Save a clean copy}}會移除所有附註、私人附註以及貼板上的所有內容。請將此功能用於要交給客戶的檔案。

### 連結整組圖紙

- **批次連結。** 選擇{{ui:Pages}} › {{ui:Batch links…}}，或在{{ui:Sheets}}面板中，於{{ui:Find text}}下方選擇{{ui:Link sheet callouts…}}。步驟 1 會列出從每張圖紙標題欄讀取的圖紙編號與名稱；若有錯誤請加以修正。步驟 2 會列出找到的圖紙註解，例如`3/A-501`或`DETAIL 2 ON A-501`。{{ui:Will link}}會顯示每個註解對應的圖紙與檢視，{{ui:Not linked}}會顯示沒有對應已開啟圖紙的編號，{{ui:Create the links}}則會在一次復原步驟中全部建立。在增補或重新編號後可再次執行；手動建立的連結永遠不會被變更。帶有檢視的連結會以 PDF 連結儲存，因此其他閱讀器也能開啟該細部圖。請參閱 [圖紙連結](topic:sheet-links)。

### 繪圖

- **圓弧，十種方法。** {{ui:Arc}}工具（{{key:O}}）現在會在頁面上方顯示{{ui:Arc method}}方框，提供十種繪製圓弧的方法，且角度、長度、半徑與方向都可以點選或輸入。請參閱 [以十種方式繪製圓弧](topic:draw-an-arc)。

### 協同作業

- **跟隨審閱者。** 在即時協作工作階段中，選擇某人姓名旁的{{ui:Follow}}，檢視就會隨其移動；自行平移或縮放即會停止跟隨。主持人可選擇{{ui:Ask everyone to follow me}}。人員清單會顯示每個人的顏色、名稱、所在的圖紙，以及其最後一次編輯的時間。請參閱 [在即時協作中跟隨其他審閱者](topic:follow-in-live)。

## 所有應用程式

- 工具提示改用 Bootstrap 工具提示，起始提示可關閉，索引標籤列溢出時可捲動，瀏覽器分頁標題為 `<document> — MarkupCraft | CadCraft`。
- 含多個區段的面板一次只展開一個並收合其他區段（游標旁的鎖定可讓某一區段保持展開）；設定中的開關可關閉此功能。
- 每個應用程式都從預設的程式庫物件集合開始。
- 單位設定中提供重量與溫度單位。

## 已修正

- **已刪除的標記不再能在儲存的 PDF 中讀取。** 過去儲存時，會將已刪除或改寫的註解從頁面移除，但物件及其文字仍留在檔案中。現在儲存時會刪除這些物件。早期版本儲存的檔案會保留它們，直到再次儲存為止。

## 已知限制

- 批次連結已在我們自己的測試圖紙集上試過。真實圖紙集會以多種方式繪製標示圈，因此在客戶的圖紙集上，部分檢視可能會被遺漏。掃描的圖紙需先執行{{ui:Read text (OCR)…}}。
- 附註、私人附註與貼板是在無頭瀏覽器與我們自己的檔案中測試的，尚未使用大型真實向量圖紙集，也未在真實的兩人即時協作工作階段中測試。變更密碼尚未實作。0.9 之前的版本不會顯示附註。
- 班級檢視即為人員清單；尚未與真實的教師與學生一起測試。
- 英文以外的語言在母語人士審閱前皆為機器草稿。
- Windows 安裝程式未經程式碼簽署（請點選「其他資訊」，再點選「仍要執行」）；macOS 磁碟映像檔未經公證（請按右鍵，然後選擇「開啟」）。

## 較早版本：0.8 與 0.8.1

以下是 MarkupCraft 0.8 與 0.8.1 相較於 0.7 的變更內容。最大的新功能是：標記可以成為由某人或自己的助理執行的工作，並會在圖紙真正變更時自動關閉。

### 新功能

**會自動運作的標記**

- **將標記設為工作。** 選取一或多個標記，開啟{{ui:Tasks}}索引標籤並選擇{{ui:Make selected a task}}。工作包含標題、負責人（某人或已連接的助理）、可選的到期日與狀態，並保留其在圖紙上的位置與回覆串。請參閱 [將標記設為工作](topic:markups-that-act)。
- **會自行關閉的工作。** 工作可以監看其標記內的圖面。開啟圖紙的較新修訂版並選擇{{ui:Check now}}：若該區域的線條變化超過細微的幅度，工作會標記為完成，其標記會變為已完成，且回覆串中的附註會說明變更內容。新的日期標記，或移動少於 1.5 點的線條，都不計入。工作也可以改為監看模型元素：由助理使用`tasks_check`回報該元素，之後若回報的內容不同，或元素已被刪除，工作便會關閉。一次復原步驟即可重新開啟。
- **尋找工作。** 可依狀態及負責對象篩選{{ui:Tasks}}清單，包括{{ui:Overdue}}；選擇{{ui:Assigned to}}，然後選擇{{ui:Assistant}}，即可查看等待助理處理的內容。超過到期日的工作會在問題面板中以警告顯示。{{ui:CSV}}會匯出清單。工作與標記一起儲存在 PDF 中，並像其他標記屬性一樣透過即時協作傳送。

**變更內容，以純列表呈現**

- **列出變更。** 開啟{{ui:Compare}}索引標籤，然後選擇比對整組圖紙，選取較早與較晚的檔案，並選擇{{ui:List the changes}}。清單開頭會列出數量，接著依變更幅度由大到小涵蓋每張有變更的圖紙：位於圖紙上的位置、大小（若圖紙已校正，除了紙上英吋外還會顯示實際單位）、線條是新增還是刪除、該處有多少標記，以及出現或消失的文字。{{ui:Copy the list}}會將清單放到剪貼簿，{{ui:CSV}}則會為每項變更寫入一列。請參閱 [列出修訂版之間的變更](topic:what-changed-in-words)。

**語音附註與決定**

- **語音附註。** 在{{ui:Notes}}索引標籤中選擇{{ui:Record a voice note}}，然後選擇{{ui:Stop recording}}；錄音滿兩分鐘會自動停止。附註會釘在圖紙中央，可拖曳至適當位置，並在{{ui:Properties}}中輸入說明文字；清單中的{{ui:Play}}可播放。錄音會儲存在 PDF 內。
- **決定。** {{ui:Pin a decision}}會在圖紙上寫入一到兩句話。若它取代較早的決定，請在{{ui:It replaces}}中選取該決定：舊決定會保留並標示為已取代，且指向新的決定。一次復原步驟即可撤銷。請參閱 [將語音附註與決定釘在圖紙上](topic:voice-notes-and-decisions)。

**紅線轉修訂版**

- **傳送與回覆。** 在{{ui:Tasks}}索引標籤中開啟{{ui:Redline to revision}}，輸入標記所對照的修訂版，然後選擇{{ui:Export redline file}}。會產生一個`.redline.json`檔案，其中每個未結標記各有一項：圖紙、位置（以圖紙比例表示，因此以另一尺寸重新出圖時仍能對齊）、文字、作者、回覆串與其工作。負責繪製變更的人會在`.redline-answers.json`檔案中回覆已接受、已拒絕或完成；{{ui:Load answers file…}}會為每個標記套用該狀態與繪圖員的附註，並作為一次復原步驟。請參閱 [將標記以紅線傳送給繪圖員](topic:redline-to-revision)。

**AI 助理**

- **更多工具。** 透過 CadCraft Studio 連接的助理可以列出工作（`tasks_list`）、建立或變更工作（`task_set`）、移除工作（`task_clear`）、依較新的修訂版或某個元素檢查工作（`tasks_check`），並讀取兩份已開啟的平面圖紙集之間的純文字變更清單（`revisions_changes`）。助理只能使用在「助理」開關下勾選的工具，且每項變更皆為一次復原步驟。請參閱 [將MarkupCraft與AI助理搭配使用](topic:use-with-ai-assistants)。

### 所有應用程式

- **語言。** CadCraft Studio 現在有 54 種語言。其中 10 種是新增的：立陶宛文、拉脫維亞文、波士尼亞文、馬拉地文、泰盧固文、阿爾巴尼亞文、南非荷蘭文、菲律賓文、史瓦希利文與烏茲別克文。除英文以外的所有語言皆為機器草稿，直到母語人士審閱為止。
- **輸入裝置。** {{ui:Settings}} › {{ui:Global}} › {{ui:Input devices}}可設定觸控板、滑鼠側邊按鍵、觸控筆、手指點按、3D 滑鼠、遊戲控制器或 MIDI 控制器的功能，可套用於所有應用程式，或僅套用於此應用程式。在變更任何設定之前，每個裝置的運作方式都與以往相同。請參閱 [使用觸控板、3D 滑鼠或控制器](common:input-devices)。
- **工具列列數。** {{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}}提供{{ui:Wrap}}（預設）、{{ui:2 rows}}與{{ui:1 row}}，讓圖面有更多空間。請參閱 [安排面板](common:arrange-panels)。
- **屬性格。** 標記的樣式欄位使用共用格線，並具有可收合的類別，以及標籤欄與數值欄。
- **問題面板。** 來自應用程式的警告（例如逾期的工作）會集中在一個問題面板中。
- **即時協作與外掛。** 即時協作工作階段的說明請見 [與他人即時協作](common:work-together-live)；依帳戶而定的外掛清單請見 [外掛與帳戶清單](common:addons-basics)。
- **連接 AI。** CadCraft Studio 是連接自有助理的中心：連接一次，即可用於全部八個應用程式。應用程式本身不包含任何 AI。

### 0.8.1 已修正

- **Studio 可在執行中切換語言。** 過去桌面應用程式與打包版本會維持英文。此功能尚未在所有平台上測試：若語言未變更，請回報。
- 0.8 版的 Studio 安裝可透過{{ui:Settings}} › {{ui:Updates}}取得 0.8.1 更新。

### 尚未包含於此版本

- **未經程式碼簽署。** Windows 安裝程式與 macOS .dmg 尚未簽署。在 Windows 上，若 SmartScreen 阻擋安裝程式，請選擇{{ui:More info}}（其他資訊），然後選擇{{ui:Run anyway}}（仍要執行）。在 Mac 上，請按右鍵 CadCraft Studio 並選擇{{ui:Open}}。Store 版本暫緩中。
- **連接 AI 仍有未完成之處。** 在 Studio 中一鍵連接、供瀏覽器助理使用的託管連接器，以及在 Studio 內使用自有 API 金鑰的功能，皆未承諾包含在此版本中。工作循環已測試，但尚未與真實的助理一起測試。
- **工作檢查需要相同的頁面尺寸。** 以其他尺寸重新出圖的圖紙將無法相符，因此其工作不會關閉。圖紙依圖紙編號配對，若無編號則依頁面位置配對。
- **語音附註僅為錄音。** 沒有逐字稿，助理只會看到附註的長度、作者與說明文字，而聽不到聲音。錄音已在無頭瀏覽器中以假麥克風測試；手機、平板或筆電上的真實麥克風仍待確認。
- **PDF 中的計算表與原因**保存在檔案的私有項目中。較舊的 MarkupCraft 會忽略該項目，並在下次儲存檔案時將其捨棄，因此請使用 0.8 或更新版本開啟並儲存此類檔案。
- **紅線的繪圖員端。** CadCraft 讀取紅線檔案並回覆的功能尚未實作。
- **其他語言。** 泰米爾文的應用程式列溢出 528 px。

其他未實作項目請見 [尚未實作的功能](topic:not-built-yet)。上一個版本請見 [0.7 版新功能](topic:whats-new-0-7)。
