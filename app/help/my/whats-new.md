ဤသည်မှာ MarkupCraft 0.8 နှင့် 0.8.1 တွင် 0.7 နှင့် နှိုင်းယှဉ်လျှင် ပြောင်းလဲသွားသောအရာများ ဖြစ်သည်။ အဓိကအသစ်မှာ မှတ်ချက်တစ်ခုသည် တစ်စုံတစ်ဦး (သို့မဟုတ် သင့်ကိုယ်ပိုင် အကူအညီပေးသူ) လုပ်ဆောင်ရမည့် **လုပ်ငန်း** ဖြစ်လာနိုင်ပြီး ပုံဆွဲတကယ် ပြောင်းလဲသောအခါ ကိုယ်တိုင် ပိတ်သွားသည်ဖြစ်သည်။

## အသစ်

### လုပ်ဆောင်သော မှတ်ချက်များ

- **မှတ်ချက်ကို လုပ်ငန်းတစ်ခု ပြုလုပ်ခြင်း။** မှတ်ချက်တစ်ခု သို့မဟုတ် တစ်ခုထက်ပိုကို ရွေးပြီး {{ui:Tasks}} တဘ်ကို ဖွင့်ကာ {{ui:Make selected a task}} ကို ရွေးပါ။ လုပ်ငန်းတွင် ခေါင်းစဉ်၊ လုပ်ဆောင်ရန် လူတစ်ဦး သို့မဟုတ် ချိတ်ဆက်ထားသော အကူအညီပေးသူ၊ ရွေးချယ်နိုင်သော သတ်မှတ်ရက်နှင့် အခြေအနေ ပါဝင်ပြီး စာရွက်ပေါ်ရှိ နေရာနှင့် ၎င်း၏ ဆွေးနွေးချက်ကို ဆက်ထိန်းထားသည်။ [မှတ်ချက်ကို လုပ်ငန်းအဖြစ် ပြောင်းခြင်း](topic:markups-that-act) ကို ကြည့်ပါ။
- **ကိုယ်တိုင် ပိတ်သွားသော လုပ်ငန်းများ။** လုပ်ငန်းသည် ၎င်း၏ မှတ်ချက်အတွင်းရှိ ပုံဆွဲကို စောင့်ကြည့်နိုင်သည်။ စာရွက်၏ revision အသစ်ကို ဖွင့်ပြီး {{ui:Check now}} ကို ရွေးပါ- ထိုနေရာရှိ မျဉ်းများက ဆံပင်တစ်စစ်ထက် ပိုပြောင်းလဲခဲ့လျှင် လုပ်ငန်းကို ပြီးဆုံးပြီဟု အမှတ်အသားပြုပြီး မှတ်ချက်သည် Completed ဖြစ်လာကာ ဆွေးနွေးချက်ထဲတွင် ဘာပြောင်းလဲသည်ကို မှတ်ချက်ရေးသည်။ ရက်စွဲတံဆိပ်အသစ်၊ သို့မဟုတ် point 1.5 ထက်နည်းစွာ ရွေ့သော မျဉ်းများသည် မရေတွက်ပါ။ လုပ်ငန်းသည် မော်ဒယ် element တစ်ခုကိုလည်း စောင့်ကြည့်နိုင်သည်- အကူအညီပေးသူက `tasks_check` ဖြင့် element ကို အစီရင်ခံပြီး နောက်ပိုင်း ကွဲပြားသော အစီရင်ခံချက် သို့မဟုတ် ဖျက်ထားသော element က လုပ်ငန်းကို ပိတ်သည်။ undo တစ်ဆင့်ဖြင့် ပြန်ဖွင့်နိုင်သည်။
- **အလုပ်ကို ရှာခြင်း။** {{ui:Tasks}} စာရင်းကို အခြေအနေနှင့် ဘယ်သူ့အတွက်ဖြစ်သည်ဖြင့် စစ်ထုတ်ပါ၊ {{ui:Overdue}} ပါဝင်သည်။ {{ui:Assigned to}} ကို ရွေးပြီးနောက် {{ui:Assistant}} ကို ရွေးလျှင် အကူအညီပေးသူအတွက် စောင့်နေသောအရာများကို ကြည့်နိုင်သည်။ သတ်မှတ်ရက်ကျော်လွန်သော လုပ်ငန်းသည် Problems panel တွင် သတိပေးချက်အဖြစ် ပြသည်။ {{ui:CSV}} သည် စာရင်းကို ထုတ်ပေးသည်။ လုပ်ငန်းများကို မှတ်ချက်နှင့်အတူ PDF ထဲတွင် သိမ်းပြီး Live မှတစ်ဆင့် အခြားမှတ်ချက်ဂုဏ်သတ္တိများကဲ့သို့ ရောက်ရှိသည်။

### ပြောင်းလဲချက်များကို ရိုးရိုးစာရင်းအဖြစ်

- **ပြောင်းလဲချက်များကို စာရင်းပြုခြင်း။** {{ui:Compare}} တဘ်ကို ဖွင့်ပြီး {{ui:Compare a whole set}} ကို ရွေးကာ ရှေးဟောင်းနှင့် နောက်ဆုံးဖိုင်များကို ရွေးပြီး {{ui:List the changes}} ကို ရွေးပါ။ စာရင်းသည် အရေအတွက်ဖြင့် စတင်ပြီး ပြောင်းလဲသော စာရွက်တိုင်းကို ပြောင်းလဲမှု အကြီးဆုံးကနေ ပြသသည်- စာရွက်ပေါ်ရှိ နေရာ၊ အရွယ်အစား (စံသတ်မှတ်ထားသော စာရွက်တွင် အမှန်တကယ် ယူနစ်နှင့် ပုံနှိပ်ထားသော လက်မများ)၊ မျဉ်းများ ထည့်ခြင်း/ဖယ်ခြင်း ရှိ/မရှိ၊ ထိုနေရာရှိ မှတ်ချက်အရေအတွက်နှင့် ပေါ်လာ သို့မဟုတ် ပျောက်သွားသော စကားလုံးများ။ {{ui:Copy the list}} က clipboard ထဲ ထည့်ပေးပြီး {{ui:CSV}} က ပြောင်းလဲမှုတစ်ခုလျှင် အတန်းတစ်ခု ရေးသည်။ [revision များကြား ပြောင်းလဲသည်ကို စကားလုံးဖြင့် စာရင်းပြုခြင်း](topic:what-changed-in-words) ကို ကြည့်ပါ။

### အသံမှတ်စုများနှင့် ဆုံးဖြတ်ချက်များ

- **အသံမှတ်စုများ။** {{ui:Notes}} တဘ်တွင် {{ui:Record a voice note}} ကို ရွေးပြီး {{ui:Stop recording}} ကို ရွေးပါ၊ အသံသွင်းခြင်းသည် မိနစ်နှစ်ခုကြာလျှင် အလိုအလျောက် ရပ်သည်။ မှတ်စုသည် စာရွက်အလယ်တွင် ချိတ်ထားပြီး သင်လိုရာသို့ ဆွဲရွှေ့ကာ {{ui:Properties}} တွင် ရုပ်ပုံစာတန်းရိုက်ထည့်နိုင်သည်၊ စာရင်းရှိ {{ui:Play}} က ဖွင့်ပေးသည်။ အသံသွင်းချက်ကို PDF ထဲတွင် သိမ်းသည်။
- **ဆုံးဖြတ်ချက်များ။** {{ui:Pin a decision}} သည် စာရွက်ပေါ်တွင် စာကြောင်း တစ်ကြောင်း သို့မဟုတ် နှစ်ကြောင်း ရေးထားသည်။ ယခင်ဆုံးဖြတ်ချက်ကို အစားထိုးလိုပါက {{ui:It replaces}} တွင် ထိုဆုံးဖြတ်ချက်ကို ရွေးပါ- အဟောင်းသည် ရှိနေဆဲဖြစ်ပြီး Replaced ဟု အမှတ်အသားပြုကာ အသစ်ကို ညွှန်ပြသည်။ undo တစ်ဆင့်ဖြင့် ပြန်ရုပ်သိမ်းနိုင်သည်။ [အသံမှတ်စုများနှင့် ဆုံးဖြတ်ချက်များကို စာရွက်ပေါ် ပင်ထိုးခြင်း](topic:voice-notes-and-decisions) ကို ကြည့်ပါ။

### ပြင်ဆင်ချက်အတွက် ရဲရင့်မှတ်သားချက် (redline)

- **ပို့ပြီး ပြန်ဖြေခြင်း။** {{ui:Tasks}} တဘ်တွင် {{ui:Redline to revision}} ကို ဖွင့်ပါ၊ မှတ်ချက်များ နှိုင်းယှဉ်နေသော revision ကို ရိုက်ထည့်ပြီး {{ui:Export redline file}} ကို ရွေးပါ။ သင်သည် `.redline.json` ဖိုင်ကို ရရှိမည်၊ ဖွင့်ထားသော မှတ်ချက်တစ်ခုလျှင် ပစ္စည်းတစ်ခုပါဝင်သည်- စာရွက်၊ နေရာ (စာရွက်၏ အစိတ်အပိုင်းအဖြစ်၊ ထို့ကြောင့် အခြားအရွယ်အစားဖြင့် ပြန်ထုတ်ပါက လိုက်ညီနေဆဲ)၊ စကားလုံးများ၊ ရေးသူ၊ ဆွေးနွေးချက်နှင့် ၎င်း၏ လုပ်ငန်း။ ပြောင်းလဲမှုများကို ရေးဆွဲသူက `.redline-answers.json` ဖိုင်တွင် Accepted၊ Rejected သို့မဟုတ် Done ဟု ပြန်ဖြေပြီး {{ui:Load answers file…}} က မှတ်ချက်တစ်ခုစီကို ထိုအခြေအနေနှင့် ရေးဆွဲသူ၏ မှတ်စုကို undo တစ်ဆင့်တည်းဖြင့် ပေးသည်။ [မှတ်ချက်များကို ရေးဆွဲသူသို့ redline အဖြစ် ပို့ခြင်း](topic:redline-to-revision) ကို ကြည့်ပါ။

### AI အကူအညီပေးသူများ

- **ကိရိယာ ပိုများလာခြင်း။** CadCraft Studio မှတစ်ဆင့် ချိတ်ဆက်ထားသော အကူအညီပေးသူသည် လုပ်ငန်းများကို စာရင်းပြု (`tasks_list`)၊ တစ်ခု ဖန်တီး သို့မဟုတ် ပြောင်း (`task_set`)၊ လုပ်ငန်းကို ဖယ်ရှား (`task_clear`)၊ revision အသစ် သို့မဟုတ် element တစ်ခုနှင့် စစ်ဆေး (`tasks_check`) နှင့် ဖွင့်ထားသော ပုံဆွဲအစုံနှစ်ခုကြား ပြောင်းလဲချက်များကို ရိုးရိုးစာရင်းအဖြစ် ဖတ် (`revisions_changes`) နိုင်သည်။ Assistants ခလုတ်အောက်တွင် သင်ရွေးထားသော ကိရိယာများကိုသာ ရရှိပြီး ပြောင်းလဲမှုတိုင်းသည် undo တစ်ဆင့်ဖြစ်သည်။ [MarkupCraft ကို AI အကူအညီပေးသူဖြင့် သုံးခြင်း](topic:use-with-ai-assistants) ကို ကြည့်ပါ။

## အက်ပ်အားလုံးတွင်

- **ဘာသာစကားများ။** CadCraft Studio တွင် ယခု ဘာသာစကား 54 ခု ရှိသည်။ အသစ် 10 ခုမှာ လစ်သူယေးနီးယား၊ လတ်ဗီးယား၊ ဘော့စ်နီးယား၊ မာရသီ၊ တဲလူဂူ၊ အယ်လ်ဘေးနီးယား၊ အာဖရီကာန်စ်၊ ဖိလစ်ပိုင်၊ စဝါဟီလီနှင့် ဥဇဘက် တို့ဖြစ်သည်။ အင်္ဂလိပ်မဟုတ်သော ဘာသာစကားအားလုံးသည် မွေးစားသူ မူကြမ်းများဖြစ်ပြီး မူလဘာသာစကား ပိုင်ဆိုင်သူက ဖတ်ပြီးမချင်း ဖြစ်မည်။
- **Input devices။** {{ui:Settings}} › {{ui:Global}} › {{ui:Input devices}} သည် trackpad၊ မောက်စ်၏ ဘေးခလုတ်များ၊ ဘောပင်၊ လက်ထိပ်တို့၊ 3D မောက်စ်၊ game controller သို့မဟုတ် MIDI controller တို့က ဘာလုပ်သည်ကို အက်ပ်တိုင်း သို့မဟုတ် ဤအက်ပ်တစ်ခုတည်းအတွက် သတ်မှတ်သည်။ သင်ပြောင်းမချင်း ကိရိယာအားလုံး အရင်ကလို အလုပ်လုပ်သည်။ [trackpad၊ 3D mouse သို့မဟုတ် controller ကို သုံးခြင်း](common:input-devices) ကို ကြည့်ပါ။
- **ကိရိယာဘား အတန်းများ။** {{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}} တွင် {{ui:Wrap}} (မူလ)၊ {{ui:2 rows}} နှင့် {{ui:1 row}} ရှိပြီး ပုံဆွဲအတွက် နေရာ ပိုရသည်။ [ပန်နယ်များကို စီစဉ်ခြင်း](common:arrange-panels) ကို ကြည့်ပါ။
- **Property grid။** မှတ်ချက်၏ Style အကွက်များသည် မျှဝေထားသော grid ကို သုံးပြီး ခေါင်းစဉ်အုပ်စုများကို ခေါက်ဖွင့်နိုင်ပြီး label နှင့် တန်ဖိုး ကော်လံများ ရှိသည်။
- **Problems panel။** လုပ်ငန်းကျော်လွန်ခြင်းကဲ့သို့ အက်ပ်မှ သတိပေးချက်များကို Problems panel တစ်ခုတည်းတွင် စုဆောင်းသည်။
- **Live နှင့် add-ons။** Live session များကို [အတူတကွ Live ဖြင့် အလုပ်လုပ်ခြင်း](common:work-together-live) တွင် ဖော်ပြထားပြီး သင့်အကောင့်ကို လိုက်သော add-on စာရင်းကို [Add-on များနှင့် သင့်အကောင့်စာရင်း](common:addons-basics) တွင် ကြည့်ပါ။
- **သင့် AI ကို ချိတ်ဆက်ခြင်း။** CadCraft Studio သည် သင့်ကိုယ်ပိုင် အကူအညီပေးသူအတွက် ဗဟိုဖြစ်သည်- တစ်ကြိမ်ချိတ်ဆက်ပါက အက်ပ်ရှစ်ခုလုံးအတွက် သုံးနိုင်သည်။ အက်ပ်များတွင် ကိုယ်ပိုင် AI မပါဝင်ပါ။

## 0.8.1 တွင် ပြင်ဆင်ထားသည်

- **Studio သည် လည်ပတ်နေစဉ် ဘာသာစကား ပြောင်းနိုင်ပြီ။** ယခင်က desktop အက်ပ်နှင့် ထုပ်ပိုးထားသော ဗားရှင်းများသည် အင်္ဂလိပ်တွင်သာ ကျန်ခဲ့သည်။ ၎င်းကို ပလက်ဖောင်းအားလုံးတွင် မစမ်းသပ်ရသေးပါ၊ ဘာသာစကား မပြောင်းပါက ကျွန်ုပ်တို့ကို အသိပေးပါ။
- Studio 0.8 ထည့်သွင်းသူများသည် {{ui:Settings}} › {{ui:Updates}} မှတစ်ဆင့် 0.8.1 ကို ရရှိမည်။

## ဤဗားရှင်းတွင် မပါသေးသည်များ

- **Code-signed မဟုတ်ပါ။** Windows installer များနှင့် macOS .dmg တွင် signature မပါသေးပါ။ Windows တွင် SmartScreen က installer ကို တားဆီးပါက {{ui:More info}} ကို ရွေးပြီး {{ui:Run anyway}} ကို ရွေးပါ။ Mac တွင် CadCraft Studio ကို right-click နှိပ်ပြီး {{ui:Open}} ကို ရွေးပါ။ Store ဗားရှင်းများကို ရပ်ထားသည်။
- **AI ချိတ်ဆက်ခြင်းမှာ အချို့နေရာတွင် မပြည့်စုံသေးပါ။** Studio အတွင်း တစ်ချက်နှိပ်ချိတ်ဆက်ခြင်း၊ ဘရောက်ဆာ အကူအညီပေးသူများအတွက် hosted connector နှင့် Studio အတွင်း သင့်ကိုယ်ပိုင် API key တို့ကို ဤဗားရှင်းအတွက် ကတိမပေးပါ။ လုပ်ငန်းစက်ဝန်းကို စမ်းသပ်ပြီးပါပြီ၊ သို့သော် အမှန်တကယ် အကူအညီပေးသူဖြင့် မစမ်းသပ်ရသေးပါ။
- **လုပ်ငန်းစစ်ဆေးမှုများသည် စာမျက်နှာအရွယ်အစား တူရန်လိုသည်။** အခြားအရွယ်အစားဖြင့် ပြန်ထုတ်ထားသော စာရွက်သည် မကိုက်ညီသဖြင့် ၎င်း၏လုပ်ငန်းများ မပိတ်ပါ။ စာရွက်များကို စာရွက်နံပါတ်ဖြင့်၊ သို့မဟုတ် မရပါက စာမျက်နှာနေရာအလိုက် တွဲပေးသည်။
- **အသံမှတ်စုများသည် အသံသွင်းချက်သာ ဖြစ်သည်။** စာသားမှတ်တမ်း မရှိပါ၊ အကူအညီပေးသူသည် မှတ်စု၏ ကြာချိန်၊ ရေးသူနှင့် ရုပ်ပုံစာတန်းကို မြင်ရသည်၊ အသံကို မကြားရပါ။ အသံသွင်းခြင်းကို headless ဘရောက်ဆာတွင် အတုမိုက်ခရိုဖုန်းဖြင့် စမ်းသပ်ခဲ့သည်။ အမှန်တကယ် ဖုန်း၊ tablet သို့မဟုတ် laptop မိုက်ခရိုဖုန်းဖြင့် ကျန်ရှိသေးသည်။
- **PDF ထဲရှိ Calc စာရွက်များနှင့် အကြောင်းရင်းများ** ကို ဖိုင်၏ သီးသန့်အချက်အလက်ထဲတွင် သိမ်းသည်။ ဟောင်းသော MarkupCraft သည် ထို entry ကို လျစ်လျူရှုပြီး နောက်တစ်ကြိမ် သိမ်းသည့်အခါ ဖျက်လိုက်သည်၊ ထို့ကြောင့် ထိုဖိုင်ကို 0.8 သို့မဟုတ် နောက်ပိုင်းဖြင့် ဖွင့်ပြီး သိမ်းပါ။
- **ရေးဆွဲသူဘက်မှ redline များ။** CadCraft သည် redline ဖိုင်ကို ဖတ်ပြီး ပြန်ဖြေခြင်းကို မတည်ဆောက်ရသေးပါ။
- **အခြားဘာသာစကားများ။** တမီးလ်၏ အက်ပ်ဘားသည် 528 px ကျော်လွန်နေသည်။
