ဤသည်မှာ MarkupCraft 0.8.1 နှင့် နှိုင်းယှဉ်လျှင် 0.9 တွင် ပြောင်းလဲခဲ့သည့်အရာများ ဖြစ်သည်။ အဓိကအယူအဆမှာ သင့်အလုပ်မှတ်စုများသည် ဖောက်သည်ရရှိသော စာမျက်နှာပေါ်တွင် မပါဝင်ရန်ဖြစ်ပြီး ဖိုင်တစ်ခုလုံးကို တစ်ကြိမ်တည်းဖြင့် လင့်ခ်ချိတ်နိုင်ခြင်း ဖြစ်သည်။

## အသစ်

### မှတ်စုများ၊ pasteboard နှင့် ကိုယ်ပိုင်မှတ်စုများ

- **Pasteboard။** စာရွက်တစ်ရွက်စီ၏ ပတ်လည်ဧရိယာသည် စားပွဲတစ်ခုဖြစ်သည်- စာရွက်ဘေးတွင် ဆွဲထားသော၊ ရိုက်ထားသော သို့မဟုတ် ကူးထည့်ထားသည့် မည်သည့်အရာမဆို မှတ်စုဖြစ်ပြီး ဘယ်တော့မှ ပုံနှိပ်မထွက်ပါ။ နေရာအတွက် ချဲ့ရန် {{ui:Show the pasteboard}} ကို ရွေးပါ၊ သို့မဟုတ် {{ui:Snapshot to the pasteboard}} ကို ရွေးပြီး ဘောက်စ်ကို ဆွဲကာ {{ui:To the pasteboard}} ကို ရွေး၍ ပုံဆွဲချက်အစိတ်အပိုင်း၏ ပုံကို စာရွက်ဘေးတွင် ထားပါ။ Snapshot သည် ပုံတစ်ပုံဖြစ်ပြီး စာရွက် ပြောင်းသော်လည်း မပြောင်းပါ။ [မှတ်စုများ၊ pasteboard နှင့် ကိုယ်ပိုင်မှတ်စုများ](topic:notes-and-pasteboard) ကို ကြည့်ပါ။
- **မှတ်စုများ ပြရန်နှင့် ဖျောက်ရန်။** မည်သည့် markup မဆို မှတ်စုဖြစ်နိုင်သည်- {{ui:Notes}} တဘ်ရှိ {{ui:New markups are}} ကို သတ်မှတ်ပါ၊ သို့မဟုတ် {{ui:Properties}} ရှိ {{ui:This markup is}} ကို သတ်မှတ်ပါ။ {{key:Shift+H}} သို့မဟုတ် စာရွက်အောက်ရှိ {{ui:Notes}} ခလုတ်သည် မှတ်စုအားလုံးကို တစ်ပြိုင်နက် ဖျောက်ပြီး ပြသည်။ မှတ်စုများကို ပုံနှိပ်ခြင်း၊ ပြားချထားသော မိတ္တူများ၊ စာရင်းများနှင့် ထုတ်ယူမှုများမှ ချန်ထားပြီး၊ အခြား PDF ဖတ်ခုနှင့်များက မပြပါ။ သင်၏ သိမ်းထားသော PDF က MarkupCraft ဖြင့် နောက်တစ်ကြိမ် ဖွင့်သည့်အခါအတွက် ၎င်းတို့ကို ထိန်းထားသည်။
- **ကိုယ်ပိုင်မှတ်စုများ။** {{ui:Set a passphrase}} ကို ရွေးပြီး markup တစ်ခုကို {{ui:A private note}} ဖြစ်အောင် ပြုလုပ်ပါ။ ၎င်းကို အက္ခရာ ၁၀ လုံးနှင့်အထက် passphrase ဖြင့် ဖိုင်အတွင်း ကုဒ်ဝှက်သည်၊ ပြန်ရယူနိုင်မှု မရှိပါ- ကျွန်ုပ်တို့အပါအဝင် ဘယ်သူမှ passphrase မရှိဘဲ ဖွင့်၍ မရပါ။ {{ui:Lock}} က ကိုယ်ပိုင်မှတ်စုများကို ဖယ်ထားသည်၊ {{ui:Stay unlocked on this device}} သည် မူလအားဖြင့် ပိတ်ထားသည်။
- **သန့်စင်သောမိတ္တူ သိမ်းခြင်း။** {{ui:Save a clean copy}} သည် မှတ်စု၊ ကိုယ်ပိုင်မှတ်စု နှင့် pasteboard ပေါ်ရှိ အရာအားလုံးကို ဖယ်ရှားသည်။ ဖောက်သည်ထံ သွားမည့် ဖိုင်အတွက် အသုံးပြုပါ။

### စာရွက်အစုတစ်ခုလုံးကို လင့်ခ်ချိတ်ခြင်း

- **အစုလိုက်လင့်ခ်များ။** {{ui:Pages}} › {{ui:Batch links…}} ကို ရွေးပါ၊ သို့မဟုတ် {{ui:Sheets}} အကန့်ရှိ {{ui:Find text}} အောက်ရှိ {{ui:Link sheet callouts…}} ကို ရွေးပါ။ အဆင့် ၁ တွင် စာရွက်တစ်ရွက်စီ၏ နံပါတ်နှင့် အမည်ကို title block မှ ဖတ်ထားသည့်အတိုင်း ပြသည်၊ မှားနေသည်များကို ပြင်ပါ။ အဆင့် ၂ တွင် တွေ့ရှိသော callout များကို ပြသည်၊ ဥပမာ `3/A-501` သို့မဟုတ် `DETAIL 2 ON A-501`။ {{ui:Will link}} က စာရွက်နှင့် view ကို တစ်ခုချင်းစီအတွက် ပြသည်၊ {{ui:Not linked}} က ဖွင့်ထားသော စာရွက်တစ်ခုမှ မရှိသော နံပါတ်များကို ပြသည်၊ {{ui:Create the links}} က အားလုံးကို undo တစ်ဆင့်တည်းဖြင့် ဖန်တီးသည်။ addendum သို့မဟုတ် နံပါတ်ပြန်ပေးပြီးနောက် ပြန်လုပ်ပါ၊ လက်ဖြင့် ပြုလုပ်ထားသော လင့်ခ်များကို ဘယ်တော့မှ မပြောင်းပါ။ view ပါသော လင့်ခ်ကို PDF link အဖြစ် သိမ်းသဖြင့် အခြားဖတ်ခုနှင့်များက detail ကိုပါ ဖွင့်နိုင်သည်။ [စာရွက်လင့်ခ်များ](topic:sheet-links) ကို ကြည့်ပါ။

### ပုံဆွဲခြင်း

- **Arc၊ နည်းလမ်းဆယ်ခု။** {{ui:Arc}} tool ({{key:O}}) တွင် ယခု စာမျက်နှာပေါ်တွင် {{ui:Arc method}} ဘောက်စ်ရှိပြီး arc ဆွဲရန် နည်းလမ်းဆယ်ခုရှိသည်၊ ထောင့်၊ အလျား၊ radius နှင့် ဦးတည်ချက်တို့ကို နှိပ်၍ သို့မဟုတ် ရိုက်၍ ထည့်နိုင်သည်။ [arc ကို နည်းလမ်းဆယ်ခုဖြင့် ဆွဲခြင်း](topic:draw-an-arc) ကို ကြည့်ပါ။

### အတူတကွ လုပ်ဆောင်ခြင်း

- **သုံးသပ်သူကို လိုက်ခြင်း။** Live session တွင် ပုဂ္ဂိုလ်တစ်ဦး၏ အမည်ဘေးရှိ {{ui:Follow}} ကို ရွေးပါ၊ သင်၏ view သည် သူတို့နှင့်အတူ ရွှေ့သွားမည်၊ သင်ကိုယ်တိုင် pan သို့မဟုတ် zoom လုပ်လျှင် ရပ်သွားသည်။ Host က {{ui:Ask everyone to follow me}} ကို ရွေးနိုင်သည်။ လူစာရင်းတွင် လူတစ်ဦးစီ၏ အရောင်၊ အမည်၊ ၎င်းရှိနေသော စာရွက်နှင့် နောက်ဆုံး ပြင်ဆင်ခဲ့သည့်အချိန်ကို ပြသည်။ [Live session တွင် အခြားသုံးသပ်သူကို လိုက်ခြင်း](topic:follow-in-live) ကို ကြည့်ပါ။

## အက်ပ်အားလုံးတွင်

- Tooltip များသည် Bootstrap tooltip များဖြစ်ပြီး၊ start tip ကို ပိတ်နိုင်သည်၊ tab strip များသည် ပြည့်သွားလျှင် scroll လုပ်သည်၊ browser tab ခေါင်းစဉ်များသည် `<document> — MarkupCraft | CadCraft` ဖတ်ရသည်။
- ပြသည်များပါသော အကန့်တစ်ခုသည် တစ်ခုကို ဖွင့်ပြီး အခြားများကို ပိတ်သည် (caret ဘေးရှိ lock က တစ်ခုကို ဖွင့်ထားသည်)၊ Settings ရှိ ခလုတ်တစ်ခုက ၎င်းကို ပိတ်နိုင်သည်။
- အက်ပ်တစ်ခုစီသည် Library object များ၏ မူလစုစည်းမှုဖြင့် စတင်သည်။
- အလေးချိန်နှင့် အပူချိန် ယူနစ်များကို Units ဆက်တင်များတွင် ရရှိနိုင်သည်။

## ပြင်ဆင်ပြီး

- **ဖိုင်ပြင်ဆင်ပြီး။** PDF ကို ဖျက်ထားသော markup သည် သိမ်းထားသော PDF အတွင်း မဖတ်နိုင်တော့ပါ။ ယခင်က သိမ်းသည့်အခါ ဖျက်ထားသော သို့မဟုတ် ပြန်ရေးထားသော annotation ကို စာမျက်နှာမှ ဖယ်ထုတ်သော်လည်း စာသားပါသော object ကို ဖိုင်တွင် ထားခဲ့သည်။ ယခု သိမ်းသည့်အခါ ထို object များကို ဖျက်သည်။ 0.9 မတိုင်မီ build များဖြင့် သိမ်းထားသော ဖိုင်များတွင် ၎င်းတို့ကို နောက်တစ်ကြိမ် သိမ်းမချင်း ရှိနေဆဲ ဖြစ်သည်။

## ရိုးရိုးသားသား ကန့်သတ်ချက်များ

- အစုလိုက်လင့်ခ်များကို ကျွန်ုပ်တို့၏ကိုယ်ပိုင် စမ်းသပ်စာရွက်အစုများပေါ်တွင်သာ စမ်းခဲ့သည်။ အမှန်တကယ် စာရွက်များသည် ဘူးဘဲလ်များကို နည်းမျိုးစုံဖြင့် ဆွဲသဖြင့် ဖောက်သည်စာရွက်များတွင် အချို့ view များ လွတ်သွားနိုင်သည်။ စကင်စာရွက်များအတွက် {{ui:Read text (OCR)…}} ကို အရင်လုပ်ရမည်။
- မှတ်စုများ၊ ကိုယ်ပိုင်မှတ်စုများနှင့် pasteboard ကို headless browser နှင့် ကိုယ်ပိုင်ဖိုင်များတွင် စမ်းခဲ့သည်၊ ကြီးမားသော အမှန်တကယ် vector စာရွက်အစုတွင် မဟုတ်ပါ၊ အမှန်တကယ် လူနှစ်ဦး Live session တွင်လည်း မဟုတ်ပါ။ Passphrase ပြောင်းခြင်းကို မတည်ဆောက်ရသေးပါ။ 0.9 မတိုင်မီ build များသည် မှတ်စုများကို မပြပါ။
- Class view သည် လူစာရင်းဖြစ်ပြီး အမှန်တကယ် ဆရာနှင့် ကျောင်းသားများဖြင့် မစမ်းရသေးပါ။
- အင်္ဂလိပ်မဟုတ်သော ဘာသာစကားများသည် မိခင်ဘာသာစကား ပိုင်ရှင်က မဖတ်မချင်း စက်မူကြမ်းများဖြစ်သည်။
- Windows installer များကို code-sign မလုပ်ထားပါ (More info၊ ထို့နောက် Run anyway)၊ macOS disk image ကို notarize မလုပ်ထားပါ (right-click၊ ထို့နောက် Open)။

## ယခင်- 0.8 နှင့် 0.8.1

ဤသည်မှာ 0.7 နှင့် နှိုင်းယှဉ်လျှင် MarkupCraft 0.8 နှင့် 0.8.1 တွင် ပြောင်းလဲခဲ့သည့်အရာများ ဖြစ်သည်။ အဓိကအသစ်အရာမှာ markup တစ်ခုသည် တစ်စုံတစ်ဦး၊ သို့မဟုတ် သင်၏ကိုယ်ပိုင်အကူအညီပေးသူက လုပ်ဆောင်သော လုပ်ငန်းတစ်ခု ဖြစ်နိုင်ပြီး ပုံဆွဲချက်အမှန်တကယ် ပြောင်းလဲသည့်အခါ ကိုယ်တိုင် ပိတ်သွားခြင်း ဖြစ်သည်။

### အသစ်

**Markup များ လုပ်ဆောင်သည်**

- **Markup ကို လုပ်ငန်းအဖြစ် ပြုလုပ်ခြင်း။** Markup တစ်ခု သို့မဟုတ် တစ်ခုထက်ပိုကို ရွေး၍ {{ui:Tasks}} တဘ်ကို ဖွင့်ပြီး {{ui:Make selected a task}} ကို ရွေးပါ။ လုပ်ငန်းတွင် ခေါင်းစဉ်၊ လုပ်ဆောင်ရန် လူတစ်ဦး သို့မဟုတ် သင်ချိတ်ဆက်ထားသော အကူအညီပေးသူ၊ ရွေးချယ်နိုင်သော ကြောင့်ကြမှုနေ့နှင့် အခြေအနေ ရှိပြီး စာရွက်ပေါ်ရှိ နေရာနှင့် ၎င်း၏ thread ကို ထိန်းထားသည်။ [Markup ကို လုပ်ငန်းအဖြစ် ပြုလုပ်ခြင်း](topic:markups-that-act) ကို ကြည့်ပါ။
- **ကိုယ်တိုင် ပိတ်သွားသော လုပ်ငန်းများ။** လုပ်ငန်းတစ်ခုသည် ၎င်း၏ markup အတွင်းရှိ ပုံဆွဲချက်ကို စောင့်ကြည့်နိုင်သည်။ စာရွက်၏ ပြင်ဆင်ထားသော ပုံအသစ်ကို ဖွင့်ပြီး {{ui:Check now}} ကို ရွေးပါ- ထိုနေရာရှိ မျဉ်းများ အနည်းဆုံး ဆံပင်တစ်ချောင်းထက် ပြောင်းလဲသွားလျှင် လုပ်ငန်းကို Done ဟု အမှတ်အသားပြုပြီး markup ၏ အခြေအနေ Completed ဖြစ်သည်၊ thread ရှိ မှတ်စုက ဘာပြောင်းခဲ့သည်ကို ပြောသည်။ ရက်စွဲတံဆိပ်အသစ် သို့မဟုတ် အမှတ် ၁.၅ ထက်နည်းစွာ ရွှေ့သွားသော မျဉ်းများကို မရေတွက်ပါ။ လုပ်ငန်းတစ်ခုသည် မော်ဒယ် element တစ်ခုကို စောင့်ကြည့်နိုင်ပြီး၊ အကူအညီပေးသူက `tasks_check` ဖြင့် element ကို တင်ပြသည်၊ နောက်ပိုင်း ကွဲပြားသော အစီရင်ခံချက် သို့မဟုတ် ဖျက်ထားသော element တစ်ခုက လုပ်ငန်းကို ပိတ်သည်။ Undo တစ်ဆင့်ဖြင့် ပြန်ဖွင့်နိုင်သည်။
- **အလုပ်ကို ရှာခြင်း။** {{ui:Tasks}} စာရင်းကို အခြေအနေနှင့် မည်သူအတွက်ဖြစ်သည်ဖြင့် စစ်ထုတ်နိုင်ပြီး {{ui:Overdue}} ပါဝင်သည်; {{ui:Assigned to}} ကို ရွေးပြီး {{ui:Assistant}} ကို ရွေးလျှင် သင့်အကူအညီပေးသူ စောင့်နေသည်များကို ပြသည်။ ကြောင့်ကြမှုနေ့ကျော်လွန်သော လုပ်ငန်းသည် Problems အကန့်တွင် သတိပေးချက်အဖြစ် ပြသည်။ {{ui:CSV}} က စာရင်းကို ထုတ်သည်။ လုပ်ငန်းများကို markup နှင့်အတူ PDF တွင် သိမ်းပြီး Live မှတဆင့် အခြား markup ဂုဏ်သတ္တိများကဲ့သို့ ပို့သည်။

**ပြောင်းလဲမှုများကို ရိုးရှင်းသော စာရင်းအဖြစ်**

- **ပြောင်းလဲချက်များကို စာရင်းပြုစုခြင်း။** {{ui:Compare}} တဘ်ကို ဖွင့်ပြီး {{ui:Compare a whole set}} ကို ရွေးပါ၊ အစောပိုင်းနှင့် နောက်ပိုင်း ဖိုင်များကို ရွေးပြီး {{ui:List the changes}} ကို ရွေးပါ။ စာရင်းသည် အရေအတွက်ဖြင့် စတင်ပြီး ပြောင်းလဲသွားသော စာရွက်တစ်ရွက်စီကို အကြီးဆုံးမှစ၍ ဖော်ပြသည်- စာရွက်ပေါ် နေရာ၊ အရွယ်အစား (စကေးချိန်ညှိထားသော စာရွက်တွင် ယူနစ်အစစ်အမှန်နှင့် စာရွက် inch များ နှစ်မျိုးလုံး)၊ မျဉ်းများ ထည့်ခဲ့ခြင်း သို့မဟုတ် ဖယ်ခဲ့ခြင်း၊ ထိုနေရာရှိ markup အရေအတွက်နှင့် ပေါ်လာခဲ့သည် သို့မဟုတ် ပျောက်သွားသည့် စာလုံးများ။ {{ui:Copy the list}} က clipboard သို့ ထည့်ပေးပြီး {{ui:CSV}} က ပြောင်းလဲမှုတစ်ခုစီအတွက် အတန်းတစ်တန်းရေးသည်။ [ပြင်ဆင်မှုများကြား ပြောင်းလဲချက်များကို စာရင်းပြုစုရန်](topic:what-changed-in-words) ကို ကြည့်ပါ။

**အသံမှတ်စုများနှင့် ဆုံးဖြတ်ချက်များ**

- **အသံမှတ်စုများ။** {{ui:Notes}} တဘ်တွင် {{ui:Record a voice note}} ကို ရွေးပြီး {{ui:Stop recording}} ကို ရွေးပါ၊ အသံသွင်းခြင်းသည် မိနစ် ၂ ပြည့်လျှင် အလိုအလျောက် ရပ်သည်။ မှတ်စုကို စာရွက်၏ အလယ်တွင် pin ထားပြီး၊ သင်ကြိုက်ရာသို့ ဆွဲရွှေ့ပြီး {{ui:Properties}} တွင် ခေါင်းစဉ်စာသား ရိုက်ထည့်ပါ၊ စာရင်းရှိ {{ui:Play}} က ဖွင့်ပေးသည်။ အသံသွင်းချက်ကို PDF အတွင်း သိမ်းသည်။
- **ဆုံးဖြတ်ချက်များ။** {{ui:Pin a decision}} က စာရွက်ပေါ်တွင် စာကြောင်း တစ်ကြောင်း ဝေါ်လေး ထား၏။ ယခင်ဆုံးဖြတ်ချက်ကို အစားထိုးလိုလျှင် {{ui:It replaces}} တွင် ထိုတစ်ခုကို ရွေးပါ၊ ဟောင်းသည် Replaced ဟု အမှတ်အသားပြုပြီး အသစ်ကို ညွှန်ပြသည်။ Undo တစ်ဆင့်ဖြင့် ပြန်ဖျက်နိုင်သည်။ [အသံမှတ်စုများနှင့် ဆုံးဖြတ်ချက်များကို စာရွက်ပေါ်တွင် ပင်ထိုးခြင်း](topic:voice-notes-and-decisions) ကို ကြည့်ပါ။

**Redline မှ ပြင်ဆင်ချက်သို့**

- **ပို့ခြင်းနှင့် ဖြေကြားခြင်း။** {{ui:Tasks}} တဘ်တွင် {{ui:Redline to revision}} ကို ဖွင့်ပြီး markup များ နှိုင်းယှဉ်နေသော ပြင်ဆင်ချက်ကို ရိုက်ထည့်ပြီး {{ui:Export redline file}} ကို ရွေးပါ။ `.redline.json` ဖိုင်တစ်ခုရရှိမည်၊ ဖွင့်ထားသော markup တစ်ခုစီအတွက် အရာတစ်ခု- စာရွက်၊ နေရာ (စာရွက်၏ အပိုင်းအစများအဖြစ်၊ ထို့ကြောင့် အခြားအရွယ်တွင် ပြန် plot လုပ်လျှင်လည်း ကိုက်ညီသည်)၊ စာသား၊ စာရေးသူ၊ thread နှင့် ၎င်း၏ လုပ်ငန်း။ ပြောင်းလဲချက်များကို ဆွဲသူက `.redline-answers.json` ဖိုင်တွင် Accepted၊ Rejected သို့မဟုတ် Done ဟု ဖြေကြားသည်၊ {{ui:Load answers file…}} က markup တစ်ခုစီကို ထိုအခြေအနေနှင့် drafter ၏ မှတ်စုကို undo တစ်ဆင့်အဖြစ် ပေးသည်။ [Redline အဖြစ် markup များကို drafter ထံ ပို့ခြင်း](topic:redline-to-revision) ကို ကြည့်ပါ။

**AI အကူအညီပေးသူများ**

- **ကိရိယာ ပိုများသည်။** CadCraft Studio မှတဆင့် ချိတ်ဆက်ထားသော အကူအညီပေးသူသည် လုပ်ငန်းများကို စာရင်းပြုစုနိုင် (`tasks_list`)၊ လုပ်ငန်းတစ်ခုကို ဖန်တီးခြင်း သို့မဟုတ် ပြောင်းလဲခြင်း (`task_set`)၊ လုပ်ငန်းကို ဖယ်ရှားခြင်း (`task_clear`)၊ ပြင်ဆင်ချက်အသစ် သို့မဟုတ် element တစ်ခုနှင့် စစ်ဆေးခြင်း (`tasks_check`) နှင့် ဖိုင်ဖွင့်ထားသော ပုံဆွဲစာရွက်အစုနှစ်ခုကြား ပြောင်းလဲချက်များ၏ ရိုးရှင်းသော စာရင်းကို ဖတ်နိုင် (`revisions_changes`)။ Assistants ခလုတ်အောက်တွင် သင်ရွေးချယ်ထားသော tools များကိုသာ ရရှိပြီး ပြောင်းလဲမှုတိုင်းသည် undo တစ်ဆင့်ဖြစ်သည်။ [MarkupCraft ကို AI အကူအညီပေးသူဖြင့် အသုံးပြုခြင်း](topic:use-with-ai-assistants) ကို ကြည့်ပါ။

### အက်ပ်အားလုံးတွင်

- **ဘာသာစကားများ။** CadCraft Studio တွင် ယခု ဘာသာစကား ၅၄ ခု ရှိသည်။ အသစ် ၁၀ ခု- Lithuanian၊ Latvian၊ Bosnian၊ Marathi၊ Telugu၊ Albanian၊ Afrikaans၊ Filipino၊ Swahili နှင့် Uzbek။ အင်္ဂလိပ်မဟုတ်သော ဘာသာစကားအားလုံးသည် မိခင်ဘာသာစကား ပိုင်ရှင် မဖတ်မချင်း စက်မူကြမ်းများဖြစ်သည်။
- **Input devices။** {{ui:Settings}} › {{ui:Global}} › {{ui:Input devices}} က trackpad၊ မောက်စ်၏ ဘေးခလုတ်များ၊ ဘောပင်၊ လက်ထိပ်တို့၊ 3D မောက်စ်၊ game controller သို့မဟုတ် MIDI controller တို့ ဘာလုပ်သည်ကို အက်ပ်တိုင်း သို့မဟုတ် ဤအက်ပ်တစ်ခုတည်းအတွက် သတ်မှတ်သည်။ သင်မပြောင်းမချင်း စက်ပစ္စည်းတိုင်း ယခင်ကအတိုင်း အလုပ်လုပ်သည်။ [trackpad၊ 3D မောက်စ် သို့မဟုတ် controller ကို သုံးခြင်း](common:input-devices) ကို ကြည့်ပါ။
- **Toolbar အတန်းများ။** {{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}} တွင် {{ui:Wrap}} (မူလ)၊ {{ui:2 rows}} နှင့် {{ui:1 row}} ရှိသဖြင့် ပုံဆွဲချက်အတွက် နေရာ ပိုရသည်။ [အကန့်များကို စီစဉ်ခြင်း](common:arrange-panels) ကို ကြည့်ပါ။
- **Property grid။** Markup ၏ Style အကွက်များသည် မျှဝေထားသော grid ကို အသုံးပြုပြီး ခေါက်သိမ်းနိုင်သော အမျိုးအစားများနှင့် label နှင့် တန်ဖိုး ကော်လံများ ပါဝင်သည်။

- **Live နှင့် add-ons။** Live session များကို [အတူတကွ Live လုပ်ဆောင်ခြင်း](common:work-together-live) တွင် ရှင်းပြထားသည်၊ သင့်အကောင့်နှင့် လိုက်သော add-on စာရင်းကို [Add-ons နှင့် သင့်အကောင့်စာရင်း](common:addons-basics) တွင် ရှင်းပြထားသည်။

### ဤဗားရှင်းတွင် မပါသေးသည့်အရာများ

- **Code-sign မလုပ်ထားပါ။** Windows installer များနှင့် macOS .dmg တွင် လက်မှတ် မရှိသေးပါ။ Windows တွင် SmartScreen က installer ကို ရပ်ပါက {{ui:More info}} ကို ရွေးပြီး ထို့နောက် {{ui:Run anyway}} ကို ရွေးပါ။ Mac တွင် CadCraft Studio ကို right-click လုပ်ပြီး {{ui:Open}} ကို ရွေးပါ။ Store build များ ရပ်ထားသည်။
- **AI ချိတ်ဆက်မှုသည် အချို့နေရာတွင် မပြီးသေးပါ။** Studio အတွင်း တစ်ချက်နှိပ်ချိတ်ဆက်ခြင်း၊ browser အကူအညီပေးသူများအတွက် hosted connector နှင့် Studio အတွင်း သင့်ကိုယ်ပိုင် API key တို့ကို ဤဗားရှင်းအတွက် ကတိမပေးပါ။ လုပ်ငန်းစက်ဝန်းကို စမ်းပြီးပါပြီ၊ သို့သော် အမှန်တကယ် အကူအညီပေးသူဖြင့် မစမ်းရသေးပါ။
- **လုပ်ငန်းစစ်ဆေးမှုများသည် စာမျက်နှာအရွယ်အစား တူညီရန် လိုသည်။** အခြားအရွယ်တွင် ပြန် plot လုပ်ထားသော စာရွက်သည် မကိုက်ညီဘဲ ၎င်း၏ လုပ်ငန်းများ ပိတ်မသွားပါ။ စာရွက်များကို စာရွက်နံပါတ်ဖြင့် တွဲစပ်သည်၊ မရှိလျှင် စာမျက်နှာနေရာဖြင့်။
- **အသံမှတ်စုများသည် အသံသွင်းချက်သာ ဖြစ်သည်။** စာသားမှတ်တမ်း မရှိပါ၊ အကူအညီပေးသူက မှတ်စု၏ အရှည်၊ စာရေးသူနှင့် ခေါင်းစဉ်ကိုသာ မြင်ပြီး အသံကို မကြားပါ။ အသံသွင်းခြင်းကို headless browser တွင် အတုမိုက်ခရိုဖုန်းဖြင့် စမ်းခဲ့သည်၊ ဖုန်း၊ တက်ဘလက် သို့မဟုတ် laptop ပေါ်ရှိ အမှန်တကယ် မိုက်ခရိုဖုန်းဖြင့် ဆက်စစ်ရန်ရှိသေးသည်။
