MarkupCraft သည် ဘရောက်ဆာ ဝင်းဒိုးကို ဖြည့်ထားသည်။ အပေါ်မှအောက်၊ ဘယ်မှညာသို့-

## အပေါ်ဆုံးဘား

အပေါ်ဆုံးရှိ ပါးလွှာသော ဘားသည် MarkupCraft ကိုယ်တိုင်မဟုတ်ဘဲ CadCraft မိသားစုနှင့် ပိုင်သည်။ ၎င်းတွင်-

- အက်ပ်အမည်နှင့် သင်လည်ပတ်နေသော ဗားရှင်း၊
- {{ui:About MarkupCraft}}၊ အက်ပ်၏ ဝက်ဘ်စာမျက်နှာကို ဖွင့်သည်၊
- {{ui:Help}}၊ ဤအကူအညီကို ဘေးဘက်ပန်နယ်တွင် ဖွင့်သည် (သို့မဟုတ် {{key:F1}} ကို နှိပ်ပါ)၊
- {{ui:Save for offline}}၊ MarkupCraft၊ ၎င်း၏ PDF ဖတ်ကိရိယာနှင့် ရေးကိရိယာ၊ နှင့် ဤအကူအညီကို ဤဘရောက်ဆာတွင် သိမ်းထားပြီး ချိတ်ဆက်မှုမရှိဘဲ ဖွင့်နိုင်စေသည်။ ၎င်းက "အော့ဖ်လိုင်း အဆင်သင့်" ဟု ပြောသည် ([အော့ဖ်လိုင်းဖြင့် အလုပ်လုပ်ခြင်း](common:offline) ကို ကြည့်ပါ)၊
- မျက်နှာပြင်မုဒ် ခလုတ် ({{ui:Full screen}})၊ နှင့်
- {{ui:Settings}} (သို့မဟုတ် {{key:Mod+,}})၊ ဤအက်ပ်အတွက် {{ui:MarkupCraft}} တဘ်နှင့် CadCraft အက်ပ်အားလုံး မျှဝေသော ဆက်တင်များအတွက် {{ui:General}} ပါဝင်သည် ([MarkupCraft ဆက်တင်များ](topic:settings) ကို ကြည့်ပါ)၊ နှင့်
- {{ui:Paper}} နှင့် {{ui:Model}}၊ အလင်းနှင့် အမှောင်အပြင်အဆင်များ။ {{ui:Model}} တွင် စာရွက်များကို အဖြူပေါ်အမည်း ပုံဖော်ထားပြီး သင့်မှတ်ချက်များသည် ၎င်းတို့၏ ကိုယ်ပိုင်အရောင်များကို ထိန်းထားသည်။

{{key:Ctrl+Shift+F}} သို့မဟုတ် မျက်နှာပြင်မုဒ် ခလုတ်သည် မုဒ်သုံးခုကို လှည့်ပေးသည်- ပုံမှန်၊ မျက်နှာပြင်အပြည့်၊ နှင့် ဘားများ ဖျောက်ထားသော မျက်နှာပြင်အပြည့်။ ဘားများ ဖျောက်ထားချိန်တွင် ညာဘက်ရှိ ပွင့်ကြောင်းကိုရွေ့ပြီး (သို့မဟုတ် ထိ) ဘားများ ပြန်ပေါ်လာသည်။ ဤဖြတ်လမ်းသည် Mac အပါအဝင် ကွန်ပျူတာအားလုံးတွင် Control ခလုတ်ကို သုံးသည်။

:::note
မျက်နှာပြင်အပြည့်တွင် {{key:Esc}} သည် ဘရောက်ဆာကိုလည်း မျက်နှာပြင်အပြည့်မှ ထွက်စေသည်။ ဆွဲခြင်းကိုသာ ပယ်ချင်ခဲ့လျှင် {{key:Ctrl+Shift+F}} ကို ထပ်နှိပ်ပြီး မျက်နှာပြင်အပြည့်သို့ ပြန်သွားပါ။
:::

## ကိရိယာဘား

အပေါ်ဆုံးဘား အောက်တွင် ကိရိယာများကို အုပ်စုဖွဲ့ပြီး အမည်ပေးထားသည်-

| အုပ်စု | ခလုတ်များ |
|---|---|
| File | {{ui:Open}}, {{ui:Save}}, {{ui:Close}} |
| Select | {{ui:Select}}, {{ui:Pan}} |
| Draw | {{ui:Pen}}, {{ui:Highlight}}, {{ui:Line}}, {{ui:Arrow}}, {{ui:Rectangle}}, {{ui:Ellipse}}, {{ui:Polyline}}, {{ui:Polygon}} |
| Revise | {{ui:Cloud}}, {{ui:Free cloud}} |
| Annotate | {{ui:Callout}}, {{ui:Text}}, {{ui:Note}}, {{ui:Stamp}} |
| Measure | {{ui:Calibrate}}, {{ui:Length}}, {{ui:Area}}, {{ui:Count}} |
| Edit | {{ui:Undo}}, {{ui:Redo}}, {{ui:Copy}}, {{ui:Paste}}, နှင့် {{ui:More}}: {{ui:Cut}}, {{ui:Copy}}, {{ui:Paste}}, {{ui:Paste in place}}, {{ui:Duplicate}}, {{ui:Delete}}, {{ui:Select all}}, {{ui:Select none}} |

သင်အသုံးပြုနေသော ကိရိယာသည် နှိပ်ထားသလို ပေါ်သည်။ ခလုတ်ပေါ်တွင် မောက်စ်ထားပါက ၎င်း၏ ကီးကို ပြသသည် (ဥပမာ "Rectangle (R)"); {{ui:More}} မီနူးက command တိုင်း၏ ကီးကို ဘေးတွင် ပြသည်။ ယခု မလုပ်နိုင်သော ခလုတ်များကို မှေးထားသည်- မှတ်ချက်တစ်ခု ရွေးမှသာ {{ui:Copy}}၊ တစ်ခုခု ကူးထားမှသာ {{ui:Paste}}။ {{ui:Save}} ၏ နောက်တွင် အစက်သေးသေးလေးသည် မသိမ်းရသေးသော မှတ်ချက်များ ရှိကြောင်း ပြသည်။ ကီးအပြည့်စုံစာရင်းကို [မောက်စ်နှင့် ကီးဘုတ်](topic:keyboard) တွင် ကြည့်ပါ။

ကိရိယာတစ်ခုကို ဆွဲပြီးနောက်လည်း ဆက်ဖွင့်ထားသဖြင့် တစ်ကြောင်းတည်းတွင် တိမ်များ အများအပြား ဆွဲနိုင်သည်။ {{key:Esc}} (ထည့်ထားသော မှတ်ချက်ကို ရွေးထားဆဲဆိုလျှင် နှစ်ကြိမ်) သို့မဟုတ် {{key:V}} ကို နှိပ်ပြီး {{ui:Select}} သို့ ပြန်သွားပါ။

## စာရွက်စာရင်း (ဘယ်)

{{ui:Sheets}} သည် ဖွင့်ထားသော PDF အားလုံး၏ စာမျက်နှာတိုင်းကို စာရင်းပြုသည်။ အတန်းတစ်ခုစီတွင် စာရွက်၏ ပုံငယ်၊ အမည်၊ စာရွက်နံပါတ် သို့မဟုတ် ဖိုင်နှင့် စာမျက်နှာ၊ နှင့် မှတ်ချက်အရေအတွက် ပြသည်။ ခေါင်းစဉ်နောက်ရှိ ဂဏန်းသည် စာရွက်အရေအတွက် ဖြစ်သည်။

- စာရွက်ကို ပြရန် အတန်းတစ်ခုကို နှိပ်ပါ။
- {{ui:Search sheets}} တွင် ရိုက်ပြီး စာရွက်အမည်၊ စာရွက်နံပါတ် သို့မဟုတ် ဖိုင်အမည်ဖြင့် စစ်ထုတ်ပါ။ ပထမဆုံး ကိုက်ညီသည်ကို ဖွင့်ရန် {{key:Enter}} ကို နှိပ်ပါ။

PDF တွင် ပါရှိပါက စာရွက်အမည်များကို PDF မှ ယူသည်။ [ပုံဆွဲအစုံ ဖွင့်ပြီး စာရွက်များကြား ရွှေ့ခြင်း](topic:open-a-plan-set) ကို ကြည့်ပါ။

## စာရွက်နေရာ (အလယ်)

သင်အလုပ်လုပ်နေသော စာရွက်။ မည်သည်မှ မဖွင့်ရသေးလျှင် {{ui:Open PDFs}} ခလုတ်ပါသော "ပုံဆွဲအစုံ ဖွင့်ပါ" ကို ပြသည်။ PDF များကို ဤနေရာတွင် မည်သည့်နေရာသို့မဆို ချလိုက်ပြီး ဖွင့်နိုင်သည်။

စာရွက်အောက်တွင် ပါးလွှာသော ဘားတစ်ခုတွင်-

- ယခင်နှင့် နောက်စာရွက် မြားများ၊ နှင့် "3 of 12: A-101 — Floor plan" (ဖိုင်နှင့် စာမျက်နှာ ကြည့်ရန် ညွှန်ပြထားပါ)၊
- ဇူးမ်ထွက်၊ ဇူးမ်အကွက် (ရာခိုင်နှုန်း ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ၊ သာမန်ဖန်သားပြင်တွင် 100% သည် အမှန်တကယ်အရွယ်အစား)၊ ဇူးမ်ဝင်၊
- {{ui:Fit page}} နှင့် {{ui:Fit width}}။

ဖွင့်ထားသော အတွင်း စာရွက်တိုင်းသည် ၎င်း၏ ကိုယ်ပိုင်ဇူးမ်ကို မှတ်ထားသည်။

စာရွက်နှစ်ရွက်ကို နှိုင်းယှဉ်သောအခါ ဤနေရာတွင် လက်ဆင့်ကမ်းချက် ပေါ်လာသည်- "ဟောင်းစာရွက်တွင်သာ", "အသစ်စာရွက်တွင်သာ" နှင့် "နှစ်ခုလုံးတွင်". [revision နှစ်ခုကို နှိုင်းယှဉ်ခြင်း](topic:compare-revisions) ကို ကြည့်ပါ။

## ပန်နယ်များ (ညာ)

တဘ်ငါးခု-

| တဘ် | ပြသသည် |
|---|---|
| {{ui:Properties}} | ရွေးထားသော မှတ်ချက်- ရေးသူ၊ ရက်စွဲများ၊ တိုင်းထားသော တန်ဖိုးများ၊ အခြေအနေ၊ ခေါင်းစဉ်၊ စာသား၊ မှတ်ချက်၊ ပုံစံ၊ ၎င်း၏ ပြန်စာများနှင့် punch အချက်။ ဆွဲကိရိယာ ဖွင့်ထားပြီး ဘာမျှ မရွေးထားလျှင် မှတ်ချက်အသစ်များ သုံးမည့် ဆက်တင်များ။ ဘာမျှ မရွေးထားဘဲ {{ui:Select}} ဖွင့်ထားလျှင် စာရွက်- နံပါတ်၊ ခေါင်းစဉ်၊ အမည်ကို ဘယ်မှ ဖတ်ခဲ့သလဲ၊ စာရွက်အရွယ်အစား၊ scale နှင့် {{ui:Rename sheet}}။ |
| {{ui:Markups}} | ဖွင့်ထားသော အစုံရှိ မှတ်ချက်အားလုံး၊ စစ်ထုတ်မှုများနှင့်အတူ၊ နှင့် {{ui:CSV}} နှင့် {{ui:BCF}} ထုတ်ယူမှုများ။ [မှတ်ချက်စာရင်းနှင့် ထုတ်ယူခြင်း](topic:markups-list-and-export) ကို ကြည့်ပါ။ |
| {{ui:Punch list}} | ဝန်ထမ်းသတ်မှတ်ချက်၊ သတ်မှတ်ရက်နှင့် အခြေအနေပါသော နံပါတ်ပေးထားသော ပြင်ဆင်ရမည့်အချက်များ။ [Punch list ဖန်တီးခြင်း](topic:punch-list) ကို ကြည့်ပါ။ |
| {{ui:Tools}} | ကိရိယာသေတ္တာ- သိမ်းထားပြီး ပုံစံချထားသော ကိရိယာများ။ [ကိရိယာသေတ္တာ](topic:tool-chest) ကို ကြည့်ပါ။ |
| {{ui:Compare}} | စာရွက်နှစ်ရွက်ကို ထပ်ဆင့်ပြခြင်း။ [revision နှစ်ခုကို နှိုင်းယှဉ်ခြင်း](topic:compare-revisions) ကို ကြည့်ပါ။ |

## အခြေအနေဘား (အောက်)

- ဘယ်ဘက်တွင်၊ မောက်စ်သည် စာရွက်ပေါ်ရှိနေရာ၊ ကစာရွက်ပေါ်တွင် လက်မ (သို့မဟုတ် [ဆက်တင်များ](topic:settings) တွင် မီလီမီတာ) ဖြင့် ပြသသည်။
- အလယ်တွင် မက်ဆေ့ချ်များ- ကိရိယာက နောက်ဘာကို မျှော်လင့်သလဲ၊ ယခုသိမ်းပြီးပြီလား၊ ဘာကြောင့် ငြင်းပယ်ခံရသလဲ။ **တစ်ခုခု မဖြစ်သောအခါ ဖတ်ပါ။**
- စာရွက်၏ scale ခလုတ် ("Not calibrated" သို့မဟုတ် scale)။ scale သတ်မှတ်ရန် နှိပ်ပါ။ [စာရွက်ကို စံသတ်မှတ်ခြင်းနှင့် တိုင်းတာခြင်း](topic:calibrate-and-measure) ကို ကြည့်ပါ။
- သင့်နာမည် ("Set your name" ပေးမချင်း)။ ပြောင်းရန် နှိပ်ပါ။

## သေးငယ်သော မျက်နှာပြင်တွင်

အကျယ် ၁၁၈၀ pixel ထက်နည်းသော မျက်နှာပြင်တွင် ပန်နယ်များ ကျဉ်ပြီး စာရွက်ပုံငယ်များ သေးသွားသည်။ ဖုန်းအရွယ် မျက်နှာပြင်တွင် အစိတ်အပိုင်းများ အထပ်လိုက်ဖြစ်သည်- ကိရိယာဘား (ဘေးသို့ ဆွဲလှည့်နိုင်သည်)၊ စာရွက်၊ အခြေအနေဘား၊ ပန်နယ်များ၊ ထို့နောက် အောက်ဆုံးတွင် စာရွက်စာရင်း။ အလျားလိုက်ထားသော tablet သည် အပြည့်အစုံ အပြင်အဆင်ကို ထိန်းသည်။
