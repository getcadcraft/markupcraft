ပုံဆွဲများကို Bluebeam Revu တွင် သုံးသပ်ပါက (သို့မဟုတ် အခြား desktop PDF ပရိုဂရမ်တွင် PDF ကို မှတ်ချက်ပေးပါက)၊ MarkupCraft ၏ အများစုသည် ရင်းနှီးသည်ဟု ခံစားရမည်: cloud များ၊ callout များ၊ tool chest၊ markup စာရင်း၊ တုံ့ပြန်ချက်များနှင့်အတူ အခြေအနေများ၊ စံသတ်မှတ်ထားသော တိုင်းတာမှုများ၊ စာရွက် overlay များ။ ဖိုင်များ ကိုင်တွယ်ပုံသည် အဓိက ကွာခြားချက် ဖြစ်သည်၊ ထို့ကြောင့် ကျန်သည်ကို ကျော်သော်လည်း နောက်အပိုင်းကို ဖတ်ပါ။

## အရေးကြီးဆုံး ကွာခြားချက် ငါးခု

1. **သိမ်းခြင်းသည် ဖိုင်အသစ် ဖန်တီးသည်။** MarkupCraft သည် ဘရောက်ဆာတွင် အလုပ်လုပ်ပြီး သင့် disk ရှိ PDF ပေါ်သို့ ရေးမရပါ။ {{ui:သိမ်းရန်}} သည် "<name> (marked up).pdf" ကို ဒေါင်းလုဒ်ဆွဲပြီး မူရင်းမှာ မူလအတိုင်း ကျန်သည်။ နောက်တစ်ကြိမ် "(marked up)" မိတ္တူကို ဖွင့်ပြီး ဟောင်းမိတ္တူများကို ကိုယ်တိုင် သပ်ရပ်အောင် ရှင်းလင်းပါ။
2. **သိမ်းသည့်အခါမှ PDF ကို သိမ်းသည်။** ထိအချိန်အထိ ဤဘရောက်ဆာရှိ ပြန်လည်ရယူသည့်မိတ္တူက အမှား ပျက်ခြင်း သို့မဟုတ် ပိတ်ထားသော tab အတွက် သင့် markup များကို ထိန်းသိမ်းထားပြီး နောက်တစ်ကြိမ် MarkupCraft က ပြန်ပေးသည်။ ၎င်းသည် ကာကွယ်ရေးသာ ဖြစ်သည်: သုံးသပ်ချက်ကို ထိန်းသိမ်းရန် PDF ကို သိမ်းပါ။
3. **သင့်ပရိုဖိုင်သည် ဘရောက်ဆာတွင် ရှိသည်။** သင့်ရေးသူအမည်၊ ကိရိယာ ဆက်တင်များနှင့် tool chest ကို ဤကွန်ပျူတာ၏ ဤဘရောက်ဆာတွင် သိမ်းထားသည်။ အခြားဘရောက်ဆာ သို့မဟုတ် ကွန်ပျူတာသည် အစမှ စတင်မည်၊ ဆိုက်ဒေတာ ရှင်းလင်းခြင်းက ၎င်းတို့ကို ဖျက်သည်။ tool chest ကို အရန်အဖြစ် ထုတ်ယူပါ။ [ဘရောက်ဆာတွင် ဘာကျန်သလဲ](topic:browser-storage) ကို ကြည့်ပါ။
4. **မျှဝေသော session မရှိသေးပါ။** တိုက်ရိုက် မျှဝေသည့် သုံးသပ်ရေး session နှင့် cloud project မရှိပါ။ သုံးသပ်ချက်သည် PDF ဖြင့် ရွှေ့ပြောင်းသည်: သိမ်းပါ၊ မိတ္တူကို ပို့ပါ၊ နောက်လူက တုံ့ပြန်ပြီး သိမ်းပါ။
5. **စကေးသည် စာရွက်တစ်ခုစီအလိုက်သာ ဖြစ်သည်။** စာရွက်တစ်ခုအတွင်း viewport မရှိပါ၊ "ဤစကေးကို စာမျက်နှာအားလုံးသို့ သုံးပါ" ဟူသည်လည်း မရှိပါ။ တိုင်းတာမည့် စာရွက်တစ်ခုစီကို စံသတ်မှတ်ပါ။

## ကွာခြားသော ကီးများ

အက္ခရာတစ်လုံးကီးများ အများစုသည် သင်မျှော်လင့်သည့်အတိုင်း ဖြစ်သော်လည်း သင့်လက်က မလုပ်မီ ဤအရာများကို စစ်ဆေးပါ:

- {{key:K}} သည် {{ui:ညွှန်းချက်}} ဖြစ်ပြီး {{key:Q}} သည် {{ui:ဧရိယာ}} ဖြစ်သည်။ callout အတွက် Q ကို သုံးလေ့ရှိပါက ဤနေရာတွင် ဧရိယာ စတင်မည်။
- {{key:C}} သည် ဘောက်စ် {{ui:တိမ်}} ဖြစ်ပြီး; {{key:Shift+C}} သည် {{ui:လွတ်လပ်သော တိမ်}} ဖြစ်သည်။
- {{key:M}} သည် {{ui:အလျား}}၊ {{key:U}} သည် {{ui:ရေတွက်ရန်}}၊ {{key:Y}} သည် {{ui:ဖြောင့်ဆက်မျဉ်း}}၊ {{key:G}} သည် {{ui:အထောင့်ပေါင်းများစွာ}}၊ {{key:I}} သည် {{ui:မီးမောင်း}} ဖြစ်သည်။
- {{key:Mod+D}} သည် ရွေးထားသည်ကို ပွားသည် (ဘရောက်ဆာ၏ bookmark အစား)။
- {{key:Mod+Plus}} နှင့် {{key:Mod+Minus}} သည် စာရွက်ကို zoom လုပ်သည်၊ ဘရောက်ဆာ စာမျက်နှာကို မဟုတ်ပါ။
- ကီးမည်သည့်အရာကိုမဆို ပြောင်းလဲနိုင်သည်: အောက်တွင် ကြည့်ပါ။

:::tip
သင့်လက်က Bluebeam Revu ကို သိပါက {{ui:ဆက်တင်များ}} › {{ui:MarkupCraft}} › {{ui:Menus, keys နှင့် mouse}} တွင် {{ui:PDF သုံးသပ်ချက်}} မီနူးပုံစံကို ရွေးပါ: မီနူးဘား (File, Edit, View, Document, Markup, Measure, Window) နှင့် သုံးသပ်ရေး ကိရိယာများ အတန်း၊ {{key:Q}} သည် callout အတွက်၊ {{key:H}} သည် highlighter အတွက်၊ {{key:N}} သည် polygon အတွက်၊ တိုင်းတာမှုများကို {{key:Alt+Shift}} နှင့် အက္ခရာတစ်လုံးဖြင့်။ ကီးမည်သည့်အရာကိုမဆို ထိုနေရာတွင်လည်း ပြောင်းနိုင်သည်။ [Menus, keys နှင့် mouse](topic:menus-keys-and-mouse) ကို ကြည့်ပါ။

## မျှော်လင့်ထားသည်ထက် ကွဲပြားစွာ အလုပ်လုပ်သည့်အရာများ

- **ကိရိယာများ ဖွင့်ထားသည်။** cloud ပြီးနောက် သင်သည် cloud ဆွဲနေဆဲ ဖြစ်သည်။ {{key:Esc}} တစ်ကြိမ်သည် ရွေးမှုကို ရှင်းပြီး နှစ်ကြိမ်သည် {{ui:ရွေးရန်}} သို့ ပြန်သွားသည်။
- **စာသားနှင့် callout များသည် စာသား လိုအပ်သည်။** ဘာမျှ မရိုက်ဘဲ ပြီးဆုံးပါက markup မထည့်ပါ။ မှတ်စုများကို ဗလာထားသည်။
- **တိုင်းတာမှုများသည် စကေး အရင်လိုအပ်သည်။** {{ui:အလျား}} နှင့် {{ui:ဧရိယာ}} သည် စံမသတ်မှတ်ရသေးသော စာရွက်တွင် {{ui:စံသတ်မှတ်ရန်}} သို့ ပြောင်းပြီး ပြီးနောက် ပြန်ရောက်လာသည်။
- **အခြားပရိုဂရမ်များမှ မှတ်ချက်များ။** အခြားနေရာတွင် ပြုလုပ်ထားသော စတုဂံများ၊ ဝိုက်ပုံများ၊ မျဉ်းများ၊ polyline များ၊ polygon များ၊ ink၊ စာသားဘောက်စ်များနှင့် sticky note များသည် တည်းဖြတ်နိုင်သော MarkupCraft markup များ ဖြစ်လာပြီး သိမ်းသည့်အခါ MarkupCraft ပုံစံဖြင့် ပြန်ရေးသည် (ပုံစံ အနည်းငယ် ပြောင်းနိုင်သည်)။ စာသား highlight များ၊ အခြားပရိုဂရမ်များ၏ တံဆိပ်များနှင့် အခြား အထူးအမျိုးအစားများသည် ဖတ်ရုံသာ ဖြစ်ပြီး: ၎င်းတို့ကို တုံ့ပြန်နိုင်သော်လည်း ပြောင်းလဲ၍ မရပါ။
- **အနောက်ဥရောပ အက္ခရာပြင်ပ စာလုံးများ** သိမ်းထားသော PDF တွင် "?" အဖြစ် ပုံနှိပ်သည်။ [markup ပါသော PDF သိမ်းခြင်း](topic:save-the-marked-up-pdf) ကို ကြည့်ပါ။
- **တံဆိပ် ရက်စွဲများသည် UTC ကို သုံးသည်၊** ထို့ကြောင့် အမေရိကတွင် ည နောက်ကျမှ ပြုလုပ်သော တံဆိပ်သည် မနက်ဖြန်ရက်စွဲကို ပြနိုင်သည်။
- **တိုင်းတာမှုများ ဆက်လက်ပါဝင်သည်** စံ တိုင်းတာမှု မှတ်ချက်များအဖြစ်၊ စံသတ်မှတ်ထားသော စာရွက်တိုင်းသည် ၎င်း၏ စကေးကို ထိန်းသိမ်းသည်၊ ထို့ကြောင့် PDF တိုင်းတာမှုများကို ဖတ်သော ပရိုဂရမ်များက ပြသနိုင်သည်။ အတိအကျ အပြုအမူသည် ထိုပရိုဂရမ်အပေါ် မူတည်သည်။

## နှစ်ခုလုံး သုံးခြင်း

သင်သည် ပြန်ပြန်သွားနိုင်သည်။ အခြားနေရာတွင် ပြုလုပ်ထားသော မှတ်ချက်များသည် MarkupCraft တွင် ဖွင့်ပြီး "(marked up)" PDF သည် အခြား PDF ပရိုဂရမ်များတွင် markup၊ တုံ့ပြန်ချက်နှင့် အခြေအနေ အားလုံး မြင်ရသည်။ MarkupCraft မှသာ ပြန်ဖတ်နိုင်သော (punch တာဝန်ခံနှင့် နောက်ဆုံးရက်၊ အကြောင်းအရာ အခြေအနေ) များကို MarkupCraft အတွက် ဖိုင်တွင် သိမ်းထားသည်။
