MarkupCraft ဖွံ့ဖြိုးဆဲဖြစ်သည်။ ဤသည်မှာ လက်ရှိဗားရှင်းက **မလုပ်ဆောင်နိုင်သေး**သည့် အရာများဖြစ်ပြီး သင်အစီအစဉ်ဆွဲနိုင်ရန် ဖော်ပြထားသည်။ ဤစာသားသည် ယနေ့ဗားရှင်းကို ဖော်ပြသည်၊ ကတိပေးချက်များ မဟုတ်ပါ။

## လူများနှင့် အလုပ်လုပ်ခြင်း

| မရှိသေးသည့်အရာ | ယနေ့ ပြုလုပ်ရန် |
|---|---|
| ကွန်ပျူတာများကြား cloud သိမ်းဆည်းခြင်းနှင့် စင့်ခ် | PDF များကို သင်၏ပရောဂျက်ဖိုင်များနှင့်အတူ ထားပါ။ Cloud သိမ်းဆည်းခြင်းကို ယခုမရနိုင်သေးပါ။ |
| လူနှစ်ယောက်၏ markup မိတ္တူများကို ပေါင်းခြင်း | စာရွက်များကို ပြန်လည်သုံးသပ်သူများအကြား ခွဲဝေပါ၊ သို့မဟုတ် {{key:Mod+C}} နှင့် {{key:Mod+V}} ဖြင့် markup အနည်းငယ်ကို ကူးယူပါ။ RFI, submittal နှင့် နေ့စဉ်မှတ်တမ်းများကို ပေါင်းနိုင်ပါသည်: [RFI, submittal နှင့် နေ့စဉ်မှတ်တမ်းများကို ခြေရာခံခြင်း](topic:field-records) ကို ကြည့်ပါ။ |
| Team များ၊ အသိပေးချက်များနှင့် RFI, submittal အတွက် cloud ပရောဂျက်များ | PDF ကို ပေးပို့ပြီး {{ui:Merge}} ကို အသုံးပြု၍ မိတ္တူများကို စုစည်းပါ။ |
| တိုက်ရိုက် session ထဲရှိ RFI, submittal နှင့် နေ့စဉ်မှတ်တမ်းများ | သူတို့တစ်ဦးချင်းစီ မိမိ၏ မိတ္တူပေါ်တွင် အလုပ်လုပ်ကြပါ; မိတ္တူများကို {{ui:Merge}} ဖြင့် စုစည်းပါ။ |
| တစ်ခုတည်းသော record ၏ မတူသော field များအတွက် လူနှစ်ယောက်၏ ပြောင်းလဲမှုများကို ပေါင်းခြင်း | နောက်ဆုံးပြောင်းလဲသော မိတ္တူက record တစ်ခုလုံးကို အနိုင်ရသည် (thread နှင့် attachment အမည်များကို ပေါင်းထားသည်)။ ဘယ်သူက ဘယ် record ကို တည်းဖြတ်မည်ကို သဘောတူပါ။ |
| RFI, submittal နှင့် နေ့စဉ်မှတ်တမ်းများအတွက် လက်ထောက် tool များ | {{ui:Field}} tab တွင် အလုပ်လုပ်ပါ။ လက်ထောက်များသည် markup များနှင့် အလုပ်လုပ်နိုင်ပါသည်: [AI လက်ထောက်ဖြင့် MarkupCraft ကို အသုံးပြုခြင်း](topic:use-with-ai-assistants) ကို ကြည့်ပါ။ |
| ပို့ပြီးသော reply ကို တည်းဖြတ်ခြင်း သို့မဟုတ် ဖျက်ခြင်း | {{ui:Undo}} ကို ချက်ချင်းနှိပ်ပါ၊ သို့မဟုတ် ပြင်ဆင်သော reply တစ်ခု ထည့်ပါ။ |
| markup ၏ ရေးသူကို ပြောင်းခြင်း | မစတင်မီ သင့်နာမည်ကို သတ်မှတ်ပါ။ |

## Markups

| မရှိသေးသည့်အရာ | ယနေ့ ပြုလုပ်ရန် |
|---|---|
| fill-in field ပါသော stamp များ၊ အသိအမှတ်ပြုထားသော ဒစ်ဂျစ်တယ်လက်မှတ်များ | သင့်နာမည်နှင့် ရက်စွဲပါဝင်သော စိတ်ကြိုက် စာသား stamp ကို အသုံးပြုပါ၊ သို့မဟုတ် သင့်လက်မှတ်ပုံကို အသုံးပြုပါ။ |
| ဓာတ်ပုံမှတစ်ပါး ဖိုင်များ (စာရွက်စာတမ်း၊ ဗီဒီယို) ကို ပူးတွဲခြင်း | ထိုဖိုင်များကို PDF ဘေးတွင် ထားပြီး မှတ်ချက်တွင် ရည်ညွှန်းပါ။ |
| ဝဘ်ဆိုဒ်များ သို့မဟုတ် မဖွင့်ထားသော ဖိုင်များသို့ လင့်ခ်များ | လိပ်စာ သို့မဟုတ် ဖိုင်အမည်ကို မှတ်ချက်တွင် ရေးပါ။ |
| စိတ်ကြိုက် status အစုံ | status လေးခုကို အသုံးပြုပါ၊ ထပ်လိုသည်များအတွက် subject ကို အသုံးပြုပါ။ |
| ဖိုင်နှင့်အတူ ပါလာသော မှတ်ချက်များ (text highlight၊ အခြားပရိုဂရမ်များ၏ stamp) ကို တည်းဖြတ်ခြင်း (read-only) | ထိုမှတ်ချက်များကို ပြန်ဖြေပါ၊ သို့မဟုတ် ၎င်းနားတွင် MarkupCraft markup ဆွဲပါ။ |
| ဖိအားအလိုက် ပင်ကလုံးရေးချက်များ | မျဉ်းအကျယ်ကို သတ်မှတ်ပါ။ |

## စာမျက်နှာ၏ ကိုယ်ပိုင်အကြောင်းအရာ

| မရှိသေးသည့်အရာ | ယနေ့ ပြုလုပ်ရန် |
|---|---|
| စာမျက်နှာပေါ်တွင် ပုံသဏ္ဍာန်အသစ်များကို တိုက်ရိုက်ဆွဲခြင်း | markup အဖြစ် ဆွဲပြီး {{ui:Put into the page}} ကို နှိပ်ပါ။ [စာမျက်နှာ၏ ကိုယ်ပိုင်အကြောင်းအရာကို ပြောင်းခြင်း](topic:page-content) ကို ကြည့်ပါ။ |
| စာမျက်နှာ object များကို မည်သည့်ထောင့်သို့မဆို လှည့်ခြင်း | ရွှေ့ပြီး အရွယ်ပြင်ပါ; စာမျက်နှာတစ်ခုလုံးကို {{ui:Pages}} ဖြင့် လှည့်ပါ။ |
| စာကြောင်းတစ်ကြောင်း၏ font သို့မဟုတ် size ကို ပြောင်းခြင်း၊ သို့မဟုတ် မျဉ်းများစွာပေါ် စီးဆင်းသော စာသား | စာကြောင်းတစ်ကြောင်းချင်းစီ စကားလုံးများကို ပြောင်းပါ; အခြား font ဖြင့် စကားအသစ်အတွက် စာသား markup ထည့်ပါ။ |
| စကင်ဖတ်ထားသော ပုံအတွင်းရှိ အရာကို တည်းဖြတ်ခြင်း | ပုံကို အစားထိုးပါ၊ သို့မဟုတ် markup ဆွဲပါ။ |
| encrypt လုပ်ထားသော သို့မဟုတ် လက်မှတ်ထိုးထားသော PDF များကို တည်းဖြတ်ခြင်း | လက်မှတ်မထိုးထားသော မိတ္တူတောင်းပါ; markup များသည် မည်သည့် PDF ပေါ်တွင်မဆို အလုပ်လုပ်ပါသည်။ |

## တိုင်းတာခြင်း

| မရှိသေးသည့်အရာ | ယနေ့ ပြုလုပ်ရန် |
|---|---|
| အချင်းဝက် တိုင်းတာခြင်း | ၎င်းတစ်လျှောက် {{ui:Arc}} ဆွဲပါ၊ သို့မဟုတ် ဖြတ်ကျော်သော {{ui:Length}} ကို တိုင်းပြီး ထက်ဝက်ယူပါ။ |
| cut-out ၏ ထောင့်များကို တည်းဖြတ်ခြင်း | cut-out များကို ဖယ်ရှားပြီး ပြန်ဆွဲပါ။ |
| စာရွက်အများအပြားအတွက် scale တစ်ခုတည်းကို အသုံးပြုခြင်း | စာရွက်တစ်ရွက်ချင်းစီကို စံသတ်မှတ်ပါ; preset ရွေးချယ်ခြင်းသည် စာရွက်တစ်ရွက်လျှင် စက္ကန့်အနည်းငယ် ကြာသည်။ |
| စာရွက်တစ်ရွက်တည်းပေါ် scale အများအပြား (viewport) | သင်အများဆုံး တိုင်းသည့် ပုံဆွဲချက်အတွက် စံသတ်မှတ်ပါ။ စာရွက်၏ scale ကို ပြောင်းလျှင် ၎င်းပေါ်ရှိ အရာအားလုံးကို ပြန်တိုင်းသည်၊ ထို့ကြောင့် ပြန်စံသတ်မှတ်မီ detail တန်ဖိုးများကို ရေးမှတ်ထားပါ။ |
| ပုံဆွဲချက်ရှိ မျဉ်းများသို့ snap လုပ်ခြင်း | နှိပ်မီ ဇူးမ်ချဲ့ပါ၊ သို့မဟုတ် အရှည်နှင့် ထောင့်များကို ရိုက်ထည့်ပါ ([စကေးအတိုင်း ဆွဲခြင်း](topic:calibrate-and-measure#sketch-to-scale) ကို ကြည့်ပါ)။ |
| item, assembly နှင့် စျေးနှုန်းပါဝင်သော အပြည့်အစုံ takeoff | TakeoffCraft ကို အသုံးပြုပါ၊ CadCraft မိသားစု၏ takeoff app ဖြစ်သည်။ |

## စာရွက်များနှင့် ဖိုင်များ

|---|---|

| set ၏ ဖိုင်တစ်ခုကို ပိတ်ခြင်း | {{ui:Close}} သည် set တစ်ခုလုံးကို ပိတ်သည်; လိုအပ်သော ဖိုင်များကို ပြန်ဖွင့်ပါ။ |
| set ကို ပရောဂျက်အဖြစ် သိမ်းပြီး တစ်ဆင့်တည်း ပြန်ဖွင့်ခြင်း | PDF များကို ထပ်မံဖွင့်ပါ။ |
| ရွေးထားသော scale ဖြင့် သို့မဟုတ် စက္ကူတစ်ရွက်ပေါ် စာရွက်များစွာ ပရင့်ထုတ်ခြင်း | သင့် browser ၏ printer dialog ကို အသုံးပြုပါ၊ သို့မဟုတ် သိမ်းထားသော မိတ္တူကို အခြား PDF viewer မှ ပရင့်ထုတ်ပါ။ |
