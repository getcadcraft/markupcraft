## ဆွဲနေစဉ်

| ကီး သို့မဟုတ် လုပ်ဆောင်ချက် | ဘာလုပ်ဆောင်သလဲ |
|---|---|
| ဆွဲနေစဉ် {{key:Shift}} | မျဉ်းများ၊ မြားများ၊ အလျားများနှင့် polyline အစွန်းများကို 45° အဆင့်များဖြင့်; စတုဂံများ၊ ဝိုက်ပုံများနှင့် အကွက် cloud များကို စတုရန်းပုံ; pen နှင့် highlighter ကို မျဉ်းဖြောင့် တစ်ကြောင်း |
| နှစ်ချက်နှိပ်ခြင်း၊ {{key:Enter}} သို့မဟုတ် ညာကလစ် | polyline၊ polygon၊ free cloud သို့မဟုတ် area ကို ပြီးစီးစေသည် |
| {{key:Backspace}} | polyline၊ polygon၊ free cloud သို့မဟုတ် area ၏ နောက်ဆုံး အမှတ်ကို ဖယ်ရှားသည် |
| {{key:Esc}} | ဆွဲနေသည့်အရာကို ပယ်ဖျက်သည်; ဘာမှ မဆွဲနေလျှင် ရွေးချယ်မှုကို ဖျက်သည်; ဘာမှ ရွေးမထားလျှင် {{ui:Select}} သို့ ပြန်သွားသည် |
| {{key:Mod+Enter}} | text box၊ callout သို့မဟုတ် note တွင် စာရိုက်ခြင်းကို ပြီးစီးစေသည် (သို့မဟုတ် အပြင်ဘက်ကို နှိပ်ပါ) |
| စာရိုက်နေစဉ် {{key:Esc}} | ရိုက်နေသော စာသားကို ပယ်ဖျက်သည် |
| {{ui:Count}} ဖြင့် {{key:Shift}}-click | ရွေးထားသော count အုပ်စု၏ အနီးဆုံး အစက်ကို ဖယ်ရှားသည် |

## ဖြတ်ခြင်း၊ ကူးခြင်းနှင့် ကူးထည့်ခြင်း

တူညီသော command များကို toolbar ရှိ {{ui:Edit}} အုပ်စု ({{ui:Copy}}, {{ui:Paste}}) နှင့် {{ui:More}} မီနူးတွင် ၎င်းတို့၏ ကီးများနှင့်အတူ တွေ့ရသည်။ တစ်ခုစီသည် undo အဆင့် တစ်ဆင့်ဖြစ်သည်။ see [Copy, paste and duplicate](topic:select-and-edit#copy-paste-and-duplicate)။

| ကီး | ဘာလုပ်ဆောင်သလဲ |
|---|---|
| {{key:Mod+X}} | ဖြတ်ခြင်း: ရွေးထားသည်ကို ကူးပြီး ဖျက်သည် |
| {{key:Mod+C}} | ရွေးထားသည်ကို ကူးသည် |
| {{key:Mod+V}} | ကူးထည့်သည်။ pointer စာရွက်ပေါ်တွင် ရှိလျှင် ကူးယူမှုသည် pointer ညွှန်ရာတွင် အလယ်ဗဟိုမှာ ကျရောက်သည်; မဟုတ်လျှင် မူရင်းဘေးတွင် ကျရောက်သည်။ ဆက်တင်များဖြင့် အမြဲမူရင်းဘေးတွင် ကူးထည့်စေနိုင်သည်။ |
| {{key:Mod+Shift+V}} | နေရာတူတွင် ကူးထည့်သည်: စာရွက်ပေါ်ရှိ တူညီသော နေရာ၊ ဤစာရွက် သို့မဟုတ် အခြားစာရွက်တွင် |
| {{key:Mod+D}} | ရွေးထားသည်ကို ဘေးတွင် ပွားသည် (clipboard ကို မထိပါ) |

:::mac

## browser က ထိန်းထားသော ဖြတ်လမ်းလင့်ချက်များ

- {{key:Mod+W}}၊ {{key:Mod+T}}၊ {{key:Mod+N}} နှင့် {{key:Mod+Q}} တို့သည် browser ၏ ဖြစ်သည်။ မသိမ်းရသေးသော markup များရှိစဉ် tab သို့မဟုတ် ပြတင်းပေါက်ကို ပိတ်လျှင် ဆုံးရှုံးသွားမည်၊ ကွန်ပျူတာပေါ်တွင် browser ၏ "Leave site?" မေးခွန်းပြီးမှ ဖြစ်သည်။
- browser အများစုသည် {{key:Mod+N}} ကို ပြတင်းပေါက်အသစ်အတွက် ထားသောကြောင့် browser tab တွင် toolbar ရှိ {{ui:New}} ကို သုံးပါ; desktop app နှင့် Studio က ကီးကို MarkupCraft သို့ ပေးသည်။
- စာရွက်ကို အက်ပ်က ကီးဘုတ်ကို ရထားသည့်အခါ MarkupCraft သည် {{key:Mod+O}}၊ {{key:Mod+S}}၊ {{key:Mod+D}}၊ {{key:Mod+A}}၊ {{key:Mod+V}}၊ {{key:Mod+Shift+V}}၊ {{key:Mod+0}}၊ {{key:Mod+Plus}} နှင့် {{key:Mod+Minus}} ကို browser မှ ယူသည်၊ markup များ ရွေးထားစဉ် {{key:Mod+C}} နှင့် {{key:Mod+X}} ကိုလည်း ယူသည်။ {{key:Mod+,}} သည် {{ui:Settings}} ကို ဖွင့်သည်။ browser စာမျက်နှာ တစ်ခုလုံးကို ချဲ့ရန် browser ၏ မီနူးကို သုံးပါ။
- {{key:Mod+9}} သည် browser အချို့တွင် MarkupCraft မမြင်မီ နောက်ဆုံး browser tab သို့ ရောက်သွားနိုင်သည်။ ဖြစ်လျှင် စာရွက်အောက်ရှိ {{ui:Fit width}} ကို သုံးပါ။
- Full screen တွင် {{key:Esc}} သည် full screen မှလည်း ထွက်စေသည်။

## key တစ်ခု အလုပ်မလုပ်သောအခါ

- **စာရိုက်နေသည် အကွက်ထဲတွင်။** ဦးစွာ စာရွက်ပေါ်တွင် click လုပ်ပါ။ (ဆွဲကိရိယာဖြင့် click လုပ်လျှင် ဆွဲသွားမည်; ထို့နောက် {{key:Esc}} နှိပ်ပါ သို့မဟုတ် {{key:Mod+Z}} သုံးပါ။)
- **dialog တစ်ခု ဖွင့်ထားသည်။** dialog ပိတ်သည်အထိ ကီးများသည် dialog သို့ သွားသည်။
- **toolbar ခလုတ်ကို ခုနက click လုပ်ထားသည်** ဦးတည်ချက် ကီးများ သို့မဟုတ် {{key:Space}} သည် ထိုခလုတ်အပေါ် အလုပ်လုပ်သည်။ pointer ကို စာရွက်ပေါ် ရွှေ့ပြီး wheel သို့မဟုတ် အလယ်ခလုတ်ကို သုံးပါ၊ သို့မဟုတ် ခလုတ်များကို click မလုပ်ဘဲ ကိရိယာ အက္ခရာတစ်လုံးကို နှိပ်ပါ။

## Move ရှိရာနေရာ

Move command မရှိပါ: markup တစ်ခုကို ရွေးပြီး ဖိရွှေ့ပါ ({{key:Shift}} က 45° အဆင့်များကို ထိန်းသည်)။ pin ကို {{ui:Move pin}} ဖြင့် ရွှေ့ပြီး စာမျက်နှာကို {{ui:Move page earlier}} သို့မဟုတ် {{ui:Move page later}} ဖြင့် ရွှေ့သည်။
