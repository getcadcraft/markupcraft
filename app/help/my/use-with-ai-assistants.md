## သင် သိရှိမည့်အရာ

AI အကူအညီပေးသူ (သို့မဟုတ် သင်ရေးသော script) ကို MarkupCraft နှင့် အလုပ်လုပ်စေနည်း၊ နှင့် ၎င်း ထိခွင့်ရှိသည့်အရာများကို ဘယ်လိုဆုံးဖြတ်မလဲ။

MarkupCraft တွင် **ကိုယ်ပိုင် AI မရှိပါ** နှင့် ဘယ်နေရာသို့မှ ဘာမျှ မပို့ပါ။ အကူအညီပေးသူကို သင်ယူလာပါ: Model Context Protocol (MCP) ကို နားလည်သော မည်သည့်ပရိုဂရမ်မဆို။ MarkupCraft က ကိရိယာများကိုသာ ပေးပြီး သင်က ဘာကို ရွေးသည်။

## ဖွင့်ရန်

1. {{ui:Settings}} (ထိပ်ဘားရှိ ဂီယာ၊ သို့မဟုတ် {{key:Mod+,}}) ကို ဖွင့်ပြီး {{ui:MarkupCraft}} tab သို့ သွားပါ။
2. {{ui:Assistants}} အောက်တွင် **AI အကူအညီပေးသူများနှင့် script များကို MarkupCraft သုံးခွင့်ပေးပါ** ကို အမှန်ခြစ်ပါ။ သင်မလုပ်မချင်း ပိတ်ထားသည်။
3. ၎င်း လုပ်ခွင့်ရှိသည့်အရာကို ရွေးပါ: **ဖတ်ရန်** ကို စတင်ရန် အမှန်ခြစ်ထားသည်; **တည်းဖြတ်ရန်**၊ **သိမ်းရန်** သို့မဟုတ် **ထုတ်ရန်** ကို လိုအပ်မှသာ အမှန်ခြစ်ပါ။

သင် အမှန်ခြစ်ထားသော ခွင့်ပြုချက်အပြင် ကိရိယာများကို အကူအညီပေးသူသို့ မပေးပါ၊ ဖြစ်ချင်လည်း တောင်းဆိုပါက MarkupCraft က ငြင်းပြီး လုပ်ဆောင်ချက်မှတ်တမ်းတွင် ရေးထားသည်။ ခလုတ်ပိတ်ခြင်းက ချိတ်ဆက်မှုအားလုံးကို တစ်ပြိုင်နက် ရပ်စေသည်; {{ui:Reset MarkupCraft settings}} ကလည်း ၎င်းကို ပိတ်သည်။

## အကူအညီပေးသူကို ချိတ်ဆက်ရန်

အကူအညီပေးသူများသည် ကွန်ပျူတာပေါ်ရှိ **CadCraft Studio** မှတစ်ဆင့် ချိတ်ဆက်သည်: Studio က ဤကွန်ပျူတာသာ ဝင်နိုင်သော server ငယ်ကို လည်ပတ်စေပြီး စတင်တိုင်းတွင် ထုတ်ပေးသော token ဖြင့် ကာကွယ်သည်။ Studio တွင် {{ui:Connect an assistant}} ကို ရွေးပြီး လိပ်စာနှင့် token ကို အကူအညီပေးသူထဲ ကူးထည့်ပါ (ထည့်ရမည့် ဆက်တင်များကို Studio က ပြသည်)။ Token ကို ဘယ်တော့မှ မမျှဝေပါနှင့်။

:::note
ဘရောက်ဇာ tab သည် အကူအညီပေးသူအတွက် ချိတ်ဆက်မှု ဖွင့်၍ မရပါ: ဘရောက်ဇာ အက်ပ်များတွင် ခလုတ်သည် သင့်ကွန်ပျူတာပေါ်ရှိ CadCraft Studio ကို မသုံးမချင်း အကျိုးမရှိပါ။
:::

## သင်ကိုယ်တိုင် ထိန်းချုပ်ထားသည်

- **ပြောင်းလဲမှုတိုင်းသည် ပြန်ဖျက်ရန် အဆင့်တစ်ခု** ဖြစ်ပြီး အကူအညီပေးသူ၏ အမည်ဖြင့် အညွှန်းတပ်ထားသည် (ဥပမာ "Assistant: add cloudrect")။ {{key:Mod+Z}} သည် အကူအညီပေးသူ၏ နောက်ဆုံး ပြောင်းလဲမှုကို တစ်ခုလုံး ပြန်ယူသည်။
- **ချိတ်ဆက်ထားချိန်ကို သိနိုင်ပါသည်။** ထိပ်ဘားရှိ ခလုတ်တစ်ခုက ချိတ်ဆက်ထားစဉ် အကူအညီပေးသူ၏ အမည်ကို ဖော်ပြသည်; နှိပ်လျှင် ၎င်း ခွင့်ပြုထားသည်များကို ကြည့်နိုင်ပြီး သို့မဟုတ် **Disconnect** ဖြင့် ဖြတ်နိုင်သည်။
- **လုပ်ဆောင်ချက်။** {{ui:Settings}} › {{ui:MarkupCraft}} › {{ui:Assistants}} › {{ui:Activity}} သည် ခေါ်ဆိုမှုတိုင်းကို စာရင်းပြုသည်: အချိန်၊ ကိရိယာ၊ ပြီးခဲ့သည် သို့မဟုတ် ငြင်းခဲ့သည်။ {{ui:Save the log}} က မိတ္တူ ထိန်းသိမ်းသည်။

## အကူအညီပေးသူက တောင်းဆိုနိုင်သည်များ

| ကိရိယာ | ခွင့်ပြုချက် | ၎င်းလုပ်ဆောင်ပုံ |
|---|---|---|
| `app_info`၊ `sheets_list` | ဖတ်ရန် | ဖွင့်ထားသော အစုံများ၊ ၎င်းတို့၏ စာရွက်များနှင့် စာရွက်တစ်ခုစီတွင် မှတ်ချက် မည်မျှ ရှိသည် |
| `markups_list` | ဖတ်ရန် | အမျိုးအစား၊ စာရွက်၊ စာသား၊ မှတ်ချက်၊ တိုင်းတာမှု၊ အခြေအနေ၊ ရေးသားသူနှင့် ပြန်ကြားချက်များပါသော မှတ်ချက်များ၊ စာရွက်၊ အခြေအနေ၊ အမျိုးအစား သို့မဟုတ် ရေးသားသူအလိုက် စစ်ထုတ်သည် |
| `markup_add` | တည်းဖြတ်ရန် | စာရွက်တစ်ခုသို့ စတုဂံ၊ တိမ်၊ ellipse၊ စာသားအကွက်၊ မှတ်စု၊ မျဉ်း သို့မဟုတ် မြား ထည့်သည် |
| `markup_status`၊ `markup_reply` | တည်းဖြတ်ရန် | မှတ်ချက်၏ အခြေအနေ သတ်မှတ်သည် (ဆွေးနွေးမှုတွင် မှတ်တမ်းတင်ပြီး အကူအညီပေးသူ လက်မှတ်ထိုး); ဆွေးနွေးမှုသို့ မှတ်ချက် ထည့်သည် |
| `markups_export` | ထုတ်ရန် | {{ui:Markups}} စာရင်းပြသသည့်အတိုင်း CSV သို့မဟုတ် BCF (သင် သတ်မှတ်ထားသော စစ်ထုတ်မှုများဖြင့်); Studio တွင် သင်ခွင့်ပြုထားသော ဖိုင်တွဲသို့ ဖိုင်ရေးနိုင်သည် |
| `tasks_list` | ဖတ်ရန် | အလုပ်များဖြစ်သော မှတ်ချက်များ: တာဝန်ခံ (လူ သို့မဟုတ် အကူအညီပေးသူ)၊ သတ်မှတ်ရက်၊ အခြေအနေ၊ လင့်ခ်၊ ပိတ်ပုံ။ `assignee: "assistant"` သည် အကူအညီပေးသူအတွက် စောင့်နေသော အလုပ်များကို စာရင်းပြုသည် |
| `task_set`၊ `task_clear` | တည်းဖြတ်ရန် | မှတ်ချက်ကို အလုပ်အဖြစ် ပြုလုပ်ခြင်း သို့မဟုတ် ပြောင်းခြင်း (ခေါင်းစဉ်၊ တာဝန်ခံ၊ သတ်မှတ်ရက်၊ အခြေအနေ၊ လင့်ခ်); အလုပ်ကို ဖယ်ရှားသည် |
| `tasks_check` | တည်းဖြတ်ရန် | လင့်ခ်ထားသော ပုံဆွဲနေရာ သို့မဟုတ် မော်ဒယ် element အမှန်တကယ် ပြောင်းလဲသော အလုပ်များကို ပိတ်သည်; အခြားအက်ပ်မှ ဖတ်ထားသော element အခြေအနေများကို ပေးပါ |
| `revisions_changes` | ဖတ်ရန် | ဖွင့်ထားသော အစုံနှစ်ခုကြား ပြောင်းလဲချက်များ၏ ရိုးရှင်းသော စာရင်း၊ သင့်စကားဖြင့် ပြန်ပြောရန် |
| `pins_list`၊ `decision_add` | ဖတ်ရန်၊ တည်းဖြတ်ရန် | အသံမှတ်စုများ (အရှည်၊ ဘယ်သူ၊ ဘယ်အချိန်၊ စာတန်း၊ အသံ သို့မဟုတ် စာသား မပါ) နှင့် ဆုံးဖြတ်ချက်များ; ဆုံးဖြတ်ချက် ပင်ထိုးပြီး အရင်တစ်ခုကို အစားထိုးသည် |
| `redline_export`၊ `redline_answer` | ထုတ်ရန်၊ တည်းဖြတ်ရန် | ဒရာဖ်တာအတွက် redline ဖိုင် ရေးသည်; ဒရာဖ်တာ၏ အဖြေများကို ကျင့်သုံးသည် |

အကူအညီပေးသူ ထည့်သော မှတ်ချက်သည် ၎င်းကို ရေးသားသူအဖြစ် အမည်ပေးသည်: အကူအညီပေးသူ ပရိုဂရမ်က ကိုယ်တိုင်ပေးသော အမည်၊ နောက်တွင် "(assistant)" သို့မဟုတ် သင် သုံးသပ်သူအမည် သတ်မှတ်ပြီးနောက် "(assistant for <your name>)" ဖြစ်သည်။ ၎င်း၏ အခြေအနေ ပြောင်းလဲမှုများနှင့် ပြန်ကြားချက်များကလည်း အတူတူ လက်မှတ်ထိုးသည်။ တစ်ခုစီသည် ပြန်ဖျက်ရန် အဆင့်တစ်ခု။ PDF ကို သိမ်းခြင်းသည် သင့်တွင် ရှိနေဆဲ: ပုံမှန်အတိုင်း {{ui:Save}} ကို သုံးပါ။

MarkupCraft မဖွင့်ဘဲ CadCraft MCP server သည် သင်အမည်ပေးသော ဖိုင်တွဲရှိ PDF ၏ မှတ်ချက်များကို စာရင်းပြုသည် (`markups_list`), နှင့် `cadcraft info Set.pdf` သည် command line တွင် ၎င်းတို့ကို ထုတ်ပြသည်။

## တစ်ခုခု အလုပ်မလုပ်လျှင်

- **အကူအညီပေးသူက MarkupCraft ကိရိယာ မမြင်ပါ:** ဤဝင်းဒိုးတွင် ခလုတ် ဖွင့်ထားပြီး ဝင်းဒိုး Studio တွင် ဖွင့်ထားသည် ဟု စစ်ပါ။
- **"needs the edit permission":** {{ui:Assistants}} အောက်တွင် **တည်းဖြတ်ရန်** ကို အမှန်ခြစ်ပြီး ထပ်မေးပါ။
- **"401" သို့မဟုတ် "token" အမှားများ:** token ပြောင်းသွားသည် (Studio ပြန်စတင်ခဲ့ သို့မဟုတ် {{ui:New token}})။ အသစ်ကို အကူအညီပေးသူ ဆက်တင်တွင် ကူးထည့်ပါ။
