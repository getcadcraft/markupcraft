{{ui:Tools}} tab တွင် သင်၏ **ကိရိယာသေတ္တာ** ရှိသည်: ပုံစံနှင့်အတူ သိမ်းထားသော မှတ်ချက်များ၊ ပြန်ဆွဲရန် အဆင်သင့်။ ကိရိယာတစ်ခုသည် မှတ်ချက်၏ အမျိုးအစား၊ အရောင်၊ မျဉ်းအထူ၊ ဖြည့်စွက်မှု၊ အလင်းပေါ်မှု (opacity)၊ စာသားအရွယ်နှင့် အကြောင်းအရာကို ထိန်းသည်၊ တံဆိပ်စာသား၊ ရေတွက်အုပ်စုအမည် သို့မဟုတ် စာသားအကွက် သို့မဟုတ် callout ၏ စတင်စာသားကိုလည်း ထိန်းသည်။

## စတင်ရရှိသော ကိရိယာများ

ကိရိယာသေတ္တာအသစ်တွင် ခြောက်ခု ပါသည်: "Revision cloud" (အနီ), "Question cloud" (အပြာ), "Yellow highlighter", "RFI callout" (အပြာ၊ "RFI: " ဖြင့် စသည်), "Field verify" (လိမ္မော်ရောင် callout ဖြစ်ပြီး "Field verify." ဟု ရေးထားသည်) နှင့် "Approved as noted" (တံဆိပ်)။

## ကိရိယာဖြင့် ဆွဲရန်

1. {{ui:Tools}} tab ကို ဖွင့်ပါ။
2. ကိရိယာတစ်ခုကို နှိပ်ပါ။ ၎င်းသည် နှိပ်ထားဟု ပုံပေါ်ပြီး ကိုက်ညီသော toolbar ကိရိယာ ဖွင့်သွားသည်။
3. ပုံမှန်အတိုင်း ဆွဲပါ။ {{ui:Properties}} က 'Drawing with "<tool>" from the tool chest.' ဟု ပြသည်။

သေတ္တာကိရိယာ ဖွင့်နေစဉ် ဆွဲမီ {{ui:Properties}} တွင် ပြုလုပ်သော ပြောင်းလဲမှုများသည် ယခုအတွက် ထိုကိရိယာအပေါ် သက်ရောက်သည်၊ သိမ်းထားသော ကိရိယာ သို့မဟုတ် သင့်ပုံမှန်ကိရိယာ ဆက်တင်များကို မပြောင်းပါ။ toolbar ခလုတ်ကို ရွေးခြင်း သို့မဟုတ် ကိရိယာ၏ ကီးကို နှိပ်ခြင်းဖြင့် ရိုးရိုးကိရိယာသို့ ပြန်သွားသည်။

## ကိုယ်ပိုင် သိမ်းရန်

1. မှတ်ချက်တစ်ခု ဆွဲပြီး သင်လိုချင်သော ပုံစံ ချပါ: အရောင်၊ မျဉ်း၊ ဖြည့်စွက်မှု၊ အကြောင်းအရာ၊ တံဆိပ်စာသား။
2. ရွေးပါ။
3. {{ui:Tools}} tab တွင် {{ui:Save selected as a tool}} သို့မဟုတ် {{ui:Properties}} တွင် {{ui:Save as a tool}} ကို ရွေးပါ။
4. {{ui:Tool name}} ကို ရိုက်ပြီး {{ui:Save tool}} ကို ရွေးပါ။

ရလဒ်: ကိရိယာသည် သေတ္တာ၏ အဆုံးတွင် ထည့်ပြီး {{ui:Tools}} tab က ၎င်းကို ပြသရန် ဖွင့်သည်။

## ရွေးထားသည်မှ ပြုလုပ်သော တံဆိပ်များ

မှတ်ချက်အများအပြား (သို့မဟုတ် {{ui:Content}} ကိရိယာဖြင့် စာမျက်နှာအကြောင်းအရာ) ကို ရွေးပြီး {{ui:More}} တွင် သို့မဟုတ် ညာကလစ်မီနူးတွင် {{ui:Save selection as a stamp…}} ကို ရွေးပါ။ သေတ္တာတွင် ၎င်းတို့အားလုံးကို ပါဝင်သော တံဆိပ်တစ်ခု ရရှိသည် ("Stamp: 3 markups together")။ ၎င်းကို နှိပ်ပြီး မည်သည့်စာရွက်ပေါ်မဆို နှိပ်ပါ: မှတ်ချက်များသည် အတူတကွ၊ နှိပ်သော နေရာတွင် အလယ်ဗဟိုဖြင့် ကျရောက်ပြီး သင့်အမည်ဖြင့် မှတ်ချက်အသစ်များ ဖြစ်လာသည်; စာမျက်နှာအကြောင်းအရာကို ထိုနေရာတွင် စာမျက်နှာပေါ် ဆွဲသည်။ ဤတံဆိပ်များကို အခြားကိရိယာများကဲ့သို့ သိမ်းပြီး သေတ္တာနှင့် မျှဝေသည်။

## ကိရိယာ ဖယ်ရှားရန်

ကိရိယာ အတန်း၏ အဆုံးရှိ × ကို ရွေးပြီး {{ui:Remove}} ကို ရွေးပါ။ ၎င်းဖြင့် ဆွဲပြီးသား မှတ်ချက်များသည် ယခင်အတိုင်း ကျန်နေမည်။

## သေတ္တာကို သိမ်းထားသည့်နေရာ

သေတ္တာကို **ဤဘရောက်ဇာတွင်၊ ဤကွန်ပျူတာပေါ်တွင်** သိမ်းသည်။ အခြားဘရောက်ဇာ သို့မဟုတ် ကွန်ပျူတာတွင် ၎င်း၏ကိုယ်ပိုင် သေတ္တာ ရှိသည် (ခြောက်ခု ပုံသေဖြင့် စတင်သည်)၊ ကိုယ်ရေးဝင်းဒိုးက ပိတ်သည့်အခါ ၎င်းကို မေ့သွားသည်၊ ဘရောက်ဇာ ဆက်တင်တွင် ဤဆိုက်၏ဒေတာကို ရှင်းလျှင် ဖျက်သွားသည်။

ဘရောက်ဇာက သိမ်းခွင့် မပေးလျှင် (သိုလှောင်မှု ပိတ်ထား သို့မဟုတ် အပြည့်) အခြေအနေဘားက ပြောသည်: "The tool chest could not be kept in this browser (storage is off or full). Export it to keep it."

:::safari
Safari သည် ဆိုက်ကို အတော်ကြာ မသုံးလျှင် ဝက်ဆိုက်၏ သိမ်းထားသောဒေတာကို ရှင်းနိုင်သည်။ ထပ်မံ သွင်းနိုင်ရန် သင့်သေတ္တာကို အချိန်အခါအလိုက် ထုတ်ယူပါ။
:::

**သင့်သေတ္တာကို မိတ္တူအဖြစ် ထုတ်ယူပါ**၊ အထူးသဖြင့် အားကိုးရသော ကိရိယာများ ဖန်တီးပြီးနောက်။

## ရုံးနှင့် သေတ္တာ မျှဝေရန်

1. ကိရိယာများကို တစ်ကြိမ် ပြင်ဆင်ပါ။
2. {{ui:Export}} ကို ရွေးပါ။ "MarkupCraft tool chest.json" ရရှိမည်။
3. ထိုဖိုင်ကို ရုံးက စံနှုန်းများ ထားသည့်နေရာတွင် ထားပါ၊ သို့မဟုတ် ပို့ပါ။
4. အခြားသူအားလုံးက ၎င်းတို့၏ {{ui:Tools}} tab တွင် {{ui:Import}} ကို ရွေးပြီး ဖိုင်ကို ရွေးပါ။

ရလဒ်: "Imported 12 tools from "MarkupCraft tool chest.json"." တူညီသော သေတ္တာမှ ကိရိယာများသည် ၎င်းတို့၏ ဟောင်းမိတ္တူများကို အစားထိုးသည်၊ ထို့ကြောင့် အပ်ဒိတ်ထားသော ရုံးသေတ္တာကို သွင်းလျှင် ကိရိယာများကို ပွားမည့်အစား ပြန်လန်းစေသည်; ကိရိယာအသစ်များ ထည့်သည်။ သေတ္တာတစ်ခုတွင် ကိရိယာ 500 အထိ ထည့်နိုင်သည်။

MarkupCraft က သွင်းသော ဖိုင်ရှိ တန်ဖိုးတိုင်းကို စစ်ဆေးပြီး အသုံးမပြုနိုင်သည်များကို ကျော်သည် ("2 skipped (not usable)")။ သေတ္တာ မဟုတ်သော ဖိုင်များကို ငြင်းပယ်သည်: "This file is not a MarkupCraft tool chest." သို့မဟုတ် "This file is not a tool chest (it is not JSON)."

အခြား မှတ်ချက်ပရိုဂရမ်များမှ ကိရိယာသေတ္တာဖိုင်များကို သွင်း၍ မရပါ။
