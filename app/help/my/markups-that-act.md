တာဝန်ဆိုသည်မှာ တစ်စုံတစ်ဦးက လုပ်ရမည့် markup ဖြစ်သည်။ ၎င်းသည် စာရွက်ပေါ်ရှိ နေရာနှင့် ၎င်း၏ thread ကို ထိန်းထားပြီး ခေါင်းစဉ်၊ တာဝန်ခံ၊ နောက်ဆုံးရက်၊ အခြေအနေနှင့် သင်လိုလျှင် ၎င်းနှင့် ဆိုင်သော ပုံဆွဲ သို့မဟုတ် မော်ဒယ် element သို့ link တစ်ခုကို ထည့်သည်။

## တာဝန်တစ်ခု ပြုလုပ်ခြင်း

1. markup တစ်ခု သို့မဟုတ် ပိုများကို ရွေးပါ။
2. {{ui:Tasks}} tab ကို ဖွင့်ပြီး {{ui:Make selected a task}} ကို ရွေးပါ။
3. ခေါင်းစဉ်ကို ဖြည့်ပါ (markup ၏ စာသားမှ စတင်သည်)၊ ဘယ်သူအတွက်လဲ ({{ui:Person}} သို့မဟုတ် {{ui:Assistant}}၊ နှင့် အမည်)၊ ရွေးချယ်စရာ နောက်ဆုံးရက်တစ်ခု၊ နှင့် ဘာကို စောင့်ကြည့်မလဲ ကို ဖြည့်ပါ။

အကူအညီပေးသူ တာဝန်သည် MarkupCraft သို့ ချိတ်ဆက်ထားသော AI အကူအညီပေးသူအတွက် အလုပ်ဖြစ်သည် (see [Use MarkupCraft with an AI assistant](topic:use-with-ai-assistants))။ MarkupCraft တွင် ကိုယ်ပိုင် အကူအညီပေးသူ မပါပါ: ၎င်းသည် အလုပ်များကို စာရင်းပြုပြီး အကူအညီပေးသူ၏ အဖြေများကို လက်ခံသည်သာ။ {{ui:Assigned to}} ကို ရွေးပြီးနောက် စာရင်းထဲမှ {{ui:Assistant}} ကို ရွေးပါက ၎င်းအတွက် စောင့်နေသော အရာများကို ပြသည်။

## ပြောင်းလဲမှုကို စောင့်ကြည့်ခြင်း

- **markup အတွင်းရှိ ပုံဆွဲ။** MarkupCraft သည် markup ၏ အကွက်အတွင်းရှိ မျဉ်းများကို လက်ရှိအတိုင်း ထိန်းထားသည်။ ထိုအကွက်ရှိ ဧရိယာတွင် မျဉ်းများ တစ်ရွဲ့ထက် ပိုကွဲပြားလျှင် (ပုံဆွဲ၏ ထိုဧရိယာ၌ ပြောင်းလဲမှု) စာရွက်ဖြစ်ပါက၊ ဖွင့်ထားသော စာရွက်၏ ပုံမှန် revision အသစ် (စာရွက်နံပါတ် တူသော ဒုတိယ ဖိုင်၊ သို့မဟုတ် တူညီသော စာမျက်နှာ နေရာ) ကို ဖွင့်လိုက်သောအခါ {{ui:Check now}} ကို ရွေးပါ: ထိုဧရိယာ၏ မျဉ်းများ ဆံပင်ထက် ပိုကွဲလျှင် တာဝန်ကို ပိတ်သည်။
- **မော်ဒယ် element။** အက်ပ်နှင့် element ၏ id ကို ပေးပါ။ သင့်အကူအညီပေးသူသည် အခြား အက်ပ်၏ ကိုယ်ပိုင် tools ဖြင့် element ကို ဖတ်ပြီး `tasks_check` ဖြင့် အစီရင်ခံသည်။ ပထမ အစီရင်ခံချက်ကို စတင်အခြေအနေအဖြစ် သိမ်းသည်; နောက်ပိုင်း ကွဲပြားသော အစီရင်ခံချက်သည် တာဝန်ကို ပိတ်သည်။ ဖျက်ပြီးသော element သည်လည်း ပိတ်စေသည်။
- **ဘာမှ မရှိ။** သင် လက်ဖြင့် ပြီးစီးစေသော ရိုးရိုး တာဝန်။

ပိတ်ထားသော တာဝန်ကို Done ဟု မှတ်ပြီး ၎င်း၏ markup သည် Completed ဖြစ်လာပြီး thread ရှိ မှတ်စုတစ်ခုက ဘာပြောင်းလဲသွားသည်ကို ပြောသည်။ undo အဆင့် တစ်ခုဖြင့် ပြန်ဖွင့်နိုင်သည်။

**ကန့်သတ်ချက်:** စစ်ဆေးမှုသည် revision အသစ်သည် စာမျက်နှာ မူလနေရာနှင့် စာမျက်နှာ အရွယ်အစား တူသည်ဟု ယူဆသည်။ အခြား အရွယ်အစားဖြင့် ပြန်ထုတ်ထားသော စာရွက်သည် မကိုက်ညီဘဲ၊ ၎င်း၏ တာဝန်များ ပိတ်မည်မဟုတ်ပါ။ စာရွက်များကို စာရွက်နံပါတ်ဖြင့်၊ မရှိလျှင် စာမျက်နှာ နေရာဖြင့် တွဲသည်; MarkupCraft သည် revision တစ်ခုကို အခြားတစ်ခုနှင့် ကိုက်ညီစေရန် အရွယ်အစား မပြောင်းပါ။

တူညီသော ပုံဆွဲကို ရက်စွဲ တံဆိပ်အသစ်ဖြင့် ပြန်ထုတ်ခြင်း၊ သို့မဟုတ် မျဉ်းများ 1.5 point အောက် ရွှေ့ခြင်းသည် ပြောင်းလဲမှုအဖြစ် မရေတွက်ပါ။ revision အသစ် ဖွင့်မထားလျှင် တာဝန်သည် ဖွင့်ထားဆဲဖြစ်ပြီး status bar က ထိုအကြောင်း ပြောသည်။

## စာရင်း

{{ui:Tasks}} စာရင်းကို အခြေအနေနှင့် ဘယ်သူအတွက်လဲ (၎င်းတွင် {{ui:Overdue}} ပါ) ဖြင့် စစ်ထုတ်နိုင်သည်။ နောက်ဆုံးရက် ကျော်လွန်သော တာဝန်သည် Problems panel တွင် သတိပေးချက်အဖြစ် ပေါ်သည်။ {{ui:CSV}} သည် စာရင်းကို ထုတ်ယူသည်။

တာဝန်များကို markup နှင့်အတူ PDF တွင် သိမ်းပြီး၊ အခြား markup ဂုဏ်သတ္တိများကဲ့သို့ Live မှတဆင့် သွားလာသည်။
