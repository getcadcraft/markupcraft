## စာရင်းကို ဖွင့်ခြင်း

ညာဘက်ရှိ {{ui:Markups}} tab ကို ရွေးပါ။ ဖွင့်ထားသော ဖိုင်တိုင်း၏ markup အားလုံးကို စာရွက်အစဉ်အလိုက်နှင့် ပြုလုပ်ခဲ့သော အစဉ်အလိုက် စာရင်းပြုသည်။ အတန်းတစ်ခုစီတွင် ပြသသည်:

- markup ၏ အရောင်ဖြင့် အိုင်ကွန်၊ ရှိပါက punch နံပါတ် ("#4")၊ နှင့် ၎င်း၏ subject၊
- ၎င်း၏ စာသား၊ တံဆိပ်စာသား သို့မဟုတ် တိုင်းတာထားသော တန်ဖိုး၊ နှင့် comment၊
- စာရွက်၊ ရေးသားသူနှင့် ရက်စွဲ၊
- status (သို့မဟုတ် ဖိုင်နှင့်အတူ လာသော မှတ်ချက်များအတွက် "Read-only") နှင့် ပြန်ကြားချက်များ ရှိပါက ၎င်းတို့၏ အရေအတွက်။

စာရင်းအပေါ်ရှိ စာကြောင်းသည် ၎င်းတို့ကို ရေတွက်ပေးသည်: "38 markups" သို့မဟုတ် စစ်ထုတ်ထားပါက "12 of 38 markups"။

## markup တစ်ခုသို့ ခုန်သွားခြင်း

အတန်းတစ်ခုကို click လုပ်ပါ။ MarkupCraft သည် ထိုစာရွက်ကို ပြပြီး markup ကို ရွေးကာ၊ မြင်ကွင်းပြင်ပ သို့မဟုတ် မြင်ရန် သေးလွန်းလျှင် ချဲ့ပေးသည်။ {{ui:Properties}} tab သို့ ပြန်သွားသောအခါ ၎င်း၏ အသေးစိတ်နှင့် thread ကို မြင်ရမည်။

## စစ်ထုတ်ခြင်း

စာရင်းအပေါ်ရှိ မီနူးလေးခု။ ၎င်းတို့ ပေါင်းစပ်အလုပ်လုပ်သည်။

| မီနူး | ရွေးချယ်စရာများ |
|---|---|
| {{ui:Sheet}} | All sheets၊ This sheet (စာရွက်ပြောင်းသည်နှင့် လိုက်ပြောင်းသည်)၊ သို့မဟုတ် markup ရှိသော စာရွက် မည်သည့်အရာမဆို |
| {{ui:Author}} | Anyone၊ သို့မဟုတ် အစုထဲရှိ ရေးသားသူတစ်ယောက်စီ |
| {{ui:Status}} | Any status၊ Open၊ Accepted၊ Rejected၊ Completed |
| {{ui:Type}} | Any type၊ သို့မဟုတ် အစုထဲရှိ markup အမျိုးအစားတစ်ခုစီ |

ဥပမာများ:

- ဤစာရွက်တွင် ဘာများ ဆက်ဖွင့်ထားသေးသလဲ: {{ui:Sheet}} "This sheet", {{ui:Status}} "Open"။
- တိုင်ပင်ခံတစ်ဦး၏ မှတ်ချက်များ: {{ui:Author}} ၏ အမည်။
- တိုင်းတာမှုအားလုံး: {{ui:Type}} "Length" သို့မဟုတ် "Area"။

စာရင်းသည် အတန်း 2000 အထိ ပြသသည်; အလွန်ကြီးသော အစုများတွင် စစ်ထုတ်ခြင်းဖြင့် ကျဉ်းအောင်လုပ်ပါ။

## CSV သို့ ထုတ်ခြင်း

tab ၏ အပေါ်ရှိ {{ui:CSV}} ကို ရွေးပါ။ "<name> markups.csv" ကို ရရှိမည်၊ **လက်ရှိ စစ်ထုတ်ထားသည့်အတိုင်း markup များ** ပါ၊ တစ်ကြောင်းလျှင် တစ်ခု၊ ဤကော်လံများနှင့်အတူ:

Punch no., Sheet, File, Page, Type, Subject, Text, Comment, Measurement, Author, Created, Modified, Status, Replies, Last reply, Color, Read-only။

- "Text" တွင် text box နှင့် callout များ၏ စကားလုံးများ၊ တံဆိပ်၏ စာသား သို့မဟုတ် count အုပ်စု၏ အမည် ပါဝင်သည်။
- "Measurement" တွင် အလျားများ၊ ဧရိယာများအတွက် "area, perimeter" နှင့် count များအတွက် "group: n" ပါဝင်သည်။
- ရက်စွဲများသည် UTC ဖြင့် အပြည့်အစုံ timestamp ဖြစ်သည်။

အားလုံးကို ထုတ်ယူလိုပါက စစ်ထုတ်မှုအားလုံးကို ပထမ ရွေးချယ်စရာသို့ ပြန်သတ်မှတ်ပါ။

## စာရွက်ပေါ်ရှိ legend

{{ui:Markups}} tab ရှိ {{ui:Legend}} သည် သင်မြင်နေသော အပေါ်ညာဘက်ထောင့်တွင် legend တစ်ခု ထားသည်: စာရွက်ပေါ်ရှိ markup အမျိုးအစားတစ်ခုစီကို (subject နှင့် အရောင်ဖြင့်၊ ဥပမာ "Cloud"၊ "Question" သို့မဟုတ် "Outlets") ၎င်းတို့ အရေအတွက်နှင့်အတူ စာရင်းပြသော အကွက်တစ်ခု။ count အုပ်စုတစ်ခုသည် ၎င်း၏ အမှတ်များကို ရေတွက်သည်။ legend သည် သင် ဆွဲ၊ ရွှေ့၊ သို့မဟုတ် ဖျက်နေစဉ် ဆက်ရေတွက်ပြီး ပရင့်ထုတ်ချိန်နှင့် သိမ်းချိန်၏ အရေအတွက်ဖြင့် ပရင့်/သိမ်းသည်။

ဖြတ်ခြင်း၊ ပုံမှန် markup ကဲ့သို့ ရွှေ့ပြီး အရွယ်အစား ပြောင်းပါ။ ၎င်း၏ {{ui:Properties}} တွင် {{ui:Title}} ကို ပြောင်းပါ၊ သို့မဟုတ် {{ui:Counts}} ကို {{ui:The whole set}} သို့ သတ်မှတ်ပြီး စာရွက်အားလုံးကို ရေတွက်ပါ။ space များ၊ အခြား legend များနှင့် အခြား programs ၏ မှတ်ချက်များကို ရေမတွက်ပါ။

## သင်၏ကိုယ်ပိုင် ကော်လံများနှင့် စီခြင်း

{{ui:Markups}} tab ရှိ {{ui:Columns}} သည် markup တိုင်းသို့ ကိုယ်ပိုင် ကော်လံများ ထည့်သည်: **စာသား**၊ **ရွေးချယ်မှု** (ဥပမာ Trade: Mechanical, Electrical, Plumbing)၊ **နံပါတ်** (ဥပမာ Cost) သို့မဟုတ် **ရက်စွဲ**။ တစ်ခုစီကို အမည်ပေးပါ၊ အမျိုးအစား ရွေးပါ၊ ရွေးချယ်မှု ကော်လံအတွက် ရွေးချယ်စရာများကို စာရင်းပြုစုပြီး {{ui:Save columns}} ကို ရွေးပါ။

- {{ui:Properties}} အောက်တွင် ဖြည့်ပါ: ကော်လံတိုင်းတွင် ထိုနေရာ၌ အကွက်ရှိသည်။ နံပါတ် ကော်လံသည် နံပါတ်များသာ လက်ခံပြီး ရက်စွဲ ကော်လံသည် ရက်စွဲသာ လက်ခံသည်။
- စာရင်းသည် markup တစ်ခုစီအောက်ရှိ တန်ဖိုးများကို ပြသသည်၊ {{ui:Column}} စစ်ထုတ်မှုသည် တန်ဖိုးတစ်ခု (သို့မဟုတ် ၎င်း ဗလာဖြစ်သော markup များ) ကို ရွေးသည်၊ နှင့် {{ui:Sort}} သည် စာရင်းကို စာရွက်အလိုက်အစား ကော်လံတစ်ခု၊ ရေးသားသူ၊ status၊ အမျိုးအစား သို့မဟုတ် ရက်စွဲအလိုက် စီသည်။
- CSV နှင့် XLSX ထုတ်ယူမှုများသည် ပုံမှန်ကော်လံများနောက်တွင် သင့်ကိုယ်ပိုင် ကော်လံများကို ပါစေသည်။ ကော်လံများကို PDF နှင့်အတူ သိမ်းပြီး ပြန်ဖွင့်သည့်အခါ ပြန်ရောက်လာသည်။

## အနှစ်ချုပ် ထုတ်ရန်: workbook သို့မဟုတ် PDF

- {{ui:XLSX}} သည် "<name> markup summary.xlsx" ကို ဒေါင်းလုဒ်လုပ်ပြီး စာရွက်သုံးရွက် ပါစေသည်: **Markups** (ပြသထားသော markup တစ်ခုလျှင် အတန်းတစ်ခု၊ CSV နှင့် တူညီသော ကော်လံများ)၊ **By sheet** (စာရွက်တစ်ခုစီတွင် markup မည်မျှ ရှိသည်၊ ဖွင့်ထား/ပိတ်ထား၊ နှင့် အမျိုးအစား တစ်ခုစီ မည်မျှ၊ စုစုပေါင်းများနှင့်တကွ) နှင့် **Punch list** (punch item များ ရှိသောအခါ)။
- {{ui:PDF}} သည် "<name> markup summary.pdf" ကို ဒေါင်းလုဒ်လုပ်သည်: ပရင့်ထုတ်ရန် သို့မဟုတ် ပို့ရန် အစီရင်ခံစာ၊ အစုအမည်၊ ရက်စွဲနှင့် ပြထားသော markup များ၏ ဇယား (နံပါတ်၊ စာရွက်၊ အမျိုးအစား၊ subject၊ စာသား သို့မဟုတ် comment၊ တိုင်းတာထားသော တန်ဖိုး၊ ရေးသားသူ၊ status နှင့် နောက်ဆုံး ပြန်ကြားချက်)။ ရှည်သော စာသားများ ခေါက်သွားပြီး ဇယား ခေါင်းစီးသည် စာမျက်နှာတိုင်းတွင် ပြန်ထပ်သည်။

နှစ်ခုစလုံးသည် စစ်ထုတ်ထားသည့်အတိုင်း စာရင်းကို ယူသည်၊ ထို့ကြောင့် စာရွက်တစ်ခု၊ ရေးသားသူတစ်ဦး သို့မဟုတ် ဖွင့်ထားသော အရာများကိုသာ အစီရင်ခံရန် ဦးစွာ စစ်ထုတ်ပါ။

## BCF သို့ ထုတ်ခြင်း

{{ui:BCF}} ကို ရွေးပါ။ MarkupCraft သည် ပြထားသော markup တစ်ခုစီ၏ ပုံရိပ်ကို ၎င်း၏ စာရွက်ပေါ်တွင် ရိုက်ယူသည် ("Making snapshots for BCF (3 of 12)…") ထို့နောက် "<name> markups.bcfzip" ကို ဒေါင်းလုဒ်လုပ်သည်။ markup တစ်ခုစီသည် BCF topic တစ်ခု ဖြစ်လာပြီး status၊ ရေးသားသူ၊ ရက်စွဲများ၊ ပြန်ကြားချက်များကို comment အဖြစ်၊ punch item မှ တာဝန်ခံနှင့် နောက်ဆုံးရက်၊ နှင့် snapshot ကို ပါစေသည်။

ပုံဆွဲပြန်လည်သုံးသပ်ချက် comment များကို BCF ဖတ်နိုင်သော BIM coordination tool များသို့ ယူသွားရန် သုံးပါ။ ကူးယူနိုင်သည်နှင့် မကူးယူနိုင်သည်များကို [BCF basics](topic:bcf-basics) တွင် ဖော်ပြထားသည်။

## BCF သွင်းခြင်း

{{ui:Import BCF}} သည် BIM tool မှ .bcfzip (သို့မဟုတ် .bcf) ဖိုင်ကို ဖတ်သည်:

- MarkupCraft ၏ကိုယ်ပိုင် BCF ထုတ်ယူမှုမှ ထွက်လာသော issue များသည် ၎င်းတို့၏ markup များကို ပြန်ရှာတွေ့သည်: ပြန်ကြားချက်အသစ်များကို thread သို့ ထည့်သည်၊ status အသစ် (Closed သည် Completed ဟု ရေတွက်သည်) ကို သတ်မှတ်သည်။ ရှိပြီးသား ပြန်ကြားချက်များကို နှစ်ခါ မထည့်ပါ။
- အခြား issue များသည် note များ ဖြစ်လာသည်၊ ၎င်းတို့၏ ခေါင်းစဉ်၊ ဖော်ပြချက်၊ ရေးသားသူနှင့် comment များပါဝင်သည်။ note တစ်ခုသည် issue ၏ label များက ပေးသော စာရွက်နံပါတ် သို့မဟုတ် အမည်ရှိ စာရွက်ပေါ်တွင် ရောက်သည်၊ မဟုတ်ပါက ဖွင့်ထားသော စာရွက်ပေါ်တွင်; BIM camera သည် စက္ကူပေါ်တွင် နေရာမရှိသောကြောင့် ထိုသို့ note များကို စာရွက်၏ ဘယ်ဘက်အပေါ်ထောင့်တွင် စုပုံထားပြီး သင် ရွှေ့ရန် ထားသည်။

သွင်းခြင်း တစ်ခုလုံးသည် အဆင့်တစ်ဆင့်သာ ဖြစ်သည်: {{key:Mod+Z}} ဖြင့် ပြန်ယူနိုင်သည်။ see [BCF basics](topic:bcf-basics)။

## စာရင်းမလုပ်နိုင်သေးသည်များ

- စာရင်းကို အုပ်စုဖွဲ့ခြင်း (စီပြီးနောက် စစ်ထုတ်ပါ အစား)။
- စာရင်းထဲတွင် တန်ဖိုးများ တည်းဖြတ်ခြင်း (တည်းဖြတ်ရန် {{ui:Properties}} တွင်; punch အကွက်များကို {{ui:Punch list}} tab တွင် တည်းဖြတ်နိုင်သည်)။
