Plan set တစ်ခုသည် discipline တစ်ခုအတွက် PDF တစ်ခု သို့မဟုတ် စာရွက်တစ်ရွက်အတွက် PDF တစ်ခုအဖြစ် ရောက်လာလေ့ရှိပါသည်။ MarkupCraft သည် သင်ဖွင့်သမျှကို **set တစ်ခု** အဖြစ် သတ်မှတ်ပါသည်။

## အတူတကွ ဖွင့်ခြင်း

ဖိုင်ရွေးချယ်ကိရိယာတွင် PDF အားလုံးကို တစ်ကြိမ်တည်း ရွေးပါ၊ သို့မဟုတ် စာရွက်နယ်ပယ်ပေါ် အားလုံးကို ချပါ။ နောက်ပိုင်း ထပ်ထည့်လိုပါက တူညီသောနည်းဖြင့် ဖွင့်ပါ၊ ၎င်းတို့သည် ဖွင့်သော အစီအစဉ်အတိုင်း {{ui:Sheets}} list ၏ အဆုံးတွင် ပေါင်းပါမည်။

ရလဒ်: "ဖိုင် 6 ခု ဖွင့်ပြီး (set တွင် စာရွက် 84 ရွက်)။" စာမျက်နှာတိုင်းသည် စာရွက်တစ်ရွက် ဖြစ်ပါသည်။ စာရွက်နံပါတ်ရှိသော စာရွက်များသည် အမည်အောက်တွင် "Sheet A-101" ကို ပြပြီး အခြားများက ဖိုင်နှင့် စာမျက်နှာကို ပြပါသည်။

"Set" ဖိုင်ဟူ၍ သိမ်းထားသည် မရှိပါ: နောက်တစ်ကြိမ် PDF တူညီသည်များကို ပြန်ဖွင့်ပါ (သိမ်းထားပါက "(marked up)" မိတ္တူများကို)။

## Set တစ်ခုလုံးအတွက်

- **စာရွက်ရှာရန်:** {{ui:Search sheets}} သည် ဖိုင်အားလုံး၏ စာရွက်နံပါတ်များ၊ စာရွက်အမည်များနှင့် ဖိုင်အမည်များကို ရှာပါသည်။ {{key:PageUp}} နှင့် {{key:PageDown}} သည် ဖိုင်အားလုံး၏ စာရွက်အားလုံးကို အစီအစဉ်အတိုင်း သွားပါသည်။
- **Markups list:** {{ui:Markups}} tab သည် ဖိုင်အားလုံးမှ မှတ်ချက်များကို ဖော်ပြပါသည်။ {{ui:Sheet}} ဖြင့် စစ်ထုတ်၍ ကျဉ်းနိုင်ပါသည်။ CSV တွင် File column ရှိပါသည်။
- **Punch list:** set တစ်ခုလုံးအတွက် နံပါတ်တစ်ခုတည်း။
- **နှိုင်းယှဉ်ခြင်း:** ဟောင်းနှင့် သစ်စာရွက်များသည် ဖိုင်မတူညီသော ဖိုင်များမှ ဖြစ်နိုင်ပါသည်။
- **ကူးခြင်းနှင့် ကူးထည့်ခြင်း:** စာရွက်တစ်ရွက်တွင် {{key:Mod+C}} နှင့် အခြားစာရွက်တစ်ရွက်တွင် {{key:Mod+V}} ကို ဖိုင်မည်သည့်ဖိုင်တွင်မဆို လုပ်နိုင်ပါသည်။ မိတ္တူသည် စာမျက်နှာပေါ် တူညီနေရာတွင် အနည်းငယ် offset ဖြင့် ကျရောက်ပါသည်။

## သိမ်းခြင်း

{{ui:Save}} ကို ရွေးပါ။ ဖိုင်တစ်ခုထက်ပို ဖွင့်ထားပါက MarkupCraft က မေးပါမည်:

- {{ui:This file}}: သင်ရှိနေသော စာရွက်၏ ဖိုင်၏ မှတ်ချက်ပါ မိတ္တူ။
- {{ui:Every changed file}}: မသိမ်းရသေးသော ပြောင်းလဲမှုရှိသည့် ဖိုင်တိုင်း၏ မိတ္တူ။ တစ်ခုစီသည် "<file name> (marked up).pdf" ဖြင့် သီးခြား ဒေါင်းလုဒ်လုပ်ပါမည်။
- {{ui:Cancel}}

:::chromium
ဖိုင်များစွာကို တစ်ပြိုင်နက် ပထမဆုံး သိမ်းသောအခါ Chrome နှင့် Edge က ဤဆိုဒ်သည် ဖိုင်အများအပြား ဒေါင်းလုဒ်လုပ်ခွင့်ရှိမရှိ မေးနိုင်ပါသည်။ {{ui:Allow}} ကို ရွေးပါ၊ မဟုတ်ပါက ပထမမိတ္တူသာ ရောက်ပါမည်။
:::

:::safari
Safari သည် ဖိုင်တစ်ခုစီအတွက် တစ်ကြိမ်စီ မေးနိုင်ပါသည်။ iPad တွင် မိတ္တူတိုင်းသည် Files app သို့ သွားပါသည်။
:::

မှတ်ချက်များ သိမ်းပြီးသော ဖိုင်သည် ပြောင်းလဲထားသည်ဟု မရေတွက်တော့ပါ၊ အခြားများက ဆက်ရေတွက်ပါသည်။

CSV၊ BCF နှင့် punch list export များကို သင်ဖွင့်ထားသော **ပထမ** ဖိုင်၏ အမည်ဖြင့် အမည်ပေးပါသည်။

## ပိတ်ခြင်း

{{ui:Close}} သည် set တစ်ခုလုံးကို ပိတ်ပါသည်၊ ဖိုင်တစ်ခုတည်းကို ယခုအချိန်တွင် ပိတ်၍မရပါ။ မသိမ်းရသေးသည် ရှိပါက မေးပါသည်:

- {{ui:Cancel}}: ဘာမျှမဖြစ်ပါ။
- {{ui:Close without saving}}: မသိမ်းရသေးသော မှတ်ချက်များ ပျောက်ပါမည်။
- {{ui:Save copies first}}: ပြောင်းလဲထားသော ဖိုင်အားလုံးကို သိမ်းပြီး ပိတ်ပါမည်။

ပိတ်ခြင်းသည် undo history ကိုလည်း ရှင်းပါသည်။

## အရွယ်ကြီး set များ

- စာမျက်နှာတိုင်း၏ စာသားကို ဖွင့်သောအခါ ဖတ်ပြီး စာရွက်နံပါတ်များကို ရှာပါသည်၊ ထို့ကြောင့် စာရွက် 100 ရှိသော set သည် အချိန်အနည်းငယ် ကြာပါမည်။ Status bar က သွားသည်နှင့်အမျှ စာရွက်များကို ရေတွက်ပါသည်။
- List ရှိ စာရွက်ပုံများကို ဆင်းသွားသည်နှင့်အမျှ ဆွဲပါသည်။
- ဖွင့်ထားသော PDF တစ်ခုစီသည် browser tab ၏ memory တွင် ရှိပါသည်။ tab နှေးလာပါက အခြား လေးလံသော tabs များကို ပိတ်ပါ၊ သို့မဟုတ် discipline တစ်ခုချင်းစီ သုံးသပ်ပါ။
- တူညီသော ဖိုင်ကို နှစ်ကြိမ်ဖွင့်ပါက ၎င်း၏ စာရွက်များ နှစ်စုရရှိပါမည်။ ထိုသို့ဖြစ်ပါက {{ui:Close}} ကို ရွေးပြီး set ကို ပြန်ဖွင့်ပါ။
