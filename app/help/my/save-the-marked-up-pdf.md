## သိမ်းရန်

1. တူးလ်ဘားရှိ {{ui:Save}} ကို ရွေးပါ၊ သို့မဟုတ် {{key:Mod+S}} ကို နှိပ်ပါ။
2. ဖိုင်အများအပြား ဖွင့်ထားလျှင် {{ui:This file}} (သင်ရှိနေသော စာရွက်၏ ဖိုင်) သို့မဟုတ် {{ui:Every changed file}} ကို ရွေးပါ။ မိတ္တူတစ်ခုစီကို သီးခြား ဒေါင်းလုဒ်လုပ်ပါမည်။
3. "Saving <file>…" ပြီးသည်အထိ စောင့်ပါ။ session တစ်ခုတွင် ပထမဆုံး သိမ်းချက်သည် PDF writer ကိုလည်း တင်ပါသည်။

ရလဒ်: သင့် browser က "<name> (marked up).pdf" ကို ဒေါင်းလုဒ်လုပ်ပြီး status bar တွင် ဤသို့ ပြပါသည်: 'သိမ်းပြီး A-Plans (marked up).pdf (မှတ်ချက် 24 ခု, 18.2 MB)။ မူရင်းဖိုင် မပြောင်းလဲပါ။' {{ui:Save}} နောက်ရှိ အစက် ပျောက်သွားပါမည်။

**မူရင်း PDF ကို ဘယ်တော့မှ မပြောင်းလဲပါ။** MarkupCraft က ဖိုင်အသစ်တစ်ခု ရေးပါသည်။ ၎င်းရောက်ရှိမည့်နေရာသည် သင့် browser ၏ ဒေါင်းလုဒ် ဆက်တင်များပေါ် မူတည်ပါသည် (see [Files MarkupCraft opens and saves](topic:files#where-downloads-go))။

## နောက်မှ ဆက်လုပ်ရန်

နောက်တစ်ကြိမ် မူရင်းမဟုတ်ဘဲ "(marked up)" မိတ္တူကို ဖွင့်ပါ။ အရာအားလုံး ပြန်လည် တည်းဖြတ်နိုင်ပါမည်: မှတ်ချက်များ၊ status များ၊ replies များ၊ punch items များ၊ စာရွက်တစ်ခုစီ၏ scale နှင့် သင်ရိုက်ထားသော စာရွက်အမည်များ။ ထပ်သိမ်းပါက တူညီသော "(marked up)" အမည်ဖြင့် ဖိုင်ကို ဒေါင်းလုဒ်လုပ်ပါမည်။ အဟောင်း download ကို ဖိုဒါတွင် ကျန်နေပါက browser က "(1)" ကဲ့သို့ နံပါတ် ထပ်ထည့်နိုင်ပါသည်။ အဟောင်း မိတ္တူများကို သင်ကိုယ်တိုင် အစားထိုး သို့မဟုတ် ရှင်းလင်းပါ။

MarkupCraft သည် PDF ကို အလိုအလျောက် မသိမ်းပါ။ သင် အလုပ်လုပ်နေစဉ် ဤ browser တွင် recovery မိတ္တူတစ်ခု ထားရှိပါသည်၊ ထို့ကြောင့် crash ဖြစ်ခြင်း သို့မဟုတ် tab ပိတ်ခြင်းကြောင့် မှတ်ချက်များ မပျောက်ပါ။ နောက်တစ်ကြိမ် MarkupCraft ကို ဖွင့်သောအခါ "သင့်အလုပ်ကို ပြန်ယူမလား?" ဟု မေးပါမည်။ See [Recover your work](common:recover)။ ပိတ်ခင် သိမ်းပါ။ သိမ်းမထားသော မှတ်ချက်များဖြင့် ထွက်ရန်ကြိုးစားပါက browser က ပထမဦးစွာ "ဆိုဒ်မှ ထွက်မလား?" ဟု မေးပါမည် (iPad Safari တွင် မမေးပါ)။

## အခြား PDF ဖတ်ကိရိယာများက ဘာမြင်သလဲ

မှတ်ချက်တစ်ခုစီကို ကိုယ်ပိုင်ပုံဆွဲချက်ဖြင့် စံ PDF comment (annotation) အဖြစ် ရေးပါသည်။ ထို့ကြောင့် မည်သည့် PDF viewer မဆို ပြသနိုင်၊ ပရင့်ထုတ်နိုင်ပြီး comments panel တွင် ဖော်ပြနိုင်ပါသည်:

- **ပုံစံသည် MarkupCraft နှင့် တူညီပါသည်**: scallops ပါသော cloud များ၊ arrowheads၊ stamps၊ count dots၊ punch number badges၊ measurement labels။
- **အသေးစိတ်များသည် စံဖြစ်ပါသည်**: author၊ date၊ subject၊ comment စာသားနှင့် အရောင်များ။
- **Clouds** များသည် မျဉ်းကွေးနယ်နိမိတ်ပါသော rectangle သို့မဟုတ် polygon comments ဖြစ်ပါသည်။ **text boxes** နှင့် **callouts** သည် text box comments ဖြစ်ပါသည်။ **notes** များသည် sticky notes ဖြစ်ပါသည်။ **pen** နှင့် **highlighter** အစင်းများသည် ink ဖြစ်ပါသည်။ **stamps** များသည် stamp comments ဖြစ်ပါသည်။
- **အလျားနှင့် ဧရိယာများ** သည် measurement comments ဖြစ်ပြီး calibrate လုပ်ထားသော စာရွက်တိုင်းတွင် scale ပါဝင်သဖြင့် measurements ကို နားလည်သော viewer များက တန်ဖိုးများ ပြနိုင်ပါသည်။
- **Replies** များသည် comment ၏ reply များဖြစ်ပြီး **statuses** များသည် review state များဖြစ်ပါသည် (Open သည် state မပါဘဲ ပြပါသည်)။
- **သင်ရိုက်ထားသော စာရွက်နံပါတ်များ** သည် အခြား viewer များ ပြသော page label များ ဖြစ်လာပါသည်။

MarkupCraft မှသာ ပြန်ဖတ်နိုင်သော အချို့အရာများရှိပါသည်: punch item ၏ assignee နှင့် due date၊ item status နှင့် style အချို့။ အခြား program များက comment ကို ပြန်မရေးမချင်း ၎င်းတို့ကို ထိန်းထားပါသည်။

အခြား program တစ်ခုတွင် comments များကို အခြား comment များလိုပင် ရွှေ့နိုင်သည် သို့မဟုတ် တည်းဖြတ်နိုင်ပါသည်။ တစ်ဦးဦးက ထိုသို့ပြုလုပ်ပြီး ဖိုင်ကို ပြန်ပို့ပါက MarkupCraft သည် ဖိုင်ကို ဖွင့်သောအခါ comment ၏ နေရာအသစ်ကို အသုံးပြုပါသည်။

အသေးစိတ် အပြည့်အစုံ: [What is saved in the PDF](topic:what-the-pdf-keeps)။

## "?" အဖြစ် ပရင့်ထွက်သော စာလုံးများ

မှတ်ချက်စာသားကို PDF viewer အားလုံးတွင် ရှိသော စံ Helvetica font ဖြင့် ရေးပါသည်။ ၎င်းတွင် အင်္ဂလိပ်နှင့် အနောက်ဥရောပ စာလုံးများ (é၊ ñ၊ ü၊ ø စသည်) ပါဝင်ပါသည်၊ သို့သော် အခြား script များ၊ ထိုအစုအဝေးပြင်ပ သင်္ကေတများ သို့မဟုတ် emoji များ မပါဝင်ပါ။ ထိုစာလုံးများကို MarkupCraft တွင် ပုံမှန်ပြသော်လည်း သိမ်းထားသော မိတ္တူတွင် "?" အဖြစ် ပရင့်ထွက်ပါမည်။ သိမ်းဆည်းမှု စာတန်းက ၎င်းတို့ကို ရေတွက်ပါသည်: "အနောက်ဥရောပ အစုအဝေးပြင်ပ စာလုံး 3 လုံးကို မိတ္တူတွင် "?" အဖြစ် ပရင့်ထွက်ပါမည်။" ထိုစကားလုံးများကို အက္ခရာလုံးပြည့် ရေးပါ၊ သို့မဟုတ် ရိုးရှင်းသော အစားထိုးစာသားသုံးပါ (ဥပမာ diameter သင်္ကေတအတွက် "dia.")။

## သိမ်း၍မရသော ဖိုင်များ

- **Protected PDFs**: "ဤ PDF ကို ကာကွယ်ထားသဖြင့် (encrypted) မှတ်ချက်ပါ မိတ္တူ ရေးမရပါ။ ကာကွယ်မထားသော မိတ္တူ တောင်းဆိုပါ။" သင်သည် မျက်နှာပြင်ပေါ်တွင် ဆက်ကြည့်နိုင်ပြီး CSV နှင့် BCF ကို export လုပ်နိုင်ပါသည်။
- အခြားအကြောင်းကြောင့် သိမ်းမရပါက "Could not save <file>" ဟူသော အကွက်တွင် အကြောင်းရင်း ပြပါမည်။ သင့်မှတ်ချက်များသည် tab ထဲတွင် ရှိနေဆဲဖြစ်ပြီး tab ကို မပိတ်မချင်း ဘာမျှ မပျောက်ပါ။

## Flatten နှင့် ပရင့်ထုတ်ခြင်း

Flatten (မှတ်ချက်များကို စာမျက်နှာထဲ ထည့်ထိုးခြင်း) နှင့် ပရင့်ထုတ်ရန် command ကို ယခုအချိန်တွင် မရှိသေးပါ။ ပရင့်ထုတ်ရန် သိမ်းထားသော မိတ္တူကို မည်သည့် PDF viewer တွင်မဆို ဖွင့်ပြီး comments ပြထားသည့် အခြေအနေတွင် ပရင့်ထုတ်ပါ။
