MarkupCraft တွင် အကောင့်မရှိပါ၊ ဆာဗာ သိုလှောင်မှုလည်း မရှိပါ။ အရာအနည်းငယ်ကို ဤဝဘ်ဆိုက်အတွက် ဘရောက်ဆာ၏ သိုလှောင်မှုတွင် သိမ်းထားပြီး ကျန်အရာအားလုံးသည် သင့်ဖိုင်များတွင် ရှိသည်။

## ဘရောက်ဆာတွင် သိမ်းထားသည့်အရာများ

| အရာ | ဘယ်မှာ သတ်မှတ်သလဲ | သိမ်းပုံ |
|---|---|---|
| သင့်ရေးသူအမည် | status bar ရှိ အမည်ခလုတ်၊ သို့မဟုတ် {{ui:ဆက်တင်များ}} | အမည်တစ်ခု |
| MarkupCraft ဆက်တင်များ | {{ui:ဆက်တင်များ}}၊ {{ui:MarkupCraft}} တက်ဘ်: markup အသစ်များ၏ အရောင်နှင့် မျဉ်းအထူ၊ ကူးထည့်သည့်နေရာ၊ ယူနစ်များ (ကြည့်ပါ [MarkupCraft ဆက်တင်များ](topic:settings)) | တစ်စု |
| ကိရိယာ ဆက်တင်များ | ဆွဲကိရိယာ ဖွင့်ထားစဉ် {{ui:ဂုဏ်သတ္တိများ}}: ကိရိယာတစ်ခုစီအတွက် အရောင်၊ မျဉ်း၊ အပြည့်၊ အလင်းဝင်နှုန်းနှင့် စာသားအရွယ်၊ ရွေးထားသော တံဆိပ်၊ ရေတွက်အုပ်စုအမည် | တစ်စု |
| ကိရိယာ သိုလှောင်ရာ | {{ui:ကိရိယာများ}} တက်ဘ် | ကိရိယာ 500 အထိ |
| နောက်ဆုံး ကူးထားသည့်အရာ | {{ui:ကူးရန်}} သို့မဟုတ် {{ui:ဖြတ်ရန်}} | ကူးထားသော markup များ၊ တက်ဘ်တစ်ခုက ကူးထည့်နိုင်ရန်၊ နောက်ကူးမှုဖြင့် အစားထိုးသည် |
| တံဆိပ်ပုံနှင့် လက်မှတ် | တံဆိပ်စာရင်းရှိ {{ui:ပုံ…}} နှင့် {{ui:ကိုယ်ပိုင်လက်မှတ်…}} | နောက်ဆုံးပုံနှင့် သင့်လက်မှတ် |
| ပြန်လည်ရယူသည့် မိတ္တူများ | PDF တွင် မသိမ်းရသေးသော markup ရှိနေစဉ် သင့်အတွက် သိမ်းထားသည် | PDF နှင့် ၎င်း၏ markup များ၊ သိမ်းသည့်အခါ၊ ပိတ်သည့်အခါ သို့မဟုတ် စွန့်ပစ်သည့်အခါ ဖယ်ရှားသည်၊ ရက် 30 အထိ သိမ်းထားသည် |

## ၎င်းကဘာကိုဆိုလိုသလဲ

- **ဘရောက်ဆာတစ်ခုစီ၊ ကွန်ပျူတာတစ်လုံးစီအလိုက်။** ကွန်ပျူတာတစ်လုံးတည်းရှိ Chrome နှင့် Firefox တစ်ခုစီတွင် ကိုယ်ပိုင်ရှိသည်။ သင့်လက်ပ်တော့နှင့် ရုံးဒက်စ်တော့တစ်ခုစီတွင်လည်း ကိုယ်ပိုင်ရှိသည်။ ဘရောက်ဆာသို့ ဝင်ရောက်ထားသော်လည်း ၎င်းတို့ကြား ဘာမျှ sync မလုပ်ပါ။
- **Private နှင့် incognito ဝင်းဒိုးများ** သည် ဗလာဖြင့် စတင်ပြီး ပိတ်သည့်အခါ အရာအားလုံးကို မေ့သွားသည်။
- **ဆိုက်ဒေတာ ရှင်းလင်းခြင်းသည် ၎င်းကို ဖျက်သည်။** ဘရောက်ဆာ ဆက်တင်တွင် ဤဝဘ်ဆိုက်အတွက် သို့မဟုတ် ဆိုက်အားလုံးအတွက် cookie နှင့် ဆိုက်ဒေတာကို ရှင်းလင်းပါက သင့်အမည်၊ ဆက်တင်များနှင့် chest ကို ဖယ်ရှားသည်။ အချို့သော သန့်စင်ကိရိယာများနှင့် ကုမ္ပဏီမူဝါဒများက ၎င်းကို အလိုအလျောက် လုပ်ဆောင်သည်။
- **တင်ပို့ခြင်း မရှိပါ။** ဤတန်ဖိုးများသည် ကွန်ပျူတာမှ ဘယ်တော့မျှ မထွက်ပါ၊ သင်သိမ်းသည့် PDF များအတွင်းရှိ သင့်အမည်မှလွဲ၍ဖြစ်သည်။ ပြန်လည်ရယူသည့် မိတ္တူများလည်း ဤဘရောက်ဆာတွင်သာ ကျန်ရှိသည်။

:::safari
Safari သည် အပတ်အနည်းငယ် မဝင်ရောက်ပါက ဝဘ်ဆိုက်၏ သိမ်းထားသည့် ဒေတာကို ဖျက်နိုင်သည်။ MarkupCraft ကို အခါအားလျော်စွာ ဖွင့်ပြီး ထုတ်ယူထားသော tool chest ကို ထားရှိပါ။
:::

## ဘရောက်ဆာတွင် မသိမ်းသည့်အရာများ

- **သင့် markup များ အမြဲတမ်း။** ၎င်းတို့သည် သင်သိမ်းသော "(marked up)" PDF တွင် ရှိရမည်။ ပြန်လည်ရယူသည့် မိတ္တူသည် အမှား ပျက်ခြင်း သို့မဟုတ် ပိတ်ထားသော tab အတွက် ကာကွယ်ရေးသာ ဖြစ်ပြီး အလုပ်သိမ်းရန် နေရာ မဟုတ်ပါ။ သိမ်းသည့်အခါ ပျောက်သွားပြီး ဆိုက်ဒေတာ ရှင်းလင်းခြင်းက ဖယ်ရှားသည်။ [သင့်အလုပ်ကို ပြန်ရယူခြင်း](common:recover) ကို ကြည့်ပါ။
- **သင်ဖွင့်ထားသော ဖိုင်များ။** MarkupCraft ကို ဖွင့်သည့်အခါတိုင်း PDF များကို ထပ်မံဖွင့်ပါ။
- **သင်ရောက်နေသော စာရွက်၊ zoom၊ စစ်ထုတ်မှုများနှင့် ပြန်ဖျက်မှတ်တမ်း။** ၎င်းတို့သည် အစုကို သို့မဟုတ် tab ကို ပိတ်သည်အထိ တည်ရှိသည်။

## အရန်ကူးခြင်းနှင့် သင့်စနစ်ကို ရွှေ့ခြင်း

- **Tool chest:** {{ui:ကိရိယာများ}} ပြီးနောက် {{ui:ထုတ်ရန်}}။ အခြားဘရောက်ဆာ သို့မဟုတ် ကွန်ပျူတာတွင် {{ui:ကိရိယာများ}} ပြီးနောက် {{ui:သွင်းရန်}}။
- **အမည်:** အခြားဘရောက်ဆာတွင် ထပ်မံရိုက်ပါ (status bar ရှိ အမည်ခလုတ်ကို နှိပ်ပါ)။
- **ကိရိယာ ဆက်တင်များ:** ထပ်မံသတ်မှတ်ပါ၊ သို့မဟုတ် ပုံစံရှိသော markup တစ်ခုစီကို ကိရိယာအဖြစ် သိမ်းပါ၊ ထို့ကြောင့် chest နှင့်အတူ ပါလာမည်။

## အစမှ ပြန်စရန်

အရာအားလုံးကို ပြန်စရန်အတွက် ဘရောက်ဆာ ဆက်တင်တွင် ဤဝဘ်ဆိုက်၏ ဒေတာကို ရှင်းလင်းပါ။ သင့်အမည်၊ ဆက်တင်များနှင့် chest ပျောက်သွားမည်၊ ပုံသေ ကိရိယာ ခြောက်ခုသည် ပြန်ပေါ်လာမည်။

## အော့ဖ်လိုင်း မိတ္တူ

ထိပ်ဘားရှိ {{ui:အော့ဖ်လိုင်းအတွက် သိမ်းရန်}} သည် အက်ပ်၏ ကိုယ်ပိုင်ဖိုင်များကို (PDF ဖတ်ကိရိယာနှင့် ရေးကိရိယာပါ၊ ခန့်မှန်း 6 MB) ဤဆက်တင်များနှင့် သီးခြား ဘရောက်ဆာတွင်လည်း သိမ်းသည်။ ဆိုက်ဒေတာ ရှင်းလင်းခြင်းက ထိုမိတ္တူကိုလည်း ဖယ်ရှားသည်; "အော့ဖ်လိုင်း အဆင်သင့်" ကို နှိပ်ပြီး "အော့ဖ်လိုင်း မိတ္တူကို ဖယ်ရှားရန်" ကို ရွေးချယ်ပါက ထိုမိတ္တူကိုသာ ဖယ်ရှားသည်။ [အော့ဖ်လိုင်း အလုပ်လုပ်ခြင်း](common:offline) ကို ကြည့်ပါ။

ကွန်ပျူတာများကြား cloud သိမ်းခြင်းနှင့် sync ကို ယခုအချိန်တွင် မရနိုင်သေးပါ။
