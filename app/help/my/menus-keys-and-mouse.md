MarkupCraft ၏ ကိရိယာများသည် သင် မည်သည့်နည်းဖြင့် ရောက်ရှိသည်ဖြစ်စေ တူညီသည်။ **menu style** သည် ၎င်းတို့ မျက်နှာပြင်ပေါ်တွင် ဘယ်မှာ ထားမည်၊ ဘာနာမည် ခေါ်မည်နှင့် ဘယ်ကီးက ရွေးမည်ကိုသာ ဆုံးဖြတ်သည်။ {{ui:Settings}} ({{key:Mod+,}}) › {{ui:MarkupCraft}} › {{ui:Menus, keys and mouse}} တွင် ရွေးပါ; ပြောင်းလဲမှုသည် ချက်ချင်း ဖြစ်ပြီး ဤ browser က မှတ်ထားသည်။

## style သုံးမျိုး

| Style | ရရှိမည့်အရာ |
|---|---|
| {{ui:MarkupCraft}} | MarkupCraft ၏ ကိုယ်ပိုင် toolbar (File, Select, Draw, Revise, Annotate, Measure, Edit) နှင့် အက္ခရာတစ်လုံးစီ ကီးများ: {{key:V}} select၊ {{key:H}} pan၊ {{key:P}} pen၊ {{key:I}} highlighter၊ {{key:L}} line၊ {{key:A}} arrow၊ {{key:R}} rectangle၊ {{key:E}} ellipse၊ {{key:C}} cloud၊ {{key:K}} callout၊ {{key:T}} text၊ {{key:N}} note၊ {{key:S}} stamp၊ {{key:M}} length၊ {{key:Q}} area၊ {{key:U}} count။ အစ။ |
| {{ui:PDF review}} | မီနူးဘား ({{ui:File}}, {{ui:Edit}}, {{ui:View}}, {{ui:Document}}, {{ui:Markup}}, {{ui:Measure}}, {{ui:Review}}, {{ui:Window}}) နှင့် review ကိရိယာများ အတန်း၊ ကီးများကို PDF review programs များ သတ်မှတ်သည့်နည်းအတိုင်း သတ်မှတ်ထား: {{key:V}} select၊ {{key:Shift+V}} pan၊ {{key:H}} highlighter၊ {{key:Q}} callout၊ {{key:N}} polygon၊ {{key:Shift+N}} polyline၊ {{key:Shift+T}} note၊ {{key:Shift+A}} arc၊ နှင့် တိုင်းတာမှုများကို {{key:Alt+Shift}} တွင်: {{key:Alt+Shift+K}} calibrate၊ {{key:Alt+Shift+L}} length၊ {{key:Alt+Shift+G}} angle၊ {{key:Alt+Shift+A}} area၊ {{key:Alt+Shift+C}} count။ {{key:Alt+L}} သည် markup စာရင်းကို ဖွင့်သည်။ အလယ်ခလုတ်က ရွှေ့ကြည့်သည်; ညာကလစ်က မဟုတ်ပါ။ |
| {{ui:Ribbon}} | အလုပ်အလိုက် အမည်ပေးထားသော tabs: {{ui:Mark up}} (ရွေး၊ ဆွဲ၊ တိမ်များ၊ callout များ၊ စာသား၊ note များ၊ တံဆိပ်များ)၊ {{ui:Measure}}၊ {{ui:Edit}}၊ {{ui:Review}} (markup စာရင်းနှင့် ၎င်း၏ထုတ်ယူမှုများ၊ BCF issue များ၊ punch list၊ field records၊ tool chest၊ compare)၊ {{ui:Pages}} နှင့် {{ui:View}}၊ {{ui:File}} နှင့် ဖွင့်ခြင်း၊ သိမ်းခြင်း၊ ပြန်ဖျက်ခြင်းနှင့် ပြန်လုပ်ခြင်းအတွက် အမြန် ခလုတ်များ။ ကိရိယာများသည် MarkupCraft ၏ ကိုယ်ပိုင် အက္ခရာတစ်လုံးစီ ကီးများကို ဆက်သုံးသည်။ မဖွင့်ထားသော panel အတွက် ခလုတ်သည် ထို panel ကို အရင် ဖွင့်သည်။ |

style တိုင်းသည် {{key:Mod}} ကီးများကို ထိန်းသည်: {{key:Mod+Z}}၊ {{key:Mod+Y}}၊ {{key:Mod+S}}၊ {{key:Mod+O}}၊ {{key:Mod+P}}၊ {{key:Mod+C}}၊ {{key:Mod+X}}၊ {{key:Mod+V}}၊ {{key:Mod+D}}၊ {{key:Mod+A}}၊ {{key:Mod+F}}၊ {{key:Mod+0}} fit page နှင့် {{key:Mod+9}} fit width; {{key:PageUp}} နှင့် {{key:PageDown}} သည် စာရွက်ကို ပြောင်းသည်။

:::tip
MarkupCraft ၏ ကိုယ်ပိုင် အပြင်အဆင်နှင့် ဆိုင်သော်လည်း သင်ရွေးထားသော style နှင့်မဆိုင်သော ကီးသည် ဘာမျှ မလုပ်ပါ၊ status bar က ၎င်း၏ ကိရိယာ ရောက်သွားသည့်နေရာကို ပြောသည် ("In PDF review, Callout is Q")။ {{key:Delete}}၊ {{key:Esc}}၊ {{key:Enter}}၊ {{key:Tab}}၊ {{key:Space}} နှင့် ဦးတည်ချက် ကီးများသည် အမြဲ ၎င်းတို့၏ အဓိပ္ပာယ်ကို ထိန်းသည်။ text box၊ callout သို့မဟုတ် note တွင် စာရိုက်နေစဉ် ကီးတိုင်းသည် စာသား၏ ဖြစ်သည်၊ ဆွဲနေစဉ် ရိုက်သော ဂဏန်းများသည် အရှည် အကွက်ကို ဆက်ဖွင့်သည်။
:::

## သင့်ကိုယ်ပိုင်အဖြစ် ပြုလုပ်ခြင်း

1. သင်လိုချင်သည်နှင့် အနီးဆုံး style ကို ရွေးပြီး {{ui:Customize…}} ကို click လုပ်ပါ။
2. {{ui:Keys and menus}} တွင် ကိရိယာတစ်ခု ရှာပါ (ရှာဖွေရေးအကွက် ကူညီသည်)။ {{ui:Add a key}} ကို နှိပ်ပြီး ကီးကို နှိပ်ပါ၊ သို့မဟုတ် ကီးနှစ်ခုကို တစ်ပြိုင်နက် (အက္ခရာနှစ်လုံး ကီးအတွက်)။ ကီးတစ်ခုကို click လုပ်ပြီး ဖယ်ရှားနိုင်သည်။
3. မီနူးဘားဖြင့် {{ui:Where it sits}} သည် ကိရိယာကို အခြားမီနူးသို့ ရွှေ့သည်၊ သို့မဟုတ် {{ui:Keys only}} သို့ ရွှေ့သည်။
4. {{ui:Mouse}} တွင် wheel နှင့် စာရွက်ကို ရွှေ့သော ခလုတ်များကို သတ်မှတ်ပါ။
5. အမည်ပေးပြီး {{ui:Save}} ကို click လုပ်ပါ။

built-in style ကို သိမ်းခြင်းသည် သင့်ကိုယ်ပိုင် မိတ္တူ ("My PDF review") ဖန်တီးသည်; built-in တစ်ခုသည် ဘယ်တော့မှ မပြောင်းပါ။ ကီးတစ်ခုကို ကိရိယာနှစ်ခုအတွက် ပေးထားလျှင် အနီရောင်ဖြင့် ပြသပြီး သိမ်းခင် ပြင်ရမည်။

## Mouse

- **Mouse wheel**: {{ui:Scroll up zooms in}} (စတင်ချက်) သို့မဟုတ် {{ui:Scroll up zooms out}}၊ နှင့် မြန်လေမြန်ပုံ။ trackpad pinch သည် သင့်လက်ချောင်းများ ရွေ့သည့် ဦးတည်ချက်အတိုင်း အမြဲ ချဲ့သည်။
- **စာရွက်ကို ရွှေ့ခြင်း အတွက်**: အလယ်ခလုတ်၊ ညာခလုတ်၊ သို့မဟုတ် နှစ်ခုလုံး။ {{key:Space}} ကိုဖိပြီး ဖိရွှေ့ခြင်းနှင့် {{ui:Pan}} ကိရိယာသည် အမြဲ ရွှေ့ကြည့်သည်; ဘယ်ခလုတ်က အခြားအတိုင်း ဆွဲပြီး ရွေးသည်၊ ထို့ကြောင့် ဤနေရာတွင် ၎င်းကို ခြစ်ခြင်းသည် ဘာမျှ မပြောင်းလဲပါ။
- MarkupCraft တွင် 3D view မရှိပါ၊ ထို့ကြောင့် 3D ခလုတ်များသည် ဘာမျှ မလုပ်ပါ။

## သင်နှင့်အတူ ယူသွားခြင်း

{{ui:Export}} သည် အသုံးပြုနေသော style ကို `.ccinput.json` ဖိုင်ငယ်အဖြစ် သိမ်းသည်; {{ui:Import…}} သည် အခြားကွန်ပျူတာ သို့မဟုတ် လုပ်ဖော်ကိုင်ဖက်မှ တစ်ခုကို ထည့်သည်။ သွင်းသော ဖိုင်သည် MarkupCraft ၏ ကိုယ်ပိုင် ကိရိယာများကိုသာ ညွှန်ပြနိုင်သည်; အခြားအရာများကို ဖယ်ရှားပြီး status bar တွင် ရေတွက်သည်။ {{ui:Delete this style}} သည် သင့်ကိုယ်ပိုင်တစ်ခုကို ဖယ်ရှားသည်။

:::note
ဤဆက်တင်များသည် ဤ browser တွင် ကျန်ရှိသည်။ style ကဒ်များအောက်ရှိ {{ui:Use this style in every app}} သည် အက်ပ်တိုင်းကို ၎င်းတို့နှင့် ကိုက်ညီသော style ဖြင့် ဖွင့်စေသည်: {{ui:PDF review}} သည် အခြားအက်ပ်များ၏ မီနူးဘား style များနှင့်၊ {{ui:Ribbon}} သည် ၎င်းတို့၏ ribbon များနှင့်၊ MarkupCraft ၏ ကိုယ်ပိုင် toolbar သည် ၎င်းတို့နှင့် ပါသွားသည်။ ကိုက်ညီသော style မရှိသော အက်ပ်သည် ကိုယ်ပိုင်အတိုင်း ဆက်ရှိသည်။
:::

:::tip
{{ui:Settings}} › {{ui:Global}} › {{ui:Layout}} ရှိ အလုပ်ခွင် အပြင်အဆင်များ ({{ui:Ribbon and project browser}}၊ {{ui:Toolbox and info box}}) သည် {{ui:Ribbon}} style ၏ tabs ဖြင့် ribbon ကို၊ MarkupCraft ၏ toolbar ဖြင့် toolbox ကို တည်ဆောက်ပြီး ကိရိယာတိုင်း ၎င်းတို့ထဲတွင် တူညီစွာ အလုပ်လုပ်သည်။
:::
