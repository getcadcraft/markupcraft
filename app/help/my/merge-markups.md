လူနှစ်ဦးက PDF တစ်ခုကို မိတ္တူနှစ်ခုဖြင့် markup လုပ်သည်။ သူတို့ထိခဲ့သော markup များ ကွဲပြားလျှင် မိတ္တူများကို လူလက်ဖြင့်မဟုတ်ဘဲ programs ဖြင့် ပေါင်းနိုင်သည်။

## ဘာကြောင့် အလုပ်ဖြစ်သလဲ

MarkupCraft သိမ်းသော markup တိုင်းသည် PDF အတွင်း ကိုယ်ပိုင်အမည် (၎င်း၏ id) ကို ပါစေပြီး အမည်သည် ဘယ်တော့မှ မပြောင်းပါ။ ပေါင်းခြင်းသည် markup များကို ဖိုင်ထဲ၏ နေရာဖြင့် မဟုတ်ဘဲ ထိုအမည်ဖြင့် ရှာသည်၊ အကြောင်းမှာ program တိုင်းက သိမ်းချိန်တွင် နေရာများကို နံပါတ်ပြန်စီသည်။ မှတ်စုများနှင့် လျို့ဝှက် ပိတ်ထားသော ကိုယ်ပိုင် မှတ်စုများကိုလည်း တူညီစွာ ကိုက်ညီစေသည်။

စာရွက်များကို ဘယ်တော့မှ မထိပါ: မိတ္တူနှစ်ခုစလုံးတွင် စာမျက်နှာအရေအတွက် တူရမည်။ ကွဲလျှင် ပေါင်းခြင်းသည် သင့်မိတ္တူကို ထားသည်အတိုင်း ထားပြီး ထိုအကြောင်း ပြောပြသည်၊ အကြောင်းမှာ စာမျက်နှာ ထည့်ခြင်း သို့မဟုတ် ဖယ်ခြင်းသည် လူ၏ အလုပ်ဖြစ်သည်။

## တပ်ဆင်ခြင်း

Git သည် repository တစ်ခုလျှင် တစ်ကြိမ် မျဉ်းနှစ်ကြောင်း လိုအပ်သည်:

```
# .gitattributes
*.pdf merge=cadcraft

# one time, on each computer
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Git မသုံးဘဲ `cadcraft merge <base> <ours> <theirs> -o <result>` ကို run ပါ။ Fossil နှင့် Mercurial သည် ၎င်းတို့၏ merge-tool ဆက်တင်တွင် ဖိုင်သုံးခုတူကို ယူသည်။ ပုံဆွဲနှင့်အတူ လိုက်သော လုပ်ငန်းဖိုင် (`<name>.markups.json`၊ see [Markups that act](topic:markups-that-act)) သည် စာသားဖိုင်အဖြစ် တူညီစွာ ပေါင်းသည်။

## စည်းမျဉ်းများ

- တစ်ဖက်တည်းတွင်သာ ပြောင်းထားသော markup ကို ယူသည်။ နှစ်ဖက်စလုံးတွင် တူညီသော ပြောင်းလဲမှုကို တစ်ကြိမ်သာ ယူသည်။
- markup တစ်ခုကို နည်းနှစ်မျိုးဖြင့် ပြောင်းထားလျှင် **ပဋိပက္ခ** ဖြစ်သည်: သင့်ဘက်က ကျန်ခဲ့ပြီး အစီရင်ခံစာက နှစ်ခုလုံးကို ဖော်ပြသည်။ ရလဒ်ကို ဖွင့်ပြီး ထို markup ကို လူလက်ဖြင့် ပြင်ပါ။
- နှစ်ဖက်မှ ထည့်ထားသော markup ကို ထိန်းသည်။ တစ်ဖက်မှ ဖယ်ထားပြီး အခြားဖက်တွင် မထိသော markup ကို ဖယ်သည်။ တစ်ဖက်မှ ဖယ်ထားပြီး အခြားဖက်တွင် ပြောင်းလဲထားလျှင်: ဖယ်ပြီး အစီရင်ခံသည်။
- လေယာများ၊ ကော်လံများ၊ မှတ်တမ်းများနှင့် မှတ်စုများသည် တူညီသော စည်းမျဉ်းများကို လိုက်နာသည်။
- လျို့ဝှက် ပိတ်ထားသော ကိုယ်ပိုင် မှတ်စုများကို ဘယ်တော့မှ မဖွင့်ပါ: နှစ်ဖက်စလုံး၏ block များကို ဖြစ်သည့်အတိုင်း ထားသည်။

ပေါင်းထားသော ဖိုင်သည် MarkupCraft ၏ ကိုယ်ပိုင် Save ကဲ့သို့ သင့်မိတ္တူ၏ အပြည့်အစုံ ပြန်ရေးခြင်း ဖြစ်သည်။ တစ်စုံတစ်ခုကိုမှ အပ်လုဒ် မလုပ်ပါ; အားလုံးသည် သင့်ကွန်ပျူတာပေါ်တွင် ဖြစ်သည်။
