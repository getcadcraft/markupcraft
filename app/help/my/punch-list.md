punch item ဆိုသည်မှာ နံပါတ်၊ တာဝန်ခံ၊ နောက်ဆုံးရက်နှင့် item status ပါသော markup တစ်ခု ဖြစ်သည်။ နံပါတ်ကို markup ဘေးရှိ sheet ပေါ်တွင် ဆွဲပေးသဖြင့် ပရင့်ထုတ်ထားသော sheet နှင့် စာရင်း ကိုက်ညီပါသည်။

## အချက်များ ထည့်ခြင်း

1. sheet များပေါ်ရှိ ပြဿနာတစ်ခုစီကို markup လုပ်ပါ: တိမ်၊ callout၊ မှတ်စု၊ မည်သည်ကိုမဆို။
2. ၎င်းတို့ထဲမှ တစ်ခု သို့မဟုတ် အများအပြား ရွေးပါ ([markup များကို ရွေး၊ ရွှေ့နှင့် ပြောင်းခြင်း](topic:select-and-edit) ကို ကြည့်ပါ)။
3. {{ui:Punch list}} tab ကို ဖွင့်ပြီး {{ui:Add selected to the punch list}} ကို ရွေးပါ၊ သို့မဟုတ် {{ui:Properties}} တွင် {{ui:Add to the punch list}} ကို ရွေးပါ။

ရလဒ်: markup တစ်ခုစီသည် နောက်တစ်နံပါတ် (1, 2, 3…) ကို ရရှိပြီး sheet အစီအစဉ်အတိုင်း၊ ထို့နောက် ဆွဲခဲ့သော အစီအစဉ်အတိုင်း ရရှိပါသည်။ sheet ပေါ်တွင် နံပါတ်ပါသော badge ပေါ်လာပြီး status bar က "ပြင်ဆင်ရမည့်စာရင်းသို့ အချက် 3 ခု ထည့်ပြီးပါပြီ။" ဟု ပြပါသည်။ နံပါတ်ရှိပြီးသား markup များနှင့် read-only မှတ်ချက်များကို ကျော်သွားပါသည်။

## အသေးစိတ် ဖြည့်ခြင်း

{{ui:Punch list}} tab တွင် item တစ်ခုစီသည် နံပါတ်၊ subject၊ စာသား၊ sheet နှင့် status ကို ပြပြီး အောက်တွင် field သုံးခု ရှိပါသည်။ markup ကို ရွေးလျှင် {{ui:Properties}} တွင် "ပြင်ဆင်ရမည့်စာရင်း" အောက်၌ တူညီသော field များ ရှိပါသည်:

- {{ui:Assignee}}: အမည် သို့မဟုတ် အလုပ်အမျိုးအစား၊ free text အဖြစ်။
- {{ui:Due}}: ရက်စွဲ၊ date picker မှ ရွေးပါ။
- {{ui:Item status}}: ဖွင့်ထား၊ လုပ်ဆောင်နေဆဲ၊ စိစစ်ရန် အဆင်သင့် သို့မဟုတ် ပိတ်ပြီး။

item ၏ ခေါင်းစီးကို နှိပ်ပြီး ၎င်း၏ sheet ပေါ်သို့ ရောက်ပါ။

item status သည် markup ၏ review status (ဖွင့်ထား၊ လက်ခံပြီး၊ ပယ်ချပြီး၊ ပြီးစီး) နှင့် သီးခြားဖြစ်သည်။ အလုပ်အတွက် item status ကို၊ မှတ်ချက်အတွက် review status ကို အသုံးပြုပါ။

## Item ကို စာရင်းမှ ဖယ်ခြင်း

markup ကို ရွေးပြီး {{ui:Properties}} တွင် {{ui:Take off the punch list}} ကို ရွေးပါ။ markup ကျန်ရှိပါမည်; နံပါတ်သာ ပျောက်ပါမည်။ set ဖွင့်နေစဉ် နံပါတ်များကို ပြန်မသုံးပါ: နောက် item သည် နောက်နံပါတ်အသစ်ကို ရရှိပါမည်၊ ထို့ကြောင့် ကွက်လပ်ရှိလျှင် item တစ်ခု ဖယ်ထားသည်ဟု ဆိုလိုသည်။ ဖိုင်ကို ပြန်ဖွင့်သည့်အခါ နံပါတ်ရေတွက်ခြင်းသည် ၎င်းထဲရှိ အမြင့်ဆုံးနံပါတ်အပြီးမှ ဆက်လက်ပါသည်။

## စာရင်း ထုတ်ယူခြင်း

{{ui:Punch list}} tab တွင် {{ui:Export CSV}} ကို ရွေးပါ။ "<name> punch list.csv" ကို ရရှိပြီး ကော်လံများ No., Sheet, File, Page, Item, Comment, Assignee, Due, Status, Markup status, Author နှင့် Created ဖြင့် နံပါတ်အစီအစဉ်အတိုင်း ပါဝင်ပါသည်။ မည်သည့် spreadsheet တွင်မဆို ဖွင့်ပါ။

punch နံပါတ်များ၊ တာဝန်ခံများ၊ နောက်ဆုံးရက်များနှင့် item status များကို markup လုပ်ထားသော PDF အတွင်းလည်း သိမ်းထားသဖြင့် ပြန်ဖွင့်သည့်အခါ ပြန်ပေါ်ပါမည်။ အခြား PDF viewer များက နံပါတ် badge ကို markup ၏ အစိတ်အပိုင်းအဖြစ် ပြပါသည်။ markups စာရင်း၏ BCF export တွင်လည်း တာဝန်ခံနှင့် နောက်ဆုံးရက် ပါဝင်ပါသည် ([BCF အခြေခံများ](topic:bcf-basics) ကို ကြည့်ပါ)။

## ဆိုဒ်တွင် tablet ဖြင့်

set ကို iPad ပေါ်တွင် ဖွင့်ပြီး အလုပ်ကို လျှောက်ကြည့်ကာ ပြဿနာတစ်ခုစီတွင် {{ui:Note}} ချပါ သို့မဟုတ် {{ui:Cloud}} ဆွဲပါ။ သွားရင်း punch list ထဲ ထည့်ပါ၊ ထွက်ခွာမီ သိမ်းပါ။ [iPad သို့မဟုတ် touch screen ပေါ်တွင် ပြန်လည်သုံးသပ်ခြင်း](topic:review-on-a-tablet) ကို ကြည့်ပါ။

ပုံစံချထားသော PDF သို့မဟုတ် spreadsheet အစီရင်ခံစာအဖြစ် punch list နှင့် item များသို့ ပူးတွဲသော ဓာတ်ပုံများသည် ယခုမရှိသေးပါ။
