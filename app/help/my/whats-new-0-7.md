ဤသည်မှာ MarkupCraft 0.6 နှင့် နှိုင်းယှဉ်လျှင် 0.7 တွင် ပြောင်းလဲခဲ့သည့်အရာများ ဖြစ်သည်။ အဓိက အသစ်အရာမှာ field records ဖြစ်သည်- RFI များ၊ submittal များနှင့် နေ့စဉ်မှတ်တမ်းများကို သင်၏ markup များနှင့်အတူ PDF အတွင်း သိမ်းထားခြင်း ဖြစ်သည်။

## အသစ်

### RFI များ၊ submittal များနှင့် နေ့စဉ်မှတ်တမ်းများ

- **Field တဘ်။** {{ui:Field}} တဘ်ကို ဖွင့်ပြီး {{ui:RFI}}၊ {{ui:Submittal}} သို့မဟုတ် {{ui:Daily log}} ကို ရွေးပါ။ RFI သို့မဟုတ် submittal သင့်တော်သည့် စာရွက်ကို နှိပ်ပါ၊ နေရာကို pin တစ်ခုက အမှတ်အသားပြုမည်၊ နေ့စဉ်မှတ်တမ်းကို pin မပါဘဲ ဖွင့်ထားသော စာရွက်ပေါ်တွင် ထားသည်။ ({{ui:Place pin}} က နောက်မှ pin ထည့်ပေးပြီး {{ui:Move pin}} က မည်သည့် pin ကိုမဆို ရွှေ့ပေးသည်။) မှတ်တမ်းတစ်ခုစီတွင် ကိုယ်ပိုင်နံပါတ် (RFI-0001၊ SUB-0001၊ LOG-0001)၊ ခေါင်းစဉ်၊ စာသား၊ အခြေအနေ၊ တာဝန်ခံ၊ ကြောင့်ကြမှုရက်၊ စာပြန်များနှင့် ပူးတွဲဖိုင်အမည်စာရင်း ပါဝင်သည်။ [RFI များ၊ submittal များနှင့် နေ့စဉ်မှတ်တမ်းများကို ခြေရာခံခြင်း](topic:field-records) ကို ကြည့်ပါ။
- **နောက်ကျနေသည်များကို ကြည့်ပါ။** စာရင်းကို အမျိုးအစား၊ အခြေအနေ၊ ကြောင့်ကြမှုရက် (နောက်ကျနေသည်၊ ရက် ၇ ရက်အတွင်း ကြောင့်ကြမည်၊ ကြောင့်ကြမှုရက် ရှိ/မရှိ)၊ ဤစာရွက် သို့မဟုတ် စာရွက်အားလုံး၊ စာသားရှာဖွေမှု သို့မဟုတ် {{ui:Assigned to me}} ဖြင့် စစ်ထုတ်နိုင်သည်။ ကြောင့်ကြမှုရက် ကျော်လွန်ပြီး စောင့်ဆဲ မှတ်တမ်းတစ်ခုကို စာရင်းနှင့် ၎င်း၏ pin ပေါ်တွင် အနီရောင်ဖြင့် **{{ui:Overdue}}** ဟု အမှတ်အသားပြုသည်။ [အရေးကြီးသည်များကို ရှာခြင်း](topic:field-records#find-what-matters) ကို ကြည့်ပါ။
- **CSV နှင့် BCF။** {{ui:CSV}} က ဖော်ပြထားသော မှတ်တမ်းများကို spreadsheet အဖြစ် ရေးသည်၊ {{ui:BCF}} က BCF topic များအဖြစ် ရေးပြီး တစ်ခုစီတွင် စာရွက်ပေါ်ရှိ နေရာ၏ snapshot ပါဝင်သည်။ နှစ်ခုစလုံးက စစ်ထုတ်ချက်များကို လိုက်နာသည်။ [ထုတ်ယူခြင်း](topic:field-records#export) ကို ကြည့်ပါ။
- **အော့ဖ်လိုင်း၊ နှင့် မိတ္တူ နှစ်ခုကို တစ်ခုတည်းဖြစ်အောင် ပေါင်းခြင်း။** မှတ်တမ်းများကို PDF အတွင်း သိမ်းသည်၊ ကွန်ရက် မလိုအပ်ဆိုသဖြင့် ဆိုက်ပေါ်ရှိ တက်ဘလက်က ထည့်၊ ဖြေကြား၊ သိမ်းနိုင်သည်။ရုံးသို့ ပြန်ရောက်လျှင် {{ui:Merge}} က တူညီသော PDF ၏ အခြားမိတ္တူမှ မှတ်တမ်းများကို id ဖြင့် ပေါင်းပြီး undo တစ်ဆင့်အဖြစ် ထားသည်။ [သိမ်းခြင်း၊ အော့ဖ်လိုင်းနှင့် မိတ္တူများ ပေါင်းခြင်း](topic:field-records#save-offline-and-merging-copies) ကို ကြည့်ပါ။

### AI အကူအညီပေးသူများ

- **အကူအညီပေးသူ လုပ်နိုင်သည့်အရာ ပိုများသည်။** CadCraft Studio မှတဆင့် ချိတ်ဆက်ထားသော သင်၏ကိုယ်ပိုင် အကူအညီပေးသူသည် markup တစ်ခု၏ အခြေအနေကို သတ်မှတ်နိုင် (`markup_status`၊ ၎င်း၏ thread တွင် မှတ်တမ်းတင်သည်)၊ thread တွင် စာပြန်နိုင် (`markup_reply`) နှင့် {{ui:Markups}} စာရင်းကို CSV သို့မဟုတ် BCF အဖြစ် ထုတ်နိုင်သည် (`markups_export`၊ စစ်ထုတ်ချက်များဖြင့် စာရင်းပြသည့်အရာ)။ ပြောင်းလဲမှုတိုင်းသည် undo တစ်ဆင့်ဖြစ်ပြီး အကူအညီပေးသူ၏ အမည်ဖြင့် လက်မှတ်ထိုးသည်။ [အကူအညီပေးသူ တောင်းဆိုနိုင်သည့်အရာများ](topic:use-with-ai-assistants#what-an-assistant-can-ask-for) ကို ကြည့်ပါ။

## အက်ပ်အားလုံးတွင်

- **ယူနစ်များ။** {{ui:Settings}} › {{ui:General}} › {{ui:Units}} တွင် အလျား၊ ဧရိယာ၊ ထုထည်၊ ထောင့်နှင့် စောက်စိမ်း (slope) အတွက် စာရင်းတစ်ခုစီရှိပြီး ယူနစ်အဓိပ္ပာယ်များက ပေးသည့် တိကျသော အရွယ်အစားများနှင့်အတူ ရှိသည် (US survey foot သည် ကိုယ်ပိုင်ယူနစ်ဖြစ်သည်)။ သင်မသုံးသော ယူနစ်များကို ပိတ်လိုက်လျှင် ယူနစ်စာရင်းမှ ထွက်သွားပြီး၊ တစ်ခုကို star ပြုလုပ်လျှင် အသစ်လုပ်ငန်းများသည် ထိုယူနစ်ဖြင့် စတင်သည်။ ဖိုင်တစ်ခုသည် အမြဲတမ်း ကိုယ်ပိုင်ယူနစ်ကို ထိန်းသည်။ MarkupCraft တွင် {{ui:Settings}} › {{ui:MarkupCraft}} ရှိ တိုင်းတာမှုနှင့် အနေအထားယူနစ်များနှင့် calibrate ဒိုင်ယာလော့ဂ်ရှိ ယူနစ်တို့သည် ခလုတ်များကို လိုက်နာပြီး၊ star က MarkupCraft ၏ ကိုယ်ပိုင်ဆက်တင်များကို သိမ်းသည်အထိ တိုင်းတာမှုယူနစ်ကို သတ်မှတ်သည်၊ calibrate လုပ်စဉ် ရိုက်ထည့်သော အမှန်တကယ် အကွာအဝေးတွင် မည်သည့်ယူနစ် အမှတ်အသားမဆို ပါနိုင်သည်၊ ဥပမာ `3 yd` သို့မဟုတ် `1.5 km`။ [ယူနစ်များ၊ ရိုက်ထည့်သော တန်ဖိုးများနှင့် ယူနစ်စာရင်းများ](common:unit-lists) ကို ကြည့်ပါ။
- **ပိုမိုကျစ်လစ်သော အပြင်အဆင်နှင့် ဖယ်ထားနိုင်သော အကန့်များ။** {{ui:Settings}} › {{ui:General}} › {{ui:Layout density}} › {{ui:Compact}} က စခရင်ပေါ်တွင် ပိုမိုထည့်နိုင်စေသည် (touch screen နှင့် ဖုန်းများက ခလုတ်ကြီးများကို ဆက်ထားသည်)။ ဘေးအကန့်တစ်ခုစီတွင် ပါးလွှာသော ခေါင်းစဉ်ဘား ရှိသည်- ဆွဲ၍ dock သို့မဟုတ် float လုပ်နိုင်သည်၊ အခြားအကန့်၏ ဘားပေါ် ချ၍ ဘောင်တစ်ခုတည်းကို တဘ်များအဖြစ် မျှဝေနိုင်သည်၊ ပင်ထိုး၍ အစွန်းသို့ ဆွဲသွားစေနိုင်သည်၊ သို့မဟုတ် ဖျောက်ထားပြီး အစွန်းမှ ပြန်ခေါ်နိုင်သည်။ [အကန့်များကို စီစဉ်ခြင်း](common:arrange-panels#make-the-layout-denser) ကို ကြည့်ပါ။
- **ဒိုင်ယာလော့ဂ်များ ရွှေ့နိုင်သည်။** ဒိုင်ယာလော့ဂ်ကို ခေါင်းစဉ်ဘားဖြင့် ဆွဲ၍ ပုံဆွဲချက်မှ ဖယ်ထုတ်နိုင်သည်၊ ထို့နောက် ထားခဲ့သည့်နေရာသို့ ပြန်ရောက်သည်။ ခေါင်းစဉ်ဘားကို နှစ်ချက်နှိပ်လျှင် ပြန်ဗဟိုချထားသည်။ [ဒိုင်ယာလော့ဂ်ကို ရွှေ့ခြင်း](common:arrange-panels#move-a-dialog) ကို ကြည့်ပါ။
- **AI အကူအညီပေးသူများအတွက် နည်းလမ်းများ။** သင်၏ကိုယ်ပိုင်အကူအညီပေးသူအတွက် တောင်းဆိုချက် ဆယ်ခု (ပုံဆွဲချက်ကို သပ်ရပ်အောင်လုပ်ခြင်း၊ စာရွက်အစုကို plot လုပ်ခြင်း၊ ပုံဆွဲချက်များ စစ်ဆေးခြင်း၊ မော်ဒယ်အကြောင်း မေးခြင်း၊ takeoff စုစုပေါင်းတွက်ခြင်း၊ အစိတ်အပိုင်း ကွဲပြားမှု စမ်းခြင်း...)၊ ခေါ်ဆိုသည့် tools နှင့် လိုအပ်သည့် ခွင့်ပြုချက်များပါဝင်ပြီး၊ ကျွန်ုပ်တို့၏ စမ်းသပ်မှုများက ပြန်လည်လုပ်ဆောင်သည်။ အက်ပ်များတွင် AI မပါဝင်ပါ။ [AI အကူအညီပေးသူများအတွက် နည်းလမ်းများ](common:assistants-recipes) ကို ကြည့်ပါ။
- **ဘာသာစကားများ။** **Português (Portugal)** သည် {{ui:Settings}} › {{ui:General}} › {{ui:Language}} တွင် အသစ်ဖြစ်သည်။ ၎င်းနှင့် **Português (Brasil)**၊ **Español (México)** နှင့် **Bahasa Indonesia** တို့တွင် အက်ပ်စကားလုံးအားလုံး ရှိပြီး၊ မိခင်ဘာသာစကား ပိုင်ရှင် မဖတ်ရသေးသော မူကြမ်းများဖြစ်သည်။ အကူအညီ ခေါင်းစဉ်များက အင်္ဂလိပ်ဖြင့်သာ ရှိသည်။
- **CadCraft Studio** သည် အပ်ဒိတ်စစ်ဆေးမှု မအောင်မြင်သည့် အကြောင်းရင်းကို ("Done" ဟု ရိုးရိုးမပြဘဲ) ပြသသည် (သင့်စနစ်အတွက် ဖိုင်မရှိသေး၊ ကွန်ရက်မရှိ၊ လက်မှတ် မမှန်)၊ ပိတ်ထားသော What's new ကတ်ကို ပြန်မပြတော့ဘဲ ပိုသစ်သော ဗားရှင်း ထွက်သည်အထိ ထားသည်။

## ဤဗားရှင်းတွင် မပါသေးသည့်အရာများ

- **0.7 ကို code-sign မလုပ်ထားပါ။** Signing နှင့် Microsoft Store package ကို 0.8 သို့ ရွှေ့လိုက်သည်၊ အကြောင်းမှာ certificate စစ်ဆေးမှု မရောက်သေးသောကြောင့် ဖြစ်သည်။ getcadcraft.com/download တွင် ဖိုင်တစ်ခုစီ၏ဘေးရှိ SHA-256 ကို စစ်ဆေးပါ။ Windows တွင် SmartScreen က installer ကို ရပ်ပါက {{ui:More info}} ကို ရွေးပြီး ထို့နောက် {{ui:Run anyway}} ကို ရွေးပါ။ Mac တွင် ပထမဆုံးအကြိမ် CadCraft Studio ကို right-click လုပ်ပြီး {{ui:Open}} ကို ရွေးပါ။ CadCraft Studio သည် အက်ပ်စတိုးတွင် မရှိသေးပါ၊ iPad သို့မဟုတ် iPhone ဗားရှင်းလည်း မရှိသေးပါ။
- {{ui:Units}} ရှိ angle နှင့် slope စာရင်းများကို သိမ်းထားသော်လည်း ၎င်းတို့ကို ဖတ်သည့် box မရှိသေးပါ။
- Field မှတ်တမ်းများကို CadCraft Studio live session တွင် မျှဝေခြင်း မရှိပါ (live session များက markup များကိုသာ သယ်သည်)၊ မိတ္တူများကို {{ui:Merge}} ဖြင့် ပေါင်းပါ။
- Merge သည် မှတ်တမ်းတစ်ခုကို နောက်ဆုံးပြောင်းထားသော မိတ္တူမှ တစ်ခုလုံး ယူသည်။ လူနှစ်ယောက်က တူညီသော မှတ်တမ်းတစ်ခု၏ အကွက်မတူညီသည်များကို ပြောင်းလဲခဲ့လျှင် နောက်ဆုံးမိတ္တူ၏ အကွက်များက ဦးစားပေးသည်။ Thread များနှင့် ပူးတွဲဖိုင်အမည်များကို ပေါင်းထားသည်။
- ပူးတွဲဖိုင်များသည် အမည်များသာ ဖြစ်ပြီး ဖိုင်များက မူလနေရာတွင်သာ ရှိသည်။ မှတ်တမ်းများအတွက် team၊ notification သို့မဟုတ် cloud project မရှိပါ၊ အကူအညီပေးသူများတွင် မှတ်တမ်းများအတွက် tools မရှိသေးပါ။
- Field မှတ်တမ်းများကို ဖုန်းနှင့် တက်ဘလက် အရွယ်အစားများဖြင့် browser တွင် ကွန်ရက်ဖြတ်ထားစဉ် စမ်းသပ်ခဲ့သော်လည်း အမှန်တကယ် တက်ဘလက်တွင် လက်ဖြင့် မစမ်းသေးပါ။
- 0.6 မှ ဆက်လက်ကျန်ရှိသည်များ- စာမျက်နှာအရာဝတ္ထုများကို မည်သည့်ထောင့်သို့မဆို လှည့်ခြင်း၊ ပုံစံအသစ်များကို စာမျက်နှာထဲ တိုက်ရိုက်ဆွဲခြင်း၊ မျဉ်း၏ font သို့မဟုတ် အရွယ်အစားကို ပြောင်းခြင်း၊ နှင့် စာကြောင်းများစွာ ကျော်ဖြတ်သွားသော စာသား။ စာမျက်နှာ ပြင်ဆင်ချက်ပါသော မိတ္တူကို Acrobat တွင် မဖွင့်ရသေးပါ။
- 0.5 မှ ဆက်လက်ကျန်ရှိသည်များ- စာမျက်နှာပြောင်းလဲမှု (ဥပမာ အလွတ်စာမျက်နှာထည့်ခြင်း) ကို undo မလုပ်နိုင်ခြင်း၊ စကင်ထားသော စာရွက်များမှ စာသား ဖတ်ခြင်း၊ နှင့် ကိုယ်ပိုင်ကွန်ရက် ပြင်ပ live session များ။

အခြားအရာများအတွက် [မတည်ဆောက်ရသေးသည့်အရာများ](topic:not-built-yet) ကို ကြည့်ပါ။
