MarkupCraft သည် touch နှင့် အလုပ်လုပ်ပါသည်: iPad (Safari သို့မဟုတ် Chrome) တွင်၊ touch-screen laptop တွင်၊ သို့မဟုတ် browser အသစ်ရှိ Windows သို့မဟုတ် Android tablet တွင်။ tablet ကို landscape ဖြင့် ထားလျှင် layout အပြည့်ကို ပြပါသည်။

## လက်ဟန်များ

| လက်ဟန် | ဘာလုပ်သလဲ |
|---|---|
| လက်ချောင်းတစ်ချောင်း | လက်ရှိကိရိယာဖြင့် ဆွဲသည်၊ သို့မဟုတ် {{ui:Select}} ဖြင့် ရွေးသည် |
| လက်ချောင်းနှစ်ချောင်း၊ ဖြန့်ခြင်း သို့မဟုတ် ညှစ်ခြင်း | လက်ချောင်းနှစ်ချောင်းကြား အမှတ်ပတ်လည် ဇူးမ်လုပ်သည် |
| လက်ချောင်းနှစ်ချောင်း၊ အတူတကွ ရွှေ့ခြင်း | ရွှေ့သည်; ဇူးမ်နှင့် ရွှေ့ကို တစ်ကြိမ်ရွှေ့ဖြင့် လုပ်နိုင်သည် |
| ဆွဲနေစဉ် ဒုတိယ လက်ချောင်း | ပထမလက်ချောင်း စတင်ထားသည်ကို ဖျက်ပြီး ဇူးမ်စတင်သည် |
| နှစ်ချက်တို့ခြင်း သို့မဟုတ် တို့ပြီး ဖိထားခြင်း | polyline, polygon, free cloud သို့မဟုတ် area ကို ပြီးစီးစေသည် |
| {{ui:Select}} ဖြင့် စာသား၊ callout သို့မဟုတ် မှတ်စုကို တို့ပြီး ဖိထားခြင်း | ၎င်း၏ စာသားကို တည်းဖြတ်ရန် ဖွင့်သည် |
| {{ui:Pan}} ဖွင့်ထားစဉ် လက်ချောင်းတစ်ချောင်း | ရွှေ့သည် |

touch screen တွင် toolbar ခလုတ်များ၊ menu များ၊ tab များနှင့် dialog ခလုတ်များသည် ပိုကြီးသဖြင့် လက်ချောင်းဖြင့် နှိပ်ရလွယ်ပါသည်။

## လက်လွှတ်သည့်အခါ ဖြစ်ပေါ်ချက်

ညှစ်ခြင်း၏ ပထမလက်ချောင်းက အမှတ်မကျန်စေရန်၊ ကိရိယာအချို့သည် သင်ထိသည့်အချိန်တွင် မဟုတ်ဘဲ **လက်လွှတ်**သည့်အချိန်တွင် လုပ်ဆောင်ပါသည်:

- {{ui:Count}}: အစက်ကို လက်လွှတ်သည့်အခါ ထည့်သည်။
- {{ui:Note}}: မှတ်စုကို လက်လွှတ်သည့်အခါ ချသည်။
- {{ui:Polyline}}, {{ui:Polygon}}, {{ui:Free cloud}} နှင့် {{ui:Area}}: point တစ်ခုစီကို လက်လွှတ်သည့်အခါ ထည့်သည်။
- {{ui:Line}}, {{ui:Arrow}}, {{ui:Length}} နှင့် {{ui:Calibrate}}: အစကို တို့ပြီးနောက် အဆုံးကို တို့လျှင် အဆုံးကို လက်လွှတ်သည့်အခါ ချသည်။

လက်ချောင်းသည် မလိုအပ်ဘဲ နည်းနည်းထက်ပို လျှောသွားလျှင် တို့ခြင်းအဖြစ် မရေတွက်ပါ၊ ဘာမျှ မထည့်ပါ။ ရှင်းရှင်းလင်းလင်း တို့ပါ; ပြင်ရန် {{ui:Undo}} ကို သုံးပါ။

ဆွဲသော ကိရိယာများ ({{ui:Pen}}, {{ui:Highlight}}, {{ui:Cloud}}, {{ui:Rectangle}}, {{ui:Ellipse}}, {{ui:Callout}}, {{ui:Text}}, {{ui:Stamp}}) သည် ထိသည်နှင့် စတင်ပါသည်; ဒုတိယလက်ချောင်းက ဖျက်ပါသည်။

## လက်ချောင်းဖြင့် ရွေးခြင်း

- markup ကို ရွေးရန် တို့ပါ; ရွှေ့ရန် ဆွဲပါ; အရွယ်ပြင်ရန် handle ကို ဆွဲပါ။ လက်ချောင်းက sheet ကို ထိပြီးနောက် markup များနှင့် handle များသည် ပစ်မှတ်ပိုကြီးပြီး handle များကို ပိုကြီးစွာ ဆွဲပါသည်။
- ဗလာ sheet ပေါ်တွင် ဆွဲ၍ ရွေးချယ်မှု ဝင်းဒိုးကို ဖွင့်ပါ (ဘယ်မှ ညာ: အပြည့်ပါဝင်; ညာမှ ဘယ်: ထိသည်)။
- {{ui:Select}} တွင် လက်ချောင်းတစ်ချောင်းဖြင့် **မ** pan လုပ်ပါ။ လက်ချောင်းနှစ်ချောင်း သုံးပါ၊ သို့မဟုတ် {{ui:Pan}} ကို ရွေးပါ။

## keyboard လိုအပ်သည့်အရာများ

keyboard မရှိလျှင် {{key:Shift}}, {{key:Esc}} သို့မဟုတ် {{key:Enter}} မရှိပါ။ ၎င်းအစား ဘာလုပ်ရမည်ကို အောက်တွင် ကြည့်ပါ:

| Keyboard လုပ်ဆောင်ချက် | keyboard မရှိလျှင် |
|---|---|
| {{key:Esc}} ဖြင့် ပယ်ဖျက်ရန် သို့မဟုတ် Select သို့ ပြန်ရန် | toolbar ရှိ {{ui:Select}} ကို နှိပ်ပါ |
| 45° မျဉ်း၊ စတုရန်းနှင့် စက်ဝိုင်းအတွက် {{key:Shift}} | ဂရုတစိုက်ဆွဲပါ; handle များဖြင့် ညှိပါ |
| ရွေးချယ်မှုထဲ ထည့်ရန် {{key:Shift}}-နှိပ်ခြင်း | ရွေးချယ်မှု ဝင်းဒိုးကို သုံးပါ |
| count အစက်ကို ဖယ်ရန် {{key:Shift}}-နှိပ်ခြင်း | မှားတို့ပြီးနောက် {{ui:Undo}} ကို နှိပ်ပါ |
| စာရိုက်ခြင်း ပြီးဆုံးရန် {{key:Mod+Enter}} | စာသား box ပြင်ပကို တို့ပါ |
| polyline ပြီးဆုံးရန် သို့မဟုတ် markup ၏ စာသားကို တည်းဖြတ်ရန် {{key:Enter}} | တို့ပြီး ဖိထားပါ၊ သို့မဟုတ် {{ui:Properties}} ရှိ {{ui:Edit on the sheet}} |
| {{key:Delete}} | toolbar သို့မဟုတ် {{ui:Properties}} ရှိ {{ui:Delete}} |
| {{key:Esc}} ဖြင့် count အုပ်စုအသစ် စတင်ခြင်း | {{ui:Select}} ဖြင့် ဗလာ sheet ကို တို့ပြီး {{ui:Count}} ကို ထပ်တို့ပါ |

keyboard case သို့မဟုတ် Bluetooth keyboard က shortcut အားလုံးကို ပြန်ပေးပါသည်; iPad တွင် ⌘ ခလုတ်က {{key:Mod+Z}} နှင့် အခြားအတွက် အလုပ်လုပ်ပါသည်။

touch တွင် ခလုတ်များသည် tooltip မပြပါ။ ကိရိယာတစ်ခုစီ၏ ကီးကို [Keyboard and mouse](topic:keyboard) တွင် ဖော်ပြထားသည်။

## Stylus နှင့် Apple Pencil

stylus (Apple Pencil, Surface Pen နှင့် တူသည်များ) သည် မောက်စ်ကဲ့သို့ အလုပ်လုပ်ပါသည်: ဆွဲပြီး ရွေးပြီး၊ ထိသည်နှင့် ချက်ချင်း လုပ်ဆောင်ပါသည်။ ညှစ်ခြင်းနှင့် ရွှေ့ခြင်းအတွက် လက်ချောင်းကို သုံးပါ။ ဖိအားသည် မျဉ်းအကျယ်ကို မပြောင်းပါ။

## iPad ပေါ်တွင် ဖွင့်ခြင်းနှင့် သိမ်းခြင်း

- {{ui:Open}} သည် Files picker ကို ပြပါသည်: iCloud Drive, On My iPad နှင့် သင်ချိတ်ဆက်ထားသော သိုလှောင်ရေး app မည်သည့်မဆို။
- {{ui:Save}} သည် download ကို မေးပါသည်; မိတ္တူသည် Files ထဲ၊ Downloads အောက်တွင် (သို့မဟုတ် Safari ၏ ဆက်တင်တွင် သတ်မှတ်ထားသော folder) ရောက်ပါမည်။

## tablet ပေါ်တွင် သင့်အလုပ်ကို ဘေးကင်းစေခြင်း

:::warning
iPad Safari သည် မသိမ်းရသေးသော အလုပ်ရှိစဉ် စာမျက်နှာမှ ထွက်သည့်အခါ သတိမပေးပါ၊ iPadOS သည် memory လွတ်စေရန် နောက်ကွယ်တွင် tab ကို ပြန် reload လုပ်နိုင်ပါသည်။ MarkupCraft သည် browser တွင် recovery မိတ္တူကို ထိန်းထားပြီး ထပ်ဖွင့်သည့်အခါ ပြန်ပေးပါသည် ([သင့်အလုပ်ကို ပြန်ယူခြင်း](common:recover) ကို ကြည့်ပါ)၊ သို့သော် **sheet တစ်ခုစီ သို့မဟုတ် လမ်းလျှောက်ကြည့်ပြီးတိုင်း သိမ်းပါ**: private tab သည် မိတ္တူ မထားပါ။
:::

- သင့်နာမည်၊ ကိရိယာ ဆက်တင်များနှင့် tool chest ကို ထို iPad ပေါ်ရှိ browser တွင် ထိန်းထားသည်၊ ကွန်ပျူတာကဲ့သို့ပင်။ [browser တွင် ဘာကျန်သလဲ](topic:browser-storage) ကို ကြည့်ပါ။
- **Signal မရှိသော site visit မတိုင်မီ:** အင်တာနက်ရှိစဉ် iPad ပေါ်ရှိ Safari (သို့မဟုတ် Chrome) တွင် MarkupCraft ကို ဖွင့်ပြီး ထိပ်ရှိ bar တွင် {{ui:Save for offline}} ကို ရွေးပါ။ "Offline ready" ဟု ပြသည်အထိ စောင့်ပါ ("Saving N of M" ဟု ရေတွက်သည်; PDF reader နှင့် writer သည် ~6 MB)။ site တွင် တူညီသော လိပ်စာ သို့မဟုတ် bookmark ကို ဖွင့်ပါ: PDF ဖွင့်ခြင်း၊ markup လုပ်ခြင်းနှင့် သိမ်းခြင်းသည် ချိတ်ဆက်မှုမရှိဘဲ အလုပ်လုပ်ပါသည်။ "Offline not available" ဟု ပြပါက သင်သည် private tab တွင် ရှိနေသည်; ပုံမှန် tab ကို သုံးပါ။ [အော့ဖ်လိုင်းတွင် အလုပ်လုပ်ခြင်း](common:offline) ကို ကြည့်ပါ။
- Safari သည် အချိန်အတော်ကြာ မသုံးထားသော အော့ဖ်လိုင်းမိတ္တူကို ဖယ်ရှားပါသည်။ ခရီးမထွက်မီ "Offline ready" ကို နှိပ်ပြီး "Save again (get the newest version)" ကို ရွေးပါ။
- အလွန်ကြီးမားသော plan set များသည် memory အများအပြား သုံးပါသည်။ tablet တွင် ဆိုဒ်ခရီးအတွက် လိုအပ်သော sheet များကိုသာ ဖွင့်ပါ။

## ဖုန်းပေါ်တွင်

အလုပ်လုပ်ပါသည်၊ သို့သော် စခရင်သေးငယ်သည်: အစိတ်အပိုင်းများ ဒေါင်လိုက် ပုံ့ပြီး (toolbar, sheet, status bar, panel များ၊ ထို့နောက် sheets စာရင်း)၊ toolbar သည် ဘေးသို့ scroll လုပ်ပါသည်။ ဖုန်းကို ကြည့်ရန်နှင့် အမြန် မှတ်စုထည့်ရန် သုံးပါ၊ စစ်စစ်ပြန်လည်သုံးသပ်ရန် tablet သို့မဟုတ် ကွန်ပျူတာကို သုံးပါ။
