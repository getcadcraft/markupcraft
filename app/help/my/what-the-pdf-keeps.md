မှတ်ထားသော မိတ္တူသည် မူရင်း PDF ပေါ်တွင် မှတ်ချက်များ (PDF annotations) ထပ်ထည့်ထားခြင်း ဖြစ်သည်။ စာမျက်နှာများ၊ ၎င်းတို့၏ ပုံဆွဲချက်များ၊ စာသား၊ bookmark များနှင့် link များကို မူလအတိုင်း ကူးယူထားသည်။

## မှတ်ချက်တစ်ခုစီ

| MarkupCraft | သိမ်းဆည်းပုံ | အခြား PDF ကြည့်ရှုသူများ မြင်ရသည့်အရာ |
|---|---|---|
| Rectangle, box cloud | Square annotation (cloud: တိမ်ပုံ နယ်နိမိတ်) | လေးထောင့် သို့မဟုတ် တိမ်ပုံ မှတ်ချက် |
| Ellipse | Circle annotation | ဘဲဥပုံ မှတ်ချက် |
| Polygon, free cloud | Polygon annotation (cloud: တိမ်ပုံ နယ်နိမိတ်) | Polygon သို့မဟုတ် တိမ်ပုံ မှတ်ချက် |
| Polyline | PolyLine annotation | Polyline မှတ်ချက် |
| Line, arrow | Line annotation (arrow: ပိတ်ထားသော မြှားဦး) | မျဉ်း သို့မဟုတ် မြှား မှတ်ချက် |
| Length | ဆိုဒ်တစ်ခုအဖြစ် တိုင်းတာမှုပါသော Line annotation | ကြည့်ရှုသူက ထောက်ပံ့သည့်နေရာတွင် အလျား တိုင်းတာမှု |
| Area | ဧရိယာအဖြစ် တိုင်းတာမှုပါသော Polygon annotation | ကြည့်ရှုသူက ထောက်ပံ့သည့်နေရာတွင် ဧရိယာ တိုင်းတာမှု၊ မဟုတ်ပါက polygon |
| Count group | Ink annotation တစ်ခု၊ အရာတစ်ခုစီအတွက် ring တစ်ခု၊ စာသားမှာ "group: n" | Ink မှတ်ချက် |
| Pen, highlighter | Ink annotation (highlighter ကို ထိုအတိုင်း မှတ်သားထား) | Ink မှတ်ချက် |
| Text | FreeText annotation | စာသားဘောက်စ် မှတ်ချက် |
| Callout | ခေါ်ဆိုချက် ဦးတည်မျဉ်းပါသော FreeText annotation | Callout မှတ်ချက် |
| Note | Text annotation | ဖွင့်လိုက်လျှင် စာသားပေါ်သော sticky note |
| Stamp | Stamp annotation | Stamp မှတ်ချက် |

အရာတိုင်းကို အောက်ပါအချက်များနှင့်အတူ သိမ်းဆည်းသည်-

- **ကိုယ်ပိုင်ပုံသဏ္ဍာန်**၊ MarkupCraft က စခရင်ပေါ်တွင် ဆွဲသည့်အတိုင်း ဆွဲထားသဖြင့် မည်သည့်ကြည့်ရှုသူတွင်မဆို တူညီစွာ မြင်ရပြီး တူညီစွာ ပုံနှိပ်ထွက်သည်၊ punch number badge ပါဝင်သည်။
- **စာရေးသူ**၊ **ဖန်တီးသည့်နှင့် ပြင်ဆင်သည့် ရက်စွဲများ**၊ **ခေါင်းစဉ်**၊ **မှတ်ချက်စာသား** (text box နှင့် callout များအတွက် စာသားနှင့် မှတ်ချက်)၊ **အရောင်** နှင့် **အကြည်ဖြာမှု (opacity)**။
- **MarkupCraft အသေးစိတ်များ** ကို အခြားပရိုဂရမ်များက လျစ်လျူရှုသော ကိုယ်ပိုင်အချက်အလက်တွင် သိမ်းထားသည်- အခြေအနေ၊ punch item၊ ပုံစံနှင့် အမျိုးအစား၊ ထို့ကြောင့် ပြန်ဖွင့်လျှင် အတိအကျ ပြန်ပေါ်လာသည်။

## စာပြန်များနှင့် အခြေအနေများ

- စာပြန်တစ်ခုစီကို ၎င်း၏ မှတ်ချက်နှင့် ချိတ်ဆက်ထားသော reply comment အဖြစ်၊ စာရေးသူ၊ ရက်စွဲနှင့် စာသားနှင့်အတူ သိမ်းသည်။ စာပြန်များတွင် စာရွက်ပေါ်တွင် ကိုယ်ပိုင် အိုင်ကွန် မရှိပါ။
- အခြေအနေပြောင်းလဲမှုတိုင်းကို review state ပါသော စာပြန်အဖြစ် သိမ်းသည်။ အခြား review ကိရိယာများက Accepted၊ Rejected သို့မဟုတ် Completed အဖြစ် ပြသည်၊ Open ကို state မပါဘဲ သိမ်းသည်။
- Open မဟုတ်သော အခြေအနေရှိသော်လည်း မှတ်တမ်းတင်ထားသော အခြေအနေပြောင်းလဲမှု မရှိသော မှတ်ချက်တစ်ခုသည် review-state စာပြန်တစ်ခု ရရှိသည်၊ ထို့ကြောင့် အခြားပရိုဂရမ်များက အခြေအနေကိုလည်း မြင်ရသည်။
- မူရင်းဖိုင်မှ ဖတ်ရန်သာ ခွင့်ပြုထားသော မှတ်ချက်များပေါ်ရှိ စာပြန်များကို ထိုမှတ်ချက်နှင့် ချိတ်ဆက်ပြီး အလားတူ သိမ်းသည်။

## စာရွက်တစ်ရွက်စီ

- **အတိုင်းအတာ (Scale):** စကေးချိန်ညှိထားသော စာရွက်တွင် စာမျက်နှာကို လွှမ်းခြုံသော measurement viewport (စာမျက်နှာစကေးကို သိမ်းဆည်းသည့် စံနည်းလမ်း) နှင့် MarkupCraft ၏ ကိုယ်ပိုင် ချိန်ညှိမှုမိတ္တူ ရရှိသည်။
- **စာရွက်နံပါတ်:** {{ui:Rename sheet}} ဖြင့် ရိုက်ထည့်သော နံပါတ်သည် စာမျက်နှာအညွှန်း ဖြစ်လာသည်။ ဖိုင်တစ်ခု၏ စာမျက်နှာတစ်ခုတွင်ပင် အညွှန်းရှိလျှင် ထိုဖိုင်၏ စာမျက်နှာအားလုံးတွင် အညွှန်း ရှိလာသည်- ရိုက်ထည့်ထားသော နံပါတ်၊ သို့မဟုတ် ယခင်အညွှန်း၊ သို့မဟုတ် စာမျက်နှာနံပါတ်။
- **စာရွက်ခေါင်းစဉ်:** ရိုက်ထည့်ထားသော ခေါင်းစဉ်ကို MarkupCraft အတွက်သာ သိမ်းသည်၊ အခြားကြည့်ရှုသူများက မပြပါ။

## စာသားနှင့် စာလုံးများ

စာသားကို ကြည့်ရှုသူ PDF အားလုံးတွင် ရှိသည့် Helvetica ဖြင့် ရေးသည်။ Western European စံ (Windows-1252) အပြင်ရှိ စာလုံးများသည် မိတ္တူတွင် "?" အဖြစ် ပုံနှိပ်သည်၊ သိမ်းဆည်းမှု မက်ဆေ့ချ်က အရေအတွက်ကို ရေတွက်ပြသည်။

## Calc စာရွက်များနှင့် အကြောင်းပြချက်များ

Calc စာရွက်များနှင့် အကြောင်းပြချက်များကို PDF ၏ `/MarkupCraftShell` ဟု အမည်ပေးထားသော ကိုယ်ပိုင်အချက်အလက်တွင် သိမ်းသည်။ အခြား PDF ပရိုဂရမ်များက လျစ်လျူရှုသည်။ ဟောင်းသော MarkupCraft က လည်း လျစ်လျူရှုပြီး ထိုဖိုင်ကို နောက်တစ်ကြိမ် သိမ်းသည့်အခါ ဖျက်ပစ်သည်။

## ရှိပြီးသား မှတ်ချက်များ၏ အဖြစ်အပျက်

မှတ်ချက်ရှိပြီးသား PDF ကို ဖွင့်သည့်အခါ-

- MarkupCraft ၏ ကိုယ်ပိုင် မှတ်ချက်များကို အတိအကျ ပြန်ဖတ်သည်။ အခြားပရိုဂရမ်တစ်ခုက ရွှေ့ခြင်း သို့မဟုတ် အရွယ်ပြောင်းခဲ့လျှင် ၎င်း၏ အသစ်ရာဇဝင်က ဦးစားပေးသည်။
- အခြားပရိုဂရမ်များမှ rectangles၊ ellipses၊ lines၊ polylines၊ polygons၊ ink၊ text boxes နှင့် sticky notes များသည် ပြင်ဆင်နိုင်သော markup များ ဖြစ်လာသည်။ **သိမ်းသည့်အခါ MarkupCraft သည် မူရင်းများကို ဖယ်ရှားပြီး ၎င်း၏ နည်းလမ်းအတိုင်း ပုံဖော်ပြန်ရေးသည်**၊ pop-up များနှင့် စာပြန်များပါဝင်သည်။ ၎င်းတို့၏ အသွင်အပြင် အနည်းငယ် ပြောင်းလဲနိုင်သည်။
- အခြားပရိုဂရမ်များမှ review state များက အခြေအနေကို သတ်မှတ်သည်၊ နောက်ဆုံးရသည်က ဦးစားပေးသည်။
- ကျန်သည့်အရာအားလုံး (စာသား highlight များ၊ အခြားပရိုဂရမ်များ၏ stamp များနှင့် အထူးအမျိုးအစားများ) ကို မိတ္တူတွင် **မထိခိုက်ဘဲ ထားရှိသည်**၊ ဖတ်ရန်သာ။
- Link များနှင့် form field များကို မထိခိုက်ဘဲ ထားရှိပြီး စာရင်းတွင် မဖော်ပြပါ။

ဖိုင်တူကို နောက်တစ်ကြိမ် ပြန်သိမ်းခြင်းသည် တစ်ခုမျှ နှစ်ဆမဖြစ်စေပါ၊ MarkupCraft ဖတ်ထားသော markup များကို အစားထိုးသည်၊ ထပ်မံမထည့်ပါ။

## မပြောင်းလဲသည့်အရာများ

ဒစ်ဖိုင်ပေါ်ရှိ မူရင်းဖိုင်ကို ဘယ်တော့မှ မပြောင်းလဲပါ။ မိတ္တူကို အရွယ်အစားအတွက် optimize မလုပ်ထားသဖြင့် မူရင်းထက် အနည်းငယ် ပိုကြီးနိုင်သည်။ ကာကွယ်ထားသော (encrypted) PDF များကို သိမ်း၍ မရပါ။
