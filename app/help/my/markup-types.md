## markup တိုင်းတွင် ပါဝင်သည်များ

| အကွက် | ဘယ်မှာ မြင်ရမလဲ |
|---|---|
| Author | {{ui:Properties}}၊ စာရင်း၊ တံဆိပ်၏ ဒုတိယစာကြောင်း၊ အခြား PDF viewer များ |
| Created and modified | {{ui:Properties}} (သင်၏ အချိန်ဇုန်)၊ စာရင်း၊ CSV |
| Status | Open၊ Accepted၊ Rejected သို့မဟုတ် Completed |
| Subject | တိုသော အမည်; မူလအားဖြင့် အမျိုးအစား ("Cloud"၊ "Text box"၊ "Length measurement") |
| Comment | ပိုရှည်သော မှတ်စုများ။ note အတွက် ၎င်း၏စာသားသည် ၎င်း၏ comment ဖြစ်သည်။ |
| Text | Text box နှင့် callout များအတွက်သာ |
| Replies | ဆက်စပ်စာကြောင်း၊ status ပြောင်းလဲမှုများနှင့်အတူ |
| Punch item | နံပါတ်၊ တာဝန်ခံ၊ နောက်ဆုံးရက်၊ item status၊ punch list သို့ ထည့်သောအခါ |
| Style | အရောင်၊ မျဉ်းအကျယ်၊ ဖြည့်ခြင်းနှင့် ဖြည့်ခြင်း အလင်းဝင်နှုန်း (ပိတ်ထားသော ပုံသဏ္ဍာန်များ၊ စာသားနှင့် callout များ)၊ အလင်းဝင်နှုန်း၊ စာသားအရွယ် (စာသား၊ callout နှင့် တိုင်းတာမှုများ) |

## ဖတ်ရုံသာ မှတ်ချက်များ

ဖိုင်နှင့်အတူ လာသော်လည်း MarkupCraft မတည်းဖြတ်နိုင်သော မှတ်ချက်များ (စာသား highlight များ၊ အခြား programs ၏ တံဆိပ်များနှင့် အခြား အထူး အမျိုးအစားများ) ကို "Other" အမျိုးအစားဖြင့် နှင့် "Read-only" status chip ဖြင့် စာရင်းပြုသည်။ ၎င်းတို့သည် ဖိုင်က ပေးထားသည့် ပုံစံအတိုင်း ဆက်ရှိနေသည်။ ရွေးနိုင်ပြီး၊ author၊ subject နှင့် comment ကို ကြည့်နိုင်ပြီး ပြန်ကြားချက် ပေးနိုင်သည်။

## မတည်ဆောက်ရသေးသည်များ

ဖိုင် attachment များကို မတည်ဆောက်ရသေးပါ။ markup မည်သည့်အရာမဆို စာရွက်သို့ link ချိတ်နိုင်သည်; see [Sheet links](topic:sheet-links)။ ပုံများနှင့် လက်မှတ်များကို {{ui:Stamp}} ကိရိယာဖြင့် ထည့်သည်; see [Stamps and notes](topic:stamps-and-notes)။ see [What is not built yet](topic:not-built-yet)။
