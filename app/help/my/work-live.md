## သင်လေ့လာရမည့်အရာ

ပုံဆွဲစာရွက်အစုတစ်ခုကို လူများစွာက တစ်ပြိုင်နက် သုံးသပ်နေစဉ် markup များ၌ ဘာဖြစ်သည်။ CadCraft Studio သည် Live TeamWork session ကို စတင် (Share live) သို့မဟုတ် ဝင် (Join) သည်; ဤစာမျက်နှာသည် စာရွက်အစုကိုယ်တိုင်အကြောင်းဖြစ်သည်။

## လူအားလုံး တစ်ပြိုင်နက် မှတ်သားခြင်း

Host ၏ PDF များသည် ဝင်လာသူအားလုံးထံ ရောက်သဖြင့် သင်တို့အားလုံး တူညီသော စာရွက်များကို ကြည့်သည်။ ပုံမှန်အတိုင်း markup များကို ဆွဲ၊ ရွှေ့၊ ပုံစံပြောင်းနှင့် ဖျက်နိုင်သည်။ သင့်ကိုယ်ပိုင်ပြောင်းလဲချက်များ ချက်ချင်းပေါ်ပြီး အခြားသူများ၏ပြောင်းလဲချက်များသည် ၎င်းတို့ ပြုလုပ်ပြီး ခဏအကြာတွင် ပေါ်လာသည်။

- **လူနှစ်ဦးက markup တစ်ခုကို ပြောင်းလျှင်:** မတူသော အရာများ (တစ်ဦးက အရောင်၊ တစ်ဦးက မျဉ်းအထူ) နှစ်ခုစလုံး ထိန်းထားသည်။ တူညီသော အရာအတွက်မူ နောက်ပိုင်းပြောင်းလဲမှုက ရလဒ်ကို သတ်မှတ်သည်။
- **စာပြန်များ:** လူတိုင်း၏ စာပြန်များသည် ရေးသားခဲ့သော အစဉ်အတိုင်း thread တွင် ရှိနေသည်။ အခြေအနေများလည်း တူညီစွာ ပို့သည်။
- **အတိုင်းအတာနှင့် စာရွက်အမည်များ** တစ်ဦးက သတ်မှတ်လျှင် လူအားလုံးအတွက် ကျင့်သုံးသည်။
- **Punch နံပါတ်များ** ဘယ်တော့မှ မထပ်ပါ- လူနှစ်ဦးက တစ်ချိန်တည်းတွင် punch item ထည့်လျှင် တစ်ဦး၏ ထည့်ချက်ကို ပြန်ယူသွားပြီး ၎င်းသည် ထပ်ထည့်နိုင်သည်။

သင့်ကိုယ်တိုင်သာ ထားရှိသည့်အရာများ- သင်ဖျောက်ထား သို့မဟုတ် လော့ခ်ချထားသော layer များ၊ စိတ်ကြိုက် ကော်လံများ၊ view၊ သင့်ကိရိယာနှင့် စာရေးသူအဖြစ် သင့်အမည်။

## ဘယ်သူ ဘယ်မှာရှိသလဲ ကြည့်ခြင်း

သုံးသပ်သူတစ်ဦးစီတွင် အရောင်တစ်ခုရှိသည်။ သင်ကြည့်နေသော စာရွက်ပေါ်တွင် အခြားသူများ၏ pointer များကို အမည်ဖြင့် မြင်ရပြီး၊ သူတို့ ရွေးထားသော markup များပတ်လည်တွင် သူတို့အရောင်ဖြင့် အစက်အပြတ်ဘောက်စ်ကို မြင်ရသည်။ စာရွက် ထိပ်ညာဘက်ရှိ သုံးသပ်သူများ၏ အစင်းတစ်ခုက တစ်ဦးချင်းစီ ရှိနေသည့် စာရွက်ကို ပြသပြီး အမည်ကို နှိပ်လျှင် ထိုစာရွက်သို့ ရောက်သွားသည်။

Markup စာရင်းတွင် စာရေးသူ၏ အမည်ဘေးရှိ အစက်သည် သုံးသပ်သူ၏ အရောင်ဖြစ်သဖြင့် ဘယ်သူ ဘာရေးခဲ့သည်ကို တစ်ချက်ကြည့်ဖြင့် သိနိုင်သည်။ စာရေးသူ စစ်ထုတ်ချက်က သုံးသပ်သူတစ်ဦး၏ markup များကို ရှာပေးသည်။ PDF ကို သိမ်းလျှင် markup တိုင်းတွင် စာရေးသူ ပါဝင်သဖြင့် သုံးသပ်ပြီးသော စာရွက်အစုတွင် ဘယ်သူ ဘာရေးခဲ့သည်ကို ပြသည်။

Pointer များနှင့် အရောင်များသည် session အတွက်သာ ဖြစ်ပြီး PDF တွင် မသိမ်းပါ။

## ပြောင်းလဲချက် ပြန်ယူခံရသည့်အခါ

Host ၏ မိတ္တူက ပြောင်းလဲချက်တိုင်းကို စစ်ဆေးသည်။ ထည့်၍မရသော ပြောင်းလဲချက်ကို သင့်စခရင်ပေါ်တွင် ပြန်ယူပြီး status bar က အကြောင်းရင်းကို ပြောသည်၊ ဥပမာ ယခုမျှ မကြာခင်က တစ်စုံတစ်ဦးက ထို markup ကို ဖျက်လိုက်လျှင်။

## Undo သည် သင်၏ကိုယ်ပိုင်အလုပ်ကိုသာ ပြန်ယူသည်

{{key:Mod+Z}} သည် သင်၏ နောက်ဆုံးပြောင်းလဲချက်ကို ပြန်ယူပြီး အခြားသူများ၏ အရာများကို မထိခိုက်ပါ။ ထို့နောက် တစ်စုံတစ်ဦးက တူညီသော အရာကို ပြောင်းလဲခဲ့လျှင် ဘာမှ ပြန်မယူရပြီး status bar က ဘယ်သူလဲဟု ပြောသည်။

## Browser မှ ဝင်ခြင်း

Studio မရှိသော အဖွဲ့ဝင်တစ်ဦးက host ၏ code အောက်ရှိ ပုံကို ဖုန်း၊ တက်ဘလက် သို့မဟုတ် ကွန်ပျူတာဖြင့် ကွန်ရက်တူညီသည့်နေရာမှ စကင်နိုင်သည်။ MarkupCraft သည် browser တွင် ဖွင့်ပြီး host က ခွင့်ပြုသည့်အခါ host ၏ ပုံဆွဲစာရွက်အစုဖြင့် ဖြည့်သည်။ အခြားကွန်ရက်မှ ဝင်ရန် ဖိတ်ခေါ်လင့်ခ်တစ်ခုရှိသည်- host သည် အက်ပ်အတွက် Team Cloud Plan seat လိုသည်၊ အခြားသူများက အခမဲ့ ဝင်နိုင်ပြီး၊ လင့်ခ်သည် host ၏ session ဖွင့်နေချိန်တွင်သာ အလုပ်လုပ်သည်။

## Session ပြီးဆုံးသည့်အခါ

Host က သာ markup ပါသော PDF များကို သိမ်းသည်။ အခြားသူအားလုံးသည် မသိမ်းရသေးသော မိတ္တူကို ထားရှိသည်; ထိန်းချင်လျှင် သိမ်းပါ။

:::note
ဝင်ပြီးနောက် သင်ဖွင့်သော PDF များသည် သင့်စခရင်တွင်သာ ရှိနေပြီး အခြားသူများ မရရှိပါ။
:::
