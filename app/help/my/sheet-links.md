စာရွက်လင့်ခ်သည် မှတ်ချက်တစ်ခုမှ set ၏ အခြားစာရွက်သို့ သင့်ကို ခေါ်သွားပါသည်: detail bubble မှ detail သို့၊ မှတ်စုမှ ၎င်းရည်ညွှန်းသော စာရွက်သို့။

## မှတ်ချက်တစ်ခုကို စာရွက်သို့ လင့်ခ်ချိတ်ခြင်း

1. မှတ်ချက်ကို ရွေးပါ။
2. {{ui:Properties}} တွင် {{ui:Link to sheet}} အောက်ရှိ စာရွက်ကို ရွေးပါ။

မှတ်ချက်၏ ညာဘက်ထိပ်တွင် မြှားသေးသေးလေး ပေါ်လာပါမည်။ လိုက်သွားရန် {{key:Mod}} ကို ဖိထားပြီး မှတ်ချက်ကို နှိပ်ပါ၊ သို့မဟုတ် ရွေးပြီး {{ui:Properties}} ရှိ {{ui:Go to …}} ကို ရွေးပါ။ {{key:Alt+Left}} သည် သင်လာခဲ့သော စာရွက်သို့ ပြန်သွားပါသည်။

လင့်ခ်သည် စာရွက်ကို နံပါတ်ဖြင့် ခေါ်ထားသဖြင့် set ကို ပြန်ဖွင့်ပြီးနောက် သို့မဟုတ် စာရွက်အသစ် slip-sheet လုပ်ပြီးနောက်တွင်ပင် အလုပ်လုပ်ပါသည်: ထိုနံပါတ်ရှိ အသစ်ဆုံး စာရွက်ကို ဖွင့်ပေးပါသည်။ ထိုစာရွက် ဖွင့်မထားပါက status bar က ထိုအကြောင်း ပြပါသည်။

## စာရွက် callout အားလုံးကို တစ်ကြိမ်တည်း လင့်ခ်ချိတ်ခြင်း

{{ui:Pages}} › {{ui:Batch links…}} ကို ရွေးပါ၊ သို့မဟုတ် {{ui:Sheets}} panel ထိပ်ရှိ {{ui:Find text}} အောက်ရှိ {{ui:Link sheet callouts…}} ကို ရွေးပါ။

1. **စာရွက်နံပါတ်များကို စစ်ဆေးပါ။** MarkupCraft သည် ဖွင့်ထားသော စာရွက်တိုင်း၏ နံပါတ်နှင့် အမည်ကို ၎င်း၏ title block (သို့မဟုတ် page label) မှ ဖတ်ထားသည့်အတိုင်း နှင့် မည်သည့်နေရာမှ ရလာသည်ကို ဖော်ပြပါသည်။ မှားနေသည်များကို ပြင်ပါ၊ မတွေ့သည့်နေရာတွင် နံပါတ်ရိုက်ပါ (title block ၏ နံပါတ်ကို မျဉ်းများအဖြစ် ပုံနှိပ်ထားပါက စာသား မရှိပါ)။ ထို့နောက် {{ui:Find callouts}} ကို ရွေးပါ။ သင့်ပြင်ဆင်မှုများသည် undo အဆင့်တစ်ခု ဖြစ်ပြီး သိမ်းထားသော PDF တွင် page labels ဖြစ်လာပါမည်။
2. **စာရင်းကို သုံးသပ်ပါ။** MarkupCraft သည် စာရွက်တိုင်း၏ စာသားကို "3/A-501"၊ "5 / A501"၊ "DETAIL 2 ON A-501"၊ "3" အပေါ် "A-501" ရှိ bubble သို့မဟုတ် မှတ်စုထဲရှိ ရိုးရိုး "A-501" ကဲ့သို့ callouts များအတွက် ဖတ်ပြီး၊ စာရွက်တိုင်း၏ view ခေါင်းစဉ်များ (detail နံပါတ်နှင့် အောက်တွင် စာရွက်နံပါတ်၊ သို့မဟုတ် ခေါင်းစဉ်ဘေးရှိ ကြီးသော နံပါတ်) ကို ဖတ်ပါသည်။ စာရင်းတွင် အပိုင်း သုံးပိုင်း ရှိပါသည်:
   - {{ui:Will link}}: callout တစ်ခုစီ၊ ၎င်းသွားမည့် စာရွက်နှင့် ထိုစာရွက်ပေါ်ရှိ view။ မလိုချင်သည်များကို အမှန်ခြစ်ဖြုတ်ပါ။ View မတွေ့ပါက (ဥပမာ view 1 မှ 6 ပါသော စာရွက်သို့ view 7 ကို callout ခေါ်သည်) ဘေးရှိ စာရင်းမှ view ကို ရွေးပါ၊ သို့မဟုတ် {{ui:Whole sheet}} ကို ထားပါ။
   - {{ui:Not linked}}: ဖွင့်ထားသော စာရွက်မရှိသော စာရွက်နံပါတ်များ၊ နံပါတ်တစ်ခုစီကို ရည်ညွှန်းသော callouts အရေအတွက်ဖြင့်။ နံပါတ်တစ်ခုစီက ဆိုလိုသည့် စာရွက်ကို ရွေးပါ (ဥပမာ နံပါတ်အသစ်ပြောင်းထားသော စာရွက်)၊ ထိုနံပါတ်သို့ ရည်ညွှန်းသော callout အားလုံး ထိုစာရွက်သို့ လင့်ခ်ချိတ်ပါမည်။ သို့မဟုတ် လင့်ခ်မချိတ်ဘဲ ထားပါ။
   - ဆက်ဆံရေးမှန်ကန်စွာ လင့်ခ်ချိတ်ပြီးသား callouts အရေအတွက်။ ၎င်းတို့ကို ထားရှိပါမည်။
3. **{{ui:Create the links}}** ကို ရွေးပါ။

Callout တစ်ခုစီတွင် စာရွက်လင့်ခ်ဖြစ်သော ပါးသော အပြာရောင် ဘောင်တစ်ခု ရရှိပါမည်။ ၎င်းပေါ်တွင် {{key:Mod}}+နှိပ်လျှင် စာရွက်ကို view သို့ zoom လုပ်ပြီး ဖွင့်ပါမည်။ {{key:Mod+Z}} တစ်ကြိမ်ဖြင့် အားလုံးကို ဖယ်ရှားပါသည်။

စာရွက်နံပါတ်ကဲ့သို့ ထင်ရသော ကုဒ်များ၊ ဥပမာ R-19 သို့မဟုတ် W12X26 ကို ထားခဲ့ပါသည်: callout သည် set ၏ ကိုယ်ပိုင် စာရွက်နံပါတ်ပုံစံနှင့် တူရမည်။ စာရွက်၏ ကိုယ်ပိုင်နံပါတ်၊ title block နှင့် view ခေါင်းစဉ်များတွင်ရှိသော နံပါတ်သည် ဘယ်တော့မှ callout မဖြစ်ပါ။ စကင်ဖတ်ထားသော စာရွက်များတွင် ဖတ်စရာစာသား မရှိပါ: ဦးစွာ {{ui:Read text (OCR)…}} ကို သုံးပါ၊ သို့မဟုတ် ၎င်းတို့၏ callouts ကို တစ်ခုချင်း လင့်ခ်ချိတ်ပါ။

## Set ပြောင်းသောအခါ ထပ်လုပ်ခြင်း

Batch links ကို လိုသလောက် ထပ်လုပ်နိုင်ပါသည်:

- **စာရွက်တစ်ခု ထပ်တိုးသောအခါ**၊ ဥပမာ A-601 ပါသော addendum: ၎င်း၏ဖိုင်ကို ဖွင့်ပြီး Batch links ကို ထပ်လုပ်ပါ။ အရင်က မလင့်ခ်ချိတ်ရသေးသော A-601 သို့ callouts များ ယခု လင့်ခ်ချိတ်ပါမည်။
- **စာရွက်နံပါတ် ပြောင်းသောအခါ**: အဆင့် 1 တွင် ၎င်း၏ နံပါတ်ကို ပြင်ပါ။ Batch links က ဖန်တီးထားသော လင့်ခ်များ ၎င်းတို့ စာရွက်ကို မတွေ့တော့သည့်အခါ **Not linked** အောက်တွင် ဖော်ပြပါမည်။ စာရွက်တစ်ခုကို တစ်ကြိမ် ရွေးပါက ၎င်းတို့အားလုံး လိုက်ပါမည်။ တခြား view သို့ ရွေ့သွားသော လင့်ခ်များကို အသစ်ပြင်ပါမည်။
- သင် **Properties** တွင် ကိုယ်တိုင် ဖန်တီးသော လင့်ခ်များကို ဘယ်တော့မှ မပြောင်းပါ။

## သိမ်းထားသော PDF တွင်

PDF တစ်ခုတည်းရှိ စာရွက်သို့ လင့်ခ်ကို PDF link အဖြစ်လည်း ရေးပါသည်၊ ထို့ကြောင့် အခြား viewer များတွင် click လုပ်ပါက ထိုနေရာသို့ ခုန်သွားပါသည်။ View ပါသော လင့်ခ်သည် အခြား viewer တွင် ထို view ကို ဖွင့်ပါသည် (PDF "fit rectangle" jump); view မပါသော လင့်ခ်သည် စာရွက်တစ်ခုလုံးကို ဖွင့်ပါသည်။ Set ရှိ အခြားဖိုင်ရှိ စာရွက်သို့ လင့်ခ်များသည် MarkupCraft တွင်သာ အလုပ်လုပ်ပါသည်။
