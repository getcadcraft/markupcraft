## ပြောင်းလဲမည့်အရာကို ရွေးခြင်း

1. {{ui:Select}} အုပ်စုတွင် {{ui:Content}} ကို ရွေးပါ၊ သို့မဟုတ် {{key:B}} ကို နှိပ်ပါ။
2. {{ui:Properties}} အောက်ရှိ {{ui:Pick}} တွင် {{ui:Shapes}}, {{ui:Pictures}} နှင့် {{ui:Text}} ကို ဖွင့်/ပိတ် ပြောင်းပါ။ ဖွင့်ထားသော အမျိုးအစားများကိုသာ ရွေးနိုင်သဖြင့် ရှုပ်ထွေးသော ပုံဆွဲချက်၏ စာသားကို မျဉ်းများမပါဘဲ ရွေးနိုင်ပါသည်။
3. အရာတစ်ခုကို နှိပ်၍ ရွေးပါ။ Shift+နှိပ်ခြင်းဖြင့် ထည့်ခြင်း သို့မဟုတ် ဖယ်ခြင်း ပြုလုပ်နိုင်သည်။ အလွတ်စာရွက်ပေါ်တွင် ဘောင်ဆွဲ၍ အများအပြား ရွေးပါ: ညာဘက်သို့ ဆွဲလျှင် ဘောင်အတွင်း အပြည့်ပါသည်၊ ဘယ်ဘက်သို့ ဆွဲလျှင် ထိသည်ကို ယူပါသည်။

clip ထားသော နေရာအတွင်းရှိ ပုံသဏ္ဍာန်ကို မြင်ရသည့် နေရာတွင်သာ ရွေးနိုင်ပါသည်။

## ရွှေ့ခြင်း၊ အရွယ်ပြင်ခြင်း၊ အရောင်ပြောင်းခြင်း၊ ဖျက်ခြင်း

- **ရွှေ့:** ရွေးထားသော object ကို ဆွဲပါ၊ သို့မဟုတ် မြားခလုတ်များကို နှိပ်ပါ ({{key:Shift}} ကို ဖိထားလျှင် ပိုကြီးသော အဆင့်ဖြင့်)။ ဆွဲနေစဉ် {{key:Shift}} ကို ဖိထားလျှင် တည့်တည့် ဘေးသို့ သို့မဟုတ် တည့်တည့် အပေါ်သို့ ရွှေ့ပါသည်။
- **အရွယ်ပြင်:** ရွေးချယ်မှုပတ်လည်ရှိ စတုရန်းပုံ ရှစ်ခုထဲမှ တစ်ခုကို ဆွဲပါ။ ဆန့်ကျင်ဘက်ဘက်မှ ကြီးလာ သို့မဟုတ် ကျဉ်းလာပါသည်။ အချိုးကို ထိန်းရန် {{key:Shift}} ကို ဖိထားပါ။
- **အရောင်ပြောင်း:** မျဉ်းနှင့် ပုံသဏ္ဍာန်များအတွက် {{ui:Properties}} တွင် {{ui:Line color}}, {{ui:Fill color}} နှင့် {{ui:Line width (pt)}} ကို သတ်မှတ်ပါ။
- **ဖျက်:** {{key:Delete}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:Delete from the page}} ကို ရွေးပါ။
- **ပြန်ဖျက်:** ပြောင်းလဲမှုတစ်ခုစီသည် အဆင့်တစ်ခု ဖြစ်သည်; {{key:Mod+Z}} က ပြန်ယူပြီး {{key:Mod+Y}} က ပြန်ထားပါသည်။

{{ui:Put back as it was}} သည် ရွေးထားသော object များ၏ ပြောင်းလဲမှုအားလုံးကို တစ်ကြိမ်တည်း ပြန်ဖျက်ပါသည်; {{ui:Put this page back as it was}} သည် စာမျက်နှာတစ်ခုလုံးအတွက် ပြုလုပ်ပါသည်။

## စာမျက်နှာ အကြောင်းအရာကို ကူးခြင်း၊ ဖြတ်ခြင်းနှင့် ကူးထည့်ခြင်း

{{ui:Content}} ကိရိယာဖြင့် မျဉ်း၊ ပုံ သို့မဟုတ် စာသားကို ရွေးပြီး:

- {{key:Mod+C}} ကူးသည်၊ {{key:Mod+X}} ဖြတ်သည် (ကူးပြီး စာမျက်နှာမှ ဖယ်ထုတ်သည်)၊ {{key:Mod+D}} က ဘေးတွင် မိတ္တူထားသည်။
- {{key:Mod+V}} သည် စာမျက်နှာ အကြောင်းအရာအဖြစ် ကူးထည့်ပါသည်၊ မူရင်းဘေး သို့မဟုတ် ညွှန်ပြချက်ရှိနေရာတွင် ([ဆက်တင်များ](topic:settings) တွင် ဖော်ပြထားသည့်အတိုင်း)။ {{key:Mod+Shift+V}} က အတိအကျ နေရာတူတွင် ကူးထည့်ပါသည်။ တူညီသော browser ရှိ တခြား စာမျက်နှာ၊ ဖွင့်ထားသော PDF တစ်ခု သို့မဟုတ် တခြား MarkupCraft tab တွင် ကူးထည့်နိုင်ပါသည်။
- {{ui:Edit}} အုပ်စုရှိ menu နှင့် right-click menu တွင် အမိန့်တူညီပါသည်။

ကူးထည့်ခြင်းသည် မျဉ်းများကို မျဉ်းအဖြစ်၊ စကားလုံးများကို ၎င်းတို့၏ font ဖြင့် စကားလုံးအဖြစ်၊ ပုံများကို ပုံအဖြစ် ထိန်းပါသည်။ ၎င်းသည် တစ်ခုတည်းသော အစိတ်အပိုင်း ဖြစ်ပါသည်: ရွှေ့ပါ၊ လေးထောင့်ဖြင့် အရွယ်ပြင်ပါ၊ ဖျက်ပါ သို့မဟုတ် {{key:Mod+Z}} ဖြင့် ပြန်ဖျက်ပါ။ ၎င်းသည် သိမ်းသော မိတ္တူတွင် စာမျက်နှာ၏ အစိတ်အပိုင်း ဖြစ်လာပါသည်။ နောက်ဆုံး ကူးထားသည့်အရာ (markup သို့မဟုတ် page content) ကို {{key:Mod+V}} က ကူးထည့်ပါသည်။

မိတ္တူတွင် ပါဝင်သည်များကို ရွေးချယ်မှု ပတ်လည် ဘောင်သို့ ဖြတ်ထားပါသည်: MarkupCraft မိတ္တူမှ ဖယ်ထုတ်၍ မရသော (အောက်တွင် ကြည့်ပါ) အရာနှင့် ထိုဘောင်အတွင်းရှိ အရာများသည် လိုက်ပါလာပါမည်။

## မျဉ်း၏ point များကို ရွှေ့ခြင်း

မျဉ်း သို့မဟုတ် ကွေးကို နှစ်ချက်နှိပ်ပါ (သို့မဟုတ် ရွေးပြီး {{ui:Edit points}} ကို ရွေးပါ)။ ၎င်း၏ point များကို စတုရန်းပုံအဖြစ်၊ curve handle များကို စက်ဝိုင်းအဖြစ် ပြပါသည်။ point သို့မဟုတ် handle ကို ဆွဲပါ; point တစ်ခုက ၎င်းနားရှိ handle များကို အတူ ရွှေ့ပြီး ကွေးသည် ပုံသဏ္ဍာန်ကို ထိန်းပါသည်။ ပြီးသည့်အခါ {{key:Esc}} ကို နှိပ်ပါ၊ သို့မဟုတ် မျဉ်းမှ ဝေးဝေးနှိပ်ပါ။

စတုဂံများတွင် ဆွဲရန် point မရှိပါ: ၎င်းတို့ပတ်လည်ရှိ စတုရန်းပုံများဖြင့် အရွယ်ပြင်ပါ။

## ပုံကို အစားထိုးခြင်း

ပုံကို ရွေးပြီး {{ui:Replace picture…}} ကို ရွေးပါ၊ ထို့နောက် PNG, JPEG သို့မဟုတ် SVG ဖိုင် (သို့မဟုတ် PDF: ပထမစာမျက်နှာ) ကို ရွေးပါ။ ပုံအသစ်သည် ဟောင်း၏ နေရာကို ဖြည့်ပြီး ၎င်း၏ ကိုယ်ပိုင် အချိုးကို ထိန်းပါသည်။

## စာကြောင်း၏ စာသားကို ပြောင်းခြင်း

စာကြောင်းကို နှစ်ချက်နှိပ်ပါ၊ {{ui:Words}} တွင် စကားအသစ်ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။ စကားများကို စာကြောင်း၏ ကိုယ်ပိုင် font နှင့် size ဖြင့် ရေးပြီး စာကြောင်း၏ အရှည် ထိန်းပါသည်၊ ထို့ကြောင့် နောက်ဆက် စာသား မရွှေ့ပါ။

:::note
PDF အများစုသည် ၎င်းတို့အသုံးပြုသော စာလုံးများကိုသာ font တစ်ခုစီမှ ထည့်ထားပါသည်။ ဖိုင်၏ font တွင် မပါသော စာလုံးကို ရိုက်လျှင် MarkupCraft က ထိုစာလုံးကို Helvetica ဖြင့် ပရင့်ပြီး ထိုသို့ ပြောပါသည်။ {{ui:Properties}} တွင် ဖိုင်ရှိ font က မည်သည့် စာလုံးများ ပါသည်ကို ပြပါသည်။
:::

စာသားကို စာကြောင်းတစ်ကြောင်းချင်း ပြောင်းပါသည်; နောက်စာကြောင်းသို့ စီးဆင်းခြင်း မရှိပါ။

## MarkupCraft ဘာကို မပြောင်းဘဲ ထားခဲ့သလဲ

- **Encrypt လုပ်ထားသော နှင့် လက်မှတ်ထိုးထားသော PDF များ:** စာမျက်နှာကို ပြောင်းလျှင် လက်မှတ်ပျက်မည်ဖြစ်သဖြင့် {{ui:Content}} ကိရိယာက ထိုသို့ ပြောပြပြီး ဘာမျှ မပြောင်းပါ။ markup များက ဆက်အလုပ်လုပ်ပါသည်။
- **Clip နယ်ပယ်များ၊ စာမျက်နှာ အကြောင်းအရာ၏ အပိုင်းနှစ်ခုကြား ခွဲထားသော object များ၊ နယ်ပယ်တစ်ခုလုံးကို ဖြည့်သော အရောင် blend များ** သည် မူလအတိုင်း ရှိနေပါသည်; ကြိုးစားသည့်အခါ MarkupCraft က အကြောင်းပြောပါသည်။
- **PDF က ဖော်ပြမထားသော စံ font ရှိ စကားလုံးများ** (ဖိုင်တွင် အက္ခရာအကျယ် မပါသော Times font ကဲ့သို့) ကို ပြောင်း၍ မရပါ၊ MarkupCraft က စာကြောင်း၏ အကွာအဝေးကို ထိန်း၍ မရသောကြောင့်ဖြစ်သည်။ စာကြောင်းကို ရွှေ့နိုင်ဆဲ ဖြစ်ပါသည်။

## Markup များကို စာမျက်နှာထဲ ထည့်ခြင်း

markup အဖြစ် ဆွဲထားသော မျဉ်း၊ စတုဂံ၊ ellipse၊ polyline၊ တိမ်နှင့် ပင်ကလုံးရေးချက်များသည် စာမျက်နှာ၏ အစိတ်အပိုင်း ဖြစ်လာနိုင်ပါသည်: ရွေးပြီး {{ui:Properties}} တွင် {{ui:Put into the page}} ကို ရွေးပါ။ စာသား၊ stamp၊ ပုံများနှင့် ပွင့်လင်းသော အရောင်များသည် markup အဖြစ်သာ ကျန်ပါမည်။
