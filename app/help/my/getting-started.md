MarkupCraft သည် ပုံဆွဲများကို သုံးသပ်ရန်အတွက် ဖြစ်သည်- PDF ပုံဆွဲအစုံများ ဖွင့်ပါ၊ cloud၊ callout၊ စာသား၊ တံဆိပ်များနှင့် တိုင်းတာမှုများဖြင့် မှတ်ချက်ထည့်ပါ၊ မှတ်ချက်တစ်ခုစီ၏ အခြေအနေကို ခြေရာခံပါ၊ ပြီးလျှင် မည်သည့် PDF ကြည့်ရှုသူမဆို ပြနိုင်သော PDF မိတ္တူကို သိမ်းပါ။

၎င်းသည် သင့်ဝဘ်ဘရောက်ဆာတွင် အလုပ်လုပ်သည်။ သင့် PDF များကို သင့်ကွန်ပျူတာပေါ်တွင်သာ ဖွင့်ပြီး **ဘယ်တော့မှ မတင်ပါ**။ သိမ်းခြင်းသည် မိတ္တူအသစ်ကို ဒေါင်းလုဒ်ဆွဲသည်၊ မူရင်းဖိုင်သည် မပြောင်းလဲပါ။

:::note
MarkupCraft သည် ဖွံ့ဖြိုးဆဲ အဆင့်တွင် ရှိသည်။ ဤအကူအညီသည် သင် လည်ပတ်နေသော ဗားရှင်းကို ဖော်ပြသည်။ မလုပ်ဆောင်နိုင်သေးသော အရာများကို [ဘာတွေ မလုပ်ရသေးလဲ](topic:not-built-yet) တွင် ဖော်ပြထားသည်။
:::

## သင်လိုအပ်သည်များ

- Mac၊ Windows သို့မဟုတ် Linux ကွန်ပျူတာပေါ်ရှိ နောက်ဆုံးရ Chrome၊ Edge၊ Firefox သို့မဟုတ် Safari၊ သို့မဟုတ် iPad ပေါ်ရှိ Safari သို့မဟုတ် Chrome။ [ဘရောက်ဆာများနှင့် ကွန်ပျူတာများ](common:browsers) ကို ကြည့်ပါ။
- PDF ဖိုင် တစ်ခု သို့မဟုတ် တစ်ခုထက်ပို။ ပုံဆွဲအစုံတစ်ခုလုံးသည် PDF တစ်ခု သို့မဟုတ် အများအပြား ဖြစ်နိုင်သည်။
- ဘီးပါသော မောက်စ်သည် အသက်သာဆုံးဖြစ်သည်။ Trackpad လည်း အလုပ်လုပ်ပြီး touch screen လည်း ရသည် ([iPad သို့မဟုတ် touch screen ဖြင့် သုံးသပ်ခြင်း](topic:review-on-a-tablet) ကို ကြည့်ပါ)။

## ပထမဆုံး သုံးသပ်ချက်- ဆင့် ၁၀ ဆင့်

1. ဘရောက်ဆာတွင် MarkupCraft ကို ဖွင့်ပါ။ မျက်နှာပြင်အလယ်တွင် "ပုံဆွဲအစုံ ဖွင့်ပါ" ဟု ပြသည်။
2. {{ui:Open PDFs}} (သို့မဟုတ် ကိရိယာဘား ဘယ်ဘက်အဆုံးရှိ {{ui:Open}}၊ သို့မဟုတ် {{key:Mod+O}} ကို နှိပ်ပါ) ကို ရွေးပါ၊ PDF တစ်ခု သို့မဟုတ် တစ်ခုထက်ပိုကို ရွေးပြီး အတည်ပြုပါ။
   {{pick:mac=Finder|windows=File Explorer|linux=သင့်ဖိုင်မန်နေဂျာ}} မှ PDF များကို ဆွဲယူပြီး စာရွက်နေရာပေါ် ချနိုင်သည်။
   ပထမအကြိမ်တွင် အခြေအနေဘား (အောက်ဆုံး) က "PDF ဖတ်ကိရိယာ တင်နေသည်…" ဟု ပြသည်။ ထို့နောက် စာမျက်နှာတိုင်း ဘယ်ဘက်ရှိ {{ui:Sheets}} စာရင်းတွင် စာရွက်တစ်ရွက် ဖြစ်လာပြီး ပထမစာရွက်က အလယ်တွင် ပြသည်။
3. စာရင်းမှ စာရွက်တစ်ခုကို နှိပ်ပြီး ပြပါ။ စာရွက်ပေါ်တွင် မောက်စ်ဘီးကို လှည့်လိုက်ပါက ညွှန်ပြထားရာနေရာကို ချဲ့ပေးသည်။
4. ကိရိယာဘား၏ {{ui:Revise}} အုပ်စုတွင် {{ui:Cloud}} ကို ရွေးပါ (သို့မဟုတ် {{key:C}} ကို နှိပ်ပါ)။
   ဆွဲကိရိယာ ပထမဆုံးရွေးသောအခါ MarkupCraft က သင့်နာမည်ကို မေးသည်။ ရိုက်ထည့်ပြီး {{ui:Save}} ကို ရွေးပါ။ မှတ်ချက်တိုင်းတွင် ထိုနာမည် မှတ်တမ်းတင်သည်။ (နောက်ထပ်အတွက် [သင့်နာမည် သတ်မှတ်ခြင်း](topic:set-your-name) ကို ကြည့်ပါ။)
5. အလံပြလိုသော နေရာတစ်ဝိုက်တွင် ဘောက်စ်ဆွဲပါ။ အနီရောင် revision cloud ပေါ်လာပြီး ရွေးထားသည်။
6. အုပ်စု {{ui:Annotate}} ရှိ {{ui:Callout}} ကို ရွေးပါ (သို့မဟုတ် {{key:K}} ကို နှိပ်ပါ)။ ညွှန်ပြလိုသော အရာပေါ်တွင် နှိပ်ပြီး စာသား ဘယ်နေရာသွားရမည်ကို ဆွဲပြီး လွှတ်ပါ။
7. ပေါ်လာသော ဘောက်စ်တွင် မှတ်ချက်ကို ရိုက်ပါ။ ဘောက်စ်အပြင်ဘက်တွင် ကလစ်နှိပ်ပါ (သို့မဟုတ် {{key:Mod+Enter}} ကို နှိပ်ပါ) ပြီးဆုံးရန်။
8. {{key:Esc}} ကို နှစ်ကြိမ်နှိပ်ပါ- တစ်ကြိမ်က ရွေးချယ်မှု ဖယ်ရန်၊ တစ်ကြိမ်က {{ui:Select}} ကိရိယာသို့ ပြန်သွားရန်။ cloud ကို နှိပ်ပါ။ ညာဘက်ရှိ {{ui:Properties}} တဘ်က ဘယ်သူ၊ ဘယ်အချိန်နှင့် ၎င်း၏ {{ui:Status}} ကို ပြသည်။
9. တူးလ်ဘားတွင် {{ui:Save}} ကို ရွေးပါ (သို့မဟုတ် {{key:Mod+S}} ကို နှိပ်ပါ)။
   ဘရောက်ဆာက "A-Plans (marked up).pdf" ကဲ့သို့ နာမည်ဖြင့် မိတ္တူကို ဒေါင်းလုဒ်ဆွဲသည်။ အခြေအနေဘားက ရေးသားခဲ့သော မှတ်ချက်အရေအတွက်ကို ပြသည်။
10. မည်သည့် PDF ကြည့်ရှုသူဖြင့်မဆို ထိုမိတ္တူကို ဖွင့်ပြီး စစ်ဆေးပါ- cloud နှင့် callout ရှိနေပြီး သင့်နာမည်ပါသော ပုံမှန် PDF မှတ်ချက်များ ဖြစ်သည်။

နောက်ပိုင်း ဆက်လုပ်ရန် "(marked up)" မိတ္တူကို MarkupCraft တွင် ဖွင့်ပါ။ သင့်မှတ်ချက်များသည် အခြေအနေများ၊ ပြန်စာများနှင့် punch နံပါတ်များနှင့်အတူ တည်းဖြတ်နိုင်သော အနေအထားဖြင့် ပြန်ပေါ်လာမည်။

## အွန်လိုင်းနှင့် အော့ဖ်လိုင်း

:::online
သင် အွန်လိုင်းဖြစ်သည်။ MarkupCraft သည် PDF ဖွင့်သော ပထမအကြိမ်တွင် PDF ဖတ်ကိရိယာကို တင်ပြီး သိမ်းသော ပထမအကြိမ်တွင် PDF ရေးကိရိယာကို တင်သည်။ နောက်ပိုင်း ချိတ်ဆက်မှုမရှိဘဲ အလုပ်လုပ်ရန် (ဆိုက်ဝင်ချိန်၊ လေယာဉ်ပေါ်တွင်) ထိပ်ဆုံးဘားရှိ {{ui:Save for offline}} ကို ယခုရွေးပြီး "အော့ဖ်လိုင်း အဆင်သင့်" ကို စောင့်ပါ။ မိတ္တူတွင် PDF ဖတ်ကိရိယာနှင့် ရေးကိရိယာ ပါဝင်သဖြင့် PDF ဖွင့်ခြင်းနှင့် သိမ်းခြင်း အော့ဖ်လိုင်းဖြင့် အလုပ်လုပ်သည်။ [အော့ဖ်လိုင်းဖြင့် အလုပ်လုပ်ခြင်း](common:offline) ကို ကြည့်ပါ။
:::

:::offline
သင် အော့ဖ်လိုင်းဖြစ်သည်။ ထိပ်ဆုံးဘားက "အော့ဖ်လိုင်း အဆင်သင့်" ဟု ပြနေလျှင် ဤဘရောက်ဆာတွင် အော့ဖ်လိုင်းသိမ်းပြီးပြီ ဖြစ်ပြီး အရာအားလုံး အလုပ်လုပ်သည်- ဖွင့်ခြင်း၊ မှတ်ချက်ထည့်ခြင်း၊ တိုင်းတာခြင်းနှင့် သိမ်းခြင်း။ မပြပါက ဤတဘ်တွင် ရှိပြီးသား အရာများကို အသုံးပြုပြီး ချိတ်ဆက်ပြန်ရတိုင်အောင် စာမျက်နှာကို ပြန်မဖွင့်ပါနှင့်။ [အော့ဖ်လိုင်းဖြင့် အလုပ်လုပ်ခြင်း](common:offline) ကို ကြည့်ပါ။
:::

## ဘာတွေ မှတ်မိသလဲ၊ ဘာတွေ မမှတ်မိဘူးလဲ

- **သင့်မှတ်ချက်များသည် သင်သိမ်းသော PDF ထဲတွင် နေသည်။** ဆာဗာတွင် ဘာမျှ မသိမ်းပါ။ အက်ပ်သည် PDF ကို သူ့ဘာသာသူ မသိမ်းပါ၊ သို့သော် သင်သိမ်းသည်အထိ ဤဘရောက်ဆာတွင် ပြန်လည်ရယူရန် မိတ္တူတစ်ခု ထားသည်။ တဘ်ကိုပိတ်မီ သိမ်းပါ၊ မသိမ်းရသေးသော မှတ်ချက်များဖြင့် ထွက်ရန် ကြိုးစားပါက ဘရောက်ဆာက ဦးစွာမေးသည် (iPad တွင် မဟုတ်ပါ၊ [iPad သို့မဟုတ် touch screen ဖြင့် သုံးသပ်ခြင်း](topic:review-on-a-tablet) ကို ကြည့်ပါ)။
- **သင့်နာမည်၊ သင့်ကိရိယာပုံစံများနှင့် သင့်ကိရိယာသေတ္တာ** သည် ဤကွန်ပျူတာ၏ ဤဘရောက်ဆာတွင် ရှိနေသည်။ အခြားဘရောက်ဆာ သို့မဟုတ် ကွန်ပျူတာသည် အသစ်မှ စတင်သည်၊ ဘရောက်ဆာ site data ကို ရှင်းလင်းလိုက်ပါက ၎င်းတို့ ပျောက်သွားသည်။ [ဘရောက်ဆာတွင် ဘာကျန်သလဲ](topic:browser-storage) ကို ကြည့်ပါ။
- လူများကြား မျှဝေသော cloud သိမ်းဆည်းမှုနှင့် သုံးသပ်ရေးဆွေးနွေးမှု session များ မရနိုင်သေးပါ။
