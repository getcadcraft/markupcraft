BCF (BIM Collaboration Format) သည် BIM ကိရိယာများကြား ပြဿနာများ ပေးပို့ရန်အတွက် ပွင့်လင်းသော ဖိုင်ပုံစံတစ်ခု ဖြစ်သည်။ မော်ဒယ် ညှိနှိုင်းသည့်နှင့် ဒီဇိုင်းရေးဆွဲသည့် ပရိုဂရမ်များစွာသည် `.bcfzip` ဖိုင်ကို ပြဿနာစာရင်းအဖြစ် သွင်းယူနိုင်သည်။ MarkupCraft သည် **BCF 2.1** ကို ရေးသားသည်။

## တစ်ခု ပြုလုပ်ရန်

1. {{ui:မှတ်ချက်များ}} တက်ဘ်ကို ဖွင့်ပါ။
2. စာရင်းကို သင်ပို့လိုသည့်အရာများသို့ စစ်ထုတ်ပါ၊ ဥပမာ {{ui:အခြေအနေ}} "ဖွင့်ထား"။ ဖော်ပြထားသော markup များကိုသာ ထုတ်ယူမည်။
3. {{ui:BCF}} ကို ရွေးပါ။
4. markup တစ်ခုစီ၏ snapshot ကို ပြုလုပ်နေစဉ် စောင့်ပါ ("BCF အတွက် snapshot များ ပြုလုပ်နေသည် (20 ထဲမှ 5)…")။

ရလဒ်: "<name> markups.bcfzip" ဒေါင်းလုဒ်ဆွဲယူမည်ဖြစ်ပြီး status bar တွင် ၎င်းတွင် ပါဝင်သော အကြောင်းအရာ အရေအတွက်နှင့် ဖိုင်အရွယ်အစားကို ပြသမည်။

## ပါဝင်သည့်အရာများ

markup တစ်ခုစီသည် **အကြောင်းအရာ (topic)** တစ်ခု ဖြစ်လာသည်:

| အကြောင်းအရာ အကွက် | ဖြည့်သည့်အရာ |
|---|---|
| ခေါင်းစဉ် | Punch နံပါတ်၊ အကြောင်းအရာနှင့် စာရွက်၊ ဥပမာ "#4 Cloud on A-101 — Floor plan" |
| အမျိုးအစား | markup အမျိုးအစား (Cloud, Callout, Length…) |
| အခြေအနေ | ဖွင့်ထား၊ လက်ခံပြီး၊ ပယ်ချပြီး သို့မဟုတ် ပြီးစီးပြီး |
| တံဆိပ်များ | markup အမျိုးအစားနှင့် စာရွက် |
| ရေးသူနှင့် ရက်စွဲများ | markup ရေးသူ၊ ဖန်တီးသည့်နှင့် ပြင်ဆင်သည့် ရက်စွဲများ |
| တာဝန်ပေးသူ၊ နောက်ဆုံးရက် | punch အကြောင်းအရာမှ၊ ရှိသည့်အခါ |
| ဖော်ပြချက် | ၎င်း၏ စာသား သို့မဟုတ် တံဆိပ်စာသား၊ တိုင်းတာထားသော တန်ဖိုး၊ မှတ်ချက်၊ နှင့် စာရွက်နှင့် ဖိုင် |
| မှတ်ချက်များ | တုံ့ပြန်ချက်တစ်ခုစီအတွက် တစ်ခု၊ ရေးသူနှင့် ရက်စွဲပါဝင် |
| Snapshot | စာရွက်၏ ထိုအပိုင်းပေါ်ရှိ markup ၏ ပုံ |
| Viewpoint | markup ၏ စာရွက်ပေါ်ရှိ နေရာကို အပေါ်မှ အမြင် |

markup တူညီသည်ကို ထပ်မံထုတ်ယူပါက topic ID တူညီမည်ဖြစ်ပြီး BCF သွင်းသည့် ကိရိယာက ၎င်းကို ပြဿနာတူညီခြင်းအဖြစ် မှတ်သားနိုင်သည်။

## သိထားရမည့် ကန့်သတ်ချက်များ

- **စာရွက်သည် မော်ဒယ် မဟုတ်ပါ။** Viewpoint သည် markup ၏ စက္ကူပေါ်ရှိ နေရာကို ညွှန်ပြပြီး စက္ကူ၏ အတိုင်းအတာကို မီတာဖြင့် တိုင်းသည်။ BIM ကိရိယာကို မော်ဒယ်ထဲရှိ နေရာသို့ မခေါ်ဆောင်ပါ။ နေရာရှာရန် snapshot နှင့် စာရွက်အမည်ကို သုံးပါ။
- **အခြေအနေများနှင့် အမျိုးအစားများသည် MarkupCraft ၏ ကိုယ်ပိုင် ဖြစ်သည်** (ဖွင့်ထား၊ လက်ခံပြီး၊ ပယ်ချပြီး၊ ပြီးစီးပြီး၊ Cloud, Callout…)။ BCF ခွင့်ပြုသည့်အတိုင်း ဖိုင်က ၎င်းတို့ကို ကြေညာသော်လည်း ကိုယ်ပိုင် စာရင်းသတ်မှတ်ထားသည့် ကိရိယာတစ်ခုက ၎င်းတို့ကို ပြောင်းလဲ သို့မဟုတ် လျစ်လျူရှုနိုင်သည်။
- **သွင်းယူခြင်းသည် မှတ်ချက်များကို ယူလာသည်၊ မော်ဒယ်အမြင်များကို မဟုတ်ပါ။** {{ui:BCF သွင်းရန်}} သည် ထုတ်ယူထားသော markup များသို့ တုံ့ပြန်ချက်နှင့် အခြေအနေများ ထည့်ပေးပြီး အခြား ပြဿနာများအတွက် မှတ်စုများ ပြုလုပ်ပေးသည်။ မော်ဒယ် ကင်မရာကို ပြသနိုင်မည် မဟုတ်ပါ။ [markup စာရင်းနှင့် ထုတ်ယူခြင်း](topic:markups-list-and-export#import-bcf) ကို ကြည့်ပါ။
- ပုံဆွဲ သုံးသပ်ချက်များအတွက် markup များကို PDF အဖြစ် ပြန်ပို့ခြင်းသည် မကြာခဏ ပိုရိုးရှင်းသည်။ BCF သည် ပုံဆွဲမှတ်ချက်များကို မော်ဒယ် ညှိနှိုင်းရေး လုပ်ငန်းစဉ်ထဲသို့ ယူရန်အတွက် ဖြစ်သည်။
