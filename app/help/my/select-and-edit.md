ပထမဦးစွာ {{ui:Select}} ({{key:V}}) ကို ရွေးပါ။ {{key:Esc}} ကို နှိပ်ခြင်းဖြင့်လည်း ရောက်နိုင်ပါသည်: ပထမ နှိပ်ချက်က ရွေးထားမှုကို ရှင်းပြီး ဒုတိယ နှိပ်ချက်က {{ui:Select}} သို့ ပြန်ပြောင်းပါသည်။

## မှတ်ချက်များ ရွေးခြင်း

:::mouse
- **မှတ်ချက်တစ်ခု:** နှိပ်ပါ။ အစက်မျဉ်ကွက်နှင့် handles များ ပေါ်လာပြီး {{ui:Properties}} တွင် ပြပါသည်။
- **တစ်ခု ထည့်ရန် သို့မဟုတ် ဖယ်ရန်:** {{key:Shift}} ကို ဖိထားပြီး နှိပ်ပါ။
- **Window အတွင်းအပြည့်:** စာရွက်ပေါ်ရှိ လွတ်သောနေရာတွင် ဘယ်မှ ညာသို့ ဆွဲပါ။ ကွက်အတွင်း အပြည့်ရှိသော မှတ်ချက်များသာ ရွေးပါမည် (အစိုင်အခဲ အစွန်းဘောင်)။
- **Window ကို ထိထားခြင်း:** ညာမှ ဘယ်သို့ ဆွဲပါ။ ကွက်က ထိသမျှ မှတ်ချက်များကို ရွေးပါမည် (အစိမ်း၊ အစက်မျဉ်ဘောင်)။
- **ဤစာရွက်ပေါ်ရှိ အရာအားလုံး:** {{key:Mod+A}}၊ သို့မဟုတ် {{ui:More}} ထို့နောက် တူးလ်ဘား၏ {{ui:Edit}} အုပ်စုရှိ {{ui:Select all}}။
- **ဘာမျှမရွေး:** လွတ်သောနေရာကို နှိပ်ပါ၊ {{key:Esc}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:More}} ထို့နောက် {{ui:Select none}}။
:::

:::touch
- **မှတ်ချက်တစ်ခု:** ထိပါ။
- **အများအပြား:** လက်ညှိုးတစ်ချောင်းဖြင့် စာရွက်ပေါ်ရှိ လွတ်သောနေရာတွင် ဆွဲ၍ window ဆွဲပါ။ ဘယ်မှ ညာသို့ဆွဲလျှင် အပြည့်ရှိသော အရာများကို ရွေးပြီး ညာမှ ဘယ်သို့ဆွဲလျှင် ထိသော အရာများကို ရွေးပါသည်။
- {{key:Shift}} ကို ဖိထားပြီး ထိခြင်းသည် keyboard ချိတ်ဆက်ထားမှသာ အလုပ်လုပ်ပါသည်။ မချိတ်ဆက်ထားလျှင် window ကို သုံးပါ။
- {{ui:Select}} တွင် လက်ညှိုးတစ်ချောင်းဖြင့် မရွှေ့နိုင်ပါ၊ လက်နှစ်ချောင်း သို့မဟုတ် {{ui:Pan}} တူးလ်ကို သုံးပါ။
:::

ဖိုင်နှင့်အတူ ပါလာသော ဖတ်ရုံသာ comments များသည် မီးခိုးရောင် အစက်မျဉ်ကွက်ဖြင့် ပြပြီး handles မပါပါ။ ၎င်းတို့ကို ရွေး၍ reply ပေးနိုင်သော်လည်း ပြောင်းလဲ၍မရပါ။

## ရွှေ့ခြင်းနှင့် အရွယ်ပြောင်းခြင်း

- **ရွှေ့ရန်:** ရွေးထားသော မှတ်ချက်ကို ဆွဲပါ။ 45° ၏ ဆပ်ဆတ်များအတိုင်းသာ ရွှေ့ရန် {{key:Shift}} ကို ဖိထားပါ။ ရွေးထားသော မှတ်ချက်အများအပြား အတူတကွ ရွှေ့ပါသည်။
- **အရွယ်ပြောင်းရန်:** မှတ်ချက်တစ်ခုကိုသာ ရွေးထားသောအခါ handle ကို ဆွဲပါ။ စတုရန်းပုံ handles များသည် ဘောင်ကို ပြောင်းပါသည် ({{key:Shift}} ကို ဖိထားလျှင် အချိုးကို ထိန်းပါသည်)။ စက်ဝိုင်းပုံ handles များသည် မျဉ်း၊ polyline၊ polygon၊ cloud သို့မဟုတ် measurement ၏ အမှတ်တစ်ခုကို ရွှေ့ပါသည် ({{key:Shift}} ကို ဖိထားလျှင် 45°)။ စိန်ပုံ handles များသည် callout ၏ tip နှင့် ကွေးကောက်မှုကို ရွှေ့ပါသည်။ Pen အစင်းများသည် ၎င်းတို့၏ ဘောင်မှ scale ပြောင်းပါသည်။
- **အနည်းငယ်ရွှေ့ရန် (Nudge):** စာရှိုးမြှားခလုတ်များကို နှိပ်ပြီး ရွေးထားမှုကို မျက်နှာပြင် pixel တစ်ခုစီ ရွှေ့ပါ။ {{key:Shift}} ကို ဖိထားလျှင် ဆယ်ခု ရွှေ့ပါသည်။ နှိပ်တိုင်း undo အဆင့်တစ်ခုဖြစ်ပါသည်။

## စာသား သို့မဟုတ် ပုံစံ ပြောင်းခြင်း

- **စာသား၊ callouts နှင့် notes:** မှတ်ချက်ကို နှစ်ချက်နှိပ်ပါ၊ သို့မဟုတ် {{key:Enter}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:Properties}} ရှိ {{ui:Edit on the sheet}} ကို ရွေးပါ။ ရိုက်ပြီး အပြင်ဘက်ကို နှိပ်ပါ သို့မဟုတ် {{key:Mod+Enter}} ကို နှိပ်ပါ။ {{key:Esc}} က တည်းဖြတ်မှုကို ပယ်ဖျက်ပါသည်။
- **Stamps:** {{ui:Properties}} တွင် stamp အခြားတစ်ခုကို ရွေးပါ (နှစ်ချက်နှိပ်လျှင် {{ui:Properties}} ကို သင့်အတွက် ဖွင့်ပေးပါသည်)။
- **ပုံစံ:** {{ui:Properties}} ရှိ "Style" အောက်ရှိ {{ui:Color}}၊ {{ui:Line width}}၊ {{ui:Fill}}၊ {{ui:Opacity}} နှင့် {{ui:Text size}}။ အများအပြား ရွေးထားသောအခါ {{ui:Properties}} သည် သင်ရွေးထားသော အမျိုးအစားများကို ပြပြီး အားလုံးကို တစ်ကြိမ်တည်း ပြောင်းပါသည်။

## ကူးခြင်း၊ ကူးထည့်ခြင်းနှင့် ပွားခြင်း

တူးလ်ဘား၏ {{ui:Edit}} အုပ်စုတွင် {{ui:Copy}} နှင့် {{ui:Paste}} ရှိပြီး {{ui:More}} မီနူးတွင် ဤအရာအားလုံးရှိကာ တစ်ခုစီတွင် ၎င်း၏ key ပါဝင်ပါသည်။

| Command | Key | ဘာလုပ်သလဲ |
|---|---|---|
| {{ui:Cut}} | {{key:Mod+X}} | ရွေးထားသော မှတ်ချက်များကို ကူးပြီး ဖျက်ပါသည် |
| {{ui:Copy}} | {{key:Mod+C}} | ရွေးထားသော မှတ်ချက်များကို ကူးပါသည် |
| {{ui:Paste}} | {{key:Mod+V}} | သင်ရှိနေသော စာရွက်ပေါ် မိတ္တူကို ထည့်ပါသည် (အောက်တွင် ဘယ်နေရာလဲ) |
| {{ui:Paste in place}} | {{key:Mod+Shift+V}} | မိတ္တူကို ကူးခဲ့သည့် နေရာအတိအကျတွင် ထည့်ပါသည်: ထိုစာရွက်တွင် မူရင်းနှင့် အပေါ်ထပ်တွင်၊ အခြားစာရွက်တွင် စက္ကူ၏ တူညီနေရာတွင် |
| {{ui:Duplicate}} | {{key:Mod+D}} | ရွေးထားမှု၏ မိတ္တူကို အနည်းငယ် အောက်နှင့် ညာဘက်တွင် ဖန်တီးပါသည်၊ ယခင်ကူးထားသည်ကို မထိပါ |

**Paste မိတ္တူကို ဘယ်မှာ ထည့်သလဲ:**

- Pointer က စာရွက်ပေါ်ရှိနေစဉ် {{key:Mod+V}} သည် pointer ရှိသည့်နေရာ၏ အလယ်တွင် မိတ္တူကို ထည့်ပါသည်။ Pointer ကို ရွှေ့ပြီး {{key:Mod+V}} ကို ထပ်နှိပ်ပါက နောက်တစ်ခု နေရာချပါသည်။
- {{ui:Paste}} ခလုတ် (ထိုအချိန် pointer သည် တူးလ်ဘားပေါ်တွင် ရှိသည်)၊ သို့မဟုတ် စာရွက်ပြင်ပ pointer ဖြင့် {{key:Mod+V}} သည် မူရင်း၏ အောက်နှင့် ညာဘက်တွင် အနည်းငယ် ထည့်ပါသည်။ တူညီသော မိတ္တူကို paste တစ်ကြိမ်ပြီးတိုင်း ထပ်ရွှေ့ပါသည်၊ ထို့ကြောင့် မိတ္တူများ တစ်ခုကို တစ်ခု မဖုံးပါ။ အခြားစာရွက်တွင် ပထမ paste သည် မူရင်း၏ စာရွက်ပေါ် နေရာတွင် ကျရောက်ပါသည်။ ထိုနေရာ မြင်ကွင်းပြင်ပ ရောက်နေပါက မိတ္တူသည် မြင်ကွင်း အလယ်တွင် ကျရောက်ပါသည်။
- {{key:Mod+V}} သည် အမြဲတမ်း မူရင်းဘေးတွင် ကူးထည့်စေလိုပါက [MarkupCraft settings](topic:settings) ရှိ {{ui:Paste}} အောက်ရှိ {{ui:Beside the copy}} ကို ရွေးပါ။

ကူးထည့်ထားသော မှတ်ချက်များသည် ရွေးထားသည်ဖြစ်ပါသည်၊ ထို့ကြောင့် ချက်ခြင်း ဆွဲနိုင်ပါသည်။ cut၊ paste သို့မဟုတ် duplicate တစ်ခုစီသည် undo အဆင့်တစ်ခုဖြစ်ပြီး {{key:Mod+Z}} သည် paste တစ်ခုလုံးကို ပြန်ဖျက်ပါသည်။

ကူးထည့်ထားသော မိတ္တူများသည် မှတ်ချက်အသစ်များ ဖြစ်ပါသည်: သင့်အမည်၊ ယနေ့ရက်စွဲ၊ Open status၊ punch number မရှိ၊ thread ဗလာ ရရှိပါသည်။ ၎င်းတို့၏ အမျိုးအစား၊ ပုံသဏ္ဍာန်၊ ပုံစံ၊ စာသားနှင့် comment တို့ ပါလာပါသည်။ ဖိုင်နှင့်အတူ ပါလာသော ဖတ်ရုံသာ comments များကို ကူး သို့မဟုတ် cut၍မရပါ။

**Tabs အကြား:** သင်ကူးထားသည့်အရာကို ဤ browser တွင်လည်း သိမ်းထားသဖြင့် တူညီသော browser ရှိ MarkupCraft tab နောက်တစ်ခုက paste လုပ်နိုင်ပါသည်။ မှတ်ချက်များ ကူးခြင်းသည် ကွန်ပျူတာ၏ clipboard ကို မသုံးပါ: အခြား program တစ်ခုသို့ ကူး၍မရပါ၊ အခြားနေရာမှ ကူးထားသော စာသားသည် မှတ်ချက်အဖြစ် paste မဖြစ်ပါ။

**Right-click မီနူး:** မှတ်ချက် (သို့မဟုတ် လွတ်သောစက္ကူ) ကို right-click လုပ်ပြီး {{ui:Cut}}၊ {{ui:Copy}}၊ {{ui:Paste here}}၊ {{ui:Paste in place}}၊ {{ui:Duplicate}}၊ {{ui:Delete}}၊ {{ui:Save selection as a stamp…}}၊ {{ui:Flatten into the page when saved}}၊ {{ui:Insert a picture here…}} နှင့် {{ui:Select all}} ကို ရွေးပါ။ ရွေးမထားသော မှတ်ချက်ကို right-click လုပ်လျှင် ၎င်းကို အရင် ရွေးပေးပါသည်။ Right button ဖြင့် ဆွဲခြင်းသည် ရွှေ့ကြည့်ခြင်းကို လုပ်ပါသည်။ Touch screen တွင် မှတ်ချက်ပေါ်တွင် ရှည်ရှည်နှိပ်ထားလျှင် တူညီသော မီနူးကို ဖွင့်ပါသည် (စာသားပေါ်တွင်ဆိုလျှင် စာသား တည်းဖြတ်ခြင်း စတင်ပါသည်)။ မီနူး key သို့မဟုတ် {{key:Shift+F10}} သည် ရွေးထားသည့်နေရာတွင် မီနူးကို ဖွင့်ပါသည်။

{{ui:Content}} တူးလ်ဖြင့် ရွေးထားသော စာမျက်နှာ၏ ကိုယ်ပိုင်မျဉ်း၊ ပုံနှင့် စာသားလည်း ကူးနိုင်၊ paste လုပ်နိုင်ပါသည်: see [Change the page's own lines, pictures and text](topic:page-content)။

စာမျက်နှာကိုယ်တိုင်၏ အပိုင်းတစ်ခုကို ပုံ (rectangle၊ ellipse သို့မဟုတ် freeform shape) အဖြစ် သို့မဟုတ် အခြားစာရွက် သို့မဟုတ် app အတွက် see-through overlay အဖြစ် ကူးလိုပါက see [Copy an area of the page, or an overlay](topic:copy-an-area)။

## ဖျက်ခြင်း

{{key:Delete}} သို့မဟုတ် {{key:Backspace}} ကို နှိပ်ပါ၊ တူးလ်ဘားရှိ {{ui:More}} ထို့နောက် {{ui:Delete}} ကို ရွေးပါ၊ သို့မဟုတ် {{ui:Properties}} ရှိ {{ui:Delete}} ကို ရွေးပါ။ Status bar က ဘယ်နှစ်ခု ဖျက်ပြီးကြောင်း ပြပါသည်။ ဖိုင်မှ ဖတ်ရုံသာ comments များကို ဘယ်တော့မှ မဖျက်ပါ ("kept as in the file")။

## Undo နှင့် redo

- {{key:Mod+Z}} သည် undo လုပ်ပြီး {{key:Mod+Y}} သို့မဟုတ် {{key:Mod+Shift+Z}} သည် redo လုပ်ပါသည်။ တူးလ်ဘားတွင် {{ui:Undo}} နှင့် {{ui:Redo}} ရှိပါသည်။
- Status bar က ဘာကို undo လုပ်ပြီးကြောင်း ပြပါသည် ("Undid move markup.")။
- Undo သည် မှတ်ချက်များ၊ status များ၊ replies များ၊ punch items များ၊ စာရွက် scale များနှင့် စာရွက်အမည်များ၏ ပြောင်းလဲမှုအားလုံးကို အဆင့် 500 အထိ ဖုံးလွှမ်းပါသည်။
- Set ကို ပိတ်သောအခါ history ကို ရှင်းပါသည်။

## မှတ်ချက်များကို အခြားစာရွက်များသို့ ကူးခြင်း

တံဆိပ်၊ မှတ်စု သို့မဟုတ် cloud တူညီသည်ကို စာရွက်အများအပြားပေါ် ထည့်လိုပါက ၎င်းကို ရွေးပါ (သို့မဟုတ် မှတ်ချက်အများအပြား) ပြီး {{ui:Properties}} ရှိ {{ui:Copy to other sheets…}} ကို ရွေးပါ။ စာရွက်များကို အမှန်ခြစ်ပါ၊ သို့မဟုတ် {{ui:All sheets}} ကို ရွေးပြီး {{ui:Copy}} ကို ရွေးပါ။ စာရွက်တစ်ခုစီသည် စာမျက်နှာပေါ် တူညီနေရာတွင် မိတ္တူရရှိပြီး သင့်အမည်ဖြင့် လက်မှတ်ထိုးထားပါသည်။ {{key:Mod+Z}} တစ်ကြိမ်ဖြင့် အားလုံးကို ဖယ်ရှားပါသည်။
