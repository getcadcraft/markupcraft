ဤသည်မှာ MarkupCraft 0.8.1 နှင့် နှိုင်းယှဉ်လျှင် 0.9 တွင် ပြောင်းလဲချက်များ ဖြစ်သည်။ အဓိကအယူအဆမှာ သင်၏ အလုပ်မှတ်စုများသည် ဖောက်သည်ရရှိသော စာမျက်နှာပေါ်တွင် မပါဝင်ဘဲ နေမည်ဖြစ်ပြီး ဒရော်ဝင်းစာရွက်အစုတစ်ခုလုံးကို တစ်ကြိမ်တည်းဖြင့် လင့်ခ်ချိတ်နိုင်သည်။

## အသစ်

### မှတ်စုများ၊ pasteboard နှင့် ကိုယ်ပိုင်မှတ်စုများ

- **Pasteboard။** စာရွက်တစ်ခုစီ၏ ပတ်လည်ဧရိယာသည် စားပွဲတစ်ခု ဖြစ်သည်- စာရွက်ဘေးတွင် ဆွဲထားသော၊ ရိုက်ထားသော သို့မဟုတ် ကူးထည့်ထားသည့် မည်သည့်အရာမဆို မှတ်စု ဖြစ်ပြီး ဘယ်တော့မျှ မပရင့်ပါ။ နေရာ ကျယ်ကျယ်ရရန် {{ui:Show the pasteboard}} ကို ရွေးပါ၊ သို့မဟုတ် {{ui:Snapshot to the pasteboard}} ကိုရွေးပြီး ဘောင်တစ်ခု ဆွဲကာ {{ui:To the pasteboard}} ဖြင့် ပုံဒရော်ဝင်း၏ တစ်စိတ်တစ်ပိုင်းကို စာရွက်ဘေးတွင် ထားပါ။ Snapshot သည် ပုံတစ်ပုံဖြစ်ပြီး စာရွက် ပြောင်းလဲသော်လည်း မပြောင်းပါ။ [Notes, the pasteboard and private notes](topic:notes-and-pasteboard) ကို ကြည့်ပါ။
- **မှတ်စုများ ပြ/ဝှက်ခြင်း။** မည်သည့် မှတ်ချက်ကိုမဆို မှတ်စု ဖြစ်အောင် လုပ်နိုင်သည်- {{ui:Notes}} tab တွင် {{ui:New markups are}} ကို သတ်မှတ်ပါ၊ သို့မဟုတ် {{ui:Properties}} တွင် {{ui:This markup is}} ကို သတ်မှတ်ပါ။ {{key:Shift+H}} သို့မဟုတ် စာရွက်အောက်ရှိ {{ui:Notes}} switch သည် မှတ်စုအားလုံးကို တစ်ပြိုင်တည်း ဝှက်/ပြသည်။ မှတ်စုများကို ပရင့်ထုတ်ခြင်း၊ ပြားချထားသော မိတ္တူများ၊ စာရင်းများနှင့် ထုတ်ယူမှုများမှ ချန်ထားသည်၊ အခြား PDF ဖတ်ကိရိယာများတွင် မပြပါ။ သိမ်းထားသော PDF သည် MarkupCraft တွင် နောက်တစ်ကြိမ် ဖွင့်သည့်အခါ ၎င်းတို့ကို ဆက်ထားသည်။
- **ကိုယ်ပိုင်မှတ်စုများ။** {{ui:Set a passphrase}} ကို ရွေးပြီး မှတ်ချက်ကို {{ui:A private note}} ဖြစ်အောင် လုပ်ပါ။ ၎င်းသည် စာလုံး 10 လုံး အနည်းဆုံးရှိသော passphrase ဖြင့် ဖိုင်ထဲတွင် ကုဒ်ပြုထားပြီး ပြန်ယူနိုင်ခြင်း မရှိပါ- ကျွန်ုပ်တို့အပါအဝင် ဘယ်သူမျှ passphrase မရှိဘဲ ဖွင့်နိုင်မည် မဟုတ်ပါ။ {{ui:Lock}} သည် ကိုယ်ပိုင်မှတ်စုများကို သိမ်းထားသည်၊ {{ui:Stay unlocked on this device}} သည် မူလအားဖြင့် ပိတ်ထားသည်။
- **သန့်စင်သော မိတ္တူ သိမ်းခြင်း။** {{ui:Save a clean copy}} သည် မှတ်စု၊ ကိုယ်ပိုင်မှတ်စုနှင့် pasteboard ပေါ်ရှိ အရာအားလုံးကို ဖယ်ရှားသည်။ ဖောက်သည်ထံ ပို့သော ဖိုင်အတွက် သုံးပါ။

### စာရွက်အစုတစ်ခုလုံးကို လင့်ခ်ချိတ်ခြင်း

- **အစုလိုက် လင့်ခ်များ။** {{ui:Pages}} › {{ui:Batch links…}} ကို ရွေးပါ၊ သို့မဟုတ် {{ui:Sheets}} panel ရှိ {{ui:Find text}} အောက်ရှိ {{ui:Link sheet callouts…}} ကို ရွေးပါ။ အဆင့် 1 တွင် title block မှ ဖတ်ထားသော စာရွက်တစ်ခုစီ၏ နံပါတ်နှင့် အမည်များကို စာရင်းပြသည်; မှားနေသည်များကို ပြင်ပါ။ အဆင့် 2 တွင် `3/A-501` သို့မဟုတ် `DETAIL 2 ON A-501` ကဲ့သို့ တွေ့ရှိသော ရည်ညွှန်းချက်များကို ပြသည်။ {{ui:Will link}} သည် တစ်ခုစီအတွက် စာရွက်နှင့် view ကို ပြသည်၊ {{ui:Not linked}} သည် ဖွင့်ထားသော စာရွက်တစ်ခုမျှ မရှိသော နံပါတ်များကို ပြသည်၊ {{ui:Create the links}} သည် အားလုံးကို undo အဆင့်တစ်ခုတည်းဖြင့် ဖန်တီးသည်။ Addendum သို့မဟုတ် နံပါတ်ပြန်ပေးပြီးနောက် ထပ်ဖွင့်ပါ; လက်ဖြင့် ချိတ်ထားသော လင့်ခ်များကို ဘယ်တော့မျှ မပြောင်းပါ။ View ပါသော လင့်ခ်ကို PDF လင့်ခ်အဖြစ် သိမ်းသဖြင့် အခြားဖတ်ကိရိယာများတွင် detail ကိုပါ ဖွင့်နိုင်သည်။ [Sheet links](topic:sheet-links) ကို ကြည့်ပါ။

### ပုံဆွဲခြင်း

- **Arc၊ နည်းလမ်းဆယ်ခု။** {{ui:Arc}} ကိရိယာ ({{key:O}}) တွင် ယခု စာမျက်နှာပေါ်တွင် {{ui:Arc method}} ဘောက်စ် ရှိပြီး အဝိုင်းအပိုင်း ဆွဲရန် နည်းလမ်းဆယ်ခု ရှိသည်၊ ထောင့်၊ အလျား၊ radius နှင့် ဦးတည်ချက်ကို နှိပ်ခြင်း သို့မဟုတ် ရိုက်ထည့်ခြင်းဖြင့် သတ်မှတ်နိုင်သည်။ [Draw an arc ten ways](topic:draw-an-arc) ကို ကြည့်ပါ။

### အတူတကွ လုပ်ဆောင်ခြင်း

- **ပြန်လည်သုံးသပ်သူကို လိုက်ခြင်း။** Live session တွင် လူတစ်ဦး၏ နာမည်ဘေးရှိ {{ui:Follow}} ကို ရွေးပါက သင့်မြင်ကွင်းသည် ၎င်းနှင့်အတူ ရွေ့သည်; ကိုယ်တိုင် pan သို့မဟုတ် zoom လုပ်လျှင် ရပ်သွားသည်။ Host သည် {{ui:Ask everyone to follow me}} ကို ရွေးနိုင်သည်။ လူစာရင်းတွင် လူတစ်ဦးစီ၏ အရောင်၊ နာမည်၊ ရှိနေသော စာရွက်နှင့် နောက်ဆုံး တည်းဖြတ်ခဲ့သည့်အချိန်ကို ပြသည်။ [Follow another reviewer in a Live session](topic:follow-in-live) ကို ကြည့်ပါ။

## အက်ပ်အားလုံးတွင်

- Tooltip များသည် Bootstrap tooltip များ ဖြစ်ပြီး စတင် အကြံပြုချက်ကို ပိတ်နိုင်သည်၊ tab အစုများသည် ပြည့်လျှင် ဘေးသို့ scroll လုပ်သည်၊ browser tab title များသည် `<document> — MarkupCraft | CadCraft` ဖြစ်သည်။
- Section အများအပြားပါသော panel တစ်ခုသည် တစ်ခုကို ဖွင့်ပြီး အခြားများကို ပိတ်သည် (caret ဘေးရှိ lock က တစ်ခုကို ဖွင့်ထားသည်); Settings switch ဖြင့် ၎င်းကို ပိတ်နိုင်သည်။
- အက်ပ်တစ်ခုစီသည် Library object များ၏ မူလစုစည်းမှုဖြင့် စတင်သည်။
- အလemေးချိန်နှင့် အပူချိန် ယူနစ်များကို Units settings တွင် ရနိုင်သည်။

## ပြင်ဆင်ပြီး

- **ဖယ်ရှားထားသော မှတ်ချက်များ သိမ်းထားသော PDF ထဲတွင် ဆက်မဖတ်နိုင်တော့ပါ။** ယခင်က သိမ်းသည့်အခါ ဖျက်ထားသော သို့မဟုတ် ပြန်ရေးထားသော annotation ကို စာမျက်နှာမှ ဖယ်ထုတ်သော်လည်း ၎င်း၏ စာသားပါသော object ကို ဖိုင်ထဲတွင် ထားခဲ့သည်။ ယခု သိမ်းသည့်အခါ ထို object များကို ဖျက်သည်။ ယခင် build များဖြင့် သိမ်းထားသော ဖိုင်များတွင် ထပ်မံသိမ်းမချင်း ၎င်းတို့ ရှိနေဆဲ ဖြစ်သည်။

## ရိုးရိုးသားသား ကန့်သတ်ချက်များ

- အစုလိုက် လင့်ခ်များကို ကျွန်ုပ်တို့၏ ကိုယ်ပိုင် စမ်းသပ်စာရွက်အစုများတွင် စမ်းသပ်ထားသည်။ အစစ်အမှန် စာရွက်အစုများသည် အေးဆေးကွက်ကို အမျိုးမျိုးဆွဲထားသဖြင့် ဖောက်သည်စာရွက်အစုတွင် view အချို့ ကျန်ခဲ့နိုင်သည်။ စကန်ဖတ်ထားသော စာရွက်များသည် ပထမဦးစွာ {{ui:Read text (OCR)…}} လိုအပ်သည်။
- မှတ်စုများ၊ ကိုယ်ပိုင်မှတ်စုများနှင့် pasteboard ကို headless browser နှင့် ကိုယ်ပိုင်ဖိုင်များဖြင့် စမ်းသပ်ထားသည်၊ အစစ်အမှန် ကြီးမားသော vector စာရွက်ဖြင့် သို့မဟုတ် အစစ်အမှန် လူနှစ်ဦး Live session တွင် မစမ်းသပ်ရသေးပါ။ Passphrase ပြောင်းခြင်းကို မတည်ဆောက်ရသေးပါ။ 0.9 မတိုင်မီ build များသည် မှတ်စုများကို မပြပါ။
- Class view သည် လူစာရင်းဖြစ်သည်; အစစ်အမှန် ဆရာနှင့် ကျောင်းသားများဖြင့် မစမ်းသပ်ရသေးပါ။
- အင်္ဂလိပ်မဟုတ်သော ဘာသာစကားများသည် ဌာနေစကားပြောသူက မဖတ်မချင်း စက်ဖြင့် ရေးထားသော မူကြမ်းများ ဖြစ်သည်။
- Windows installer များကို code-sign မလုပ်ရသေးပါ (More info၊ ပြီးမှ Run anyway); macOS disk image ကို notarize မလုပ်ရသေးပါ (right-click၊ ပြီးမှ Open)။

## ယခင်- 0.8 နှင့် 0.8.1

ဤသည်မှာ 0.7 နှင့် နှိုင်းယှဉ်လျှင် MarkupCraft 0.8 နှင့် 0.8.1 တွင် ပြောင်းလဲချက်များ ဖြစ်သည်။ အကြီးဆုံး အသစ်မှာ မှတ်ချက်တစ်ခုသည် တစ်စုံတစ်ယောက် (သို့မဟုတ် သင့်ကိုယ်ပိုင် assistant) လုပ်ဆောင်သော လုပ်ငန်း ဖြစ်နိုင်ပြီး ပုံဆွဲတကယ် ပြောင်းလဲသည့်အခါ ကိုယ်တိုင် ပိတ်သွားခြင်း ဖြစ်သည်။

### အသစ်

**လုပ်ဆောင်သော မှတ်ချက်များ**

- **မှတ်ချက်ကို လုပ်ငန်း ဖြစ်အောင် လုပ်ခြင်း။** မှတ်ချက် တစ်ခု သို့မဟုတ် ထို့ထက်ပို ရွေးပြီး {{ui:Tasks}} tab ကိုဖွင့်ကာ {{ui:Make selected a task}} ကို ရွေးပါ။ လုပ်ငန်းတစ်ခုတွင် title၊ လုပ်ဆောင်ရန် လူတစ်ဦး သို့မဟုတ် ချိတ်ဆက်ထားသော assistant၊ ရွေးချယ်နိုင်သော due day နှင့် state ရှိပြီး စာရွက်ပေါ်ရှိ နေရာနှင့် ၎င်း၏ thread ကို ထိန်းသည်။ [Make a markup a task](topic:markups-that-act) ကို ကြည့်ပါ။
- **ကိုယ်တိုင် ပိတ်သော လုပ်ငန်းများ။** လုပ်ငန်းတစ်ခုသည် ၎င်း၏ မှတ်ချက်အတွင်းရှိ ပုံဆွဲကို စောင့်ကြည့်နိုင်သည်။ စာရွက်၏ revision အသစ်ကို ဖွင့်ပြီး {{ui:Check now}} ကို ရွေးပါ- ထိုဧရိယာရှိ မျဉ်းများသည် ဆံပင်တစ်ချောင်းထက် ပိုပြောင်းခဲ့လျှင် လုပ်ငန်းကို Done အဖြစ် မှတ်ပြီး မှတ်ချက်သည် Completed ဖြစ်လာကာ thread ရှိ မှတ်စုက ဘာပြောင်းခဲ့သည်ကို ပြောသည်။ ရက်စွဲ တံဆိပ်အသစ်၊ သို့မဟုတ် 1.5 point ထက်နည်းစွာ ရွေ့သော မျဉ်းများကို မရေတွက်ပါ။ လုပ်ငန်းသည် မော်ဒယ် element တစ်ခုကို စောင့်ကြည့်နိုင်ပြီး၊ သင့် assistant က element ကို `tasks_check` ဖြင့် တင်ပြသည်၊ နောက်ပိုင်း အစီရင်ခံချက် ကွဲပြားခြင်း သို့မဟုတ် element ဖျက်ခြင်းသည် လုပ်ငန်းကို ပိတ်သည်။ Undo အဆင့်တစ်ခုဖြင့် ပြန်ဖွင့်နိုင်သည်။
- **အလုပ်ကို ရှာခြင်း။** {{ui:Tasks}} စာရင်းကို state နှင့် ဘယ်သူ့အတွက်လဲဆိုသည်ဖြင့် စစ်ထုတ်ပါ၊ {{ui:Overdue}} ပါဝင်သည်; {{ui:Assigned to}} ကို ရွေးပြီး {{ui:Assistant}} ကို ရွေးလျှင် သင့် assistant ကို စောင့်နေသည့်အရာများကို ပြသည်။ Due day ကျော်သော လုပ်ငန်းသည် Problems panel တွင် သတိပေးချက်အဖြစ် ပြသည်။ {{ui:CSV}} သည် စာရင်းကို ထုတ်ယူသည်။ လုပ်ငန်းများကို မှတ်ချက်နှင့်အတူ PDF တွင် သိမ်းပြီး Live မှတစ်ဆင့် အခြား markup property များကဲ့သို့ ရွှေ့သည်။

**ပြောင်းလဲချက်များ ရိုးရိုးစာရင်းအဖြစ်**

- **ပြောင်းလဲချက်များကို စာရင်းပြုစုခြင်း။** {{ui:Compare}} tab ကိုဖွင့်ပြီး {{ui:Compare a whole set}} ကို ရွေးကာ စောစောပိုင်းနှင့် နောက်ပိုင်း ဖိုင်များကို ရွေးပြီး {{ui:List the changes}} ကို ရွေးပါ။ စာရင်းသည် အရေအတွက်ဖြင့် စတင်ပြီး ပြောင်းလဲသော စာရွက်တစ်ခုစီကို အကြီးဆုံး ပြောင်းလဲမှု ဦးစွာ ဖော်ပြသည်- စာရွက်ပေါ် အဘယ်နေရာ၊ အရွယ်အစား (တိုင်းတာထားသော စာရွက်တွင် အမှန်ယူနစ်နှင့် စက္ကူ လက်မ)၊ မျဉ်းများ ထည့်ခြင်း/ဖယ်ရှားခြင်း၊ ထိုနေရာရှိ မှတ်ချက် အရေအတွက်နှင့် ပေါ်လာ/ပျောက်သွားသော စာလုံးများ။ {{ui:Copy the list}} သည် clipboard သို့ ထည့်ပေးပြီး {{ui:CSV}} သည် ပြောင်းလဲမှုတစ်ခုလျှင် အတန်းတစ်ခု ရေးသည်။ [List what changed between revisions](topic:what-changed-in-words) ကို ကြည့်ပါ။

**အသံမှတ်စုများနှင့် ဆုံးဖြတ်ချက်များ**

- **အသံမှတ်စုများ။** {{ui:Notes}} tab တွင် {{ui:Record a voice note}} ကို ရွေးပြီး {{ui:Stop recording}} ကို ရွေးပါ; အသံသွင်းခြင်းသည် မိနစ် 2 ပြည့်လျှင် အလိုအလျောက် ရပ်သည်။ မှတ်စုသည် စာရွက်၏ အလယ်တွင် ပင်ထိုးထားပြီး ဆွဲ၍ သင့်နေရာသို့ ရွှေ့ပါ၊ {{ui:Properties}} တွင် ခေါင်းစဉ်ရိုက်ပါ၊ စာရင်းရှိ {{ui:Play}} သည် ဖွင့်ပေးသည်။ အသံကို PDF အတွင်း သိမ်းသည်။
- **ဆုံးဖြတ်ချက်များ။** {{ui:Pin a decision}} သည် စာရွက်ပေါ်တွင် စာကြောင်း တစ်ကြောင်း သို့မဟုတ် နှစ်ကြောင်း ရေးသည်။ အဟောင်း ဆုံးဖြတ်ချက်ကို အစားထိုးလျှင် {{ui:It replaces}} တွင် ထိုဆုံးဖြတ်ချက်ကို ရွေးပါ: အဟောင်းသည် Replaced ဟု မှတ်ပြီး ကျန်ရှိကာ အသစ်ကို ညွှန်ပြသည်။ Undo အဆင့်တစ်ခုဖြင့် ပြန်ရုတ်နိုင်သည်။ [Pin voice notes and decisions on a sheet](topic:voice-notes-and-decisions) ကို ကြည့်ပါ။

**Redline မှ revision သို့**

- **ပို့ပြီး ပြန်ဖြေခြင်း။** {{ui:Tasks}} tab တွင် {{ui:Redline to revision}} ကိုဖွင့်ပါ၊ မှတ်ချက်များ နှိုင်းယှဉ်ထားသော revision ကို ရိုက်ထည့်ပြီး {{ui:Export redline file}} ကို ရွေးပါ။ ဖွင့်ထားသော မှတ်ချက် တစ်ခုစီအတွက် ပစ္စည်းတစ်ခုပါသော `.redline.json` ဖိုင်ကို ရရှိသည်- စာရွက်၊ နေရာ (စာရွက်၏ အစိတ်အပိုင်းအဖြစ်၊ ထို့ကြောင့် အခြားအရွယ်တွင် ပြန်ထုတ်လျှင်လည်း ကိုက်ညီသည်)၊ စာလုံးများ၊ ရေးသူ၊ thread နှင့် ၎င်း၏ လုပ်ငန်း။ ပုံဆွဲပြင်သူက `.redline-answers.json` ဖိုင်တွင် Accepted၊ Rejected သို့မဟုတ် Done ဟု ပြန်ဖြေသည်; {{ui:Load answers file…}} သည် မှတ်ချက်တစ်ခုစီကို ထို status နှင့် drafter ၏ မှတ်စုကို ပေးပြီး undo အဆင့်တစ်ခုတည်း ဖြစ်သည်။ [Send markups to the drafter as a redline](topic:redline-to-revision) ကို ကြည့်ပါ။

**AI assistant များ**

- **ကိရိယာ ပိုများလာခြင်း။** CadCraft Studio မှတစ်ဆင့် ချိတ်ဆက်ထားသော assistant သည် လုပ်ငန်းများကို စာရင်းပြနိုင် (`tasks_list`)၊ တစ်ခုကို ပြုလုပ် သို့မဟုတ် ပြောင်း (`task_set`)၊ ဖယ်ထုတ် (`task_clear`)၊ နောက် revision သို့မဟုတ် element တစ်ခုနှင့် စစ်ဆေး (`tasks_check`) နှင့် ဖွင့်ထားသော ပုံဆွဲအစုနှစ်ခုကြား ပြောင်းလဲချက်များ၏ ရိုးရိုးစာရင်းကို ဖတ် (`revisions_changes`) နိုင်သည်။ Assistants switch အောက်တွင် သင်ရွေးထားသော ကိရိယာများသာ ရရှိပြီး ပြောင်းလဲချက်တိုင်း undo အဆင့်တစ်ခု ဖြစ်သည်။ [Use MarkupCraft with an AI assistant](topic:use-with-ai-assistants) ကို ကြည့်ပါ။

### အက်ပ်အားလုံးတွင်

- **Input devices။** {{ui:Settings}} › {{ui:Global}} › {{ui:Input devices}} သည် trackpad၊ mouse ၏ ဘေးခလုတ်များ၊ pen၊ လက်ထိတ်ပုတ်ခြင်း၊ 3D mouse၊ game controller သို့မဟုတ် MIDI controller ၏ လုပ်ဆောင်ချက်ကို အက်ပ်အားလုံး သို့မဟုတ် ဤအက်ပ်တစ်ခုတည်းအတွက် သတ်မှတ်သည်။ ပြောင်းမချင်း ကိရိယာအားလုံး ယခင်အတိုင်း အလုပ်လုပ်သည်။ [Use a trackpad, 3D mouse or controller](common:input-devices) ကို ကြည့်ပါ။
- **Toolbar အတန်းများ။** {{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}} တွင် {{ui:Wrap}} (မူလ)၊ {{ui:2 rows}} နှင့် {{ui:1 row}} ရှိပြီး ပုံဆွဲအတွက် နေရာ ပိုရသည်။ [Arrange the panels](common:arrange-panels) ကို ကြည့်ပါ။
- **Property grid။** မှတ်ချက်၏ Style အကွက်များသည် မျှဝေထားသော grid ကို သုံးပြီး ခေါက်ဖွင့်နိုင်သော အမျိုးအစားများနှင့် label နှင့် value column များ ရှိသည်။
- **Problems panel။** Overdue လုပ်ငန်းကဲ့သို့ အက်ပ်မှ သတိပေးချက်များ တစ်နေရာတည်းတွင် စုဝေးသည်။
- **Live နှင့် add-on များ။** Live session များကို [Work together live](common:work-together-live) တွင် ဖော်ပြထားပြီး သင့်အကောင့်နှင့်ဆိုင်သော add-on စာရင်းကို [Add-ons and your account list](common:addons-basics) တွင် ကြည့်ပါ။
- **သင့် AI ကို ချိတ်ဆက်ပါ။** CadCraft Studio သည် သင့်ကိုယ်ပိုင် assistant အတွက် hub ဖြစ်ပြီး အက်ပ် ရှစ်ခုလုံးအတွက် တစ်ကြိမ်ချိတ်ဆက်ရုံ ဖြစ်သည်။ အက်ပ်များတွင် ကိုယ်ပိုင် AI မပါပါ။

### ဤဗားရှင်းတွင် မပါသေးသည်များ

- **Code-sign မလုပ်ရသေးပါ။** Windows installer များနှင့် macOS .dmg တွင် လက်မှတ် မပါသေးပါ။ Windows တွင် SmartScreen က installer ကို ရပ်ပါက {{ui:More info}} ကို ရွေးပြီး {{ui:Run anyway}} ကို ရွေးပါ။ Mac တွင် CadCraft Studio ကို right-click လုပ်ပြီး {{ui:Open}} ကို ရွေးပါ။ Store build များ ရပ်ဆိုင်းထားသည်။
- **သင့် AI ချိတ်ဆက်ခြင်းသည် အချို့နေရာတွင် မပြီးသေးပါ။** Studio အတွင်း တစ်ချက်နှိပ်ချိတ်ဆက်ခြင်း၊ browser assistant အတွက် hosted connector နှင့် Studio အတွင်း သင့်ကိုယ်ပိုင် API key တို့ကို ဤဗားရှင်းတွင် ကတိမပေးပါ။ လုပ်ငန်း loop ကို စမ်းသပ်ပြီးပြီ၊ သို့သော် အစစ်အမှန် assistant နှင့် မစမ်းသပ်ရသေးပါ။
- **Task စစ်ဆေးမှုသည် တူညီသော စာမျက်နှာအရွယ် လိုအပ်သည်။** အခြားအရွယ်တွင် ပြန်ထုတ်ထားသော စာရွက်သည် မကိုက်ညီသဖြင့် ၎င်း၏ လုပ်ငန်းများ မပိတ်ပါ။ စာရွက်များကို စာရွက်နံပါတ်ဖြင့်၊ မရလျှင် စာမျက်နှာ နေရာဖြင့် တွဲသည်။
- **အသံမှတ်စုများသည် အသံသွင်းချက်သာ ဖြစ်သည်။** စာသားမှတ်တမ်း မရှိပြီး assistant သည် မှတ်စု၏ အရှည်၊ ရေးသူနှင့် ခေါင်းစဉ်ကို မြင်သည်၊ အသံကို မကြားပါ။ အသံသွင်းခြင်းကို headless browser တွင် အတုမိုက်ခရိုဖုန်းဖြင့် စမ်းသပ်ထားသည်; ဖုန်း၊ tablet သို့မဟုတ် laptop ပေါ်ရှိ အစစ်အမှန် မိုက်ခရိုဖုန်းကို ဆက်စစ်ရဦးမည်။
- **PDF ရှိ Calc sheet များနှင့် အကြောင်းပြချက်များ** ကို ဖိုင်၏ ကိုယ်ပိုင် entry တွင် သိမ်းသည်။ ယခင် MarkupCraft သည် ထို entry ကို လျစ်လျူရှုပြီး နောက်တစ်ကြိမ် သိမ်းသည့်အခါ ဖျက်သည်၊ ထို့ကြောင့် ထိုဖိုင်များကို 0.8 သို့မဟုတ် နောက်ဗားရှင်းဖြင့် ဖွင့်ပြီး သိမ်းပါ။
- **Redline ဖိုင်ကို ဖတ်ပြီး ပြန်ဖြေခြင်းသည် drafter ဘက်မှ** CadCraft တွင် မတည်ဆောက်ရသေးပါ။
- **အခြား ဘာသာစကားများ။** Tamil ၏ app bar သည် 528 px ကျော်သွားသည်။
