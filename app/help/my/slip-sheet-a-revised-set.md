ဒီဇိုင်းပုံကြမ်းများ၏ issue အသစ် ရောက်လာသောအခါ slip-sheeting သည် သင်၏ သုံးသပ်ချက်ကို အသစ်သို့ ရွှေ့ပါသည်: စာရွက်အသစ်တိုင်းသည် တူညီသော နံပါတ်ရှိ စာရွက်ဟောင်း၏ မှတ်ချက်များကို ယူပြီး စာရွက်ဟောင်းကို "Superseded" ဟု stamp ထုတ်ပါသည်။

## Slip-sheet

1. လက်ရှိ set ကို သင့်မှတ်ချက်များနှင့်အတူ ဖွင့်ပါ။
2. {{ui:Pages}} ကို ရွေးပြီး ထို့နောက် {{ui:Slip-sheet a revised set…}} ကို ရွေးပြီး PDF အသစ်များကို ရွေးပါ။ ၎င်းတို့သည် ဟောင်း set ၏ ဘေးတွင် ဖွင့်ပါမည်။
3. Dialog က စာရွက်အသစ်တိုင်းနှင့် ၎င်း အစားထိုးသော စာရွက်ဟောင်းကို ဖော်ပြပါသည်။ အတန်းတစ်ခုကို အမှန်ခြစ်ဖြုတ်လျှင် ထိုစာရွက်၏ မှတ်ချက်များ ၎င်းတို့ရှိနေရာတွင် ဆက်ရှိပါမည်။ နံပါတ်အသစ် ရှိသော စာရွက်များတွင် ယူစရာ မရှိပါ။
4. ပိတ်ထားသော မှတ်ချက်များ (Accepted၊ Rejected၊ Completed) ကို စာရွက်ဟောင်းများပေါ်တွင် ထားမထားနှင့် စာရွက်ဟောင်းများကို stamp ထုတ်မထုတ် ရွေးပါ။
5. **{{ui:Carry markups forward}}** ကို ရွေးပါ။

ရလဒ်: မှတ်ချက်များသည် စာရွက်အသစ်များပေါ်တွင် တူညီသော နေရာတွင်၊ replies၊ statuses နှင့် စာရေးသူများနှင့်အတူ ပေါ်လာပါမည်။ Punch item သည် စာရွက်အသစ်သို့ ရွှေ့ပြီး နံပါတ်ကို ဆက်ထားပါသည်။ စာရွက်ဟောင်းများသည် မှတ်ချက်များကို မှတ်တမ်းအဖြစ် ဆက်ထားပြီး အနီရောင် "Superseded" stamp အောက်တွင် ရှိပါသည်။ Status bar က ရွှေ့ထားသည်များကို စုစည်းပြပါသည်။

{{ui:Just open the files}} သည် မည်သည့်အရာကိုမျှ မယူဘဲ set အသစ်ကို ဖွင့်ပါသည်၊ ဥပမာ နှိုင်းယှဉ်ခင် ကြည့်ရန်။ See [Compare two revisions](topic:compare-revisions)။

## စာရွက်များကို ဘယ်လို ကိုက်ညီစေသလဲ

- **စာရွက်နံပါတ်ဖြင့်**: စာရွက်များ list ပြသသည့်အတိုင်း ဖတ်သည်: {{ui:Rename sheet}} ဖြင့် သင်ရိုက်ထားသော နံပါတ်၊ PDF ၏ page label၊ သို့မဟုတ် title block။ Case၊ space၊ dot နှင့် dash သည် အရေးမကြီးပါ: "A-101" သည် "a101" နှင့် ကိုက်ညီပါသည်။
- ဖွင့်ထားသော ဖိုင်နှစ်ခုတွင် ထိုနံပါတ်ရှိ စာရွက်ရှိပါက အသစ်ဆုံးကို အစားထိုးပါသည်၊ ထို့ကြောင့် issue တစ်ခီးပြီးတစ်ခီး slip-sheet လုပ်နိုင်ပါသည်။
- **စကင်ဖတ်ထားသော sets** တွင် ဖတ်ရန်နံပါတ် မရှိပါ။ ဖိုင်အသစ်တွင် နံပါတ်မရှိသောအခါ ၎င်း၏စာမျက်နှာများကို ဖွင့်ထားသော စာမျက်နှာအရေအတွက် တူညီသည့် ဖိုင်တစ်ခုနှင့် စာမျက်နှာအစဉ်အတိုင်း ကိုက်ညီစေပါသည်။ ယူမီမတိုင်မီ ထိုအတန်းများကို စစ်ဆေးပါ။

## သိထားရန်

- {{key:Mod+Z}} တစ်ကြိမ်ဖြင့် slip-sheet တစ်ခုလုံးကို ပြန်ယူပါသည်: မိတ္တူများ၊ stamps နှင့် ရွှေ့ထားသော punch items များ။ ဖိုင်အသစ်များသည် ဖွင့်ထားဆဲ ရှိပါသည်။
- စာရွက်အသစ်သည် အရွယ်အစား မတူပါက မှတ်ချက်များကို စာမျက်နှာနှင့်အတူ scale ပြောင်းပြီး status bar က စစ်ဆေးရမည့် အရေအတွက်ကို ပြပါသည်။
- စာရွက်အသစ်သည် အရွယ်တူပြီး scale မရှိသောအခါ စာရွက်ဟောင်း၏ scale ကို ယူပါသည်။
- အခြား program များက ပြုလုပ်သော comments များသည် စာရွက်ဟောင်းပေါ်တွင် ဆက်ရှိပါသည်: ဤနေရာတွင် ဖတ်ရုံသာ ဖြစ်ပါသည်။
- ယူထားသော မှတ်ချက်များကို ထိန်းထားရန် ဖိုင်အသစ်များကို သိမ်းပါ။ See [Save the marked-up PDF](topic:save-the-marked-up-pdf)။
