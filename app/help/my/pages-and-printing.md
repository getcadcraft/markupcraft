{{ui:File}} အုပ်စုရှိ {{ui:Pages}} menu သည် ဖွင့်ထားသော sheet ပိုင်သည့် PDF ပေါ်တွင် အလုပ်လုပ်ပါသည်။ ဤကွန်ပျူတာပေါ်ရှိ PDF ကို ဘယ်တော့မှ မပြောင်းပါ: ပြောင်းလဲမှုများသည် သင်သိမ်းသော မိတ္တူ၏ အစိတ်အပိုင်း ဖြစ်ပါသည်။

## ပရင့်ထုတ်ခြင်း

1. {{key:Mod+P}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:Pages}} ကို ရွေးပြီး {{ui:Print…}} ကို ရွေးပါ။
2. sheet တစ်ခုထက်ပို ဖွင့်ထားလျှင် ပရင့်ထုတ်မည့်အရာကို ရွေးပါ: {{ui:This sheet}}၊ ဤဖိုင်၏ စာမျက်နှာအားလုံး၊ set တစ်ခုလုံး သို့မဟုတ် သင်ရိုက်ထည့်သော စာမျက်နှာများ (ဥပမာ `1-3, 5`)။
3. {{ui:Print}} ကို ရွေးပါ။ သင့် browser ၏ printer dialog ဖွင့်ပါမည်: printer, စက္ကူနှင့် scale ကို ဤနေရာတွင် ရွေးပါ။

markup များသည် sheet ပေါ်တွင် ကြည့်ရသည့်အတိုင်း ပရင့်ထွက်ပါသည်: ၎င်းတို့ကို ပရင်တာသို့ သွားသော မိတ္တူ၏ စာမျက်နှာများထဲ ဆွဲထားသည်။ အခြား ပရိုဂရမ်များ ပြုလုပ်ထားသော မှတ်ချက်များသည် ၎င်းတို့ PDF ပြောသည့်အတိုင်း ပရင့်ထွက်ပါသည်။

:::safari firefox
သင့် browser က စာမျက်နှာအတွင်းမှ ပရင့်မထုတ်နိုင်လျှင် sheet များကို tab အသစ်တွင် PDF အဖြစ် ဖွင့်ပါမည်။ ထိုနေရာမှ ပရင့်ထုတ်ပါ။
:::

## စာမျက်နှာ လှည့်ခြင်း

{{ui:Pages}} ကို ရွေးပြီး {{ui:Rotate page clockwise}} သို့မဟုတ် {{ui:Rotate page counterclockwise}} ကို ရွေးပါ။ ဖွင့်ထားသော sheet သည် ၉၀ ဒီဂရီ လှည့်ပါမည်။ ၎င်း၏ markup များသည် ပုံဆွဲချက်ပေါ်တွင် မူလနေရာတွင် ရှိနေဆဲ ဖြစ်ပြီး သင်ရိုက်ထားသော စာသားသည် စာမျက်နှာနှင့်အတူ လှည့်သဖြင့် ဒေါင်လိုက် ဖတ်ရပါသည်။

## စာမျက်နှာ ရွှေ့ခြင်း

{{ui:Pages}} ကို ရွေးပြီး {{ui:Move page earlier}} သို့မဟုတ် {{ui:Move page later}} ကို ရွေးပါ။ ဖွင့်ထားသော sheet သည် ၎င်း၏ PDF အတွင်း နိုင်ဘူးနေရာနှင့် နေရာလဲလှယ်ပါမည်။ ၎င်း၏ markup များ၊ scale နှင့် sheet နံပါတ်တို့ လိုက်ပါလာပါမည်။

## စာမျက်နှာ ထည့်ခြင်း

- {{ui:Insert pages from a PDF…}} သည် အခြား PDF ၏ စာမျက်နှာအားလုံးကို ဖွင့်ထားသော sheet ၏ နောက်တွင် ထည့်ပါသည်။
- {{ui:Insert a blank page}} သည် ဖွင့်ထားသော sheet ၏ နောက်တွင် အရွယ်တူ အလွတ်စာမျက်နှာ တစ်ခု ထည့်ပါသည်၊ ပုံဆွဲချက်နှင့် မှတ်စုများအတွက်။ {{ui:New}} ဖြင့် ပြုလုပ်ထားသော set တွင် set ၏ grid လည်း ပါဝင်ပါသည်။
- {{ui:New}} ဖြင့် ပြုလုပ်ထားသော set တွင် {{ui:Sheets}} စာရင်းအောက်ရှိ {{ui:Add a blank page}} သည် နောက်ဆုံးတွင် အခြားစာမျက်နှာများကဲ့သို့ တစ်ခု ထပ်ထည့်ပါသည်။ [အလွတ်စာမျက်နှာများဖြင့် စတင်ခြင်း](topic:open-a-plan-set#start-with-blank-pages) ကို ကြည့်ပါ။

ထည့်ထားသော စာမျက်နှာများသည် အမည်မပြောင်းမချင်း ၎င်းတို့၏ စာမျက်နှာနံပါတ်ကို label အဖြစ် ရရှိပါသည်။ [sheet အမည်ပြောင်းခြင်း](topic:open-a-plan-set#rename-a-sheet) ကို ကြည့်ပါ။

## စာမျက်နှာများ ဖျက်ခြင်း

1. {{ui:Pages}} ကို ရွေးပြီး {{ui:Delete pages…}} ကို ရွေးပါ။
2. ဤ PDF ၏ စာမျက်နှာနံပါတ်များကို ရိုက်ပါ၊ ဥပမာ `3` သို့မဟုတ် `2-4`။ ဖွင့်ထားသော sheet ၏ စာမျက်နှာကို ဖြည့်ပြီးသား ဖြစ်ပါသည်။
3. {{ui:Delete pages}} ကို ရွေးပါ။ ထိုစာမျက်နှာများတွင် markup ရှိလျှင် MarkupCraft က အရေအတွက်ကို ပြပြီး ထပ်မေးပါမည်။

PDF တစ်ခုတွင် စာမျက်နှာအနည်းဆုံး တစ်ခု ကျန်ပါသည်။ ဖိုင်တစ်ခုလုံးကို ဖယ်ရန် set ကို ပိတ်ပြီး လိုအပ်သော ဖိုင်များကို ပြန်ဖွင့်ပါ။

## စာမျက်နှာ ထုတ်ယူခြင်း

{{ui:Pages}} ကို ရွေးပြီး {{ui:Extract pages…}} ကို ရွေးကာ စာမျက်နှာများကို ရိုက်ပါ။ ၎င်းတို့ကို "<file> (pages 1-3).pdf" ဟု အမည်ပေးထားသော PDF အသစ်အဖြစ် download လုပ်ပါမည်၊ markup များသည် ဆက်လက် တည်းဖြတ်နိုင်သော မှတ်ချက်များအဖြစ် ပါဝင်ပါသည်။ ဖွင့်ထားသော ဖိုင်သည် မူလအတိုင်း ရှိနေပါသည်။

## သိထားသင့်သည်များ

- **Undo သည် စာမျက်နှာပြောင်းလဲမှုတွင် ရပ်သည်။** {{key:Mod+Z}} သည် ထို့နောက် ဆွဲထားသော markup များကို ပြန်ဖျက်ပါသည်၊ သို့သော် စာမျက်နှာပြောင်းလဲမှု ကိုယ်တိုင် သို့မဟုတ် ၎င်းရှေ့ရှိ အရာများကို မပြန်ဖျက်ပါ။ အစမှ ပြန်စရန် မသိမ်းဘဲ ပိတ်ပြီး မူလ PDF မှ ပြန်စပါ။
- စာမျက်နှာနံပါတ်များသည် PDF တစ်ခု၏ စာမျက်နှာများကိုသာ ရေတွက်ပြီး set တစ်ခုလုံးကို မဟုတ်ပါ။ စာမျက်နှာရွှေ့ခြင်းသည် ၎င်းကို ၎င်း၏ဖိုင်အတွင်း ထားပါသည်။
- ပြောင်းထားသော စာမျက်နှာများသည် မသိမ်းရသေးသော အလုပ်ဖြစ်ပါသည်: {{ui:Save}} သည် စီစဉ်ပြီးသော မိတ္တူကို download လုပ်ပါမည်၊ ထွက်သည့်အခါ မေးပါမည်။
