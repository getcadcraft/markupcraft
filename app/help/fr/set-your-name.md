Chaque annotation enregistre qui l'a créée et quand. Les tampons affichent le nom (« Par Ana Ruiz, 10 oct. 2026 »), les réponses l'affichent, la liste des annotations peut filtrer par nom, et les autres lecteurs PDF l'affichent comme auteur du commentaire.

## Connecté : le nom de votre compte

Si vous êtes connecté à votre compte CadCraft, MarkupCraft utilise le nom de votre compte et ne le demande jamais. Les annotations, les réponses, les tampons et la barre d'état l'affichent. Dans {{ui:Paramètres}} › {{ui:MarkupCraft}} › {{ui:Votre nom}}, il est indiqué « Depuis votre compte (votre nom) ».

- Pour utiliser un autre nom, choisissez {{ui:Utiliser un autre nom}} et saisissez-le. Un nom que vous saisissez l'emporte dès lors.
- Pour revenir au nom de votre compte, choisissez {{ui:Utiliser le nom de mon compte}}.

Seul le nom est utilisé, jamais votre adresse e-mail. Si vous changez de nom sur le site, MarkupCraft l'affiche à sa prochaine ouverture.

## La première fois (non connecté)

Lorsque vous n'êtes pas connecté, la première fois que vous choisissez un outil de dessin, une boîte intitulée « Votre nom sur les annotations » s'ouvre.

1. Saisissez votre nom comme vous voulez que les relecteurs le voient (80 caractères maximum).
2. Choisissez {{ui:Enregistrer (S)}}.

Résultat : votre nom apparaît à l'extrémité droite de la barre d'état, et chaque nouvelle annotation le porte.

Si vous choisissez {{ui:Pas maintenant}}, les annotations sont créées sans auteur (« Non renseigné » dans {{ui:Propriétés}}), et les tampons n'affichent que la date. MarkupCraft le redemande à la prochaine ouverture.

## Modifier

1. Cliquez sur votre nom (ou « Définir votre nom ») à l'extrémité droite de la barre d'état.
2. Saisissez le nouveau nom et choisissez {{ui:Enregistrer (S)}}.

Ou ouvrez {{ui:Paramètres}} ({{key:Mod+,}}), restez sur l'onglet {{ui:MarkupCraft}} et saisissez-le sous {{ui:Votre nom}}. Voir [Paramètres de MarkupCraft](topic:settings).

Seules les annotations que vous créez à partir de maintenant reçoivent le nouveau nom. Les annotations déjà dessinées gardent le nom sous lequel elles ont été créées ; il n'existe aucun moyen de changer l'auteur d'une annotation existante.

## Où le nom est conservé

Votre nom est enregistré **dans ce navigateur, sur cet ordinateur** (le stockage local du navigateur pour ce site web). Cela signifie que :

- Un autre navigateur sur le même ordinateur, ou le même navigateur sur un autre ordinateur, le redemande.
- Une fenêtre privée ou de navigation incognito le demande à chaque fois, et l'oublie à sa fermeture.
- Effacer les données de ce site (cookies et données de site) dans les paramètres du navigateur fait oublier le nom.
- Rien n'est envoyé nulle part. Le nom ne quitte cet ordinateur que dans les PDF que vous enregistrez.

:::safari
Safari peut effacer les données d'un site web si vous ne l'avez pas visité depuis un moment. Si MarkupCraft vous redemande votre nom, c'est pour cette raison.
:::

Si plusieurs personnes partagent un ordinateur et une session de navigateur, chacune doit vérifier le nom dans la barre d'état avant de commencer, puisqu'il est partagé.

Voir aussi [Ce qui reste dans ce navigateur](topic:browser-storage).
